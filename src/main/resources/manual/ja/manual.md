@@ workflow | 制作フロー
PSD2Live は、レイヤー分けされた PSD を動く Live2D モデルにそのまま変換します。読み込むと、メッシュ、デフォーマ、パラメータ、待機とまばたきのモーション、物理演算が一度に生成されます。そのうえで形を整え、モーションを足し、Cubism やほかのランタイム向けに書き出します。Cubism を開かなくてもモデルは完成させられます。
## 学習ルートを選ぶ
ヘルプページのインタラクティブチュートリアルは、現在のワークスペース上で要点となるコントロールをハイライトし、あなたのショートカット設定に合わせて操作を案内します。Live2D が初めてなら、次のルートから始めてください。分割済み PSD、パーツ、パラメータの説明から書き出しまでを通して進めます。
{path=BEGINNER}
Cubism を使ったことがあるなら、このルートでまずアートメッシュ、デフォーマ、パラメータを PSD2Live に対応づけ、そのあと自動生成、キャンバスモード、ボーン、アニメーション、物理演算をまとめて説明します。
{path=EXPERIENCED}
## PSD から書き出しまで
1. **PSD を用意する**：動くパーツごとに別のレイヤーにし、レイヤー名にはパーツがわかるように書きます（[[precautions-for-psd-data]] を参照）。
2. **生成する**：スタートページの **PSD から生成** でプリセット（最小 / 標準 / フル）を選び、PSD をウィンドウにドラッグするか {key:OPEN_PSD} を押します。生成後は自動的に編集ワークスペースに入ります（[[psd-import]]、[[model-presets]] を参照）。
3. **認識結果を確認する**：**レイヤー** パネルで各レイヤーのタグ（パーツ、左右）と差分を確認し、誤認識があればその場で修正します（[[layers-palette]] を参照）。
4. **プレビューする**：キャンバスモードメニューで **プレビュー** を選び、待機、まばたき、マウス追従、物理演算が自然か確認します（[[preview-canvas]] を参照）。
5. **必要に応じて編集する**：編集キャンバスで変形、編集、ボーン、描画などのモードを使ってキーフォーム、メッシュ、ピクセルを修正し、物理演算パネルとモディファイアパネルで揺れとシミュレーションを調整します（[[canvas-modes]]、[[modifiers]] を参照）。
6. **保存する**：{key:SAVE_PROJECT} で `.psd2live` として保存します。元画像、すべての編集、分岐履歴が含まれます。
7. **書き出す**：{key:GENERATE} で **Live2D モデルを書き出し…** を開き、`.moc3` ランタイムファイルまたは `.cmo3` プロジェクトを書き出します。ほかの形式は **ファイル → 形式を指定して書き出し** にあります。
PSD から始めない方法もあります。**レイアウトプロジェクト** は空のキャンバスに画像、PSD、SVG 素材を配置してから生成します（[[layout-project]] を参照）。**CMO3 から読み込み** は既存の Cubism モデルの編集を続けます（[[cmo3-import]] を参照）。
## 再生成しても編集は消えない
キャンバス上の変更はすべて、再生可能な編集として記録されます。レイヤーのタグやモデルプリセットを変えるとモデルが元画像から再生成され、あなたの編集が元の順序で適用し直されます。PSD2Live をアップグレードしても既存のプロジェクトが黙って変わることはありません。新しいジェネレーターを使いたいときは **モデル → 生成結果を更新** を実行します（[[update-generated-rig]] を参照）。
*> Cubism Editor で仕上げを続けるときは `.cmo3` を書き出します。Cubism で変更したモデルは **モデル → CMO3 で現在のモデルを置き換え…** で ID を照合してプロジェクトに戻せます（[[modeling-menu]] を参照）。

@@ file-type-and-extension | ファイルの種類と拡張子
日常で覚えておくのは 1 種類だけです。`.psd2live` がプロジェクト本体で、それ以外は読み込む素材か、書き出す成果物です。

| `.psd2live.json` | 書き出し時に付くレポート（書き出しウィンドウでオフにできる）。損失と警告を記録するもので、プロジェクトファイルではない |
## 読み込み
| 拡張子 | 説明 |
|---|---|
| `.psd` | レイヤー付き PSD。モデルを生成する元画像 |
| `.cmo3` | Cubism Editor のモデルプロジェクト。新規プロジェクトの作成や現在のモデルの置き換えに使う |
| `.png` `.webp` `.tiff` `.bmp` | 階層（挿入マークの位置に入れる・挿入する）や編集キャンバス（離した位置に置く）にドラッグするか、**レイヤーをインポート…** で 1 枚のレイヤーとして追加する。素材ライブラリにも登録される |
| `.svg` などの画像 | レイアウトプロジェクトの素材ライブラリに読み込む |
## 書き出し
| 拡張子 | 説明 |
|---|---|
| `.cmo3` / `.can3` | Cubism Editor のモデルプロジェクト。モーションがあるときは同名の `.can3`（Animator プロジェクト）も書き出され、同じフォルダーに置く |
| `.moc3` `.model3.json` など | Cubism ランタイムのファイル一式。モデル、設定、物理演算、モーション、表示情報、テクスチャで、`.model3.json` から読み込む |
| `.vtube.json` | `.moc3` のファイル一式と一緒に書き出され、VTube Studio が読み取る |
| `.p2lrt` | PSD2Live ランタイムモデル。Web プレーヤーでも使う |
| `.p2lunity` | Unity プレハブ書き出しのモデルデータ |
| `.psd` | 指定したポーズのレイヤー付き PSD、または生成レイヤーを含む元の PSD |
| `.png` `.gif` `.apng` `.webp` `.mp4` `.webm` `.mov` | 連番画像、スプライトシート、アニメーション画像、動画 |

各形式の内容と制限は [[export-moc3-motion3-files]] と [[exporting-images]] を参照してください。

@@ fault-map | Editor／Viewerが正常に起動しない場合の確認事項
表示がおかしい、プレビューが開かない、プログラムが予期せず終了する、といったときは、まず次の表を確認してください。多くは再インストールしなくても解決できます。
## よくある状況
| 症状 | 対処 |
|---|---|
| 編集キャンバスが真っ黒、ちらつく、表示が崩れる | **設定 → キャンバス操作** で「編集キャンバスとアトラスページをソフトウェアで描画」をオンにします。同じ場所に現在使っているのが GPU かソフトウェア描画かが表示されます。GPU がマルチサンプリングに対応していない場合や GPU 描画に失敗した場合は、プログラムが自動的に互換モードへ切り替えます |
| プレビューキャンバスで Cubism SDK が使えない | 使える Cubism SDK のネイティブライブラリがないときは、プレビューキャンバスの **プレビューランタイム** で PSD2Live ランタイムに切り替えます。XWayland のない純粋な Wayland や musl の Linux では自動的にフォールバックします |
| パネルが見当たらない | ワークスペースのタブバー右側の **ウィンドウ** メニューでもう一度チェックを入れるか、**レイアウトをリセット** を選びます |
| キャンバスにモデルが表示されない | {key:FRAME_VIEW} で選択対象に合わせるか、{key:RESET_CAMERA} でカメラをリセットし、レイヤーの表示/非表示を確認します |
| プログラムが異常終了した | 次回起動時に、保存していない編集を復元するか尋ねられます（[[autosave]] を参照） |
| 設定や画面の状態がおかしい | 設定ページの目次の下部にある **デフォルトに戻す** をクリックします。それでも直らなければプログラムを閉じ、`--clear-user-data` パラメータを付けて一度起動し、設定とローカルデータを消去します |
## 不具合を報告する前に
1. **ログ** パネルを開き、レベルとソースでエラーを絞り込んで **ログをコピー** をクリックします。
2. **設定 → ファイルとデータ** に **エラーログ** の場所が表示されます。異常終了で OS の一時フォルダーに残ったデータもここで整理できます。
3. ヘルプページの **概要** にバージョンと実行環境が表示されます。
4. **ヘルプ → オンライン → 不具合の報告** から、バージョン、OS、再現手順、関連する素材を添えて送信します。

@@ performance | SDKでモデルを扱うときのパフォーマンスについて
書き出したモデルが実行時に軽く動くかどうかは、主にメッシュの頂点数、キーフォームの数、テクスチャサイズ、マスクで決まります。これらの多くはジェネレーターが設定に従って生成するので、制御するときは 1 つずつ頂点を削るのではなく、設定を変更します。
## 確認と調整の場所
| 要因 | 場所 |
|---|---|
| メッシュの頂点数 | **メッシュ** パネルに選択レイヤーの頂点数と辺の長さが表示され、全体の既定値の変更やレイヤーごとの上書きができる。**レイヤー** の情報にも頂点数がある |
| テクスチャサイズとビデオメモリ | 「テクスチャ」ワークスペース：レイヤーを選択していないとき、テクスチャパネルに各ページのサイズ、タイル数、使用量、ビデオメモリ（RGBA）が一覧表示される。右上でアトラス予算（ページサイズ、最大ページ数、間隔）を設定でき、レイヤーごとにテクスチャ密度も調整できる（[[texture-atlas-edit]] を参照） |
| キーフォームの数 | シミュレーションをキーフォーム軸にベイクすると、メッシュのキーフォーム数がモードのキー点の数だけ増える。「ブレンドシェイプ」（Cubism 4.2+）を選ぶと避けられ、「自動」はキーフォームが 64 個を超えるとブレンドシェイプに切り替える（[[simulation]] を参照） |
| ターゲットバージョン | 書き出し時に、選んだ SDK ターゲットが対応しない機能が取り除かれ、ダウングレードされた項目が一覧表示される（[[target-version-selection]] を参照） |
書き出しレポート `.psd2live.json` にはダウングレードと損失が記録されるので、納品前に一度確認しておくとよいでしょう。
## エディターでのプレビューの負荷
プレビューキャンバスの **フレームレート上限** でフレームレートを制限したり、ディスプレイに合わせたりできます。プレビューメニューの **拡張モード** は PSD2Live ランタイムでのみ有効で、布と髪のシミュレーションをリアルタイムで実行します。動作が重いときは先にこれをオフにしてください。

## 自動生成で加わった概念
| 用語 | 意味 |
|---|---|
| モデルプリセット | 生成するモーション、物理演算、シミュレーションを制御する設定。変形量と口形状は各ロールコンポーネントのカードにある（[[model-presets]]、[[modifiers]] を参照） |
| タグ | レイヤーのパーツや左右など。ジェネレーターはこれでパーツを認識する |
| 差分 | 差分なし、差分トグル（1 つのパラメータで有無を制御）、差分切替（同じパラメータで 1 つを選ぶ）（[[variants]] を参照） |
| 生成結果 | 元画像とプリセットから自動生成されたモデル。あなたの編集はその上に再適用される |
| キャンバスモード | オブジェクト、変形、編集、シミュレーション、ボーン、描画、プレビュー（[[canvas-modes]] を参照） |

| 変形パス | 曲線に沿ってメッシュを変形するツール。書き出し時にメッシュのキーフォームへベイクされる |
| ボーン / シミュレーション | スケルトンと布・髪のシミュレーション。書き出し時にパラメータ、キーフォーム、振り子へベイクされる |
| ベイク | Cubism にない機能をネイティブのデフォーマ、キーフォーム、振り子に変換すること |
| アトラス | 各レイヤーのピクセルをまとめたテクスチャページ。レイヤーごとにテクスチャ密度を設定できる |
| 参照レイヤー | キャンバスに表示されるが、生成にも書き出しにも使われないレイヤー |

@@ shortcut | ショートカットキー一覧
下の表はすべてのショートカットと現在の割り当てです。既定は Photoshop スタイルで、**設定 → ショートカット** の「プリセット」で Blender スタイルや Live2D Cubism スタイルに切り替えたり、項目ごとにキーを変更したりできます。Cubism スタイルは Photoshop のキー配置に Cubism Editor でよく使うキーを加えたもので、Cubism から来たときに手に馴染みやすくなります。
## キーを変更する
1. {key:OPEN_SETTINGS} で設定を開き、**ショートカット** を選びます。
2. キーのセルをクリックし、新しいキーの組み合わせを押します。セル上でマウスホイールを回すか、マウスボタンを押しても入力できます。{kbd:Esc} で録画をキャンセルします。
3. 他の操作と競合すると通知されます。同じ操作に予備のキーを追加でき、「このショートカットを戻す」で 1 項目を元に戻せます。
!> プリセットを切り替えると、カスタムしたキーはすべて上書きされます。
このマニュアルとインタラクティブチュートリアルに表示されるキーは、現在の割り当てに追従します。

@@ target-version-selection | ターゲットバージョン選択
ターゲットバージョンは、書き出す `.moc3` / `.cmo3` で使える Cubism の機能を決めます。PSD2Live では書き出し時のオプションの 1 つです。編集中はすべての機能を気にせず使え、古いバージョンへ書き出すときにプログラムが代わりにダウングレードします。同じプロジェクトを別々のバージョン向けに書き出すこともできます。
## ターゲットを選ぶ
1. {key:GENERATE} で **Live2D モデルを書き出し…** を開きます。
2. **SDK ターゲット** のドロップダウンで Cubism 3.0、3.3、4.0、4.2、5.0、5.3 のいずれかを選びます（既定は 5.0）。
3. モデルがターゲット非対応の機能を使っていると、ウィンドウに「使用中の機能は書き出し時にダウングレードされます」と表示され、形式、機能、対象が 1 項目ずつ一覧表示されます。
## よくあるダウングレード項目
| 機能 | 説明 |
|---|---|

@@ canvas-modes | キャンバスモード
キャンバスモードは、キャンバス上で何を変更するかを決めます。形状、メッシュ、ボーン、ピクセルのどれかです。各キャンバス左上のモードメニューにすべてのモードが並び、メニューを開いている間は 1–7 で直接選べます。切り替えると、左側のツールバーがそのモードのツールに変わります。
## モード一覧
| モード | 編集する内容 | ショートカット |
|---|---|---|
| オブジェクト | オブジェクトを選択し、Warp、回転デフォーマ、変形パスを作成する | {key:MODE_SELECT} |
| 変形 | 基本形状、または現在のパラメータキー上のキーフォーム | {key:MODE_DEFORM} |
| 編集 | メッシュのトポロジーとパスのバインド、グルー | {key:MODE_EDIT} |
| シミュレーション | 布と髪のシミュレーションが読む頂点ウェイトグループ | {key:MODE_SIMULATE} |
| ボーン | スケルトンのポーズと構造 | {key:MODE_SKELETON} |
| 描画 | レイヤーのピクセル | {key:MODE_PAINT} |
| プレビュー | 編集せず、再生と確認を行う | {key:MODE_PREVIEW} |
変形は形状を変え、編集はメッシュの構造を変えます。この 2 つが最も混同しやすい組み合わせです。描画はピクセルを変更し、独立したセッションの中で行われ、個別に取り消せます。最後にモードバーで適用するか破棄します。
{tutorial=HIERARCHY}
## オブジェクトモードで選択する
1. モードメニューで **オブジェクト** を選ぶか、{key:TOOL_SELECT} でクリック選択ツールを有効にします。必要に応じて投げ縄 {key:TOOL_LASSO_SELECT} やブラシ選択 {key:TOOL_BRUSH_SELECT} に切り替えます。
2. クリックで選択します。{kbd:Shift} で追加選択、{kbd:Alt} で選択解除、{kbd:Ctrl} + クリックで重なった複数のオブジェクトの間を階層順に切り替え、ドラッグで矩形選択、{key:SELECT_ALL} で全選択します。
3. 選択は階層と同期します。{key:FRAME_VIEW} で選択対象をビューの中央に表示します。
4. 対象を選んだら、使いたいモードに切り替えます。対象を選んでいないときは、先に選択するよう案内が出ます。
ほかのモードでも {key:TEMPORARY_SELECT} を押している間は一時的に選択に切り替わり、離すと元に戻ります。{key:TOGGLE_OBJECT_MODE} でオブジェクトモードと前回使ったモード（既定は変形）を切り替えます。配置や頂点配置の線などの複数ステップの操作は、モードバーの「確定」か {kbd:Enter} で完了し、{key:CANCEL} でキャンセルします。
{tutorial=SELECT_MODE}
*> シミュレーション、ボーン、描画は Cubism にないモードです。その結果は書き出し時にパラメータ、キーフォーム、振り子へベイクされるか、テクスチャに直接書き込まれます。

@@ preview-canvas | プレビューキャンバス
プレビューキャンバスは書き出し後のモデルを再生するもので、モーション、物理演算、シミュレーションの確認に使い、モデルは変更しません。`.moc3` の書き出しと同じコンパイル結果を使うので、ここで見える状態がそのまま納品される内容です。
## プレビューを開く
- キャンバスモードメニューで **プレビュー**（{key:MODE_PREVIEW}）を選びます。ほかのモードを選ぶと編集に戻ります。
- **表示 → プレビューキャンバスを追加**（{key:NEW_PREVIEW_TAB}）、または **ウィンドウ → プレビューキャンバスを追加**。
- 「プレビュー」「アニメーション」「物理演算」など、プレビューキャンバスを備えたワークスペースに切り替えます。
## プレビューオプション
| 項目 | 作用 |
|---|---|
| 待機アニメーション | 待機モーションを再生または停止する |
| マウス追従 | 頭と視線がマウスに追従する。「滑らかな追従と身体 Y」をオンにできる |
| 物理演算 | 物理演算のオン/オフ |
| プレビューランタイム | Cubism SDK（書き出した moc3 を公式 Cubism 5 ランタイムで再生）または PSD2Live ランタイム（書き出した .p2lrt） |
| 拡張モード | PSD2Live ランタイムのみ：円弧に沿ったスキニング、正確なリンク、布と髪のリアルタイムシミュレーション |
| フレームレート上限 | ディスプレイに合わせる、または FPS を固定する |
キャンバス下部には現在のランタイム、物理演算の状態、ズーム倍率が表示されます。シミュレーションがまだベイクされていないときは案内が出ます。
!> 参照シミュレーションはエディター内でのみ動作し、書き出されません。書き出しファイルに含めるには、シミュレーションのカード、またはモディファイアパネルの **ワールド** ページでベイクする必要があります。

@@ guide-function | ガイド機能
ガイドは定規からドラッグで引き出す水平・垂直の参照線です。パーツの位置合わせ、左右対称の確認、キーフォームの目標位置の目印に使います。ガイドはプロジェクトと一緒に保存され、履歴には入らず、書き出されることもありません。
## 定規とガイドの表示
- キャンバス右下の表示レールで **ガイド** をクリックします（{key:TOGGLE_GUIDES}）。キャンバスの上端と左端に定規が現れ、目盛りの単位はキャンバスのピクセルです。
- 表示するかどうかは編集キャンバスごとに決まります。ガイド自体はプロジェクトに属し、すべての編集キャンバスで同じものを共有します。
## 操作
| 操作 | 方法 |
|---|---|
| 追加 | 上の定規から下へドラッグで水平ガイド、左の定規から右へドラッグで垂直ガイド |
| 移動 | 選択系のツールか **変形** のとき、ガイドの上でポインタが両矢印になったらドラッグ。ブラシ、作成ツール、ペイントモード、Shift や Alt を押した操作はガイドの近くでもそのまま働き、ポインタの下のハンドルもガイドより優先されます |
| 削除 | ガイドを定規へドラッグして戻す。または表示レールの **キャンバス補助設定…** で **すべてのガイドを消去**。同じメニューの **消去したガイドを戻す** で直前に消去したガイドを戻せます |
| ロック | **キャンバス補助設定…** で **ガイドをロック** をオン（{key:LOCK_GUIDES}）。ロック中のガイドは破線で表示され、追加もドラッグもできません |
| スナップ | **グリッドとガイドにスナップ** をオンにすると（{key:TOGGLE_SNAP}）、ドラッグした点がガイドに近づくと線に揃います |
ガイドの色は **キャンバス補助設定…** でテーマの色から選ぶので、どのテーマでも見やすいままです。
*> Cubism と違い、ロックと色は表示レールの設定メニューで切り替え、専用のガイドダイアログはありません。スナップとグリッドがオンのときは、ドラッグ中のガイドもグリッド線に吸着します。

@@ solo | Solo機能
単独表示（Solo）は選択したレイヤーだけを表示し、ほかのレイヤーを一時的に隠します。髪や服に隠れたパーツを確認するときに便利です。
## 使い方
1. 階層でレイヤーを右クリックします。
2. 「表示」グループで **このレイヤーのみ表示** を選ぶと、メニュー項目の横に `SOLO` の印が付きます。
3. 確認が終わったら、もう一度右クリックして **単独表示を解除** を選ぶと、ほかのレイヤーは単独表示する前の表示/非表示の状態に戻ります。
単独表示は現在のキャンバスにだけ作用し、同じワークスペースのほかのキャンバスは通常どおり表示されます。
*> 単独表示は編集中の一時的な表示切り替えにすぎません。パラメータに応じてパーツを表示/非表示にしたいときは、差分か不透明度のキーフォームを設定してください（[[variants]] を参照）。

@@ grid | グリッド機能
グリッドはドキュメントの範囲に等間隔の参照線を描き、メッシュの点、デフォーマ、パーツの位置合わせに使います。編集キャンバスにだけ表示され、モデルや書き出しには影響しません。
## グリッドの表示
キャンバス右下の表示レールで **グリッド** をクリックします（{key:TOGGLE_GRID}）。
## 設定
表示レールの **キャンバス補助設定…** で調整します。
| 項目 | 内容 |
|---|---|
| 間隔 | 主グリッド線の間隔（キャンバスのピクセル、2–1024） |
| 分割数 | 1 マスをさらに何分割するか。1 なら主線のみ |
| 不透明度・色 | 線の濃さと色。色はテーマの色から選びます |
縮小すると、詰まりすぎる分割線は自動で隠れ、必要に応じて主線の間隔も倍に広がるので、画面が線で埋まることはありません。
## スナップ
**グリッドとガイドにスナップ** をオンにすると（{key:TOGGLE_SNAP}）、メッシュやデフォーマの点をドラッグしてグリッド線に近づける（約 6 ピクセル以内）と、点が線の上に乗ります。吸着するのはポインタではなくつかんだ点なので、点そのものが線に揃い、選択中のほかの点も同じだけ動きます。クリックや選択はポインタの位置のままです。吸着するのは現在の倍率で見えている段階のグリッド線です。ペイントと変形ブラシはストロークが線に引き寄せられないよう吸着しません。

@@ snapshot | スナップショット機能
@@ onion-skin | オニオンスキン
オニオンスキンは、隣のキーや隣のフレームの形を半透明で現在の表示に重ねます。形を作るときは前後のキーの形が、アニメーションを作るときは前後のフレームの流れが見えます。編集キャンバスにだけ表示され、プロジェクトには書き込まれず、書き出されることもありません。
## オニオンスキンの表示
アニメーションパネルのツールバー右端で **オニオンスキン** をクリックします（{key:TOGGLE_ONION_SKIN}）。対象は現在の編集キャンバスで、現在のキャンバスがプレビューキャンバスのときは最初の編集キャンバスです。重ねる内容は状況で変わります。
| 状況 | 重ねる形 |
|---|---|
| アニメーションパネルでモーションを開いている | 再生ヘッドの前後で「フレーム間隔」ごとに取ったフレーム |
| モーションを開いていない | パラメータパネルで最後に設定したパラメータの、現在値の前後にあるキー。選択中のオブジェクトにそのパラメータのキーがあればそのキー、なければモデル全体のキー |
オニオンスキンのボタンのツールチップに、いまどちらを重ねているかが表示されます。
## 設定
オニオンスキンの右の矢印から、前と後の数（0–5）、フレーム間隔、不透明度、前と後それぞれの色を調整します。現在の姿勢から遠い層ほど薄くなります。
*> オニオンスキンはキャンバスの表示フィルタ（選択のみ表示、レイヤーの表示）に従います。パラメータスナップショットのホバープレビュー中とペイントモードでは表示されません。

@@ multiview | マルチビュー
1 つのワークスペースに複数のキャンバスを置けます。たとえば編集キャンバスとプレビューキャンバスを並べて、キーフォームを編集しながら完成状態を見たり、編集キャンバスを 2 つ置いて、一方で細部を拡大し、もう一方で全身を見たりできます。
## キャンバスを追加する
1. ワークスペースのタブバー右側の **ウィンドウ** メニューを開きます。
2. **編集キャンバスを追加** か **プレビューキャンバスを追加** を選ぶと、新しいキャンバスがワークスペースにドッキングされます。タイトルをドラッグすると位置を変えられます。
3. 不要になったら、**ウィンドウ** メニューの「キャンバス」グループでチェックを外すか、そのまま閉じます。ワークスペースには少なくとも 1 つのキャンバスを残します。
## 独立するもの、共有されるもの
| キャンバスごとに独立 | 共有 |
|---|---|
| 選択、ツール、カメラ、表示設定、キャンバスモード | パラメータのポーズ、パラメータロック、再生コントロール |
そのため、編集キャンバスでパラメータをドラッグすると、プレビューキャンバスにも同じポーズが反映されます。
*> 2 つの異なるパラメータのポーズを並べて比較したいときは、2 つのワークスペースに分けてください。ワークスペースごとにポーズが保持されます。

@@ random-pose | ランダムポーズ
ランダムポーズは、パラメータをそれぞれの範囲内のランダムな値に設定し、多くのパラメータの組み合わせを一度に確認して、突き抜けや破れ、暴れる変形を見つけるための機能です。
## 使い方
1. パラメータパネルのツールバーでサイコロの **ランダムポーズ** をクリックします（{key:RANDOM_POSE}）。クリックするたびに別の姿勢になります。
2. 確認が済んだら、サイコロの右の矢印メニューで **ポーズを戻す** をクリックします（{key:RESTORE_RANDOM_POSE}）。パラメータは最初のランダムポーズの前の値に戻ります。
## 対象のパラメータ
サイコロの右の矢印メニューで選びます。
| 項目 | 内容 |
|---|---|
| ロックされていない全パラメータ | すべてのパラメータが対象。パラメータパネルでロックしたパラメータは動きません |
| 編集中のパラメータ | パラメータパネルで最後に設定したパラメータだけ。プレビューキャンバスなど、このキャンバスで設定したパラメータがないときはロックされていない全パラメータが動きます |
| 範囲 | 各パラメータが既定値からどこまで離れてよいか。100% で範囲の両端まで |
ランダムポーズはスライダーをドラッグしたときと同じように現在の姿勢を設定しますが、開いているモーションに自動でキーを打つことはありません。

@@ toolbar | ツールバーについて
ツールバーは各キャンバスの左上、モードメニューの下にあり、現在のモードで使えるツールだけが並びます。同じ種類のツールは 1 つのスロットにまとめられ、最後に使ったものが表示されます。このスロットをもう一度クリックするか右クリックすると残りのツールが展開し、ホバーすると名前とショートカットが表示されます。
## モードごとのツール
| モード | ツール |
|---|---|
| オブジェクト | 選択、変形、投げ縄選択。Warp 作成、回転作成、変形パス |
| 変形 | 選択、変形、投げ縄選択、ブラシ選択。押し引きブラシ、スムーズブラシ、膨張・収縮 |
| 編集 | 変形モードのツールに、頂点配置、再分割、グルー（2 つのメッシュを選択したときに使える）を加えたもの |
| シミュレーション | ウェイトブラシ、ウェイトグラデーション。下に描画するウェイトグループが並ぶ |
| ボーン | ボーンのポーズ、ボーンを編集 |
| 描画 | ブラシ、鉛筆、消しゴム。塗りつぶし、スポイト。図形 |
バリエーションのあるツール（ブラシの形状、グルーとボーンのサブツール、ウェイトグループの種類、描画の図形）は、選択するとバリエーションがアイコンで並び、{key:PICK_OPTION_1}–{key:PICK_OPTION_5} で直接切り替えられます。
## 数値を調整する場所
| 場所 | 内容 |
|---|---|
| モードバー（キャンバス上部） | 点 / 辺 / 面の選択、現在のステップの確定とキャンセル |
| ツールオプションバー（キャンバス左下） | 半径、強さ、硬さ、不透明度など。数値を左右にドラッグして調整し、クリックするとスライダーが開く |
| キャンバスの右クリックメニュー | オプションバーと同じ数値に、そのツールの操作を加えたもの |
| ツール詳細パネル | より広いスペースが必要な詳細設定（[[detailed-toolpalatte]] を参照） |
ブラシの大きさと硬さはショートカットでも直接調整できます。たとえば {key:BRUSH_RADIUS_DOWN} / {key:BRUSH_RADIUS_UP} です。

@@ edit-level | 編集レベル
ワープデフォーマ（Warp）を編集するとき、1 点ずつ細かく調整したい場合もあれば、メッシュ全体を 1 本の弧に曲げたいだけの場合もあります。変形モードの 2 つの編集レベルがこの 2 つの要望に対応します。**頂点** と **ベジェ** です。
## レベルを切り替える
1. ワープデフォーマを選択して、変形モードに入ります。
2. モードバーで **頂点**（{key:PICK_OPTION_1}）か **ベジェ**（{key:PICK_OPTION_2}）を選びます。
3. 頂点レベルでは制御点を 1 つずつ直接ドラッグします。ベジェレベルではシアンのアンカーと琥珀色のハンドルだけをドラッグし、メッシュ全体が曲線に沿って滑らかに曲がります。細かい格子は薄く表示され、編集できません。
対象がワープデフォーマでないときはモードバーにレベルは表示されず、アートメッシュの頂点は従来どおり点、辺、面で選択して編集します。
## 関連設定
インスペクタパネルとツール詳細パネルの **ベジェ分割数**（1–16）がベジェレベルの分割数を決め、**ベジェ制御点をリセット** でハンドルが既定の位置に戻ります。
{tutorial=DEFORM_MODE}
*> Cubism の編集レベル 1–3 は表示する点の密度を制御します。ここには頂点とベジェの 2 段階しかなく、ワープデフォーマにのみ有効です。

@@ palatte-basic-operation | パレットの基本操作
キャンバスとパネルはどちらもドッキングできるモジュールで、ドラッグするだけで作業に合ったレイアウトを組めます。レイアウトはそれぞれのワークスペースに記憶されるので、崩してしまっても影響はそのワークスペースだけです。
## 基本操作
| やりたいこと | 操作 |
|---|---|
| 並べ替え、またはタブグループにまとめる | モジュールのタブを同じ列の別の位置、または別の列のタブの間にドラッグする |
| 分割 | モジュールを目的の領域の上、下、左、右の端にドラッグして離すと新しい列ができる。区切り線をドラッグして比率を調整する |
| グループごと移動 | タブバーの空白部分、または右端の淡い色のハンドルをドラッグする |
| フローティング | メインウィンドウの外へドラッグして独立したウィンドウにする。フローティングウィンドウのタイトルバーの **ワークスペースに戻す** で戻す |
| 閉じる | タブを中クリックする。タブを右クリックして **同じグループの他のタブを閉じる** や **同じグループのタブをすべて閉じる** も選べる |
| 再表示 | **ウィンドウ** メニューでチェックを入れる、または **レイアウトをリセット** |
タイトルバー右上のサイドバーボタンで、片側のパネルをまとめて折りたたんだり展開したりでき、ホバーすると中のモジュールが表示されます。スタート、ヘルプ、設定ページのパネルも同じように整理できます。

| ツール | 設定 |
|---|---|

| Warp作成 / 回転作成 | 作成時の既定値。ベジェ分割数など |

@@ inspector-palette | インスペクタパレット
**インスペクタ** パネルは選択したオブジェクトのプロパティを表示して編集します。内容はオブジェクトの種類によって変わり、何も選択していないときは案内が表示されます。
## 主なプロパティ
| オブジェクト | プロパティ |
|---|---|
| アートメッシュ | 名称、クリッピングマスク、描画順、不透明度、乗算色、スクリーン色、ブレンドモード、カリング、ユーザデータ、頂点情報 |
| ワープデフォーマ | ベジェ分割数、編集レベルの設定、デフォーマの変換方式 |

{tutorial=INSPECTOR}
*> ジェネレーターが生成したキーフォームに変更を加えた場合、インスペクタの「生成結果の上書き」に、再生成できれいに統合できない項目が一覧表示されます。

@@ partspalatte | パーツパレット
パーツパレットをお探しの場合：オブジェクトの階層は **階層** に、PSD レイヤーの認識と差分は **レイヤー** パネルにあります（[[layers-palette]] を参照）。階層はアートメッシュをデフォーマの親子関係のまま並べ、`.cmo3` の書き出し時にパーツが書き込まれます。
## 階層
- ルートノード「モデル階層」にデフォーマとレイヤーの数が表示されます。
- 上部のバーでデフォーマとレイヤーを検索でき、すべて展開/折りたたみや、モデル順、高さ、水平位置、描画順、名称での並べ替えもできます。
- 目のアイコンで表示/非表示を切り替えます。ツリーでのクリック選択はキャンバスのハイライトと同期します。

@@ convert-id | IDの変換
パラメータ、パラメータグループ、パーツ、デフォーマ、アートメッシュの ID を新しい ID に変えます。たとえば Cubism 2 形式の `PARAM_ANGLE_X` を Cubism 3 標準の `ParamAngleX` にします。参照はすべて追従します。キーフォームとブレンドシェイプが使うパラメータ、親とパーツ、クリッピングマスク、グルー、パス、頂点グループ、結合パラメータとパラメータグループ、モーションカーブ、自分で作った物理演算グループとスイングの対象です。標準 ID で生成される物理演算、モーション、表情も、変換したパラメータを見つけます。
## ID を変換する
1. **モデル → IDの変換…**。
2. **オブジェクト** でパラメータ、パラメータグループ、アートメッシュ、ワープデフォーマ、回転デフォーマ、パーツのいずれかを選び、**絞り込み** で一覧を絞ります。
3. 変えたいオブジェクトの横に新しい ID を入力します。**Cubism 3 標準 ID を入力** は、Cubism 2 形式のパラメータ（`PARAM_…`）とパーツ（`PARTS_01_…`）に対応する標準 ID を入力します。
4. **変換** をクリックします。まとめて 1 つの履歴になり、元に戻せます。
新しい ID は英字で始まる英数字とアンダースコアで、同じ種類のオブジェクトと重複できません（ワープデフォーマと回転デフォーマは同じ ID 空間です）。使えない ID のときはダイアログの下に理由が表示されます。規則でまとめて変えるには [[search-and-replace]] を参照してください。
## 書き出し前のチェック
書き出し時に ID をチェックします。同じ種類のオブジェクトが ID を共有していると書き出しを中止し、重複した ID を示します。英数字とアンダースコア以外の文字を含む ID は警告だけです。
!> スイング、シミュレーション、内部造形が生成または参照するパラメータとメッシュは単独では変換できません。先にそれぞれのパネルで外してください。ボーンにバインドされたメッシュ、ボーンのパラメータとデフォーマも変換できません。変換すると、現在のポーズ、パラメータスナップショット、タイムラインのブックマーク、デフォーマの表示状態も新しい ID に追従し、取り消すと元に戻ります。
*> Cubism と違い、変換表ファイルは読み書きしません。変換はプロジェクトの履歴に記録され、以後の編集は新しい ID を使い、モデルを生成し直しても順番どおりに再生されます。

@@ autosave | 自動バックアップ機能
編集中、PSD2Live は保存されていない変更をこのマシンのワークスペースストレージに書き込み続けます。万一プログラムがクラッシュしたり停電したりしても、次回の起動時にそれらの変更を取り戻せるので、バックアップファイルを手作業で探す必要はありません。
## 復元する
1. 変更を保存または破棄する前にプログラムが異常終了したら、PSD2Live を再起動します。
2. 「未保存の編集を復元」ウィンドウが表示されたら **復元** を選びます。**破棄** を選ぶと復元されません。
3. プロジェクトは未保存の状態で開き、履歴、パラメータのポーズ、スナップショット、ワークスペースはそのまま残っています。{key:SAVE_PROJECT} で保存します。
正常に保存または破棄して終了すると、復元データは消去されます。クラッシュ時に実行中だったバックグラウンドタスクは記録が表示されますが、自動的に再実行されることはありません。
!> 復元された内容はまだ保存されていません。早めに `.psd2live` として保存してください。
## 保存場所
**設定 → ファイルとデータ** にワークスペースストレージの場所とサイズが表示され、開いているプロジェクトの履歴はここに保存されています。異常終了で OS の一時フォルダーに残ったデータもここで整理できます。

@@ material | 素材分け・PSD作成
@@ divide-the-material | 素材分けについて
PSD2Live は、レイヤー分けされた PSD から動くモデルを直接生成できます。その前提として、別々に動くパーツや、互いに隠し合うパーツは別のレイヤーに描かれている必要があります。うまく分けるほど、自動生成されたメッシュ、デフォーマ、パラメータの手直しが少なくなります。
## 分け方
- パーツごとに 1 レイヤー：白目、瞳、上まつ毛、眉、鼻、口、前髪、後ろ髪、顔、首、上着など。
- 瞳は完全な円として描き、まぶたに隠れる部分も描きます。白目が瞳の表示範囲を制限します。
- 口は最大に開いた状態を描き、閉じた口はプログラムが生成します。口腔は 1 レイヤーにまとめても、上の歯、下の歯、舌にさらに分けてもかまいません。
- 前髪と後ろ髪は分け、隠れる部分を多めに描いておくと、髪が揺れたときに下地が見えません。
- 左右一対のパーツ（両目、両耳、両腕）は左右 2 つのレイヤーに分け、名前に左右を明記します。
レイヤー名はジェネレーターに各レイヤーがどのパーツかを伝えます。命名規則と認識できる名前は [[precautions-for-psd-data]] を参照してください。
## 分け漏れてもエディターで補える
同じレイヤーに描かれた左右のパーツは、読み込み時に自動では分かれません。読み込み後に [[split-by-mesh]] で連結領域ごとに独立したレイヤーへ分割できます。1 つのレイヤーが別のパーツの前と後ろの両方に現れる必要があるとき（襟が首を回り込む場合など）は [[depth-split]] を使います。素材が複数のファイルにあって 1 つの PSD に合成しにくいときは、[[layout-project]] で画像を直接配置してから生成できます。

@@ reimport-psd | インポートPSDの作り方
PSD を用意するときにいくつかのルールを守れば、読み込み後すぐに動くモデルが得られ、レイヤーごとの手動バインドを省けます。
## ファイル
- RGB、8 ビット、背景透明のレイヤー付き PSD を使います。
- テキスト、ベクター、レイヤースタイル、調整効果は、先にラスタライズするか、対応するピクセルレイヤーに統合します。
- 体はおおむね正立させ、頭は少し傾けてもかまいません。読み込み後、自動推定された基準をプレビューで確認します。
## レイヤー名がパーツを決める
ジェネレーターはレイヤー名でパーツを認識します。英語、中国語、日本語、韓国語のどれでもよく、たとえば `front hair`、`前发`、`eyelash-l`、`左睫毛` などです。認識結果は初期値にすぎず、読み込み後に「レイヤー」パネルの **タグ** 列でいつでも修正できます。
*> Cubism に慣れている方へ：PSD のフォルダー構造はパーツになりません。パーツはジェネレーターが認識したパーツに従って作るので、フォルダーよりレイヤー名のほうが重要です。
- 左右はキャラクター自身から見た側を指します。キャラクターの左側は通常、画面の右にあります。
- 名前の数字（`front hair 1` など）は同種の素材を区別するためだけに使います。Photoshop が自動で付けるコピーの接尾辞は取り除かれます。
- 数字から表情の切り替えは作られません。パラメータに応じて表示/非表示や切り替えをしたいレイヤーは、読み込み後に [[variants]] を設定します。
## キャンバスサイズ
メッシュ設定は既定で **ドキュメントサイズに合わせる** になっており、メッシュの長さは長辺を固定サイズに換算したドキュメントを基準に計算されます。そのため大きな PSD でも同じ密度のメッシュになります。鮮明さはレイヤー自体のピクセルで決まります。

@@ precautions-for-psd-data | PSD作成上の注意点
自動生成はレイヤー名とレイヤーの分け方に依存します。以下は認識できるレイヤー名と、描くときに最も問題になりやすい点のまとめです。表にない名前のレイヤーも失われません。読み込み後に「レイヤー」パネルの **タグ** 列でパーツを補ってください。
!> 名前の認識に成功しても、造形が合格とは限りません。読み込み後、ニュートラルポーズ、目と口の開閉、頭の回転、髪の動きを確認し、レイヤー順、左右、マスク、下地の露出を点検してください。

@@ split-by-mesh | メッシュごとにレイヤーを分割
1 つのレイヤーに互いに離れた部分が複数描かれているとき（たとえば両目が同じレイヤーにある場合）は、エディターでメッシュの連結領域ごとにそのまま分割できます。それぞれが独自のメッシュ、変形、タグを持つので、お絵かきソフトに戻って PSD を直す必要はありません。
## レイヤーを分割する
1. **モデル → メッシュごとにレイヤーを分割…** を開くと、独立した複数のメッシュを含むすべてのレイヤーがダイアログに一覧表示されます。**すべて選択** / **選択解除** のあと **選択したレイヤーを分割** をクリックします。1 つのレイヤーだけを処理するときは、階層でそのレイヤーを右クリックして **独立したメッシュを分割…** を選ぶか、キャンバスの右クリックメニューの **メッシュ** から選びます。
2. 各領域のプレビューを確認し、名前の付け方を選びます。2 つのときは `L / R`、`T / B`、`1 / 2` または **名前を指定** を選べ、3 つ以上のときは番号か名前の指定になります。
3. **レイヤーを分割** をクリックします。分割したくないときは **1 レイヤーのまま** をクリックし、一括処理では **すべて1レイヤーのまま** をクリックできます。
`L / R` はキャラクター自身の左右で名前が付きます。画面の左側の部分には `-r` の接尾辞が付いて右側とされ、もう一方は `-l` になります。
レイヤーの読み込み後に、プログラムが自動で分割するかどうかを尋ねることもあります。今後この確認を表示したくないときはダイアログでチェックを入れるか、**設定 › 確認ダイアログ** で「レイヤーのインポート時にメッシュ分割を提案」をオフにします。
## 分割後
元のレイヤーはパーツに置き換わり、メッシュは元のメッシュの対応する部分から取られ、元のレイヤー上のキーフォーム、ブレンドシェイプ、パス、ウェイト、グルーは各パーツに引き継がれます。あとで特定のパーツのメッシュ設定を変えると、そのパーツ自身のピクセルからメッシュが再生成され、これらのバインドが引き継がれます。
任意の形状で分けたいときや、1 つのレイヤーを前後に入り組ませたいときは [[depth-split]] を使います。
!> CMO3 から読み込んだモデルはメッシュごとに分割できません。

@@ depth-split | 前後に分層
襟の後ろ側は首の後ろに隠れ、前側は首の前に重なる。このように 1 つのレイヤーが別のパーツの前と後ろの両方に現れる場合は、**前後に分層** を使えばエディターの中で 1 ステップで解決できます。プログラムがレイヤーを複製して中間のオブジェクトを挟む前後 2 つのレイヤーにし、描画順を自動で整え、グルーで 2 つのレイヤーを一緒に変形させます。あなたは前のレイヤーで、後ろに隠れるべき部分を消すだけです。
## 操作手順
1. 編集キャンバスで **オブジェクト** モードに切り替え、分層したいレイヤー（たとえば上着）を選択し、{kbd:Shift} を押しながら間に挟むオブジェクト（たとえば首）を追加選択します。
2. 分層したいレイヤーを右クリックし、「**レイヤー名** を前後に分層」を選びます。メニューには複製されるオブジェクトが表示されるので、クリックする前に確認します。
3. プログラムが「`レイヤー名 · 後`」と「`レイヤー名 · 前`」の 2 つのレイヤーを作成して元のレイヤーに置き換え、前のレイヤーを選択して **描画** モードの **消しゴム** に切り替えます。
4. 間のオブジェクトの縁に沿って、前のレイヤーのうち隠れるべき部分を消します。消しすぎたときは描画セッション内で元に戻せます。
5. **適用** をクリックします。前のレイヤーは元のメッシュと変形を保つので、メッシュを再生成する必要はありません。
6. パラメータパネルで頭の回転や体の回転などのパラメータをドラッグして確認し、必要なら前のレイヤーに戻って縁を整えます。
{tutorial=PAINT_MODE}
1 つのレイヤーだけを選択しているときは、階層でそれを右クリックして **前後に分層…** を選び、ポップアップの **間に挟むパーツ** で中間のオブジェクトを選び、前のレイヤー、中間、後ろのレイヤーの関係を確認してから **作成して消しゴムへ** をクリックします。
## 注意事項
- 一度に分層できるレイヤーは 1 つです。中間のオブジェクトは複数追加選択でき、それらはまとめて前後のレイヤーの間に置かれ、互いの順序を保ちます。
- 作成直後は見た目がすぐには変わりません。前のレイヤーは最初は完全な複製で、消したあとに遮蔽の効果が現れます。
- 未確定の描画セッションがあるときは、先に適用または破棄してから作成してください。
!> CMO3 から読み込んだモデルは、前後に分層にまだ対応していません。

@@ layout-project | Layout プロジェクトと素材ライブラリ
レイアウトプロジェクトでは、先にキャンバス上でパーツを配置してパーツを指定し、そのあとバインドを生成します。生成後も画像を追加したりタグを変えたりして再生成でき、既存の編集はすべて保持されます。素材が複数のファイルに分散している場合や、ほかのツールで分割した場合に向いています。プロジェクトで使うすべての画像は **素材** パネルに置かれ、キャンバス上のレイヤーのピクセルはそれに関連づけられた素材から来ます。
## レイアウトプロジェクトを始める
- **空のキャンバス**：スタートページで **レイアウトプロジェクト**（または **ファイル → 新規作成 → 新規レイアウトプロジェクト…**）を選び、よく使うサイズを選ぶか幅と高さを入力して **レイアウトプロジェクトを作成** をクリックします。
- **PSD から**：通常どおり PSD を読み込むと、プロジェクトはそのままバインドを生成し、PSD の各レイヤーが素材としても登録されてキャンバス上のレイヤーと関連づけられます。
- **レイアウトマニフェストから**：外部ツールが書き出したマニフェスト（JSON、またはルートにそれを置いた zip）を、PSD を開くのと同じ方法で開くと、レイヤーがマニフェストのとおりに配置され、まだ生成はされていません。
## 配置と生成
1. 素材パネルで **読み込み** または **フォルダーを読み込む…** をクリックするか、ファイルをパネルに直接ドラッグします。PNG、BMP、TIFF、WebP、JPEG、SVG、および PSD のレイヤーと CMO3 の各 ArtMesh 画像に対応します。PSD は 1 つのフォルダーになり、レイヤーグループはサブフォルダーになります。
2. 素材またはフォルダー全体をキャンバスにドラッグするか、右クリックして **キャンバスに配置** を選びます。
3. **オブジェクト** モードで変形ボックスを使ってレイヤーを移動、拡大縮小、ミラーします。これらの操作ではピクセルはリサンプリングされません。
4. 「レイヤー」パネルの **タグ** 列でパーツと左右を指定し、**差分** 列で [[variants]] を設定します。
5. 編集キャンバス右上の生成バーで **生成** をクリックします。その後に新しく配置したレイヤーやタグを変えたレイヤーは「生成待ち」と表示され、**再生成** をクリックするとバインドに取り込まれます。
{tutorial=LAYOUT}
*> キャンバスの単位がモデルの大きさと比率を決め、鮮明さは素材自身のピクセルで決まります。レイヤーを小さく配置するほど、テクスチャは密になります。
まだ生成していないレイヤーは {key:LAYER_FORWARD} / {key:LAYER_BACKWARD} で 1 つ上下に動かし、{key:LAYER_TO_FRONT} / {key:LAYER_TO_BACK} で最前面、最背面に置けます。生成後は [[draworder]] を使います。
## 素材を整理する
- 素材をほかのフォルダーにドラッグすれば移動できます。右クリックで名前の変更、フォルダーの新規作成、削除ができます。レイヤーが使用中の素材は削除できません。フォルダーに付けたタグは、そこから配置したすべてのレイヤーに引き継がれます。
- 素材をダブルクリックすると独立した素材ウィンドウが開き、拡大表示、描画、反転、色調整ができ、その素材を使うすべてのレイヤーが一緒に更新されます。
- 素材を右クリックして **選択レイヤーの画像を差し替え** を選ぶと、レイヤーのキャンバス上の位置とサイズはそのままで、ピクセルだけが入れ替わります。[[psd-re-import]] を参照してください。
- すべてのレイヤーはピクセルの唯一の元として素材を 1 つ持ちます。PSD・CMO3・画像の読み込みやレイヤーの分割で登録されます。複数のレイヤーが素材を共有しているときは、どれに描いても素材に描かれます。1 つだけ変えたいときは右クリックで **独立した素材にする** を選びます。古いプロジェクトで素材のないレイヤーがあると、素材パネル上部に **素材ライブラリに登録** が表示されます。
- 原画やラフなど、見比べ用の画像は参考画像または参照レイヤーとして配置できます。[[sketch]] を参照してください。

@@ modeling | モデリング
@@ psd-import-folder | PSDインポート
@@ psd-import | PSDのインポート
レイヤー付き PSD を読み込むと、PSD2Live はレイヤー名でパーツを認識し、メッシュ、デフォーマ、パラメータ、モーション、物理演算を一度に生成して、動くモデルをそのまま得られます。以降の変更はすべて編集として記録され、再生成のときに自動的に再適用されます。どの内容を生成するかは [[model-presets]] が決めます。
## 読み込み
1. **ファイル → 新規作成 → PSD から新規プロジェクト…**（{key:OPEN_PSD}）を選ぶか、PSD をウィンドウのどこかにドラッグします。スタートページで **PSD から生成** をクリックし、まず詳細パネルで **最小** / **標準** / **フル** のプリセットを選んで必要に応じて調整してからファイルを選ぶこともできます。**最近の PSD** ではダブルクリックですぐに生成できます。
2. 生成が完了するまで待ちます。そのあと髪と服のシミュレーションが順にベイクされ、進行状況はステータスバーに表示されます。
3. **レイヤー** パネルを開き、各レイヤーに認識された **タグ**（パーツと左右）を確認します。違っていればクリックして修正します。生成済みのレイヤーは再生成後に新しいタグが使われます。
4. パラメータに応じて表示/非表示や切り替えをしたいレイヤーは、**差分** 列で [[variants]] を設定します。
5. プレビューに切り替えて、まばたき、口形状、頭の回転、髪の動きを確認し、{key:SAVE_PROJECT} で `.psd2live` プロジェクトとして保存します。
{tutorial=BASIC}
選んだプリセットは記憶され、以降メニュー、最近のファイル、ドラッグ＆ドロップで読み込む PSD はそのプリセットで生成されます。PSD の各レイヤーは素材としても登録されるので、[[layout-project]] でさらに画像を追加できます。
*> Cubism から来た方へ：パーツは認識されたパーツに従って自動で作られ、PSD のフォルダーでは分けられません。既存の Cubism モデルプロジェクトは [[cmo3-import]] で開いてください。

@@ psd-re-import | PSDの再インポート
原画を修正したあとは、新しいピクセルだけを既存のプロジェクトに入れ替えられ、モデルに加えた編集はすべて保持されます。PSD2Live は PSD 全体のレイヤー対応づけは行わず、レイヤーごとに入れ替えます。
## レイヤーのピクセルを入れ替える
1. 素材パネルで修正した PSD を **読み込み** ます。新しい素材フォルダーになります。
2. キャンバスまたはレイヤー一覧で、更新したいレイヤーを選択します。
3. 新しい素材を右クリックして **選択レイヤーの画像を差し替え** を選びます。レイヤーのキャンバス上の位置とサイズは変わらず、ピクセルとアトラスのタイルだけが変わります。
4. 生成バーの **再生成** をクリックします。画像を差し替えたレイヤーは、既定では新しいピクセルでメッシュが再構築されます。元のメッシュを残したいときは、生成ボタンのドロップダウンで **差し替えた画像のメッシュは保ったまま生成** を選びます。
1 つのレイヤーは **テクスチャ** パネルの **画像を置き換え…** でも置き換えられます。[[png-file-export-replacement]] を参照してください。原画にパーツが増えたときは、それを新しい素材としてキャンバスにドラッグし、タグを付けてから **再生成** します。[[layout-project]] を参照してください。
!> すでに制作者の編集、バインド、確定済みメッシュがあるレイヤーでは、画像の置き換えとメッシュの再構築が拒否されることがあります。理由はアトラスページの上部に表示されます。
## 最初から再生成する
修正した PSD で完全にやり直したいときは **モデル → PSD を再解析**（{key:REANALYZE}）を使います。現在の PSD を読み直し、現在のプリセットで新しいプロジェクトを生成します。元のプロジェクトの編集は引き継がれません。未保存の変更があるときは、先に保存するか尋ねられます。

@@ model-presets | モデルプリセット
**モデルプリセット** は、モディファイアパネルの **ワールド** ページにある節で、どのモーション、物理演算、シミュレーションを自動生成するかをまとめて決めます。変形量、口形状、各部位のリグの数値は、それぞれのロールコンポーネントのカードで調整します（[[modifiers]] を参照）。変更するとモデルが新しい設定で再生成され、既存の編集はそのまま再適用されるので、気軽に何度も試せます。
## 設定する場所
- 読み込み前：スタートページの **PSD から生成** の詳細パネルで、まず **最小** / **標準** / **フル** を選び、そのあと項目ごとに調整します。生成ボタンのメニューでプリセットを切り替えたり、**現在のモデルに適用** したりできます。
- 読み込み後：モディファイアパネルの **ワールド** ページにある **モデルプリセット** の節（パネルを閉じた場合は **ウィンドウ** メニューから開き直せます）。節内のツールバーですべて展開/折りたたみでき、**デフォルトに戻す** で全プリセットを元に戻します。
## 各グループの内容
| グループ | 内容 |
|---|---|
| モーション | **基本モーション**、**ボーンモーション** の 2 グループ。オフにするとそのグループのモーションがアニメーションパネル、プレビュー、書き出しから取り除かれる |
| 物理演算とシミュレーション | 前髪と後ろ髪はそれぞれ **シミュレート** / **従来の揺れ** / **オフ** を選ぶ。**衣装** シミュレーション（ゆったりした部分にだけ作用）、瞳のゼリー揺れ、Pin 物理ウェイトを自動設定 |
**選択のみ** にチェックを入れると、物理演算とシミュレーションのプリセットは選択したレイヤーにだけ作用します。
*> まず既定値で生成してプレビューし、調整が必要なら一度に 1 項目だけ変えると、各項目の効果がわかりやすくなります。アトラスの設定はここではなく、書き出しウィンドウにあります。

@@ update-generated-rig | 生成結果を更新
髪のシミュレーションの有効化、スケルトンの有効化、レイヤーの分割といった操作は、あなたの編集をそのときの生成結果に統合して固定します。そのため、プログラムをアップグレードしてもモデルが黙って変わることはありません。新しいバージョンのジェネレーターの改善を使いたいときは、自分で **生成結果を更新** を実行します。
## 操作
1. まず **モデル → 生成結果の更新をプレビュー** を選びます。更新でモデルが変わるか、確認が必要な項目がいくつあるかがステータスバーに表示され、プロジェクト自体は変わりません。
2. 次に **モデル → 生成結果を更新** を選びます。あなたが変更していない部分は新しいバージョンの生成結果に置き換わり、あなたの変更は残ります。
3. きれいに引き継げない箇所があると、ステータスバーに件数が表示され、インスペクタパネルの **生成結果の上書き** に 1 項目ずつ一覧表示されます。
更新は履歴の 1 ステップで、元に戻せます。生成結果に変化がないときは履歴は作られません。
プロジェクトを開いたとき、または生成結果が変わったあと、プログラムはバックグラウンドで、古いバージョンで正しく統合されなかった結果がないか確認します。あると編集キャンバスの上部に通知が出て、そこから直接「生成結果を更新」か「変更をプレビュー」をクリックできます。通知を閉じると、生成結果が再び変わるまで表示されません。
*> ジェネレーターが所有するキーフォーム上でのキャンバス編集は、生成結果に対する上書きとして保存され、更新時に新しい結果と 3 方向でマージされるので、手作業で整えた形状が消えることはありません。

@@ cmo3-import | CMO3 から読み込み
既存の Cubism モデルプロジェクト（`.cmo3`）を PSD2Live に読み込んで、編集、プレビュー、書き出しを続けられます。パラメータとキーフォーム、デフォーマと階層、テクスチャとメッシュ、物理演算が引き継がれ、`.psd2live` プロジェクトと一緒に保存されます。CMO3 を書き出せば、Cubism Editor に戻って作業を続けることもできます。
## 2 つの読み込み方法
| 方法 | 入口 | 結果 |
|---|---|---|
| CMO3 から新規プロジェクトを作成 | **ファイル → 新規作成 → CMO3 から新規プロジェクト…**、またはスタートページの **CMO3 から読み込み** | 現在のモデルを空にし、内容はそのファイルのみから来る |
| CMO3 で現在のモデルを置き換え | **モデル → CMO3 で現在のモデルを置き換え…**、またはスタートページの **CMO3 で置き換え…** | 現在のプロジェクトを残し、CMO3 内のオブジェクトで同名のオブジェクトを ID で置き換えて新しいオブジェクトを追加し、CMO3 にないオブジェクトはそのままにする |
どちらの方法でも、モデルプリセットは自動では適用されません。

## 注意事項
- Cubism で参考画像と指定されたパーツは、moc3 の書き出しでは既定で書き出されません。必要なときは書き出しウィンドウで **ガイド画像 Part を書き出す** にチェックを入れます。
- 素材パネルでも CMO3 を読み込めます。その中のレイヤー画像は素材として使われます。[[layout-project]] を参照してください。
!> CMO3 から読み込んだモデルでは [[split-by-mesh]] と [[depth-split]] は使えません。

@@ texture | テクスチャ
@@ texture-atlas-edit | テクスチャアトラス編集
テクスチャアトラスはモデルに合わせて自動でパックされるので、普段は気にする必要がありません。特定のパーツの鮮明さを調整したいときや、テクスチャをより小さいページに収めたいときは、**テクスチャ** ワークスペースでタイルの位置、密度、回転を直接調整し、ページ予算を設定します。
## 3 種類のサイズ
各レイヤーには 3 種類のサイズがあります。キャンバス上で覆う矩形（キャンバス単位）、自身のラスターのピクセル、アトラス内のタイルのピクセルです。**テクスチャ** パネルは選択したレイヤーのこの 3 つを「キャンバス → 元画像 → アトラス」の 3 つ並びで表示します。
## タイルを調整する
1. アトラスページでタイルをクリックして対応するレイヤーを選択するか、空白部分でドラッグして範囲選択します。選択はキャンバスやレイヤー一覧と同期します。
2. タイルをドラッグして移動します。ほかのタイルのメッシュと重なるか、ページからはみ出すとタイルが赤くなり、離しても移動しません。
3. 選択したタイルの角点をドラッグして比率を保ったまま密度を調整し、上辺の外側にある円形のハンドルをドラッグして回転します（{kbd:Shift} を押しながらで 15° 刻み）。
4. ページ上部にセッションバーが表示され、元に戻す、やり直し、**破棄** ができます。問題なければ **適用** をクリックし、履歴の 1 ステップとしてコミットします。
タイルを右クリックすると、密度を 2 倍 / 半分にする、90° 回転、別のページへ移動、サイズをロック、選択したタイルの配置、画像の置き換えもできます。重なりはメッシュが実際に覆う領域で判定されるので、タイルの透明な角は互いに入れ子にできます。
## 配置と予算
- 左上の **配置** で一度に並べ直して保存します。**メッシュ形状で（タイルを入れ子に）** または **矩形で**、範囲は **すべてのタイル** または **選択タイルのみ** です。
- **自動配置** をオンにすると、変更のたびに矩形で並べ直されます。新規プロジェクトでは既定でオフで、現在のレイアウトを保ちます。
- 右上の **アトラス予算** でページサイズ、最大ページ数、間隔を設定します。「フィット」が 100% 未満のときは収まっていないことを示し、ロックされていないすべてのタイルがまとめて縮小されます。**サイズをロック** したレイヤーは変わりません。
レイヤーを選択していないとき、**テクスチャ** パネルは各ページのサイズ、タイル数、使用量、ビデオメモリの見積もりを表示します。レイヤーを選択すると **テクスチャ密度** のスライダーと ½× / 2× / リセットのボタンで、元の 1 ピクセルあたりのアトラスのピクセル数を調整できます（1/64–16）。
*> 編集キャンバス右下の表示バーの **元画像のピクセル** は、キャンバスにレイヤー自身のラスターを直接サンプリングさせるので、パック後の鮮明さと比較しやすくなります。

@@ png-file-export-replacement | PNGファイルの書き出し差し替え
お絵かきソフトでテクスチャを修正したいときは、先に書き出し、修正したらレイヤーごとに置き換えます。アトラスは自動で再パックされるので、タイルの位置を保つ必要はありません。
## 書き出し
- [[texture-atlas-edit]] のアトラスページの空白部分で右クリックして **このページを PNG で保存…** を選ぶと、内容は書き出したモデル内のテクスチャとバイト単位で一致します。
- **ファイル → 形式を指定して書き出し → 元の PSD…**（生成レイヤーを含む）（{key:REEXPORT_PSD}）でレイヤー付き PSD を書き出します。1× または高解像度化の倍率を選べ、**生成された補助レイヤーを含める** こともできるので、お絵かきソフトでレイヤーごとに細かく仕上げるのに向いています。
- 素材パネルでフォルダーを右クリックして **フォルダーを PSD に書き出し…**。
## 置き換え
1. 置き換えたいレイヤーを選択します。
2. **テクスチャ** パネルで **画像を置き換え…** をクリックします（またはアトラスページでタイルを右クリック）。
3. フィット方法 **引き伸ばし** か **全体を収める**、および **新しいピクセルからメッシュを再構築** するかどうかを選びます。
新しい画像は任意の解像度でよく、キャンバス上の矩形は変わらず、大きい画像ではレイヤーの密度が上がります。素材パネルで右クリックして **選択レイヤーの画像を差し替え** を選んでも置き換えられます。
!> すでに制作者の編集、バインド、確定済みメッシュがあるレイヤーでは、画像の置き換えとメッシュの再構築が拒否されます。理由はアトラスページの上部に表示されます。
*> 数か所のピクセルを直すだけなら、[[paint-mode]] を直接使うほうが手軽です。

@@ texture-upscale | テクスチャ高解像度化
原画の解像度が低いとき、テクスチャ高解像度化はアトラスをパックする前にレイヤーごとに AI でテクスチャを拡大し、大きく表示しても線やディテールがはっきり見えるようにします。元の PSD、キャンバスサイズ、バインドは変わらず、プレビューと書き出しは処理後のテクスチャを使い、倍率の調整やオフはいつでもできます。
## 使い方
1. **モデル → テクスチャ高解像度化…**（{key:TEXTURE_UPSCALE}）を開くか、**テクスチャ** パネルで **テクスチャ高解像度化…** をクリックします。
2. ローカルの実行環境を入力します。超解像モデルが検出されないときは **モデルとフレームワークを一括ダウンロード (110MB)** をクリックすると、自動でダウンロードしてモデルのディレクトリと nunif のディレクトリを入力します。このマシンにすでに環境があるときは **検出したローカル環境を使用** をクリックします。
3. **倍率** とノイズ除去のレベルを選び、**適用** をクリックします。プログラムがレイヤーごとに処理してプレビューを再構築し、設定はプロジェクトと一緒に保存されます。
4. 編集ページでメッシュと変形を確認し、プレビューで確かめてから再び書き出します。
{tutorial=TEXTURE_UPSCALE}
| 項目 | 内容 |
|---|---|
| Python | nunif の依存関係（PyTorch を含む）をインストールした Python 実行ファイル |
| nunif ソースディレクトリ | `nunif` と `waifu2x` のサブディレクトリを含むローカルのソースディレクトリ |
| Art ウェイトディレクトリ | Art の `.pth` ウェイトを保存するディレクトリ |
| 倍率 | 1 でオフ。2× または 4× に拡大 |
| ノイズ除去と線のシャープ化 | ノイズ除去なしは拡大のみ、または Level 0–3。既定は Level 1 |
| ニューラルアルファ | 既定でオン。オフにするとアルファをバイリニアで拡大する |
| 入力タイルサイズ | 64–512、既定は 256。ビデオメモリが足りないときは小さくする |
## 注意事項
- 配布パッケージには Python と PyTorch が含まれないので、自分でインストールする必要があります。別のマシンに移ったときはローカルのパスを確認し直してください。
- 対応するモデルがないとエラーになり、通常の補間を超解像と偽ることはありません。
- ニューラルアルファは半透明の輪郭を変えることがあるので、明るい背景と暗い背景で、髪の毛、まつ毛、唇の線、動いているときのマスクの縁を確認してください。

@@ paint-mode | 描画モード
縁を整える、色を補う、余分な線を少し消すといったことのために、お絵かきソフトへ戻る必要はありません。描画モードはエディターの中でレイヤーのピクセルを直接編集します。ストロークは独立した描画セッションに置かれ、確定して初めて履歴の 1 ステップとしてプロジェクトに書き込まれるので、失敗してもいつでも破棄できます。
## 描画を始める
1. キャンバスまたはレイヤー一覧でレイヤーを 1 つ選択します。
2. キャンバス左上のモードメニューで **描画**（{key:MODE_PAINT}）を選びます。
3. 左側のツールバーでツールを選び、左下のツールオプションバーでサイズ、硬さ、不透明度を調整します。
4. 描き終えたら、キャンバス上部のセッションバーの **適用** をクリックします。**破棄** をクリックするとこのセッションのすべてのストロークを捨てます。
{tutorial=PAINT_MODE}
セッションバーには描画中のレイヤーとストローク数が表示され、元に戻す・やり直しも使えます。「ツール詳細」パネルにも **変更を破棄** と **適用** があります。セッション中の {key:UNDO} はストロークだけを取り消し、プロジェクトの履歴には影響しません。
## ツールとショートカット
| ツール | ショートカット |
|---|---|
| ブラシ | {key:TOOL_PAINT_BRUSH} |
| 鉛筆 | {key:TOOL_PAINT_PENCIL} |
| 消しゴム | {key:TOOL_PAINT_ERASER} |
| 塗りつぶし | {key:TOOL_PAINT_BUCKET} |
| スポイト | {key:TOOL_PAINT_EYEDROPPER} |
| 図形（直線 / 矩形 / 楕円） | {key:TOOL_PAINT_LINE}。{key:PAINT_SHAPE_CYCLE} で図形を切り替え |
ブラシ先端の大きさ {key:BRUSH_RADIUS_DOWN} / {key:BRUSH_RADIUS_UP}、硬さ {key:BRUSH_HARDNESS_DOWN} / {key:BRUSH_HARDNESS_UP}、不透明度 {key:PAINT_OPACITY_DOWN} / {key:PAINT_OPACITY_UP}。{key:BRUSH_ADJUST_DRAG} を押しながらドラッグするとその場で調整できます。ツールオプションバーの先頭は描画色 / 背景色で、{key:AXIS_CONSTRAIN_X} で入れ替えます。
## メッシュの外に描く
キャンバス全体に描けます。適用時にレイヤーのメッシュで切り取られ、メッシュ内の部分はレイヤーに残り、メッシュ、キーフォーム、バインドは変わりません。メッシュの外の部分は新しいレイヤーに分けられ、名前は元のレイヤー名に「+」を付けたもので、元のレイヤーの真上に置かれ、同じ親に従って動きます。元のレイヤー自身のメッシュで新しく描いた領域を覆いたいときは、メッシュパネルで **現在のピクセルから再構築** をクリックします。
*> 素材に関連づけられたレイヤーでは、ストロークは素材自体に書き込まれ、その素材を使うすべてのレイヤーが一緒に変わります。[[layout-project]] を参照してください。

@@ parts | パーツについて
パーツはアートメッシュとデフォーマをグループにまとめるもので、オブジェクトの整理、まとめての表示/非表示、書き出し時のグループ分けに使います。PSD2Live では通常、自分でパーツを作る必要はありません。ジェネレーターが認識したパーツに従って「頭部」「後ろ髪」「顔」「前髪」「頭部アクセサリ」「その他」「身体」などのパーツを自動で作り、レイヤーはタグに従って入れられ、認識されなかったレイヤーは「身体」に入ります。
## パーツを確認する場所
**階層** に表示されるのはデフォーマとアートメッシュの親子関係で、変形がどう継承されるかを決めるものであり、パーツのツリーではありません。あるアートメッシュがどのパーツに属するかを見るには、それを選択して **インスペクタ** の **パーツ** ドロップダウンを見ます。所属を変更するには [[edit-parts]] を参照してください。
{tutorial=HIERARCHY}
*> CMO3 から読み込んだモデルは元のパーツ構造を保ちます。moc3 の書き出しでは、書き出しウィンドウの **非表示 Part を書き出す** で非表示のパーツを書き込むかどうかが決まります。

@@ edit-parts | パーツの編集
パーツはジェネレーターが作りますが、調整が必要なときはアートメッシュの所属を変えたり、デフォーマの作成時にどのパーツに入れるかを指定したりできます。
## アートメッシュの所属パーツを変更する
1. キャンバスまたは階層でアートメッシュを選択します。
2. **インスペクタ** の **パーツ** ドロップダウンで目的のパーツを選ぶか、**(なし)** を選んで最上位へ移動します。
変更は履歴の 1 ステップとして記録され、元に戻せます。
## 新しいデフォーマの作成時にパーツを指定する
オブジェクトモードで Warp を作成するとき、「ツール詳細」パネルの **挿入するパーツ** が新しいデフォーマの所属パーツを決めます。既定は **選択から継承** です。
*> Cubism のパーツパレットでオブジェクトをドラッグすることに慣れている方へ：PSD2Live でドラッグして調整するのは階層の親子関係で、パーツの所属はインスペクタでのみ変更します。[[partspalatte]] を参照してください。

@@ edit-parts-sketch | 下絵パーツ
原画やラフなど、見比べるためだけの画像は参照レイヤーにできます。キャンバスには表示されますが、生成には使われず、書き出されません。
## 参照にする
1. レイヤーを選択します。
2. 「レイヤー」パネルのツールバーの **参照として扱う** をクリックするか、{key:LAYER_TOGGLE_REFERENCE} を押します。キャンバスの右クリックメニューにも **参照として扱う** の切り替えがあります。
参照レイヤーは名前の後ろに参照アイコンが付き、それをクリックするとモデルのレイヤーに戻ります。戻したレイヤーは次の生成でモデルに加わります。生成済みのレイヤーは参照にできません。
## 表示
参照レイヤーは既定ではモデルの下に敷かれますが、キャンバス右下の表示バーの **参照レイヤーを上に表示** でモデルの上に重ねられます。異なる角度の参照は右クリックして **キーフォームに固定** でき、対応するパラメータ値のときだけ表示されます。[[sketch]] を参照してください。
*> 参照はパーツ単位ではなく、レイヤー単位で設定します。CMO3 から読み込んだ参考画像のパーツは、moc3 の書き出しでは既定で書き出されません。必要なときは書き出しウィンドウで **ガイド画像 Part を書き出す** にチェックを入れます。

@@ variants | 差分
頬の赤み、涙、メガネのような「あり / なし」のパーツや、表情、手のジェスチャー、衣装のような「多択」の造形は、差分として扱えます。レイヤー上で宣言しておくと、生成時に対応するパラメータと表示制御が自動で作られ、パラメータをドラッグするだけで切り替えられるので、不透明度にキーを手動で打つ必要はありません。差分は「レイヤー」パネルの **差分** 列で設定します。
| 種類 | 作用 | 向いているもの |
|---|---|---|
| 差分なし | タグに従って対応するパーツを生成する | 通常のレイヤー |
| 差分トグル | 1 つのパラメータでそのレイヤーを表示または非表示にする | 頬の赤み、涙、メガネ、陰影 |
| 差分切替 | 同じパラメータで、そのうち 1 つの ID に対応するレイヤーだけを一度に表示する | 表情、手のジェスチャー、衣装 |
{tutorial=VARIANTS}
## 差分トグルを設定する
1. 「レイヤー」パネルでその行の **差分** を **差分トグル** にします。
2. **パラメータ連動** にパラメータ名（たとえば `blush`）を入力します。同じパラメータ名で複数のトグルレイヤーを駆動できます。
## 差分切替を設定する
1. 関連するレイヤーをすべて **差分切替** にします。
2. **パラメータ連動** に同じパラメータ名を入力します。ドロップダウンから既存の切替パラメータを選ぶこともできます。
3. 隣の ID を順に 0、1、2… にします。たとえば `expression`：0 が通常、1 が笑顔。
設定後に対応するパラメータをドラッグすると、編集でもプレビューでも効果が確認できます。
!> レイヤー名の数字から差分は自動では作られません。差分トグルにはパラメータの指定が必要で、差分切替にはパラメータの共有と異なる ID の設定が必要です。

@@ copy-and-paste | オブジェクトのコピーや貼り付け
アートメッシュとデフォーマをコピーして複製を貼り付けます。複製は元のキーフォーム、ブレンドシェイプ、クリッピングマスク、パス、頂点グループを持ち、テクスチャとレイヤーを共有します。貼り付けた後はそれぞれ別に編集できます。
## コピーと貼り付け
1. **オブジェクト** モードで、階層ツリーかキャンバスでアートメッシュ（複数可）を、または階層ツリーでデフォーマを 1 つ選択します。
2. {key:COPY} を押すか、階層ツリーで右クリックして **コピー** を選びます。
3. {key:PASTE} を押すか、右クリックして **ペースト** を選びます。複製はそれぞれ元のすぐ隣、同じ親の下に入ります。デフォーマを右クリックして **このデフォーマの下にペースト** を選ぶと、複製はそのデフォーマの下に入り、アートメッシュはキャンバス上の位置を保ちます。
貼り付けは 1 つの履歴になり、元に戻せます。複製の ID は元の ID に `_copy` を付けたもの（使用済みなら `_copy_2`、`_copy_3`…）です。あとから [[convert-id]] で変えられます。
## コピーされる範囲
| コピーするオブジェクト | 一緒にコピーされるもの |
|---|---|
| アートメッシュ | キーフォーム、ブレンドシェイプ、パス、頂点グループ。一緒にコピーした 2 つのメッシュ間のグルー |
| デフォーマ | 配下のすべての子デフォーマとアートメッシュ。親はそれぞれの複製を指す |
| パーツ | 子パーツ、アートメッシュ、そのパーツに属するデフォーマ |
| パラメータ | 範囲と既定値が同じ新しいパラメータ（元の隣に入る）。キーフォームは元のパラメータに残る |
一緒にコピーしたメッシュを指すクリッピングマスクは複製を指し、それ以外は元のマスクのままです。パーツのコピーは MCP で行います。パラメータの定義はパラメータパネルでも複製できます。
*> スイング、シミュレーション、内部造形はドキュメント全体のもので、オブジェクトと一緒にはコピーされません。貼り付けるのは貼り付けた時点のオブジェクトです。コピーの後で元を変えると、その変更も複製に入ります。

@@ search-and-replace | オブジェクトの検索、置換
名前か ID でオブジェクトを検索し、まとめて置換します。片側で作った部位をもう片側の名前に変える、パラメータ群に接頭辞を付けるなど、命名の整理に使います。
## 使い方
1. **モデル → 検索と置換…**。
2. **検索対象** で **名前** か **ID** を選び、下のオブジェクトの種類を切り替えます。**選択中のみ** にチェックすると、階層ツリーで選んだオブジェクトだけを対象にします。
3. **検索** と **置換後**、または **接頭辞を追加**、**接尾辞を追加** を入力します。必要なら **正規表現** にチェックするか（置換後で `$1` によりグループを参照できます）、**大文字と小文字を区別** を外します。
4. 一覧に、一致した各オブジェクトが置換後どうなるかが入力に合わせて表示されます。**すべて置換** でまとめて 1 つの履歴として適用します。
## 左右を入れ替え
**左右を入れ替え** は、名前や ID のなかで単語として独立した左右の印を入れ替えます。`L`/`R`（`ArmL`、`Hair_L_01`、`ParamEyeLOpen` など）、`Left`/`Right`、`左`/`右` が対象で、`Lip` のような単語の中の文字は変わりません。
ID の置換は [[convert-id]] と同じく、参照がすべて追従します。
*> 置換する内容を何も入れなければ一致したオブジェクトを表示するだけなので、検索としても使えます。

*> まだ生成していないレイアウトのレイヤーは上下の順序（{key:LAYER_FORWARD} / {key:LAYER_BACKWARD}）で調整し、生成後は描画順を使います。[[layout-project]] を参照してください。

@@ concept-of-artmesh | アートメッシュについて
アートメッシュ（ArtMesh）は、頂点と三角形でできたメッシュにテクスチャを貼ったもので、頂点を動かすと画像が変形します。PSD の各レイヤーは読み込み後に 1 つのアートメッシュになります。メッシュは読み込み時にレイヤーの透明度に従って自動で生成されています。
## メッシュの構成
- 頂点：変形のときに動かす点。
- 辺と三角形：頂点をつなぎ、頂点に合わせて画像がどう伸び縮みするかを決める。
- 輪郭：レイヤーの不透明なピクセルの縁に沿い、メッシュの外のピクセルは表示されない。
頂点が密なほど変形は滑らかになりますが、編集時と実行時の負荷も大きくなります。密度の調整は [[mesh-edit]]、トポロジーの部分的な変更は [[mesh-edit-manual]] を参照してください。複数のメッシュをまとめて変形させるのは [[deformer]] です。
{tutorial=LIVE2D_BRIDGE}
## プロパティ
アートメッシュを選択すると、**インスペクタ** に名称、ID、パーツ、デフォーマ、クリップ ID、反転マスク、描画順、不透明度、乗算色、スクリーン色、ブレンドモード、カリング、ユーザデータが表示されます。

@@ mesh-edit | メッシュの自動生成
読み込み時に、各レイヤーにはすでにメッシュがあります。プログラムがレイヤーの透明度に沿って輪郭を描き、設定に従って縁の点と内部の点を置いて三角形に分割します。メッシュが粗すぎる、細かすぎる、輪郭が合わないといったときは、**メッシュ** パネルの設定を変更すれば再構築され、既存のキーフォーム、パス、ウェイト、グルーは新しいメッシュに引き継がれるので、やり直す必要はありません。
## メッシュを調整する
1. **メッシュ** ワークスペース、または **ウィンドウ** メニューから **メッシュ** パネルを開きます。
2. **グローバル既定** は個別に設定されていないすべてのパーツに作用します。あるアートメッシュを選択すると、パネルにそのアートメッシュ自身の設定が表示され、変更すると「カスタム設定」と表示されます。
3. 変更するとメッシュはすぐ再構築されるので、変形モードとプレビューで効果を確認します。
メッシュが見えているピクセルの一部を覆っていないときは、パネルにその割合が表示されるので、**現在のピクセルから再構築** をクリックすると含められます。パネルの **説明を表示** で各オプションの説明を展開できます。
## 主な設定
| グループ | 設定 | 作用 |
|---|---|---|
| 輪郭の位置 | 1 層 / 2 層 / 3 層の縁、外縁の距離、縁メッシュの幅 | 輪郭の近くに頂点を何周置くかとその位置 |
| 点の密度 | 縁の点の距離、内部の密度 | 輪郭の頂点の間隔と内部の点の間隔 |
| 内部の充填アルゴリズム | 漸疎ポアソン充填（既定）、バランス四分木充填、正三角フラクタル細分、輪郭層敷き、単純三角充填 | 内部の点の並べ方 |
| 接続トポロジー | 縁の点どうしをまたぐ接続線を抑える | 隣り合わない縁の点を内部の点経由でつなぐ |
| 単位 | ドキュメントサイズに合わせる、テクスチャのピクセルで輪郭を描く、包み込み | 長さの単位、輪郭を描く精度、閉じたまつ毛などの細かい突起の間のすき間 |

@@ mesh-edit-manual | メッシュの手動編集
自動メッシュの一部が合わないときは、**編集** モードでトポロジーを直接変更します。再分割、接続、結合、複製、削除、頂点配置（点の追加、線）です。メッシュにすでにキーフォームがあっても変更でき、UV、キーフォーム、ブレンドシェイプ、グルーの頂点参照は同時に更新され、各操作はそのまま履歴に入ります。
## 編集モードに入る
1. 1 つ以上のアートメッシュを選択します。
2. モードメニューで **編集**（{key:MODE_EDIT}）を選ぶと、メッシュが強制的に表示されます。
3. モードバーで点 / 辺 / 面（{key:PICK_OPTION_1}–{key:PICK_OPTION_3}）を選び、選択ツールで選ぶ要素を決めます。
{tutorial=EDIT_MODE}
## 操作
| 操作 | 結果 |
|---|---|
| 再分割（{key:TOOL_SUBDIVIDE}） | ヒットした辺に点を加えて三角形を組み直し、隣接する面の継ぎ目も同時に処理する |
| 接続 / 結合 | 選択した点の間に接続を作る、または選択した頂点を 1 点にまとめる |
| 複製 | 選択した頂点とそれを完全に覆う面を複製し、新しいコピーが選択状態になる |
| 削除（{key:DELETE_SELECTION}） | 選択範囲を削除し、穴を埋めようとする。正しいトポロジーにならない場合は拒否される |
| 頂点配置・点（{key:TOOL_MESH_POINT}） | 空白をクリックで頂点を追加（三角形内・辺上・メッシュ外）、空白をドラッグで「配置間隔」ごとにストロークに沿って追加、頂点をドラッグで移動。{kbd:Shift}+クリックで選択頂点から接続、{kbd:Alt}+クリックで頂点または辺を削除。「左右対称」も使える。追加した点の周りはメッシュが自動で結び直すため、点どうしが辺で結ばれるとは限らない |
| 頂点配置・線（{key:TOOL_KNIFE}） | 点ごとにクリックして折れ線を引く。各点は直前の点と辺で結ばれ、メッシュはこの線で折れる（まぶた、口の線、しわ）。点や辺に近づくとスナップする（{kbd:Shift} を押している間は一時的にオフ）。{key:FINISH_PATH} で完了、{key:CANCEL} でキャンセル |
| 辺を削除 | 辺モードで {key:DELETE_SELECTION}、またはトポロジーメニュー：内側の辺は四角形のもう一方の対角線に、輪郭の辺は所属する三角形ごと削除。メッシュが壊れる場合は拒否 |
| 再三角形分割 | トポロジーメニュー：選択頂点の周り（未選択ならメッシュ全体）の細長い三角形を均等なつなぎ方に反転。頂点とテクスチャは動かない |
複数のアートメッシュを同時に選択しているとき、あるメッシュの頂点をクリックして選ぶと、それが主メッシュになります。頂点配置の「線」と辺・面の選択は主メッシュにだけ作用します。
!> 輪郭の点を削除すると境界が変わるので、変更後に複数のパラメータのポーズで確認してください。日常的な形の引っ張りは変形モードで行い、編集モードはトポロジーの変更にだけ使います。

@@ mesh-duplication | メッシュの複製
1 つのアートメッシュの頂点と三角形を、ほかのアートメッシュに複製します。開いた目と閉じた目、いくつかの表情など、同じ形の差分に向いています。対象はソースがキャンバス上にある位置で同じトポロジーになり、それぞれ自分のテクスチャを参照します。対象のキーフォーム、ブレンドシェイプ、パス、頂点グループ、グルーは新しいメッシュに移行します。
## 使い方
1. 階層ツリーで、ソースのメッシュと 1 つ以上の対象メッシュを一緒に選択します。
2. ソースのメッシュを右クリックし、**このメッシュを選択中の N 個のメッシュに複製** を選びます。
複製は 1 つの履歴になり、元に戻せます。
!> 対象の絵のうちソースのメッシュから外れた部分は描かれず、対象の絵から外れたソースの頂点は絵の外を参照します。複製後に編集モードで確認し、必要なら [[mesh-edit-manual]] で点を足すか切ってください。
*> 複製するのはメッシュの構造で、変形ではありません。対象のキーフォームは頂点の位置に従って移行し、ソースのキーフォームは複製されません。

@@ clipping-mask | クリッピングマスク
クリッピングマスクは、あるアートメッシュを別のアートメッシュの範囲内にだけ表示するもので、たとえば瞳が白目の中にだけ現れるようにします。モデルの生成時によく使うマスクはすでに自動で設定されています。瞳は同じ側の白目でマスクされ、歯や舌など口の中のパーツは口でマスクされます。
## 手動で設定する
1. マスクされるアートメッシュを選択します。
2. **インスペクタ** の **クリップID** でマスクを指定します。ID を直接入力する（複数のときはカンマ区切り）、リストボタン **リストからクリッピングマスクを選択** をクリックする、または照準ボタン **キャンバスからマスクを関連付け** をクリックしてからキャンバス上のマスクのアートメッシュをクリックする、のいずれかです。
1 つのアートメッシュを複数のマスクで同時に制限できます。逆の効果にしたいときは [[reversed-mask]] を参照してください。
{tutorial=INSPECTOR}

@@ reversed-mask | マスクの反転
反転マスクは、アートメッシュをマスクの範囲の外にだけ表示するもので、[[clipping-mask]] とは逆の効果です。
## 設定
1. **クリップID** が設定されたアートメッシュを選択します。
2. **インスペクタ** の **反転マスク** にチェックを入れます。
変更は履歴の 1 ステップとして記録され、元に戻せます。

@@ sketch | 下絵の配置
制作中に原画、ラフ、ほかの角度の設定画をキャンバスに置いて見比べると、形をより正確に調整できます。参考は階層の一員で参考アイコンが付き、3 つの表示位置のいずれかにあります。表示位置でモデルに入るかどうかが決まります。
| 表示位置 | モデルに入るか | 説明 |
|---|---|---|
| 背景 | 入らない | モデル全体の下に敷き、エディターでのみ表示。選択するとキャンバス上でドラッグして移動・拡大縮小・回転でき、ロックもできる |
| レイヤーの中 | 入る | 生成後はモデルの ArtMesh としてレイヤーの間に描画順で置かれ、デフォーマーの下に入れて変形に追従させられる。書き出しではガイド画像パーツで、**ガイド画像 Part を書き出す** をオンにしたときだけ書き出す |
| 前景 | 入らない | モデル全体の上に重ねる。ほかは背景と同じ |
レイアウトプロジェクトの最初の生成までは、レイヤーの中の参考もほかのレイヤーと同じく生成を待ち、生成後にモデルに入ります。
## 参考を追加する
1. 画像か素材を編集キャンバスにドラッグすると、下部に大きな項目が現れます。**背景 · 参考**、**レイヤーの中 · 参考**、**前景 · 参考**、選択レイヤーの画像の置き換え、素材ライブラリにのみ追加で、それぞれモデルに入るかが書かれています。キャンバスのほかの場所で離すと通常のレイヤーとして配置されます。
2. 階層ツールバーかキャンバスの表示バーの参考画像ボタン（前景に追加）や、素材の右クリックの **参考として追加** の 3 項目でも追加できます。
キャンバス上の、まだ生成に使われていないレイヤーや読み込んだ画像は、「レイヤー」パネルのツールバーの **参照として扱う** か {key:LAYER_TOGGLE_REFERENCE} でレイヤーの中の参考になります。[[edit-parts-sketch]] を参照してください。
## 参考を調整する
- 階層で参考をクリックします。背景・前景の参考は編集キャンバスにハンドルが現れ、内側で移動、角で拡大縮小、上の丸で回転します。レイヤーの中の参考はほかの ArtMesh と同じく変形ボックスで調整します。
- 参考を右クリックし、**表示位置** で背景・レイヤーの中・前景を切り替えます。各項目にモデルに入るかが示され、素材、位置、表示、固定は保たれます。メニューには表示/非表示、不透明度とロック（背景・前景）、モデルのレイヤーに戻す（レイヤーの中）、削除もあります。
- {key:REFERENCE_TOGGLE_SHOWN} で現在のキャンバスの背景・前景の参考の表示を切り替えます。
## キーフォームに応じて表示する
正面、横、あおりなど異なる角度の参考を同じ位置に重ね、それぞれ対応するキーフォームでだけ表示できます。1 つの参考を複数のキーフォームに出すこともできます。
1. 参考を右クリックすると、メニュー下部の **キーフォームに固定** に、モデルでキーフォームを持つパラメータがパラメータパネルと同じ形で並びます。1 次元はキーフォーム点付きのスライダー、対のパラメータは 2D パッドです。
2. キーフォーム点をクリックするとそこに点を打ち（塗りつぶし）、もう一度で外します。点は複数打て、参考はいずれかの点で表示され、ほかのポーズでは隠れます。灰色の印は現在のポーズです。
3. **固定を解除** はすべての点を消し、どのポーズでも表示されるようにします。
*> キャンバスの右クリックメニューの **キーフォームに固定** も同じパネルです。固定はエディターでの表示だけを決め、書き出しには入りません。

@@ hittest | 当たり判定の設定準備
当たり判定（HitArea）は、モデルのどこがクリックされたかをアプリに伝えます。頭をタップしたら表情を変える、体なら動作を再生する、といった使い方です。PSD2Live は当たり判定をプロジェクトに保存し、書き出し時に model3.json の `HitAreas`（VTube Studio 用パッケージにも含まれます）と `.p2lrt` ランタイムモデルに書き込みます。
## 当たり判定の設定
- **インスペクタ**：アートメッシュを選択し、**当たり判定** で所属する判定を選ぶか、**新しい当たり判定** でそのメッシュから作成します。判定がまだないときは **頭と体の当たり判定を設定** で、自動認識した顔と上着（上着がなければ首か下衣）から Head と Body を作成できます。判定に属したメッシュでは **判定名**（アプリが名前で問い合わせます。Head、Body が一般的）と **判定 ID** を編集できます。
- **階層パネル**：アートメッシュを右クリックし、**当たり判定** の項目で所属する判定をチェックまたは解除するか、**このメッシュで当たり判定を作成** を選びます。
1 つの判定に複数のアートメッシュを含められます。判定は一覧の順に行われ、先に当たった判定が優先されます。変更はそれぞれ 1 つの履歴になり、元に戻せます。判定を 1 つも設定していない場合、`.p2lrt` ランタイムは自動生成の Head と Body を使い、model3.json には当たり判定を書き込みません。
## プレビューで確認
プレビューキャンバスでモデルを（ドラッグせずに）クリックすると、当たった判定がアクセントカラーで強調され、ログに「当たり判定：名前（ID）」と表示されます。当たらなかったときはログにその旨が出ます。判定方法はランタイムと同じで、表示されていて不透明度が 0 より大きく、点が三角形の内側にあるメッシュが当たりになります。
*> model3.json の当たり判定は 1 つのアートメッシュしか指せないため、複数のメッシュを含む判定は同じ名前の複数の項目として書き出され、書き出しレポートに記録されます。Cubism SDK のサンプルはメッシュの外接矩形で判定するため、プレビューと結果が少し異なることがあります。Cubism のモデルでは不透明度 0 の判定用メッシュがよく使われますが、そうしたメッシュは PSD2Live のプレビューと `.p2lrt` ランタイムでは当たりになりません。model3.json に書き出した後の判定はホスト次第です。メッシュを分割すると分割片が判定内の位置を引き継ぎ、レイヤーを削除するとそのメッシュは判定から外れます。存在しなくなったメッシュを指す判定では、インスペクタに **見つからないメッシュ** が表示され、書き出しではそれらを除いて書き出しレポートに記録します。

@@ blend-mode | ブレンドモード
ブレンドモードは、アートメッシュの色を下にすでに描画された内容とどう合成するかを決め、影やハイライトによく使われます。アートメッシュを選択し、**インスペクタ** の **ブレンドモード** で選びます。
| モード | 効果 |
|---|---|
| 通常 | 通常どおり上書きする |
| 乗算 | 下の色と掛け合わせる。影に使う |
| 加算 | 下の色に足す。発光やハイライトに使う |
PSD レイヤーのブレンドモードは読み込み時に自動で変換されます。覆い焼き（リニア）(加算) などの加算系のモードとリニアライトは加算に、乗算、焼き込み（リニア）、焼き込みカラーは乗算に変換され、そのほかのモードは通常として扱われます。
*> 合成方法を変えずにアートメッシュに色を付けたいだけのときは、インスペクタの **乗算色** と **スクリーン色** を使います。[[multiply-color-screen-color]] を参照してください。

@@ interior-shape | 内部造形
大きな服や髪は、振り向いたときに輪郭だけが動くと、まるで 1 枚の紙のように見えてしまいます。内部造形は、レイヤー内部のテクスチャを仮想の曲面に沿って伸縮・偏らせることで、回転時に立体感を出します。必要なキーフォームを自動で生成し、標準のブレンドシェイプと物理演算の設定として書き出されます。新しいテクスチャや影は生成せず、布のシミュレーションでもありません。
## 使い方
1. 生成済みのレイヤーを選択し、モディファイアパネルの **追加** メニューで **内部造形** を選びます。それがそのメッシュのスタックのカードになります。
2. カードのタイトルにあるスイッチで有効/無効を切り替えます。有効にすると、プログラムが内部造形を生成します。
3. **造形** で横方向 / 縦方向の振れ幅、曲面の膨らみ、偏り、しわの強さ、輪郭の維持を調整します。部分的なしわが必要なときは **局所折り目** で + 追加をクリックします。
4. 動きにイージングを付けたいときは **追従・伝達** を展開し、追従時間、伝達時間、伝達強度、**伝達方向** を設定します。
5. カードの **試し動かし** で 2 次元パラメータパッドをドラッグするか、**マウス追従** をオンにして効果を確認します。カードメニューの **単独表示・中央** はこのレイヤーだけを表示してキャンバスの中央に置き、**キャンバスで編集** で内部造形のハンドルに入ります。
ドラッグを終えるたびに履歴が 1 件コミットされます。生成に失敗したときは、下書きとそれ以前の有効な結果が残ります。
## 設定
| 設定 | 範囲 | 意味 |
|---|---|---|
| 横方向 / 縦方向の振れ幅 | 0–2 | 2 つの方向それぞれの造形の総量 |
| 曲面の膨らみ / 偏り | 0–2 | 仮想のアーチ面とその偏りの度合い。どちらかが 0 だと曲面による変位はない |
| しわの強さ | 0–2 | 局所的なしわの寄与。局所的なしわがないと効果がない |
| 輪郭の維持 | 0–1 | 0 で見えている輪郭を解放し、1 で原画の輪郭を守る |
| 追従時間 | 0–0.6 秒 | 第 1 段階の応答時間 |
| 伝達時間 | 0–0.5 秒 | 前の領域に対する後ろの領域の伝わる時間 |
| 伝達強度 | 0–1 | 後ろの領域のウェイト。0 で領域を分けない |
**詳細設定** の横方向 / 縦方向のマウス倍率はマウスでの試し動かしにだけ影響し、キーフォームの振れ幅や書き出されるパラメータの範囲は変わりません。**入力パラメータ** では既存のパラメータを選ぶか **新規パラメータ** を作成できます。
## 注意事項
- カードのスイッチをオフにすると設定は残りますが変形は適用されません。カードメニューの **削除** はレシピとその物理演算を取り除き、元に戻せます。
- メッシュ、素材、入力パラメータが変わると、カードに再生成または再バインドが案内されます。無効になった効果は書き出し時にスキップされ、警告に一覧表示されます。
- イージングはプロジェクトの物理演算グループを使い、標準の物理演算設定として書き出されます。

@@ modifiers | モディファイア
**モディファイア** パネルは、選択したオブジェクトを Live2D が実際に計算する順に表示します。まずそのオブジェクト自身のキーフォーム、続いて親デフォーマーが内側から外側へ順に並びます。1 つ 1 つの層を **ステージ** と呼び、ステージの順序は階層ツリーの入れ子の順序です。順序を変えるには階層ツリーで親子関係を変更してください。
## オブジェクトページ
- ステージごとに 1 行で、名前、生成元（頭の向き、目、スイング……、または **手作業**）、作用しているカードの数が表示されます。選択したオブジェクト自身のステージはデフォルトで展開され、ほかは折りたたまれます。ツールバーの **作用があるもののみ** は、ほかに何も作用していないステージを隠します。
- ステージを展開すると、まずそのキーフォームがどのジェネレーターと手作業の編集から来ているか（パラメータ一覧）が表示され、続いて作用するカード（モディファイア、シミュレーション、内部造形、スイング）が並びます。カードは実行順に並び、後ろのカードは前のカードの結果を読みます。カードは展開して設定したり、スイッチで切り替えたり、上下に移動したり、キーフォームとして適用したり、削除したりできます。
- ステージ行の矢印ボタンはそのデフォーマーを選択し、**+** はそのステージに追加します。ツールバーの **追加** は選択したオブジェクト自身のステージに追加します。メッシュ自身のステージには **シミュレーション · 布 / 髪** と **内部造形** も追加できます。
- シミュレーションのカードには焼き込み、材質、入力、出力、グルー、頂点ウェイトグループ、比較（参照シミュレーションのスイッチ）が、内部造形のカードには試し動かしとすべての造形設定が、スイングのカードには方向、プリセット、支点、各方向の形状と振り子があります。
## ミラー
- パラメータの片側だけを作り、もう片側はミラーで得ます。例えば角度 X の正側だけを作れば負側は自動で対称になり、正側を変えると負側も追従します。
- オプション：**パラメータ** でミラーするパラメータを選びます（新規作成時は対象がキーを持つ両側パラメータ、角度 X を優先）。**残す側** は正または負、**参照元** には別のメッシュやワープ（左目から右目など）を指定でき、その場合は全範囲で参照元の変位を使います。
- **ミラー線 x** は鏡映する縦線の位置（キャンバス x）で、新規作成時は対象の中心です。
- 頂点ではなく変形場をミラーするため、左右非対称のメッシュや頂点の異なる左右の目にも使えます。
- **出力方法**：**メッシュのキーフォームに統合**、または **専用ワープ**（メッシュと親の間にモディファイアのパラメータだけでキーを打つワープを挟み、メッシュのキーフォームを増やさない）。**自動** はキーフォームが倍増する場合に専用ワープを使います。

## サーフェス追従・斜め補正・立体回転
- **サーフェス追従**：線画、影、ハイライト、アクセサリーを、その下に描かれているメッシュ（**ホスト**。新規作成時は下にある最も合うレイヤー）と一緒に動かします。ホストにどんなキーフォームがあっても、キーを打ち直さずに追従します。**強さ** 1 で完全に追従します。
- **斜め補正**：X と Y を別々に作ったとき、斜めのポーズ（両方を同時に動かした状態）は崩れがちです。斜めを各軸単独の効果の和にします。**強さ** を 1 より大きくするとさらに外へ押し出します。
- **立体回転**：対象を中心の手前 **奥行き** の位置にある立体として、パラメータ（既定は角度 X / Y）で回転させ透視で投影します。手前ほど大きく動き、奥側は狭くなります。**膨らみ** は中央を手前に膨らませ、**角度** はパラメータ端での回転角、**視点距離** が近いほど透視が強くなります。

## ロールコンポーネント
自動生成された頭の向き、目、眉、口、体のポーズ、呼吸、髪は、それぞれ 1 つのロールコンポーネントです。メッシュを選択すると、そのメッシュが属する各ステージに何かを生成したコンポーネントが、ステージの前にカードとして並びます。**ワールド** ページの **ロールコンポーネント** 節にはモデルのすべてのコンポーネントが並びます。
- カードのタイトルにあるスイッチでコンポーネントをオフにできます。そのパラメータは、コンポーネントが生成したものをもう動かさなくなりますが、デフォーマーと既存の編集は残ります。頭の向きをオフにすると、目などの角度 X への反応も止まります。
- **数値**：以前の「リグの数値」のうちそのコンポーネントに属する項目で、よく使うものが先頭、残りは **詳細** にあります。目と眉は **左右を分ける** にチェックを入れると、**閉じ目の弧**、**閉じ目の目尻**、**閉じ目のまつ毛の太さ**、眉の上下に左右それぞれの値を持たせられます。
- コンポーネント固有の設定：頭は **頭部の可動範囲** と **顔パーツ移動デフォーマ**、体は **身体の可動範囲**、口は唇の線、口形状、線幅と色、目は待機中のまばたき、前髪から透ける表現と瞳のゼリー揺れ、眉は前髪から透ける表現、髪は振り子。
- **メンバー**：コンポーネントが認識したレイヤーとその役割・左右。役割を変えるとそのレイヤーのセマンティックタグが変わります。名前をクリックするとレイヤーを選択します。
- **パラメータ**：コンポーネントが生成したパラメータ。

## ワールドページ
- **ロールコンポーネント**：モデルのすべてのコンポーネントのカード。
- **シミュレーション**：すべての物理ボディとその焼き込み状態。**すべて焼き込む** と **自動で焼き込む** があり、行をクリックするとそのメッシュを選択してオブジェクトページに切り替わります。
- **問題**：すべてのカードの問題（パラメータ不足、キーフォームが多すぎる、許容範囲を超えた、内部造形の再生成が必要）。行をクリックすると該当するオブジェクトへ移動します。
- **モデルプリセット**：[[model-presets]] を参照してください。
!> シミュレーションはスタックでそれより前にあるものだけを読みます。前のカードが変わると、その焼き込みは **古い** と表示されます。

@@ deformer-folder | デフォーマ
@@ deformer | デフォーマについて
デフォーマはアートメッシュや他のデフォーマを包み、パラメータに応じて自分の形を変え、中身をまとめて動かします。PSD を読み込むと、PSD2Live はレイヤーの分類に沿ってデフォーマ構造一式（体、頭、顔、髪など）を組み上げてあるので、ほとんどの場合はゼロから組まず、この構造を微調整します。
## 2 種類のデフォーマ
| 種類 | 変形のしかた | 主な用途 |
|---|---|---|
| ワープデフォーマ（Warp） | 制御点の格子で子オブジェクトを包み、制御点を動かして中身をなめらかに曲げる | 顔の向き、体の曲げ、髪の揺れ |
| 回転デフォーマ（Rotation） | 原点を中心に全体を回転させる（拡大縮小も可）。子オブジェクトは剛体のまま | 腕、首、アクセサリーなど関節で回る部品 |
*> ワープデフォーマは Cubism のワープデフォーマと同じものです。
## 確認する場所
階層ツリーにはデフォーマとアートメッシュが親子関係に沿って並び、クリックはキャンバスの選択と同期します。キャンバス右下の表示バーにある「デフォーマ Warp」「回転デフォーマ Rotation」スイッチで、キャンバス上での表示を切り替えます。あるオブジェクトがどのデフォーマの影響を受けているかは [[convenient-function-deformer]] を参照してください。

@@ making-and-placement-of-warp-deformer | ワープデフォーマ
生成された構造に適したデフォーマがないとき（たとえばアクセサリーや一房の髪だけを単独で曲げたいとき）は、自分でワープデフォーマを追加します。PSD2Live ではキャンバス上で枠をドラッグして作成し、ドラッグ中のプレビュー枠がそのまま最終的な格子になります。
## 作成
1. 階層ツリーまたはキャンバスで、デフォーマに入れたいアートメッシュを選択します。複数選択する場合は同じ親デフォーマの下にある必要があります。
2. オブジェクトモードの左ツールバーの最後のグループで「Warp作成」（{key:TOOL_CREATE_WARP}）を選びます。キャンバスの右クリックメニュー「作成」から、または階層ツリーの右クリック「親 · ワープ」「子 · ワープ」から入ることもできます。
3. キャンバス上で矩形をドラッグし、ドラッグ中にホイールで変換の分割数を調整します。選択したオブジェクトにぴったり合わせるだけなら、「選択範囲から作成」を押します。
4. 左下の配置パネルで追加先、挿入するパーツ、サイズの扱いを確認します。枠の内側をドラッグすると移動、角や辺の中点をドラッグすると拡大縮小します。
5. モードバーの「作成」を押すか {key:FINISH_PATH} でプロジェクトに書き込み、「キャンセル」または {key:CANCEL} で破棄します。
{tutorial=CREATE_DEFORMER}
| 配置オプション | 内容 |
|---|---|
| 追加先 | 選択オブジェクトの親にする / 選択デフォーマの子にする（空）/ 親デフォーマを指定 |
| 挿入するパーツ | 新しいデフォーマを入れるパーツ。デフォルトは選択範囲のパーツを引き継ぐ |
| サイズ | 選択に合わせる（+5% 外側へ拡張）/ キーフォーム包絡を含める / 選択の中心に合わせる |
| 連続作成 | 作成後、続けて次のデフォーマを配置する |
*> Cubism の作成ダイアログと違い、名前と分割数は作成前には入力しません。分割はドラッグ中にホイールで決め、デフォルト値は「ツール詳細」パネルとモデルプリセットで設定します。配置枠は移動と拡大縮小だけで、回転はできません。
## 編集レベル：頂点とベジェ
ワープデフォーマを選んで変形モードに入ると、モードバーに「頂点」と「ベジェ」の 2 つのレベルが表示されます（{key:PICK_OPTION_1} / {key:PICK_OPTION_2}）。頂点レベルでは格子の点を 1 つずつ編集します。ベジェレベルではシアンのアンカーと琥珀色のハンドルだけをドラッグして、少数の制御点で格子全体を曲げます。このとき細かい格子は薄く表示され、編集できません。インスペクタでは「ベジェ分割数」、「ベジェ制御点をリセット」、「デフォーマ変換(3.2方法)」を設定できます。

@@ making-and-rotation-of-rotationdeformer | 回転デフォーマ
腕、首、ペンダントのように 1 点を中心に回る部品には、回転デフォーマが最も手軽です。持っているのは原点、角度、拡大率だけなので、パラメータがどの値でも正確な剛体回転になり、格子のように中間値で形が崩れることがありません。
## 作成
1. 回転させたいアートメッシュまたはデフォーマを選択します。
2. オブジェクトモードのツールバーで「回転作成」（{key:TOOL_CREATE_ROTATION}）を選ぶか、キャンバスの右クリックメニュー「作成」、階層ツリーの右クリック「親 · 回転」から入ります。
3. キャンバス上で回転の中心から方向の端点へドラッグします。1 回のドラッグで原点と向きが同時に決まります。Shift を押すと 15° 単位でスナップします。
4. 新しいデフォーマは選択したオブジェクトの直接の親として挿入され、元の親は保たれます。キャンバスには付け替わるオブジェクトがハイライト表示され、配置パネルには影響するデフォーマとアートメッシュの数が表示されます。
5. {key:FINISH_PATH} を押すか「作成」で確定し、{key:CANCEL} でキャンセルします。
{tutorial=CREATE_DEFORMER}
## 調整
変形モードで、原点をドラッグすると平行移動、端点をドラッグすると回転します。Shift で角度をスナップし、Alt + 端点ドラッグで拡大率を調整します。回転デフォーマには変形ブラシを使えないので、移動、回転、拡大縮小ツールを使ってください。
*> ハンドルの向きは Cubism の慣例に従い、0° で上向き、時計回りが正です。そのため書き出し後に Cubism Editor で見る角度も一致します。
四肢、しっぽ、翼の回転デフォーマは、通常は手作業で作る必要はありません。ボーンから自動生成されます。[[skeleton]] を参照してください。

@@ system-of-parent-child-relation | 親子関係の仕組み
オブジェクトは、置かれているデフォーマに従って動きます。親が先に変形し、子オブジェクトはまとめて運ばれ、その上に子自身のキーフォームが重なります。これを理解すると、ある形が「自分で動いている」のか「運ばれて動いている」のかを見分けられます。
## 継承のルール
- ワープデフォーマの下のオブジェクト：形全体が親の格子と一緒に曲がります。
- ワープデフォーマの下のワープデフォーマ：子デフォーマの制御点が親によって変換され、内部は自分の格子で補間されます。
- ワープデフォーマの下の回転デフォーマ：原点の位置と角度だけを継承し、親の曲げはその下に伝わりません。
- 回転デフォーマの下のオブジェクト：原点に合わせて剛体として回転します。
## 編集時に 2 種類の動きを見分ける
オブジェクトに直接割り当てられたパラメータはそのオブジェクト自身の形を決め、親のパラメータは階層を通じて伝わります。形を変える前に、オブジェクト自身の軸を変えたいのか、実は親側を変えるべきなのかを確認してください。そうしないと、親から来るポーズをオブジェクト自身の割り当てと取り違えやすくなります。階層ツリーの「親」バッジは、選択したオブジェクトの祖先を示します。
関連：[[setting-of-parent-child-relation]] · [[combintion-of-parent-child-relation]] · [[keyform-parent-chilid-relation]]

@@ setting-of-parent-child-relation | 親子関係の設定
親を変えるには階層ツリーでドラッグするだけです。新しいデフォーマを作るときにも、誰の上または下に入れるかをその場で決められます。
## 階層ツリーで親を変更する
1. 階層ツリーで、アートメッシュまたはデフォーマの行を押さえます。
2. 目的のデフォーマの上にドラッグして離すと、その下に入ります。「ここにドロップして最上位へ移動」の領域にドラッグするとルートへ移動します。
3. 親の変更は 1 ステップの履歴で、元に戻せます。
{tutorial=HIERARCHY}
!> 透明な画像を階層ツリーにドラッグするのはレイヤーの読み込みで、親の変更ではありません。
## デフォーマの挿入時に設定する
- 階層ツリーの右クリック「親 · ワープ」「子 · ワープ」「親 · 回転」で、選択したオブジェクトの上または下に新しいデフォーマを挿入します。デフォーマを削除すると、その子は 1 つ上の階層に移ります。
- Warp を作成するとき、配置パネルの「追加先」で、選択オブジェクトの親にする、選択デフォーマの子にする（空）、親デフォーマを指定、のいずれかを選べます。[[making-and-placement-of-warp-deformer]] を参照してください。
*> 生成されたモデルで親を変更したあと、モデルプリセットやスケルトンの変更などで再生成が行われても、変更は 3 方向マージで保持されます。[[update-generated-rig]] を参照してください。

@@ combintion-of-parent-child-relation | 親子関係の組み合わせ
複雑な動きをいくつかの単純な動きの層に分けるのが、デフォーマ構造の基本的な考え方です。外側の層が大きな向きの変化を、内側の層が局所的な曲げや回転を担当し、各層は必要なパラメータだけを割り当て、下の層は上の層の動きを自動で継承します。
## 生成モデルでの層構造
PSD2Live が生成する体はこのように積み重なっています（実際の構造は階層ツリーで確認してください）：
1. `DeformBodyXY`：体 X / Y。上半身全体の向きと、腰に合わせた移動。
2. `DeformBodyLean`：体の前後傾と頭身（デフォルメ）。
3. `DeformBodyZBreath`：体 Z と呼吸。
4. その下に頭の回転と顔の経緯格子、さらにその下に顔パーツと髪があります。
そのため、頭を回すと頭は体の向きにも同時に引っ張られ、頭の上で体の動きを重ねて作り直す必要はありません。スケルトンを有効にすると、胴体の曲げと四肢の回転デフォーマがこのチェーンの末端につながります。[[skeleton]] を参照してください。
## 組み立てるときのコツ
- 粗い格子の上位デフォーマは下位の形を再サンプリングするため、細かい曲げはメッシュに最も近い層に置きます。
- 曲げに追従させたい部品はワープデフォーマの下に置きます。回転デフォーマの下に置くと、原点と角度しか継承しません。

@@ auto-generation-of-deformer | デフォーマの自動生成
PSD を読み込むと、PSD2Live はレイヤーの分類に沿ってデフォーマ、パラメータ、キーフォーム一式を一度に生成し、モデルはすぐに動きます。作業は「構造を組む」ことから「構造を調整する」ことに変わります。
## 生成される内容
- 体のチェーン：体 X / Y、前後傾、体 Z と呼吸。立ち姿の全身キャラクターには脚のデフォーマも加わります。
- 頭：頭の回転と頭殻の追従、顔の経緯格子、顔の輪郭と顔パーツの移動。[[face-auto-edit]] を参照してください。
- 髪：前髪と後ろ髪の追従と揺れの分岐。別途 [[auto-generation-of-sway-motion]] やシミュレーションを加えることもできます。
- スケルトン（有効時）：胴体の曲げと四肢の回転デフォーマ。[[skeleton]] を参照してください。
具体的なオブジェクトはモデルプリセットによって変わるので、階層ツリーで確認してください。
## 生成結果の調整
1. モディファイアパネルの **ワールド** ページにある「ロールコンポーネント」の節で各コンポーネントの幅や数値を、「モデルプリセット」の節でモーションや物理演算を調整すると、モデルがそれに合わせて再生成されます。
2. 生成結果に対して行った編集は、新しい生成結果にマージされて保持されます。
3. 新しいバージョンのジェネレーターの改良を取り込みたいときは、「モデル → 生成結果を更新」を使います。[[update-generated-rig]] を参照してください。
*> ワープデフォーマを手動で作成するときも、「選択範囲から作成」と配置パネルのサイズの扱いによって、選択したオブジェクトに合わせて自動でサイズが決まります。
関連：[[model-presets]] · [[psd-import]]

| オブジェクトを表示の中央に置く | {key:FRAME_VIEW} |

@@ parameter | パラメータについて
パラメータは、角度 X や目の開閉のように、モデルを駆動する数値スライダーです。オブジェクトはパラメータのいくつかのキーごとに形（キーフォーム）を 1 つ記録し、パラメータが中間の値をとると形が自動で補間されます。アニメーション、物理演算、フェイストラッキングも、最終的にはパラメータの値を変えているだけです。読み込み後に生成されたモデルにはすでにパラメータ一式が付いているので、パラメータパネルでスライダーを動かすだけで効果を確認できます。
## パラメータパネル
| 操作 | 方法 |
|---|---|
| 値を変える | スライダーを左ドラッグ |
| キーにスナップ | キーマークにホバーして右クリック |
| 2D 操作 | 2 つのパラメータを結合すると 2D パッドとして表示される。左ドラッグで操作し、右クリックで 2 つのパラメータのキーの交点にスナップ |
| リセット / ロック | 行内のリセットボタンとロックボタン。ツールバーの「すべてデフォルト値にリセット」「すべてロック解除」 |
| 検索 | 名前または ID で検索。「関連のみ」で選択したコンポーネントに割り当てられたパラメータだけを表示 |
| 定義の変更 | パラメータ名をクリックして「パラメータ設定」を開く。[[parameter-modifyication]] を参照 |
{tutorial=PARAMETERS}
## キーマークの見方
- 丸は通常のキーで、キーとキーの間は補間されます。四角はブレンドシェイプのキーで、形の差分を基本の形に加算します。[[blend-shape]] を参照してください。
- キーマークにホバーすると、そのキーにキーフォームを持つコンポーネントが一覧表示されます。
- 物理演算アイコンの付いたパラメータは物理演算の出力パラメータで、プレビューでは物理演算が制御します。
!> パラメータ上のキーはモデリングのデータで、アニメーションのタイムライン上のキーフレームとは別物です。
*> 複数のキャンバスタブは同じパラメータのポーズを共有します。あるキャンバスで調整した値は、ほかのキャンバスにも反映されます。

@@ edit-parameters | パラメータにキーを追加・削除
PSD2Live では、キーの位置はパラメータ自身のものであり、そのパラメータを割り当てたすべてのオブジェクトで共有されます。オブジェクトがあるキーで変形されると、その形がそのキーに記録されます。
*> Cubism ではオブジェクトを選択してから「2点追加 / 3点追加」でそのオブジェクトにキーを追加します。ここでは、「パラメータ設定」でパラメータのキーポイントをまとめて編集し、オブジェクトは「キー上で変形する」ことで割り当てられます。
## キーの追加・削除と移動
1. パラメータパネルでパラメータ名をクリックし、「パラメータ設定」を開きます。
2. 「キーポイント」軸の空いている所をクリックして点を追加し、ドラッグで値を調整します。数字をクリックすると直接入力でき、Enter で確定します。右クリックで削除します。
3. 「ステップ」はドラッグ時のスナップ間隔を決め、「等分」はキーポイントを均等に並べます。軸の両端では最小値、デフォルト値、最大値を直接入力できます。
4. 「キー編集を戻す」「キー編集をやり直す」で戻し、「保存」を押して一度にコミットします。
!> キーを移動すると、既存のキーフォームもキーと一緒に移動します。キーを削除すると、各オブジェクトのそのキーの形も一緒に削除されます（元に戻せます）。
## オブジェクトにキー上の形を持たせる
1. オブジェクトを選択します。
2. パラメータパネルでパラメータを目的のキーまでドラッグします（または右クリックでキーにスナップします）。
3. 変形モード（{key:MODE_DEFORM}）に切り替えて形を変更すると、結果がそのキーのキーフォームに書き込まれます。
新規作成したパラメータ自体は動きを生みません。キー上でオブジェクトの形を作って初めて動きます。

@@ parameter-modifyication | パラメータの調整
パラメータの名前、範囲、キーは「パラメータ設定」で変更します。パラメータが増えたら、フォルダと 2D 結合でパラメータパネルを整理します。
## 定義を変更する
1. パラメータパネルでパラメータ名をクリックし、「パラメータ設定」を開きます。
2. 「名称」を変更します。ID は新規作成時のみ編集できます。
3. 「キーポイント」軸の両端で最小値、デフォルト値、最大値を変更します。デフォルト値は範囲内である必要があります。
4. 「保存」を押します。これは 1 ステップの元に戻せる履歴です。
ダイアログには、ほかに「パラメータ値をロック」（プレビューだけを現在の値に保つ。定義には含まれません）、「パラメータ定義を複製」（名前と範囲を複製し、コンポーネントの割り当てと変形データは複製しません）、「パラメータを削除」（関連するキーフレームと連動関係も一緒に削除します）があります。
通常のパラメータでは「リピート」もオンにでき、値が最大値を超えると最小値から続きます。[[repeat]] を参照してください。
!> 範囲を狭めると、アニメーション内のキーの値とベジェ制御点も合わせて制限されます。パラメータを削除すると、対応するアニメーションのトラックも削除されます。
## パラメータパネルを整理する
- ツールバーでパラメータまたはフォルダを新規作成します。フォルダを右クリックすると、その中にパラメータ / フォルダを新規作成、ラベル色の設定、名前の変更、フォルダの解除ができます。
- 行内の結合ボタンでパラメータを次の項目と結合して 2D コントローラにします。「結合を解除」で 2 本のスライダーに戻ります。2D パッドの高さはドラッグで調整できます。

@@ extended-interpolation-folder | 拡張補間
@@ extended-interpolation | 拡張補間について
@@ extended-type | 補間の種類
@@ repeat | リピート
パラメータの「リピート」をオンにすると、値が最大値を超えると最小値から、最小値を下回ると最大値から続きます。回り続ける車輪や風車、ぐるぐる揺れるしっぽに向いています。
## 設定
1. パラメータパレットでパラメータ名をクリックし、「パラメータのプロパティ」を開きます。
2. **リピート（最大値を超えると最小値に戻る）** にチェックを入れ、「保存」を押します。元に戻せる履歴 1 ステップです。通常のパラメータだけが設定でき、ブレンドシェイプパラメータには設定できません。
## 効果
- プレビューとランタイムは値を範囲内に戻します。最大値と最小値は同じ姿勢になるので、両端の形をそろえておきます。
- モーションではこのパラメータのキーを範囲の外に、最大 64 周まで打てます。連続した回転に使います。[[timeline-basic-operation-repeat]] を参照してください。
- `moc3` にはパラメータのリピートフラグ（Cubism 5.3 以降の形式）が、`cmo3` には `isRepeat` が書き出されます。
- 値の戻し方は Cubism と同じです。ちょうど整数周だけ最大値を超えると最小値に、最小値を下回ると最大値になります。
- 物理演算の入力とモーションのフェードは範囲内に戻した値を使うため、両端をまたぐと反対側の値で計算され、連続した回転の想定と異なることがあります。
- リピートに対応しないターゲットへ書き出すと、ダウングレードレポートに範囲外のキーを持つモーションのカーブが 1 件ずつ載ります。
!> Cubism 5.3 より前の SDK ターゲットへ書き出すと、リピートは外されてダウングレードの報告に載り、範囲を超えたモーションの値はランタイムで両端に切り詰められます。
@@ recording-parameters | パラメータの操作を記録してアニメーションを生成
@@ copy-and-paste-parameter-values | パラメータ値をコピー/貼り付け
気に入った表情やポーズができたらパラメータスナップショットとして保存しておくと、あとでワンクリックでその状態に戻れます。パラメータ値を 1 つずつコピーするより手軽で、いくつかのポーズを行き来しながら形を比べて直すときに向いています。スナップショットはパラメータの値だけを記録し、モデルは変更しません。
## パラメータスナップショットを使う
1. パラメータパネルでパラメータを目的のポーズに合わせます。
2. スナップショットバーの「現在のパラメータをスナップショットとして保存」を押すと、新しいスナップショットが「スナップショット n」という名前で作られます。
3. スナップショットにホバーするとキャンバスでそのポーズをプレビューでき、クリックで読み込み、中クリックで削除します。
4. スナップショットを右クリックすると「現在の値で上書き」、名前の変更、削除ができます。
*> スナップショットはパラメータ一式を読み込むので、Cubism のように選択したパラメータだけをコピーして貼り付けるのではなく、すべてのパラメータ値を一度に貼り付けるのと同じです。
## ボーンのポーズ
ボーンモードで付けたポーズは、「ツール詳細」で名前を付けて保存して再び適用できます。アニメーションエディターの「保存ポーズを挿入」は、それを再生ヘッドの位置に挿入します。[[skeleton]] を参照してください。

@@ how-to-choose | 選択の方法

@@ how-to-edit | 編集の方法
キーフォームはすべて変形モードで作ります。パラメータをあるキーに合わせてから、オブジェクトの形を変更します。パラメータがまだ割り当てられていないオブジェクトでは基本の形を、割り当て済みのオブジェクトでは現在のパラメータの組み合わせのキーフォームを変更します。
## 基本の流れ
1. オブジェクトを選択し、変形モード（{key:MODE_DEFORM}）に切り替えます。
2. パラメータパネルでパラメータを目的のキーに合わせます。
3. 下の表のツールで形を変更します。マウスを離すと履歴に入り、{key:UNDO} で元に戻し、{key:REDO} でやり直せます。
{tutorial=DEFORM_MODE}
| ツール | ショートカット | 働き |
|---|---|---|
| 変形 | {key:TOOL_TRANSFORM} | 変形枠で選択した点を移動、拡大縮小、回転する |
| 変形ブラシ | {key:TOOL_BRUSH} | ブラシ範囲内の点を押し動かす。[[deform-brush]] を参照 |
| スムーズブラシ | {key:TOOL_SMOOTH} | 形をなめらかにする |
| 膨張・収縮 | {key:TOOL_INFLATE} | 外側へ膨らませる、または内側へ縮める |
- {key:AXIS_CONSTRAIN_X} / {key:AXIS_CONSTRAIN_Y} で移動を 1 つの軸方向に制限します。
- ワープデフォーマは「頂点」「ベジェ」の編集レベルを切り替えられます。回転デフォーマは原点と端点をドラッグして編集します。
- 「ツール詳細」の「正確な変形」では、数値で選択した点を移動、拡大縮小、回転できます。[[edit-vertices]] を参照してください。
- キャンバスの右クリックメニュー「キーフォームをミラー」で、できあがった側を反対側へミラーします。[[motion-mirroring]] を参照してください。
- キャンバスの右クリックメニュー「キーフォーム」で、現在のキーの形状をコピー・貼り付け・リセット・補間します。[[copy-and-blend-shape]] を参照してください。
- 「ソフト選択」（{key:SOFT_SELECTION_TOGGLE}）をオンにすると、選択した点をドラッグ・変形したとき周囲の点も距離に応じて減衰しながら一緒に動きます。範囲はツールオプションバー、または {key:BRUSH_RADIUS_DOWN} / {key:BRUSH_RADIUS_UP} で調整します。減衰カーブは変形ブラシと共通で、影響を受ける点は赤い円で示されます。
*> メッシュ構造の変更（点の追加、線）は編集モードで行い、形の変更とは分かれています。普段の修形は変形モードのままで十分です。ジェネレーターが所有するキーフォームを編集すると、変更は生成結果の上書きとして記録され、再生成後も保持されます。[[generated-overrides]] を参照してください。

@@ keyform-parent-chilid-relation | キーフォーム(親子関係の動き)
親デフォーマと子オブジェクトは同じパラメータを割り当て、それぞれのキーに形を記録できます。パラメータが変わると、親が運ぶ全体の動きと子自身の形が重なって最終的な結果になります。こうすると大きな動きは親に任せ、子オブジェクトは小さな補正だけで済みます。
## 生成モデルの例
角度 X で首を振るとき、頭のデフォーマが頭全体の向きを担当し、顔の経緯格子と顔パーツがそれぞれ角度 X に応じて形を補正します。生成されたモデルはこのように層を分けて割り当てられています。
## 編集時の注意
- 先にオブジェクトが直接割り当てられているパラメータ（パラメータパネルの「関連のみ」）を確認し、親から階層を通じて来る動きと区別します。
- 子オブジェクトで編集する形は、現在のポーズでの親の状態を基準にします。
- キーフォームのミラーはオブジェクト自身の変形だけを扱い、デフォルトポーズの親を座標系とします。親のキーフォームは個別にミラーする必要があります。

@@ keyform-xydirection | キーフォーム（X,Yの動きをつける）
オブジェクトが 2 つのパラメータ（角度 X と角度 Y など）に同時に割り当てられている場合、キーフォームは格子状に並びます。X のキーと Y のキーの組み合わせごとに形が 1 つあり、斜めのポーズは周囲のキーから補間されます。生成された頭は、角度 X / Y の端点と中点の組み合わせですでに 9 つのポーズが作られており、斜めの角には別途補正があります。強さは「頭の向き」コンポーネントカードの **数値** で調整できます。
## XY の形を自分で作る
1. パラメータパネルで行内の結合ボタンを使って 2 つのパラメータを 2D コントローラとして結合し、パッド上で右クリックして 2 つのパラメータのキーの交点にスナップします。
2. 変形モードで各交点の形を順に作ります。まず端点と中点を、次に 4 つの斜めの角を作ります。
3. パッドでキーの間をドラッグし、補間が自然か確認します。
{tutorial=PARAMETERS}
*> 4 つの斜めの角の形は 1 つずつ作る必要があります。PSD2Live は Cubism のように自動合成しません。

@@ copy-and-blend-shape | フォームの編集
変形モードのキャンバス右クリックメニュー「キーフォーム」では、あるキーの形状を別のキーや同等のオブジェクトへコピーしたり、キーをデフォルトの形状へリセットしたり、両側のキーから中間のキーを補間したりできます。結果は通常のキーフォームとして書き込まれ、元に戻せます。
## 使い方
1. 変形モードでオブジェクトを選択し、パラメータをそのオブジェクトのキーに合わせます。
2. キャンバス右クリックメニュー「キーフォーム」から操作を選ぶか、下表のショートカットを使います。
| 操作 | ショートカット | 内容 |
|---|---|---|
| キーフォームをコピー | {key:KEYFORM_COPY} | 選択中の各オブジェクトの、現在のパラメータでの形状と不透明度・色などを記録します。後でコピー元を変えても貼り付けには影響しません |
| キーフォームを貼り付け | {key:KEYFORM_PASTE} | コピーした形状を移動量として現在のキーに書き込みます（メッシュは初期形状から、ワープと回転デフォーマはデフォルトキーの形状から）。同じオブジェクト、または同じ種類で三角形（ワープは行と列）と親が同じオブジェクトへ貼り付けられます |
| デフォルトキーの形状にリセット | {key:KEYFORM_RESET} | 現在のキーを、各パラメータがデフォルト値のときの形状に戻します |
| メッシュの初期形状にリセット | — | メッシュのみ：現在のキーを変形前のメッシュに戻します |
| （パラメータ）の隣接キーから補間 | {key:KEYFORM_INTERPOLATE} | そのパラメータの両側の隣接キーから現在のキーを作り直します。補間できるパラメータが複数あるときはメニューにそれぞれ並びます（ブレンドシェイプのパラメータを除く） |
- 点を選択しているときは、貼り付け・リセット・補間は選択した点だけを変更し、メニューに点の数が表示されます。ベジェレベルのワープとローテーションデフォーマは常に全体を扱います。
- オブジェクトがパラメータにバインドされていないか、パラメータがキーの間にあるときは、メニューに理由が表示され、形状の操作は使えません。
- ジェネレーターが所有するキーフォームの形状を変えると、生成結果の上書きとして記録されます。[[generated-overrides]] を参照してください。
- 「オプションを指定して貼り付け…」で一部の内容だけを貼り付けたり、比率でブレンド・反転したり、複数形状の貼り付け先を指定したりできます。[[paste-form-special]] と [[confirm-target-for-pasting-multiple-forms]] を参照してください。「全キーをデフォルトキーの形状に復元」は [[restore-deformer-shape]]、「複数キーの編集…」は [[multi-key]] を参照してください。

@@ paste-form-special | フォームの特殊な貼り付け
「オプションを指定して貼り付け」は、チェックした内容だけを貼り付け、比率でブレンドしたり反転したりして貼り付けることもできます。
## 使い方
1. 変形モードでオブジェクトを選択し、{key:KEYFORM_COPY} またはキャンバスの右クリックメニュー「キーフォーム → キーフォームをコピー」でコピーします。
2. 書き込むキーにパラメータを合わせ、「キーフォーム」から「オプションを指定して貼り付け…」を選びます。
3. ダイアログで設定し「貼り付け」（または Enter）を押します。
| オプション | 内容 |
|---|---|
| 貼り付ける内容 | 形状（点）、不透明度、描画順、乗算色、スクリーン色を任意に組み合わせます。形状を外すと、チャンネルは選択中のどのオブジェクトにも貼り付けられます（描画順はメッシュのみ） |
| ブレンド率 | 100% でそのまま貼り付け、小さいと現在のキーをその割合だけコピーした値に近づけます（フォームのブレンド） |
| 反転 | 左右反転ではワープの列を、上下反転では行を逆順にします。メッシュは初期形状で鏡像の位置にある頂点を対応させます（初期形状がその向きに対称でなければ拒否）。各点は対応点の移動量を反転して受け取り、回転デフォーマは角度の変化を反転します |
*> Cubism と異なり、反転は移動量に対して行うため反転軸の指定は不要で、ワープの「裏返す」オプションはありません。非対称なメッシュは [[motion-mirroring]] を使ってください。ダイアログを閉じた後の通常の貼り付けは形状のみです。

@@ confirm-target-for-pasting-multiple-forms | フォームの貼り付けの適用先
複数オブジェクトの形状をまとめてコピーした場合、各形状をどのオブジェクトへ貼り付けるかを「オプションを指定して貼り付け」ダイアログで確認・変更できます。
## 対応の決め方
- コピー時は選択中のメッシュごとに形状を記録します（最初が現在のターゲット）。
- 貼り付け時、コピー元自身が選択中でそのキー上にあれば自分自身へ、そうでなければまだ割り当てられておらず形状を受け取れる次の選択オブジェクト（同じ種類、同じ三角形〔ワープは行と列〕、同じ親）へ貼り付けます。
- ダイアログの「貼り付け先」にコピー元 → 貼り付け先が並び、ほかの適合するオブジェクトや「貼り付けない」に変更できます。形状を外すと選択中のどのオブジェクトにも割り当てられます。
- どの形状もコピーした時点の状態で書き込まれるため、A と B を互いに貼り付けると入れ替わります。
*> 通常の貼り付け（{key:KEYFORM_PASTE}）はダイアログを出さず自動の対応を使います。

@@ synthesize-corners | 四隅のフォームを自動生成
@@ face-auto-edit | 顔の動きの自動生成
頭の向き、まばたき、目玉、眉、口の変形と口の開閉は、PSD を読み込んだ時点ですべて生成されます。上下左右の形を先に手作業で作っておく必要はありません。数値で幅を調整し、気になる箇所だけ手動で修形します。
## 生成される内容
- 頭 X / Y：端点と中点の組み合わせで 9 つのポーズを作り、原画の頭の傾きを基準にします。斜めの角には別途補正があります。
- 顔は経緯格子と領域ごとの修形を使います。目と眉、瞳、口、耳には個別の補正やマスクがあります。
- 口：口形の設定に従って開閉と口の変形を生成し、上下の唇の輪郭も選択して生成できます。
- 前髪から透ける眉：前髪に隠れる眉ごとに複製を前髪のすぐ上へ半透明で描き、前髪でクリッピングして、アニメのように髪越しに眉を見せます。複製は元の眉の変形・フォーム・編集にすべて追従するので、編集は複製ではなく元の眉に行います。前髪から透ける目：白目、瞳とハイライト、まつ毛など目のすべてのパーツの範囲で前髪が薄くなり、目全体が髪越しに見えます。閉じ目は眉と同じく前髪の上に複製します。新しいモデルではどちらもオンで、以前に作ったモデルはそのまま（目はオフ）、オンにするまで作られません。
- 前髪と後ろ髪は強い顔の変形から切り離され、それぞれの揺れパラメータを出力します。
## 幅の調整
1. モディファイアパネルの **ワールド** ページにある「ロールコンポーネント」の節で「頭の向き」カードを開き、「顔パーツ移動デフォーマ」スイッチと「頭部の可動範囲」を調整します。「体のポーズ」カードでは「身体の可動範囲」を調整します。
2. 各コンポーネントカードの「数値」で、頭の向き、目、眉、口、髪の各項目を細かく調整します（鼻と耳は頭の向きにあります）。あまり使わない項目は「詳細」にあります。
3. 変更するとモデルが再生成され、既存の手動編集はマージされて保持されます。
## 手動での修形
生成された顔のキーフォームは、変形モードでそのまま修正できます。方法は [[how-to-edit]] を参照してください。
!> これはプリセットのアルゴリズムによる生成結果で、3D 復元ではありません。レイヤー分けの仕方、幅の広い髪束、極端な角度、重なった領域などでは手動での修形が必要になることがあります。
関連：[[model-presets]] · [[standard-parameter-list]]

@@ auto-generation-of-sway-motion | 揺れの動きの自動生成
髪、アクセサリー、スカートの裾などの部品は、選択するだけで一度に揺れを生成できます。PSD2Live は新しいパラメータの -1 / 0 / 1 に揺れのキーフォームを自動で作り、同時に物理演算の振り子も生成するので、書き出し後は頭の動きに合わせて揺れます。設定はプロジェクトと一緒に保存され、いつでも開き直して調整できます。
## 開く
- オブジェクトモードで、キャンバス上で選択したメッシュまたはワープデフォーマを右クリックし、「揺れを生成...」を選びます。生成済みの場合は「揺れを編集...」と表示されます。階層ツリーの右クリックにも同じメニューがあります。
- 物理演算パネルの「新規」→「選択対象に揺れを作成…」。
メッシュを選択した場合は、ぴったり合うワープデフォーマが自動で 1 層かぶせられます。回転デフォーマは対象にできません。
## 編集
1. 開くとキャンバスが揺れの編集に入り、左下に揺れパネルが表示されます。
2. キャンバス上でハンドルをドラッグします。先端の丸で振幅と跳ね上がり、中心線のひし形で柔らかさ、先端の両角で拡大 / 縮小と平行度を設定し、中抜きの丸で揺れの矩形全体を回転、中抜きの四角で支点の辺を変更します。
3. パネルで揺れ方向（左右 / 上下、同時にチェック可）、分割（1–3）、自動推定（髪 / 小物 / 布）、物理演算の振り子を生成するかどうかを選びます。
4. 「揺れをプレビュー」で効果を確認します。「生成」/「適用」または Enter で書き込み、「キャンセル」または Esc で破棄します。
*> Cubism の同名の機能に比べ、メッシュを対象にでき、上下方向の揺れ、分割、根元の平行（複数の髪束を一緒に揺らす）にも対応しています。パラメータが存在しない場合は自動で `ParamSwing<id>` という名前で作成され、振り子は physics3.json と cmo3 に書き出されます。
## 再生成とベイク
揺れの軸上のキーフォームは揺れが所有し、再構築のたびに対象の現在の形から再計算されます。これらのキーフォームへの手動の変更は生成結果の上書きとして記録されます（[[generated-overrides]] を参照）。完全に手動で引き継ぎたいときは「キーフォームとして適用」を押すと、現在の形が通常のキーフォームとして書き込まれ、物理演算の振り子だけが残ります。「削除」は生成された軸と自動作成されたパラメータも一緒に削除します。

@@ edit-vertices | 頂点をキャンバス座標で編集
PSD2Live では、ドラッグ、変形枠、ブラシは常に点がキャンバス上に表示されている位置に作用します。オブジェクトがどのデフォーマの下にあっても、プログラムが親のローカル座標へ自動で換算します。これはデフォルトの動作で、別途オンにする必要はありません。正確な数値が必要な場合は「正確な変形」を使います。
## 正確な変形
1. 変形モードで動かしたい点を選択します。
2. 「ツール詳細」パネルの「正確な変形」を開きます。
3. 移動量（キャンバスのピクセル）、拡大率、回転角度を入力し、「適用」を押します。
回転と拡大縮小は変形枠のアンカーを中心にします。対象が回転デフォーマ 1 つの場合はその原点を中心にします。数値は選択した点全体に作用し、頂点ごとの座標入力はありません。
{tutorial=TOOL_DETAILS}
## 変形枠で数値を見る
変形枠をドラッグすると、ポインターの横に回転角度、拡大率、または移動したキャンバスのピクセル数が表示されます。アンカーをドラッグすると中心を変更でき、中心、角、辺の中点の近くでスナップします。

@@ restore-deformer-shape | デフォーマ形状の復元
デフォーマ（またはメッシュ）のキーフォームが崩れてやり直したいときは、「全キーをデフォルトキーの形状に復元」で、そのオブジェクトのすべてのキーをパラメータがデフォルト値のときの形状に戻します。1 回の履歴として記録され、元に戻せます。
## 使い方
1. 変形モードでデフォーマまたはメッシュを選択します。
2. キャンバスの右クリックメニュー「キーフォーム → 全キーをデフォルトキーの形状に復元」を選びます。
*> Cubism と異なり、「元の形状」は別に記録しません。復元の基準はオブジェクトの現在のデフォルトキーの形状（通常は最初にキーを追加したときの形状）です。MCP では `keyform_apply op=reset all_keys=true` です。

@@ glue | グルー
2 つの部品が継ぎ目で動くと裂けてしまうときは、グルーで 2 つのメッシュの頂点を貼り合わせます。グルー点は 2 つのメッシュが共有する同じ点で、キャンバスでは 1 つのひし形として表示され、選択やドラッグをすると両側の頂点が常に一緒に動きます。
## 作成
1. オブジェクトモードで 2 つのメッシュを選択し、編集モード（{key:MODE_EDIT}）に切り替えます。
2. 「グルー」ツール（{key:TOOL_GLUE}）を選びます。その下に 3 つのサブツールがあります：グルーブラシ、重みブラシ、再結合（{key:PICK_OPTION_1}–{key:PICK_OPTION_3}）。
3. 重なっている所をグルーブラシで塗ります。または {key:FINISH_PATH} / モードバーの「グルーを作成」で、2 本の輪郭に沿って一続きに接着します。
{tutorial=EDIT_MODE}
## 操作
| 操作 | 効果 |
|---|---|
| グルーブラシ | 重なっている所で、もう一方のメッシュに頂点を追加またはスライドさせる（UV も一緒に動く）。メッシュだけを変え、画は変えない |
| Alt + ドラッグ | 接着を解除する |
| 重みブラシ | 両側の引き寄せウェイトを青（A）/ オレンジ（B）で表示して塗る |
| 再結合 | 塗った頂点の既存の接着を外し、スナップの許容値で接着し直す |
| {key:GENERATE} | どちらかのメッシュで選択した頂点を接着する |
| 右クリック「距離で縫い目全体を再結合」 | 2 つのメッシュ間の接着をすべて外し、輪郭に沿って接着し直す |
*> 2 つのメッシュに、あらかじめ位置のそろった頂点がある必要はありません。グルーブラシがもう一方に頂点を補ったりスライドさせたりして、両側を重ねます。
!> 接着は静止形（すべてのパラメータがデフォルト値）の上で行います。パラメータがデフォルト値でないときは、グルーブラシ、再結合、グルーの作成は、まずパラメータをなめらかにデフォルト値へ戻してから接着します。
ボーンで分割した四肢や前後分割には、グルーが自動生成されるので、通常は手作業で処理する必要はありません。

@@ deformpath | 変形パス
変形パス（実験的）は、部品に沿って曲線を描き、曲線上の制御点をドラッグすると、メッシュが曲線に沿って変形する機能です。長い髪、リボン、しっぽに向いています。パスはメッシュに付ける編集補助にすぎず、結果はそのメッシュの通常のキーフォームとして書き込まれます。パス自体はデフォーマではありません。
## 作成と編集
1. アートメッシュを選択し、階層ツリーの右クリックで「変形パス」を選ぶか、{key:TOOL_CREATE_DEFORM_PATH} を押します。
2. アートメッシュ上をクリックして制御点を 2 つ以上置き、{key:FINISH_PATH} で確定、{key:CANCEL} でキャンセルします。
3. 編集モードでパスの割り当て位置、影響幅、硬さ、閉じ、角の点を調整します。このときメッシュは動きません。
4. パラメータパネルで目的のポーズを設定し、変形モードに切り替えて制御点をドラッグすると、形がアートメッシュのキーフォームに書き込まれます。
パスは L2 / L3 の 2 グループに分かれ、それぞれ別に保存されます。配置パネルか「ツール詳細」の「パス編集レベル」で選び、既存のパスはインスペクタの「編集レベル」で変更します。キャンバスには現在のグループのパスだけが表示されます。この 2 グループは、ワープデフォーマの頂点 / ベジェのレベルとは関係ありません。
## 書き出し
`.cmo3` にはパスコントローラの構造とメッシュのキーフォームが保存されます。`.moc3` にはベイク後のメッシュのキーフォームだけが保存され、ランタイムでパスのアルゴリズムは実行されません。
!> 1 つのメッシュに複数のパスを付けられますが、1 本のパスで複数のメッシュを制御することはできません。ドラッグの効果が Cubism Editor と完全に一致するかはまだ検証されていないため、幅、硬さ、大きな角度の変形は自分で確認してください。

@@ skinning | スキニング
関節をまたぐ 1 枚のメッシュ（分けていない腕やストッキングなど）を複数のボーンに合わせてなめらかに曲げる作業は、PSD2Live ではスケルトンに任せます。メッシュをボーンにバインドするとウェイトが自動計算され、書き出し時に回転デフォーマとメッシュの補正キーフォームへベイクされます。
## バインドとウェイト
1. ボーンモードで「ボーンを編集」（{key:TOOL_SKELETON_EDIT}）を選び、「バインド」サブツールでメッシュをボーンにバインドします。同じ肢のメッシュはそのうち 1 本にバインドするだけで十分です。
2. ウェイトは肢全体で自動計算されます。各頂点は関節の両側の最大 2 本のボーンに追従し、「関節の幅」の範囲でなめらかに遷移します。
3. 修正が必要な場合は「ウェイト」サブツールを使います。バインド済みのメッシュと同じ肢のボーンを選び、増加、減少、置換、スムーズで塗ります。
4. 「ツール詳細」では、自動ウェイトのクリーンアップや復元、別のメッシュへのウェイトのコピー / ミラーができます。
5. ポーズを付けるときに「表示 ▾」の「スキンウェイトを表示」（ピンで表示レールにも置けます）をオンにすると、ボーンの色で関節部の遷移を確認できます。
{tutorial=SKELETON}
関節の範囲内の頂点は、角度に応じて関節周りの回転をブレンドするため、曲げても肢の幅が変わりません。
*> Cubism のスキニングはメッシュをそのまま回転デフォーマの連なりに変換し、そのあとその連なりを編集します。ここではウェイトがスケルトンに属し、ボーンを変更したら再ベイクされます。詳しくは [[skeleton]] を参照してください。

@@ skeleton | ボーン
体、四肢、しっぽ、翼を動かしたいときは、ボーンが最も手早いバインド方法です。プログラムがレイヤーからスケルトンを自動で推定してメッシュをバインドし、あなたは関節を調整してポーズを付けます。書き出し時には Cubism でそのまま動く構造（胴体の曲げデフォーマ、四肢の回転デフォーマ、関節をまたぐメッシュの補正キーフォーム）へベイクされます。書き出したモデルはこのプログラムに依存しません。
*> Cubism Editor にはスケルトンオブジェクトがなく、四肢は通常、回転デフォーマの連なりとスキニングで手作業で組みます。ここでのボーンは、これらの構造を自動生成するためのツールです。
## スケルトンを作成する
1. モードメニューからボーンモード（{key:MODE_SKELETON}）に入ります。プロジェクトにまだスケルトンがない場合は、キャンバス中央か「スケルトン」タブの「スケルトンを作成」を押します。
2. プログラムがレイヤーのタグと左右からボーンを推定してバインドします。腕は同じ側の handwear、脚は legwear、足は footwear に、しっぽと翼はそれぞれのレイヤーにバインドされます。
3. 「ボーンを編集」（{key:TOOL_SKELETON_EDIT}）で調整します：「編集」で関節をドラッグし、「新規ボーン」「押し出し」でボーンを追加し、「バインド」でメッシュをまとめてバインドし、「ウェイト」でスキニングを修正します（[[skinning]] を参照）。
4. 「ツール詳細」ではボーンの複製、ミラー、細分化、融合ができます。「スケルトン」タブでボーンを選択すると、「関節の幅」と最小 / 最大角度を調整できます。
5. 「完了」を押すと 1 つの履歴として保存されます。ボーンのポーズへの切り替え、モードの変更、別のレイヤーの選択でも保存され、「キャンセル」だけが今回の変更を破棄します。
{tutorial=SKELETON}
!> 左右が同じレイヤーに描かれた肢はバインドされません。先に「モデル → メッシュごとにレイヤーを分割…」で分けてからバインドしてください。
## ポーズを付ける
「ボーンのポーズ」（{key:TOOL_SKELETON_POSE}）では、ボーンの本体をドラッグすると FK でそのボーンだけが回転し、末端をドラッグするか Shift を押しながらドラッグすると IK になります。「ツール詳細」では IK チェーンの長さ、反復回数、曲げる方向を設定し、「選択先端を固定」ができます。ポーズ付けはパラメータの値を変えるだけで履歴は作られず、「ポーズ復帰」ですべてゼロに戻ります。よいポーズは名前を付けて保存でき、あとで再適用したりアニメーションに挿入したりできます。
## 生成される構造とパラメータ
| 内容 | 説明 |
|---|---|
| 胴体の曲げ | `DeformSkelTorso`。上半身と下半身が腰を中心に曲がる |
| 四肢、しっぽ、翼 | 回転デフォーマ `DeformSkel_<ボーン ID>` |
| ボーンのパラメータ | `ParamArmLA`、`ParamLegLA`、`ParamTail1..n` など。単位は度 |
| ポーズのパラメータ | しゃがみ、重心移動、しっぽ振り、羽ばたき、内股、跳ね |
スケルトンで再生できるモーションはアニメーションパネルに表示されます。[[builtin-motions]] を参照してください。「スケルトン」タブの下部にある「パラメータのサンプリング」で、許容誤差、最小角度間隔、メッシュごとのキーフォームの上限を設定し、書き出しサイズを制御します。
## 書き出し時の注意
- 加算できる四肢のパラメータは、書き出し先が Cubism 5.0 以上の場合はブレンドシェイプのパラメータとして書き込まれます。5.0 未満の場合はすべて通常のキーフォームにベイクされ、回転デフォーマ上のポーズは取り除かれます。
- Cubism Editor にはボーン自体は残りません。あとでボーンを変更したい場合は `.psd2live` プロジェクトを保管してください。
関連：[[making-and-rotation-of-rotationdeformer]] · [[blend-shape]]

@@ generated-overrides | 生成結果の上書き
揺れ、シミュレーション、ボーンなどのジェネレーターのキーフォームは、再構築のたびに再計算されます。これらのキーフォームに加えた手作業の変更が再構築で消えることはありません。「生成結果の上書き」として記録され、すべてのジェネレーターのあとに新しい結果とマージされます。そのため、生成結果を安心して修形でき、あとから揺れ、スケルトン、モデルプリセットを調整することもできます。
## どの編集が上書きになるか
- 揺れが対象のワープデフォーマに生成したキーフォーム（揺れのパラメータがデフォルト値でないとき）。
- ベイク済みのシミュレーションがキーフォーム軸としてメッシュに書き戻したキーフォーム。
- ボーンのスキニングが、自分で付け替えたメッシュに書き込んだキーフォーム。
生成パラメータのデフォルト値での編集は通常の編集のままで、静止形を変更します。
## マージのルール
| 状況 | 結果 |
|---|---|
| 自分が変更していない点 | 新しい生成結果に従う |
| ジェネレーター側が今回変わっていない点 | 自分の値を保持する |
| 両方が変更した点 | 自分の値を保持し、競合として報告する |
## 問題を確認する
問題があると、インスペクタのツールバーに「上書きの問題 n 件」バッジが表示されます。選択したオブジェクトの問題はインスペクタ上部の「生成結果の上書き」に一覧表示され、バッジをクリックするとすべての問題が表示されます。
- 競合：一部の点がジェネレーターと自分の編集の両方で変更されたため、自分の編集を保持しました。
- 未適用：生成されたキーフォームがもう存在しない、生成された形の点数が変わった、またはメッシュが分割されて置き換えられた。
!> 生成されたキーフォームへの、または生成されたキーフォームからのコピーや、ジェネレーターの軸上でのキーの追加・削除は上書きとして記録できないため、拒否されます。揺れを完全に手動で編集したい場合は、先に揺れパネルで「キーフォームとして適用」を行ってください。
関連：[[auto-generation-of-sway-motion]] · [[simulation]] · [[update-generated-rig]]

@@ multi-key | マルチキー編集機能
複数のオブジェクトの多数のキーフォームについて、不透明度、描画順、乗算色、スクリーン色をまとめて変更します。たとえば、まばたきの全キーでまつげの描画順をまとめて前髪より前にします。
## 使い方
1. 変形モードで変更するオブジェクトを選択します（メッシュは複数選択可）。
2. キャンバスの右クリックメニュー「キーフォーム → 複数キーの編集…」を選びます。
3. 「編集範囲」にパラメータごとのキー値が並びます。不要な値をクリックして外すと範囲が絞られ、変更されるキーフォームの数が下に表示されます。
4. 変更する内容にチェックを入れて値を設定し、方法を選んで「適用」を押します。
| 方法 | 内容 |
|---|---|
| 上書き | 各キーフォームをその値にします |
| 加算 | 各キーフォームの値に加えます |
| 乗算 | 各キーフォームの値に掛けます（描画順は上書きと加算のみ） |
| スクリーン | 1 −（1 − 元の値）×（1 − 値）。主に色に使います |
- 結果は 1 回の履歴になります。変更するのはチャンネルのキーフォームで、通常のキーフォームとして書き込まれ、生成結果の上書きにはなりません。各チャンネルは既にある自身の軸に書き込み、トラックがまだないときだけオブジェクトの形状のキーに書き込みます。
*> デフォーマには描画順がないため、デフォーマを含むときは描画順を変更できません。MCP では `keyform_apply op=multi_key` です。

@@ motion-mirroring | 動きの反転
左右対称の動きは片側だけ作ります。角度 X 30 の形を作ったら -30 へ、あるいは左目の形を右目へミラーします。対称キーと反対側のオブジェクトはパラメータとレイヤーの意味からプログラムが自動で判断し、結果は通常のキーフォームとして書き込まれ、元に戻せます。
## 使い方
1. 変形モードでオブジェクトを選択し、パラメータをミラーしたいキーに合わせます。
2. キャンバスの右クリックメニュー「キーフォームをミラー」で操作を選ぶか、{key:MIRROR_KEYFORM} で対称キーへミラーします。
| 操作 | 働き |
|---|---|
| 対称キーへミラー | 現在のキーを対称キーへミラーし、そのキーに切り替えて結果を表示する |
| 対称キーからミラー | 対称キーの形で現在のキーを上書きする |
| 反対側のオブジェクトへミラー | 反対側の同種オブジェクトへ書き込む。L/R 付きのパラメータは反対側のものに置き換え、左右のパラメータは符号を反転する |
| その場で左右反転 | オブジェクト自身の中心で現在のキーを反転する |
| すべてのキーを反対側へミラー / すべてのキーを反対側のオブジェクトへミラー | すべてのキーを一度に処理する |
## 対称の判断のしかた
- 符号を反転する左右のパラメータは、範囲がデフォルト値を中心に対称で、かつ 2D 結合の横軸であるか ID が X、Z で終わるパラメータです（AngleX、BodyAngleX、EyeBallX など）。
- 反対側のオブジェクトは、まずレイヤーの意味で対応づけ、次に名前の L/R、Left/Right、左/右で対応づけます。
- オブジェクト自身の変形だけを扱い、親のキーフォームは個別にミラーする必要があります。複数のレイヤーを選択した場合はそれぞれミラーし、1 つの履歴としてコミットします。

@@ temporary-deform-tool | 一時変形ツール
一時変形ツールは、選択した点（またはオブジェクト全体）に使い捨ての格子を重ね、格子の点をドラッグしてそれらの点をまとめて曲げます。大きく形を変えるときに便利で、格子自体は保存されません。
## 使い方
1. 変形モードでメッシュまたはワープ（「頂点」レベル）を選択し、必要なら変形する点を選びます。
2. {key:TEMPORARY_DEFORM} を押すか、キャンバスの右クリックメニュー「一時変形（ワープ）」を選びます。
3. 格子の点をドラッグすると、内側の点がバイリニア補間で追従します。離すたびに 1 回の履歴になります。パラメータがキーの間にあるときは押した時点でまずキーに吸着し、別のキー・元に戻す・ほかの編集で形状が変わったときは現在の形状に格子を張り直します。この場合その押下ではドラッグは始まらないので、もう一度押してください。
4. ツールバーの「格子」で 1×1〜4×4 を切り替えます（現在の形状に格子を張り直します）。Enter、{key:CANCEL}、または「完了」で終了します。
*> Cubism と異なり、一時ワープ（格子）のモードだけです。拡大縮小や回転は変形ツール {key:TOOL_TRANSFORM}、パスに沿った曲げは変形パスを使います。

@@ deform-brush | 変形ブラシ
髪や顔の輪郭など、広い範囲をやわらかく調整したい箇所では、変形ブラシでブラシのように形を押し動かすと、点を 1 つずつドラッグするよりずっと速く作業できます。変更するのはジオメトリだけで、テクスチャは変更しません。
## 使い方
1. オブジェクトを選択して変形モードに切り替え、「変形ブラシ」（{key:TOOL_BRUSH}）を選びます。同じグループに「スムーズブラシ」（{key:TOOL_SMOOTH}）と「膨張・収縮」（{key:TOOL_INFLATE}）もあります。
2. キャンバス上でドラッグして形を押し動かします。選択がない場合はオブジェクトのすべての点に、選択がある場合は選択した点だけに作用します。ホバー中は、押したときに動く点が赤い円で示され、円が大きいほど影響が強くなります。
3. {key:BRUSH_ADJUST_DRAG} のドラッグでその場で半径または硬さを調整できます。{key:BRUSH_RADIUS_DOWN} / {key:BRUSH_RADIUS_UP} で半径を、{key:BRUSH_HARDNESS_DOWN} / {key:BRUSH_HARDNESS_UP} で硬さを調整することもできます。{key:CANCEL} で現在のストロークをキャンセルします。
{tutorial=DEFORM_MODE}
## 設定
| 設定 | 働き |
|---|---|
| 先端 | 円形、直線、矩形。{key:BRUSH_SHAPE_CYCLE} で順に切り替え |
| 半径 / 硬さ / 強度 | 作用範囲、縁のやわらかさ、1 回の押し出しの強さ |
| 減衰 | スムーズ、球状、ルート、逆二乗、シャープ、リニア、一定、ランダム |
| 接続のみ | ポインター下のメッシュとつながった点だけに影響する |
先端は左ツールバーのブラシの下で選び、そのほかの設定は左下のツールオプションバーとキャンバスの右クリックメニューにあります。
*> 「接続のみ」は、隣り合う髪束や上下の唇のように近接した部品を分けて塗るのに向いています。
{tutorial=TOOL_DETAILS}

@@ blend-shape | ブレンドシェイプ
ブレンドシェイプのパラメータは、ほかのパラメータのキーと掛け合わせるのではなく、オブジェクトの既存のキーフォームに形の差分を加算します。複数のパラメータがそれぞれ独立して作用する場合、ブレンドシェイプを使うとキーフォームの数を大幅に減らせます。ボーンとシミュレーションが書き出しサイズを抑えられるのも、これのおかげです。
## ブレンドシェイプのパラメータを新規作成する
1. パラメータパネルでパラメータを新規作成し、「パラメータ設定」で「ブレンドシェイプ」を選びます（種類は新規作成時にしか選べず、デフォルトの範囲は 0…1 です）。
2. パラメータパネルでは、ブレンドシェイプのキーは四角で表示されます。0 は中立の基本形で、移動や削除はできません。
3. パラメータをほかのキーに合わせ、変形モードでメッシュまたはデフォーマを変更すると、加算する形が記録されます。
ボーンとシミュレーションはブレンドシェイプのパラメータ（ボーンのパラメータ、シミュレーションのモードパラメータ）を自動生成します。[[skeleton]]、[[simulation]] を参照してください。
!> ブレンドシェイプの編集フローはまだ整備中です。Cubism の重みの制限設定と制限カーブはまだ提供されておらず、既存のパラメータをブレンドシェイプに変更することもできません。
## 書き出し
メッシュとワープデフォーマのブレンドシェイプには、書き出し先が Cubism 4.2 以上である必要があります。回転デフォーマとパーツのブレンドシェイプには 5.0 以上が必要です。ターゲットバージョンが対応していない場合、書き出しはダウングレードされ、レポートに記載されます。

@@ multiply-color-screen-color | 乗算色・スクリーン色
パーツを別のレイヤーを描き足さずに染めたり、暗くしたり、明るくしたりできます。乗算色はオブジェクトを暗くしたり色を付けたりし、スクリーン色（Cubism のスクリーン）はオブジェクトを明るくします。頬染め、影、ハイライトに向いています。
## 設定方法

!> インスペクタで設定するのはオブジェクトの固定色で、パラメータに応じて変わりません。Cubism のようにキーごとに異なる色を設定する方法は、画面ではまだ提供されていません。

@@ animation | アニメーション
@@ animation-preparation | アニメーション作成のための準備
モデルを生成すると、待機、まばたき、頷き、首振りはすでにできます。ほかの動きをさせたいときは、同じプロジェクトの中で直接作ります。モーションはプロジェクトに保存され、元に戻す／やり直す、保存と一緒に扱われ、書き出し時に自動で `motion3.json` になります。
## モーションの入手元
- **組み込みモーション**：モデルの生成時にモデルプリセットに従って自動で作られます。いくつかのスライダーを調整するだけです。[[builtin-motions]] を参照してください。
- **カスタムモーション**：「アニメーション」パネルで **新規モーション** を押し、**空のモーション** を選んでゼロから始めるか、**プリセットから複製** を選んで組み込みモーションをもとに変更します。
## 作り始める
1. ワークスペースのタブバー右側の **+** を押して **アニメーション** プリセットを選びます。モーション一覧がプレビューキャンバスの左に、アニメーションエディターがその下に、パラメータパネルが右側に配置されます。
2. 「アニメーション」パネルでモーション行の編集ボタンをクリックするか、右クリックで **編集** を選ぶと、モーションがアニメーションエディターで開きます。
3. パラメータパネルでポーズを付け、アニメーションエディターでキーフレームとして記録します。やり方は [[timeline-basic-operation-timelinepalette]] を参照してください。
{tutorial=ANIMATION}
*> Cubism の Animator に慣れている場合：ここにはシーンやモデルトラックはなく、開いたモーションが現在のモデルのパラメータを直接動かします。CMO3 を書き出すとモーションは同名の `.can3` に別途保存され、Animator で編集を続けられます。
@@ builtin-motions | 組み込みモーション
組み込みモーションは、生成したばかりのモデルをすぐ動かすためのものです。待機やまばたきなどのよく使うモーションをプログラムがモデルに合わせて作るので、キーフレームを 1 つも打つ必要がなく、書き出し時には手作業で作ったモーションと同じく `motion3.json` になります。
## モーション一覧
| グループ | モーション | 説明 |
|---|---|---|
| 基本モーション | 待機モーション、瞬き、頷き、首振り | どのモデルでも再生できる。待機モーションはループ |
| ボーンモーション | しっぽ振り、しゃがみ、重心移動、照れ、手を振る、首かしげ、喜び、片足上げ、ゆらゆら、かわいい待機 | スケルトンが必要。現在のスケルトンで再生できないモーションは表示されない。かわいい待機はループ |
2 つのグループを生成するかどうかは、モデルプリセットの「モーション (Motions)」グループにある **基本モーション**、**ボーンモーション** のチェックボックスで決まります。[[model-presets]] を参照してください。スケルトンの作り方は [[skeleton]] を参照してください。
## 調整
1. 「アニメーション」パネルの **組み込みモーション** フォルダで、各行の左のチェックボックスをオン／オフにして、そのモーションを書き出すかどうかを決めます。
2. モーション行をクリックすると調整項目が展開されます。待機モーションには **揺れ**、**呼吸**、**頭**、**速度** と **まばたき** のスイッチがあり、瞬きには **閉じ具合**、**速度** と **二回まばたき**、頷きと首振りには **振幅**、**速度**、**回数** があります。
3. 行の右側の再生ボタンで、そのモーションをプレビューキャンバスで再生して確認します。
{tutorial=ANIMATION}
## 手動でキーフレームを変更したあと
アニメーションエディターで組み込みモーションのキーフレームを変更すると、行に **変更済み** と表示され、調整項目はデフォルトに戻すまで使えなくなります。右クリックメニューでは次の操作ができます：
- **カスタムモーションとして複製**：現在の内容を新しいカスタムモーションとして保存します。元の組み込みモーションは変わりません。
- **デフォルトに戻す**：手動の変更を破棄し、調整項目から生成した結果に戻します。
- **削除**：書き出されなくなります。あとから **新規モーション** メニューの **削除したプリセットを復元** で戻せます。
!> 物理演算で動くパラメータは、モーションと物理演算が同じパラメータを奪い合わないよう、待機モーションには書き込まれません。
@@ loading-model-and-placement | モデルの読み込みと配置
@@ eye-blink-settings | まばたき設定
自動まばたきを別に設定する必要はありません。組み込みのまばたきモーションがエディターと書き出しでのまばたきアニメーションを担当し、書き出し時には `model3.json` に `EyeBlink` グループも書き込まれるため、SDK の自動まばたきはこれに基づいて動作します。
## 設定方法
1. モデルプリセットの「モーション (Motions)」グループで **基本モーション** にチェックが入っていることを確認します。
2. 「アニメーション」パネルで **瞬き** にチェックを入れます。その行をクリックして展開すると **閉じ具合** と **速度** を調整でき、**二回まばたき** にチェックを入れると 2 回続けてまばたきします。
3. 待機モーションにはまばたきが含まれています。不要な場合は、待機モーションの調整項目で **まばたき** をオフにします。
基本モーションと瞬きがどちらも有効で、メッシュのみの書き出しでない場合、`EyeBlink` グループには `ParamEyeLOpen` と `ParamEyeROpen` が含まれます。
*> Cubism ユーザーは Viewer や Animator のまばたきエフェクトで間隔を設定しますが、ここにはその設定はなく、まばたきのリズムは瞬きのモーション自体で決まります。

@@ timeline-basic-operation-timelinepalette | タイムラインパレットの表示と操作
アニメーションエディターはモーションを作る場所です。パラメータごとに 1 本のトラックがあり、再生ヘッドを動かし、ポーズを付け、キーフレームを打ち、ドープシートやカーブで細かく調整します。
## 開く
**ウィンドウ** メニューから「アニメーションエディター」を開くか、「アニメーション」ワークスペースのプリセットを使います。「アニメーション」パネルでモーションを編集するか、エディターのツールバーの **モーションを選択…** で選びます。
## モーションを作る
1. **トラック** を押し、動かしたいパラメータを検索して追加します。トラック行には再生ヘッドの位置の値が表示され、**再生ヘッドにキーを追加** とトラックを削除するボタンがあります。
2. ルーラーをクリックまたはドラッグして再生ヘッドを目的の時間に動かし、パラメータパネルでポーズを付けます。
3. {key:MOTION_KEY_POSE}（**ポーズをキー**）で、すべてのトラックの現在の値を再生ヘッドの位置に記録します。または **自動キー**（{key:MOTION_TOGGLE_AUTO_KEY}）をオンにすると、以降はパラメータを変えるだけで自動でキーが打たれ、トラックのないパラメータも自動で追加されます。
4. {key:MOTION_PLAY_PAUSE} で再生して確認します。キャンバスに結果がリアルタイムで表示されます。
{tutorial=ANIMATION}

| ドープシート / カーブ | [[timeline-basic-operation-dopesheet]] と [[grapheditor]] を切り替える |
| シャイを隠す / ブックマーク | [[timeline-basic-operation-shy]]、[[parameter-bookmark]] を参照 |

@@ timeline-basic-operation-dopesheet | ドープシートの基本操作
ドープシートは各トラックのキーフレームを 1 行の点として並べるので、タイミングを組むのに最適です。リズムを動かしたり、動きの一部をコピーしたり、補間をまとめて変えたりできます。アニメーションエディターのツールバーで **ドープシート** を押すとここに切り替わります。
| 操作 | 方法 |
|---|---|
| キーフレームを追加 | トラックの空いている所をダブルクリック |
| 選択 | クリック。{kbd:Shift} で追加、{kbd:Ctrl} で切り替え。空いている所をドラッグして矩形選択。{key:MOTION_SELECT_ALL} ですべて選択 |
| 移動 | 選択したキーフレームをドラッグ（**フレームにスナップ** がオンのときはフレーム単位でそろう） |
| コピー / 貼り付け | {key:MOTION_COPY_KEYS} / {key:MOTION_PASTE_KEYS} |
| 削除 | {key:MOTION_DELETE_KEYS}、または下部の **キーを削除** |
キーフレームを選択すると、下部に **n 個のキーを選択中** と表示され、**時間** と **値** を直接入力でき、補間をまとめて設定できます。連続したドラッグや入力は 1 つの履歴として記録されます。
@@ parameter-bookmark | パラメータブックマーク
パラメータが増えたら、よく使うものをブックマークします。アニメーションエディタでそのトラックだけを表示でき、トラックを追加するときも先頭に並びます。
## 操作
| 操作 | 方法 |
|---|---|
| ブックマーク / 解除 | トラック行のブックマークボタン、またはトラック行をクリックして {key:MOTION_TOGGLE_BOOKMARK} |
| ブックマークのみ | ツールバーの **ブックマーク**：ブックマークしたパラメータのトラックだけを表示 |
| トラックを追加 | **トラック** メニューではブックマークしたパラメータが ★ 付きで先頭に並びます。**ブックマークのトラックを追加** でトラックのないブックマークをまとめて追加 |
ブックマークはプロジェクト全体のもので、すべてのモーションで共通です。プロジェクトと一緒に保存されますが、モデルのデータではないので履歴には入らず、書き出されません。
*> Cubism と違い、ブックマークは 1 組だけです。パラメータはブックマークされているか、いないかのどちらかです。
@@ timeline-basic-operation-shy | シャイ機能
いま見なくてよいトラックを「シャイ」にして **シャイを隠す** をオンにすると、タイムラインには編集中のトラックだけが残ります。シャイのトラックもそのまま再生され、書き出されます。
## 操作
1. トラック行のシャイボタン（伏せた目）を押すか、トラック行をクリックして {key:MOTION_TOGGLE_SHY} を押します。
2. ツールバーの **シャイを隠す**（{key:MOTION_HIDE_SHY}）で隠す / 表示を切り替えます。トラック一覧の見出しに隠れている数が出ます。
シャイはモーションごとに記録され、プロジェクトと一緒に保存されます。履歴には入りません。
@@ freeze | フリーズ機能
フリーズすると、再生中や再生ヘッドを動かしている間もトラックが一定の値に保たれます。ほかのパラメータの動きだけを確かめたいとき、たとえばまばたきを止めて頭の回転を見るときに使います。
## 操作
1. 欲しい値になる時間に再生ヘッドを動かします。
2. トラック行のフリーズボタン（雪の結晶）を押すか、トラック行をクリックして {key:MOTION_TOGGLE_FREEZE} を押します。再生ヘッドの値でフリーズし、行にその値が表示され、ドープシートではトラックに斜線が、カーブではフリーズ値の破線が引かれます。
3. もう一度押すと解除します。
フリーズ中はそのトラックのキーを選択・ドラッグ・打つことができず、オートキーも飛ばします。キー自体と書き出されるモーションは変わりません。フリーズはモーションごとに記録され、プロジェクトと一緒に保存されます。履歴には入りません。
*> フリーズはアニメーションエディタで開いているモーションに効きます。MCP からのキー編集は止めません。
@@ timeline-basic-operation-repeat | パラメータリピートのアニメーション
[[repeat]] を設定したパラメータでは、モーションのキーの値を範囲の外に打てます。回り続ける動きに使います。たとえば範囲 0–360 の車輪に 0 秒で 0、1 秒で 720 を打てば、1 秒に 2 回転します。
- キーは範囲を最大 64 周まで超えられます。カーブでは 1 周ごとに破線が引かれます。
- プレビューは値を範囲内に戻して表示し、書き出した `motion3.json` は打った値のままで、ランタイムが範囲内に戻します。
- タイムラインでキーを打つと（自動キーも）、カーブの値に最も近い周の値が書き込まれ、540 がプレビュー表示の 180 になることはありません。
- ループするモーションを [[loop-editing-support]] でつなぐと、このようなパラメータの終わりは回転の向きに次の整数周へそろい（0→170 なら 360）、回転が逆戻りしません。64 周を超える場合はエラーになり、何も変えません。
!> パラメータのリピートを外したり範囲を狭めたりすると、範囲を超えたキーは両端に切り詰められます。
@@ grapheditor | グラフエディタ
カーブビューはトラックを時間に対する値のカーブとして表示し、イージングやオーバーシュートの調整に使います。ドープシートと同じ領域、同じ選択とショートカットを共有しており、アニメーションエディターのツールバーで **カーブ** を押して切り替えます。
## 操作
1. 左側のトラック行をクリックすると、そのカーブだけが表示されます。**すべて表示** を押すと、すべてのカーブの表示に戻ります。
2. キーフレームをドラッグすると時間と値が同時に変わります。カーブを 1 本だけ表示しているときは、空いている所をダブルクリックするとその位置にキーフレームが追加されます。
3. ベジェ区間のキーフレームの両側にはハンドルがあり、ドラッグして加速と減速を調整します。下部の **ハンドルをリセット** でデフォルトの形に戻します。
4. {kbd:Ctrl+Wheel} で時間を、{kbd:Ctrl+Shift+Wheel} で値を拡大縮小し、{kbd:Wheel} で上下にスクロールします。
## 補間
| 補間 | 効果 |
|---|---|
| リニア | 2 つのキーの間を等速で変化する |
| イージング (ベジェ) | デフォルト。ハンドルで加速と減速を制御する |
| ステップ | 前のキーの値を保ち、次のキーで切り替わる |
| 逆ステップ | すぐに次のキーの値に切り替わって保つ |
*> ハンドルの時間はその区間内に制限されており（`motion3.json` の `AreBeziersRestricted` と一致）、書き出し後もカーブの形は変わりません。
@@ marker | マーカー機能
マーカーはタイムライン上の名前と色の付いた時間で、拍やセリフ、ほかの動きとタイミングを合わせるのに使います。
## 操作
| 操作 | 方法 |
|---|---|
| 追加 | ツールバーのマーカーボタンか {key:MOTION_ADD_MARKER} で再生ヘッドに追加（**フレームにスナップ** がオンならフレームにそろう） |
| 移動 | ルーラーの旗をドラッグ |
| 編集 | 旗をクリック：再生ヘッドがそこへ移り、ラベル・時間・色と **マーカーを削除** が開きます |
| ジャンプ | {key:MOTION_PREV_MARKER} / {key:MOTION_NEXT_MARKER} で前 / 次のマーカーへ |
マーカーはモーションごとに記録され、プロジェクトと一緒に保存されます。履歴には入らず、書き出されません。`motion3.json` のイベントではありません（ユーザーデータは [[userdata]]）。
@@ locus-of-tracks | トラックの軌道
軌跡は、選択したオブジェクトがモーションの中で通る道筋をプレビューキャンバスに描きます。フレームごとに点を打ち、再生ヘッドのフレームを輪で示すので、動きの弧がなめらかか確かめられます。
## 使い方
1. アニメーションエディタでモーションを開き、ツールバーの **軌跡** をオンにします。
2. レイヤーを 1 つ以上（メッシュの中心をたどります）、またはデフォーマを 1 つ（回転デフォーマは回転の中心、ワープデフォーマは中央）選択します。
3. プレビューキャンバスで確認します。キーを変えたり再生ヘッドを動かしたりすると軌跡も追従します。
軌跡はモーションのキーから求め、フリーズしたトラックはフリーズ値のままです。物理演算とマウス追従は含みません。

@@ about-fade | フェードについて
フェードは、ランタイムでモーションを切り替えるときの滑らかさを決めます。新しいモーションはフェードイン時間のうちに徐々に効き始め、古いモーションはフェードアウト時間のうちに徐々に消えるため、ポーズが急に変わりません。
- カスタムモーションには **フェードイン (秒)** と **フェードアウト (秒)** があり、デフォルトはどちらも 1 秒で、`motion3.json` の `FadeInTime` / `FadeOutTime` に書き出されます。
- 手動で変更していない組み込みモーションにはフェード時間を書き込まず、ランタイムのデフォルト値が使われます。
フェードはアプリでモーションを切り替えるときにだけ効きます。エディターで 1 つのモーションだけを再生しても違いは見えません。設定方法は [[fade-setting]] を参照してください。
@@ fade-setting | フェード値の設定
フェードは「アニメーション」パネルでモーションごとに設定します。
1. 「アニメーション」パネルの **カスタムモーション** フォルダで、モーション行をクリックして設定を展開します。
2. **フェードイン (秒)** と **フェードアウト (秒)** に 0–5 秒の値を入力します。
3. 書き出し後、そのモーションの `motion3.json` に書き込まれます。

@@ physics-operation | 物理演算について
物理演算は、髪、アクセサリー、衣服が頭や体の動きに合わせて慣性で揺れるようにします。PSD2Live は Cubism と同じ振り子モデルを使い、計算は Cubism Native Framework と項目ごとに対応しているので、エディターで見る揺れは SDK での揺れと同じです。
## 仕組み
- **入力**：頭や体の角度などのパラメータが、振り子の根元を押したり（位置X）、重力の向きを傾けたり（角度）します。
- **振り子**：根元から垂れ下がる振り子の連なりで、長さ、揺れやすさ、反応速度、収束の速さに従って動きます。
- **出力**：ある振り子の振れ角に倍率を掛けて、出力パラメータに書き込みます。
物理演算はパラメータの値を変えるだけで、揺れの形は出力パラメータのキーフォームから来ます。出力パラメータの端点の形が作られていないと、パラメータは動いてもモデルは動きません。
## 物理グループの由来
大部分の物理グループは手動で作る必要がありません。前髪、後ろ髪、瞳のゼリーはモデルプリセットから、ボーン、揺れ、シミュレーションのベイクもそれぞれのグループを生成し、手動で新規作成することもできます。管理方法は [[physics-group-information]] を参照してください。
@@ physical-operation-setting | 物理演算の設定方法
「物理演算」パネルで物理グループを 1 つ選択すると、その下に振り子キャンバス、応答カーブ、振り子の設定、入力、出力、詳細設定が順に並びます。最も手早い調整方法は振り子キャンバスで直接ドラッグし、応答カーブと最大出力で効果を判断することです。
## 振り子キャンバス
| 操作 | 働き |
|---|---|
| 空いている所を左右にドラッグ | モデルを引っ張る。離すと元の位置に戻る |
| 振り子の末端のリングを上下にドラッグ | その振り子の長さを調整する。クリックで選択 |
| 右側の出力ラベルをある振り子の横までドラッグ | その振り子の角度を読み取るように変更する（振り子番号） |
| 出力ラベルをクリック | 範囲の扇形を表示し、扇形の縁をドラッグして倍率を調整する |
振り子の下の応答カーブは、右へ 1 秒引っ張ってから離したときの反応を示し、設定ごとのオーバーシュートと収束をそのまま比較できます。

## 設定項目
1. **プリセット**：プリセットを 1 つ選んで **読込** を押すと、すべての振り子が置き換わります。**追加…** で現在の振り子を自分のプリセットとして保存します。
2. **編集する振り子**：**すべて** またはある番号を選び、下のスライダーでどの振り子を調整するかを決めます。振り子の追加、削除、上下の移動ができます。
3. スライダー：**全長 / 長さ**、**揺れやすさ**、**反応速度**、**収束の速さ**。Cubism Editor と名前も意味も同じです。
4. **入力**：**追加** でパラメータを加え、**位置X** または **角度** を選び、**影響度** と反転を設定します。
5. **出力**：**振り子番号**、**倍率**、反転を設定します。**最大出力** は出力がパラメータの端点に達した割合を示し、**最大値で倍率を調整** で 100% に合わせます。
6. **詳細**：振り子の設定表、出力の詳細、**入力の正規化**。
ドラッグや入力のたびに、手を離した時点で 1 つの履歴として記録されます。
*> 出力は角度タイプのみです。位置X タイプの出力は Cubism ランタイムでは常に 0 になります。
@@ physics-group-information | 物理演算グループ編集
「物理演算」パネル上部の一覧に、モデルのすべての物理グループが表示されます。ジェネレーターが作ったグループは由来に合わせて自動で更新され、自分で変更した箇所は保持されます。
## 物理グループ一覧
- 計算順に並び、番号が付いています。チェックボックスでグループを有効／無効にし、無効なグループは書き出されません。
- 各行には由来（プリセット、ボーン、揺れ、シミュレーション、カスタムなど）と状態が表示されます：**編集済み**、**無効**（パラメータが存在しない、入力や出力がないなど）、**置換済み**（同じ出力パラメータがすでにほかのグループで動かされていて、このグループは書き出されない）。
- タイトルバーの上へ / 下へで計算順を調整します。あるグループがほかのグループの出力を読み取る場合、読み取られる側のグループを前に置きます。
## 新規作成
**新規** を押します：
- **空の振り子**：デフォルトで頭と体の揺れを入力とし、出力はまだありません。
- **新しいグループとして複製**：選択したグループを複製し、出力パラメータは空になります。
- **physics3.json を読み込む…**：ファイル内の各グループがカスタムグループになります。ID が同じグループは置き換えられます。
- **選択対象に揺れを作成…**：キャンバスで選択したメッシュまたはワープデフォーマに揺れを作成します。[[auto-generation-of-sway-motion]] を参照してください。
## 生成されたグループの変更
生成されたグループは直接編集でき、編集すると **編集済み** と表示され、その後由来が変わっても自分の変更は上書きされません。**その他** メニューの **生成値に戻す** で生成されたバージョンに戻ります。カスタムグループは **名前を変更**、**削除** できます。

@@ simulation | 布と髪のシミュレーション
スカートの裾、上着の裾、長い髪は、数本の振り子では布らしさが出にくいものです。シミュレーションは、エディター内でメッシュに対して本物の 2D の布と髪のシミュレーションを行い、その結果を Cubism で再生できるパラメータ、キーフォーム、振り子に**ベイク**します。書き出したモデルはどの Cubism ランタイムでも動きます。
## まずモデルプリセットを使う
モデルプリセットの「物理・シミュレーション (Physics & Simulation)」グループで、よく使う部品のシミュレーションを一度に生成できます。前髪、後ろ髪のドロップダウンを **シミュレーション** にするか、**衣装** にチェックを入れると、プログラムが物理ボディを作り、ウェイトを書き込み、バックグラウンドでベイクします。あとから対象メッシュのシミュレーションのカード（モディファイアパネル）で調整を続けられます。[[model-presets]] を参照してください。

## 物理ボディを手動で作る
1. キャンバスでスカートや髪のメッシュを選択し、モディファイアパネルの **追加** メニューで **シミュレーション · 布** または **シミュレーション · 髪** を選びます。1 つの物理ボディ内の複数のメッシュは一緒にシミュレーションされ、それらのメッシュのスタックにシミュレーションのカードとして加わります。
2. 固定点を指定します。キャンバスの「シミュレーション」モード（{key:MODE_SIMULATE}）に切り替え、**ウェイトペイント** または **ウェイトグラデーション** で固定点を描きます。腰とつながったグルーは **接着** の節で **固定点にする** に設定することもできます。[[glue]] を参照してください。
3. カードの **比較** の節で **参照シミュレーション** をオンにし、首を振ったり体を揺らしたりしながら、**材質** の節でプリセットを替えたり数値を微調整したりして、自然に揺れるまで調整します。
4. カードの **焼き込み** の節の **焼き込み** か、**ワールド** ページの **シミュレーション** の節の **すべて焼き込む** を押します。ベイクはバックグラウンドで行われ、通常は数秒かかり、完了すると 1 ステップの元に戻せる操作としてコミットされます。
5. **参照シミュレーション** をオフにして **書き出し結果** に戻します。キャンバスで再生されるのは書き出しモデルの動きなので、参照シミュレーションと見比べられます。
## 頂点ウェイトグループ
ウェイトグループは、シミュレーションにどこを固定し、どこをより硬く、または重くするかを伝えます。このソフト内にだけ存在し、書き出しファイルには書き込まれません。
| 種類 | 働き |
|---|---|
| 固定点 | リグに引き留められる頂点。1 で完全にバインドに追従し、0 で完全にシミュレーションに任せる |
| 剛性 | 伸びと曲げの剛性を頂点ごとに拡大縮小し、根元は硬く、裾は柔らかくする |
| 形状保持 | 原画の形へ戻る力を頂点ごとに拡大縮小し、外に広がるスカートの裾や跳ね上がった毛先を支える |
| 質量 | 質量を頂点ごとに拡大縮小する。重いほど遅れとオーバーシュートが目立つ |
| 減衰 | 動きの減衰を頂点ごとに拡大縮小し、角や縁の震えを抑える |
## 材質、入力、ベイク
- **材質**：布は綿、シルク、シフォン、ウール、デニム、革、伸縮素材、髪は髪、細く柔らかい髪、太く硬い髪が選べ、選んだあとも各項目を微調整できます。
- **入力**：物体を揺らすパラメータです。新規作成時に頭や体の角度などが自動で入ります。リストが空だとベイクできません。
- **焼き込み**：**モード数**（1–3、デフォルト 2）は生成するパラメータの数、**キー数** は各パラメータのキーフォームの数を決め、**誇張** は揺れを拡大し、再ベイクは不要です。ベイク後は R² と誤差が表示されます。
- ベイクされた振り子は由来が「シミュレーション」として「物理演算」パネルに、パラメータは `ParamSim…` という名前でパラメータパネルに現れます。
!> 設定、メッシュ、ウェイト、またはスタックでそれより前にあるものを変更するとベイクは **古い** と表示され、再ベイクするまで書き出しには古い結果が使われます。参照シミュレーション自体は書き出されません。

@@ external-application-integration | 外部アプリケーション連携
PSD2Live にはローカルの MCP サービスが内蔵されています。有効にすると、Claude Code や Codex などの AI ホストや自作のスクリプトが、現在のプロジェクトを読み取り、編集できます。読み込み、リグの変更、物理演算の調整、モーションの作成、保存、書き出しまで、画面での操作と同じコマンドを通るため、同じく履歴に入り、元に戻せます。
## 有効化と接続
1. **設定**（{key:OPEN_SETTINGS}）の **MCP** を開きます。
2. 「サービス」で **MCP サービスを有効にする** にチェックを入れ、**ポート**（デフォルト 23871）、**アクセストークン**（**再生成** 可能）、**ツールセット** を設定して、**適用して再起動** を押します。
3. 「ホストを接続」で、ホストごとのコマンドや設定をコピーします。**セットアップ用プロンプトをコピー** を押して、そのプロンプトをホストに渡し、自分で設定させることもできます。
4. ホストが接続したら、まず `workspace_inspect` を呼び出して現在のプロジェクトのオブジェクト ID と状態を読み取ります。
## ツールセット
| ツールセット | 向いている用途 |
|---|---|
| コンパクト（推奨） | ほとんどのホスト。同系統の操作を 1 つのツールにまとめ、残りは `workspace_call` 経由で呼び出す。スキーマが簡潔で、バックグラウンドジョブは結果を直接返せる |
| フル | ツールをオンデマンドで読み込むホスト。操作ごとに 1 つのツールで、完全なスキーマ付き |
どちらのツールセットでもすべての操作を呼び出せ、実行と検証はまったく同じです。
## 注意事項
- サービスはこのマシン上でのみ動作し、Streamable HTTP と Bearer トークン認証を使います。トークンで現在のワークスペースを編集できるため、ローカルのホスト設定にだけ保存してください。ポートやトークンを変更したら、接続済みのホストの設定も合わせて更新します。
- Stdio にしか対応していないホストでは、Python 3 でリポジトリのルートにある `mcp_proxy.py` を実行して中継します。
- ウィンドウを開かないときは、コマンドラインの `mcp` サブコマンドで MCP エンドポイントだけを起動できます。
@@ external-application-integration-api | Live2D Cubism Editor 外部連携 API
スクリプトを書くときやホストの呼び出しを調べるときは、MCP 操作の呼び出しの約束事を知っておく必要があります。各操作には厳密なリクエストと結果のスキーマがあり、`workspace_list_operations` で一覧表示、`workspace_get_operation` でフィールドを確認できます。
## 呼び出しの約束事
- パラメータは `{"request": {...}}` の中に置きます。
- 変更操作には `state`（`workspace_inspect` または前回の結果から取得）が必要です。`state` が現在のプロジェクトと一致しない場合は競合が報告されるので、読み直してから再試行します。
- フルのツールセットではさらに `project_id` と一意の `request_id` が必要です。コンパクトのツールセットでは省略でき、`request_id` はパラメータから導出されるため、同じ呼び出しを再試行すると元の結果が返ります。
- 時間のかかる操作はバックグラウンドジョブを返すので、`job_wait` / `job_get` で結果を取得します。コンパクトのツールセットの `wait_ms` を使うと、制限時間内であれば結果を直接返せます。
- `workspace_apply_edits` は 1–128 件の編集を 1 つのアトミックな一括操作としてコミットし、すべて成功したときだけ履歴ノードを 1 つ追加します。`workspace_preview_edits` は試行のみで、プロジェクトは変更しません。
主なツールの用途別グループは [[external-application-integration-api-list]] を参照してください。

@@ pose-setting | ポーズの設定
ポーズは、パーツのグループのうち同時に 1 つだけを表示します。たとえば腕 A と腕 B、2 種類の衣装などです。SDK は書き出された `pose3.json` を読み込みます。読み込み時は各グループの最初のパーツを表示し、切り替え時は設定した時間で新しいパーツをフェードインし、古いパーツをフェードアウトします。
## ポーズグループを設定する
1. アニメーションパネルを開き、**ポーズ** セクションを展開します。
2. **グループを作成** を押し、そのグループの最初のパーツを選びます。グループの最初のパーツには **最初に表示** と表示されます。
3. グループを展開し、**パーツを追加** で同じグループのほかのパーツを加えます。1 つのパーツは、すべてのグループを通して 1 回しか使えません。
4. 別のパーツと一緒に表示・非表示にしたいパーツ（たとえば腕 A の手）は、その行の **リンク** を押して選びます。もう一度押すとリンクを解除します。
5. セクションの下部で **切り替えフェード (秒)** を設定します（秒、デフォルト 0.5）。
変更のたびに 1 件の履歴として記録され、元に戻せ、プロジェクトと一緒に保存されます。パーツが削除されると、グループではそれが **（存在しません）** と表示され、書き出しでは無視されます。
## Cubism との違い
- エディター内で設定でき、別の Viewer を開く必要も、`pose3.json` を別に保存する必要もありません。
- 編集キャンバスとプレビューにはポーズは適用されません。すべてのパーツがそれぞれの不透明度でそのまま表示され、ポーズは SDK がモデルを読み込むときだけ効きます。
- moc3 の書き出しで `<名前>.pose3.json` を書き出し、`model3.json` の `Pose` から参照します。グループがないときは書き出しません。
@@ facial-expression-system | 表情の仕組み
表情はパラメータ値の集まりで、ホストがモーションの上に重ねて使います。たとえば待機モーションを再生したまま「笑顔」に切り替えます。SDK は書き出された `exp3.json` を読み込み、各パラメータをブレンド方式に従ってモーションの値と合成します。
| ブレンド方式 | 結果 |
|---|---|
| 加算（Add） | モーションの値 + 表情の値 |
| 乗算（Multiply） | モーションの値 × 表情の値 |
| 上書き（Overwrite） | 表情の値。モーションは無視 |
表情を切り替えると、新しい表情はフェードイン時間をかけて現れ、古い表情はフェードアウト時間をかけて消えるので、気分ごとに別のモーションを作る必要はありません。
## 標準の表情
生成されたモデルには 4 つの標準の表情（笑顔、悲しみ、怒り、驚き。名前は UI の言語に従います）が付属します。モデルにある口の形、目の開閉、眉のパラメータで構成され、足りないパラメータは自動的に省かれます。読み込んだ CMO3 モデルには標準の表情は付きません。表情リストを最初に変更したとき（作成、削除、どれかの編集）、標準の表情は通常の表情としてプロジェクトに取り込まれ、以後はプロジェクト内の表情だけが書き出されます。表情の右クリックメニューで **標準の表情に戻す** を選ぶと、自動生成された一式に戻せます。
## パラメータの削除や範囲変更があったとき
パラメータを削除すると、表情内のそのパラメータの項目も一緒に削除されます。パラメータの範囲を狭めると、上書き方式の値は新しい範囲に収められます。
@@ create-facial-expressions | アニメーションビューで表情を作成
表情はパラメータの状態から直接作ります。パラメータパネルやキャンバスで顔を思いどおりにしてから、表情として保存します。
## 現在のパラメータから作成
1. パラメータパネルで表情（目、眉、口など）を整えます。プレビューでモーションを再生中は、パネルに現在表示されている値が使われます。
2. アニメーションパネルのツールバーで **+** を押し、**現在のパラメータから表情を作成** を選びます。
3. デフォルト値と異なるパラメータは、デフォルト値との差を値とする加算の項目になります。Cubism のアニメーションビューで表情を作る出発点と同じです。
## そのほかの作成方法
- **スナップショットから表情を作成**：パラメータパネルのスナップショットバーに保存したパラメータスナップショットの値を使い、表情名にはスナップショット名が使われます。
- **空の表情を作成**：パラメータのない表情です。ホストが「表情なし」にリセットする先として使えます。
- 既存の表情を右クリックして **現在のパラメータで更新** を選ぶと、現在のパラメータからすべての項目を作り直します。
## プレビュー
表情行の右側の目のアイコンを押す（または右クリックして **パラメータに適用してプレビュー** を選ぶ）と、表情がブレンド方式に従って現在のパラメータに適用され、キャンバスとプレビューで効果を直接確認できます。これはプレビューのパラメータだけを変え、履歴には入りません。
@@ setting-and-exporting-facial-expressions | 表情の設定と書き出し
各表情の項目、ブレンド方式、フェードは、アニメーションパネルの **表情** セクションで設定し、書き出し時に自動的に書き込まれます。
## 設定
1. 表情の行を押して設定を展開します。
2. **フェードイン時間**、**フェードアウト時間**：この表情に切り替えるとき、およびこの表情から離れるときにかける秒数（デフォルト 0.5）。
3. 項目は 1 行ずつです。パラメータ名、ブレンド方式のボタン（加算 / 乗算 / 上書き）、値、削除。値を変えずにブレンド方式だけを変えると、パラメータのデフォルト値で同じ結果になるように値が換算されます。
4. **パラメータを追加** で、まだ設定していないパラメータを加えます。
5. 右クリックメニューで名前の変更、複製、**上へ** / **下へ**、削除ができます。表情の順序が `model3.json` での順序になります。
変更のたびに 1 件の履歴として記録され、元に戻せ、プロジェクトと一緒に保存されます。
## 書き出し
- moc3 の書き出しでは、各表情が `<名前>.<表情 ID>.exp3.json`（`Type`、`FadeInTime`、`FadeOutTime`、`Parameters`）として書き出され、`model3.json` の `Expressions` から名前で参照されます。モデルにもう存在しないパラメータは無視され、項目のない表情もそのまま書き出されます。
- VTube Studio 用のパッケージには、表情ごとにその表情を切り替えるホットキーが追加されます。
- PSD2Live ランタイムモデル（`.p2lrt`）と Web プレーヤーにも表情が含まれます。
- `.cmo3` / `.can3` には表情は保存されず、書き出しレポートにその旨が記されます。SDK で使うには moc3 を書き出してください。
*> メッシュのみの書き出しでは、表情とポーズは書き出されません。
