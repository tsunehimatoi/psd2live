キャラクターにまばたきをさせます。PSD2Live では、まばたきは読み込み時にレイヤーのタグから生成済みです。このレッスンでは、素材を正しくレイヤー分けし、閉じ目の形を確認して、気になる箇所を修正します。
## 素材の準備
- 白目、黒目、上まつ毛はそれぞれ別レイヤーにします。レイヤー名は `eyewhite` / `眼白`、`irides` / `瞳孔`、`eyelash` / `睫毛` などが使えます。
- まつ毛レイヤーには上まつ毛だけを描いてください。下まぶたの線が混ざっていると、目を閉じたときに下まぶたまで一緒に引っ張られます。
- 左右の目は分け、名前に左右を付けます（例：`eyelash-l`、`左睫毛`。左右はキャラクター自身から見た向き）。
- 特定の閉じ目の形が必要な場合は `eye_close` / `闭眼` レイヤーを別に描きます。描かない場合は、まつ毛に沿って閉じ目の曲線が生成されます。
## 生成と確認
1. **ファイル → 新規作成 → PSD から新規プロジェクト…**（{key:OPEN_PSD}）を選び、PSD を指定します。
2. スタート画面の **クイック設定** は **標準** のままにし、生成後に編集ワークスペースへ進みます。
3. **レイヤー** パネルで、目の各レイヤーの **タグ**（部位と左右）を確認し、違っていればタグを開いて修正します。
4. **パラメータ** パネルで **左目 開閉** / **右目 開閉** を動かします。0 が閉じ、1 が開きです。
5. 閉じ目の弧や目尻の位置が合わない場合は、**モディファイア** パネルの **目** コンポーネントカードの **数値** で **閉じ目の弧**、**閉じ目の目尻**、**閉じ目のまつ毛の太さ** を調整します（**左右を分ける** にチェックを入れると左右別々に調整できます）。手動で形を直すよりずっと速く済みます。
{tutorial=BASIC}
## 閉じ目の形を手動で整える
数値で合わせきれないときに手を動かします。修整は生成結果の上に重なり、再生成後も保持されます。
1. 階層ツリーでまつ毛または白目を選択し、開閉パラメータを閉じ目のキーに動かします（キーマークを右クリックするとスナップします）。
2. **変形** モード（{key:MODE_DEFORM}）に切り替え、制御点をドラッグするか、ブラシ（{key:TOOL_BRUSH}）で形を押し動かします。
3. 片側が整ったら、キャンバスの右クリックメニュー **キーフォームをミラー → … へミラー** を選びます。形が反対側の同種オブジェクトに書き込まれ、パラメータも自動でその側の開閉パラメータに置き換わります。
4. **プレビュー**（{key:MODE_PREVIEW}）に切り替え、**待機モーション** をオンにして自動まばたきを確認します。
{tutorial=DEFORM_MODE}
*> MOC3 を書き出すとき、まばたきモーションが有効なモデルでは model3.json に EyeBlink グループが書き込まれ、ランタイムでそのまま自動まばたきできます。そのほかの設定は [[eye-blink-settings]] を参照してください。

@@ t-figure | 図で覚えるLive2D
Live2D にまだ触れたことがない人は、まずモデルが何でできているかを数分で把握しましょう。PSD2Live は PSD を読み込むと、これらの構造をすべて自動で生成します。理解しておくと、階層ツリーやパラメータパネルの内容が読めるようになり、どこから修正すればよいかもわかります。
{path=BEGINNER}
## アートメッシュ：変形する画像
PSD の各レイヤーは、読み込み後にアートメッシュになります。1 枚のテクスチャと、その上に重なる三角形メッシュです。メッシュの頂点を動かすと、テクスチャも一緒に曲がったり伸びたりします。メッシュの粗さや形は **編集** モードで、変形は **変形** モードで行います。
*> アートメッシュは Cubism のアートメッシュ（ArtMesh）にあたります。
## デフォーマ：アートメッシュを包む枠
デフォーマは、アートメッシュや他のデフォーマを中に入れてまとめて動かす枠のようなものです。**ワープデフォーマ** は一組の制御点で中身全体を曲げ（Cubism のワープデフォーマにあたります）、**回転デフォーマ** は中身を 1 点の周りに回転させます。デフォーマは入れ子にでき、親の動きが子に伝わります。頭が回ると目や髪もついてきます。入れ子の関係は **階層ツリー** で確認でき、何が何を隠すかは描画順で別に決まります。
{tutorial=HIERARCHY}
## パラメータとキーフォーム：スライダーで形を変える
パラメータは **角度 X**、**左目 開閉** のようなスライダーです。あるパラメータ値で記録した形がキーフォームで、パラメータ横のマークが「キー」です。スライダーが 2 つのキーの間にあるときは、形が自動で補間されます。2 つのパラメータを 2D で結合すると、四隅の組み合わせのポーズを同時に制御でき、たとえば斜めに首を振れます。
## アニメーションと物理演算：パラメータを動かすだけ
アニメーションは時間に沿ってパラメータの値を変えるものです。物理演算は頭や体などの入力パラメータから揺れを計算し、「髪の揺れ」のようなパラメータへ出力します。どちらも形を直接変えず、パラメータを動かすだけで、形はキーフォームが決めます。
*> PSD2Live にはボーン、変形パス、グルーなどの補助ツールもあり、書き出し時にはすべて上記の標準構造へベイクされます。詳しくは [[concept-of-artmesh]]、[[deformer]]、[[parameter]] を参照してください。

3. 片側ができたら {key:MIRROR_KEYFORM} を押して、現在のキーを対称キーへミラーします（例：角度 X 30 → −30）。親のキーフォームは個別にミラーする必要があります。
4. **プレビュー** で **視線追従** をオンにし、マウスで視線と首振りをぐるりと動かして、中間値を確認します。
{tutorial=DEFORM_MODE}
!> 9 つのポーズは原画の頭の傾きを基準に推定されます。幅の広い髪束や極端な角度では、手動での修形が必要になることがあります。

モデルのモーションを作ります。別にアニメーション用のプロジェクトを開く必要はありません。生成時に待機、まばたき、頷きなどのプリセットモーションが付いており、そのまま調整できます。自分のモーションを作りたいときは、**アニメーションエディター** で作ります。

1. **アニメーション** ワークスペースに切り替え、**アニメーション** パネルを開きます。
2. **組み込みモーション** でモーションを 1 つ選んで再生します。プリセットごとに調整項目があり、たとえば待機には **揺れ**、**呼吸**、**頭**、**速度**、**まばたき** があります。
3. 調整値はプロジェクトと一緒に保存され、プレビューと書き出しの両方に使われます。
## カスタムモーションを作る
1. アニメーションパネルで **新規モーション** を押し、**空のモーション** または **プリセットから複製** を選びます。
2. **アニメーションエディター** で **トラック** を押してパラメータのトラックを追加し、トラックをダブルクリックしてキーフレームを追加します。
3. **自動キー**（{key:MOTION_TOGGLE_AUTO_KEY}）をオンにすると、再生ヘッドの位置でパラメータを動かすかキャンバス上でポーズを付けるだけでキーが打たれます。手動の場合はポーズを付けたあと **ポーズをキー**（{key:MOTION_KEY_POSE}）で書き込みます。
4. **ドープシート** でタイミングを並べ、**カーブ** でイージングを調整します。キーフレームのデフォルトはベジェのイージングです。
5. {key:MOTION_PLAY_PAUSE} で再生して確認します。アニメーションエディターで **ループ** を切り替え、アニメーションパネルでフェードイン・フェードアウト時間を設定します。
{tutorial=ANIMATION}
*> CMO3 を書き出すとモーションは同名の `.can3` に別途保存され、Cubism Animator で編集を続けられます。MOC3 を書き出すと motion3.json になります。

4. **テクスチャ** ワークスペースを開いてテクスチャアトラスのページ数とサイズを確認し、右上でページサイズと最大ページ数を設定します。

@@ t-physical-calculation-settings | 2. 物理演算の設定
髪やアクセサリーが、ランタイムで頭や体に合わせて揺れるようにします。物理グループはレイヤーから自動生成されます。パネルで入力と出力を確認し、キャンバス上で振り子を直接ドラッグして調整できます。
## 物理グループの確認と調整
1. **物理演算** ワークスペースに切り替えて **物理演算** パネルを開きます。**物理グループ** の一覧には、プリセット、ボーン、揺れ、カスタム、シミュレーションなどを由来とするグループが表示されます。
2. グループを 1 つ選択し、**入力**（角度 X、身体の角度 X など）と **出力**（**前髪の揺れ** など）を確認します。不足しているパラメータ、フィードバックループ、出力の競合は、パネル上に直接表示されます。
3. キャンバス上で振り子のリングをドラッグして長さを変え、キャンバスの空いている所をドラッグしてモデルを引っ張り、揺れを観察します。
4. 出力の最大値と範囲を確認し、**最大値で倍率を調整** をクリックして補正し、パラメータの端点で長く頭打ちにならないようにします。
{tutorial=PHYSICS}
## 物理グループを新規作成する
- **新規 → 空の振り子**：入力、出力、振り子をゼロから設定します。
- **選択対象に揺れを作成…**：選択した髪やアクセサリーに、揺れの形と対応する物理演算を同時に生成します。
- **physics3.json を読み込む…**：既存の Cubism の物理演算設定を読み込みます。
- **プリセット**：頭と体の揺れなど、組み込みの設定を適用します。
## 髪と衣装のシミュレーション
髪や服に布のような効果がほしいときは、シミュレーションで生成してからパラメータと振り子にベイクできます。[[simulation]] を参照してください。
{tutorial=SIMULATION}
*> MOC3 を書き出すとき、**physics3.json を含める** にチェックを入れると、物理演算が納品ファイルに書き込まれます。

@@ t-motion-hint | モーションのクオリティを上げるコツ
モーションの良し悪しは、キーフレームの数よりも、リズムと層の重なりで決まることが多いものです。以下の一般的なコツは、PSD2Live のアニメーションエディターでそのまま使えます。
## コツ
- **先にリズムを決めてから細部を調整する**：まず **ドープシート** で主要なポーズのタイミングを並べ、そのあと **カーブ** ビューでイージングを調整します。
- **イーズイン・イーズアウト**：キーフレームのデフォルトはベジェのイージングです。始まりと終わりを等速にせず、カーブのハンドルで出だしと終わりを遅くします。
- **タイミングをずらす**：頭、体、視線を同じフレームで動かし始めず、体や視線を少し早めたり遅らせたりすると、動きに奥行きが出ます。
- **フォロースルーは物理演算に任せる**：髪やアクセサリーの揺れは物理演算に任せれば、フレームごとに作る必要はありません。プレビューで物理演算をオンにして効果を確認します。
- **静止中も生き生きと**：まばたきや小さな呼吸があると、止まっている間も硬く見えません。待機モーションの **まばたき**、**呼吸** の調整項目をそのまま使えます。
- **端点で止めない**：パラメータが長く範囲の端点に留まると硬く見えます。必要に応じてパラメータの範囲を広げるか、物理演算の出力倍率を調整します。
*> 再生中はすべてのキャンバスが同じポーズを共有するので、アニメーションエディターで調整しながら、プレビューキャンバスで確認できます。
{tutorial=ANIMATION}
関連：[[grapheditor]] · [[timeline-basic-operation-dopesheet]] · [[physics-operation]]
@@ t-function | 便利機能紹介
PSD2Live が最も時間を節約してくれるのは、「まず自動生成し、生成結果の上で修正し、その修正は再生成しても失われない」という点です。以下に、知っておくと便利な機能を用途別に挙げます。詳しい説明はリンク先を参照してください。
{tutorial=LIVE2D_BRIDGE}
## 生成と再生成
- **自動生成**：PSD の読み込み時にモデルプリセットに従ってメッシュ、デフォーマ、パラメータ、モーション、物理演算を生成します。[[model-presets]] を参照してください。
- **生成結果を更新**：**モデル → 生成結果を更新** で、新しいバージョンのジェネレーターで再生成し、そこへ自分の編集をマージします。[[update-generated-rig]] と [[generated-overrides]] を参照してください。
- **Layout プロジェクト**：ばらばらの素材を配置してから生成し、あとから画像を追加して再生成できます。[[layout-project]] を参照してください。
## 編集補助
- **キーフォームをミラー**：片側を作ったら対称キーや反対側のオブジェクトへミラーします。[[motion-mirroring]] を参照してください。
- **ボーン**：FK/IK でポーズを付け、書き出し時にパラメータとキーフォームへベイクします。[[skeleton]] を参照してください。
- **グルーと変形パス**：隣り合うメッシュを一緒に動かしたり、パスに沿ってメッシュを曲げたりします。[[glue]] と [[deformpath]] を参照してください。
- **揺れの生成**：髪やアクセサリーの揺れの形と物理演算をワンクリックで生成します。[[auto-generation-of-sway-motion]] を参照してください。
- **髪と衣装のシミュレーション**：シミュレーション後にパラメータと振り子へベイクします。[[simulation]] を参照してください。
## 素材とテクスチャ
- **メッシュごとの分割 / 前後分割**：同じレイヤーに描かれた部品を分けます。[[split-by-mesh]] と [[depth-split]] を参照してください。
- **ペイントモード**：プロジェクト内でレイヤーのピクセルを直接修正します。[[paint-mode]] を参照してください。
- **テクスチャ高解像度化**：**モデル → テクスチャ高解像度化…**（{key:TEXTURE_UPSCALE}）。原画の解像度が低いときに使います。[[texture-upscale]] を参照してください。
## プロジェクト管理
- **分岐する履歴**：履歴はツリーとして保存され、任意のバージョンに戻って続きを作業できます。[[history-palette]] を参照してください。
- **パラメータスナップショット**：パラメータパネルで現在のパラメータの組み合わせを保存し、いつでも読み込めます。
- **多様な書き出し形式**：**ファイル → 形式を指定して書き出し** でランタイム、画像、動画を書き出します。[[other-formats]] を参照してください。
{tutorial=PROJECT_HISTORY}
@@ t-model-introduction | モデル紹介動画を作ってみよう
モデルのモーションを動画として書き出します。シーンを組む必要はなく、プロジェクトから直接モーションの動画を書き出せます。

1. **アニメーション** パネルで **新規モーション** を押し、**空のモーション** または **プリセットから複製** を選びます。
