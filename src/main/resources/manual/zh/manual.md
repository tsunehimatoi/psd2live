@@ workflow | 制作流程
PSD2Live 把一张分层 PSD 直接变成能动的 Live2D 模型：导入后，网格、变形器、参数、待机与眨眼动作、物理一次生成好，你在此基础上修形、补动作，再导出给 Cubism 或其他运行时。打不打开 Cubism 都能完成一个模型。

已经用过 Cubism 的话，这条路线先把 ArtMesh、变形器、参数对应到 PSD2Live，再集中讲自动生成、画布模式、骨骼、动画与物理：

## 从 PSD 到导出
1. **准备 PSD**：每个会动的部件放在单独的图层，图层名尽量写清部位（见 [[precautions-for-psd-data]]）。
2. **生成**：在开始页的 **从 PSD 生成** 选好预设（最小 / 默认 / 完整），把 PSD 拖进窗口，或按 {key:OPEN_PSD}。生成完成后自动进入编辑工作区（见 [[psd-import]]、[[model-presets]]）。
3. **核对识别结果**：在 **图层** 面板看每层的标签（部位、侧别）与差分，识别错了直接改（见 [[layers-palette]]）。
4. **预览**：画布模式菜单选 **预览**，看待机、眨眼、鼠标跟踪和物理是否自然（见 [[preview-canvas]]）。
5. **按需修改**：在编辑画布上用变形、编辑、骨骼、绘画等模式修关键形、网格与像素；在物理面板与「修改器」面板调摆动与模拟（见 [[canvas-modes]]、[[modifiers]]）。
6. **保存**：{key:SAVE_PROJECT} 存为 `.psd2live`，源图、全部编辑与分支历史都在里面。
7. **导出**：{key:GENERATE} 打开 **导出 Live2D 模型…**，导出 `.moc3` 运行时文件或 `.cmo3` 工程；其他格式在 **文件 → 导出为**。
不从 PSD 开始也可以：**排版工程** 先在空画布上摆放图片、PSD 或 SVG 素材再生成（见 [[layout-project]]）；**从 CMO3 导入** 则接着编辑已有的 Cubism 模型（见 [[cmo3-import]]）。
## 编辑不会被重新生成冲掉
画布上的每次修改都记成可重放的编辑。改了图层标签或模型预设后，模型从源图重新生成，你的编辑再按原顺序套上去。升级 PSD2Live 不会悄悄改变已有工程；想用新版生成器时，执行 **模型 → 更新生成结果**（见 [[update-generated-rig]]）。
*> 要在 Cubism Editor 里继续精修，导出 `.cmo3`。在 Cubism 中改过的模型可以用 **模型 → 用 CMO3 替换当前模型…** 按 ID 换回工程（见 [[modeling-menu]]）。

@@ file-type-and-extension | 文件类型和扩展名
日常只需要记住一种文件：`.psd2live` 是工程本体，其余要么是导入的素材，要么是导出的交付物。
## 工程
| 扩展名 | 说明 |
|---|---|
| `.psd2live` | 工程。未加密的 ZIP，包含源 PSD 或 CMO3、素材、设置、全部编辑与分支历史，不依赖原 PSD 的路径 |
| `.psd2live.json` | 导出时附带的报告（可在导出窗口关掉），记录损失与警告，不是工程文件 |
## 导入
| 扩展名 | 说明 |
|---|---|
| `.psd` | 分层 PSD，生成模型的源图 |
| `.cmo3` | Cubism Editor 模型工程，可新建工程或替换当前模型 |
| `.png` `.webp` `.tiff` `.bmp` | 拖到层级树（按插入标记放入或插入）、编辑画布（放在松手处）或用 **导入图层…** 加为单张图层，同时登记为素材 |
| `.svg` 等图片 | 导入排版工程的素材库 |
## 导出
| 扩展名 | 说明 |
|---|---|
| `.cmo3` / `.can3` | Cubism Editor 模型工程；有动作时另写同名 `.can3`（Animator 工程），两者放在同一文件夹 |
| `.moc3` `.model3.json` 等 | Cubism 运行时文件族：模型、设置、物理、动作、显示信息与纹理，从 `.model3.json` 加载 |
| `.vtube.json` | 随 `.moc3` 文件族一起导出，供 VTube Studio 读取 |
| `.p2lrt` | PSD2Live 运行时模型，也用于网页播放器 |
| `.p2lunity` | Unity 预制体导出的模型数据 |
| `.psd` | 指定姿势的分层 PSD，或含生成图层的源 PSD |
| `.png` `.gif` `.apng` `.webp` `.mp4` `.webm` `.mov` | 序列帧、精灵表、动图与视频 |
!> `.cmo3` 里不包含生成器设置与编辑历史。要回到 PSD2Live 继续编辑，请保留 `.psd2live`。
各格式的内容与限制见 [[export-moc3-motion3-files]] 与 [[exporting-images]]。

@@ fault-map | Editor/Viewer无法正常开启时的确认事项
画面不对、预览打不开或程序意外退出时，先对照下表；多数情况不用重装就能解决。
## 常见情况
| 现象 | 处理 |
|---|---|
| 编辑画布黑屏、闪烁或显示错乱 | 在 **设置 → 画布交互** 勾选「编辑画布与纹理集页面使用软件渲染」；同一处显示当前用的是 GPU 还是软件渲染。显卡不支持多重采样或 GPU 绘制失败时，程序会自动改用兼容方式 |
| 预览画布用不了 Cubism SDK | 没有可用的 Cubism SDK 原生库时，在预览画布的 **预览运行时** 改用 PSD2Live 运行时；Linux 上没有 XWayland 的纯 Wayland 或 musl 系统会自动回退 |
| 面板不见了 | 从工作区标签栏右侧的 **窗口** 菜单重新勾选，或选 **重置布局** |
| 画布上看不到模型 | 按 {key:FRAME_VIEW} 适配所选，或 {key:RESET_CAMERA} 重置镜头，再检查图层显隐 |
| 程序异常退出 | 下次启动时会询问是否恢复未保存的编辑（见 [[autosave]]） |
| 设置或界面状态错乱 | 在设置页目录底部点 **恢复默认**；还不行就关闭程序，带 `--clear-user-data` 参数运行一次，清除设置与本机数据 |
## 反馈问题前
1. 打开 **日志** 面板，按等级与来源筛出错误，点 **复制日志**。
2. **设置 → 文件与数据** 显示 **错误日志** 的位置；这里也能清理之前异常退出留在系统临时文件夹里的残留。
3. 帮助页的 **关于** 显示版本与运行环境。
4. 从 **帮助 → 在线资源 → 问题反馈** 提交，附上版本、操作系统、复现步骤与相关素材。

@@ performance | 处理SDK中模型时的性能
导出的模型在运行时跑得快不快，主要看网格顶点数、关键形数量、纹理尺寸与遮罩。这些量大多由生成器按设置产生，所以要控制它们，改的是设置，而不是逐个对象去删点。
## 在哪里查看和调整
| 因素 | 位置 |
|---|---|
| 网格顶点数 | **网格** 面板显示选中图层的顶点数与边长，可改全局默认或逐层覆盖；**图层** 信息里也有顶点数 |
| 纹理尺寸与显存 | 「纹理」工作区：未选图层时，纹理面板列出每页的尺寸、图块数、占用与显存（RGBA）；右上角设纹理集预算（页面尺寸、最多页数、间距），也可逐层调纹理密度（见 [[texture-atlas-edit]]） |
| 关键形数量 | 模拟烘焙成关键形轴时，网格的关键形数会乘以模态的关键点数；选「融合变形」（Cubism 4.2+）可避免，「自动」在关键形超过 64 个时改用融合变形（见 [[simulation]]） |
| 目标版本 | 导出时按所选 SDK 目标去掉不支持的功能，并列出降级项（见 [[target-version-selection]]） |
导出报告 `.psd2live.json` 会记下降级与损失，交付前值得看一眼。
## 编辑器里的预览负担
预览画布的 **帧率上限** 可以限制帧率或跟随显示器。预览菜单的 **高级模式** 只对 PSD2Live 运行时有效，会实时运行布料与头发模拟，机器吃力时先关掉它。

## 自动生成带来的概念
| 术语 | 含义 |
|---|---|
| 模型预设 | 控制生成的动作、物理与模拟；形变幅度与口型在各角色组件卡片中（见 [[model-presets]]、[[modifiers]]） |
| 标签 | 图层的部位、侧别等，生成器靠它识别部件 |
| 差分 | 无差分、开关差分（一个参数控制有无）、切换差分（同一参数多选一）（见 [[variants]]） |
| 生成结果 | 由源图与预设自动生成的模型，你的编辑在它上面重放 |
| 画布模式 | 物体、变形、编辑、模拟、骨骼、绘画、预览（见 [[canvas-modes]]） |
| 工作区 | 顶部的标签，各有自己的画布与面板布局（见 [[workspace]]） |
| 变形路径 | 沿曲线变形网格的工具，导出时烘焙为网格关键形 |
| 骨骼 / 模拟 | 骨架与布料、头发模拟，导出时烘焙为参数、关键形与摆锤 |
| 烘焙 | 把 Cubism 没有的功能换算成原生变形器、关键形或摆锤 |
| 纹理集 | 打包各图层像素的纹理页，可逐层设纹理密度 |
| 参考图层 | 显示在画布上、不参与生成与导出的图层 |

@@ target-version-selection | 选择目标版本
目标版本决定导出的 `.moc3` / `.cmo3` 能用哪些 Cubism 功能。在 PSD2Live 里它是导出时的一个选项：编辑时可以放心使用所有功能，导出到旧版本时再由程序替你降级，同一个工程也能分别导出给不同版本。
## 选择目标
1. 按 {key:GENERATE} 打开 **导出 Live2D 模型…**。
2. 在 **SDK 目标** 下拉中选 Cubism 3.0、3.3、4.0、4.2、5.0 或 5.3（默认 5.0）。
3. 如果模型用到了目标不支持的功能，窗口里会出现「导出时将降级以下已使用的功能」，逐项列出格式、功能与对象。
## 常见的降级项
| 功能 | 说明 |
|---|---|
| 四角变形方式 | 较早目标不支持新的弯曲变形方式 |
| 反转蒙版 | 需要较新的目标 |
| 混合形状 | 融合变形相关功能按版本分级 |
| 正片叠底颜色 / 滤色颜色 | 较早目标不支持 |
| 扩展混合模式、部件离屏合成 | 需要较新的目标 |
目标版本也会影响生成：比如目标不支持融合变形时，模拟的模态写成关键形轴。

@@ guide-function | 辅助线功能

- 在画布右下的显示栏点 **辅助线**（{key:TOGGLE_GUIDES}），画布上沿与左沿出现标尺，刻度单位是画布像素。

| 操作 | 方法 |
|---|---|

@@ grid | 栅格功能
栅格在文档范围内画出等距的参考线，用来对齐网格点、变形器和部件的位置。只在编辑画布上显示，不影响模型与导出。
## 显示栅格
在画布右下的显示栏点 **栅格**（{key:TOGGLE_GRID}）。
## 设置
在显示栏的 **画布辅助设置…** 中调整：
| 项目 | 作用 |
|---|---|
| 间距 | 主栅格线之间相隔的画布像素（2–1024） |
| 细分 | 每格再分成几小格；为 1 时只画主线 |
| 不透明度、颜色 | 栅格线的浓淡与颜色，颜色按主题色选择 |
缩小画布时，过密的细分线会自动隐去，必要时主线成倍拉开，画面不会糊成一片。
## 吸附
开启 **吸附到栅格与辅助线**（{key:TOGGLE_SNAP}）后，拖动网格或变形器的点时，点靠近栅格线（约 6 像素以内）就会落到线上。吸附的是被抓住的那个点而不是指针，所以点本身正好在线上，选区中的其余点随之移动同样的距离；点击与点选仍按指针的实际位置。吸附的是当前缩放下看得见的那一级栅格线。绘画与变形笔刷不吸附，以免笔触被拉到线上。

@@ onion-skin | 洋葱皮
洋葱皮把相邻关键或相邻帧的形状半透明地叠在当前画面上：修形时能看到前后关键的样子，做动作时能看到前后帧的走向。只在编辑画布上显示，不写入工程，也不导出。
## 显示洋葱皮
在动画面板工具条右端点 **洋葱皮**（{key:TOGGLE_ONION_SKIN}）。它作用于当前编辑画布；当前画布是预览画布时，作用于第一块编辑画布。叠显的内容取决于当前状态：

|---|---|

| 没有打开动作 | 最近在参数面板设置的参数在当前值前后的关键；选中的对象在该参数上有关键时取它的关键，否则取整个模型的 |

*> 洋葱皮沿用画布的显示过滤（仅显示选中项、图层显隐）；悬停预览参数快照时与绘画模式中暂不显示。

@@ convert-id | ID转变
把模型里参数、参数组、部件、变形器和图形网格的 ID 换成新的 ID，例如把 Cubism 2 风格的 `PARAM_ANGLE_X` 换成 Cubism 3 标准的 `ParamAngleX`。所有引用都会一起改：关键形与混合形状用到的参数、父级与部件、剪贴蒙版、胶水、路径、顶点组、组合参数与参数组、动作曲线、自建的物理组和摆动的目标；按标准 ID 生成的物理、动作与表情也会找到改了 ID 的参数。
## 转变 ID
1. **模型 → ID 转变…**。
2. 在 **物体类型** 中选择参数、参数组、图形网格、网格变形器、旋转变形器或部件，用 **筛选** 缩小列表。
3. 在要改的物体旁填写新 ID。**填入 Cubism 3 标准 ID** 会为 Cubism 2 风格的参数（`PARAM_…`）与部件（`PARTS_01_…`）填好对应的标准 ID。
4. 点 **转变**。整批作为一步历史记录，可以撤销。
新 ID 只能用字母、数字和下划线并以字母开头，且同类物体之间不能重复（网格变形器与旋转变形器共用一套 ID）；不合规时对话框下方会说明原因。按规则批量改 ID 见 [[search-and-replace]]。
## 导出前的检查
导出时会检查 ID：同类物体共用一个 ID 时拒绝导出并列出冲突的 ID；含有字母、数字和下划线以外字符的 ID 只给出警告。
!> 摆动、模拟和内部造型自己生成或读取的参数与网格不能单独转变 ID，需要先在对应面板中移除；绑定到骨骼的网格、骨骼参数和骨骼变形器也不能转变。转变后，当前姿态、参数快照、时间轴书签和变形器显隐随之改用新 ID，撤销时换回。
*> 与 Cubism 不同，这里不读写转换表文件。转变记录在工程历史里，之后的编辑使用新 ID，重新生成模型时也按原顺序重放。

@@ autosave | 自动备份功能
编辑时，PSD2Live 会不断把未保存的修改写进本机的工作区存储。万一程序崩溃或断电，下次启动可以把这些修改找回来，不需要手动去翻备份文件。
## 恢复
1. 程序在保存或放弃修改之前异常关闭后，重新启动 PSD2Live。
2. 出现「恢复未保存的编辑」窗口时选 **恢复**；选 **放弃** 则不恢复。
3. 工程以未保存状态打开，历史、参数姿态、快照与工作区都在；按 {key:SAVE_PROJECT} 保存下来。
正常保存或放弃后退出时，恢复数据会被清除。崩溃时正在运行的后台任务会显示记录，但不会自动重新执行。
!> 恢复出来的内容仍未保存，请尽快存成 `.psd2live`。
## 存储位置
**设置 → 文件与数据** 显示工作区存储的位置与大小，已打开工程的历史就存在这里；这里也能清理之前异常退出留在系统临时文件夹中的残留。

@@ divide-the-material | 关于素材拆分
PSD2Live 能从一张分层 PSD 直接生成可动的模型，前提是会分别运动、或会互相遮挡的部分画在不同图层上。拆得越合理，自动生成的网格、变形器和参数就越少需要返工。
## 怎么拆
- 每个部位单独一层：眼白、瞳孔、上睫毛、眉毛、鼻子、嘴巴、前发、后发、脸、脖子、上衣等。
- 瞳孔画成完整的圆，被眼皮遮住的部分也画出来；眼白负责限制瞳孔的显示范围。
- 嘴巴画最大张口状态，闭口由程序生成；口腔可以画成一层，也可以再分上牙、下牙、舌头。
- 前发和后发分开，被遮挡的地方多画一些，头发摆动时才不会露底。
- 左右成对的部件（双眼、双耳、双臂）分成左右两层，并在名称里写明侧别。
图层名告诉生成器每一层是什么部位，命名约定和可识别的名称见 [[precautions-for-psd-data]]。
## 拆漏了也能在编辑器里补
画在同一层的左右部件不会在导入时自动分开。导入后可以用 [[split-by-mesh]] 按连通区域拆成独立图层；一层需要同时位于另一部件前后时（例如领子绕过脖子），用 [[depth-split]]。素材来自多个文件、不方便合成一张 PSD 时，可以在 [[layout-project]] 里直接摆放图片再生成。

@@ reimport-psd | 如何制作载入PSD
准备 PSD 时只要守住几条规则，导入后就能直接得到一个可动的模型，省去逐层手动绑定。
## 文件
- 使用 RGB、8 位、透明背景的分层 PSD。
- 文字、矢量、图层样式和调整效果先栅格化，或合并到对应的像素层。
- 身体保持基本正立，头部可以轻微倾斜；导入后在预览中核对一下自动估计的基准。
## 图层名称决定部位
生成器按图层名称识别部位，英文、中文、日文、韩文都可以，例如 `front hair`、`前发`、`eyelash-l`、`左睫毛`。识别结果只是初始值，导入后可以在「图层」面板的 **标签** 列随时修改。
*> 习惯 Cubism 的用户注意：PSD 的文件夹结构不会变成部件，部件由生成器按识别出的部位建立，所以图层名比文件夹更重要。
- 左右指角色自身：角色的左侧通常在画面右边。
- 名称里的数字（如 `front hair 1`）只用来区分同类素材；Photoshop 自动加的部分副本后缀会被清理。
- 数字不会建立表情切换。需要随参数显隐或切换的图层，导入后设置 [[variants]]。
## 画布尺寸
网格设置默认 **随文档尺寸缩放**，网格长度按长边缩放到固定尺寸的文档计算，所以大尺寸 PSD 也会得到同样疏密的网格；清晰度来自图层自身的像素。

@@ precautions-for-psd-data | 创建PSD的注意事项
自动生成依赖图层名称和分层方式。下面汇总了能被识别的图层名，以及绘制时最容易出问题的地方；名称不在表中的图层也不会丢，导入后在「图层」面板的 **标签** 列补上部位即可。
!> 名称识别成功不代表造型已经合格。导入后检查中立姿势、眼口开合、转头和头发运动，核对层序、左右、遮罩和露底。

@@ split-by-mesh | 按网格拆分图层
一层里画着几块互不相连的部分时（例如两只眼睛在同一层），可以在编辑器里直接按网格的连通区域把它拆开，每块各自得到网格、变形和标签，不必回到绘图软件改 PSD。
## 拆分图层
1. 打开 **模型 → 按网格拆分图层…**，对话框列出所有包含多个独立网格的图层，可 **全选** / **取消全选** 后点 **拆分所选**。只处理一个图层时，在层级树中右键它选 **拆分独立网格…**，或在画布右键菜单的 **网格** 中选择。
2. 确认每个区域的预览，选择命名方式：两块时可选 `L / R`、`T / B`、`1 / 2` 或 **自定义命名**，更多块时按编号或自定义。
3. 点 **拆分图层**；不想拆时点 **保持单层**，批量处理时可点 **全部保持单层**。
`L / R` 按角色自身的左右命名：画面左侧那块得到 `-r` 后缀并标为右侧，另一块为 `-l`。
导入图层后程序也可能主动询问是否拆分；不想再看到提示时在对话框里勾选，或在 **设置 › 提示** 关闭「导入图层时提示按网格拆分」。
## 拆分后
部件取代原图层，网格取自原网格的对应部分，原图层上的关键形、混合形、路径、权重与胶水随之带到各部件上。以后修改某个部件的网格设置时，会按它自己的像素重新生成网格并迁移这些绑定。
需要按自定义形状分开、或让一层前后穿插时，用 [[depth-split]]。
!> 从 CMO3 导入的模型不能按网格拆分。

@@ depth-split | 前后分层
后领口藏在脖子后、前领片盖在脖子前——这类一层要同时出现在另一部件前后的情况，用 **前后分层** 在编辑器里一步解决：程序把图层复制成前后两层夹住中间对象，自动排好绘制顺序并用胶水让两层一起变形，你只需在前层上擦掉应该藏到后面的部分。
## 操作步骤
1. 在编辑画布切到 **物体** 模式，选中要分层的图层（如上衣），按住 {kbd:Shift} 加选要夹在中间的对象（如脖子）。
2. 右键要分层的图层，选择 **将「图层名」前后分层**。菜单里显示的是将被复制的对象，点之前确认一下。
3. 程序创建「`图层名 · 后`」和「`图层名 · 前`」两层取代原图层，选中前层并切到 **绘画** 模式的 **橡皮擦**。
4. 沿中间对象的边缘擦掉前层中应被遮住的部分，擦多了可以在绘画会话里撤销。
5. 点 **确认应用**。前层保留原网格和变形，不需要重新生成网格。
6. 在参数面板拖动转头、身体转动等参数检查，必要时回到前层继续修边。
{tutorial=PAINT_MODE}
只选中了一个图层时，在层级树中右键它选 **前后分层…**，在弹窗的 **穿插对象** 中选择中间对象，确认前层、中间、后层的关系后点 **创建并擦除**。
## 注意事项
- 一次只分层一个图层；中间对象可以加选多个，它们一起放在前后层之间并保持彼此的顺序。
- 创建后外观不会马上变化：前层起初是完整复制，擦除之后才出现遮挡效果。
- 有未提交的绘画会话时，先应用或放弃再创建。
!> 从 CMO3 导入的模型暂不支持前后分层。

@@ layout-project | Layout 工程与素材库
Layout 工程让你先在画布上摆好部件、标好部位，再生成绑定；生成之后还能继续加图、改标签再重新生成，已有的编辑都会保留。适合素材分散在多个文件、或由其他工具拆分出来的情况。工程用到的所有图片都放在 **素材** 面板里，画布上图层的像素来自它关联的素材。
## 开始一个 Layout 工程
- **空画布**：在开始页选 **排版工程**（或 **文件 → 新建 → 新建 Layout 工程…**），选常用尺寸或输入宽高后点 **创建排版工程**。
- **从 PSD**：照常导入 PSD，工程直接生成绑定，PSD 的每个图层同时登记为素材并与画布上的图层关联。
- **从 Layout 清单**：外部工具写出的清单（JSON，或根目录放着它的 zip）用打开 PSD 的方式打开，图层按清单摆好，尚未生成。
## 摆放与生成
1. 在素材面板点 **导入** 或 **导入文件夹**，或把文件直接拖到面板上。支持 PNG、BMP、TIFF、WebP、JPEG、SVG，以及 PSD 的图层与 CMO3 的各 ArtMesh 图片；PSD 成为一个文件夹，图层组成为子文件夹。
2. 把素材或整个文件夹拖到画布上，或右键 **放置到画布**。
3. 在 **物体** 模式下用变换框移动、缩放、镜像图层；这些操作不会重采样像素。
4. 在「图层」面板的 **标签** 列写明部位与侧别，在 **差分** 列设置 [[variants]]。
5. 点编辑画布右上角生成栏的 **生成**。之后新放的或改过标签的图层显示为「待生成」，点 **重新生成** 把它们并入绑定。
{tutorial=LAYOUT}
*> 画布单位决定模型的大小与比例，清晰度来自素材自身的像素：图层摆得越小，纹理越密。
还没生成的图层用 {key:LAYER_FORWARD} / {key:LAYER_BACKWARD} 上下移动一层，{key:LAYER_TO_FRONT} / {key:LAYER_TO_BACK} 置顶、置底；生成后改用 [[draworder]]。
## 整理素材
- 把素材拖到其他文件夹即可移入；右键可重命名、新建文件夹、删除。正在被图层使用的素材不能删除。文件夹上的标签会带给从它放置的每个图层。
- 双击素材打开独立的素材窗口，可以放大查看、绘画、翻转和调色，所有使用该素材的图层一起更新。
- 素材上右键 **替换选中图层的图片**，图层在画布上的位置与大小不变，只换像素，见 [[psd-re-import]]。
- 每个图层都有一个素材作为像素的唯一来源：导入 PSD、CMO3 或图片、拆分图层时都会登记。多个图层共用一个素材时，画其中任一个就是画素材；只想改其中一个，右键 **设为独立素材**。旧工程里还没有素材的图层，素材面板顶部会提示 **登记到素材库**。
- 原画、草稿等对照用的图片可以作为参考图或参考图层放置，见 [[sketch]]。

@@ psd-import | PSD载入
导入分层 PSD 后，PSD2Live 按图层名称识别部位，一次生成网格、变形器、参数、动作和物理，直接得到能动的模型；之后的所有修改都记录为编辑，重新生成时会自动重放。生成哪些内容由 [[model-presets]] 决定。

1. 选择 **文件 → 新建 → 从 PSD 新建工程…**（{key:OPEN_PSD}），或把 PSD 拖到窗口任意位置。也可以在开始页点 **从 PSD 生成**，先在详情面板选 **最小** / **默认** / **完整** 预设、按需调整，再选文件；**最近的 PSD** 中双击即可直接生成。

{tutorial=BASIC}
所选预设会被记住，之后从菜单、最近文件或拖放导入的 PSD 都按它生成。PSD 的每个图层同时登记为素材，可在 [[layout-project]] 中继续增补图片。

@@ psd-re-import | PSD重新载入
原画改了以后，可以只把新像素换进现有工程，你在模型上做过的编辑都会保留。PSD2Live 不做整份 PSD 的图层对应，而是逐层替换：
## 替换图层的像素
1. 在素材面板 **导入** 修改后的 PSD，它成为一个新的素材文件夹。
2. 在画布或图层列表中选中要更新的图层。
3. 在新素材上右键 **替换选中图层的图片**。图层在画布上的位置与大小不变，只有像素和纹理集图块变化。
4. 点生成栏的 **重新生成**。替换过图片的图层默认按新像素重建网格；想保留原网格，在生成按钮的下拉中选 **生成但保留替换图片的几何**。
单个图层也可以在 **纹理** 面板用 **替换图像…** 替换，见 [[png-file-export-replacement]]。原画新增了部件时，把它当作新素材拖到画布上、标好标签再 **重新生成**，见 [[layout-project]]。
!> 已有作者编辑、绑定或物化网格的图层，替换图像并重建网格可能被拒绝，原因显示在纹理集页面上方。
## 从头重新生成
想按改过的 PSD 完全重来时，用 **模型 → 重新分析 PSD**（{key:REANALYZE}）：重新读取当前 PSD，按当前预设生成一个新工程。原工程里的编辑不会带过去；有未保存的修改时会先询问是否保存。

@@ model-presets | 模型预设
**模型预设** 位于「修改器」面板「世界」页的「模型预设」节，集中决定自动生成哪些动作、物理与模拟。形变幅度、口型与各部位的 Rig 数值在各自的角色组件卡片里调整（见 [[modifiers]]）。改动后模型按新设置重新生成，你已有的编辑照常重放，所以可以放心反复试。
## 在哪里设置
- 导入前：开始页 **从 PSD 生成** 的详情面板，先选 **最小** / **默认** / **完整**，再逐项调整；生成按钮的菜单里可以切换预设，或 **应用到当前模型**。
- 导入后：「修改器」面板「世界」页的 **模型预设** 节（面板关掉后可从 **窗口** 菜单重新打开）。节内工具条可以全部展开或折叠，**恢复默认** 把所有预设还原。
## 各组内容
| 组 | 内容 |
|---|---|
| 动作 | **基础动作**、**骨骼动作** 两组；关闭后该组动作从动画面板、预览和导出中移除 |
| 物理与模拟 | 前发、后发各选 **模拟** / **经典摆动** / **关闭**；**服装** 模拟（只作用于宽松部位）；果冻眼；自动 Pin 物理权重 |
勾选 **仅选中** 时，物理与模拟的预设只作用于选中的图层。
*> 建议先用默认值生成并预览，需要调整时一次只改一项，便于看清每项的作用。纹理集的设置不在这里，在导出窗口中。

@@ update-generated-rig | 更新生成结果
开启头发模拟、启用骨架、拆分图层这类操作，会把你的编辑合并到当时的生成结果上并固定下来，这样升级程序不会悄悄改变你的模型。想用上新版本生成器的改进时，主动执行 **更新生成结果**。
## 操作
1. 先选 **模型 → 预览生成结果更新**：状态栏显示更新会不会改变模型、有几项需要查看，工程本身不变。
2. 再选 **模型 → 更新生成结果**。你没改过的部分换成新版本的生成结果，你的修改保留。
3. 无法干净迁移的地方，状态栏会提示条数，并在检视面板的 **生成结果覆盖** 中逐项列出。
更新是一步历史，可以撤销；生成结果没有变化时不产生历史。
打开工程或生成结果变化后，程序会在后台检查有没有较早版本合并得不对的结果，有则在编辑画布顶部提示，可以直接点「更新生成结果」或「预览变化」。关掉提示后，在生成结果再次变化前不会再出现。
*> 在生成器拥有的关键形上做的画布编辑，会作为对生成结果的覆盖保存，更新时与新结果三方合并，所以手工调过的形状不会被冲掉。

@@ texture | 纹理
@@ texture-atlas-edit | 编辑纹理集
纹理集随模型自动打包，平时不用管；需要控制某个部位的清晰度、或把贴图塞进更小的页面时，在 **纹理** 工作区里直接调整图块的位置、密度和旋转，并设置页面预算。
## 三种尺寸
每个图层有三种尺寸：画布上覆盖的矩形（画布单位）、自身栅格的像素、纹理集中的图块像素。**纹理** 面板以「画布 → 原图 → 纹理集」三格并列显示所选图层的这三项。
## 调整图块
1. 在纹理集页面单击图块选中对应图层，或在空白处拖动框选；选择与画布、图层列表同步。
2. 拖动图块移动；与其他图块的网格重叠或超出页面时图块变红，松开不会移动。
3. 拖动所选图块的角点按比例调整密度，拖动顶边外的圆形手柄旋转（按住 {kbd:Shift} 以 15° 步进）。
4. 页面顶部出现会话栏，可撤销、重做或 **放弃**，满意后点 **应用**，作为一步历史提交。
右键图块还可以加倍 / 减半密度、旋转 90°、移到其他页、锁定尺寸、排布所选图块或替换图像。重叠按网格实际覆盖的区域判断，图块的透明角落可以互相嵌套。
## 排布与预算
- 左上角 **排布** 一次性重排并保存：**按网格形状（图块嵌套）** 或 **按矩形**，范围为 **全部图块** 或 **仅所选图块**。
- 开启 **自动排布** 后每次修改都按矩形重排；新工程默认关闭，保持当前布局。
- 右上角 **纹理集预算** 设置页面尺寸、最多页数与间距。「适配」低于 100% 表示放不下，所有未锁定图块一起缩小；**锁定尺寸** 的图层保持不变。
未选图层时，**纹理** 面板显示每页尺寸、图块数、占用和显存估算；选中图层后可用 **纹理密度** 滑块与 ½× / 2× / 重置按钮调整每个原图像素对应的纹理集像素（1/64–16）。
*> 编辑画布右下显示栏的 **原始像素** 让画布直接采样图层自身的栅格，方便和打包后的清晰度对比。

@@ png-file-export-replacement | 输出和替换PNG文件

@@ copy-and-paste | 复制和贴上物体
复制图形网格和变形器，再粘贴出副本。副本带着原物体的关键形、混合形状、剪贴蒙版、路径和顶点组，与原物体共用纹理和图层，粘贴后可以各自修改。

@@ artmesh | 图形网格
@@ concept-of-artmesh | 关于图形网格
图形网格（ArtMesh）把纹理贴在由顶点和三角形组成的网格上，移动顶点就能让图像变形。PSD 的每个图层导入后成为一个图形网格，在 PSD2Live 中也叫画元；网格在导入时已按图层的透明度自动生成。
## 网格的构成
- 顶点：变形时移动的点。
- 边与三角形：连接顶点，决定图像如何随顶点拉伸。
- 轮廓：沿图层不透明像素的边缘，网格外的像素不显示。
顶点越密，变形越细腻，但编辑和运行时的负担也越大。调整疏密见 [[mesh-edit]]，局部修改拓扑见 [[mesh-edit-manual]]；带动多个网格整体变形的是 [[deformer]]。
{tutorial=LIVE2D_BRIDGE}
## 属性
选中图形网格后，**检视面板** 显示名称、ID、部件、变形器、剪贴 ID、反转蒙版、绘制顺序、不透明度、正片叠底色、屏幕色、混合模式、剔除与用户数据。

@@ mesh-edit | 自动网格生成
导入时每个图层都已经有了网格：程序沿图层的透明度描出轮廓，按设置放置边缘点和内部点再三角化。网格太疏、太密或轮廓不贴合时，改 **网格** 面板的设置即可重建，已有的关键形、路径、权重与胶水会迁移到新网格上，不用重做。
## 调整网格
1. 在 **网格** 工作区或 **窗口** 菜单打开 **网格** 面板。
2. **全局默认** 作用于所有没单独设置的部件；选中某个 ArtMesh 后，面板显示它自己的设置，修改后显示「已自定义设置」。
3. 改动后网格立即重建，在变形模式和预览中检查效果。
网格没覆盖到部分可见像素时，面板会提示比例，点 **按当前像素重建** 即可包含进来。面板的 **显示说明** 可以展开每个选项的解释。
## 主要设置
| 分组 | 设置 | 作用 |
|---|---|---|
| 轮廓位置 | 单层 / 双层 / 三层边缘、外边缘距离、边缘网格宽度 | 轮廓附近放几圈顶点及其位置 |
| 点位密度 | 边缘点距离、内部密度 | 轮廓顶点间距与内部点距 |
| 内部填充算法 | 渐疏泊松填充（默认）、平衡四叉树填充、正三角分形细分、轮廓层铺、简单三角填充 | 内部点的排布方式 |
| 连接拓扑 | 抑制边缘点之间的跨越连线 | 让不相邻的边缘点经内部点连接 |
| 单位 | 随文档尺寸缩放、按贴图像素描出轮廓、包裹 | 长度单位、描轮廓的精度、闭合睫毛等细小凸起之间的缝隙 |

## 操作
| 操作 | 结果 |
|---|---|
| 细分（{key:TOOL_SUBDIVIDE}） | 在命中的边上加点并重组三角形，相邻面同步处理接缝 |
| 连接 / 合并 | 在选中点之间建立连接，或把选中顶点合为一点 |
| 复制 | 复制选中顶点及其完整覆盖的面，新副本成为选区 |
| 删除（{key:DELETE_SELECTION}） | 删除选区并尝试补好缺口；无法形成合法拓扑时拒绝 |
| 布点 · 点（{key:TOOL_MESH_POINT}） | 单击空白处加顶点（三角形内、边上或网格外），在空白处拖动按「布点间距」沿笔画加点，拖动顶点移动；{kbd:Shift}+单击从选中顶点连线，{kbd:Alt}+单击删除顶点或边；可开「左右对称」。新加的点由网格自动整理连接，彼此之间不保证有边 |
| 布点 · 线（{key:TOOL_KNIFE}） | 逐点单击画一条折线，每点与上一点连成边，网格可沿这条线折弯（眼睑、嘴线、褶皱）；靠近点或边时吸附（按住 {kbd:Shift} 临时关闭）；{key:FINISH_PATH} 完成、{key:CANCEL} 取消 |
| 删除边 | 边模式下 {key:DELETE_SELECTION} 或拓扑菜单：内部边换成四边形的另一条对角线，轮廓边删掉所在三角形；会破坏网格时拒绝 |
| 重新三角化 | 拓扑菜单：在选中顶点周围（不选则全网格）把细长三角形翻成更均匀的连接，顶点和贴图不动 |
同时选中多个画元时，点选某个网格的顶点会把它设为主网格；布点的「线」和边、面选择只作用于主网格。
!> 删除轮廓点会改变边界，修改后在多个参数姿势下检查。日常拉形请在变形模式中进行，编辑模式只用来改拓扑。

@@ mesh-duplication | 复制网格
把一个图形网格的顶点与三角形复制到其他图形网格上，适合形状相同的差分，例如睁眼与闭眼、几套表情。目标网格在源网格所在的画布位置采用同样的拓扑，各自采样自己的纹理；目标原有的关键形、混合形状、路径、顶点组和胶水会迁移到新网格上。
## 使用方法
1. 在层级树中同时选中源网格和一个或多个目标网格。
2. 右键源网格，选 **把此网格复制到选中的 N 个网格**。
复制作为一步历史记录，可以撤销。
!> 目标图像超出源网格范围的部分不会显示，源网格超出目标图像的顶点会采样到图像以外。复制后在编辑模式下检查，必要时按 [[mesh-edit-manual]] 补点或切割。
*> 复制的是网格结构而不是变形：目标的关键形按顶点位置迁移，不会照搬源网格的关键形。

@@ clipping-mask | 剪贴蒙版
剪贴蒙版让一个图形网格只在另一个图形网格的范围内显示，例如瞳孔只出现在眼白里。生成模型时常用的蒙版已经自动设好：瞳孔由同侧眼白遮罩，牙齿、舌头等口内部件由嘴巴遮罩。
## 手动设置
1. 选中要被遮罩的图形网格。
2. 在 **检视面板** 的 **剪贴ID** 中指定蒙版：直接输入 ID（多个用逗号分隔），点列表按钮 **从列表中选择剪贴蒙版**，或点准星按钮 **从画布中快速关联蒙版** 后在画布上点击蒙版画元。
一个图形网格可以同时由多个蒙版限制。想要相反的效果，见 [[reversed-mask]]。
{tutorial=INSPECTOR}

@@ reversed-mask | 反转蒙版
反转蒙版让图形网格只在蒙版范围之外显示，与 [[clipping-mask]] 的效果相反。
## 设置
1. 选中已设置 **剪贴ID** 的图形网格。
2. 勾选 **检视面板** 的 **反转蒙版**。
修改作为一步历史记录，可以撤销。

@@ sketch | 参考图置入
制作时把原画、草稿或其他角度的设定图放在画布上对照，能更准地调形。参考是层级树里的一类成员，带参考图标，显示在三个位置之一，位置决定它是否进入模型：
| 显示方式 | 是否进入模型 | 说明 |
|---|---|---|
| 背景 | 不进入 | 垫在整个模型下，只在编辑器里显示；选中后在画布上拖动移动、缩放、旋转，可以锁定 |
| 图层中 | 进入 | 生成后是模型里的一个 ArtMesh，放在图层之间按绘制顺序叠放，可以挂到变形器下跟随变形；导出时属于参考图部件，默认不写出，导出窗口勾选 **导出指南图层** 时写出 |
| 前景 | 不进入 | 盖在整个模型上，其余与背景相同 |
排版工程第一次生成之前，图层中的参考与其他图层一样等待生成，生成后进入模型。
## 添加参考
1. 把图片或素材拖到编辑画布上，画布下方出现大的选项：**背景 · 参考**、**图层中 · 参考**、**前景 · 参考**、替换选中图层的图片、仅导入素材库，每项写明是否进入模型；松开在画布其他地方则放置为普通图层。
2. 也可以点层级面板工具栏或画布右下显示栏的参考图按钮（加在前景），或右键素材 → **添加为参考** 下的三项。
画布上已有、还没参与生成的图层或导入的图片，可以用「图层」面板工具栏的 **作为参考** 或 {key:LAYER_TOGGLE_REFERENCE} 变成图层中的参考，见 [[edit-parts-sketch]]。
## 调整参考
- 在层级树里点选参考：背景与前景的参考在编辑画布上出现手柄，拖内部移动，拖角点等比缩放，拖上方的圆点旋转；图层中的参考与其他 ArtMesh 一样用变换框调整。
- 右键参考，**显示方式** 在背景、图层中、前景之间切换，每项标出是否进入模型；素材、位置、显示与固定都保留。菜单里还有显示/隐藏、不透明度与锁定（背景与前景）、恢复为模型图层（图层中）和移除。
- {key:REFERENCE_TOGGLE_SHOWN} 切换当前画布是否显示背景与前景的参考。
## 按关键形显示
正面、侧面、仰视等不同角度的参考可以叠在同一位置，各自只在对应关键形出现，一个参考也可以出现在多个关键形上：
1. 右键参考，菜单下方的 **固定到关键形** 以参数面板的形状列出模型里有关键形的参数：一维参数是带关键形点的滑条，成对的参数是 2D pad。
2. 点关键形点即在那里打点（实心），再点取消；可以打多个点，参考在任意一个点上都显示，其余姿态隐藏。灰色的标记是当前姿态。
3. **取消固定** 清除全部点，恢复为任何姿态都显示。
*> 画布右键菜单的 **固定到关键形** 子菜单是同一个面板。固定只决定编辑器里何时显示，不写进导出。

@@ hittest | 重叠检测的设置准备
点击区域（HitArea）告诉应用“点到了模型的哪个部位”，例如点头部时换表情、点身体时播放动作。PSD2Live 把点击区域保存在工程中，导出时写入 model3.json 的 `HitAreas`（VTube Studio 包同样带上）与 `.p2lrt` 运行时模型。
## 设置点击区域
- **检视面板**：选中图形网格，在 **判定区域** 中选择它所属的区域，或选 **新建判定区域** 以它新建一个。还没有区域时可选 **设置头部与身体判定**，按自动识别的脸与上衣（没有上衣时取颈或下装）建立 Head 与 Body。网格属于某个区域后，可以修改 **判定名称**（应用按名称查询，常用 Head、Body）与 **判定 ID**。
- **层级树**：右键图形网格，在 **判定区域** 一节中勾选或取消它所属的区域，或选 **以此网格新建判定区域**。
一个区域可以包含多个图形网格；判定按区域列表的顺序进行，先命中的区域优先。每次修改是一步历史记录，可以撤销。没有设置任何区域时，`.p2lrt` 运行时使用自动生成的 Head 与 Body，model3.json 不写点击区域。
## 在预览中验证
在预览画布上单击模型（不拖动）：命中的区域以强调色高亮，日志写出“命中判定区域：名称（ID）”；没有命中时日志提示此处没有判定区域。判定方式与运行时相同：网格可见、不透明度大于 0，且点落在它的三角形内即为命中。
*> model3.json 的每个点击区域只指一个图形网格，包含多个网格的区域会写成同名的多项，导出报告中会注明。Cubism SDK 示例按网格的包围矩形判定，结果可能与预览略有不同。Cubism 模型常用不透明度为 0 的专用判定网格：这种网格在 PSD2Live 预览与 `.p2lrt` 运行时中不会命中，导出到 model3.json 后是否命中由宿主决定。网格被拆分时分片接替它在区域中的位置，图层被删除时其网格移出区域；区域仍指向已不存在的网格时，检视面板列出 **缺失网格**，导出跳过它们并写入导出报告。

@@ blend-mode | 混合模式
混合模式决定图形网格的颜色如何与下方已绘制的内容合成，常用来做阴影和高光。选中图形网格，在 **检视面板** 的 **混合模式** 中选择：
| 模式 | 效果 |
|---|---|
| 通常 | 正常覆盖 |
| 乘算 | 与下方颜色相乘，用于阴影 |
| 加算 | 与下方颜色相加，用于发光、高光 |
PSD 图层的混合模式在导入时自动转换：线性减淡（添加）等相加类模式和线性光转为加算；正片叠底、线性加深、颜色加深转为乘算；其他模式按通常处理。
*> 只想给图形网格着色而不改变合成方式时，用检视面板的 **正片叠底色** 与 **屏幕色**，见 [[multiply-color-screen-color]]。

@@ interior-shape | 内部造型
大块的衣服、头发在转身时只有轮廓在动，看起来会像一张纸。内部造型让图层内部的纹理随一个虚拟曲面收放和偏压，转动时产生体积感；它自动生成所需的关键形，导出为标准的融合变形与物理设置。它不生成新纹理或阴影，也不是布料模拟。
## 使用
1. 选择一个已生成的图层，在「修改器」面板的 **添加** 菜单中选 **内部造型**。它成为该网格栈里的一张卡片。
2. 卡片标题上的开关启用或停用它；启用后程序生成内部造型。
3. 在 **造型** 中调整横向 / 纵向幅度、曲面鼓起、偏压、褶皱强度与轮廓保持；需要局部褶皱时在 **局部褶皱** 中点 + 添加。
4. 需要运动带缓动时，展开 **缓动与传动**，设置缓动时间、传递时间、传动强度和 **传动方向**。
5. 在卡片的 **试动** 中拖动二维参数盘或开启 **鼠标跟随** 检查效果；卡片菜单的 **独显并居中** 只显示此图层并在画布居中，**在画布上编辑** 进入内部造型手柄。
每次拖动结束提交一条历史；生成失败时保留草稿和之前的有效结果。
## 设置
| 设置 | 范围 | 含义 |
|---|---|---|
| 横向 / 纵向幅度 | 0–2 | 两个方向各自的造型总量 |
| 曲面鼓起 / 偏压 | 0–2 | 虚拟拱面及其偏压程度；任一为 0 时没有曲面位移 |
| 褶皱强度 | 0–2 | 局部褶皱的贡献；没有局部褶皱时不生效 |
| 轮廓保持 | 0–1 | 0 释放可见轮廓，1 保护原图轮廓 |
| 缓动时间 | 0–0.6 秒 | 第一阶段的响应时间 |
| 传递时间 | 0–0.5 秒 | 后区相对前区的传播时间 |
| 传动强度 | 0–1 | 后区权重，0 不分区 |
**更多设置** 中的横向 / 纵向鼠标倍率只影响鼠标试动，不改变关键形幅度或导出的参数范围；**驱动参数** 可以选已有参数或 **新建参数**。
## 注意事项
- 关闭卡片的开关会保留设置但不应用形变；卡片菜单的 **删除** 移除配方及其物理，可以撤销。
- 网格、素材或驱动参数变化后，卡片提示重新生成或重新绑定；失效的效果在导出时跳过，并在警告中列出。
- 缓动使用工程的物理组，导出为标准物理设置。

@@ modifiers | 修改器
「修改器」面板按 Live2D 实际的计算顺序显示选中的对象：先是它自己的关键形，再依次是每一层父变形器（从里到外）。每一层叫一个 **阶段**，阶段的顺序就是层级树里的嵌套顺序，要改顺序请在层级树里改父子关系。
## 物体页
- 每个阶段一行：名称、由谁生成（头部转向、眼睛、摆动……，或 **手工**）、作用于它的卡片数。选中对象自己的阶段默认展开，其余折叠；工具条的 **仅有贡献** 隐藏没有其他内容作用的阶段。
- 展开一个阶段，先看到它的关键形来自哪些生成器与手工编辑（参数列表），然后是作用于它的卡片：修改器、模拟、内部造型、摆动。卡片按执行顺序排列，后面的读前面的结果；卡片可以展开设置、开关、上下移动、应用为关键形或删除。
- 阶段行的箭头按钮选中那个变形器，**+** 往这个阶段添加；工具条的 **添加** 加到选中对象自己的阶段。网格自己的阶段还可以添加 **模拟 · 布料 / 头发** 与 **内部造型**。
- 模拟卡片含烘焙、材质、输入、输出、胶水、顶点权重组与对比（参考模拟开关）；内部造型卡片含试动与全部造型设置；摆动卡片含方向、预设、支点与每个方向的形状和摆锤。
## 镜像
- 只做参数的一侧，另一侧由镜像得到：例如角度 X 只做正向，负向自动对称；改正向，负向跟着变。
- 选项：**参数** 选要镜像的参数（新建时默认取已打键的双侧参数，优先角度 X），**保留的一侧** 选正向或负向，**来源** 可选另一个网格或 Warp（如左眼到右眼），此时在整个范围上取来源的位移。
- **镜像线 x** 是镜像所沿的竖线位置（画布 x），新建时取目标的中心。
- 镜像的是变形场，不是顶点：左右不对称的网格、左右眼顶点不同也可以用。
- **输出方式**：**并入网格关键形**，或 **专用 Warp**（在网格与父级之间插入一个只在修改器参数上打键的 Warp，网格自己的关键形不会成倍增加）；**自动** 在关键形会成倍增加时用专用 Warp。

## 跟随表面、斜角修正、立体转向
- **跟随表面**：线稿、阴影、高光、饰品随它所画在其上的网格（**宿主**，新建时默认取下面最贴合的图层）一起动，宿主有什么关键形，它就跟着动，不必重复打键。**强度** 1 为完全跟随。
- **斜角修正**：只在 X、Y 两轴上分别做了形状时，斜角姿势（两者同时取值）常常塌陷。它让斜角等于两轴各自效果之和；**强度** 大于 1 再往外推。
- **立体转向**：把对象当作中心前方一定 **深度** 的立体，随参数（默认角度 X / Y）转动并按透视投影：在前面的移得多，远侧变窄。**隆起** 让中间凸出，**角度** 是参数到端点时的转角，**观察距离** 越近透视越强。

## 角色组件
自动生成的头部转向、眼睛、眉毛、嘴巴、身体姿态、呼吸、头发各是一个角色组件。选中网格时，生成了它所在各阶段的组件以卡片列在阶段之前；「世界」页的 **角色组件** 节列出模型的全部组件。
- 卡片标题上的开关关闭组件：它的参数不再带动它生成的任何内容，变形器与已有编辑保留。头部转向关闭后，眼睛等对角度 X 的反应也随之停止。
- **数值**：原「Rig 数值」中属于该组件的各项，常用项在前，**高级** 中是其余。眼睛与眉毛可勾选 **左右分开**，此时闭眼弧深、闭眼眼角、闭眼睫毛厚度与眉毛升降对左右各给一个值。
- 组件自己的设置：头部的幅度与五官位移变形器，身体的幅度，嘴巴的唇线描边、嘴形、线宽与颜色，眼睛的待机眨眼、透过刘海与果冻眼，眉毛的透过刘海，头发的摆锤。
- **成员**：组件认出的图层及其角色与左右；改角色就是改该图层的语义标签。点名称选中图层。
- **参数**：组件生成的参数。

## 世界页
- **角色组件**：模型的全部组件卡片。
- **模拟**：全部物理体及其烘焙状态，**烘焙全部** 与 **自动烘焙**；点一行选中它的网格并切到物体页。
- **问题**：所有卡片的问题（缺参数、关键形过多、超出容差、内部造型需要重新生成），点一行跳到对应对象。
- **模型预设**：见 [[model-presets]]。
!> 模拟只读取栈中排在它前面的内容；前面的卡片改变后，它的烘焙显示 **已过期**。

@@ deformer-folder | 变形器
@@ deformer | 关于变形器
变形器包住图形网格和其他变形器，自己随参数改变形状，里面的一切就跟着动。导入 PSD 后，PSD2Live 已经按图层分类搭好了一整套变形器（身体、头部、面部、头发等），多数时候你是在这套结构上微调，而不是从零搭建。
## 两种变形器
| 种类 | 怎样变形 | 常用在 |
|---|---|---|
| 网格变形器（Warp） | 用一张控制点网格包住子对象，移动控制点让内部平滑弯曲 | 脸的转向、身体弯曲、头发摆动 |
| 旋转变形器（Rotation） | 绕原点整体旋转（可带缩放），子对象保持刚性 | 手臂、脖子、饰物等绕关节转动的部件 |

- 生成的结构有哪些：[[auto-generation-of-deformer]]。

@@ making-and-placement-of-warp-deformer | 弯曲变形器
当生成的结构里没有合适的变形器——比如想让一个饰品、一缕头发单独弯曲——就自己加一个网格变形器。PSD2Live 直接在画布上拖框创建，拖出的预览框就是最终的网格。
## 创建
1. 在层级树或画布上选中要放进变形器的画元；多选时它们必须挂在同一个父变形器下。
2. 在物体模式左侧工具栏最后一组选「创建 Warp」（{key:TOOL_CREATE_WARP}）。也可以从画布右键菜单「创建」，或层级树右键的「父级 · 网格」「子级 · 网格」进入。
3. 在画布上拖出矩形，拖动时滚动滚轮调整转换分割。只想贴合所选对象时，直接点「按选区创建」。
4. 在左下角的放置面板里核对挂载位置、插入部件和尺寸策略；拖框内部移动，拖角点或边中点缩放。
5. 点模式条上的「创建」或按 {key:FINISH_PATH} 写入工程，「取消」或 {key:CANCEL} 放弃。
{tutorial=CREATE_DEFORMER}
| 放置选项 | 内容 |
|---|---|
| 挂载位置 | 设为所选对象的父 / 设为所选变形器的子（空格子）/ 指定父变形器 |
| 插入部件 | 新变形器放进哪个部件，默认继承选区部件 |
| 尺寸策略 | 贴合选区（+5% 外扩）/ 含关键形状包络 / 与选区中心对齐 |
| 连续创建 | 创建后继续放置下一个 |
*> 不同于 Cubism 的创建对话框，名称和分割不在创建前填写：分割在拖框时用滚轮定，默认值在「工具细节」面板和模型预设中设置。放置框只能移动和缩放，不能旋转。
## 编辑级别：顶点与贝塞尔
选中网格变形器进入变形模式后，模式条上有「顶点」和「贝塞尔」两级（{key:PICK_OPTION_1} / {key:PICK_OPTION_2}）。顶点级别逐点编辑网格；贝塞尔级别只拖青色锚点和琥珀色手柄，用少量控制点弯曲整张网格，此时详细网格变淡、不可编辑。检视面板里可设置「贝塞尔分割数」、「重置贝塞尔控制点」，以及「变形器转换(3.2方法)」。
{tutorial=DEFORM_MODE}

@@ making-and-rotation-of-rotationdeformer | 旋转变形器
手臂、脖子、垂饰这类绕一个点转动的部件，用旋转变形器最省事：它只有原点、角度和缩放，参数取任意值都是精确的刚体旋转，不会像网格那样在中间值变形。
## 创建
1. 选中要旋转的画元或变形器。
2. 在物体模式工具栏选「创建旋转」（{key:TOOL_CREATE_ROTATION}），或从画布右键菜单「创建」、层级树右键「父级 · 旋转」进入。
3. 在画布上从旋转中心向方向端点拖动，一次拖动同时定下原点和朝向；按住 Shift 以 15° 吸附。
4. 新变形器作为所选对象的直接父级插入，原来的父级保留。画布高亮将要改挂的对象，放置面板显示会影响多少变形器和画元。
5. 按 {key:FINISH_PATH} 或点「创建」确认，{key:CANCEL} 取消。
{tutorial=CREATE_DEFORMER}
## 调整
在变形模式中拖原点平移、拖端点旋转；Shift 吸附角度，Alt + 拖端点调整比例。旋转变形器不接受变形笔刷，请用移动、旋转或缩放工具。
*> 手柄方向沿用 Cubism 的约定：0° 朝上，顺时针为正，所以导出后在 Cubism Editor 里看到的角度一致。
四肢、尾巴和翅膀的旋转变形器通常不必手工创建，骨骼会自动生成，见 [[skeleton]]。

@@ system-of-parent-child-relation | 父子结构的机制
对象挂在哪个变形器下，就跟着哪个变形器走：父级先变形，子对象被整体带着移动，子对象自己的关键形再叠加在上面。理解这一点，才能分清一个形状是“自己动的”还是“被带着动的”。
## 继承规则
- 网格变形器下的对象：整个形状随父级网格一起弯曲。
- 网格变形器套网格变形器：子变形器的控制点被父级变换，内部再按自己的网格插值。
- 网格变形器下的旋转变形器：只继承原点位置和角度，父级的弯曲传不下去。
- 旋转变形器下的对象：随原点刚性转动。
## 编辑时分清两种运动
对象直接绑定的参数决定它自己的形状，父级参数则通过层级传下来。改形状前先看清是要改对象自己的轴，还是其实应该去改父级——否则容易把父级带来的姿态误当成对象自身的绑定。层级树中的「父级」徽章会标出所选对象的祖先。
相关：[[setting-of-parent-child-relation]] · [[combintion-of-parent-child-relation]] · [[keyform-parent-chilid-relation]]

@@ setting-of-parent-child-relation | 父子结构设置
要换父级，在层级树里拖一下就行；新建变形器时也能当场决定它插在谁的上面或下面。
## 在层级树中改父级
1. 在层级树中按住画元或变形器的行。
2. 拖到目标变形器上松开，即挂到它下面；拖到「拖到此处移到顶层」区域则移到根级。
3. 改父级是一步历史，可撤销。
{tutorial=HIERARCHY}
!> 把透明图片拖到层级树上是导入图层，不是改父级。
## 插入变形器时设定
- 层级树右键「父级 · 网格」「子级 · 网格」「父级 · 旋转」在所选对象上方或下方插入新变形器；删除变形器时它的子级上移一层。
- 创建 Warp 时，放置面板的「挂载位置」可选设为所选对象的父、设为所选变形器的子（空格子），或指定父变形器，见 [[making-and-placement-of-warp-deformer]]。
*> 在生成的模型上改了父级，之后改模型预设、骨架等触发重新生成时，你的改动会按三方合并保留，见 [[update-generated-rig]]。

@@ combintion-of-parent-child-relation | 父子结构的组合
把复杂的动作拆成几层简单运动，是变形器结构的核心思路：外层管大的转向，内层管局部的弯曲或旋转，每层只绑定自己需要的参数，下层自动继承上层的运动。
## 生成模型里的分层
PSD2Live 生成的身体就是这样叠起来的（以层级树中的实际结构为准）：
1. `DeformBodyXY`：身体 X / Y，整个上半身转向、随髋部移动。
2. `DeformBodyLean`：身体前后倾与大小变（头身比）。
3. `DeformBodyZBreath`：身体 Z 与呼吸。
4. 再往下是头部旋转与面部经纬网，然后是五官与头发。
所以转头时头部会同时被身体的转向带着走，不需要在头上重复做身体的运动。启用骨架后，躯干弯曲和四肢旋转变形器接在这条链的末端，见 [[skeleton]]。
## 搭建时的经验
- 粗网格的上层变形器会重新采样下层的形状，精细的弯曲放在离网格最近的一层。
- 需要跟着弯曲的部件挂在网格变形器下；挂在旋转变形器下只会继承原点和角度。

@@ auto-generation-of-deformer | 变形器的自动生成
导入 PSD 时，PSD2Live 按图层分类一次生成整套变形器、参数和关键形，模型立即能动。你的工作从“搭结构”变成“调结构”。
## 生成了什么
- 身体链：身体 X / Y、前后倾、身体 Z 与呼吸；站立全身角色另有腿部变形器。
- 头部：头部旋转与头壳跟随、面部经纬网、脸部轮廓和五官位移，见 [[face-auto-edit]]。

2. 你在生成结果上做过的编辑会合并到新结果上保留。
3. 想用上新版本生成器的改进时，用「模型 → 更新生成结果」，见 [[update-generated-rig]]。
*> 手工创建网格变形器时，「按选区创建」和放置面板的尺寸策略也会按所选对象自动定大小。

@@ parameter | 关于参数
参数是驱动模型的数值滑块，比如角度 X、眼睛开合。对象在参数的几个键上各记一个形状（关键形），参数取中间值时自动插值；动画、物理和面部追踪最终都只是在改参数值。导入后生成的模型已带一整套参数，拖一拖参数面板就能检查效果。
## 参数面板
| 操作 | 方法 |
|---|---|
| 改数值 | 左键拖动滑条 |
| 吸附到键 | 悬停键标记后右键单击 |
| 二维控制 | 两个参数关联后显示为 2D pad：左键拖动，右键吸附到两个参数的键交点 |
| 复位 / 锁定 | 行内复位与锁定按钮；工具栏「全部复位」「全部解锁」 |
| 查找 | 搜索名称或 ID；「仅关联」只看绑定到选中组件的参数 |
| 改定义 | 单击参数名打开「参数属性」，见 [[parameter-modifyication]] |
{tutorial=PARAMETERS}
## 读懂键标记
- 圆点是普通键，键与键之间插值；方点是融合变形键，把形状差叠加到基础形状上，见 [[blend-shape]]。
- 悬停键标记会列出在该键上有关键形的组件。
- 带物理图标的参数是物理输出，预览时由物理接管。
!> 参数上的键是建模数据，和动画时间线上的关键帧不是一回事。
*> 多个画布标签共用同一份参数姿态，在一个画布里调的值，其他画布同样看得到。

@@ edit-parameters | 向参数追加/删除键
在 PSD2Live 里，键的位置属于参数本身，所有绑定该参数的对象共用同一组键；对象在某个键上被修改时，形状就记到这个键上。
*> Cubism 是选中对象后按“追加 2 点 / 3 点”给这个对象加键；这里改为在「参数属性」里统一编辑参数的关键点，对象靠“在键上变形”来绑定。
## 增删和移动键
1. 在参数面板单击参数名，打开「参数属性」。
2. 在「关键点」轴上点空白处加点、拖动调值；点数字可直接输入，回车确认；右键删除。
3. 「步长」决定拖动时的吸附间隔，「均分」把关键点均匀排开；轴两端可直接输入最小值、默认值、最大值。
4. 用「撤销点编辑」「恢复点编辑」回退，点「保存」一次提交。
!> 移动键时，已有关键形随键一起移动；删除键会同时删掉各对象在这个键上的形状（可撤销）。
## 让对象在键上有形状
1. 选中对象。
2. 在参数面板把参数拖到目标键（或右键吸附到键）。
3. 切到变形模式（{key:MODE_DEFORM}）修改形状，结果写进这个键的关键形。
新建的参数本身不产生运动，要在键上给对象做了形状才会动。

@@ parameter-modifyication | 参数调整
参数的名称、范围和键在「参数属性」里修改；参数多了以后，用文件夹和 2D 关联把参数面板整理清楚。
## 修改定义
1. 在参数面板单击参数名，打开「参数属性」。
2. 改「名称」；ID 只在新建时可编辑。
3. 在「关键点」轴两端修改最小值、默认值、最大值，默认值必须在范围内。
4. 点「保存」，这是一步可撤销的历史。

@@ repeat | 循环
勾上参数的「循环」后，参数值越过最大值会从最小值接着走，越过最小值则从最大值接着走，适合转个不停的轮子、风车或循环摆动的尾巴。
## 设置
1. 在参数面板单击参数名，打开「参数属性」。
2. 勾选 **循环（超过最大值回到最小值）**，点「保存」。这是一步可撤销的历史；只有普通参数可以设，混合形参数不能。
## 效果
- 预览与运行时都把值绕回范围内。最大值与最小值是同一个姿态，两端的形状应当一致。
- 动作里这个参数的关键帧可以打到范围之外，最多 64 圈，用来做连续旋转，见 [[timeline-basic-operation-repeat]]。
- `moc3` 写入参数循环标志（Cubism 5.3 起的格式），`cmo3` 写入 `isRepeat`。
- 绕回与 Cubism 相同：正好超出整圈时，越过最大值落在最小值，低于最小值落在最大值。
- 物理的输入和动作的淡入淡出用的是绕回后的值，跨过两端时按另一端计算，可能与连续转动的预期不同。
- 导出到不支持循环的目标时，降级报告按动作逐条列出键值超出范围的曲线。
!> 导出到 Cubism 5.3 之前的 SDK 目标时，循环设置会被去掉并列在降级报告里，运行时会把超出范围的动作值截到两端。

@@ how-to-edit | 如何编辑
关键形都在变形模式里做：把参数调到某个键，再改对象的形状。对象还没绑定参数时，改的是它的基础形状；已绑定时，改的是当前参数组合上的关键形。
## 基本流程
1. 选中对象，切到变形模式（{key:MODE_DEFORM}）。
2. 在参数面板把参数调到目标键。
3. 用下表的工具修改形状；松开鼠标即进入历史，{key:UNDO} 撤销、{key:REDO} 重做。
{tutorial=DEFORM_MODE}
| 工具 | 快捷键 | 作用 |
|---|---|---|
| 变换 | {key:TOOL_TRANSFORM} | 用变换框移动、缩放、旋转所选点 |
| 推拉笔刷 | {key:TOOL_BRUSH} | 推动笔刷范围内的点，见 [[deform-brush]] |
| 平滑笔刷 | {key:TOOL_SMOOTH} | 把形状抹顺 |
| 膨胀/收缩 | {key:TOOL_INFLATE} | 向外膨胀或向内收缩 |

- 网格变形器可切换「顶点」「贝塞尔」编辑级别；旋转变形器拖原点、拖端点。
- 「工具细节」的「精确数值变换」用数值移动、缩放、旋转所选点，见 [[edit-vertices]]。
- 画布右键菜单「镜像关键形」把做好的一侧镜像过去，见 [[motion-mirroring]]。

@@ keyform-parent-chilid-relation | 关键点（父子结构的动作）
父变形器和子对象可以绑定同一个参数，各自在键上记形状；参数变化时，父级带来的整体运动和子对象自己的形状叠加成最终结果。这样大动作交给父级，子对象只需做小幅修正。
## 生成模型中的例子
角度 X 转头时，头部的变形器负责整个头的转向，面部经纬网和五官再各自按角度 X 修正形状——生成的模型就是这样分层绑定的。
## 编辑时注意
- 先看清对象直接绑定了哪些参数（参数面板「仅关联」），把它与父级通过层级带来的运动区分开。
- 在子对象上编辑的形状，以父级在当前姿态下的状态为基础。
- 镜像关键形只处理对象自身的形变，以默认姿势下的父级为坐标系；父级的关键形需要单独镜像。

@@ keyform-xydirection | 关键点（添加X和Y的移动）
对象同时绑定两个参数（如角度 X 和角度 Y）时，关键形排成一张网格：每个 X 键和每个 Y 键的组合各有一个形状，斜向的姿势由四周的键插值出来。生成的头部已经按角度 X / Y 的端点与中点组合做好九个姿势，斜角另有修正，强度在「头部转向」组件卡片的「数值」里调。
## 自己做一组 XY 形状
1. 在参数面板用行内关联按钮把两个参数关联成 2D 控制器，在 pad 上右键吸附到两个参数的键交点。
2. 在变形模式依次给各交点做形状：先做端点和中点，再做四个斜角。
3. 拖 pad 在键之间来回移动，检查插值是否自然。
{tutorial=PARAMETERS}
*> 四个斜角的形状需要逐个制作，PSD2Live 不会像 Cubism 那样自动合成。

@@ copy-and-blend-shape | 形状的编辑
在变形模式画布右键菜单的「关键形」里，可以把一个键的形状复制到另一个键或另一个同样的对象，把键重置回默认形状，或用两侧的键补间出中间的键。结果写成普通关键形，可撤销。
## 使用方法
1. 在变形模式选中对象，把参数调到对象的某个键上。
2. 在画布右键菜单「关键形」中选择操作，或使用下表的快捷键。
| 操作 | 快捷键 | 作用 |
|---|---|---|
| 复制关键形 | {key:KEYFORM_COPY} | 记下所选各对象在当前参数下的形状与不透明度、颜色等；之后来源再改也不影响粘贴 |
| 粘贴关键形 | {key:KEYFORM_PASTE} | 把复制的形状写到当前键：粘贴的是位移（网格相对原形、Warp 与旋转变形器相对默认键形状）；可写回原对象，或写给同类、三角形（Warp 为行列）相同且父级相同的对象 |
| 重置为默认键形状 | {key:KEYFORM_RESET} | 把当前键改回各参数取默认值时的形状 |
| 重置为网格原形 | — | 仅网格：把当前键改回未变形的网格 |
| 按（参数）的相邻键补间 | {key:KEYFORM_INTERPOLATE} | 用该参数两侧相邻键的形状按位置插值，重做当前键；有多个可补间的参数时菜单逐个列出（融合变形参数除外） |
- 选中了点时，粘贴、重置与补间只改选中的点，菜单行标出点数；Warp 在「贝塞尔」级别以及旋转变形器总是整体处理。
- 对象未绑定参数或参数不在它的键上时，菜单会说明原因，形状操作不可用。
- 在生成器拥有的关键形上改形状时记为生成结果覆盖，见 [[generated-overrides]]。
- 「按选项粘贴…」可只粘贴部分内容、按比例混合或翻转，并调整多个形状的粘贴对象，见 [[paste-form-special]] 与 [[confirm-target-for-pasting-multiple-forms]]；「全部键恢复为默认键形状」见 [[restore-deformer-shape]]，「多键编辑…」见 [[multi-key]]。

@@ paste-form-special | 形状的特殊粘贴
「按选项粘贴」只粘贴勾选的内容，也可以按比例混合或翻转后粘贴。
## 使用方法
1. 在变形模式选中对象，按 {key:KEYFORM_COPY} 或画布右键菜单「关键形 → 复制关键形」复制。
2. 把参数调到要写入的键，在「关键形」中选「按选项粘贴…」。
3. 在对话框中设定后点「粘贴」（或按 Enter）。
| 选项 | 作用 |
|---|---|
| 粘贴内容 | 形状（点）、不透明度、绘制顺序、正片叠底色、滤色，任意组合；不勾形状时，通道可粘贴给任何选中对象（绘制顺序只给网格） |
| 混合比例 | 100% 为直接粘贴；较小时当前键按该比例向复制的值靠近，即形状混合 |
| 翻转 | 左右翻转时 Warp 按列反转、上下翻转按行反转；网格按静止位置找镜像对应的顶点（静止形状须左右或上下对称，否则拒绝）；各点取对应点的位移并反向；旋转变形器的角度变化取反 |
*> 与 Cubism 不同：翻转作用于位移，不需要指定翻转轴，也没有 Warp 的「翻过来」选项；不对称的网格请用 [[motion-mirroring]]。对话框关闭后普通粘贴仍只粘贴形状。

@@ confirm-target-for-pasting-multiple-forms | 形状粘贴应用对象
同时复制多个对象的形状后，粘贴时每个形状写到哪个对象可以在「按选项粘贴」对话框里确认和调整。
## 程序怎样配对
- 复制时选中的每个网格各记一份形状（第一份是当前目标）。
- 粘贴时，来源对象自己也在当前选择中且参数在它的键上，就写回它自己；否则依次配给下一个尚未配对、且能接收该形状的选中对象：同类、三角形（Warp 为行列）相同、父级相同。
- 对话框「粘贴到」一栏逐行列出「来源 → 目标」，可改成其他合适的对象，或选「不粘贴」排除；不勾形状时可配给任何选中对象。
- 所有形状都按复制时的样子写入，A、B 互相粘贴时两者正好交换。
*> 普通粘贴（{key:KEYFORM_PASTE}）直接使用自动配对，不弹出对话框。

@@ face-auto-edit | 面部动作的自动生成
头部转向、眨眼、眼球、眉毛、嘴型与口型，在导入 PSD 时就已全部生成——不需要先手工做好上下左右的形状。你要做的是用数值调幅度，再对个别地方手动修形。
## 生成的内容
- 头部 X / Y：端点与中点组合成九个姿势，以原画的头部倾斜为基准，斜角另有修正。
- 面部用经纬网和分区修形；眼眉、瞳孔、嘴和耳朵各有独立的补偿或遮罩。
- 嘴：按嘴形设置生成开合与嘴型，可选生成上下唇描边。
- 眉毛透过刘海：被前发盖住的眉毛各复制一份，画在刘海之上、以半透明显示并剪切到刘海范围内，呈现动漫中眉毛透过头发的效果。复制件跟随原件的全部变形、形状与编辑，请编辑原件而不是复制件。眼睛透过刘海：刘海在眼白、虹膜与高光、睫毛等所有眼部图层范围内按比例变淡，整只眼睛透过头发显示；闭眼线与眉毛一样复制到刘海之上。新模型默认两者都开启；之前做的模型保持原样（眼睛关闭），打开开关后才有。
- 前后发与强面部形变分开，各自输出摆动参数。
## 调整幅度
1. 在「修改器」面板「世界」页的「角色组件」节打开「头部转向」卡片，调「五官位移变形器」开关与「头部幅度」；「身体姿态」卡片调「身体幅度」。
2. 在各组件卡片的「数值」中细调头部转向、眼睛、眉毛、嘴巴、头发各项（鼻子与耳朵在头部转向里）；不常用的项在「高级」里。
3. 修改后模型重新生成，你已有的手动编辑会合并保留。
## 手动修形
生成的面部关键形可以直接在变形模式里继续修改，方法见 [[how-to-edit]]。
!> 这是按预设算法生成的结果，不是 3D 重建。特殊的分层方式、宽发片、极端角度和重叠区域都可能需要手动修形。

@@ auto-generation-of-sway-motion | 摇摆运动的自动生成
头发、饰品、裙摆这类部件，选中后一步生成摆动：PSD2Live 在新参数的 -1 / 0 / 1 上自动做出摆动关键形，并同时生成物理摆锤，导出后就能随头部晃动。设置随工程保存，可以随时回来调整。
## 打开
- 物体模式下右键画布上选中的网格或网格变形器，选「生成摇摆...」；已生成的显示「编辑摇摆...」。层级树右键有同样的菜单。
- 物理面板「+ 新建」→「为选中对象创建摆动…」。
选中网格时会自动包一层贴合的网格变形器；旋转变形器不能作为目标。
## 编辑
1. 打开后画布进入摇摆编辑，左下角出现摇摆面板。
2. 在画布上拖手柄：尖端圆点设幅度和上翘，中心线菱形设柔软度，尖端两角设放大 / 缩小与平行，空心圆旋转整个摇摆矩形，空心方块改支点边。
3. 在面板中选摇摆方向（左右 / 上下，可同时勾选）、分段（1–3）、自动估计（发丝 / 饰品 / 布料），以及是否生成物理摆锤。
4. 「预览摆动」看效果；「生成」/「应用」或 Enter 写入，「取消」或 Esc 放弃。
*> 比起 Cubism 的同名功能，这里还能以网格为目标、做上下方向的摆动、分段，并用底部平行让多束头发一起摆。参数不存在时自动创建为 `ParamSwing<id>`，摆锤导出到 physics3.json 和 cmo3。
## 重新生成与烘焙
摇摆轴上的关键形归摇摆所有，每次重建都按目标当前的形状重新计算；你在这些关键形上的手动修改记为生成结果覆盖（见 [[generated-overrides]]）。想彻底手动接管时，点「应用为关键形」把当前形态写成普通关键形，只保留物理摆锤；「删除」会连同生成的轴和自动创建的参数一起移除。

@@ edit-vertices | 在画布坐标中编辑顶点
在 PSD2Live 里，拖动、变换框和笔刷总是作用于点在画布上显示的位置，不管对象挂在哪个变形器下，程序都会自动换算到父级的局部坐标——这是默认行为，不需要另外开启。需要精确数值时，用「精确数值变换」。

1. 在变形模式中选中要移动的点。
2. 打开「工具细节」面板的「精确数值变换」。
3. 输入移动量（画布像素）、缩放比例或旋转角度，点「应用」。
旋转和缩放以变换框的锚点为中心；目标是单个旋转变形器时以它的原点为中心。数值作用于所选点整体，不提供逐个顶点的坐标输入。
{tutorial=TOOL_DETAILS}
## 用变换框看数值
拖动变换框时，指针旁会显示旋转角度、缩放比例或移动的画布像素；拖动锚点可改变中心，靠近中心、角点或边中点时吸附。

@@ restore-deformer-shape | 恢复变形器形状
变形器（或网格）的关键形改乱了、想从头再来时，用「全部键恢复为默认键形状」把该对象的每个键都改回参数默认值处的形状，作为一步历史，可撤销。
## 使用方法
1. 在变形模式选中变形器或网格。
2. 画布右键菜单「关键形 → 全部键恢复为默认键形状」。
*> 与 Cubism 不同：不单独记录「原始形状」，恢复的基准是对象当前的默认键形状（通常就是第一次加键时的形状）；MCP 为 `keyform_apply op=reset all_keys=true`。

@@ glue | 胶水
两个部件在接缝处一动就裂开时，用胶水把两张网格的顶点粘在一起。胶水点是两张网格共享的同一个点，画布上显示为一个菱形，选中或拖动时两侧顶点总是一起移动。
## 创建
1. 在物体模式选中两张网格，切到编辑模式（{key:MODE_EDIT}）。
2. 选「Glue」胶合工具（{key:TOOL_GLUE}），下面有三个子工具：胶水刷、权重笔刷、重新合并（{key:PICK_OPTION_1}–{key:PICK_OPTION_3}）。
3. 在重叠处用胶水刷涂抹；或按 {key:FINISH_PATH} / 点模式条「创建胶水」，沿两条轮廓整段胶合。
{tutorial=EDIT_MODE}
## 操作
| 操作 | 效果 |
|---|---|
| 胶水刷 | 在重叠处让另一张网格新增或滑动一个顶点（UV 随之移动），只改网格不改画面 |
| Alt + 拖动 | 解除胶合 |
| 权重笔刷 | 以蓝色（A）/ 橙色（B）显示并绘制两侧的拉力权重 |
| 重新合并 | 去掉被刷顶点上已有的胶合，再按吸附容差重新胶合 |
| {key:GENERATE} | 胶合任一网格上选中的顶点 |
| 右键「按距离重新合并整段」 | 去掉两网格间的全部胶合，沿轮廓重新胶合 |
*> 两张网格不需要事先有对齐的顶点：胶水刷会在另一侧补出或滑动顶点，使两侧重合。
!> 胶合在静止形（所有参数为默认值）上进行。参数不在默认值时，胶水刷、重新合并和创建胶水会先把参数平滑移回默认值再胶合。
骨骼拆分的肢体和前后分层会自动生成胶水，一般不必手工处理。

@@ deformpath | 转换路径
变形路径（实验性）让你沿一个部件画一条曲线，拖动曲线上的控制点，网格就顺着曲线变形——适合长条的头发、丝带、尾巴。路径只是挂在一张网格上的编辑辅助，结果写成这张网格的普通关键形，它本身不是变形器。
## 创建与编辑
1. 选中画元，在层级树右键选「变形路径」，或按 {key:TOOL_CREATE_DEFORM_PATH}。
2. 在画元上单击放置至少两个控制点，按 {key:FINISH_PATH} 确认，{key:CANCEL} 取消。
3. 在编辑模式调整路径的绑定位置、影响宽度、硬度、闭合与角点，此时网格不动。
4. 在参数面板设好目标姿态，切到变形模式拖动控制点，形状写进画元的关键形。
路径分 L2 / L3 两组，各存一套，在放置面板或「工具细节」的「路径编辑层级」中选择；已有路径在检视面板的「编辑层级」里改。画布只显示当前组的路径。这两组与网格变形器的顶点 / 贝塞尔级别无关。
## 导出
`.cmo3` 保存路径控制器结构及网格关键形；`.moc3` 只保存烘焙后的网格关键形，运行时不执行路径算法。
!> 一张网格可以有多条路径，但一条路径不能控制多张网格。拖动效果尚未与 Cubism Editor 完全验证一致，宽度、硬度和大角度形变需要自己检查。

@@ skinning | 蒙皮
跨关节的一整张网格（比如没拆开的手臂、长袜）要随多根骨骼平滑弯曲，在 PSD2Live 里交给骨架：把网格绑定到骨骼，权重自动计算，导出时再烘焙成旋转变形器和网格的修正关键形。
## 绑定与权重
1. 在骨骼模式选「编辑骨骼」（{key:TOOL_SKELETON_EDIT}），用「绑定」子工具把网格绑定到骨骼；同一条肢体的网格只需绑定到其中一根。
2. 权重在整条肢体上自动计算：每个顶点最多跟随关节两侧的两根骨骼，在「关节带宽」内平滑过渡。
3. 需要修正时用「权重」子工具：选已绑定的网格和同一肢体内的骨骼，按增加、减少、替换、平滑绘制。
4. 「工具细节」中可清理、恢复自动权重，或把权重复制 / 镜像到另一张网格。
5. 摆姿态时打开「视图 ▾」里的「显示蒙皮权重」（也可用图钉固定到显示栏），按骨骼颜色检查关节处的过渡。
{tutorial=SKELETON}
关节带内的顶点按角度混合着绕关节旋转，弯曲时肢体宽度不变。
*> Cubism 的蒙皮会把网格直接转换成一串旋转变形器，之后在那串变形器上编辑；这里权重属于骨架，改了骨骼会重新烘焙。完整说明见 [[skeleton]]。

@@ skeleton | 骨骼
有身体、四肢、尾巴或翅膀要动时，骨骼是最快的绑定方式：程序按图层自动推断骨架并绑定网格，你调整关节、摆姿态，导出时它被烘焙成 Cubism 能直接运行的结构——躯干弯曲变形器、四肢的旋转变形器和跨关节网格的修正关键形。导出的模型不依赖本程序。
*> Cubism Editor 没有骨架对象，那边的肢体通常靠旋转变形器链和蒙皮手工搭建；这里的骨骼正是自动生成这些结构的工具。
## 创建骨架
1. 用模式菜单进入骨骼模式（{key:MODE_SKELETON}）。工程还没有骨架时，点画布中央或「骨骼」标签页的「创建骨架」。
2. 程序按图层标签和侧别推断骨骼并绑定：手臂绑同侧的 handwear，腿绑 legwear，脚绑 footwear，尾巴、翅膀绑各自的图层。
3. 用「编辑骨骼」（{key:TOOL_SKELETON_EDIT}）调整：「编辑」拖动关节，「新骨骼」「挤出」添加骨骼，「绑定」批量绑定网格，「权重」修正蒙皮（见 [[skinning]]）。
4. 「工具细节」中可复制、镜像、细分、融合骨骼；在「骨骼」标签页选中骨骼后可调「关节带宽」与最小 / 最大角度。
5. 点「完成」保存为一条历史。切到骨骼姿态、换模式或选中别的图层也会保存，只有「取消」放弃本次修改。
{tutorial=SKELETON}
!> 左右画在同一图层的肢体不会被绑定，请先用「模型 → 按网格拆分图层…」拆开再绑定。
## 摆姿态
在「骨骼姿态」（{key:TOOL_SKELETON_POSE}）中，拖动骨骼身体为 FK，只转这一根；拖动末端或按住 Shift 拖动为 IK。「工具细节」可设置 IK 链长、迭代与弯曲方向，并「固定所选骨骼末端」。摆姿态只改参数值，不产生历史；「重置姿态」全部归零。好的姿态可以按名称保存，之后再次应用或插入动画。
## 生成的结构与参数
| 内容 | 说明 |
|---|---|
| 躯干弯曲 | `DeformSkelTorso`，上下半身绕腰弯曲 |
| 四肢、尾巴、翅膀 | 旋转变形器 `DeformSkel_<骨骼 ID>` |
| 骨骼参数 | `ParamArmLA`、`ParamLegLA`、`ParamTail1..n` 等，单位为度 |
| 姿势参数 | 下蹲、重心转移、甩尾、扇翅、膝盖内扣、弹起 |
骨架能播放的动作会出现在动画面板中，见 [[builtin-motions]]。「骨骼」标签页底部的「骨骼参数采样」设置容差、最小角度间隔和单网格关键形上限，用来控制导出体积。
## 导出须知
- 能相加的四肢参数在导出目标为 Cubism 5.0 及以上时写成融合变形参数；目标低于 5.0 时全部烘焙为普通关键形，旋转变形器上的姿势会被去掉。
- Cubism Editor 中不保留骨骼本身，之后还要改骨骼时请保留 `.psd2live` 工程。
相关：[[making-and-rotation-of-rotationdeformer]] · [[blend-shape]]

@@ generated-overrides | 生成结果覆盖
摇摆、模拟、骨骼这类生成器的关键形，每次重建都会重新计算。你在这些关键形上动过的手，不会被重建冲掉：它们被记为“生成结果覆盖”，在所有生成器运行之后与新结果合并。所以你可以放心地在生成结果上修形，之后照样调整摇摆、骨架或模型预设。
## 哪些编辑会成为覆盖
- 摇摆在目标网格变形器上生成的关键形（摇摆参数不在默认值时）。
- 已烘焙的模拟以关键形轴写回网格的关键形。
- 骨骼蒙皮写在你自己改挂过的网格上的关键形。
在生成参数的默认值处编辑，仍是普通编辑，改的是静止形状。
## 合并规则
| 情况 | 结果 |
|---|---|
| 你没改过的点 | 跟随新的生成结果 |
| 生成器这次没变的点 | 保留你的值 |
| 两边都改了 | 保留你的值，并报告冲突 |
## 查看问题
有问题时，检视面板工具栏显示「n 项覆盖问题」徽标；选中对象的问题列在检视面板顶部的「生成结果覆盖」中，点徽标列出全部问题。
- 冲突：某些点同时被生成器和你的编辑修改，已保留你的编辑。
- 未生效：生成的关键形已不存在、生成的形状点数已改变，或网格已被拆分替换。
!> 复制到或复制自生成的关键形、在生成器的轴上增删键，都无法作为覆盖记录，会被拒绝。想完全手动编辑摇摆时，先在摇摆面板点「应用为关键形」。
相关：[[auto-generation-of-sway-motion]] · [[simulation]] · [[update-generated-rig]]

@@ multi-key | 多键编辑功能
一次修改多个对象、多个关键形的不透明度、绘制顺序、正片叠底色和滤色，例如把眨眼的所有键的睫毛绘制顺序一起提到刘海前面。
## 使用方法
1. 在变形模式选中要改的对象（可多选网格）。
2. 画布右键菜单「关键形 → 多键编辑…」。
3. 「编辑范围」按参数列出各键值，点掉不需要的值缩小范围；下方显示将修改的关键形数。
4. 勾选要改的内容并设定数值，选择方式后点「应用」。
| 方式 | 作用 |
|---|---|
| 覆盖 | 每个关键形直接改为该值 |
| 相加 | 在每个关键形原有值上加上该值 |
| 相乘 | 与原有值相乘（绘制顺序只能覆盖或相加） |
| 滤色 | 1 −（1 − 原值）×（1 − 该值），常用于颜色 |
- 结果作为一步历史提交。改的是通道关键形，写成普通关键形，不经过生成结果覆盖；每个通道只在它自己已有的轴上写入，尚无轨道时才按对象的形状键写入。
*> 变形器没有绘制顺序；对话框里选了变形器时不能改绘制顺序。MCP 为 `keyform_apply op=multi_key`。

@@ motion-mirroring | 动作镜像
左右对称的动作只做一边：做好角度 X 30 的形状后镜像到 -30，或者把左眼的形状镜像给右眼。对称键和对侧对象由程序按参数和图层语义自动判断，结果写成普通关键形，可撤销。
## 使用方法
1. 在变形模式选中对象，把参数调到要镜像的键。
2. 在画布右键菜单「镜像关键形」中选择操作，或直接按 {key:MIRROR_KEYFORM} 镜像到对称键。
| 操作 | 作用 |
|---|---|
| 镜像到对称键 | 把当前键镜像到对称键，并切换到该键显示结果 |
| 从对称键镜像 | 用对称键的形状覆盖当前键 |
| 镜像到（对侧对象） | 写给另一侧的同类对象；带 L/R 的参数换成另一侧，左右参数取反 |
| 原位左右翻转 | 以对象自身中心翻转当前键 |
| 全部键镜像到另一侧 / 全部键镜像到（对侧对象） | 一次处理所有键 |
## 程序怎样判断对称
- 取反的左右参数：范围以默认值对称，且是二维关联的横轴，或 ID 以 X、Z 结尾（AngleX、BodyAngleX、EyeBallX 等）。
- 对侧对象：先按图层语义配对，再按名称中的 L/R、Left/Right、左/右配对。
- 只处理对象自身的形变，父级的关键形需要单独镜像；选中多个图层时分别镜像，在一条历史中提交。

@@ temporary-deform-tool | 临时变形工具
临时变形工具在选中的点（或整个对象）上铺一张一次性的网格，拖动网格点就能整体弯曲这些点，适合大块地调整形状；网格本身不保存。
## 使用方法
1. 在变形模式选中网格或 Warp（Warp 在「顶点」级别），可先选中要变形的点。
2. 按 {key:TEMPORARY_DEFORM} 或画布右键菜单「临时变形（网格）」。
3. 拖动网格点：其中的点按双线性插值跟随，每次松开记为一步历史。参数不在键上时，按下会先把参数吸附到键；参数、撤销或其他修改让形状变了时，按下会按当前形状重铺网格——这两种情况下这次按下不开始拖动，再按一次即可。
4. 工具栏「网格」可在 1×1 到 4×4 之间切换（会以当前形状重新铺网格）；按 Enter、{key:CANCEL} 或「完成」结束。
*> 与 Cubism 不同：只有临时网格（弯曲）一种模式；放大缩小、旋转等用变换工具 {key:TOOL_TRANSFORM}，路径式弯曲用变形路径。

笔尖在左侧工具栏的笔刷下方选，其余设置在左下角工具选项栏和画布右键菜单里。
*> 「仅相连项」适合分开刷靠得很近的部件，比如相邻的发丝、上下唇。

@@ blend-shape | 融合变形
融合变形参数把形状差叠加到对象已有的关键形上，而不是与其他参数的键相乘组合。几个参数各自独立作用时，用它能大幅减少关键形数量——骨骼和模拟正是靠它控制导出体积。
## 新建融合变形参数
1. 在参数面板新建参数，在「参数属性」中选「融合变形」（类型只能在新建时选，默认范围 0…1）。

3. 把参数调到其他键，在变形模式中修改网格或变形器，就记下了叠加形状。
骨骼和模拟会自动生成融合变形参数（骨骼参数、模拟的模态参数），见 [[skeleton]]、[[simulation]]。
!> 融合变形的编辑流程仍在完善：Cubism 的权重限制设置和限制曲线还没有提供，已有参数也不能改成融合变形。

@@ animation-preparation | 动画创建准备
模型生成好以后，它已经会待机、眨眼、点头和摇头；想让它做别的动作，就在同一个工程里直接做。动作保存在工程中，随撤销/重做和保存一起走，导出时自动写成 `motion3.json`。
## 动作从哪里来
- **内置动作**：生成模型时按模型预设自动做好，只需调几个滑块，见 [[builtin-motions]]。

1. 点工作区标签栏右侧的 **+**，选 **动画** 预设：动作列表在预览画布左侧，下方是动画编辑器，右侧是参数面板。
2. 在「动画」面板中单击动作行的编辑按钮（或右键选 **编辑**），动作在动画编辑器中打开。

*> 习惯 Cubism Animator 的话：这里没有场景和模型轨道，打开的动作直接驱动当前模型的参数。导出 CMO3 时动作另存为同名 `.can3`，可以在 Animator 中继续编辑。
@@ builtin-motions | 内置动作
内置动作让刚生成的模型马上就能动起来：待机、眨眼等常用动作由程序按模型生成，不用打一个关键帧，导出时与手做的动作一样写成 `motion3.json`。
## 有哪些动作
| 分组 | 动作 | 说明 |
|---|---|---|
| 基础动作 | 待机动画、眨眼动作、点头动作、摇头动作 | 任何模型都能播放；待机动画循环 |
| 骨骼动作 | 甩尾、下蹲、重心转移、害羞扭捏、挥手、歪头、开心欢呼、单脚翘、开心摇摆、少女待机 | 需要骨架，当前骨架做不到的动作不列出；少女待机循环 |
两组是否生成由模型预设「动作 (Motions)」组的 **基础动作**、**骨骼动作** 勾选框决定，见 [[model-presets]]。骨架的制作见 [[skeleton]]。
## 调整
1. 在「动画」面板的 **内置动作** 文件夹中，用每行左侧的勾选框决定该动作是否导出。
2. 单击动作行展开调节项。待机动画有 **摆动**、**呼吸**、**头部**、**速度** 和 **眨眼** 开关；眨眼动作有 **闭合程度**、**速度** 与 **连眨两次**；点头、摇头有 **幅度**、**速度**、**次数**。
3. 点行右侧的播放按钮，在预览画布中查看效果。
{tutorial=ANIMATION}
## 手动改关键帧之后
在动画编辑器里改过内置动作的关键帧，行上会标出 **已修改**，调节项随之停用，直到恢复默认。右键菜单里可以：
- **复制为自定义动作**：把当前内容另存为自定义动作，原内置动作不变。
- **恢复默认**：丢弃手动修改，回到调节项生成的结果。
- **删除**：不再导出；之后可从 **新建动作** 菜单的 **恢复已删除的预设** 找回。

@@ freeze | 冻结功能
冻结让一条轨道在播放和拖动播放头时保持一个固定值，方便单独检查其他参数的动作，比如先停住眨眼，再看头部转动。
## 操作
1. 把播放头移到想要的值所在的时间。
2. 点轨道行的冻结按钮（雪花），或单击轨道行后按 {key:MOTION_TOGGLE_FREEZE}。轨道按播放头处的值冻结：行上显示这个值，摄影表里这条轨道画上斜线，曲线视图画出冻结值的虚线。
3. 再点一次解除冻结。
冻结期间，这条轨道的关键帧不能选中、拖动或打帧，自动插帧也会跳过它；关键帧本身不变，导出的动作也不变。冻结按动作分别记录，随工程保存，不进历史。
*> 冻结只作用于动画编辑器里打开的动作；通过 MCP 直接改关键帧不受冻结限制。
@@ timeline-basic-operation-repeat | 参数循环动画
给设了 [[repeat]] 的参数做动作时，关键帧的值可以超出参数范围，用来做一直转下去的动作：例如范围 0–360 的车轮，0 秒打 0、1 秒打 720，就是一秒转两圈。
- 关键帧最多可以超出范围 64 圈；曲线视图在每一整圈的位置画一条虚线。
- 预览把值绕回范围内显示；导出的 `motion3.json` 保留原值，由运行时绕回。
- 在时间轴打帧（含自动打帧）时，写入离曲线当前值最近的那一圈，不会把 540 写成预览显示的 180。
- 循环的动作用 [[loop-editing-support]] 的首尾衔接时，这类参数的结尾沿转动方向落在下一个整圈（0→170 收在 360），转动不会倒回去；会超过 64 圈时报错，不做修改。
!> 关闭参数的循环或收窄范围后，超出范围的关键帧会被截到范围两端。

1. 单击左侧轨道行，只显示这一条曲线；点 **显示全部** 恢复所有曲线。
2. 拖动关键帧同时改时间和数值；只显示一条曲线时，在空白处双击即在该处添加关键帧。

## 插值
| 插值 | 效果 |
|---|---|
| 线性 | 两键之间匀速变化 |

@@ about-fade | 关于淡变
淡变决定运行时切换动作时有多平滑：新动作在淡入时间内逐渐生效，旧动作在淡出时间内逐渐退出，姿势不会突然跳变。

@@ notes-for-sdk | 嵌入SDK时的注意事项

| 动作 | 动作组 | 文件名 |
|---|---|---|

@@ loop-editing-support | 循环编辑辅助
做循环动作（待机、走路、转动）时，结尾要接回开头，否则每轮循环都会跳一下。动作打开 **循环** 后，时间轴帮你看清并修好接缝。
## 看接缝
- 标尺底部的色带标出循环区间（从 0 到结尾）；区间之外淡淡地画出前后两轮的曲线与关键帧，接缝处是否连贯一眼就能看出。

## 首尾衔接
工具栏的首尾衔接按钮（{key:MOTION_CLOSE_LOOP}）一次处理所有未冻结的轨道：在 0 与结尾补上关键帧，结尾取开头的值（[[repeat]] 参数沿转动方向取整圈），进入结尾的一段是贝塞尔时，结尾以开头离开的斜率进入，曲线在接缝处平滑相接。这是一步可撤销的历史。
*> 循环区间就是整个动作：`motion3.json` 不支持只循环其中一段。

@@ physics-operation | 关于物理模拟
物理让头发、饰品、衣物随头部和身体的动作惯性摆动。PSD2Live 用的是与 Cubism 相同的摆锤模型，计算逐项对应 Cubism Native Framework，所以编辑器里看到的摆动就是 SDK 里的摆动。
## 机制
- **输入**：头部、身体角度等参数推动摆锤根部（位置X），或倾斜重力方向（角度）。
- **摆锤**：从根部垂下的一串摆锤，按长度、摇摆度、反应速度、收敛速度运动。
- **输出**：某个摆锤的摆角乘以倍率，写入输出参数。
物理只改参数值，摇摆的形状来自输出参数上的关键形；输出参数没做好端点形状时，参数在动，模型却不动。
## 物理组从哪里来
大多数物理组不用手建：前发、后发和果冻眼来自模型预设，骨骼、摆动和模拟烘焙也会生成各自的组，也可以手动新建。管理方法见 [[physics-group-information]]。
@@ physical-operation-setting | 如何设置物理模拟
在「物理」面板选中一个物理组，下方依次是摆锤画布、响应曲线、摆锤设置、输入、输出与高级设置。最快的调法是直接在摆锤画布上拖，看响应曲线和最大输出力判断效果。
## 摆锤画布
| 操作 | 作用 |
|---|---|
| 在空白处左右拖动 | 牵动模型，松开后回到原位 |
| 上下拖动摆锤末端的圆环 | 调整该摆锤长度；单击选中它 |
| 把右侧输出标签拖到某个摆锤旁 | 改为读取该摆锤的角度（摆锤数） |
| 单击输出标签 | 显示范围扇形，拖动扇形边缘调整倍率 |
摆锤下方的响应曲线显示向右牵动 1 秒后松开的反应，不同设置的过冲与收敛可以直接对比。
{tutorial=PHYSICS}
## 设置项
1. **预置**：选一个预置后点 **导入**，替换全部摆锤；**追加…** 把当前摆锤存为自己的预置。
2. **编辑摆锤**：选 **全部** 或某个编号，决定下方滑块作用于哪个摆锤；可追加、删除和上下移动摆锤。
3. 滑块：**总长 / 长度**、**摇摆度**、**反应速度**、**收敛速度**，与 Cubism Editor 同名同义。
4. **输入**：用 **添加** 加入参数，选择 **位置X** 或 **角度**，设置 **影响度** 与反转。
5. **输出**：设置 **摆锤数**、**倍率** 与反转。**最大输出力** 显示输出达到参数端点的百分比，**按最大值调整倍率** 把它调到 100%。
6. **高级**：摆锤设置表、输出细节与 **输入标准化**。
每次拖动或输入在松手后记一条历史。
*> 输出只有角度类型：位置X 类型的输出在 Cubism 运行时中始终为 0。

@@ simulation | 布料与头发模拟
裙摆、外套下摆和长发用几根摆锤很难做出布料感。模拟在编辑器里对网格做真正的 2D 布料与头发模拟，再把结果**烘焙**成 Cubism 能播放的参数、关键形和摆锤，导出的模型在任何 Cubism 运行时里都能动。
## 先用模型预设
模型预设「物理与模拟 (Physics & Simulation)」组能一步生成常见部件的模拟：前发、后发的下拉框改为 **模拟**，或勾选 **服装**，程序会建好物理体、写好权重并在后台烘焙。之后都能在目标网格的模拟卡片（「修改器」面板）里继续调整，见 [[model-presets]]。
{tutorial=SIMULATION}
## 手动建一个物理体
1. 在画布上选中裙子或头发的网格，在「修改器」面板的 **添加** 菜单选 **模拟 · 布料** 或 **模拟 · 头发**。一个物理体中的多张网格一起模拟，它成为这些网格栈里的一张模拟卡片。
2. 指定固定点：切到画布的「模拟」模式（{key:MODE_SIMULATE}），用 **权重笔刷** 或 **权重渐变** 绘制固定点；与腰部相连的胶水也可以在 **胶水** 节设为 **作为固定点**，见 [[glue]]。
3. 在卡片的 **对比** 节打开 **参考模拟**，转头、摇身体，在 **材质** 节换预设或微调数值，直到摆得自然。
4. 点卡片 **烘焙** 节的 **烘焙**，或「世界」页 **模拟** 节的 **烘焙全部**。烘焙在后台进行，通常需要数秒，完成后作为一步撤销提交。
5. 关掉 **参考模拟**，回到 **导出效果**：画布播放的就是导出模型的动作，可与参考模拟对比。
## 顶点权重组
权重组告诉模拟哪里固定、哪里更硬或更重。它只存在于本软件，不写入导出文件。
| 种类 | 作用 |
|---|---|
| 固定点 | 被 Rig 牵住的顶点；1 完全跟随绑定，0 完全交给模拟 |
| 刚度 | 逐顶点缩放拉伸与弯曲刚度，做出根部硬、下摆软 |
| 保形 | 逐顶点缩放向原画形状的回弹，托住外张的裙摆、翘起的发梢 |
| 质量 | 逐顶点缩放质量，越重滞后与过冲越明显 |
| 阻尼 | 逐顶点缩放运动衰减，抑制边角抖动 |
## 材质、输入与烘焙
- **材质**：布料有棉布、丝绸、雪纺、羊毛、牛仔布、皮革、弹力布，头发有头发、细软发、粗硬发；选好后各项仍可微调。
- **输入**：让物体晃动的参数，新建时自动填入头部和身体角度等；列表为空时无法烘焙。
- **烘焙**：**模态数**（1–3，默认 2）决定生成几个参数，**关键点** 决定每个参数上的关键形数，**夸张** 放大摆动且不需要重新烘焙。烘焙后显示 R² 与误差。
- 烘焙出的摆锤出现在「物理」面板，来源为「模拟」；参数出现在参数面板，名为 `ParamSim…`。
!> 改了设置、网格、权重或栈中排在它前面的内容后，烘焙显示 **已过期**，导出仍用旧结果，直到重新烘焙。参考模拟本身不会导出。

@@ facial-expression-system | 表情的机制
表情是一组参数值，宿主在动作之上叠加它，例如在待机动作播放的同时切到“笑”。SDK 读取导出的 `exp3.json`，每个参数按混合方式与动作给出的值合成：
| 混合方式 | 结果 |
|---|---|
| 加算（Add） | 动作的值 + 表情值 |
| 乘算（Multiply） | 动作的值 × 表情值 |
| 覆盖（Overwrite） | 表情值，忽略动作 |
切换表情时，新表情在淡入时间内渐入、旧表情在淡出时间内渐出，不需要为每种心情单独做动作。
## 标准表情
生成的模型自带四个标准表情（微笑、悲伤、生气、惊讶，名称随界面语言），由模型已有的嘴形、眼睛开合与眉毛参数组成，缺少的参数自动略去；导入的 CMO3 模型不带标准表情。第一次修改表情列表（新建、删除、改动任何一个）时，标准表情会作为普通表情收进工程，此后只导出工程里的表情；在表情右键菜单选 **恢复标准表情** 可回到自动生成的那一组。
## 参数被删除或改范围时
删除参数时，表情里该参数的条目一并删除；缩小参数范围时，覆盖方式的值收进新范围。
@@ create-facial-expressions | 在动画视图中创建表情
表情直接从参数状态做出来：先在参数面板或画布上把脸摆成想要的样子，再存成表情。
## 从当前参数新建
1. 在参数面板调好表情（眼睛、眉毛、嘴等）。预览中正在播放动作时，取的是面板当前显示的值。
2. 在「动画」面板工具栏点 **+**，选 **从当前参数新建表情**。
3. 与默认值不同的参数都成为加算条目，值为与默认值之差，与在 Cubism 动画视图中做表情的起点一致。
## 其他新建方式
- **从快照新建表情**：用参数面板快照栏里保存的参数快照的值，表情名取快照名。
- **新建空表情**：没有参数的表情，可作为宿主重置到的“无表情”。
- 已有表情右键选 **用当前参数更新**，用当前参数重新生成全部条目。
## 试看
点表情行右侧的眼睛图标（或右键 **套用到参数试看**），表情按混合方式套到当前参数上，可在画布与预览中直接看到效果；这只改变预览参数，不进历史。
@@ setting-and-exporting-facial-expressions | 设置和输出表情
每个表情的条目、混合方式与淡入淡出都在「动画」面板的 **表情** 分区里设置，导出时自动写出。
## 设置
1. 点表情行展开设置。
2. **淡入时间**、**淡出时间**：切换到与离开这个表情所用的秒数（默认 0.5）。
3. 每个条目一行：参数名、混合方式按钮（加算 / 乘算 / 覆盖）、值、移除。改混合方式而不改值时，值会换算成在参数默认值处得到同样结果。
4. **添加参数** 加入一个尚未设置的参数。
5. 右键菜单可重命名、复制、上移 / 下移、删除。表情的顺序就是 `model3.json` 中的顺序。
每次修改记为一条历史，可撤销，随工程保存。
## 导出
- 导出 moc3 时，每个表情写成 `<名称>.<表情 ID>.exp3.json`（`Type`、`FadeInTime`、`FadeOutTime`、`Parameters`），并在 `model3.json` 的 `Expressions` 中按名称引用。模型里已不存在的参数会被跳过；没有条目的表情照样写出。
- VTube Studio 包为每个表情加一个切换表情的热键。
- PSD2Live 运行时模型（`.p2lrt`）与网页播放器同样带上表情。
- `.cmo3` / `.can3` 不保存表情，导出报告会注明；要交给 SDK 使用，请导出 moc3。
*> 仅网格导出不写表情与姿势。
@@ userdata-event-information | 确认用户数据和Event信息
「动画」面板底部的 **用户数据与 Event** 分区集中列出宿主能从模型收到的全部文本：每个动作的 Event（动作名、时刻、值）与每个 ArtMesh 的用户数据（网格名、值）。
- 点一条 Event 打开该动作并把播放头移到那一刻。
- Event 在自定义动作的设置里编辑，网格用户数据在检视面板编辑，见 [[userdata]]。
- 导出后，Event 在各动作 `motion3.json` 的 `UserData` 中，网格用户数据在 `userdata3.json` 中。
