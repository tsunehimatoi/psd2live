### 새 기능

- **영역별 리그 모듈**: 자동 생성 리그를 눈, 눈썹, 입, 머리, 머리카락, 몸, 의상, 표정, 모션 영역으로 나누고, 영역마다 기본 방식을 고르고 모듈을 더합니다. 새 프로젝트는 적용 가능한 모든 모듈을 켠 모던 구성이며 프리셋과 비용 예산이 있습니다.
- **그려진 눈과 눈썹에 맞춤**: 눈꺼풀은 흰자 윤곽과 감은 눈 선에서 만들어지며 머리를 기울이거나 돌려도 얼굴을 따라 감깁니다. 눈썹은 호를 따라 돌며 윗눈꺼풀을 움직이고, 앞머리가 눈썹을 가리면 눈꺼풀이 감정을 표현합니다.
- **단계적으로 열리는 입**: 위아래 입술 가장자리를 따라 단계적으로 열리며 모음, 얼굴 캡처, 턱, 입술 다물기 / 벌리기를 지원합니다. 레이어로 나눈 입(입술, 입술선, 이, 입 안)도 지원하며, 이와 혀는 입술과 함께 움직이고 그림보다 더 크게 벌려 외칠 수 있습니다.
- **깊이 있는 머리 회전**: 머리를 원기둥처럼 돌리며 이목구비, 앞머리, 뒷머리, 귀가 각자의 깊이에 있습니다. 끝까지 돌리면 먼 쪽 옆머리가 얼굴 뒤로 넘어갑니다.
- **머리카락·의상·몸의 사슬 흔들림**: 머리카락이 진자 사슬처럼 마디별로 흔들리고, 치마, 리본, 펜던트, 동물 귀, 꼬리, 날개도 사슬로 흔들립니다. 가슴 흔들림, 팔 흔들기, 목이 머리 기울기를 나눠 맡습니다.
- **표정과 자연스러운 동작**: 홍조·우울 감정 파라미터, 더 풍부한 표준 표정(수줍음, 졸림, 우울 추가), 자연스러운 눈 깜빡임과 시선, 모듈 리그에 맞춘 VTube Studio 매핑.
- **특징점 도구**: `Shift+Y`로 캔버스에 눈·눈썹·입 핸들을 표시하고, 드래그해 다시 맞추면 모든 포즈가 따라가며, Alt 클릭으로 원래대로 돌아갑니다.

### 개선

## v3.6.5 · 2026-10-23

### 새로운 기능

- **페인트 선택 영역과 새 도구**: 선택 도구(`Alt+L`)에 사각형, 원형, 올가미, 다각형 올가미, 자동 선택이 있으며 추가·빼기·교차, 페더, 반전을 지원합니다. 브러시, 채우기, 그라데이션은 선택 영역 안에만 적용됩니다. 그라데이션, 흐림 브러시, 불연속 채우기, 손떨림 보정, 좌우 대칭, 투명도 잠금도 추가했습니다.
- **수동 포인트 배치**: 편집 모드의 포인트 배치(`Alt+M`)로 클릭하거나 스트로크를 따라 점을 추가하고, 드래그로 이동하고, Shift 클릭으로 선을 연결하고, Alt 클릭으로 점이나 변을 삭제할 수 있습니다. 좌우 대칭도 지원합니다. 토폴로지 메뉴에 변 삭제와 다시 삼각화를 추가했습니다.
- **내부 형태 캔버스 핸들**: `Shift+I`로 캔버스에서 부풀기, 편향, 전달 방향을 드래그하고 주름 가이드선을 직접 그려 편집할 수 있으며 패널 수치와 동기화됩니다.
- **키폼 도구**: 디폼 모드의 키폼 메뉴에서 복사한 형태를 다른 키나 오브젝트에 붙여넣고(블렌드 비율, 반전), 기본 형태로 복원하고, 인접한 키 사이를 보간하고, 여러 키를 동시에 편집할 수 있습니다. `Shift+T` 임시 래티스는 선택한 점을 한꺼번에 움직입니다.
- **캔버스 보조**: 그리드, 눈금자 안내선(스냅 가능, 프로젝트에 저장), 어니언 스킨, 랜덤 포즈. 전환은 캔버스 오른쪽 아래에 있습니다.
- **복사·붙여넣기와 일괄 이름 변경**: 오브젝트 모드에서 `Ctrl+C` / `Ctrl+V`로 메시, 디포머, 파츠, 파라미터를 복사합니다. 메시 토폴로지를 다른 레이어에 복제하고, 이름이나 ID로 찾아 바꾸고, ID를 일괄 변환하면 모든 참조가 함께 갱신됩니다.
- **표정, 포즈, 이벤트**: 애니메이션 패널에서 현재 파라미터로 표정을 만들고(가산 / 곱셈 / 덮어쓰기, 페이드 인·아웃), 한 번에 하나만 표시되는 포즈 그룹을 설정하고, 모션에 이벤트를 놓을 수 있습니다. exp3, pose3, 모션 UserData를 내보내며 생성된 모델에는 미소, 슬픔, 화남, 놀람 네 가지 표정이 기본으로 들어갑니다.
- **히트 영역**: 검사기나 계층에서 HitArea를 설정하고 미리보기에서 클릭해 적중을 확인할 수 있습니다. 내보낼 때 model3와 VTube Studio 패키지에 기록합니다.
- **타임라인 보조와 루프**: 파라미터 북마크, 샤이, 고정, 마커, 모션 궤적. 한 번에 처음과 끝을 이어 붙이고, 파라미터를 루프로 설정해 계속 회전시키는 등의 동작을 만들 수 있습니다.
- **앞머리 너머의 눈썹**: 자동 생성할 때 앞머리에 가려진 눈썹을 앞머리 위에 반투명으로 표시합니다. 불투명도를 조절할 수 있고 끌 수도 있습니다.

### 개선

- **편집기와 에이전트 동시 편집**: 작업 공간은 런타임을 유일한 기준으로 삼으며, 편집기의 미확정 변경은 에이전트의 커밋과 충돌하는 필드만 양보하고 나머지는 그대로 커밋됩니다. 저장되는 것은 실제 상태입니다.
- **스크린 혼합**: PSD의 스크린 레이어는 Cubism 5.3에서는 Screen으로, 이전 버전에서는 가산으로 근사해 내보내며 손실 보고서에 기록합니다. 색상, 불투명도, 그리기 순서의 생성 결과 덮어쓰기도 유지됩니다.
- **창 모드**: 설정 → 표시에서 창, 최대화, 전체 화면을 고르고 기억합니다. `F11` 또는 「보기 → 전체 화면」으로 전환하며, 최대화해도 작업 표시줄을 가리지 않습니다.
- **새 외관**: 패널이 창 배경 위의 둥근 카드가 되고 간격이 좁아졌습니다. 제목 표시줄 메뉴, 드롭다운, 우클릭 메뉴가 같은 반투명 메뉴 스타일로 통일되었습니다.

### 수정

- 자동 생성된 입술선을 그리면 입 레이어와 입 설정에서 만들어진다고 안내하며 「원본 레이어를 찾을 수 없음」을 표시하지 않습니다. 파라미터 이름 우클릭으로 선택한 메시나 디포머와의 연결을 해제할 수 있습니다(#55).
- 저장된 창 크기가 화면 작업 영역 안으로 제한되어 제목 표시줄이 화면 밖으로 나가지 않습니다.
- 큰 캔버스에서 메시에 디포머 추가, 본 이동, 루트 메시 전체 압축 시 잘못된 붕괴나 재생성 충돌을 보고하지 않습니다(#56, #59).

### 호환성

- 표정, 포즈, 히트 영역이 들어 있는 프로젝트는 이전 버전에서 열리지 않으며, 데이터가 조용히 사라지지 않습니다.
- 오래된 프로젝트의 스크린 레이어는 다시 열면 일반 혼합 대신 스크린(또는 가산)으로 내보냅니다.

## v3.6.0 · 2026-10-20

### 새로운 기능

- **도움말이 매뉴얼과 튜토리얼로**: Cubism 매뉴얼·튜토리얼 사이트의 구성에 맞춰 재배치하고, 각 페이지에 Cubism과의 관계를 표시해 해당 페이지로 연결하며 끝에 관련 MCP 작업을 나열합니다.
- **참조가 계층의 구성원으로**: 배경·레이어 안·전경 세 가지 참조를 여러 개 유지할 수 있고, 잠금, 키폼 고정, 불투명도 연속 조절, Alt+R 표시 전환을 지원합니다. 참조 이미지와 ArtMesh는 서로 변환할 수 있습니다.
- **텍스처 구조를 따라 재배치**: 텍스처에 그려진 주름, 명암 경계, 무늬 선을 따라 메시 내부를 다시 만들고 키폼, 경로, 가중치, Glue는 그대로 이전합니다.
- **키폼 미러**: 포인트/디폼 메뉴에서 현재 키를 대칭 키, 반대쪽 오브젝트, 제자리 좌우 반전으로 미러할 수 있고 Shift+M으로 대칭 키에 한 번에 미러합니다.
- **놓은 위치가 정하는 드롭**: 마우스를 놓은 위치가 동작을 결정하며(매터리얼, 계층 삽입, 레이어 배치, 참조, 이미지 교체, 라이브러리에만 가져오기), CMO3를 놓으면 바로 열립니다.
- **매터리얼과 CMO3**: 모든 레이어에 해당 매터리얼이 있고 연결이 조용히 끊기지 않습니다. 가져온 CMO3는 현재 레이어로 텍스처 아틀라스를 다시 묶습니다.
- **기록 트리 압축**: 연속된 선형 버전을 카드 하나로 합치고, 도구 모음에서 노드별 보기로 되돌릴 수 있습니다. 카드를 더블 클릭하면 그 구간의 마지막 단계로 체크아웃합니다.

### 개선

- **생성 전에 편집**: 아직 생성되지 않은 Layout 프로젝트에서도 일반 프로젝트처럼 메시, 디포머, 파라미터, 계층을 편집하고 바로 내보낼 수 있습니다.
- **더 부드럽게**: 편집 캔버스를 따로 그려 파라미터 드래그와 포즈를 표시하지 않는 패널이 매 프레임 재구성되지 않습니다. PSD 가져오기 준비는 백그라운드에서 합니다(#50).
- **매터리얼 패널**: 사용 수를 표시하고, 호버하면 사용 중인 레이어를 나열하며, 오른쪽 클릭으로 태그 편집, 기본 참조 레이어 설정, 사용 레이어 선택을 할 수 있습니다.

### 개선

- **긴 머리가 고개 기울임에 따라 휨**: 턱 아래의 머리카락이 고개를 기울이면 점차 되돌아오며(새 조정 "긴 머리 기울임 유지", 기본값 80%), 다발째 튀어나가지 않습니다.
- **참조 이미지와 클로즈업**: 소재를 참조 이미지로 편집 캔버스에 겹칠 수 있으며 생성과 내보내기에는 포함되지 않습니다. 참조 이미지에서 클로즈업 소재를 잘라낼 수 있습니다.
- **페인트가 메시 범위에 제한되지 않음**: 캔버스 전체에 그릴 수 있으며, 메시 밖의 부분은 적용 시 새 레이어가 됩니다.
- **오른쪽 클릭 메뉴와 드롭다운 통일**: 모든 패널의 메뉴가 같은 모양과 애니메이션으로 클릭한 곳에서 열립니다.
- 편집기의 "선택" 모드 이름이 "오브젝트" 모드로 바뀌었습니다.
