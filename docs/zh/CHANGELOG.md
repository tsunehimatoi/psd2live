## v3.5.0 · 2026-10-15

### 新功能

- **开始、帮助与设置成为页面**：帮助中心与设置不再是弹窗，和开始页一样是标签栏最前面的页面（`F1` / `Ctrl+,` 打开，再按一次回到工作区）。三个页面的面板改用编辑器的停靠框架，可拖动重新停靠、合并成标签、浮动或关闭，布局保存在本机，「重置布局」可复原。三个页面都是目录加内容，开始页另有详情面板；「重置布局」移入「窗口」菜单；设置的「缩放与显示」按检查器的分组重排，合并了原「环境信息」。开始页的最近 PSD 位于生成视口下方，排版工程的常用尺寸、宽高与预览合在一个面板；从 CMO3 导入的详情列出保留内容，并可直接「用 CMO3 替换」当前模型。功能更新改为按版本列出的文字说明，详情面板可按版本跳转，有教程的条目可直接打开教程。关于页的版本号改由构建写入。
- **设置新增「文件与数据」与「MCP」**：「文件与数据」可清空最近文件、打开上次导出的文件夹，查看安装位置、工作区存储、下载的运行时、超分缓存、错误日志与命令行 MCP 存储的位置和大小，清空超分缓存与日志，清理异常退出留下的临时文件，并显示偏好设置的保存位置；原「工具 → MCP…」对话框移入设置的「MCP」。「文件 → 打开文件夹」可打开工程、源文件、输出所在的文件夹，以及工作区存储和应用数据文件夹。
- **标题栏菜单整理**：菜单为文件、视图、模型、帮助。「工具」改为「模型」，汇集作用于整个模型的操作（重新分析 PSD、用 CMO3 替换、按网格拆分图层、纹理高清化、更新生成结果）；「文件 → 导入」改为「文件 → 新建」；开始页只保留在「文件」菜单；「视图」中的界面缩放比例与字体大小移交设置页。设置改为标题栏右侧的齿轮，位于语言与明暗主题旁；明暗主题按钮改用侧栏开关的颜色。「帮助」菜单只剩两项：「帮助」打开帮助页，「在线资源」打开 GitHub 仓库、文档、示例仓库、版本发布与问题反馈。帮助页新增「示例」（示例仓库的内容与用法、投稿入口）与「第三方许可」（所用组件、许可与用途），图层规范补充素材准备、前后发与左右的说明，链接、关于页的文字随之更新。
- **开始工作区**：开始不再是导入后的弹窗，而是工作区标签栏最左侧固定的「开始」页，启动时显示，打开或新建工程后自动切走，随时可点回。布局与编辑器的面板一致，分隔条可拖动调整大小：左侧导航（打开工程 / 最近 / 从 PSD 生成 / 排版工程 / 从 CMO3 导入 / 快速上手 / 功能更新），打开时位于「最近」（还没有最近文件时位于「从 PSD 生成」），像素材面板一样列出最近的文件；排版工程带 NEW 标记，中间是内容，右侧属性面板设置将要发生的事，底部操作栏放醒目的主按钮（Enter 也可触发）。一键生成仍是一步：导入 PSD 前在属性面板选好预设，之后拖入窗口任意位置，或在最近的 PSD 胶片条中双击，即按它生成并进入编辑；单击则在视口中预览。工程打开后「开始」标签以动画收起，可从「文件 / 工具 → 开始页」再次打开。排版工程按比例预览画布尺寸，常用尺寸双击直接创建。最近文件可按网格或列表查看、筛选，并显示缩略图、修改时间与大小；工程保存时会在文件中附带一张缩略图，PSD 读取其内嵌缩略图或合成图。原先画在空画布上的内容移到这里，空画布只留一行提示和「前往开始」。按网格拆分图层改为「工具 → 按网格拆分图层…」。
- **无窗口 MCP**：`psd2live mcp` 不再在后台建起整个编辑器界面，工作区由应用层宿主直接承载；没有窗口时 `view_sample_motion` 也能采样动作（此前会等到超时），启动时打印 `capabilities` 说明是否可用。
- **剥离部件（MCP）**：`material_peel` 用一张去掉了某个部件的生成图把部件从图上剥下来，得到部件和它下面的图，部件之外保留原像素，叠回去就是原图；`material_set_placement` 让外部生成的高清图取特写的位置；`keep` 用部件上的点去掉生成模型顺手改动的碎点，`compare_scale` 让在较小尺寸生成后放大的图按生成尺寸比较。`mcp_proxy.py` 可直接从命令行或 Python 脚本调用操作。配套的 ComfyUI 工具见 `tools/comfy`。
- **素材库**：新增素材面板，可导入图片、PSD、CMO3 中的分层图片和 SVG，按文件夹整理、加标签、预览，并把文件夹导出为 PSD；素材随工程保存，修改可撤销。导入的 PSD 图层也会出现在素材库中。
- **先摆放、再生成**：开始页的「排版」模式（或「文件 > 导入 > 新建 Layout 工程」）从空画布开始，把素材拖到画布上摆放后再生成 Rig；生成后继续加图、改标签，点「重新生成」并入，已有的关键形、变形器、物理、骨骼等编辑保留。新增 Layout 工作区与「素材与摆放」教程。
- **语义标签**：图层表的「类型 / 部件 / 侧别」改为标签，可组合部位与左右，也可加自己的标签；差分单独一栏。
- **用素材替换图片**：替换后图层在画布上的位置和大小不变。
- **素材窗口**：双击素材在独立窗口中查看，可缩放平移，用画笔、铅笔、橡皮擦、油漆桶和吸管直接修改，或翻转、调色相饱和度明度对比度；已放置的图层同步更新。素材面板保留精简文件夹树，分栏宽度可拖动；PSD / CMO3 导入的文件夹显示为对应的文件图标和项目数；可把素材拖到文件夹、树或路径栏上移动。
- **素材窗口直接使用绘画模式**：工具栏、选项栏、绘画会话栏、右键菜单、笔尖显示与快捷键都与画布的绘画模式相同，笔画即时显示；应用后作为一步历史写入素材，绘画期间可照常编辑别的内容。
- **素材是关联图层的唯一来源**：在绘画模式里画从素材放置的图层就是画素材，所有用它的图层一起更新；图层表用链环标记关联的图层，可解除关联让图层独立。
- **素材树**：树中显示文件夹里的图片，可拖到画布、双击打开；树的右键菜单可新建文件夹、导入。单击素材立即选中。右键菜单不再显示说明文字。
- **下拉菜单动效统一**：浮动栏的下拉菜单（如「生成」选项）与模式菜单一样逐行出现、高亮随指针滑动。
- **右键菜单统一**：各面板的右键菜单与画布右键菜单外观和动画一致，从点击处展开；物体模式画布菜单的创建类操作统一收入「创建」二级菜单；画布菜单新增「网格」（重建网格、拆分独立网格、前后分层）和「素材」（在素材窗口中打开、解除关联）二级菜单。

### 改进

- **长发歪头时弯曲**：下巴以下的头发在 Angle Z 歪头时逐渐反向转回（新调参「长发歪头保持」，默认 80%），长侧发和后发不再整束甩出、露出身体下面的部分。
- **参考图与特写**：素材可设为参考图叠在编辑画布上（右键菜单设置、调整不透明度、清除；画布右下显示开关可隐藏），它不是图层，不参与生成与导出；可从参考图按画布区域无损裁出特写素材并导出为 PNG，放置时落回原位。编辑画布新增「纹理密度」热力图，按图层每画布单位的纹理像素着色。MCP 新增 `layout_set_reference`、`material_crop`、`material_export_png`，`view_render_model` 可叠加参考图、显示差值与纹理密度；`./gradlew run --args=mcp` 可不开窗口单独启动 MCP 服务。
- **矢量绘制部件**：MCP 新增 `material_draw`，以画布坐标的 SVG 绘制部件，按指定的纹理密度渲染，重画时已放置的图层随之更新和移动；`layout_set_drawing_kit` 设定所有绘制共用的颜色、线条样式与渐变，修改后全部部件一起更新；SVG 支持类样式规则、套件颜色变量与两头收细的线条（`data-taper`）。新增 `reference_sample`（参考图取色与主色）、`reference_trace`（魔棒取轮廓，返回可直接使用的路径）、`reference_snap`（把点吸到线条上）；`view_render_model` 可画带坐标的网格，并把绘制的轮廓描在参考图上对照。
- 素材面板新增「导入文件夹」，嵌套的子文件夹按原结构成为素材文件夹，文件按名称中的数字顺序排列，跳过隐藏文件与文件夹。
- 放置 PSD 素材时，PSD 画布整体居中映射到工程画布（比工程画布大时等比缩小），不再按 PSD 坐标原样放到左上；新建 Layout 工程页说明画布单位的含义：决定模型大小与比例，清晰度由素材像素和纹理集预算决定。
- 绘画不再受网格范围限制：整张画布都可以画，应用时网格外的部分自动拆成原图层正上方的新图层（同时出现在素材库中），原图层的网格与绑定不变；应用时不再弹出「重建网格」对话框。
- 编辑器的「选择」模式改名为「物体」模式。
- 修改已生成图层的分类不再立即重新生成，改为在下一次「重新生成」时一并生效。

## v3.4.5 · 2026-10-13

### 修复

- **保存与恢复**：完善保存、关闭与崩溃恢复的状态协调，恢复检查点保留完整工程状态，连续姿势编辑按顺序提交。
- **保留导入源文件**：工程保留导入时的 PSD / CMO3 原始内容，后续读取不再依赖外部源文件。

- **独立网格检查**：检查失败会显示错误；超过 60 秒会停止，关闭检查后迟到的结果不再重新弹出对话框。内存不足和调用栈溢出也有明确提示。

### 改进

- **示例素材独立分发**：示例素材、工程和输出迁移到[独立示例仓库](https://github.com/tsunehimatoi/psd2live-examples)，可按需下载；主仓库保留说明与固定版本清单，并欢迎投稿。

## v3.4.4 · 2026-10-13

### 修复

- **保存与关闭更可靠**：修复长时间编辑后无法保存或关闭的问题；保存期间继续编辑会保留未保存状态，放弃修改与崩溃恢复保持一致。
- **撤销与重做**：先提交正在输入的字段再切换历史，修复连续编辑时历史状态不一致的问题。

- **导出与动作**：导出失败时恢复上一套文件，重新导出较短的帧序列会清理旧尾帧；修复 GIF 帧时长、贝塞尔动作裁剪及部分运行时和 Web 导出问题。
- **稳定性**：加强损坏文件的检查，修复清除用户数据、预览异常恢复和后台任务取消的问题，减少 MCP 连接日志噪声。

## v3.4.1 · 2026-10-11

### 改进

- **自动骨架更准确**：自动骨架沿网格形状识别肢体。尾巴和翅膀在持续分叉处分支（如鱼尾、双尾），每个分支各有骨骼，主干沿较粗的分支走；身体框架取自实际网格，忽略空的模板图层；肩膀落在手臂末端，隐藏的髋部按脊柱对称补出；肩、髋、肘、膝的位置与比例按人体结构校正。
- **下载文件统一命名**：发布附件统一为 `PSD2Live-<版本>-<系统>-<架构>[-<类型>][-ffmpeg]`，安装包带 `setup`，架构统一为 `x64` / `arm64`（例如 `PSD2Live-3.4.1-windows-x64-setup.exe`、`PSD2Live-3.4.1-linux-x64.deb`）。

## v3.4.0 · 2026-10-11

### 新增

- **柔性骨骼**：柔性骨链沿经过各关节的曲线平滑弯曲蒙皮，适用于尾巴、触手、鳍、飘带等，卷起时相互接触的部分不会粘在一起；骨链可以分叉，各分支分别弯曲。“拉直”把画出的弯曲网格展开，使参数为 0 时是直的，原来画的形状保存为一个姿势。被三个及以上关节弯曲的网格烘焙为按关节分层的 Warp，弯曲时保持长度。旧工程中的尾巴骨链打开时自动转为柔性骨骼。
- **Linux tar.gz 包**：发布新增解压即可运行的 tar.gz（amd64 与 arm64，自带 Java 运行时，内容与 Deb 相同），适用于没有 Deb 的发行版。
- **导出对话框的 can3 选项**：导出 CMO3 时可勾选是否同时导出 Cubism Animator 工程（.can3）。

### 改进

- **骨骼编辑重新整理**：骨骼树只列出骨骼，所选骨骼的名称、关节、IK、变换与对称轴集中在检查器中，各模式一致；角度限制以扇形、混合带以括号、对称轴以可拖动的线直接在画布上编辑，精确数值收在“高级”里，也可在画布控柄旁直接输入。骨架编辑、姿势工具和对象模式使用同一套骨骼选择与点击判定。
- **骨骼外形区分种类**：柔性骨骼画成等宽矩形，躯干更粗，锚点为无尾关节的菱形，固定的 IK 末端带圆点；颜色按骨骼角色固定，添加骨骼不再让其他骨骼变色。
- **IK 显示更清楚**：画布上显示 IK 可转动的骨骼链、起始枢轴和固定弯曲方向的箭头，带发光、方向箭头、关节环和末端准星，检查器中有图例。
- **从源码运行无需 Rust**：没有可用 cargo 时自动下载 CI 用同一份源码构建的运行时库（校验 sha256，失败时改用编辑器求值器）。

### 修复

- **moc3 导出的混合形**：Warp 下没有关键形的网格（例如布料烘焙后的裙子）带混合形时，导出的模型在参数离开中立位后网格不再飞出画布（#29）。
- **快速撤销不再丢步**：撤销、重做完成前编辑器保持忙碌状态，连续按撤销不再丢掉其中一次。
- **删除拆分出的部件**不再报“Generation layer has no current artwork”。
- **拆分过的工程重新打开后保持原修订**。
- **旋转变形器**：只设置部分原点、角度或缩放的关键形不再被丢弃；MCP 创建旋转变形器默认保持姿势，网格不再跳出画布；Warp 下旋转变形器的原点按画布像素换算，导出的 moc3 不再与编辑器相差数像素。
- **缩小参数范围**时动作关键帧随之收进范围，删除参数时一并删除其动作曲线，动作保持可编辑。
- **调整设置滑块时提交姿势**不再冲突，滑块不再弹回。

## v3.3.1 · 2026-10-10

### 新增

- **崩溃后恢复未保存的编辑**：程序崩溃或内存不足被关闭后，下次启动会询问是否恢复上次未保存的编辑；恢复后作为未保存的工程打开，保存即可保留。
- **旧版本合并结果的修复提示**：工程中有旧版本合并、新版本会合并成不同结构的生成结果（可能表现为弯曲小臂时手臂脱离肩膀、网格不随上身转动）时，编辑画布顶部给出提示，可直接“更新生成结果”或“预览变化”；修复后之后的编辑都会保留。MCP `workspace_inspect` 的再生成检查同样列出这些位置（`REGENERATION_REPAIR_AVAILABLE`）。
- **历史面板“回到最新”**：一键检出最新版本并滚动到它。

### 改进

- **参数名称不再被截断**：参数面板的名称列默认更宽，分隔线常态下也淡淡可见。
- **物理预设按组记忆**：预设选择从当前组设置对应的预设开始，每组各自记住所选预设。
- **窗口记住大小**：窗口在上次关闭时的大小与最大化状态下居中打开。
- **导出进度**：导出尚未报告进度时进度条显示为不确定状态，而不是停在 0。
- **内存占用**：程序按本机内存的一半设置上限，不再固定占用 8 GB；`gradlew run` 时 Gradle 自身也只占 4 GB。
- **工程更小**：保存时不再带上 MCP 工具渲染的视图图片（此前可能有数百张、几十 MB）；旧工程照常打开。
- **GIF 颜色更准**：每个动作按自身画面生成调色板，并默认开启抖动（导出设置 `dither` 可关闭），不再出现偏色与色块。
- **纹理预算提示（MCP）**：换成更高密度的图片后超出纹理页预算或被降低密度时，`atlas_get`、纹理编辑结果和批量编辑都会提示，并给出 `atlas_pack`、`atlas_set_budget` 的处理方法。

### 改进

- **改生成设置不再混入改写**：同一次编辑既改生成设置（或分类）又改写较早的 Rig 编辑时会被拒绝并提示分开提交，而不是把旧编辑悄悄重放到新的生成结果上。
- **拆分后部件继续跟随生成**：拆分图层（连通块、多边形、前后分层）时，部件在原层的位置参与自动生成，你在原层上做的关键形、路径、权重与胶水带到部件上；之后改脸部设置、站姿、骨架或分类，部件也会更新。拆分不再因个别条件退回旧格式。
- **改生成设置与分类更稳**：修改脸部特征、嘴型、头身强度、图层分类等生成设置时，新的生成结果与你已有的编辑直接合并并固定保存，不再在每次打开时重新推演，旧编辑不会因为生成规则变化而失效。
- **长编辑历史不再变慢**：编辑生成的模型时，模型每隔一段（第一次编辑、之后每 32 步）自动固定保存一次，之后的提交、撤销、重做、拖动只在最近的固定点之后重算，与历史长短无关，也不再为此重新生成整个基础模型；模拟烘焙同样不再等待基础模型生成。这样编辑过的工程会以新的修订格式保存，旧版本程序无法打开。
- **旧工程只重算一次**：较早版本保存的、带旧拆分记录或生成迁移记录的工程照常打开；第一次编辑时当前模型被固定保存下来，此后不再按旧记录重放，打开与编辑更快、更稳定。旧拆分的部件作为你自己的网格保留。

- **绘画笔刷按部件自身像素计**：笔刷、铅笔、橡皮和形状的 px 数按所画图层自己的像素计算，缩小显示的高分辨率图层上 16 px 的笔刷就是图层上的 16 个像素，最小可以画到单个像素。

- **模拟求解更快**：头发与布料模拟的弯曲约束每次只算一次角度，参考模拟、实时模拟与烘焙快约三分之一；运动结果与之前有细微差别，编辑器与 PSD2Live 运行时（含网页播放器）仍逐帧一致。
- **模拟起步更稳**：物体静止时的形状校准得更准（同样耗时，与画出的形状相差约为原来的三分之一到二分之一），参考模拟和实时预览重置后的轻微晃动从约 3–6 px 减到 1–1.5 px（裙子、上衣、长发），烘焙的训练数据里混入的这段晃动也随之减小。

### 修复

- **拆分或开启头发模拟之后创建的骨架能让手脚动起来**：在开始界面拆分了图层或开启了头发模拟的工程里，之后创建或修改骨架，骨骼虽然显示，但不会生成手臂和腿的参数，导出的模型与挥手、欢呼等动作里手脚都不动；现在骨架会正常烘焙进模型。设置里直接开关头发模拟等改动同理。在受影响版本中做过并保存的这类修改，打开工程后执行「工具 → 更新生成结果」即可补上。
- **骨骼自动胶水恢复**（v3.1.0 起失效）：把肢体拆成多段（例如腿与鞋分左右拆分、或袖子在肘部切开）再启用骨架时，接缝上的自动胶水（`GlueSkel__…`）消失，后拆分的部件也不再挂到骨骼下、不随骨骼转动。原因是第一次拆分之后，之后的拆分校验没有考虑拆分新生成的成对 Warp，被退回旧版拆分记录，而启用骨架时的合并又不会把骨架给旧版拆分部件的蒙皮与胶水带过去。两处都已修复：新的拆分照常写新版记录，带旧版拆分记录的工程启用骨架时部件也会蒙皮并自动上胶水。已在 v3.1.0–v3.1.2 中启用骨架的工程，撤销到启用骨架之前再重新启用即可恢复。
- **开启五官位移等生成设置之后创建的骨架不再让网格炸开**：在开始界面选「完整」预设（或之后改了五官位移、头部/身体强度等生成设置）的工程里再启用自动骨架，骨架不会蒙皮任何网格（欢呼等动作里手臂不抬起），而尾巴在尾巴摆动时会变成铺满整个画面的大三角形。原因是生成设置变化后网格挂到了生成变形器的改名副本下，启用骨架时的合并把每个网格都当成用户改过父级、保留原位，却又带上了骨架在骨骼空间里做的姿势混合形。现在合并按改名后的变形器对齐，网格正常蒙皮；保留用户父级的网格不再带入在别的父级空间里生成的混合形。已受影响的工程，撤销到启用骨架之前再重新启用即可。
- **导出帧中的「加算（发光）」**：按编辑器的 W3C 加算绘制，不再按 Cubism 旧式加算绘制。
- **快速切换动作不再跳变**：网页播放器和运行时中，上一个动作还在淡出时再切换动作，最早的那个动作会被直接丢掉，画面会突然跳一下；现在每个被替换的动作都会完整淡出。
- **多个角色不再同时眨眼**：同一程序里加载多个角色时，它们的眨眼时机以前完全相同，现在各自错开。
- **运行时出错不再让编辑器闪退**：PSD2Live 运行时（p2lrt）求值某个模型时若内部出错，以前会让整个程序直接退出；现在只是该模型停止响应：软件预览自动改用编辑器自己的求值器，运行时预览后端与导出报告出错原因，程序继续运行。接口不匹配的运行时库（例如经 `PSD2LIVE_RUNTIME` 指定的旧版本）不再被加载，改用编辑器求值器。

### 修复

- **在模拟与摆动参数上打键**：可以像 Cubism 中使用物理输出参数一样，让其他网格或 Warp 在模拟、摆动参数上打键，也可以改这些参数的名称和范围；此前会报「参数不在模型中」，部分操作（通道关键形、在默认值处新建轴、删除生成的键、在层级里改名）不报错但提交后结果丢失。用到的参数从此属于工程，删除对应的模拟或摆动后仍保留。
- **删除摆动所作用的 Warp**：摆动随之去掉这个目标，没有其他目标时连同它的参数和物理组一起移除，不再留下不带动任何东西的摆动；其他原因导致摆动失效时（例如重新生成后目标不存在），物理面板中该摆动的物理组下会显示原因。
- **生成关键形上的贝塞尔与 MCP 变形**：在摆动、模拟生成的关键形上用贝塞尔编辑或 MCP `rig_deform` 不再报错，与画笔变形一样作为生成结果覆盖保存；按住 Ctrl 保留子级、复制关键形、增删生成器的键无法保存为覆盖，现在编辑时直接说明原因，不再在提交后丢失。
- **改了生成设置后工程打不开或报错**：开启头发模拟、启用或调整骨架、拆分图层等会改变自动生成结果的操作，此前要把整条编辑历史在新的生成结果上重放，引用已不存在的变形器或顶点的编辑会让整个工程报错（例如“Art primitive parent is missing”“Vertex group has … weights for … vertices”）。现在这类操作把已有的编辑合并到新的生成结果上并作为数据保存，之后不再重放这些旧编辑；无法干净迁移的内容在质量报告中列出。包含这类保存点的工程需要本版本或更新版本才能打开。
- **打开工程更快**：保存时同时保存每个历史版本编辑后的模型，打开、撤销和切换历史时直接读取，不再重新生成与重放。
- **模拟网格上的变形报错**：网格加了模拟预设（或其他生成器添加的参数）后，在它上面用变形笔刷、贝塞尔等编辑会报「参数不在模型中」：编辑记下了生成器参数，而重放编辑时生成器还没运行。现在与 Cubism 一样，编辑只记录目标自身读取的参数：带动父级的摆动、模拟参数无论停在什么值都不影响编辑，目标自身的生成器参数在默认值时也不写进记录。胶水同样按 Cubism 的方式在静止形上胶合，参数不在默认值时先平滑移回默认值，胶合点在静止时不再产生拉扯。
- **按 Alt 后界面卡住**：在 Windows 上单按 Alt（或用 Alt + 右键拖动调整笔刷后松开）会让窗口进入系统菜单模式，之后的按键被吞掉。
- **画布工具与菜单**：工具栏展开较长时下方的工具不再穿透到画布；变换工具、权重渐变、骨骼模式和吸管的右键菜单不再为空；胶水工具在没有选中两张网格时改为禁用并说明原因，不再消失；形状工具的线宽与画笔大小分开；骨骼权重笔刷可用 `[` `]` 调整大小；Warp 网格尺寸标签随界面语言显示。
- **运行时参数逐帧累积**：网页播放器和 C 接口在每帧更新时把呼吸、视线、眨眼和加法表情叠加在上一帧的结果上，播放一段时间后角度等参数会漂到数万。现在每帧都从宿主设置的姿势重新计算。
- **Windows 上保存失败**：被替换的工程文件被短暂占用时，保存会等待占用解除，不再直接失败。
- **命令行 `--mesh-pixels` 报未知选项**：帮助中列出的这个选项此前无法使用，现在按源像素计算网格间距。

- **安装与升级**：升级或重装默认装回原来的目录，不再询问目录非空；重新构建的同版本安装包会替换已安装的版本，而不是并存。

## v3.0.0 · 2026-10-08

距 v2.0.4 改动较大：新增多种导出格式和独立运行时，纹理可以逐层调整，MCP 接口重新设计。旧工程照常打开。

### 新增

- **更多导出格式**：**文件 → 导出为** 新增 VTube Studio、PSD2Live 运行时模型、网页播放器、PNG 序列帧、精灵表、GIF、APNG、WebP 动图、MP4、WebM、ProRes 4444 和指定姿势的 PSD。每次导出附带损失报告，说明目标格式丢失了什么。视频与动图需要自行安装 ffmpeg。
- **PSD2Live 运行时**：开源（MIT）的 Rust 运行时，可在浏览器、Godot 4 或任何能调用 C 接口的程序中播放导出的模型，自带眨眼、呼吸、视线跟随和口型。
- **纹理工作区**：逐层调整纹理密度；在纹理集页面上直接拖动、缩放图块；按网格形状紧凑排布，布局保持不变，直到你要求重新排布。
- **保留原始分辨率**：导入的图片、素材和 CMO3 贴图不再缩到画布分辨率，绘画在图层自身的分辨率上进行。
- **MCP 重新设计**：公开操作从 25 个增至 181 个，可分页发现；最多 128 项编辑可原子提交，也可先试运行检查几何问题；耗时操作作为后台任务执行。旧的工具名已删除，需按新接口接入。
- 实验性：Spine 4.2、DragonBones 5.5、glTF 2.0 导出，仅限命令行。

### 改进

- **拆分更可靠**：按网格拆分、多边形拆分和前后分层得到的部件直接取代原图层，并参与自动生成。之后修改脸部设置、站姿或骨架，部件会跟着更新；原图层不再占用纹理集。
- **关节更自然**：骨骼弯曲时，肘、膝等关节按实测的人体关节姿态塑形，内侧不再出现纹理折叠。
- **手工修改不丢失**：在摇摆、模拟烘焙等生成结果上的修形，重新生成后按三方合并保留；冲突或已失效的修改会在检查器中提示。
- **文件菜单重新整理**：分为「导入」「导出 Live2D 模型」「导出为」三组。
- **统一的变换框**：「变换」工具、Warp / 图层放置框和纹理集图块使用同一套变换框；拖动角点外侧即可旋转（悬停时角点外亮起带箭头的弧线），新增可拖动的锚点作为旋转和 Alt 缩放的中心（默认在中心，带描边便于辨认），缩放光标随框的角度转动；手柄改为圆角方块与胶囊形，拖动时指针旁显示角度、缩放比例或位移。
- **画布与参数**：网格选择与框变换分开；变形工具作用于选中的参数关键点；添加或拖动关键点默认连续移动，选择步长后才吸附。
- **工程格式 v2**：未改动的内容在历史修订之间共享。旧工程照常打开，保存时自动转换。
- **更快**：修改分类或单个图层的网格时只重算受影响的部分；打开工程时复用已保存的骨架结果；编辑提交不再每次重建整个模型；Cubism 原生预览改为就地更新。
- **结果可复现**：同一个 PSD 每次生成的骨架和导出文件完全一致。

### 修复

- 绘画后重建网格时，位于骨骼、站姿变形器、修改过的格子或导入变形器下的网格不再偏移或缩小。
- 动画播放、参数滑块与画布姿势保持同步；平滑跟踪的速度不再受帧率影响。
- 纹理集中新放入的图块不再跳进其他图块空出的位置。
- Windows 上连续快速保存时偶尔替换文件失败。
