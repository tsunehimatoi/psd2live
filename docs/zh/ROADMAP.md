# 路线图

[项目首页](../../README.md) · [实测记录](STATUS.md) · [架构边界](spec/RUNTIME_EXPORT_ARCHITECTURE_AND_GAPS.md) · [更新日志](CHANGELOG.md)

## 归属与优先级

本页只记录后续方向，不承诺排期。代码已有入口、完整工作流可用和效果通过验收分别判断；评价只在 [STATUS.md](STATUS.md) 记录，已完成的条目移出本页，见[更新日志](CHANGELOG.md)。

每个新能力按它与 Cubism 的关系归入三档：

| 归属 | 含义 |
| --- | --- |
| p2lrt | Cubism 完全不支持，也无法烘焙，只在 p2l 运行时、网页、Godot 和光栅导出里生效 |
| 兼容 | Cubism 不支持，但可以烘焙成关键形、参数、摆锤或纹理，关键点之间可能有近似 |
| p2ledior | Cubism 完全支持且无损，或者是只影响编辑过程的工具 |

优先级标在每条开头：

- 【下一步】当前阶段优先实现，同时不超过五条左右；
- 【后续】当前阶段之后或依赖其他条目；
- 【远期】有难度但未来希望实现；
- 【持续】随功能推进逐步完善、没有单一完成点的项；
- 【待定】是否要做尚未决定。

文末另有“暂不计划”。每条后的括号是归属与工作性质：**深化**（给已有系统加能力）、**优化**（同一套算法或预设的效果与性能）、**全新**（新系统）、**重构**（改变已有系统的结构）。

## 阶段

后续工作分三段推进：先做与修改器无关的功能，再把修改器栈重构作为一个阶段性目标，最后做依赖它的功能。修改器栈已经落地（见[已有基础](#已有基础)），依赖它的功能可以开始；它们直接做成修改器，不在旧变形器上实现。

| 阶段 | 内容 |
| --- | --- |
| 阶段一 | 与修改器无关的编辑、动画与导出功能，见下文各主题中标【下一步】的条目 |
| 阶段目标 | 修改器栈：已完成，余项见[修改器栈](#修改器栈) |
| 阶段三 | 依赖修改器的功能：光照与阴影、内部造型的三维投影预设、头发体积壳、类变形器、2D 几何节点等 |

## 光照与阴影

属于阶段三，排在修改器栈之后，单独推进。只做静态主光，优先服务画师画好的阴影层，动态光只留给运行时。体积代理不以扩大转头角度为目标，大角度只能靠多视角素材。

- [ ] 【后续】**画师阴影 / 高光层随角度移动**（兼容 · 全新）：识别剪切 + 正片叠底 / 滤色层，或新增 SHADOW / HIGHLIGHT / RIM 标签，让它随角度移动、淡入淡出；轮廓内的明暗收放可复用内部造型。
- [ ] 【后续】**静态主光**（兼容 · 全新）：明暗交界线、刘海投影、天使环高光、远侧压暗、层间接触阴影，烘焙为阴影层关键形和变形器颜色关键形。
- [ ] 【后续】**运行时动态光**（p2lrt · 全新）：法线图逐像素光照；导出 Cubism 时降级为静态光并写进损失报告。
- [ ] 【后续】**头发体积壳**（兼容 · 全新，有难度）：低头、仰头时刘海离开或贴合额头，烘焙进角度轴。
- [ ] 【远期】**反向光照烘焙**（兼容 · 全新）：从画师已画的明暗反推法线，供静态主光使用。
