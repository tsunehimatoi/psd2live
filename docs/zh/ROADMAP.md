## 已有基础

PSD 自动建模、桌面四种编辑模式、绘画会话、工程与分支历史、基础 CLI 导出、交互教程、参数 / 动画 / 物理面板以及本地 MCP 已有实现。不要再把这些整体列为“待实现”；其具体缺口见下文。

## 编辑与格式

- [ ] 补齐 Blend Shape 创建、限制曲线与产品编辑流程。
- [ ] 扩展 Glue 配对、权重编辑和修复诊断。
- [ ] 物理的风力等全局设置与更多输入 / 输出类型。
- [ ] 模拟：示例模型上裙子与头发烘焙结果的官方运行时视觉验收；融合变形模态参数被摆锤驱动在 Cubism Editor 中的读回确认；进一步缩短烘焙耗时（目前 tml 后发约 6–8 秒）；逐个模态拟合在会甩出鞭梢的细长发束上比一起拟合略差（旧求解器上 R² 0.60 对 0.66）；按面积分配质量后参考模拟在转头时略粗（粗糙度 0.095，原 0.075）；模型预设烘焙数据在新材质模型下重测；可绘制的纹理方向；拖动时导出摆幅约为模拟六成（现由夸张系数补偿）；风力等力场导出；刚体链与软体（见[模拟与烘焙](guide/SIMULATION.md)）。
- [ ] 统一 Motion / Expression / Pose / UserData 等边车的工程模型和引用维护。
- [ ] 完善导出损失展示、目标版本检查和真实 Cubism 往返样本。
- [ ] 验证变形路径在官方 Editor 中的打开、拖动和重存行为。
- [ ] 按实际需求扩展绘画的压感、防抖、选区和对称工具。
- [ ] 切换工作区仍有卡顿：停靠区按工作区重建全部模块和浮动窗口，画布按工作区重建并重新上传预览模型与 GPU 资源；需要让模块组合跨工作区保留（只替换所属工作区的状态），并让同一预览模型的 Cubism 视图在编辑 / 预览切换时复用而不是销毁重建。

## 格式与多目标导出

按 `docs/local` 中的格式设计分阶段推进；已实现的模块与目标见[中立绑定 IR 与导出目标](spec/EXPORT_TARGETS.md)。

- [x] 引擎拆为独立 `:umamo` 模块，消除对产品层的反向引用，删除 KRA / CLIP 读取器等无入口代码。
- [x] 中立绑定 IR（MIT）与 `PuppetModel` 双向无损转换器；moc3 / cmo3 改为从 IR 编译，导出结果与重构前逐字节一致。
- [x] 导出框架（能力描述、损失报告、编译器版本）、光栅类目标（PNG 序列、精灵表、GIF）、指定姿势的分层 PSD、`export` 命令与导出对话框入口。
- [x] 文档层样板：依赖图、内容哈希缓存与三方合并框架；摆动生成结果上的编辑以覆盖保存并在重新生成时合并（见[文档层](spec/DOCUMENT_LAYER.md)）。
- [x] 生成器依赖图接入重放：摆动与烘焙模拟按图运行，模拟关键形上的编辑同样以覆盖保存并合并；按测量把骨架烘焙与生成动作接入生成缓存；工程格式 v2（按内容寻址的文档节点）与 v1 打开、保存时迁移并保留备份（见[文档层](spec/DOCUMENT_LAYER.md)、[工程格式](spec/PROJECT_FORMAT.md)）。
- [ ] 逐层像素尺寸：图层栅格与画布矩形解耦、按密度与统一 fit 在预算内打包、保持画布矩形的换图核心、cmo3 画布分辨率降级与纹理工作区界面已完成；在栅格空间绘画、导入保留分辨率、纹理应用命令与 MCP、纹理映射（UV 变换）编辑以及 cmo3 原分辨率图层的编辑器实测待完成（见[文档层](spec/DOCUMENT_LAYER.md#逐层尺寸)）。
- [ ] Rig 生成内部阶段拆为独立图节点；覆盖冲突在质量报告与界面中提示；混合形写回的模拟关键形覆盖；打开工程时直接读取固化结果而不重放。
- [ ] 骨骼动画类目标（Spine 4.2、DragonBones 5.5、glTF 2.0）：实验性，已从界面隐藏，仅命令行可用，暂停开发，是否继续待定。参数按逐个烘焙后叠加，组合姿势与编辑器差异明显（由 Warp 实现的关节、作用于 Warp 的摆锤无法表达）；Spine 4.3 编辑器只能导入 JSON（二进制须与编辑器版本一致），DragonBones 整身片段受运行时每动画数据上限影响。现状见[导出目标](spec/EXPORT_TARGETS.md)。
- [x] 视频与动图：MP4、WebM（带透明）、ProRes 4444、APNG、动态 WebP，经系统或指定的 ffmpeg 编码。
- [x] VTube Studio：moc3 模型包与 `.vtube.json`（标准参数的面部跟踪映射、动作热键）；尚未在 VTube Studio 中实测加载。
- [x] `.p2lrt` 与 Rust 运行时（MIT）：变形、物理、动作片段与 C ABI，规则由黑盒探测编辑器得到，与编辑器求值器逐姿势一致；JVM 绑定 `:format-eval`（见[运行时](spec/RUNTIME.md)）。
- [x] 运行时程序化行为（眨眼、呼吸、视线、口型）与 Godot 4 节点 `P2LCharacter`（GDExtension）。
- [x] 网页播放器（`web`）：运行时的 WebAssembly 构建与 WebGL 播放器，支持遮罩、叠加/乘算与动作、视线、口型。
- [x] 导出烘焙改用运行时并随安装包分发；Godot 支持屏幕色与全部扩展混合模式。
- [x] 运行时：绘制组按部件的参数驱动绘制顺序排序。
- [x] 编辑器软件预览经运行时求值（后台编译，失败回退引擎）。
- [ ] Godot 中的反相遮罩（受画布组限制，需改用离屏遮罩纹理）。
- [x] 光栅导出的软件光栅器：全部混合模式、乘算 / 屏幕色、按纹理 alpha 的遮罩。
- [ ] 光栅导出：部件分组合成与非 over 的 alpha 合成；与 Cubism 原生渲染的保真度对比工具。
