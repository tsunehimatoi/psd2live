## 归属与优先级

本页只记录后续方向，不承诺排期。代码已有入口、完整工作流可用和效果通过验收分别判断；评价只在 [STATUS.md](STATUS.md) 记录。

每个新能力按它与 Cubism 的关系归入三档：

| 归属 | 含义 |
| --- | --- |
| p2lrt | Cubism 完全不支持，也无法烘焙，只在 p2l 运行时、网页、Godot 和光栅导出里生效 |
| 兼容 | Cubism 不支持，但可以烘焙成关键形、参数、摆锤或纹理，关键点之间可能有近似 |
| p2ledior | Cubism 完全支持且无损，或者是只影响编辑过程的工具 |

优先级标在每条开头：【下一步】优先实现；【远期】有难度但未来希望实现；【持续】原路线图里尚未完成的项。文末另有“暂不计划”。每条新能力后的括号是它的归属。

工作按性质分为五类：

- **深化**：给已有系统增加新能力，如给骨骼加 B-Bone。
- **优化**：改善现有的同一套算法或预设数值来得到更好的效果（如改善默认 rig），或者针对性能的优化。
- **全新**：新系统，如光照。
- **重构**：改变已有系统的结构，如用修改器栈重构变形器。
- **验证与文档**：实测、往返验证、发布和文档，不增加功能。

## 已有基础

以下已有实现，不再整体列为“待实现”；具体缺口见下文各类清单。

- **编辑器**：PSD 自动建模、七种画布模式、绘画会话、工程与分支历史、参数 / 动画 / 物理面板、交互教程、本地 MCP。
- **引擎与格式**：独立 `:umamo` 模块；中立绑定 IR 与 `PuppetModel` 双向无损转换，moc3 / cmo3 从 IR 编译；文档层（依赖图、内容哈希缓存、三方合并）与工程格式 v2。
- **导出**：导出框架与损失报告；PNG 序列、精灵表、GIF、APNG、动态 WebP、MP4、WebM、ProRes 4444；指定姿势的分层 PSD；VTube Studio 模型包（尚未在 VTS 里实测加载）。
- **运行时**：`.p2lrt` 与 Rust 运行时（与编辑器求值器逐姿势一致）；程序化眨眼、呼吸、视线、口型；Godot 4 节点；WebAssembly 网页播放器；绘制组按参数排序；编辑器预览经运行时求值。
- **光栅器**：全部混合模式、乘算 / 屏幕色、按纹理 alpha 的遮罩。

## 全新

光照与阴影是首个要做的方向：只做静态主光，优先服务画师画好的阴影层，动态光只留给运行时。体积代理不以扩大转头角度为目标，大角度只能靠多视角素材。

- [ ] 【下一步】**画师阴影 / 高光层随角度移动**（兼容）：识别剪切 + 正片叠底 / 滤色层，或新增 SHADOW / HIGHLIGHT / RIM 标签，让它随角度移动、淡入淡出。
- [ ] 【下一步】**静态主光**（兼容）：明暗交界线、刘海投影、天使环高光、远侧压暗、层间接触阴影，烘焙为阴影层关键形和变形器颜色关键形。
- [ ] 【下一步】**运行时动态光**（p2lrt）：法线图逐像素光照；导出 Cubism 时降级为静态光并写进损失报告。
- [ ] 【下一步】**头发体积壳**（兼容，有难度）：低头、仰头时刘海离开或贴合额头，烘焙进角度轴。
- [ ] 【下一步】**像素渲染**（p2lrt）：像素网格固定在屏幕、调色板量化；光栅导出可用。
- [ ] 【下一步】**网点 / 半调**（p2lrt）：网点固定在屏幕上。
- [ ] 【下一步】**ASCII 字符画**（p2lrt）：屏幕空间后处理。
- [ ] 【下一步】**flipbook 动图纹理集**（兼容 / p2lrt）：Cubism 里降级为多网格切换；真正的帧动画在运行时。
- [ ] 【远期】**缺失区域提示图**（p2ledior）：算出各角度会露出的未绘区域，提示补画或留余量。
- [ ] 【远期】**多视角转身**（兼容）：正面、3/4、侧面多套美术对应变形 + 交叉淡化。
- [ ] 【远期】**3D 道具与挂点**（兼容）：挂点是父变形器；道具多角度预渲染后切换。
- [ ] 【远期】**3D 动作重定向**（p2ledior）：BVH、VMD 转为普通 motion3 曲线。
- [ ] 【远期】**反向光照烘焙**（兼容）：从画师已画的明暗反推法线，供静态主光使用。
- [ ] 【远期】**渐变映射换色**（p2lrt / p2ledior）：实时换色在运行时；导出前预烘焙配色无损。
- [ ] 【远期】**与风格化联动的预烘焙纹理集**（兼容）：屏幕空间效果会丢失。
- [ ] 【远期】**运行时写入纹理**（p2lrt）：涂鸦、脏污、贴纸、签名；Cubism 纹理运行时只读。
- [ ] 【远期】**粒子**（p2lrt）：固定轨迹可部分烘焙。
- [ ] 【远期】**AOV 渲染通道导出**（p2lrt）：深度、法线、UV、部件 ID、运动矢量，用于合成或 AI 重绘。
- [ ] 【持续】可独立保存的参数模板与稳定语义接口。
- [ ] 【持续】Agent：跨工具事务、结构化历史差异和可恢复任务执行。
