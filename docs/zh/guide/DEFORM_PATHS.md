# 变形路径（实验性）

变形路径是挂在 ArtMesh 上的**编辑辅助对象**，不是网格/旋转变形器之外的第三种 deformer。入口在层级树右键「添加变形路径」或快捷键 P / D，不强制进入编辑模式。

在工作区选择一个 ArtMesh 对应图层，用快捷键或层级树「打开路径」/「添加变形路径」。

1. 点击「新建路径」，沿图像单击至少两个控制点，再点击「完成路径」（或按 `Enter` 键）。完成后进入**编辑模式**，便于只调绑定位置。同一个网格可以建立多条路径。
2. 在编辑模式拖动控制点只修改路径绑定，图像保持不变。创建面板与右侧检视器可调整路径宽度、衰减硬度、闭合，选中点可切换折点（尖角）或删除该点。创建时显式显示当前 L2 / L3 编辑层级。
3. 选择目标参数并微调滑块，切换至**变形模式**，拖动控制点可实时形变网格并在当前参数值自动烘焙几何位移 K 帧。
4. 选择模式不编辑路径控制点。编辑层级 1 隐藏路径；层级 2（主路径）、层级 3（辅助路径）分别保存不同路径组。同层级其他路径的控制点参与固定约束。
5. **待提交区事务保障**：「撤销」（`Ctrl + Z`）退回草稿中的上一条编辑；「保存到工程」（`Ctrl + S`）将所有待提交编辑作为一个历史节点原子提交；「放弃草稿」丢弃全部修改（有未保存修改时会弹窗确认）。每批最多支持 128 条编辑。
6. **DCC 视口操作**：支持鼠标滚轮以光标为中心自由缩放；鼠标中键拖拽或按住空格键加左键拖拽平移视口；双击或按 `F` / `Home` 键快速视口居中；顶部提供网格线框显示切换按钮。

窗口显示的是选中网格的父级局部形状，便于编辑自身的 K 帧。完整的父变形器、遮罩和其他图层效果请在保存后使用主预览检查。

## 保存与导出

- `.psd2live`：路径的三角形绑定、设置和已生成的几何 K 帧随编辑日志保存，可以恢复和历史回退。
- `.cmo3`：使用原生 `CControllerExtension` / `CControllerCurve` / `CControllerPoint` 结构写入路径，并保留网格 K 帧。宽度转换为画布单位；控制点分别写入局部坐标和画布恢复坐标。
- `.moc3`：只导出已经生成的网格 K 帧；路径属于编辑辅助对象，不在运行时重复执行形变算法。

## 当前兼容性边界

交互语义参考 [Cubism 变形路径手册](https://docs.live2d.com/en/cubism-editor-manual/deformpath/)。目前形变计算使用独立实现的曲线采样、刚性移动最小二乘和三角形控制点约束，**并非已验证的 Cubism Editor 相同算法**。宽度、硬度以及大角度变形可能产生不同结果。父空间非均匀缩放下，路径宽度采用网格边长比例换算，只是单一标量近似。

当前支持单 ArtMesh 多路径，不支持一条路径同时控制多个 ArtMesh。导出控制器的本项目读写回归已覆盖，但尚未完成官方 Editor 打开、拖动、重存的实际兼容性验收，不能据此宣称与官方效果完全一致。

网格过疏或重叠控制点的目标相互冲突时，无法满足所有控制约束，编辑器会拒绝这次形变。改变网格拓扑前请先移除相关路径并重新建立绑定。

## 已覆盖的回归

三角形内外绑定、身份/平移/旋转、固定路径约束、层级隔离、三角形内部控制点移动、非法输入拒绝、日志重放、父级局部坐标与宽度换算、CMO3 路径和 K 帧读写、路径删除保留 K 帧、MOC3 多参数值采样。
