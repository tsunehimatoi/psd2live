# 变形路径（实验性）

[画布编辑](CANVAS_EDITOR.md) · [文档目录](../../README.md)

路径是挂在 ArtMesh 上的编辑辅助对象，不是 Warp / Rotation 之外的第三种变形器。当前支持一个 ArtMesh 上的多条路径，不支持一条路径控制多个 ArtMesh。

## 最短操作

1. 选中画元，树右键「添加变形路径」（默认 `P` / `D`）。
2. 单击放置至少两个控制点，Enter 确认，Esc 取消。
3. 在**编辑模式**调整路径绑定位置、宽度、硬度、闭合与角点；此时不应改变图像形状。
4. 在参数面板设置目标姿态，切到**变形模式**拖控制点，将结果写入画元形状。

选择模式只选择对象。L2 / L3 路径分组分别编辑；辅助线按选中对象和编辑页视图设置显示，预览页不显示路径。普通编辑沿用主画布历史。

## 保存与导出

| 文件 | 保存内容 |
| --- | --- |
| `.psd2live` | 路径设置、绑定与可重放的形状编辑 |
| `.cmo3` | 原生控制器结构及网格关键形 |
| `.moc3` | 烘焙后的网格关键形，运行时不执行路径算法 |

当前算法使用曲线采样、移动最小二乘及三角形绑定。控制器可读写不代表拖动效果已与 Cubism Editor 验证一致；宽度、硬度、大角度形变和非均匀父级缩放尤其需要检查。

主画布拓扑操作会重新绑定路径。过疏网格或互相冲突的约束仍可能导致形变被拒绝。官方 Editor 打开、拖动与重存的完整兼容性验收尚未在本页记录。

Agent 的 `path` 工具见 [MCP 接口](../agent/MCP_AUTHORING.md)。
