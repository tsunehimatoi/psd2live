# 预设

已有显式栈的工程会显示「预设」面板；旧工程打开时继续使用原来的预设面板。可用「转换为可编辑预设」显式转换；当前已验证普通素材、基础旧版绑定和含多个部位及附加模块的现代预设用例；其他工程仍可能因结果有差异而被拒绝。已停用的旧模拟作为停用实例保留，启用中的旧模拟需要现有烘焙与候选输入相符。源图绑定已可在新面板添加、调整、排序和固化；摆动、物理组、模拟与生成动作也可在同一入口添加并在栈内调整。开始页快捷组合也通过隔离转换添加显式修改器；此前版本完成过多语言和主题出图；本次简化界面尚未重新进行视觉验收。

## 新建 PSD 工程

「旧版」「新版」是同一工程模型下的两套修改器组预设，不是两种工程版本。开始页的「推荐预设」直接添加新版组中的拟合绑定、附加模块、物理、动作及衣物模拟，由栈统一求值，不先生成旧模型再转换。不会再按“标准”模块等级删减功能。失败或取消不会安装部分工程。

## 添加与切换

1. 选择网格，或不选以处理全部网格。添加后目标固定，不随选择变化。
2. 「添加预设」按部位分类；同部位的旧／新算法在一起。衣物、前发、后发的模拟位于相应分类，自动识别部件并建立材质、权重与烘焙绑定；通用生成器放在高级分类。
3. 点击条目仅规划依赖与新增清单，确认时执行昂贵求值。不能叠加且所选目标均已拥有的项不再显示，禁用项也计为已存在。部分目标已有时显示已有数量，只为未覆盖目标补齐；允许叠加的摆动、动作等仍可添加。
4. 「切换预设」整体替换为「旧版（完整旧算法）」「新版（拟合算法）」或「空白」，不是追加。普通作者内容保留；切换一次记录一个历史节点，撤销恢复原栈。

旧版使用原始基础算法和默认动态设置；新版使用重构前的完整现代配方。贴身衣物无需模拟时跳过，不阻止整组生成。自动权重随单独添加的模拟实例保存，已有同名作者权重优先。整组切换目前遇到生成内容覆盖或已固化的预设能力会明确拒绝，不丢弃编辑；需要先处理这些内容。兼容 MCP 分档组仍可读取和添加，但不再作为界面的主要组选择。

面板提供两种模式。「设置」按文件夹归纳，默认按用途分组；可新增、改名、删除文件夹，并拖动修改器和文件夹整理位置，整理不改变求值顺序，也不重算模型。「排序」显示平铺列表，沿用参数列表的拖动交互调整实际求值顺序；非法依赖次序仍拒绝。新项自动带入前置项，不重排已有实例。文件夹布局随工程保存，支持撤销和重做。

「切换预设」还提供新版轻量、新版丰富动态、旧版轻量组合。「管理预设」可保存当前配置、导入或导出 JSON，并删除选中的库预设。保存包含修改器配置和文件夹，不包含生成内容上的作者覆盖与烘焙缓存；模拟在应用时重新烘焙。用户预设与内置预设都以 JSON 存在应用偏好中，内置项缺失时先从随程序附带的 JSON 恢复，再按相同路径读取。跨工程应用时按稳定对象引用或唯一同名同类型对象定位目标，无法唯一匹配会报错，不会扩大作用范围。

公共结构修改器的「面部特征位移」使用原有变形层级。若头脸绑定位于其后，公共结构固化后仍保留该层级。

新添加的公共结构使用版本 2，共用同一目标组的父级，避免为每个网格复制完整父级链。共享结构的后续绑定必须覆盖该组的完整目标；不同作者父级下的目标不能合并成同一结构。已保存的版本 1 栈继续按原对象 ID 重放，本次不自动升级或合并旧分支。

## 调整和定位

点击列表中的预设，在右侧直接调整完整数值，包括转头风格、强度和各项细节。列表保持紧凑行高，两侧独立滚动，中间分隔条可拖动调整宽度。数值沿用检查器布局；物理编辑当前输入、输出或段，动作编辑当前轨道与关键帧。

「目标」与「生成内容」分别提供作用对象定位和实际贡献；「应用截至此处」保留在当前项操作中。

脸部有两个互斥基础算法：`face/legacy`（旧算法）和 `face/fitted`（拟合转头）。同一目标不能同时启用。拟合项内部复用已有拟合算法，并提供下游所需的头脸参数；不另加旧脸部项。旧工程中的 `face.depth-turn` 记录继续重放，新添加入口使用 `face/fitted`。单项添加需要头脸依赖时，会复用目标上已有的旧脸部提供者；没有提供者时默认添加拟合脸部。显式选择旧脸部或旧算法组仍使用旧算法，已有栈不自动改写。

在「排序」模式拖动修改器名称改变实际求值顺序；拖影和相邻行让位与参数面板共用实现。违反依赖的移动会被拒绝，原栈不变。连续拖动滑条或输入数值在结束时只提交一个历史节点。

禁用后不再求值；依赖它的下游项仍留在栈中并显示「依赖缺失」。重新启用原实例可恢复其覆盖。移除同样保留休眠覆盖，撤销可以恢复；另加的新实例不会继承已移除实例的编辑。

生成的网格、部件和变形器可在常规编辑器中改名、调整适用的静态外观、改挂变形器或移动层级。引用的对象须在该项求值时已存在。生成参数的改名、范围与默认值调整随提供该参数的实例保存。与下游参数定义冲突的调整会被拒绝。编辑跟随创建对象的修改器，禁用时休眠，重新启用时恢复。

可在修改器生成的对象轨道上插入、移动和删除关键形。若命令会同时改动分属不同实例的轨道，请选择具体轨道。生成参数的面板关键点也随提供该参数的实例保存。

导出支持运行时实时模拟的格式时，启用且烘焙有效的模拟项会随模型导出，并引用同一次求值生成的参数和物理组。

## 应用截至此处

「应用截至此处」将当前项及其之前的有效结果固化为普通可编辑内容，并移除整个前缀。禁用项也随前缀移除，但不产生内容。后续项保留实例和对象引用；应用前后完整结果必须一致。

物理组成为普通物理配置，生成动作为普通片段（保留文件名、导出组和运行时默认淡入淡出），模拟固化已生成的绑定内容。它不记录当前播放帧。缺失依赖、无法匹配的覆盖或无效烘焙会阻止应用；失败不会留下部分结果。撤销恢复原来的栈。

眼部修改器还可添加睁大、眼睑线淡出和高光视差。睁大显式把开眼范围扩到 2，贡献清单显示参数修改；高光的添加计划包含头脸绑定依赖。新增停止点的关键形显示坐标，便于区分其来源。

眼部和眉部刘海透视可分别添加和调节透明度。贡献清单显示生成的副本网格、层级和蒙版关系。

「开关编排」为目标中的开关与差分图层添加参数和透明度关键形。切换差分时，新图层先淡入，旧图层随后淡出。开关与差分也可以驱动已添加的摆动链，贡献清单会列出受影响的物理组。

「嘴部轮廓」为适用的嘴部素材生成上下唇网格和各自的贴图，可在修改器中调节线宽，输入 RGB 颜色或恢复自动取色。应用后，网格和贴图随工程保存。

## 原生生成器

摆动可调整支点、偏移、轴向、分段、形状及附带物理；物理组可调整参数输入／输出、各段和归一化。生成动作使用已有算法，只添加当前参数可以支持的轨道，在弹出菜单中选择预设；进入栈后可调整时长、循环、淡入淡出、轨道与关键帧。数值在添加后的预设调整区编辑。

物理组需要已有且可用的输出参数和不同的输入参数。无合适参数时先添加绑定或普通参数。输出写入冲突会阻止添加；不会替换已有物理组。模拟在后台对实际栈前缀烘焙，不使用当前播放帧；可调整材质、输入、模态数、关键点数和夸张，并选择混合形输出模式、添加或移除静态输入轴。固定、刚度、形状、质量、阻尼和风力可选择目标上的具名顶点组，默认读取每个目标的首个同类组。碰撞体可选择非模拟目标的网格，设置顶点 A／B、两端半径和摩擦，或移除。两个端点相同表示圆形，不同表示胶囊形，顶点编号从 0 开始。训练片段可选已有普通动作和栈中前置动作，并调整权重或移除。缺少引用的片段时，模拟保留并暂停求值；将模拟移到提供片段的动作之前会被拒绝。开启自动烘焙时，上游编辑会在同一事务内刷新结果；关闭后，过期结果会阻止提交。没有足够运动的输入会被拒绝；确认需要保留小幅输入时可勾选「保留」。

眨眼余震与眉毛回弹会连同绑定添加物理组。展开修改器内的「物理」可调整输入／输出、段和归一化，值保存在该实例中。不同目标可以共用兼容的标准物理组；复用清单显示其来源，名称保留先行项。更改物理值与共享方不兼容时会拒绝提交，需要先停用其他共享方再逐项调整到一致。固化后得到保留这些值的普通物理配置。

嘴部还可添加口型捕捉、伸舌、下颌随动、口腔纵深和嘴部回弹。添加计划会列出所需前置项；脸红与阴沉则添加颜色通道，可与口型组合。颜色关键形的编辑也归属实例，停用后休眠，恢复原实例后重新生效。

物理面板显示栈实际求值的组，来源标记为「修改器」。请在所属修改器内调整生成组；「打开预设」可返回该面板。生成组的顺序由修改器栈决定，固化后则成为可普通编辑、停用和重排的自定义配置。

皮肤裁切为腮红、皮肤明暗与刘海阴影添加脸部蒙版。颈部联动让颈部随头部倾斜，并裁切颈部阴影；添加计划包含固定的头脸绑定前置项。两者都沿用已有素材。 贡献区会显示蒙版在添加前后的来源和反转状态，点击对象或来源即可定位。

头发可选择分段链基础算法，与同一目标的旧头发摆动互斥。裙摆、飘带和饰坠、兽耳／尾／翼链，以及胸部和手臂随动也可单独添加。添加计划列出所需身体与头脸绑定；链条的摆幅、头发软硬和实际物理组在所属项内调整。调整其他项的顺序不会更改这些链条的对象引用。

拟合脸部本身就是头脸基础绑定。在该项内调整转动幅度、纵深和造型。选择新造型时，该项的其他数值恢复默认。符合条件的侧发在大角度转头时会转到脸后。

添加物理时，可选择前发、后发和眼球果冻预设。缺少所需参数时，添加计划会列出需要同时添加的基础绑定。添加动作时，可选择原版或自然版的待机、眨眼、点头、摇头，或选择自然说话。选择自然动作时，添加计划会补齐缺失的基础绑定。确认前编辑数值会保留计划中的前置项。确认添加后，物理规则和动作轨道都可在对应实例内编辑。

## 与 MCP 共用

`modifier_catalog` 提供算法目录，`modifier_stack` 提供捕获版本的状态和实际贡献。`modifier_plan` 规划源图绑定及前置项，也支持摆动、物理组、模拟与生成动作的原生配置；先将其 `group` 和 `entries` 交给 `workspace_preview_regeneration`，再以同一 `state` 提交 `modifier_add_group`，可以复现 GUI 的添加流程。详见 [MCP 接口](../agent/MCP_AUTHORING.md)。

眨眼动作修改器同时贡献 EyeBlink 运行时参数角色，在关系列表中显示。应用修改器后，该角色固化为普通模型元数据并随工程保存。

应用动作修改器会保留原片段的文件名和曲线控制点。之后调整参数范围，普通动作会按新范围整理；仅保存、重开或重建不会改变曲线。

动作轨道可在栈内展开，编辑关键点时间、数值、插值及贝塞尔入／出手柄；事件分组支持添加、编辑时间和内容、删除。应用后仍保留为普通动作片段。

## 非 PSD 新建

空白 Layout 和 Layout 清单导入使用空预设栈；素材仍可普通编辑。空栈首次生成使用完整新版基线；已有预设后再生成新素材仍按所选兼容组补充绑定，已有预设保持。MCP 的 `rig_generate.preset_group` 可选六种组或 `none`（保留普通网格）；源图数据新建使用推荐组。旧工程仍保留旧生成路径。

从 CMO3 新建使用空预设栈，导入的模型与物理配置作为普通作者内容保留。
