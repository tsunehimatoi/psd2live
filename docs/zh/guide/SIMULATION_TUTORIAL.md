# 模拟图文教程：让头发与服装自然摆动

[文档目录](../../README.md) · [模拟与烘焙](SIMULATION.md) · [画布编辑](CANVAS_EDITOR.md) · [操作速查](USER_GUIDE.md)

头发、裙摆和宽松服装可以通过模拟获得跟随、滞后和回弹。本教程先用前发的修改前后对比说明调整目标，再演示固定点权重与烘焙的操作。

## 先看问题与修改目标

自动生成的固定范围未必适合每张素材。本例需要调整前发摆动时脸侧发束的形状与位置：保持发根跟随头部，调整下方可自由运动的区域，让前发更接近想要的轮廓。

![前发模拟修改前后对比：左侧为修改前，右侧为修改后](../../imgs/simulation-tutorial/preview-comparison.webp)

*左侧取自修改前的整体预览，右侧取自修改后的局部预览；已裁切并拼接为一张头部对比图。保留两张截图的原始内容，便于对照脸侧发束。动态摆动还需通过参数变化或动作播放检查。*

调整思路是：**检查固定点 → 用权重笔刷修改固定范围 → 观察参考模拟 → 重新烘焙 → 检查导出效果**。修改固定点时保留根部连接，通过渐变控制哪些区域随头部走、哪些区域可以摆动。

## 操作前准备

**参考模拟**用于实时调整，**导出效果**用于查看烘焙后的表现。要让这些动作出现在导出的模型中，必须完成烘焙。先打开一个已生成网格和绑定的模型，再按下面的步骤操作。

## 1. 在模型预设中开启模拟

打开 **修改器** 面板 **世界** 页的 **模型预设 → 物理与模拟**。前发和后发各有一个下拉框，可以分别设置运动方式。

![模型预设的物理与模拟组，以及头发运动方式下拉框](../../imgs/simulation-tutorial/model-presets.webp)

*这张截图展示的是下拉框入口，红框圈出的是「经典摆动」。跟随本教程时，请选择它上面的「模拟」。*

| 选项 | 用途 |
| --- | --- |
| 模拟 | 创建头发物理体和固定点权重，并生成烘焙结果，之后可进一步调整 |
| 经典摆动 | 使用原有头发摆动与摆锤，不创建本教程使用的头发模拟物理体 |
| 关闭 | 关闭该类头发的摆动 |

先把 **前发** 设为 **模拟**，等待生成完成。需要后发也参与时，再把 **后发** 设为 **模拟**。若只希望处理部分图层，先选中它们，再开启 **仅选中**。

预设会自动为发束根部生成固定点。可以先观察默认结果，再决定是否手工调整。

### 服装也可以从这里开启

勾选 **服装**，程序会按部位生成模拟，只让宽松区域参与运动，贴身区域继续跟随绑定。

![服装预设下列出的上衣、裙子宽松度和贴身部件](../../imgs/simulation-tutorial/clothing-report.webp)

*服装行下方列出参与模拟的部位与宽松度，贴身部件汇总在「贴身，不模拟」一行。*

这里的百分比是程序对素材宽松程度的报告，用于了解预设处理了哪些部位。具体运动效果仍需通过固定点、材质和预览检查。

## 2. 选择要调整的物理体和网格

打开 **模拟** 面板，在 **物理体** 列表中选中 **前发（预设）**。列表左侧的复选框控制该物理体是否启用。

调试时，打开面板顶部的预览开关，使标签显示 **参考模拟**。这时运行编辑器内的实时模拟，可以在参数面板转动头部、倾斜身体，观察发束如何跟随。

要修改固定点，选中对应的前发网格，将画布左上角模式切换为 **模拟**，在左侧工具栏选择 **权重笔刷 → 固定点**。也可以在 **修改器** 面板中展开前发网格栈里的模拟卡片，在 **顶点权重组** 中点击固定点一行的 **绘制** 进入该工具。

![模拟模式下选择固定点权重组，前发根部呈红色，发梢呈蓝色](../../imgs/simulation-tutorial/pin-weights.webp)

*图中选择的是前发网格，颜色显示当前固定点权重。其他部件变暗是编辑显示效果。*

| 颜色 | 固定点权重 | 含义 |
| --- | --- | --- |
| 红色 | 接近 1 | 牢牢跟随原有绑定，适合发根或连接处 |
| 绿／黄色 | 中间值 | 部分固定，用于过渡 |
| 蓝色 | 接近 0 | 较自由地参与模拟，适合发梢或下摆 |

头发通常从根部固定、向发梢逐渐放开；裙摆通常从腰部固定、向下摆放开。先检查连接处是否稳固，再调整可摆动的区域。

## 3. 用权重笔刷调整固定范围

画布左下角的工具选项栏显示权重笔刷设置（在画布上右键也能打开同一组设置）。先选择修改方式，再调整 **半径、强度、硬度**。

![权重笔刷右键设置：半径、硬度、强度，以及增加、减少、设为和平滑](../../imgs/simulation-tutorial/weight-brush.webp)

*截图选中「减少」，适合减弱固定、扩大可摆动的区域。*

| 操作 | 适合的调整 |
| --- | --- |
| 增加 | 让根部或连接处固定得更牢 |
| 减少 | 让固定过多的区域更自由地摆动 |
| 设为 | 将权重逐渐拉向当前强度值 |
| 平滑 | 柔化相邻顶点之间的权重变化 |

例如头发固定得太多、发束不容易摆动时，可以用 **减少** 在根部下方轻刷，逐步放开过渡区域；保留真正连接头部的发根。如果连接处也开始滑动，则用 **增加** 补回根部权重。

用较小半径修边，用较低硬度做柔和过渡。每次少量修改，观察颜色后再继续。可用 **平滑** 整理突变；需要沿一个方向过渡时，也可使用 **权重渐变**。

## 4. 检查权重分布与参考模拟

下面是一种调整后的分布：顶部仍保持较高固定权重，往两侧和发梢逐渐降低。

![调整后的前发固定点权重，根部与自由区域之间形成渐变](../../imgs/simulation-tutorial/weights-adjusted.webp)

*重点是连接处稳定、过渡连续、发梢有自由度。固定范围应按自己的素材调整。*

回到 **预览** 模式，保持 **参考模拟** 开启。缓慢转头，再快速转动并停住，分别观察跟随、甩出和回摆。如果头发整体几乎不动，检查是否固定得过多；如果根部漂移，检查连接处固定点是否足够。

还可以在模拟卡片（**修改器** 面板中前发网格的栈里，或在 **世界** 页的 **模拟** 节点它的一行）的 **材质** 中调整：

| 项目 | 调整目的 |
| --- | --- |
| 弯曲 | 控制发束弯曲的难易程度 |
| 阻尼 | 控制运动衰减速度；增大后通常更快停下 |
| 保形 | 控制向原画形状回弹的程度 |
| 拉伸 | 保持发束长度，头发通常应接近 1 |

先使用 **头发** 材质预设，每次只改一项。其他材质、权重组和胶水角色的说明见[模拟与烘焙](SIMULATION.md)。

模型预设中的 **自动 Pin 物理权重** 会重新计算权重并重新烘焙。手工修好固定点后，需要保留这份分布时，继续使用模拟卡片的烘焙按钮。

## 5. 修改完成后重新烘焙

调整权重或材质后，已有烘焙会变为 **已过期**。在前发网格的模拟卡片中展开 **烘焙**，点击 **重新烘焙**；还没有结果时，按钮显示 **烘焙**。

![前发物理体已过期，红框标出重新烘焙按钮（旧版界面截图）](../../imgs/simulation-tutorial/rebake.webp)

*红框按钮只烘焙当前物理体。多个物理体需要更新时，可使用面板顶部的「烘焙全部」。*

第一次可以保留默认的 **模态数 2、关键点 5、夸张 ×1.3**，先完成一次烘焙并观察。模态数决定用几个参数表现整体摆动和额外形变，关键点影响形状采样细节，夸张控制烘焙后的摆幅。

**已过期**表示当前设置与旧烘焙不同，导出仍会使用旧结果。重新烘焙后，权重和材质修改才会体现在新的导出效果里。

## 6. 等待烘焙完成

烘焙期间，底部状态栏会显示进度。耗时取决于网格和物理体的复杂程度，等待完成后再检查结果。

![模拟烘焙期间，红箭头指向底部状态栏的进度条](../../imgs/simulation-tutorial/bake-progress.webp)

*箭头指向本次烘焙进度。完成后，最新烘焙的物理体在列表中显示绿点。*

若需要停止，可使用进度旁的取消按钮。**自动烘焙**默认关闭；需要连续手工修权重时，可以先集中修改，完成后再统一烘焙。

## 7. 切回导出效果并保存

关闭模拟卡片 **对比** 节的 **参考模拟**，回到 **导出效果**。这时画布播放烘焙后的关键形与摆锤，用来检查导出模型的表现。

检查转头、倾斜、快速运动后停住，以及身体上下移动。留意根部是否稳定、发梢是否自然回摆、服装是否仍保留原有造型。需要对照时，用相同动作在 **参考模拟** 与 **导出效果** 之间切换；也可以展开物理体的 **对比** 节，把参考模拟叠在导出上（**叠影**）或在两张画布上 **并排** 播放，选一个动作 **播放** 让两者同时从静止开始，或 **检验** 得到该动作上的摆幅、滞后与回落对比。

确认结果后保存 `.psd2live` 工程，再导出模型。之后若继续修改权重、网格或材质，记得检查烘焙状态并更新。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| 「世界」页的模拟列表没有前发物理体 | 前发下拉框是否选择了「模拟」，素材是否被识别为前发；也可选中目标网格，在「修改器」面板的「添加」菜单选「模拟 · 头发」手工创建 |
| 权重颜色没有显示 | 是否选中目标网格，并进入画布「模拟」模式和「固定点」权重组 |
| 头发根部松脱，或几乎不摆动 | 固定点是否过少或过多；先稳住连接处，再让发梢逐渐放开 |
| 参考模拟会动，导出效果没有更新 | 是否未烘焙或已过期，需要烘焙或重新烘焙 |
| 有些服装部件没有模拟 | 查看服装宽松度报告与「贴身，不模拟」列表，确认预设识别是否符合素材 |
| 烘焙效果与参考模拟有差别 | 烘焙是对实时模拟的拟合；查看质量提示，并按需调整模态数或关键点后重新烘焙，用实际运动检查改善情况 |
