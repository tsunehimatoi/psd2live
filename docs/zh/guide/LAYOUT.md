# 素材与 Layout

[文档目录](../../README.md) · [使用指南](USER_GUIDE.md) · [画布编辑](CANVAS_EDITOR.md) · [实现说明](../spec/MATERIAL_LAYOUT_WORKSPACE.md) · [Layout 清单](../spec/LAYOUT_MANIFEST.md)

Layout 让你先在工程里摆好部件，再生成 Rig；生成之后还可以继续加图、改标签，然后重新生成，已经做好的编辑会保留。

## 开始

- **从空画布开始**：在「开始」页选「排版工程」（「文件 > 新建 > 新建 Layout 工程」也会打开这里），选择常用尺寸或在属性面板输入宽高，点「创建排版工程」或双击尺寸。新工程还没有 Rig，并自动切到 Layout 工作区。
- **从 PSD 开始**：照常导入 PSD。工程会直接生成 Rig，同时 PSD 的每个图层也出现在素材面板里，与画布上的图层关联。
- **从 Layout 清单开始**：外部工具（例如 AI 拆件）写出的 [Layout 清单](../spec/LAYOUT_MANIFEST.md)——一个 JSON，或根目录放着它的 zip——用打开 PSD 的方式打开，或直接拖进窗口。图层按清单摆好：位置、上下顺序、组、标签和差分都已设置，小部件保留比画布更多的像素；工程还没有 Rig，并自动切到 Layout 工作区。
- 任何工作区都可以从窗口菜单打开"素材"面板。

Layout 工作区：左侧素材面板，中间编辑画布（物体模式），右侧层级树与图层表。

## 素材面板

- **导入**：点"导入"选择文件，点"导入文件夹"选择整个文件夹，或直接把文件、文件夹拖到面板上（拖到某个文件夹或路径栏的某一级上即导入到那里）。文件夹按原来的嵌套结构导入，每一级子文件夹都成为素材文件夹，文件按名称中的数字顺序排列（arm2 在 arm10 之前）；隐藏的文件和文件夹（如 .git）以及不支持的文件会被跳过。支持 PNG、BMP、TIFF、WebP（含有损）、JPEG、PSD、CMO3 中各 ArtMesh 的图片和 SVG。PSD 成为一个文件夹，图层组成为子文件夹，每个图层记住它在 PSD 中的位置。
- **浏览**：左侧是精简的素材树（文件夹及其中的图片，默认全部展开，工具栏的树形按钮可收起；树里的图片同样可以拖到画布、双击打开），右侧列出当前文件夹的内容：先文件夹、再素材，可切网格与列表。两栏之间的分隔线可以拖动调整宽度；网格的缩略图大小用右下角滑条调整（四周透明较多的素材只显示有内容的部分）。双击文件夹进入，用树、上方路径栏的 ↑ 或任一级返回；搜索会在全部文件夹中查找。条目右上角的数字是使用它的图层数。
- **来源**：从 PSD 或 CMO3 导入的文件夹显示为带「PSD」/「CMO3」色带的文件图标，后面叠着一页，右下角是其中的项目数和箭头，表示可以双击打开；悬停可看到来源文件名。
- **整理**：把素材或文件夹拖到另一个文件夹上（网格、树或路径栏的某一级均可），即可移入。右键菜单从点击处弹出，与画布右键菜单一致；树的顶层和文件夹的菜单里可以新建文件夹、导入文件或文件夹到这里。网格或列表的空白处右键，可在当前文件夹新建或导入，并切换网格、列表与文件夹树；树的空白处右键则在素材库顶层新建或导入。条目菜单可重命名、编辑标签、移到上一级、删除。标签用逗号分隔，留空清除；文件夹标签可供搜索，并由放置的素材继承。正在被图层或参考图使用的素材不能删除，包含这类素材的文件夹也不能删除，菜单会显示引用数量。删除项使用警示色，工程忙碌时修改操作不可用。
- **默认参考图层**：素材或文件夹右键「默认放置为参考图层」，切换其素材拖到画布时的默认类型；文件夹会作用于所有子目录中的素材。菜单的「放置到画布」仍明确放置为模型图层，「添加为参考 > 图层中」明确放置为参考图层。
- **素材是图层的唯一来源**：每个图层都显示一个素材，导入 PSD、CMO3 或图片、拆分图层、画出网格时都会自动登记。只有自己使用的素材跟着图层的修改走；几个图层共用一个素材时，画其中任一个就是画素材，其余图层同步，要单独修改其中一个，右键「设为独立素材」。旧工程里还没有素材的图层，面板顶部会提示「登记到素材库」。
- **SVG**：右键"纹理分辨率…"，输入如 `512x256`。分辨率决定进入纹理集的像素，画布上的大小不变；已经放置的图层会一起更新。
- **导出 PSD**：在文件夹上右键"文件夹导出为 PSD…"。

## 素材窗口

双击素材（或右键"在素材窗口中打开"）会打开一个独立窗口，可以自由调整大小、移到另一块屏幕。窗口打开时，在面板里单击别的素材，窗口随之切换。

- **查看**：滚轮缩放，鼠标中键或按住空格拖动平移；右下角可切棋盘格 / 白底 / 黑底，"适合窗口"（F）与 1:1（Home）。放大到 2 倍以上按像素显示。
- **绘画**：窗口里就是画布的绘画模式——左侧工具栏、底部选项栏、顶部的绘画会话栏（撤销、重做、放弃、应用）、右键菜单、笔尖与吸色的显示和全部快捷键都与绘画模式相同，只是画在素材自己的像素上。颜色和各工具的大小等设置从当前画布带过来，关窗后带回去。
- **应用**：和绘画模式一样，笔画先留在会话里，"应用"（Enter）作为一步历史写入素材，"放弃"丢掉；切换到别的素材或关闭窗口时会自动应用。绘画期间可以照常在主窗口编辑别的内容。
- **调整**：左上角"调整"菜单里可以水平或垂直翻转，以及调色相、饱和度、明度和对比度；拖动滑条时先预览，点"应用"后写入。有未应用的笔画时先应用或放弃。

所有已经放置了这个素材的图层会一起更新，画布上的位置与大小不变。SVG 素材绘画或调整后会按当前分辨率变为位图。

## 素材与图层的关联

从素材放置的图层（以及导入 PSD 时的图层）和素材是关联的：图层显示的就是素材的像素，素材是唯一的来源。

- 在绘画模式里画这种图层，画的是素材本身，所有用这个素材的图层一起变；会话栏会写明"绘画素材「…」· N 个图层共用"。整张画布都可以画：应用时落在图层网格上的部分写进素材，网格外的部分拆成一个新图层，放在它正上方，并作为新素材放在原素材旁边。
- 图层表里关联的图层名后有一个链环标记，悬停可以看到素材名和共用的图层数；点开可以"在素材窗口中打开"或"解除关联"。
- 解除关联后，图层的像素归它自己，再画不会影响素材和其他图层。其他会让图层像素与素材不同的编辑（例如拆分、用别的图片替换）也会自动解除关联。
- 用另一个素材"替换选中图层的图片"会把图层改为关联那个素材。

素材随工程保存，所有修改都可以撤销。

## 摆放

- 把素材或整个文件夹**拖到画布上**，在落点放置；也可以右键"放置到画布"。文件夹里的素材保持相对位置，子文件夹成为源图组。
- **拖入文件与素材**：从电脑拖入文件和从素材面板拖动素材用同一套落点，松手的位置决定做什么，鼠标旁的提示会先写明。拖到素材面板导入为素材（落在某个文件夹上即导入到那里）；把图片拖到层级树，落在变形器上放入它下面，落在网格的上半或下半插入到它前方或后方；拖到编辑画布时，画布下方出现大的选项：背景 / 图层中 / 前景三种参考（各自写明是否进入模型）、替换选中图层的图片、仅导入素材库（只对文件），松开在画布其他地方即在那里放置为图层。工程、PSD、CMO3、Layout 清单拖到其他地方即打开。不接受的位置不会落下，也不报错。
- PSD 来的素材默认放回它在 PSD 中的位置：PSD 的画布整体放在工程画布正中，比工程画布大时等比缩小；两者尺寸相同就是原位。其他素材按"1 素材像素 = 1 画布单位"放在画布中央，超出画布时自动缩小。
- 画布单位是模型的坐标：导出到 Cubism 后就是模型画布的像素，决定模型的大小和比例，不决定清晰度。清晰度来自素材自身的像素——摆放、缩放都不重采样，图层摆得越小纹理越密；导出时贴图还要放进纹理集预算（纹理工作区中的页面尺寸和页数），放不下时图块会一起缩小。
- 在物体模式下用变换框**移动、缩放、镜像**图层。像素不会被重采样：把一张 600×600 的眼睛缩到 64×64 的画布范围，纹理集里仍按 600×600 的密度保存（受纹理集预算限制）。
- **上下顺序**：新放置的图层在最上面，整个文件夹放置时保持文件夹里原来的上下顺序。选中图层后，用图层表工具栏的「上移一层」「下移一层」，或在画布上按 Ctrl+] / Ctrl+[ 上移、下移一层，Ctrl+Shift+] / Ctrl+Shift+[ 置顶、置底。图层表从后往前列出图层，越往下越靠前，与 Cubism 的描画顺序一致。还没生成的图层都可以调整；生成之后，已生成图层的前后用描画顺序调整，新放置的图层在重新生成前仍可调整，生成前它们暂时显示在最前面。
- **参考**：原图、设定图、草稿之类的对照图是层级树里的一类成员（参考图标），可以有多个。每个参考显示在三处之一，显示方式决定它是否进入模型：**背景**（不进入模型，只在编辑器里垫在整个模型下）、**图层中**（进入模型：是模型里的一个四点矩形 ArtMesh，添加时不做像素轮廓追踪或完整网格生成，按绘制顺序放在图层之间，可以挂到变形器下跟随变形，导出时属于参考图部件，只在导出窗口勾选「导出指南图层」时写出）、**前景**（不进入模型，只在编辑器里盖在整个模型上）。图层中的参考进入画布即为可编辑的矩形 ArtMesh，无需先生成 Rig。添加：把图片或素材拖到编辑画布，从画布下方的大选项里选显示方式；或用层级工具栏、画布右下显示栏的参考图按钮（加在前景），或素材右键「添加为参考」。在层级树里点选背景或前景的参考，编辑画布上出现手柄：拖动内部移动，拖角点等比缩放，拖上方的圆点旋转，松手才记一次历史；图层中的参考与其他 ArtMesh 一样用变换框调整。右键参考：「显示方式」在三处之间切换（各项标出是否进入模型，素材、位置、显示与固定都保留），以及显示/隐藏、不透明度与锁定（背景、前景）、恢复为模型图层（图层中）与移除。Alt+R 切换当前画布是否显示背景与前景的参考。
- **把图层设为参考**：还没参与生成的图层（生成前的任何图层、之后新放的图层）和导入的图片，可以用图层表工具栏的「作为参考」或 Ctrl+Alt+R 变成图层中的参考，画布右键菜单里也有「作为参考」开关；参考图层名字后有参考图标，点它即恢复为模型图层，已进入模型的保留网格作为普通图层。Layout 清单里标了 `reference` 的图层打开后就是图层中的参考。已生成的图层不能设为参考。
- **固定到关键形**：不同角度的参考（正面、侧面、仰视……）可以叠在同一位置，各自只在对应关键形显示，一个参考也可以出现在多个关键形上，三种显示方式都可以。右键参考，菜单下方的「固定到关键形」以参数面板的形状列出模型里有关键形的参数：一维参数是带关键形点的滑条，成对的参数是 2D pad。点关键形点即在那里打点（实心），再点取消；参考在任意一个点上显示（每个参数与点相差不超过参数范围的 0.5%），其余姿态隐藏。灰色标记是当前姿态。「取消固定」清除全部点。画布右键菜单的同名子菜单是同一个面板。固定只决定编辑器里何时显示，不写进导出。
- **替换图片**：先选中图层，再在素材上右键"替换选中图层的图片"。图层在画布上的位置与大小不变，只有像素和纹理集图块变化；纹理集视图里的右键替换也一样。

## 标签

图层表里每个图层有一格**标签**，点开即可编辑：

- 部位与侧别的词告诉生成器它是什么，例如"头发 + 前"是前发，"眼 + 瞳孔 + 左"是左眼瞳孔，"嘴 + 张开"是张嘴。菜单下方可直接选部位和侧别。
- 输入框里可以输入词表里的词，也可以输入常见图层名（如"前发"、"eye-l"），会换算成对应的词；其他文字成为你自己的标签，只用于整理和搜索，不影响生成。
- 部件角色词说明图层在部位里是什么：`highlight`（高光）、`pupil`（瞳孔）、`lower`（下睫毛）、`lid`（双眼皮线）、`shadow`（阴影）、`blush`（腮红）、`side`（侧发）、`ahoge`（呆毛）、`ponytail`（马尾）、`braid`（辫子）、`animal`（兽耳）、`ribbon`（缎带）、`pendant`（吊坠、流苏）、`rigid`（纽扣、徽章等硬质饰物）、`sleeve`（袖）、`skirt`（裙）。生成时会按图层名、所在文件夹和图层间的位置自动判断并显示在标签里；判断错了可以改写，删掉一个自动判断的角色后不再自动判断。角色只影响「部位与模块」中的模块，不改变原有生成方式。
- 开关差分、切换差分不在标签里，在旁边的"差分"栏设置。
- 给素材或素材文件夹加标签后，从它放置的图层会自动带上这些标签。

## 生成与重新生成

编辑画布右上角的生成栏显示还有什么在等待：

- **未生成**：新建的 Layout 工程。图层进入画布即有正式网格，可以编辑网格、变形器、参数和层级，也可以导出。空画布同样可以编辑；摆好后点"生成"，按标签生成自动绑定。
- **待生成 N**：生成之后放置的图层、改过标签或分类的图层。新放置的图层立即支持普通工作区的全部编辑和导出，下一次生成时再加入自动绑定。改过的分类在下一次生成前不影响 Rig（图层表里以强调色描边标出）。
- 点"重新生成"后，这些内容并入 Rig。你做过的关键形、变形器、物理、摆动、骨骼和 Glue 会保留；不能干净迁移的内容会在质量检查中列出。
- 替换过图片的图层默认会按新像素重新生成网格；如果想保留原来的网格，在生成按钮的下拉里选"生成但保留替换图片的几何"。

生成一次的耗时与导入同样大小的 PSD 相当。
