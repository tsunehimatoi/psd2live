# 画布编辑器

编辑页使用一个画布完成选择、网格、笔刷、变形器和路径编辑。左侧为工具栏，顶部为当前工具的属性栏，底部显示选区、操作提示或提交错误。图标、颜色和紧凑控件沿用程序现有主题。

## 操作逻辑

- **选择与变换分开**：V 是选择工具，只负责点选、框选和套索，选中后画一圈细轮廓，拖动不会改变几何。T 是变换工具，在选区上显示包围盒、八个手柄和旋转柄，拖本体移动、拖角边缩放、拖圆圈旋转。两者共享同一份选区，来回切换不丢失。
- **对象与控制点分开选择**：V / T 处理整个对象；Tab 进入网格控制点编辑，再按 Tab 返回对象选择。W 编辑变形器。框选和套索沿用当前选择层级。
- **直接编辑**：控制点、路径节点和形变笔刷直接作用于画布中的模型。变换工具下按 X 或 Y 把拖动约束到单轴，画布上会画出对应的轴向参考线，再按一次解除。
- **上下文属性**：只显示当前工具的半径、强度、拓扑操作、路径属性或精确变换输入。较窄窗口可横向滚动属性栏。
- **一次手势，一条历史**：拖动期间显示临时预览，释放鼠标后写入工程历史。Esc 放弃当前拖动或未完成的路径。Ctrl+S 保存工程；提交期间的保存会排队到提交结束。

交互参考：[Cubism 形变笔刷](https://docs.live2d.com/en/cubism-editor-manual/deform-brush/)、[Photoshop 上下文任务栏](https://helpx.adobe.com/photoshop/desktop/get-started/learn-the-basics/boost-workflows-with-the-contextual-task-bar.html)、[Blender 选择操作](https://docs.blender.org/manual/id/3.0/interface/selecting.html)。本程序采用与现有模型、参数及历史结构相匹配的实现。

| 单轴约束 | X / Y（仅变换工具拖动本体时） |

| 变形器控制点 | W |
| 推拉 / 平滑 / 膨胀笔刷 | B / Shift+B / I；推拉时按住 Shift 临时平滑 |
| 膨胀 / 收缩切换 | 按住 Alt 临时反转，或用属性栏的膨胀／收缩切换 |
| 笔刷半径 / 硬度 | [ / ] 调半径；Shift+[ / Shift+] 调硬度 |
| 调整笔刷（PS 式） | 按住 Alt 用右键拖动：左右调半径，上下调硬度（向下更硬），一次只改一个 |

| 平移视图 | 空格＋左键、中键，或 H 工具 |

## 网格与笔刷

选择画元后按 Tab，可切换点、边、面选择。选区支持拖动、框选、套索、移动、旋转及缩放（整个对象的变换用 V 选中后再按 T）。

- **细分边**：选中一条边的两个端点，在该边中点加点并分割相邻三角形。
- **连接**：选中两个可连接的点，沿网格建立连接。
- **合并**：将所选顶点合并到其中心。
- **删除**：删除选中顶点及引用它们的三角形；拒绝产生空网格。

拓扑修改同步调整关键形状、混合形状与 Glue 顶点引用，并重新绑定该画元的路径控制点。

笔刷是**形变笔刷**，修改几何形状。圆圈表示半径和硬度范围；半径按**画布尺寸**（文档像素）计，缩放画面时圆圈跟着一起缩放，因此在任何缩放下覆盖的都是同一块区域。无控制点选区时作用于当前画元或 Warp 的全部点，有选区时仅影响选中的点。平滑笔刷按相邻顶点平均位置平滑。

膨胀笔刷把顶点沿「离笔画最近点」的径向向外推，用于整体鼓起或收拢一块区域，不依赖拖动方向。位移量与光标走过的距离成正比，因此停住不动时不会继续变形；按住 Alt 或切换属性栏的收缩模式即可向内收（收缩时圆圈转为琥珀色）。方向在按下鼠标时确定，一笔之内不会中途反向。

按住 Alt 用右键在画布上拖动可随时调节笔刷：左右拖动改半径，上下拖动改硬度（向下更硬），方向与 Photoshop 一致。为避免误改，一次拖动只会锁定其中一个——位移超过 4 像素后按主轴判定，锁定后直到松手都不会再动另一个。拖动时笔刷停留在按下点不动，并按真实衰减曲线叠加一层红色预览（与 Photoshop 的笔刷预览一致），旁边的浮层列出半径、硬度、强度，正在调整的那一项高亮显示。方向在按下右键时确定，中途松开 Alt 不会中断。Esc 取消并恢复拖动前的数值。

## 变形器

从层级树选择 Warp 或 Rotation 后，可直接编辑控制点，或按 T 用变换工具整体移动、旋转、缩放。旋转变形器显示原点与方向端点；拖动原点平移，拖动方向端点调整方向和比例。

W 工具的属性栏可为选中画元创建 Warp。多个画元需要共享父变形器。创建后自动选择新的变形器，初始形状保持原有外观。

**创建根旋转**会包裹所选画元所属的整个根变形器分支，因此也影响该分支下的其他画元。它从零角度、单位比例和画布原点开始；这避免了在非线性 Warp 内插入旋转时破坏原有姿态。

## 变形路径

选择画元，按 P 或点击路径工具，在画布上单击添加至少两个控制点，按 Enter 完成。也可以使用“新建路径”和“完成”按钮。

- 拖动节点调整路径绑定位置。
- 单击曲线选择路径；Ctrl＋单击曲线插入控制点。
- “续接”为开放路径追加节点。
- 属性栏支持闭合／开放、角点切换、影响宽度、硬度，以及 L2／L3 编辑层级。
- Delete 删除选中控制点；没有节点选区或路径只剩两个点时删除整条路径。
- 按 D 后拖动节点，将路径形变写入当前画元几何。

路径辅助线只在该路径所属画元（或该画元所属变形器）被选中时，且在编辑标签页绘制；未选中任何部件时画布不显示路径，预览标签页也不显示。在层级树中悬停部件可临时预览其路径。

路径形变继续使用项目现有算法；其与 Cubism 的效果一致性仍以[变形路径说明](DEFORM_PATHS.md)中的限制为准。

## 基础形状与参数姿态

未绑定参数的对象默认编辑基础形状。已绑定参数的对象编辑当前参数组合，自动包含全部直接绑定的几何轴。属性栏可以选择额外参数，把编辑写入该参数当前值的关键形状。

改变参数后再编辑即可制作其他姿态。拓扑操作作用于所有关键形状；普通形变操作作用于当前编辑目标。每次成功提交都进入现有版本历史，并通过现有工程保存和导出流程重放。
