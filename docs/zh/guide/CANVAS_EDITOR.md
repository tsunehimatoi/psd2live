# 画布编辑器

编辑页使用一个画布完成选择、网格、笔刷、变形器和路径编辑。左上为**模式条**，左侧为当前模式的编辑工具栏，右侧检查器为当前工具的属性，底部显示选区、操作提示或提交错误。画布**右键**打开按模式/工具变化的上下文菜单（绘画参数、拓扑操作、撤销等）；图标、颜色和紧凑控件沿用程序现有主题。

## 操作逻辑

右上角切换 **选择 / 变形 / 编辑 / 绘画**。选择层级只选择对象；变形层级调整参数姿态和控制点；编辑层级处理网格拓扑；绘画层级修改纹理。

创建 Warp / Rotation / 路径通过**层级树右键**或快捷键（C / R / P）开始，采用 **放置确认**：指定「为谁、父级还是子集」后，画布出现可拖动的幽灵与左下角参数面板，确认后才写入；Esc 取消。

拖动期间预览，松手提交一条历史。Esc 取消当前笔画、变换、创建、Glue 首选或草稿，并清理控制柄状态。保存失败时切割草稿保留；Backspace / Delete 可退回一个草稿点。

工具属性按上下文显示。创建工具需要先选画元；未选择时点击画元会先选中并提示下一步。可拖动创建，或点击“按选区创建”。创建成功后自动选中新变形器并回到选择工具（开启「连续创建」时保持创建工具）。

## 网格与笔刷

选择画元后进入编辑层级，可在属性面板切换点、边、面选择。选区支持拖动、框选、套索、移动、旋转及缩放。细分边、连接、删除等拓扑操作在**画布右键菜单**与右侧工具详情中提供。

- **细分边**：可 Shift 加选多条边并一次在每条边的中点加点；边选择会准确保留所选边，不会顺带细分端点之间的其他边。只选中一个顶点时细分其所有相邻边，面选择会处理所选面的全部边。
- **连接**：选中两个可连接的点，沿网格建立连接。
- **合并**：将所选顶点合并到其中心。
- **复制**：把所选顶点及其完全覆盖的面复制一份接在末尾，新副本成为选区，便于紧接着拖动。
- **细分**：把选中区域里**两端都被选中**的每条边从中点切开，单顶点选区则处理所有相邻边。一个三角形按被切边数 0/1/2/3 变成 1/2/3/4 个，接缝处不会留下 T 型顶点。同一条规则也做成了笔刷（M）：落点半径内的边会被切开，悬停预览将细分的边，拖动时按笔刷扫过的边并集累积，松手一次提交。
- **删除**：删除选中顶点，并**把留下的环形轮廓重新三角化**补上——以前只丢掉引用它们的三角形，画面会真的破一个洞。补出来的面在画布上画得淡，提示它是临时的；这个标记只活在本次会话里，下一次提交或取消就消失。删除落在轮廓上时，缺口用一条弦闭合后再补，那一段轮廓会从曲线变成直线。耳切补不动时整个删除被拒绝，而不是留下半补的面。
- **切割刀**（K）：沿切割线逐点单击。吸附恒定开启，没有开关：落点进入吸附半径（默认 10 屏幕像素，可在属性栏调 3–30）内的顶点或边就吸附上去——顶点优先，边取指针正下方那一点而不是边中点——半径外则落一个新点；Shift 临时关闭吸附。指向下一点的切割虚线画成红色，吸附时指针环变红并放大；网格内外均可自由落点，外部点会扩展网格轮廓；每个落点在提交时变成真实顶点，相邻两点之间沿直线切开经过的三角形。`Enter` 完成，`Esc` 取消。整条折线要么全成要么全不成——中途被拒时草稿保留，可以退一步重来。

拓扑修改同步调整关键形状、混合形状与 Glue 顶点引用，并重新绑定该画元的路径控制点。

以上所有网格编辑都只改控制点、不改画面：新顶点由源顶点**按同一组权重**同时算出位置与 UV，所以贴图仍然钉在原来的像素上。新顶点可由本次切割产生的顶点继续插值得到，来源权重最终合成为原始网格顶点的权重，用于关键形状和 UV 的重建。

笔刷是**形变笔刷**，修改几何形状。圆圈表示半径和硬度范围；半径按**画布尺寸**（文档像素）计，缩放画面时圆圈跟着一起缩放，因此在任何缩放下覆盖的都是同一块区域。无控制点选区时作用于当前画元或 Warp 的全部点，有选区时仅影响选中的点。平滑笔刷按相邻顶点平均位置平滑。

膨胀笔刷把顶点沿「离笔画最近点」的径向向外推，用于整体鼓起或收拢一块区域，不依赖拖动方向。位移量与光标走过的距离成正比，因此停住不动时不会继续变形；按住 Alt 或切换属性栏的收缩模式即可向内收（收缩时圆圈转为琥珀色）。方向在按下鼠标时确定，一笔之内不会中途反向。

按住 Alt 用右键在画布上拖动可随时调节笔刷：左右拖动改半径，上下拖动改硬度（向下更硬），方向与 Photoshop 一致。为避免误改，一次拖动只会锁定其中一个——位移超过 4 像素后按主轴判定，锁定后直到松手都不会再动另一个。拖动时笔刷停留在按下点不动，并按真实衰减曲线叠加一层红色预览（与 Photoshop 的笔刷预览一致），旁边的浮层列出半径、硬度、强度，正在调整的那一项高亮显示。方向在按下右键时确定，中途松开 Alt 不会中断。Esc 取消并恢复拖动前的数值。

## 变形器

从层级树选择 Warp 或 Rotation 后，可直接编辑控制点，或按 T 用变换工具整体移动、旋转、缩放。旋转变形器显示原点与方向端点；拖动原点平移，拖动方向端点只调整方向并保持比例；按住 Alt 拖端点只调比例，Shift 旋转时吸附到 15°。属性面板提供精确变换输入。

### 创建流程（Blender 式放置确认）

1. **在层级树右键**目标节点，选择「在父级添加…」或「在子集添加…」（画元上还可「添加变形路径」）；或用快捷键在当前选区上开始。
2. 进入**放置模式**：画布出现半透明幽灵（网格框或旋转轴），左下角面板显示**为谁创建、父/子关系、名称、部件、转换分割、贝塞尔分割**。
3. 在画布上**拖动框体/角点**调整位置与大小（旋转则拖原点与端点）。幽灵上的实线格 = 转换分割（写入模型），虚线格 = 贝塞尔编辑分割。
4. 点「确认创建」或按 Enter 提交；Esc 取消。提交前不写入工程。预览框位置与确认后的变形器一致（含挂在父级 Warp 下时）。

面板会写明例如「作为『头发』的父级添加 · 将影响 3 个画元」，避免不知道建在哪、给谁建。

### 创建网格变形器（快捷键 C / 树右键）

- **在父级添加**：新 Warp 成为锚点的父（画元改挂其下，或插入到变形器之上）。
- **在子集添加**：新 Warp 挂在所选变形器下（可为空格子，或先包住其下画元）。
- **转换的分裂数量**（默认 5×5）：格子控制点密度，写入 `rows`/`columns`。
- **贝塞尔分割数**（默认 2×2）：变形 L2 编辑手柄密度，创建时一并记下。
- 创建时写入 `partId`（默认同步锚点部件）。

### 创建旋转变形器（快捷键 R / 树右键父级）

插入为所选画元或变形器的**直接父级**（挂在原父级之下），不再抬到整根分支顶。放置时高亮实际影响范围；拖枢轴与方向后确认。原点与角度按父级局部坐标写入（Warp 下为 UV）。

## 变形路径

变形路径与 ArtMesh **同级**（挂在网格上的编辑辅助，不是 deformer）。树右键画元 →「添加变形路径」，或快捷键 P。单击加点 → Enter / 确认完成 → 回到选择工具调绑定。

- 拖动节点调整路径绑定位置。
- 单击曲线选择路径；Ctrl＋单击曲线插入控制点。
- “续接”为开放路径追加节点。
- 属性栏支持闭合／开放、角点切换、影响宽度、硬度，以及 L2／L3 编辑层级（创建时显式显示当前 Level）。
- Delete 删除选中控制点；没有节点选区或路径只剩两个点时删除整条路径。
- 在变形模式拖动路径控制点，将路径形变写入当前画元几何。

路径辅助线只在该路径所属画元（或该画元所属变形器）被选中时，且在编辑标签页绘制；未选中任何部件时画布不显示路径，预览标签页也不显示。在层级树中悬停部件可临时预览其路径。

路径形变继续使用项目现有算法；其与 Cubism 的效果一致性仍以[变形路径说明](DEFORM_PATHS.md)中的限制为准。当前仅支持单 ArtMesh。

## 基础形状与参数姿态

未绑定参数的对象默认编辑基础形状。已绑定参数的对象编辑当前参数组合，自动包含全部直接绑定的几何轴。属性栏可以选择额外参数，把编辑写入该参数当前值的关键形状。

改变参数后再编辑即可制作其他姿态。拓扑操作作用于所有关键形状；普通形变操作作用于当前编辑目标。每次成功提交都进入现有版本历史，并通过现有工程保存和导出流程重放。

## Glue

G 工具依次点选两个不同画元，按当前参数姿态的世界坐标匹配邻近顶点。属性面板可调整匹配距离；每侧顶点最多匹配一次，没有可匹配点时给出错误。创建经过统一历史入口，重放保持同一个 Glue ID。

## 验证范围

执行 Kotlin 编译与自动回归测试，覆盖旋转创建保持姿态、跨 180° 旋转连续性、Glue 创建与日志重放、吸附投影和角度约束。未进行 GUI 鼠标操作验收和实际模型导出验收。
