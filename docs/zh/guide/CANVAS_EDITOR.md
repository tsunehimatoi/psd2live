# 画布编辑速查

[文档目录](../../README.md) · [操作速查](USER_GUIDE.md) · [前后分层图文教程](DEPTH_SPLIT.md) · [变形路径](DEFORM_PATHS.md)

对应程序内零基础路线第 3、6–12 课。本页按主题整理画布上的编辑规则；具体按钮位置和当前快捷键以帮助页的 **教程** 为准。

## 先选模式，再选工具

画布左上角的模式菜单（类似 Blender 的模式下拉列表）列出全部模式，菜单打开时可按 1–7 直接选择、方向键移动、Enter 确认。「预览」也在这个菜单里，作用与原来标题栏的「预览」相同；在预览画布上选任意其他模式即回到编辑。

| 模式 | 修改内容 | 常用工具 |
| --- | --- | --- |
| 物体 | 对象选区 | 点选、框选、套索；与层级树同步；内部造型手柄；工具栏「创建」 |
| 变形 | 基础形状或当前参数关键形 | 点 / 边 / 面选择、变换、推拉、平滑、膨胀、路径控制点 |
| 编辑 | 网格拓扑与路径绑定 | 点 / 边 / 面选择、布点（点 / 线）、连接、合并、细分、删边、重新三角化、删除、胶水（选中两张网格时可用） |
| 模拟 | 模拟读取的顶点权重组（仅本软件） | 权重笔刷、权重渐变，其下按种类（固定点、刚度等）切换要画的组；模式条可新建布料 / 头发、切换参考模拟（不导出） |
| 骨骼 | 骨架 | 姿态、骨骼编辑；切到姿态或退出模式时保存骨骼编辑 |
| 绘画 | 图层像素 | 画笔、铅笔、橡皮、模糊、填充、渐变、吸管、形状、选区 |
| 预览 | 不修改 | 播放、鼠标跟随、物理、帧率 |

模拟模式与编辑模式一样同时作用于所有选中的网格，并始终以 Blender 的权重色（蓝 0 → 绿 → 黄 → 红 1）显示当前权重组。权重笔刷的圆环按模式着色（增加白、减少红、设为强调色、平滑青），悬停时圆环标出按下会影响的顶点，指针旁的数字是最近顶点的权重；Alt + 右键拖动调整半径 / 硬度并预览衰减。权重渐变从满值拖到淡出位置。模拟本身只在编辑器内运行，要导出须在模拟面板烘焙，见[模拟与烘焙](SIMULATION.md)。

当前工具的设置分几处，各有分工：

| 位置 | 内容 |
| --- | --- |
| 左侧工具栏 | 当前模式的工具，每个工具一行，按类别以分隔线分组；物体模式下最后一组是创建 Warp、Rotation 与变形路径。选中工具的变体（笔刷形状、绘画形状、选区方式、胶水与骨骼子工具、权重组种类）在工具下方展开，`1`–`5` 也可选择 |
| 模式条（画布顶部） | 模式菜单之后是决定画布如何操作的项：变形 / 编辑模式选择类工具的点 / 边 / 面（`1`–`3`），以及当前步骤的确认与取消（放置、切割、路径、胶水等） |
| 工具选项栏（画布左下角） | 当前工具的数值：半径、强度、硬度、不透明度、模式等；左右拖动数值调节，单击向上弹出滑块。绘画模式下最前面是前景 / 背景色 |
| 画布右键菜单 | 与模式条、选项栏同一组设置（每项一行），加上该工具的操作，每个操作带图标；打开和悬停的动画与模式菜单相同。物体模式下，创建 Warp、Rotation、变形路径、骨骼和摆动统一收在「创建」二级菜单中。物体、编辑和绘画模式下，对图层整体的操作也各有二级菜单：「网格」里是按当前像素重建网格、拆分独立网格，以及可用时的前后分层；关联素材的图层另有「素材」，可在素材窗口中打开或解除关联。其余内容不超过 10 行时全部直接显示；超出时才把最大的组（如拓扑、衰减）折叠为一行，悬停时在右侧展开。各面板的右键菜单（层级树、素材、纹理集、动作、物理等）与画布菜单的外观和打开动画相同：从按下处展开，靠近窗口边缘时翻到另一侧 |

模式条、选项栏与右键菜单显示的是同一份定义，范围一致；`[` `]` 等笔刷快捷键调整的也是当前工具在选项栏中的同一个值。右侧「工具细节」面板只保留需要更多空间的高级设置：精确数值变换、Warp / Rotation 的创建默认值、路径列表、骨骼绑定与权重、绘画调色板。蒙皮权重的显示在右下角的显示栏中开关。

默认滚轮缩放，中键或空格 + 左键平移，Shift 加选、Alt 减选。

固定点权重笔刷的操作截图与烘焙流程见[模拟图文教程](SIMULATION_TUTORIAL.md)。

## 画布上的点与线

所有模式下可编辑的点和线外观一致，颜色各有固定含义：

| 外观 | 含义 |
| --- | --- |
| 浅色细线与小点 | 正在编辑的网格或 Warp 网格；同时编辑多个网格时各用自己的颜色区分 |
| 强调色、放大并带白边 | 已选中的点、边、面 |
| 白色外圈 | 悬停的点，即单击会选中的点 |
| 红色圆圈 | 笔刷按下会推动的点，圈越大越实表示受影响越强；悬停时就显示，拖动时保留 |
| 强调色圆圈 | 选择笔刷按下会选中的点 |
| 权重色（蓝 → 红） | 模拟与骨骼的权重 |

点的形状表示它是什么：网格顶点为圆点，Warp 控制点为方点，胶水点为菱形。只有能直接点选的点才会显示；右下角显示栏的网格开关只画各部件的网格线（各用部件自己的颜色），不再画点。正在编辑的网格或 Warp 由画布直接绘制，显示栏不再重复画一份。

## 形变与关键形

未绑定参数的对象编辑基础形状；已绑定对象编辑当前参数组合。目标是网格变形器（Warp）时，模式条上可切换「顶点」（编辑网格点）与「贝塞尔」：贝塞尔下只能拖动青色锚点与琥珀色手柄，详细网格变淡显示且不可编辑；其他对象两者没有区别，不显示。先在参数面板设置目标值，再调整控制点。检查对象自身的轴和父级继承运动，避免把父级姿态误当作当前对象的直接绑定。

变形模式的画布右键菜单「镜像关键形」把当前键的关键形沿竖直线左右镜像，结果写成普通关键形，可撤销：

| 操作 | 作用 |
| --- | --- |
| 镜像到对称键 | 把当前键镜像到对称键（如 AngleX 30 → −30），随后切换到该键显示结果；快捷键 `Shift+M` |
| 从对称键镜像 | 反向：用对称键的形状覆盖当前键 |
| 镜像到对侧对象 | 写到另一侧的同类对象（左眼 → 右眼），键随之镜像：带 L/R 的参数换成另一侧（EyeLOpen → EyeROpen），左右参数取反 |
| 原位左右翻转 | 以对象自身中心翻转当前键 |
| 全部键镜像到另一侧 / 到对侧对象 | 一次处理所有键：同一对象只复制当前姿势所在一侧的键 |

取反的「左右参数」是范围以默认值对称、且为二维关联横轴或 ID 以 X、Z 结尾的参数（AngleX、AngleZ、BodyAngleX、EyeBallX 等）。对侧对象先按图层语义配对，再按 ID 或名称中的 L/R、Left/Right、左/右配对。镜像只处理对象自身的形变，以默认姿势的父级为坐标系；父级的关键形需单独镜像。选中多个图层时对每个网格分别镜像，在一条历史中提交。

同一右键菜单的「关键形」处理当前键的形状，结果同样写成普通关键形，可撤销。参数须正好在对象的键上：

| 操作 | 作用 |
| --- | --- |
| 复制关键形 | 记下当前对象在当前参数下显示的形状；快捷键 `Ctrl+Alt+C` |
| 粘贴关键形 | 把复制时定格的形状作为位移写到当前键（网格相对原形，Warp 与旋转变形器相对默认键形状）；可写回原对象，或写给同类、三角形（Warp 为行列）相同且父级相同的对象；`Ctrl+Alt+V` |
| 重置为默认键形状 | 把当前键改回各参数取默认值时的形状；`Ctrl+Alt+X` |
| 重置为网格原形 | 仅网格：改回未变形的网格 |
| 按（参数）的相邻键补间 | 用该参数两侧相邻键的形状按位置插值，重做当前键；有多个可补间的参数时逐个列出，快捷键 `Ctrl+Alt+I` 取第一个 |
| 按选项粘贴… | 对话框中选择粘贴内容（形状、不透明度、绘制顺序、正片叠底色、滤色）、混合比例（100% 为粘贴，较小时按比例混合）、左右 / 上下翻转（Warp 反转列 / 行，网格须静止形状对称，按镜像位置对应顶点），并逐行确认每个复制的形状粘贴到哪个对象 |
| 全部键恢复为默认键形状 | 对象的每个键都回到默认键形状，从头再来 |
| 多键编辑… | 按参数键值选范围，一次修改多个对象、多个关键形的不透明度、绘制顺序和颜色（覆盖、相加、相乘或滤色） |

复制时选中的每个网格各记一份形状；粘贴时写回自身，或依次配给下一个能接收它的选中对象，所有形状都按复制时的样子写入。选中了点时，粘贴、重置与补间只改选中的点，菜单行标出点数；Warp 在「贝塞尔」级别与旋转变形器总是整体处理。改动生成器拥有的关键形的形状时记为生成结果覆盖。参数不在对象的键上或对象未绑定参数时，菜单会说明原因。

**软选择**：选择或变换工具下打开工具选项栏的「软选择」（`O`），拖动或变换选中点时，周围的点按到最近选中点的距离衰减跟随。「影响范围」以画布单位计，可用 `[` / `]` 调整；衰减曲线与形变笔刷共用。受影响的点以红色圆圈标出，圈越大跟随越多。提交的仍是一次普通的几何编辑。

**临时变形**：`Shift+T` 或右键菜单「临时变形（网格）」在选中点（无选择时为整个网格或 Warp）上铺一张一次性网格，拖动网格点时其中的点按双线性插值跟随，每次松开为一步历史。参数不在键上时按下先吸附到键，形状已被其他操作改变时按下会按当前形状重铺网格，这两种按下都不开始拖动，再按一次即可。工具栏「网格」切换 1×1–4×4；Enter、Esc 或「完成」结束，网格本身不保存。

## 多画布、参数与动画

同一工作区的所有画布共用参数姿态、参数锁和播放控制。切换编辑／预览模式、切换焦点或隐藏画布都不会换回另一份姿态。选区、工具、镜头与显示设置仍由各画布分别保存；不同工作区保留各自姿态。

在编辑画布拖动参数或用骨骼摆姿态会暂停动画，直接显示编辑值；重置参数和吸附关键点不会自动加锁。动画编辑器拖动时间轴会把采样姿态送到工作区，编辑画布也能查看和继续调整。编辑取值不会使用之前播放留下的预览帧；摆姿态时，鼠标跟随和暂停物理不会覆盖它。重新开启播放或切换鼠标跟随可回到动态预览。在预览画布调参数仍可观察暂停物理的响应。

动画轨道名称旁的小标尺显示参数关键点，曲线视图以带数值的参考线显示同一组关键点。删除参数会移除对应动画轨道，收缩参数范围会同步限制动画键值和贝塞尔控制点。

播放、时间轴和烘焙不会自动新建、显示或切换画布。需要画布时，可通过窗口菜单或面板中的显示画布按钮手动打开。

## 形变笔刷

形变笔刷修改几何，不修改贴图。无控制点选区时作用于当前对象的全部点；有选区时限制在选中点。半径按画布单位计算。默认 Alt + 右键拖动调整半径或硬度，Esc 取消当前手势。

笔尖形状在左侧工具栏的笔刷下方选择（权重笔刷相同）；其余设置在工具选项栏和画布右键菜单中：

| 设置 | 作用 |
| --- | --- |
| 形状 | 圆形、直线或矩形 |
| 半径 / 硬度 / 强度 | 作用范围、边缘软硬与每次推动的力度 |
| 衰减 | 从中心到边缘的权重曲线：平滑、球状、根凸、平方反比、锐利、线性、常值、随机 |
| 仅相连项 | 只影响与指针下方网格相连的点；圆形笔刷改为沿网格边测量距离 |

![形变笔刷的设置面板，以及开启「仅相连项」后的作用范围](../../imgs/mesh-brush.webp)

*左：笔刷设置。右：开启「仅相连项」后，圆圈虽然覆盖了相邻发束，受影响的顶点（红色）仍只在指针所在的那一缕上。悬停时这些顶点就以红色圆圈标出，圈越大受影响越强。适合分开刷相邻的发丝、上下唇这类靠得很近的部件。*

## 网格拓扑

| 操作 | 结果 |
| --- | --- |
| 细分边 / 区域细分 | 对命中的边加点并重组三角形；相邻面同步处理接缝 |
| 连接 / 合并 | 建立选中点之间的连接，或将选中顶点合为一点 |
| 复制 | 复制选中顶点及其完整覆盖的面，新副本成为选区 |
| 删除 | 删除选区并尝试重建缺口；无法形成合法拓扑时拒绝操作 |
| 删除边 | 删除选中的边（边模式下按 `Del`，或拓扑菜单「删除边」）：内部边在两侧三角形组成的四边形内换到另一条对角线，四边形在静止形或任一关键形、混合形中不凸时拒绝（否则摆姿态时会翻面）；轮廓边删掉所在三角形，不再被使用的顶点一并删除；会让顶点只靠一点相连或删光三角形时拒绝 |
| 重新三角化 | 拓扑菜单：在选中顶点周围（不选则全网格）把细长三角形翻成更均匀的连接；顶点、轮廓与贴图都不动，已经最均匀时提示无需处理 |
| 布点 | 自动布点需要修正时逐点调整：「点」加点、移点、删点，「线」沿一条线加相连的边，见下文 |

### 布点

编辑模式工具栏中拓扑组的第一个工具，普通网格与带内部造型的网格都可使用。它有两种模式，在选项条或工具栏下方切换，也可直接按各自的快捷键：

| 模式 | 快捷键 | 用途 | 日志命令 |
| --- | --- | --- | --- |
| 点 | `Alt+M` | 加点、移点、删点，调整网格密度；每次单击或每一笔立即提交，新点周围的连接由网格自动整理，点与点之间**不保证有边** | `add_points`（及 `connect` / `delete` / `delete_edges`） |
| 线 | `K` | 逐点单击画一条折线，Enter 一次提交；每点都与上一点连成边，网格可沿这条线**折弯**（眼睑、嘴线、褶皱） | `knife` |

两种模式落点规则相同：指针靠近顶点或边时吸附（共用一个吸附半径，Shift 在「线」模式下临时关闭吸附），悬停处显示按下会落到哪里，都可以落在网格外。

#### 点

| 操作 | 结果 |
| --- | --- |
| 单击空白处 | 在该处加一个顶点：落在三角形内则把它分成三个，落在边上则拆分这条边，在网格外则从最近的可见轮廓边长出一个三角形 |
| 在空白处拖动 | 沿笔画每隔「布点间距」（画布像素）加一个顶点，整笔一次提交 |
| 拖动顶点 | 移动顶点，与选择工具相同：贴图不动，胶合的点一起移动 |
| Shift + 单击顶点 | 从当前选中的一个顶点连线到它，之后选区移到它上面，连续 Shift + 单击即可连成折线 |
| Alt + 单击 | 删除顶点（并补上缺口）或删除边 |

#### 线

逐点单击，每次单击落下一个锚点：落在顶点上就用这个顶点，落在边上就拆分这条边，落在三角形内或网格外则新加一个顶点；相邻两个锚点之间连成边，经过的边被拆分。Enter（或模式条的「完成画线」）一次提交整条线，Delete 退回一点，Esc 取消。连不上（会与网格重叠）时整条拒绝、草稿保留，可退回最后一点重新放。

#### 共同说明

新顶点的位置、UV、关键形、混合形状和顶点权重都由周围原顶点按同一组权重得出，所以加点不会让画面移动；加点后在不改变贴图的前提下翻转周围的边，减少细长三角形。打开「左右对称」时，加点、删除和删边会在以网格当前包围盒竖直中线为轴的对称位置同时进行（对称位置上没有点或边时只处理本侧）。右键菜单的选区组另有「选择轮廓顶点」「选择内部顶点」，方便只调整边界或只调整内部。

带内部造型的网格在加点、删点、删边、重新三角化或移动静止形顶点后，会在同一步里按新网格重新烘焙造型；新网格无法通过造型的面积检查时，编辑照常提交，内部造型面板提示网格已变化、需要重新生成。

拓扑更新同时处理 UV、关键形、混合形状与 Glue 顶点引用，并重新绑定路径。仍应检查已有姿态，特别是删除轮廓点后边界的变化。

## 内部造型手柄

物体模式的「内部造型手柄」（Shift+I，或内部造型面板工具条的「画布编辑」，在其他模式中按下会切到物体模式）在选中网格上直接调整[内部造型](../spec/INTERIOR_SURFACE.md)；物体模式不画网格顶点，手柄不会和顶点挤在一起。网格还没有效果或效果已关闭时，选项条提示并可一键开启；单击其他物体即改为选中它，手柄随之移过去。

| 手柄 | 作用 |
| --- | --- |
| 中心十字 | 上臂鼓起、左臂偏压、右臂横向幅度、下臂纵向幅度；臂越长数值越大，到虚线框边为 2 |
| 拱线 | 实线为静止时的虚拟拱面，虚线为满输入时按偏压倾斜的拱面（示意） |
| 箭头 | 开启缓动与传动时显示；拖两端改起点 / 终点，拖中点整体平移 |
| 引导线 | 在网格上或画布空白处单击开始画褶皱线，单击最后一点或 Enter 完成；拖点移动，拖线段平移整条线，Ctrl+单击加点，Alt+单击删点，Delete 删除所选点或整条线；选中的褶皱线可拖半径手柄 |

悬停时手柄与线条高亮，状态栏显示名称与数值。每次拖动松手只记一条历史，Esc 取消拖动；面板数值与手柄实时同步。开启试动后拖动时可直接看到造型变化。

## 特征点

物体模式的 **特征点** 工具（默认 `Shift+Y`）显示拟合五官的手柄：每只眼的内外眼角与上下睑中点、每条眉的两端与眉峰、嘴的两个嘴角与上下唇中点（只在这些部位使用拟合的基础算法时出现）。拖动手柄后松开，五官按新的位置重新拟合，开合、笑眼、情绪、口型等所有姿态随之更新；睑缘或唇缘在中点处跟随最多、在两端跟随眼角或嘴角。修改记入 Rig 配方，一次拖动是一步历史，重新生成后保留；被移动过的手柄画成方形，`Alt` + 单击使它回到原画位置；选项栏的 **复位此特征** 与 **复位全部特征** 一次撤回整个特征或全部特征的移动。MCP 用 `settings_update` 的 `changes.rig.moves` 修改同一份数据。

## 创建与素材放置

1. 选中目标，在物体模式工具栏最后一组选 Warp、Rotation 或变形路径，或直接按 `C` / `R` / `P`；也可在层级树右键选择添加父级 / 子级 Warp 或 Rotation，或在物体模式的画布右键菜单「创建」中选择。
2. 调整画布中的放置预览，核对影响对象、名称、父级和分割设置。
3. 点模式条上的「确认」或按 Enter 写入工程；点「取消」或按 Esc 取消。

将 PNG / WebP / TIFF / BMP 拖到层级树，或用树右键「导入图层…」，也会进入放置会话。拖到画元时，新层挂在该画元的父变形器下。完成放置后检查遮挡与多参数姿态。

## 变换框

「变换」工具、Warp / 图层的放置框和纹理集页面上选中的图块使用同一个变换框，外观和操作一致。变换工具在没有选中任何内容时与选择工具相同，可点选或框选，选中后即出现变换框：

| 操作 | 效果 |
| --- | --- |
| 拖动框内 | 移动 |
| 拖动角点 / 边中点 | 缩放，对边保持不动；`Shift` 拖角点保持比例，`Alt` 以锚点为中心缩放 |
| 拖动顶边外的圆形手柄，或角点外侧（悬停时角点外亮起带箭头的弧线） | 绕锚点旋转，`Shift` 以 15° 步进 |
| 拖动锚点（带描边的十字圆圈） | 移动锚点，靠近中心、角点或边中点时吸附，拖回原位即恢复默认 |

锚点默认在选区中心（各点的重心），对选区在框中的相对位置保持不变，移动、缩放、旋转后仍跟着选区走；「精确数值变换」的旋转和缩放也以它为中心。换选区或按 Esc 退出工具时锚点回到默认位置。拖动时指针旁显示旋转角度、两边的缩放比例或移动的画布像素，其余手柄变淡。框在屏幕上不足 40 像素宽或高时，按中间总是移动，锚点不能拖动（放大视图即可）。Warp 和图层的放置框按矩形创建，只能移动和缩放，不能旋转；纹理集图块的角点按比例缩放密度，没有边中点。

## 旋转变形器

拖动原点平移，拖动端点旋转；默认按住 `Shift` 吸附角度，`Alt` + 拖端点调整比例。

## 多网格编辑

编辑模式同时作用于所有选中的画元：

- 顶点点选、框选、笔刷选择、变换框和形变笔刷都跨网格生效。
- 点选某个网格的顶点会把它设为**主网格**；布点的「线」、边 / 面模式和路径只作用于主网格。
- 删除等顶点操作对每个有选区的网格一次提交，进入同一条历史记录。

## Glue

选中两张网格后在编辑模式选 Glue 工具，工具栏中其下列出三个子工具：胶水刷、权重笔刷、重新合并（`1`–`3`）。胶水点是两个网格共享的同一个点，画布上显示为一个菱形。选中或拖动时两侧顶点总是一起移动，编辑时不会因胶合而错位。

与 Cubism 相同，胶合在网格的静止形（所有参数为默认值）上进行，胶合点在静止时两侧重合、不产生拉扯。参数不在默认值时，胶水刷、重新合并、「创建胶水」与胶合选中顶点会先把参数平滑移回默认值再胶合；调权重与解除胶合不改变姿态。

| 操作 | 效果 |
| --- | --- |
| 胶水刷 | 只改网格、不改画面：在重叠处（或吸附容差内）让另一网格新增或滑动一个顶点，UV 随之移动；插入后在不改变贴图的前提下翻转边，避免细长三角形 |
| `Alt` + 拖动 | 解除胶合 |
| 权重笔刷 | 以蓝色（A）/ 橙色（B）在贴图上显示两侧权重 |
| 重新合并 | 去掉被刷顶点上已有的胶合，再按吸附容差重新胶合 |
| `Enter` 或模式条「创建胶水」 | 沿两条轮廓整段胶合 |
| `Ctrl+G`（导出模型的键位，此时不打开导出） | 胶合在任一网格上选中的顶点 |
| 右键「按距离重新合并整段」 | 去掉两网格间的全部胶合，沿轮廓重新胶合 |

## 绘画的应用与放弃

先选图层再进入绘画。笔画保存在独立绘画会话中，支持会话内撤销重做。画下第一笔后，画布顶部中间滑出会话栏（与纹理集的调整会话栏相同），显示正在绘画的图层与笔数，提供撤销、重做、放弃与 **应用**；画布较窄时按钮只显示图标，悬停显示名称。「工具细节」面板中同样有「放弃」与「确认应用」。

调色板采用 Photoshop 的方式：左下角工具选项栏最前面是前景色 / 背景色重叠色块，右上角交换（X），左下角恢复默认的黑 / 白；单击色块打开拾色器——左侧饱和度 / 明度色域、右侧竖向色相条，「新的 / 当前」对比色块（点「当前」恢复），H S B 与 R G B 数值及十六进制代码，下方是色板和最近使用的颜色。「工具细节」面板直接内嵌前景色的色域与色相条，以及色板和最近使用的颜色。画笔、铅笔、橡皮和形状的大小互相独立，形状的线宽不会改动画笔大小。

工具栏分三组：画笔、铅笔、橡皮、**模糊**；油漆桶、**渐变**、吸管；形状、**选区**。各工具的选项在左下角选项栏，选区命令在画布右键菜单的「选区」组中：

| 功能 | 用法 |
| --- | --- |
| 选区工具（`Alt+L`） | 矩形、椭圆、套索、多边形套索、魔棒、快速选择六个变体，`1`–`6` 切换。拖动框选；套索按住拖出轮廓；多边形逐点单击，点回起点、按 `Enter` 闭合，`Delete` 撤回上一点，`Esc` 放弃；魔棒按容差选取单击处颜色，关闭「连续」时选取全图同色像素；快速选择是一支画笔，涂过的地方连同相连的相近颜色（含渐变阴影）一起选中，遇到颜色突变的边缘停下，每一笔都添加到选区，按住 `Alt` 涂抹则减去，`[` `]` 调笔刷大小，容差取选项栏「容差」。比较颜色时预乘透明度，所以透明区域无论隐藏什么颜色都算同一种。按住 `Shift` 添加、`Alt` 减去、`Shift+Alt` 交叉，也可在选项栏固定组合方式；单击不拖动取消选择。选区以蚂蚁线显示 |
| 选区命令 | `Ctrl+A` 全选、`Ctrl+D` 取消选择、`Ctrl+I`（或 `Ctrl+Shift+I`）反选、`Alt+Backspace` 用前景色填充选区（无选区时填充整层）、`Del` 清除选区内容；右键菜单另有「羽化选区」「扩展选区」「收缩选区」（距离取选项栏「羽化」「扩展/收缩」；收缩不从画布边缘往里缩）与「按不透明度选取像素」（以图层透明度为选区，相当于 Photoshop 中 Ctrl+单击图层缩略图） |
| 选区的作用 | 有选区时，所有工具（画笔、橡皮、模糊、填充、渐变、形状、清除）只改选区内，软边按比例过渡。选区不进入笔画历史：撤销一笔时选区保持不变；应用、放弃或换图层后选区清除 |
| 自由变换（`Alt+T`，绘画模式下也可按 `T`） | 选中工具即把选区内像素（无选区时为图层上全部内容）放进变换框，原位置随即空出。框内拖动移动；拖动角点等比缩放（`Shift` 不等比），边上控制点单向缩放，`Alt` 从中心缩放；框外拖动绕中心旋转（`Shift` 以 15° 步进）。`Enter` 或选项栏「应用变换」落笔，`Esc` 或 `Ctrl+Z` 取消并放回原处，换工具即应用。选项栏「平滑」关闭时按最近像素采样，适合像素画。应用后整个变换是笔画历史里的一步，选区随像素一起移动 |
| 渐变（`Alt+G`） | 拖动定出起点与终点，线性或径向，从前景色到背景色或到透明，受选区与保护透明度约束 |
| 模糊（`Alt+J`） | 涂过的地方变柔和；「强度」决定模糊程度，同一笔来回涂抹不会越来越糊 |
| 防抖 | 画笔、铅笔、橡皮、模糊的选项栏「防抖」0–30，数值越大线条越稳、跟随越慢，松手时补到松手位置 |
| 对称 | 同上四种工具可选左右、上下或四向镜像，轴为画布中心，画布上以虚线标出 |
| 保护透明度（`/`） | 只给已有像素上色、不改变透明度；此时橡皮改为用背景色涂 |
| 油漆桶 | 关闭「连续」时填充全图同色像素 |
| 直线 | `Shift` + 单击从上一笔终点画直线 |
| 默认颜色 | `Alt+D` 恢复黑 / 白（`X` 交换前景 / 背景） |

压感、旋转 / 翻转视图、涂抹与水彩混色尚未支持，与 Photoshop / SAI 的完整对照见[绘画系统](../spec/PAINT_SYSTEM_ARCHITECTURE_AND_PRD.md#工具对照与差距)。

绘画不受图层矩形限制，整张画布都可以画。应用时按图层的网格裁切：

- **网格上的部分**留在图层里。图层的网格、关键形和绑定都不变。
- **网格外的部分**拆成一个新图层，名字是原图层名加「+」，放在原图层正上方。新图层有自己的网格，挂在原图层的同一个父级、同一个部件下，所以会跟着一起动。它也会作为素材出现在素材库里，放在原图层的素材旁边（原图层没有素材时放在顶层），图层与这个素材关联。
- 在网格外擦除不起作用：那里的像素本来就不显示，图层原有的淡边也不会被拆走。
- 还没有网格的图层（例如刚画第一笔的透明图层）不裁切，网格按全部像素生成。
- 关联素材的图层，网格上的部分写进素材，所有用这个素材的图层一起变；网格外的部分同样拆成新图层。

如果想让图层自己的网格覆盖新画的区域，可以在网格面板里用「重建网格」，关键形、路径、权重和胶合会迁移到新网格上。

应用后检查变形与遮罩，再保存工程。实现细节见[绘画系统](../spec/PAINT_SYSTEM_ARCHITECTURE_AND_PRD.md)。

## 提交与恢复

普通几何手势在拖动中预览，成功结束后进入工程历史；创建、布点画线和绘画有自己的确认步骤。不要把「当前草稿」「已经提交的历史」「已写入磁盘的工程」当成同一状态。

路径的模式区别和导出限制见[变形路径](DEFORM_PATHS.md)。工程持久化见[工程格式](../spec/PROJECT_FORMAT.md)。
