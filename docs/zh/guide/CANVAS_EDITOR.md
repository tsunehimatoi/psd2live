# 画布编辑速查

[操作速查](USER_GUIDE.md) · [文档目录](../../README.md)

对应程序内第 3、6–12 课。具体按钮和当前快捷键以 **帮助 → 教程…** 为准。

## 先选模式，再选工具

| 模式 | 修改内容 | 常用工具 |
| --- | --- | --- |
| 选择 | 对象选区 | 点选、框选、套索；与层级树同步 |
| 变形 | 基础形状或当前参数关键形 | 变换、推拉、平滑、膨胀、路径控制点 |
| 编辑 | 网格拓扑与路径绑定 | 点 / 边 / 面选择、连接、合并、细分、切割、删除 |
| 绘画 | 图层像素 | 画笔、铅笔、橡皮、填充、吸管、形状 |

右侧「工具细节」显示当前工具参数；画布右键菜单按模式和工具变化。默认滚轮缩放，中键或空格 + 左键平移，Shift 加选、Alt 减选。

## 形变与关键形

未绑定参数的对象编辑基础形状；已绑定对象编辑当前参数组合。先在参数面板设置目标值，再调整控制点。检查对象自身的轴和父级继承运动，避免把父级姿态误当作当前对象的直接绑定。

形变笔刷修改几何，不修改贴图。无控制点选区时作用于当前对象的全部点；有选区时限制在选中点。半径按画布单位计算。默认 Alt + 右键拖动调整半径或硬度，Esc 取消当前手势。

## 网格拓扑

| 操作 | 结果 |
| --- | --- |
| 细分边 / 区域细分 | 对命中的边加点并重组三角形；相邻面同步处理接缝 |
| 连接 / 合并 | 建立选中点之间的连接，或将选中顶点合为一点 |
| 复制 | 复制选中顶点及其完整覆盖的面，新副本成为选区 |
| 删除 | 删除选区并尝试重建缺口；无法形成合法拓扑时拒绝操作 |
| 切割刀 | 逐点指定折线；靠近点或边时吸附，Shift 临时关闭吸附；Enter 完成、Esc 取消 |

切割允许在原网格外落点。拓扑更新同时处理 UV、关键形、混合形状与 Glue 顶点引用，并重新绑定路径。仍应检查已有姿态，特别是删除轮廓点后边界的变化。

## 创建与素材放置

1. 在层级树选择目标，右键选择添加父级 / 子级 Warp 或 Rotation；画元还可添加变形路径。
2. 调整画布中的放置预览，核对影响对象、名称、父级和分割设置。
3. 确认后写入工程；Esc 取消。

将 PNG / WebP / TIFF / BMP 拖到层级树，或用树右键「导入图层…」，也会进入放置会话。拖到画元时，新层挂在该画元的父变形器下。完成放置后检查遮挡与多参数姿态。

旋转变形器可拖原点平移、拖端点旋转；默认 Shift 吸附角度，Alt + 端点调比例。Glue 通过依次选择两个不同画元，按当前姿态和匹配距离连接邻近顶点；这不是完整的权重绘制工作流。

## 绘画的应用与放弃

先选图层再进入绘画。笔画保存在独立绘画会话中，支持会话内撤销重做；模式条提供应用 / 放弃。应用时按提示选择保留现有网格或重建网格。

保留网格适合修边补色，新增到网格外的像素未必能显示；扩大轮廓时可能需要重建。应用后检查变形与遮罩，再保存工程。实现细节见[绘画系统](../spec/PAINT_SYSTEM_ARCHITECTURE_AND_PRD.md)。

## 提交与恢复

普通几何手势在拖动中预览，成功结束后进入工程历史；创建、切割和绘画有自己的确认步骤。不要把「当前草稿」「已经提交的历史」「已写入磁盘的工程」当成同一状态。

路径的模式区别和导出限制见[变形路径](DEFORM_PATHS.md)。工程持久化见[工程格式](../spec/PROJECT_FORMAT.md)。
