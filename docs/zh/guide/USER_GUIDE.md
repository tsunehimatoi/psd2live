# 操作速查

[文档目录](../../README.md) · [English](../../en/guide/USER_GUIDE.md) · [日本語](../../ja/guide/USER_GUIDE.md)

先打开 **帮助 → 教程…**（`F1`）。交互教程会高亮控件、切换到相关面板，并按你当前的快捷键提示操作；本文是它的文字版，用于回看，不逐个讲解按钮。

## 最短流程

导入 PSD（`Ctrl+Shift+O`）→ 检查图层分类与预览 → 按需编辑 → 保存工程（`Ctrl+S`）→ 导出（`Ctrl+G`）。已有 `.psd2live` 用 `Ctrl+O` 打开。

已有 Cubism 模型在 **文件 → 导入** 中打开：**用 CMO3 替换当前模型…** 按 ID 替换文件中的对象并加入新对象，保留文件中未出现的内容；**从 CMO3 新建工程…** 清空当前模型后导入，模型内容仅来自该 CMO3。两种方式均不自动生成预设，导入的参数、关键形、变形器、贴图和物理可随工程保存。

## 工作区

界面由顶部的工作区标签组成，每个标签有自己的画布与面板布局。点标签栏右侧的 **+** 新建工作区，可选八种预设或空白布局，右侧会预览布局与用途：

![新建工作区菜单](../../imgs/workspace-presets.webp)

| 预设 | 用途 |
| --- | --- |
| 编辑 | 一块编辑画布，处理变形器、关键形和骨骼，属性面板齐全 |
| 网格 | 层级树、编辑画布与网格面板，编辑网格拓扑 |
| 绑定 | 编辑画布与实时预览并排，参数面板常驻 |
| 动画 | 动作列表、预览画布与动画编辑器 |
| 预览 | 大尺寸预览，只保留动作列表 |
| 物理 | 预览画布加参数与物理面板，边牵动模型边调整 |
| 纹理 | 纹理集页面、编辑画布与纹理面板，查看并调整每个图层的像素尺寸 |
| 历史 | 只有历史树和它的操作列表，浏览与切换历史 |
| 空白 | 空的停靠区，从 **窗口** 菜单添加需要的画布和面板 |

**重置布局** 恢复当前工作区的预设布局。

### 纹理工作区

每个图层有三种尺寸：在画布上覆盖的矩形（画布单位）、自身栅格的像素，以及它在纹理集中的图块像素。「纹理」工作区把三者并列显示，并逐层调整：

- **纹理集**（左）：整页图像铺满视图，操作方式与编辑画布一致——滚轮缩放，中键或 Space + 拖动平移，`F` 聚焦所选、`Home` / `0` 适应页面，`Ctrl+A` 选择本页全部图块。单击图块选择对应图层，在空白处拖动框选（Shift 追加，Alt 减选，与编辑画布相同）；选择与画布和图层列表同步。**拖动图块** 时图块的像素随指针实时移动，松开后图块停在该位置，与其他图块的网格（按网格实际覆盖的单元格，而不是矩形）重叠或超出页面时不移动，此时图块显示为红色；选中的图块带有与编辑画布相同的变换框：拖动顶边外的 **圆形手柄**，或在角点外侧（悬停时亮起带箭头的弧线）拖动，可绕 **锚点** 任意旋转（按住 Shift 以 15° 步进），旋转后同样按网格判断重叠；锚点（十字圆圈）默认在图块中心，拖动可移到任意位置，靠近中心、角点或边中点时吸附。移动、缩放、旋转都是**调整会话**，与绘画模式相同：调整时只改纹理集页面上的显示，不重建模型，绝对流畅；有调整时，页面顶部中间滑出会话栏（与绘画模式的会话栏相同），显示已调整的图块数，可撤销/重做（Ctrl+Z / Ctrl+Shift+Z）、放弃，点 **应用**（或按 Enter）后所有调整作为一步提交，只重建一次、只产生一个历史节点；视图较窄时按钮只显示图标，悬停显示名称。会话中“排布”、自动排布、预算、锁定、替换图像等会重新布局或立即提交的命令暂不可用；**拖动所选图块的角点** 按到对角的距离缩放密度（图块按新尺寸实时显示），连续变化、没有档位，按住的角的对角保持不动（按住 Alt 时锚点保持不动），多选时其余图层按同一比例缩放，松开后进入会话；放大后会与其他图块的网格重叠时显示为红色，松开不应用；移动同样不吸附，跟随指针；纹理面板的密度滑块拖动时，页面和尺寸卡片同样实时显示新尺寸；双击图块聚焦。右键图块可加倍/减半/重置密度、旋转 90° 或重置旋转、多页时移到第 N 页（放进该页从左上起第一个不与其他图块网格重叠的空位，同样进入会话；放不下时拒绝并提示）、锁定或解除锁定尺寸（所选图层部分已锁定时显示已锁定数量，点击锁定其余图层）、排布所选图块、替换图像；右键空白处可排布全部图块、导出本页为 PNG（与导出写出的内容逐字节一致）、全选或适应页面。会话中有调整时，菜单顶部会提示哪些命令需要先应用或放弃。页码的悬停提示给出该页尺寸、图块数与占用。左上角是与编辑画布模式栏相同的浮动栏：**排布** 按钮一次性排布并保存结果，旁边的下拉菜单只放排布选项：单选的排布方式——按网格形状（默认，图块按网格实际覆盖的区域互相嵌套，最紧凑）或按矩形，以及单选的范围——全部图块或仅所选图块；**自动排布** 按钮按下即开启、再按关闭（开启时高亮）——开启时每次修改后按矩形（MaxRects）重新排布，关闭时（新工程默认）保持当前布局，新增图层和原位置放不下的图块都静默放入空闲区域，放入后的位置会被保留——移动或缩放其他图块空出的位置不会被后面的图块自动填补；多页时还有页码。右上角是纹理集预算（页面尺寸 1024–16384、最多页数与间距）。右下是与编辑画布相同的显示栏，悬停展开：纹理、网格线框、轮廓与 **密度热力图**（默认关闭；按“每画布单位的纹理集像素”着色：蓝色低于 1，绿色约为 1，橙色高于 1，图例 ¼–4），左下状态条显示悬停或拖动中的图块，否则显示适配比例与占用。“适配”低于 100% 表示预算放不下，所有未锁定图块一同缩小，相关说明只写入日志面板。已删除的图层（包括拆分前的原图层）不占用纹理集，也不显示。
- **纹理面板**（右）：以“画布 → 原图 → 纹理集”三格显示选中图层的画布矩形、原始像素与图块尺寸，并在色标上标出实际密度。**纹理密度** 滑块与 ½× / 2× / 重置按钮调整倍率（每个原始像素对应的纹理集像素，1/64–16，多选时统一设置），**锁定尺寸** 让图层在纹理集需要缩小时保持尺寸；单选时 **旋转** 可直接输入图块角度（**摆正** 归零），与在页面上旋转一样进入会话。**替换图像…** 以任意分辨率替换像素并保持画布矩形，可选“拉伸 / 完整容纳”以及是否用新像素重建网格；**纹理高清化…** 打开工程的高清化设置。画布矩形的精确数值折叠在 **精确画布矩形** 中。未选择图层时显示纹理集概况——每页尺寸、图块数与占用、空闲面积、页面占用的显存（RGBA）、锁定数与适配比例及其含义——以及预算，预算同样等待会话应用或放弃。导出对话框只显示纹理集摘要，并可跳转到纹理工作区；透明阈值移到网格面板的全局设置中。
- **原始像素预览**：编辑画布右下显示栏的 **原始像素** 让该画布直接采样各图层自身的栅格，而不是纹理集图块，用于对比打包后的清晰度。该选项按画布保存，打开时此画布使用软件绘制；预览画布（Cubism 或 PSD2Live 运行时）与导出始终使用纹理集像素。

移动画布矩形、替换图像并重建网格对已有作者编辑、绑定或物化网格的图层会被拒绝，原因显示在纹理集页面上方。每项修改都是一个历史节点，可撤销。Agent 侧的同名操作见 [MCP_AUTHORING.md](../agent/MCP_AUTHORING.md#纹理与纹理集)。

## 按交互教程学习

教程目录共有 19 个主题：零基础路线包含下列 18 课；有 Cubism 经验的路线会先读一章术语对照，再跳过部分入门课。除「基础流程」外，各章在没有打开模型时会先要求导入 PSD 或打开工程。

| 课 | 主题 | 操作要点 |
| --- | --- | --- |
| 1 | 基础流程 | 导入分层 PSD，检查预览、图层预设和模型预设，再选择导出格式；贴图图集在导出窗口中设置。 |
| 2 | 工作区导览 | 编辑页改模型，预览页看效果，历史页切版本；每个画布标签页独立保存镜头和视图开关。 |

| 4 | 图层类型与差分 | 「预设」使用部件算法；「开关差分」用一个参数控制有无；「切换差分」用同一参数及不同关联 ID 实现多选一。 |
| 5 | 参数与关键形 | 拖滑块或 XY 控件检查姿态；右键参数键标记吸附。先确定目标参数值，再编辑关键形。 |

## 容易混淆的概念

头发与服装模拟的分步截图见[模拟图文教程](SIMULATION_TUTORIAL.md)，包含固定点权重调整、烘焙和导出效果检查。

- **保存与导出**：保存保留工作区和历史；导出生成目标软件使用的模型文件。`.psd2live.json` 是报告，不是工程。导出 CMO3 时，模型的动作另存为同名 `.can3`，可在 Cubism Editor 的 Animator 中与 cmo3 一起打开编辑；两者需放在同一文件夹，并且来自同一次导出。
- **导出完成**：Live2D 模型、PSD 与“导出为”的各格式导出完成后，导出窗口关闭并弹出“导出成功”窗口，显示写入位置以及警告或该格式无法保留的内容，可直接 **打开文件夹**。选择 **关闭并不再提示** 后只在日志与状态栏报告；**设置 › 提示** 列出所有带“不再提示”的窗口（含导入后的开始界面），可逐项重新开启或 **恢复所有提示**。
- **关键形与关键帧**：参数键上的关键形属于建模，键之间会插值出模型形状；关键帧位于动画时间线，记录某个时刻的参数值。
- **变形与编辑**：变形改变形状；编辑改变控制网格的结构。绘画修改像素，采用独立的应用 / 放弃会话。
- **显隐与差分**：树中的临时独显、图层静态显隐用于编辑检查；需要随参数切换时，设置差分或不透明度关键形。

### 前后分层：让一个图层穿过另一个部件

例如领子只有一层，却需要形成「后领子 → 脖子 → 前领子」的遮挡：在层级树中右键领子选择 **前后分层…**，或多选领子与脖子后右键领子选择 **将「领子」前后分层**。原层由前后两层取代，前层用胶水跟随后层，随后在前层上用橡皮擦去后领子部分并应用。分步截图与细节见[前后分层图文教程](DEPTH_SPLIT.md)。

## 生成结果与旧记录

**旧工程的拆分记录**：较早版本的拆分（连通块、多边形、前后分层）把原层拆分时的状态整体固定在部件里。打开这样的工程照常显示；第一次编辑时，当前模型会被固定保存下来，此后不再按旧记录重放，这些部件作为你自己的网格保留，你在上面做的修改都在。新的拆分不再有这个区别：部件在原层的位置参与生成，你在原层上做的关键形、路径、权重与胶水带到部件上，之后改脸部设置、站姿、骨架或分类也会更新部件。

**更新生成结果**：开启头发模拟、启用或调整骨架、拆分等改变自动生成结果的操作，会把你已有的编辑合并到新的生成结果上并保存为固定的数据，此后升级程序也不会自动改变这些结果。想采用新版本生成器的改进时，用 **工具 → 更新生成结果**：你没改过的部分换成新版本的生成结果，你的修改保留，无法干净迁移的地方在状态栏提示条数、在检查器列出。生成结果没有变化时不产生历史；更新为一步历史，可撤销。想先看看会改变什么，用 **工具 → 预览生成结果更新**：状态栏显示更新会不会改变模型、有几项需要查看，工程不变。

## 常用快捷键

以下为默认（Photoshop 风格）键位。**设置**中可切换为 Blender 或 Cubism 风格预设，也可逐项自定义；**帮助 → 快捷键…** 显示当前绑定。除键盘外，带修饰键的滚轮（上 / 下 / 左 / 右）、鼠标中键与侧键（`MouseBack` / `MouseForward`）也能绑定到任意命令：录制时把指针移到正在录制的单元格上滚动滚轮或按下鼠标按键即可。**画布鼠标手势**（平移、拖动缩放、调整笔刷）绑定的是按下后拖动的鼠标按键，左右键也可用，但须带修饰键。不带修饰键的滚轮、左键与右键保留给滚动 / 缩放、工具与右键菜单。Windows 会把横向滚轮报告为 Shift + 滚轮，因此录制结果显示为 `Shift+WheelUp` / `Shift+WheelDown`。

| --- | --- |
| 打开工程 / 导入 PSD | `Ctrl+O` / `Ctrl+Shift+O` |
| 保存 / 另存为 | `Ctrl+S` / `Ctrl+Shift+S` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` 或 `Ctrl+Y` |
| 导出模型 / 导出 PSD | `Ctrl+G` / `Ctrl+Shift+E` |
| 重新分析 PSD | `Ctrl+R` |
| 纹理高清化 | `Ctrl+U` |

| 调整笔刷：大小·硬度 / 不透明度·角度 | `Alt+MouseRight` / `Shift+Alt+MouseRight` 拖动 |

| 临时选择 / 快速预览切换 | 按住 `Z`，松开恢复 / 反引号键（Esc 下方） |
| 确认 / 取消当前操作 | `Enter` / `Esc`，具体以当前工具提示为准 |
| 动作时间轴：播放 / 打关键帧 / 逐帧 | `Space` / `K` / `Left` `Right`（时间轴获得焦点时） |

## 检查与排错

| 现象 | 先检查 |
| --- | --- |
| 部件动作不对或没有动作 | [图层命名](../spec/PSD_LAYER_SPEC.md)与「图层」表格中的类型、侧别；遮罩与父级 |
| 静态姿态正常，运动时穿帮 | 在动画或物理面板中播放检查；单个静态姿态不能代表完整运动 |
| 面板不见了 | 「窗口」菜单中的面板开关，或右上角「重置布局」 |
| 画布上看不到模型 | 先适配画布（`F` / `Home`），再检查图层显隐 |
| 导出失败或提示降级 | 日志面板与导出报告 `.psd2live.json`，以及导出目标版本 |

提交问题时请附版本、操作系统、复现步骤及相关素材。
