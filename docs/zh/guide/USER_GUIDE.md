# 操作速查

[文档目录](../../README.md) · [PSD 图层规范](../spec/PSD_LAYER_SPEC.md) · [画布编辑](CANVAS_EDITOR.md) · [开发与 CLI](DEVELOPMENT.md)

> [!TIP]
> 初次使用建议直接在程序内按 `F1` 打开帮助页，从 **制作流程** 开始交互教程（零基础 19 课 / Cubism 经验者 14 课）。本文用于回看操作与速查快捷键。

---

## 1. 最短流程

1. **导入**：`Ctrl+Shift+O` 导入分层 PSD（已有 `.psd2live` 工程按 `Ctrl+O` 打开）。
2. **检查**：查看自动生成预览与图层分类，按需在画布上微调。
3. **保存**：`Ctrl+S` 保存为 `.psd2live` 工程（`Ctrl+Shift+S` 另存为）。
4. **导出**：`Ctrl+G` 导出目标模型（`.moc3` / `.cmo3` 等）。

> **导入已有 Cubism 模型**：
> - **文件 → 新建 → 从 CMO3 新建工程…**：清空当前模型后导入，模型内容仅来自该 CMO3。
> - **模型 → 用 CMO3 替换当前模型…**：按 ID 替换文件中出现的对象并加入新对象，保留未出现的现有内容。
> - 两种方式均不自动生成预设，导入的参数、关键形、变形器、贴图与物理可随工程保存。

## 2. 保存状态与恢复

结束正在输入或拖动的编辑后按 `Ctrl+S` 保存；底部状态栏显示当前保存状态：

| 状态栏文字 | 含义与操作 |
| --- | --- |
| 正在编辑草稿 | 输入或拖动仍在进行，或草稿正在提交；先完成当前编辑 |
| 更改已提交到内存 | 更改已进入当前工程，但尚未确认恢复副本写入；仍需保存工程 |
| 正在保存恢复副本… | 正在写入用于异常退出恢复的本地副本 |
| 恢复副本已保存 · 工程未保存 | 恢复副本已写入；按 `Ctrl+S` 将更改保存到 `.psd2live` 文件 |
| 恢复保存失败 · 重试 | 点击重试写入恢复副本（悬停查看错误）；不会新增历史 |
| 正在保存工程… | 工程文件正在写入，等待完成 |
| 工程保存失败 | 悬停查看错误，处理后再次保存或另存为 |
| 工程已保存 | 当前更改已保存到 `.psd2live` 文件 |

> 恢复副本仅用于异常退出后恢复；需要备份、传递或跨设备继续工作时，请保存 `.psd2live` 工程文件。部件子设置的操作见 [预设与修改器](MODIFIERS.md#部件子设置与物理)。

## 3. 应用页面与菜单

工作区标签栏最前面是应用自带页面：**开始**、**帮助** 与 **设置**。它们不随工程保存，面板可拖动停靠、合并或浮动，布局保存在本机偏好中；可通过 **窗口** 菜单重新打开或 **重置布局**。

### 开始页
启动时自动显示（打开或新建工程后收起，可从 **文件 → 开始页** 重新打开）。目录支持 `↑` / `↓` 切换，主按钮按 `Enter` 触发：

- **从 PSD 生成**：在右侧选预设（最小 / 默认 / 完整），将 PSD 拖入窗口或点击 **生成…**；下方 **最近的 PSD** 单击预览、双击生成。画在同一层的左右部件用 **模型 → 按网格拆分图层…** 拆开。
- **排版工程**：左侧按比例预览画布，右侧选择常用尺寸或输入自定义宽高，创建后进入先摆放再生成流程（见 [素材与 Layout](LAYOUT.md)）。
- **从 CMO3 导入**：新建或替换当前模型。
- **最近**：按网格或列表搜索、筛选最近的工程与 PSD，双击打开。
- **功能更新**：按版本查看更新说明，支持直接跳转对应的交互教程。

### 标题栏菜单
- **文件**：新建、打开、保存、导出、打开所在文件夹（工程 / 源文件 / 输出 / 应用数据）。
- **视图**：画布、面板与工作区布局控制。
- **模型**：作用于整个模型的操作（重新分析 PSD、用 CMO3 替换、按网格拆分图层、纹理高清化、更新生成结果）。
- **帮助**：打开帮助页与在线资源（GitHub、文档、示例仓库、版本发布、问题反馈）。
- **右侧工具**：侧栏开关、语言、明暗主题、**设置**（齿轮）。

### 帮助页（`F1`）
再按一次 `F1` 回到工作区。目录含 **手册**、**教程**、示例、社区链接、第三方许可与关于：
- 手册与教程按 Cubism Editor 结构组织，彩色标签标明 **相同** / **操作不同** / **独有** / **未实现**（灰色不可打开）。
- 手册末尾「MCP 与工具」列出对应 MCP 操作及字段（读自正在运行的服务）。
- 图层规范见 **手册 → 素材划分/PSD创作 → 创建PSD的注意事项**；快捷键见 **手册 → 关于编辑 → 快捷键列表**。

### 设置页（`Ctrl+,`）
包含缩放与显示、主题、语言、显示、图形、提示、快捷键、文件与数据、MCP，多数修改立即生效（MCP 需点 **应用并重启**）：
- **显示**：支持窗口 / 最大化 / 全屏（`F11`）。
- **图形与性能**：画质预设（低 / 中 / 高 / 极高）、渲染路径（GPU / GPU 窗口加软件画布 / 全软件）、显卡选择、垂直同步、抗锯齿、纹理过滤与性能叠加层。画布显示异常时可先试「GPU 窗口，软件画布」。
- **文件与数据**：查看并清理超分缓存、错误日志、异常退出临时残留及最近文件列表。

## 4. 工作区与纹理工作区

点击顶部标签栏右侧 **+** 可新建工作区，提供 8 种预设与空白布局：

![新建工作区菜单](../../imgs/workspace-presets.webp)

| 预设 | 用途 |
| --- | --- |
| 编辑 | 单块编辑画布，处理变形器、关键形与骨骼，属性面板齐全 |
| 网格 | 层级树、编辑画布与网格面板，专注网格拓扑 |
| 绑定 | 编辑画布与实时预览并排，参数面板常驻 |
| 动画 | 动作列表、预览画布与动画编辑器 |
| 预览 | 大尺寸预览，仅保留动作列表 |
| 物理 | 预览画布加参数与物理面板，边牵动模型边调整 |
| 纹理 | 纹理集页面、编辑画布与纹理面板，管理图块排布与纹理密度 |
| 历史 | 仅保留历史树与操作列表，用于浏览与切换分支 |
| 空白 | 空停靠区，从 **窗口** 菜单自行添加面板 |

### 纹理工作区要点
每个图层对应三种尺寸：**画布矩形**（画布单位）、**自身栅格像素**、**纹理集图块像素**。

- **纹理集视图（左）**：
  - 缩放/平移与编辑画布一致（滚轮缩放，中键或 `Space` + 拖动平移，`F` 聚焦，`Home`/`0` 适应，`Ctrl+A` 全选）。
  - 拖动图块、角点缩放密度或外侧手柄旋转均进入**调整会话**（仅预览不重建模型）；顶部会话栏可撤销/重做/放弃，点 **应用**（或 `Enter`）一次性提交为一个历史节点。
  - 图块与其他图块网格重叠或超出页面时显示为红色且不可应用。
  - 左上浮动栏提供 **排布**（按网格形状 / 矩形，全部 / 所选）、**自动排布**（MaxRects）开关与页码；右上设置预算（页面尺寸 1024–16384、页数、间距）；右下可开启 **密度热力图**（蓝 < 1，绿 ≈ 1，橙 > 1）。
- **纹理面板（右）**：
  - 显示「画布 → 原图 → 纹理集」三格尺寸与实际密度。
  - 可调 **纹理密度**（`1/64`–`16`）、**锁定尺寸**、**旋转**、**替换图像…**（可选是否重建网格）及 **纹理高清化…**。
- **原始像素预览**：编辑画布右下显示栏开启 **原始像素** 后，该画布直接采样图层原始栅格，便于对比打包后的清晰度（导出与预览画布始终使用纹理集像素）。
- Agent 侧同名操作见 [MCP 使用与接口](../agent/MCP_AUTHORING.md#纹理与纹理集)。

## 5. 交互教程目录（20 主题）

| 课 | 主题 | 操作要点 |

| 1 | 基础流程 | 导入分层 PSD，检查预览与预设，再导出 |
| 2 | 工作区导览 | 编辑 / 预览 / 历史页协作；各画布独立保存镜头与开关 |

| 4 | 差分 | 无差分 / 开关差分（单参数控制有无）/ 切换差分（多选一） |
| 5 | 素材与摆放 | 导入素材并摆放，用标签说明部位后生成（见 [素材与 Layout](LAYOUT.md)） |

| 7 | 物体模式 | 框选、套索与树画布联动定位，不修改几何 |
| 8 | 创建变形器 | 选目标 → 添加父/子级变形器 → 预览放置 → 确认 |
| 9 | 变形模式 | 调整控制点、整体变换或笔刷；网格变形器可用 `1`/`2` 切换顶点/贝塞尔 |
| 10 | 编辑模式 | 修改网格拓扑（细分、连接、布点、删除），完成后复查姿态 |
| 11 | 绘画模式 | 画笔、橡皮、填充等修像素；会话内独立撤销，应用或放弃 |
| 12 | 检视面板 | 修改名称、归属、遮罩、绘制顺序、透明度与颜色 |
| 13 | 工具选项 | 左下角选项栏调半径、硬度、强度；「工具细节」放高级设置 |
| 14 | 骨骼绑定与编辑 | 新建/镜像骨骼、绑定画元、FK/IK 摆姿、刷权重并烘焙导出 |
| 15 | 动画与动作编辑器 | 调节生成动作；时间线编辑参数轨道、关键帧与贝塞尔缓动 |
| 16 | 物理画布调试 | 设置输入、摆锤与输出，用实测最大值校准倍率 |
| 17 | 布料与头发模拟 | 生成模拟、绘制固定点/刚度等权重，烘焙为参数与摆锤导出 |
| 18 | 工程与历史 | 保存 `.psd2live`，在历史树搜索/检出分支；**更新生成结果** 合并新版本 |
| 19 | 贴图高清化 | 配置本地后端，选 2× / 4× 并检查边缘与导出结果 |

## 6. 容易混淆的概念

- **保存与导出**：保存（`.psd2live`）保留工程与分支历史；导出生成目标软件使用的模型。`.psd2live.json` 只是诊断报告。导出 CMO3 时动作另存为同名 `.can3`，需同目录同批次打开。
- **关键形与关键帧**：关键形属于参数建模，在参数键之间插值变形；关键帧位于动画时间线，记录某一时刻的参数值。
- **变形与编辑**：变形改变形状；编辑改变网格拓扑结构；绘画修改像素并走独立会话。
- **显隐与差分**：树中的临时独显/静态显隐用于编辑检查；随参数切换请用差分或不透明度关键形。
- **前后分层**：如领子穿过脖子，右键领子选 **前后分层…**（详见 [前后分层图文教程](DEPTH_SPLIT.md)）；头发与服装模拟步骤见 [模拟图文教程](SIMULATION_TUTORIAL.md)。

## 7. 生成结果与旧工程升级

- **Rig 模块**：新工程按部位（眼、眉、嘴、头、发、身体、服饰、表情、动作）生成，每个部位由基础算法加可独立开关的模块组成。在 **模型预设 › 部位与模块** 可按精简 / 标准 / 完整或参数预算一键调整。风格五官可在画布上用 **特征点** 工具（`Shift+Y`）修正（见 [画布编辑](CANVAS_EDITOR.md#特征点)）。
- **旧工程拆分记录**：旧版拆分结果在首次编辑时固化为普通网格，保留已有修改；新版拆分直接在原层位置参与生成，修改脸部或骨架时可同步更新部件。
- **更新生成结果**：通过 **模型 → 更新生成结果** 可将未修改部分升级为新版生成器结果，并三方合并保留手工编辑；**模型 → 预览生成结果更新** 可先预览变更项数而不改动工程。

## 8. 常用快捷键（默认 Photoshop 风格）

可在 **设置** 中切换为 Blender / Cubism 预设或自定义绑定（支持修饰键 + 滚轮及鼠标侧键）。

| 操作 | 默认键位 |
| --- | --- |
| 打开工程 / 导入 PSD | `Ctrl+O` / `Ctrl+Shift+O` |
| 保存 / 另存为 | `Ctrl+S` / `Ctrl+Shift+S` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` 或 `Ctrl+Y` |
| 导出模型 / 导出 PSD | `Ctrl+G` / `Ctrl+Shift+E` |
| 重新分析 PSD / 纹理高清化 | `Ctrl+R` / `Ctrl+U` |
| 帮助 / 设置 / 全屏 | `F1` / `Ctrl+,` / `F11` |
| 缩放 / 平移画布 | 滚轮 / 中键（或 `Space` + 左键）拖动 |
| 拖动缩放画布 | `Ctrl+MouseMiddle` 上下拖动 |
| 调整笔刷大小·硬度 / 不透明度·角度 | `Alt+MouseRight` / `Shift+Alt+MouseRight` 拖动 |
| 旋转笔刷 | `Alt+WheelUp` / `Alt+WheelDown`（加 `Shift` 步进 45°） |
| 适配所选 / 重置镜头 | `F` / `Home` 或 `0` |
| 笔刷大小 / 硬度 / 不透明度 | `[` `]` / `Shift+[` `Shift+]` / `Alt+Shift+[` `Alt+Shift+]` |
| 模式或工具第 1–5 项 | `1`–`5` |
| 绘画：选区 / 渐变 / 模糊 / 自由变换 | `Alt+L` / `Alt+G` / `Alt+J` / `Alt+T`（绘画模式 `T` 切自由变换） |

| 绘画：交换·默认颜色 / 保护透明 / 直线 | `X` / `Alt+D` · `/` · `Shift` + 单击 |
| 临时选择 / 快速预览 | 按住 `Z` / 反引号 `` ` `` |
| 物体模式 / 上次模式切换 | `Tab` |
| 确认 / 取消当前操作 | `Enter` / `Esc` |

## 9. 检查与排错

| 现象 | 先检查 |
| --- | --- |
| 部件动作不对或没有动作 | [PSD 图层规范](../spec/PSD_LAYER_SPEC.md) 与「图层」表中的类型、侧别、遮罩与父级 |
| 静态姿态正常，运动时穿帮 | 在动画或物理面板中播放完整运动轨迹 |
| 面板不见了 | **窗口** 菜单中的面板开关，或 **重置布局** |
| 画布上看不到模型 | 先适配画布（`F` / `Home`），再检查图层显隐 |
| 导出失败或提示降级 | 日志面板、导出报告 `.psd2live.json` 与导出目标版本 |
