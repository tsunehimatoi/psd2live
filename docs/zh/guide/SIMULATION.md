# 模拟与烘焙

[文档目录](../../README.md) · [物理](PHYSICS.md) · [摇摆生成](SWING.md) · [画布编辑](CANVAS_EDITOR.md) · [MCP 使用与接口](../agent/MCP_AUTHORING.md)

第一次操作可先看[模拟图文教程](SIMULATION_TUTORIAL.md)，按截图完成预设、固定点权重、重新烘焙与效果检查。

模拟在编辑器里对网格做真实的 2D 布料 / 头发模拟：顶点被固定点牵住，受重力和惯性驱动。Cubism 运行时不会做这种模拟，所以**模拟本身不导出**。要导出，须把它**烘焙**成 Cubism 能播放的内容：新参数上的网格关键形，由拟合出的摆锤驱动，另加若干参数上的精确修正。烘焙结果存进工程；重建模型时只写回结果，不会重新模拟。

## 基本流程

1. 在画布上选中裙子或头发的网格，在「修改器」面板「物体」页的「添加」菜单选「模拟 · 布料」或「模拟 · 头发」。同一个物理体里的多张网格一起模拟，它成为这些网格栈里的一张模拟卡片。
2. 指定固定点。可以二选一或同时使用：
   - 在模拟卡片的「顶点权重组」里点「固定点」一行的「绘制」，或切到画布的「模拟」模式，用权重笔刷绘制「固定点」权重组；
   - 在卡片的「胶水」里把与腰部相连的胶水设为「作为固定点」。
3. 在卡片的「对比」节打开「参考模拟」，在预览里转头、摇身体，调整材质直到效果自然。
4. 在卡片「烘焙」节点「烘焙」，或在「修改器」面板「世界」页的「模拟」节点「烘焙全部」。烘焙需要数秒，在后台进行，期间可以继续编辑其他内容，完成后在当时的最新版本上作为单独一步撤销提交。「自动烘焙」默认关闭；打开后每次修改立即提交，随后在后台重新烘焙。烘焙后物理面板出现来源为「模拟」的摆锤组，参数面板出现 `ParamSim…` 参数，导出即包含它们。
5. 关闭「参考模拟」回到「导出效果」，预览播放的就是导出模型的动作，与参考模拟对照。

### 界面

模拟没有单独的面板，都在「修改器」面板里（见[修改器栈](../spec/DOCUMENT_LAYER.md#修改器)）：

- **模拟卡片**（「物体」页，目标网格的栈中）：标题是名称，右侧是烘焙状态（已烘焙 / 烘焙已过期 / 未烘焙）、开关和菜单（烘焙、应用为关键形、上下移动、删除）。卡片里先是类型（切换会套用该类型的材质预设），然后是可折叠的：
  - 「烘焙」：先是在没见过的动作上的视觉检查（摆幅之比、滞后、回落、抖动，看得出差别时以警告色显示），其次是 R² 与误差（有顶到极值或更抖时另行警告）、「烘焙 / 重新烘焙」「清除烘焙」和各模态的摆幅，再下面是模态数、上下参数、关键点和夸张；模态写法、参与训练的动作与精确姿态收在「高级」里。
  - 「材质」：顶部可选命名预设，材质改动后节标题出现「恢复该类型的预设」按钮。
  - 「输入」：逐行列出参数名和 ID，模型中已不存在的参数以警告色标为「不存在」；烘焙后每个输入下面显示它带动物体多远，被剔除的以警告色标为「已剔除」并带「保留」勾选框；再下面一行是它的训练范围；输入与默认不同时节标题出现「恢复默认输入」按钮，没有输入时警告无法烘焙。
  - 「输出」：烘焙后列出生成的模态参数和摆锤（名称与 ID），点名称可重命名，清空或改回默认名即恢复按物理体命名；每个模态参数下面可改 ID、范围和增益。
  - 「胶水」「顶点权重组」：见下文。
  - 「对比」：「参考模拟」开关（关闭为「导出效果」）、参考模拟时节标题上的重置按钮，以及把烘焙结果和参考模拟放在一起看的工具，见[导出效果与参考模拟](#导出效果与参考模拟)。
- **「世界」页的「模拟」节**：一行内是「烘焙全部」「自动烘焙」与状态数量（有待烘焙时黄色显示「1/2 个待烘焙」，否则「2/2 个已烘焙」），下面列出全部物理体。每行左侧的勾选框启用 / 停用物理体，右侧是烘焙状态和类型：已烘焙只显示绿点，需要注意的状态才写出文字（黄色已过期即导出仍用旧结果、红色未烘焙即不会导出、灰色已停用）。点一行选中它的网格并切到「物体」页；右键菜单可烘焙、清除烘焙或删除。
- 新建的物理体名称为 `sim` 加第一张网格去掉 `ArtMesh` 前缀的名字（如 `ArtMeshBottomwear` → `simBottomwear`，重名时加序号）。「烘焙全部」依次烘焙所有未烘焙或已过期的启用物理体，后面的物理体在前面的烘焙结果上烘焙，全部完成后作为一步撤销提交；都已是最新时再点会全部重新烘焙。烘焙进行中可以继续编辑，也可以再烘焙其他物理体（排入队列，下一轮烘焙）；某个物理体的设置在烘焙期间被改动时，它的结果不会按旧设置提交，而是重新烘焙；烘焙期间被删除的物理体则丢弃结果。「自动烘焙」是本机的界面偏好，不随工程保存。烘焙时状态栏显示当前物理体、序号和进度；个别物理体烘焙失败时保留它的旧烘焙并在列表下方提示，其余照常提交。
- 模拟只读取栈中排在它前面的内容；前面的卡片（例如移到它之前的修改器）改变后，烘焙显示过期。

## 模型预设

「修改器」面板「世界」页的「模型预设」节（原「模型预设」面板）中的「物理与模拟」组把常见部件一步做成模拟并烘焙，结果是普通的权重组和物理体，之后仍可在模拟卡片里调整。面板里的「形变与口型」「动作」「物理与模拟」三组都是与参数面板文件夹相同样式的可折叠行，右侧显示摘要。「动作」组只决定模型有没有「基础动作」和「骨骼动作」两组，单个动作在动画面板中启用和调整。「物理与模拟」每项一行：前发、后发各有一个下拉框，在「模拟 / 经典摆动 / 关闭」间切换；服装与果冻眼是复选框，勾选即应用预设，取消即移除，服装的逐网格宽松度列表显示在服装行下方。控件旁的灰字说明当前内容（已模拟的服装部位、原画中没有该部件，悬停显示全文），未烘焙或模拟体已删除时以警告色提示。顶部工具栏的「仅选中（n）」让勾选只作用于选中的图层（取消勾选总是整体移除），右侧为「自动 Pin 物理权重」。烘焙进度与取消在底部状态栏，失败原因显示在组内底部。每次勾选都是一步撤销，MCP 对应 `model_apply_preset` 工具。

「开始」页（工作区标签栏最左侧，或「文件 → 开始页」）的「从 PSD 生成」在导入 PSD **之前**汇总同样的预设：属性面板顶部的「最小 / 默认 / 完整」分别对应只保留绑定（无动作、物理与模拟、嘴部描边）、两组动作 + 头发经典摆动 + 服装模拟 + 果冻眼、在默认基础上模拟前后发并开启五官位移；下方可逐项调整，选择会被记住。之后无论从开始页、「文件」菜单、最近文件还是拖放导入 PSD，生成后都会把改动过的预设作为一步撤销写入，再依次生成头发与服装模拟（每个模拟各占一步），并切到编辑工作区。服装默认开启，原画中识别到服装时会生成并烘焙服装模拟。已打开由 PSD 生成的模型时，「生成」按钮菜单里的「应用到当前模型」把同样的预设套到它上面。按网格拆分图层不再随导入弹出，改用「模型 → 按网格拆分图层…」扫描全部图层后批量确认。

| 预设 | 做什么 |
| --- | --- |
| 前发 / 后发 | 该类头发的全部网格合成一个头发物理体（`preset_front_hair` / `preset_back_hair`），每束发（网格的每个连通块）从自身顶端固定、向发梢放开，只写固定点组；前发用「刘海」材质，后发用默认头发材质；同时移除该类头发的旧摆动（`ParamHairFront/Back` 参数、`DeformHair*Physics` 变形器与摆锤），网格（含拆分出的部件）改挂到跟随变形器，原画位置不变。改选「经典摆动」或「关闭」时删除该物理体并恢复旧摆动（「关闭」同时停用旧摆动） |
| 服装 | 读取上衣、下装、领饰、手部（袖子）和腿部穿戴图层，只在原画看起来宽松的地方模拟，贴身部分跟随绑定。下装先判定裙子或裤子：名称优先（裙、skirt、スカート / 裤、pants、ズボン 等），否则看 Alpha 轮廓，从裆部持续到下摆的中缝间隙判为裤子。躯干与下装逐行比较轮廓与身体：身体轮廓从肩线（下装从腰线）开始，向下只能缓慢变宽，超出部分记为宽松（褶边、蝴蝶结、喇叭下摆、外套开襟）；上衣在腰线以下（腰线取下装腰线，或伸进上衣下方的腿部穿戴顶端）、裙子在臀部以下且比臀部宽时、领饰在结以下视为自由悬垂，直筒裤和铅笔裙保持贴身。袖子与腿部穿戴随肢体弯曲，改用形态学开运算：比肢体粗细一半的圆盘还细的部分（袖口 / 袜口褶边、飘带）才算宽松，泡泡袖、翻边袖口随肢体。肤色区域始终贴身，手指张开也不会被模拟。宽松度按到贴身区域的图层内距离渐增，生成固定点（1 − 宽松度）、质量与受风（随宽松度增加，肢体受风较小）。宽松顶点不足的网格不建物理体，并从原先所在的服装预设物理体中移出。物理体按部位分为 `preset_top`、`preset_skirt`、`preset_trousers`、`preset_neckwear`、`preset_sleeves`、`preset_legwear`，裤子、袖子与腿部穿戴较硬。服装行下方逐网格列出部位和宽松比例条，贴身的合为一行，下装悬停可看判定依据。取消勾选删除全部服装预设物理体 |
| 果冻眼 | 开关眼睛的果冻摆锤 |
| 「自动 Pin 物理权重」（工具栏） | 按部件类型重新计算选中图层或所有已模拟网格的上述权重组，并重新烘焙用到它们的物理体，不新建物理体 |

预设写入的组名为 `preset_pin`、`preset_mass`、`preset_wind`；物理体已在 `groups` 中指定了自己的组时，原地刷新那个组。再次应用同一预设会更新原有物理体，不会叠加。已属于用户自建物理体的网格会被拒绝。受风组目前只在 MCP `simulation_simulate` 传入风时起作用（见上文）。

## MCP

模拟按操作拆成几个工具，参数放在 `{"request": {...}}` 中，都按 `id` 指定物理体，并带 `project_id`、`state` 和 `request_id`；它们返回后台任务句柄，用 `job_wait` / `job_get` 取结果：

- `simulation_put`：按 `id` 新建或局部修改物理体，字段包括 `targets`、`material`、`material_preset`（上表预设名：`cotton`、`silk`、`chiffon`、`wool`、`denim`、`leather`、`elastic`、`hair`、`fine_hair`、`thick_hair`、`bangs`，同时给出的 `material` 字段覆盖其数值）、`groups`、`glue_roles`、`inputs`、`modes`、`keys`、`exaggeration`、`static_inputs`、`blend_shapes`（`true` / `false` / `null` 为自动）、`auto_bake`、`output_names`（按参数或摆锤 ID 指定名称，整体替换）、`input_ranges`（按输入参数给出 `[min, max]` 训练范围，整体替换）、`vertical`（`true` / `false` / `null` 为自动）、`outputs`（按生成的模态参数 ID 给出 `{id, range, gain}`，整体替换，不需要重新烘焙）、`force_inputs`（即使几乎不带动物体也保留的输入）、`training_clips`（参与训练的动作，`{动作: 0.05–1}`，整体替换）；新建时未给 `inputs` 写入默认输入，给空数组即没有输入；`auto_bake` 开启（默认）时在同一步内重新烘焙，并返回 `bake` 摘要或 `bake_error`；
- `simulation_simulate`：只读试算（面板里没有对应按钮），每个输入保持 `hold` 秒再松开、观察 `release` 秒，可选 `wind`，返回峰值、静止漂移、拉伸和设置提示；
- `simulation_bake`：烘焙（数秒），返回各模态参数与摆幅、关键点数、摆锤 ID 与节数、独立摆锤的 ID（`own_pendulums`，有时）、每个输入的读取结果（`inputs`：带动物体的距离、是否只平移旋转、所属组或已剔除）、每组在检验动作上的视觉检查（`visual`）、烘焙方法（`method`），以及在检验动作上的 `fit_r2`、`error_p95_px`、`parameter_peak`（模态参数最多用到范围的比例）、`clipped_frames`（顶到极值的帧占比）与 `jerk_ratio`（急动度与模拟之比）；
- `simulation_compare`：只读后台任务，用 `motions` 中的动作（用户动作 ID 或内置名称，最多 8 个）分别驱动参考模拟和导出模型，返回每个动作的视觉检查；
- `simulation_clear_bake`：清除烘焙；
- `simulation_delete`：删除物理体。

参考模拟预览对应试听会话，不进入文档和历史：`simulation_preview` 以 `mode=start` 和 `simulation_id` 开始（`restart` / `stop` 带 `session_id`），`simulation_preview_step` 按 `dt` 秒（最多 0.1）推进 1–240 步，`simulation_preview_get` 读取当前帧，`simulation_preview_render` 渲染当前帧。

`vertex_group_update` 按规则（`fill`、`outline`、`gradient`、`glue`、`region`）生成权重组，`delete=true` 删除，不传逐顶点数组；`vertex_group_paint` 用与画布相同的笔刷、渐变和反转修改权重。`workspace_inspect` 的 `scope=simulations` 列出物理体、胶水键和烘焙摘要（含 `bake_stale`），`scope=vertex_groups` 列出权重组。

## 当前范围

- 已实现：布料与头发（XPBD 求解，按面积分配质量，三角形面积与防翻转，基于旋转的弯曲，自动纹理方向与各向异性，固定点、胶水角色、长程约束）、顶点权重组、参考模拟预览、烘焙为参数 + 关键形（融合变形或关键形轴，可自动选择）+ 摆锤并导出、自动烘焙、夸张系数；模型预设（头发模拟替换旧摆动、按宽松度模拟上衣 / 裙子 / 裤子 / 领饰 / 袖子 / 腿部穿戴、自动 Pin 物理权重）。
- 实测：上表 tml 后发的对比数据。模型预设在 tml 上的烘焙（检验动作 R² / 95% 误差，旧求解器上测得，需在新材质模型下重测）：后发 0.69 / 229 px，与手动固定顶部 10% 相同；前发 0.25 / 185 px，换任何固定范围都在 0.2–0.3。前发的问题在材质而不在固定范围：贴额头横扫的刘海不像后发那样由发束长度承担重力，默认头发材质的弱回弹把它变成约 0.75 Hz 的软弹簧，左右摇头（1.2 Hz）时偏离骨架 74 px（骨架带动 33 px），点头时 47 px。改用「刘海」材质后（新材质模型，tml / ds）：摇头 41 / 30 px，点头 12 / 10 px，转头停住后残留 10 / 6 px，烘焙 R² 0.18 → 0.27 / 0.21 → 0.49，95% 误差 216 → 85 / 112 → 57 px；裙子的数据是在已移除的碰撞功能下测得的，需重新实测。头发加质量 / 受风组会把后发的 R² 从 0.69 降到 0.56，所以头发预设不写这两组。
- 障碍物：模拟体可带障碍物（`obstacles`）——跟随另一网格的圆或胶囊，粒子被挡在外面，参与参考模拟与烘焙，并导出到播放实时模拟的运行时目标（p2lrt、网页）。目前只能经 MCP `simulation_put` 编写，画布上还没有编辑入口。较早的网格碰撞体（按边距）实测不可靠，已移除；旧工程中的这类碰撞体和碰撞权重组在加载时忽略。
- 尚未实现：风等力场导出、刚体与软体、烘焙为普通关键（去掉生成器）。
- 宽松度热力图人工检查（tml、ds 与一份 Q 版素材）：tml 只有裙子下半部宽松；ds 的围裙、腰后蝴蝶结与裙摆宽松，泡泡袖、袖口和袜口贴身；Q 版敞开外套腰线以下宽松，直筒裤贴身。
- 尚待实测：示例模型上的裙子与头发导出后在官方运行时中的视觉效果；模型预设生成的头发与服装模拟的自然度。
