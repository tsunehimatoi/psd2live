# 摇摆生成

摇摆生成对应 Cubism Editor 5.1 的「揺れの自動生成」：选中弯曲变形器，自动在一个参数的 -1 / 0 / 1 上生成摆动的关键形态。在此基础上它还做了这些事：

- 选中网格也可以，会自动给网格包一层贴合的弯曲变形器；
- 分**左右**和**上下**两种摇摆；
- 同时生成对应的**物理摆锤**；
- 设置随工程保存，随时可以重新打开调整。

## 打开方式

- 画布（对象模式）右键选中的网格或弯曲变形器 →「生成摇摆...」。多选时一起注册。
- 层级树里右键网格或弯曲变形器 →「生成摇摆...」。已经生成过摇摆的对象显示为「编辑摇摆...」。
- 物理面板 →「摇摆物理摆锤」卡片：列出所有摇摆，可以编辑，也可以从当前选中对象生成。

打开后画布切到编辑模式，进入摇摆编辑。编辑时不会弹出遮挡画布的窗口：形状直接在画布上拖出来，左下角只有一个可以折叠的小面板。多个目标共用同一组参数和同一个摆锤；编辑期间画布被锁定，点在手柄以外的地方不会选中或拖动其它对象；要追加目标，在层级树里选中其它网格，再点面板上的「注册选中对象」。右键菜单在编辑期间也不弹出。旋转变形器不能作为目标。

## 画布上的控件

画布上会同时画出三个轮廓：静止形状（虚线）、+1 姿态（实线）、-1 姿态（淡色），并画出两个姿态的中心线。固定边会加粗显示。所有手柄都放在 +1 姿态上，拖到哪里，+1 姿态的那一部分就到哪里：

| 手柄 | 位置 | 拖动效果 |
| --- | --- | --- |
| 圆点 | 尖端 | 横向拖设幅度，拖到另一侧就是翻转；沿轴拖设上翘 / 下坠。伸缩弹跳时只沿轴方向起作用 |
| 菱形 | 中心线中点 | 设柔软度：中段跟着尖端走得越少，根部越挺 |
| 小方块 | 尖端两角 | 设尖端的放大 / 缩小 |
| 空心方块 | 其余三条边的中点 | 点击后把这条边设为支点 |

所有修改都会实时显示在模型上。面板上的「预览摆动」让参数在 -1 和 1 之间来回摆动（多段时逐段错开）。「生成」/「应用」或 Enter 会写成一条历史记录；「取消」或 Esc 不留任何改动。

## 两种摇摆与支点

「摇摆方向」指尖端在屏幕上的运动方向；「支点」是固定不动的那条边（按格点的行列计算，第 0 行是上边）。两者的组合决定变形方式：

| 方向 | 支点 | 变形 | 典型用途 |
| --- | --- | --- | --- |
| 左右 | 上 / 下 | 弧形弯曲 | 发丝、飘带、尾巴 |
| 上下 | 左 / 右 | 弧形弯曲 | 横向伸出的饰物、侧边飘带 |
| 上下 | 上 / 下 | 伸缩弹跳 | 耳坠、蓬松发梢、胸 |
| 左右 | 左 / 右 | 伸缩弹跳 | 很少用 |

- **弧形弯曲**：沿中心线弯曲时长度保持不变，所以尖端摆出去时会自然上抬，不会像单纯平移那样被拉长。
- **伸缩弹跳**：尖端沿支点方向伸长或缩短。伸长时变窄，压缩时变宽，保持体积感。
- **自动支点**：
  - 细长的对象取上边；
  - 横向的对象取离身体中线更近的一侧。

## 设置

面板里只放画布上没有对应位置的选项（摇摆方向、自动估计、分段、自动支点、物理），其余几项只读显示当前数值。

| 设置 | 作用 |
| --- | --- |
| 摇摆幅度 | ±1 时尖端移动的距离，按支点到尖端的长度计（0.25 = 四分之一长度） |
| 上翘 / 下坠 | 弯曲时尖端额外抬起（正值）或下坠（负值） |
| 柔软度 | 0：整条均匀弯曲；1：根部保持挺直，主要是尖端在动 |
| 放大 / 缩小 | ±1 时靠近尖端的部分变宽或变窄 |
| 左右翻转 | 把 +1 和 -1 的方向对调 |
| 分段 | 1–3 段，每段一个参数。第 k 段只弯曲它下面的部分，物理上共用一根多节摆锤，下面一段比上面一段晚一拍，形成甩鞭式的跟随 |
| 自动估计 | 发丝 / 饰品 / 布料，给出一组初始形状和摆锤参数；摆锤长度按目标的像素长度估算 |

参数不存在时会自动创建（范围 -1..1）。如果选用已有的参数，关键放在它的最小值、默认值和最大值上。

勾选「自动更新关键形态」后，画布会实时显示修改；「预览摆动」让参数在 -1 和 1 之间来回摆动（多段时逐段错开）。点「生成」或「应用」才会写成一条历史记录，「取消」不留任何改动。

## 物理

勾选「为此摇摆生成物理摆锤」后，导出的 physics3.json 和 cmo3 里会多出 `PhysicsSwing_<id>` 物理组：

- **左右**：输入与前后发相同，头部和身体的角度 X（X 类型）、角度 Z（角度类型）。
- **上下**：输入头部和身体的角度 Y、以及小权重的角度 Z。
  - Cubism 的摆锤杆是刚性的，一根垂直挂着的摆对上下平移没有反应。
  - 所以这里把角度 Y 当作横向（X 类型）激励输入，再用摆的角度去驱动上下形态。
- **分段**：每段对应摆锤的一个顶点，第 k 段参数接在第 k 个顶点的输出上。

在物理面板里对同一输出参数新建的自定义组会替换掉这个摆锤。

## 生成器语义与烘焙

摇摆是一个「生成器」：每次重建模型时，都会按目标变形器当前的形态重新计算，然后在后面加上摇摆轴。所以：

- 目标原有的关键轴（例如角度 X）都会保留。每个原有关键形态都会各自展开出 -1 / 0 / 1 三个形态。
- 这条摇摆轴归摇摆所有，手动改这条轴上的关键形态，重建后会被覆盖。
- 想手动微调时，在面板上点「烘焙为关键」：
  - 当前形态会写成普通关键形态，之后可以自由编辑；
  - 摆锤保留，摇摆只剩物理部分。
- 「删除」会连同生成的轴和自动创建的参数一起移除。

## Agent

MCP 的 `swing` 工具提供 `put` / `delete` 两个分支，字段与界面上的设置一一对应：

- 省略 `physics` 时，按目标尺寸估算摆锤；
- `physics_enabled=false` 表示不生成摆锤；
- `delete` 的 `bake=true` 等同于「烘焙为关键」。

`inspect` 的 `scope=swings` 列出当前所有摇摆。
