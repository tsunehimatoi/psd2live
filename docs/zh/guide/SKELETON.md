# 骨骼与姿态

骨骼把身体、肢体、尾巴、翅膀烘焙成 Cubism 能直接运行的结构：上、下半身是身体变形器链末端的**弯曲变形器**，**旋转变形器**负责四肢等整块部件的转动，跨关节的网格用**修正关键形**完成平滑弯曲。导出的 moc3/cmo3 不依赖本程序，在 Cubism Editor 里可以继续编辑。

## 工作流

骨骼的操作集中在「骨骼」标签页，它和「层级树」在同一个面板里，是并列的两个标签（旧的布局会自动加上这个标签；也可以从窗口菜单单独打开或关闭）。树里按层级列出每根骨骼，绑定到它的画元列在下面，用同一种颜色标出，显示的是图层名（拆分时起的名字）；点画元名称会在层级树里选中对应图层。

**骨架是一个独立的选择对象**，和画元、变形器并列，三种模式对它的作用与对画元一致：

| 模式 | 骨架被选中时 |
| --- | --- |
| 对象模式 | 画布上淡淡显示骨骼，点击骨骼（或在「骨骼」标签页点骨骼行）即选中骨架；选中画元或变形器时骨架自动取消选中。视图选项中的「骨骼」开关可以隐藏这层骨骼，隐藏后画布上点不到骨骼，仍可从标签页选中 |
| 变形模式 | 摆姿态（工具栏只有「骨骼姿态」） |
| 编辑模式 | 编辑骨架（工具栏只有「编辑骨骼」） |

1. **创建 / 编辑骨架**：在「骨骼」标签页点「创建骨架」或「编辑骨架」，或选中骨架后切到编辑模式（默认快捷键 `Alt+W`）。编辑时，每个绑定的画元会在画布上用它所属骨骼的颜色半透明填充，选中骨骼的画元更醒目。首次创建会自动推断一套骨架：
   - **按语义绑定**：按图层标签和侧别绑定——手臂绑同侧的 handwear，腿绑 legwear，脚绑 footwear，尾巴、翅膀绑各自的图层。开关类、切换类的变体图层一起绑定，但不参与骨骼位置的估计。
   - **按人体构型定位**：
     - 肩关节放在躯干肩线下方、躯干边缘内侧；髋关节放在髋线下方（被裙子遮住也照样放）。
     - 弯着的肘/膝放在折弯的外角内侧，直的肢体按比例放：上臂 : 前臂 : 手 ≈ 1 : 0.85 : 0.55，大腿 ≈ 小腿。
     - 手腕按前臂与手的比例放；有鞋子时脚踝放在鞋口，脚尖取鞋子最远的一端。
     - 尾巴沿网格内部的中轴线等分成 3–4 节。
   - 拖动关节端点调整位置；点击 ArtMesh 绑定到当前骨骼。
   - 绑定的网格会在**整条肢体**上自动计算权重，同一条肢体的网格只需绑定到其中一根骨骼。
   - 在树中点选骨骼，再点画布上的 ArtMesh 即可绑定；画元行末的「×」解除绑定。尾巴、翅膀可在标签页顶部勾选添加或移除。
   - 选中骨骼后可以在标签页底部调整「关节带宽」（在关节两侧多宽的范围内平滑过渡，点「自动」恢复默认值）和「最小 / 最大」角度，角度范围就是该骨骼参数的范围。
   - **离开编辑模式即保存**：切换到其他模式、选中别的图层、点「完成」都会把修改写成一条历史记录并重建模型；点「完成」后会进入变形模式摆姿态。只有「取消」会放弃本次修改。
   - 「禁用」只是关闭骨架，骨骼和绑定都会保留；在标签页中点「启用」即可恢复。
2. **摆姿态**：选中骨架后进入变形模式，或在「骨骼」标签页点「姿态」（默认快捷键 `Shift+W`）。
   - 拖动骨骼身体：FK，只旋转这根骨骼。
   - 拖动骨骼末端，或按住 `Shift` 拖动：IK，这根骨骼连同最多两级父骨骼一起转向指针，每个关节都遵守角度限制。
   - 默认角度范围很宽（例如大臂 -90°~150°、小臂 ±150°），拖动不会被中途卡住；需要限制某个关节时，在编辑骨架时调小它的最小/最大角度。
   - 摆姿态只修改参数值，不修改网格，也不产生历史记录。工具面板中的「重置姿态」会把所有骨骼参数和姿势参数归零；「显示蒙皮权重」会按骨骼颜色给每个顶点着色，关节带里的颜色是两根骨骼颜色的混合。
3. **动作**：动画面板中会出现当前骨架能播放的动作。导出时如果勾选了动作，会同时写出对应的 `motion3.json`，并注册到 model3 的同名动作组。每个预设都只驱动下表的**姿势参数**，不直接写骨骼角度：姿势对每个关节、每张网格的作用已经烘焙在模型里，动作只决定何时做到什么程度。

| 动作 | 条件 | 驱动的姿势参数 |
| --- | --- | --- |
| Idle（循环 6 秒） | 始终 | 全身跟着两个节拍动：重心一个周期、呼吸两个周期。髋部带头换重心，上半身、身体转向依次滞后跟上，头部反向微倾保持视线水平、最后转头；手臂、尾巴、翅膀滞后于它们挂着的部位。没有骨架时只保留身体和头部的部分 |
| TailSwing（3 秒） | 有已绑定网格的尾巴 | 甩尾，往返三次 |
| Crouch（1.8 秒） | 有已绑定网格的腿 | 下蹲再站起，重心保持为 0 |
| WeightShift（3 秒） | 有已绑定网格的腿 | 重心移到一侧再回来，下蹲保持为 0 |

导出物理时，尾巴第 2 节以后的关节和翅膀交给物理驱动。如果某个姿势涉及的骨骼全部由物理驱动（例如扇翅），Idle 就不再写这个姿势，避免两者冲突。物理写的是骨骼参数，姿势是叠加在上面的融合变形，两者可以同时生效。

## 生成的结构

| 对象 | ID | 说明 |
| --- | --- | --- |
| 躯干弯曲 | `DeformSkelTorso`（弯曲变形器） | 挂在呼吸变形器下，接管呼吸变形器原有的全部子对象（躯干、衣服、手臂、翅膀、头部旋转）。以上半身、下半身参数为轴：腰线以上随上半身、以下随下半身绕腰转动，腰部过渡带内平滑弯曲 |
| 腿部弯曲 | `DeformSkelLegs`（弯曲变形器） | 挂在身体变形器下，与呼吸变形器并列，只以下半身参数为轴，承载腿、尾巴和留在身体变形器上的腿部网格。呼吸不会把脚抬离地面，下半身转动时腿和裙子按同一个弯曲函数转动。没有东西挂在它下面时不生成 |
| 骨骼旋转变形器 | `DeformSkel_<骨骼 ID>` | 只给四肢、尾巴、翅膀生成。pivot 在骨骼头部（即父骨骼末端的关节），手柄沿骨骼方向（Cubism 的手柄在 0° 时朝上、顺时针为正，所以竖直向下的骨骼 `baseAngle` 为 180°，嵌套的变形器只记录相对父骨骼的转角），按骨骼层级嵌套；手臂、翅膀挂在躯干弯曲下，腿、尾巴挂在腿部弯曲下。下面没有挂网格或子变形器的骨骼不生成变形器；同一张网格内部的关节（没有自己的网格、只连着下一段）也不单独生成，并入下一段的变形器 |
| 胶水 | `GlueSkel__<网格A>__<网格B>` | 同一条肢体拆分成多个网格时，接缝上位置重合的顶点自动焊接 |
| 骨骼参数 | `ParamArmLA`、`ParamArmLB`、`ParamHandL`、`ParamLegLA`、`ParamLegLB`、`ParamFootL`、`ParamTail1..n`、`ParamWingL` 等 | 单位是度；正值表示向远离身体的方向摆动，左右两侧一致 |
| 下蹲 | `ParamSkelCrouch`（0..1，融合变形） | 身体变形器下沉，腿部关节由 IK 求解，脚保持原位；大臂稍微外张 |
| 重心转移 | `ParamSkelWeight`（-1..1，融合变形） | 髋部横移并略微倾斜，必要时同时下沉，保证双脚都够得着地面；上身反向回正，大臂随后跟上 |
| 甩尾 | `ParamSkelTailSwing`（-1..1，融合变形） | 尾巴逐节卷向一侧，越靠近尾尖转得越多 |
| 手臂摆动 | `ParamSkelArmSway`（-1..1，融合变形） | 左右手臂反向摆动，远端关节幅度递减 |
| 扇翅 | `ParamSkelWingFlap`（-1..1，融合变形） | 左右翅膀对称扇动 |

## 算法

- **变形器层级**：旋转变形器挂在弯曲变形器下时，只继承支点位置和角度，上层弯曲的非刚性形变传不下去；弯曲变形器挂在弯曲变形器下时，只变换子变形器的控制点。所以身体骨骼不用旋转变形器，而是做成身体链末端的细网格弯曲变形器：身体 X/Y、身体 Z、呼吸的弯曲一路传到躯干网格，肩部、头部的支点也跟着移动；精细的腰部弯曲直接作用在网格和四肢上，不会被粗网格的上层变形器重新采样。弯曲变形器在静止时是恒等映射，插入它不会移动任何对象，也不改动子对象的坐标。
  ```
  DeformBodyXY（身体 X/Y、下蹲/重心的髋部运动）
   ├ DeformBodyZBreath（身体 Z、呼吸）
   │   └ DeformSkelTorso（上半身 + 下半身）
   │       ├ 躯干、衣服等网格
   │       ├ 手臂、翅膀的旋转变形器
   │       └ DeformHeadRotation → 头部
   └ DeformSkelLegs（下半身）
       └ 腿、尾巴的旋转变形器，腿部网格
  ```
- **腰部弯曲**：上、下半身都以腰（骨骼头部）为轴。沿骨骼方向到腰的距离在「关节带宽」内按 smoothstep 过渡，带外完全刚性转动。默认半宽为骨骼长度的 25%，上限 45%，可以在编辑骨架时选中上/下半身调整。
- **刚体部分**：旋转变形器插值的是角度，不是顶点位置，所以参数取任意值时肢体都是精确的刚体旋转，不会在关键帧之间缩短；几个关节同时转动时，也不需要把关键形乘起来。
- **权重**：每个顶点最多跟随关节两侧的两根骨骼。离顶点最近的骨骼是它的主骨骼；在主骨骼两端的关节带内，按到关节角平分线的有向距离用 smoothstep 过渡。关节带默认半宽为两根骨骼中较短者的 35%，上限 45%，因此同一根骨骼两端的关节带不会重叠。
- **角度混合**：关节带内的顶点绕关节旋转「权重 × 相对角度」，而不是在两个刚体位置之间做线性混合（LBS）。这样顶点到关节的距离保持不变，弯曲时肢体宽度不变，肘部内侧不会塌陷。
- **网格挂在哪里**：
  - 每张网格挂在**顶点最多的那根骨骼**的旋转变形器下，pivot 在这根骨骼的关节上，转这个变形器就是转网格里画的这一段。网格伸到其他骨骼上的部分，按这些骨骼的角度写进网格自己的关键形。
  - **未拆分**（一张网格覆盖整条肢体）：例如丝袜从大腿中段画到脚踝、大部分在小腿上，就挂在小腿下；上方的大腿变形器下面虽然没有网格，但作为髋部支点带着整条腿转动，保留下来。下方没有网格的骨骼（例如脚）不生成变形器。
  - **已拆分**（每段一张网格）：每段挂在自己骨骼的旋转变形器下。关节带里的顶点仍按位置蒙皮，两段在重叠处的变形完全相同，接缝不会裂开；接缝上重合的顶点另外自动上胶水。
  - **中间关节**（例如大腿和小腿是一张网格、挂在大腿下，脚是另一张）：每张网格最多一个旋转变形器，小腿不单独生成。脚的旋转变形器直接挂在大腿下，把小腿参数作为自己的关键形轴：角度直接相加，pivot 按与大腿网格相同的关键值沿膝盖的圆弧取值，所以脚踝和网格在关键帧之间的落点一致。
- **修正关键形**：关键形只以相关关节的参数为轴，每轴间隔不超过 7.5°；单个网格的关键形总数超过 600 时，均匀放宽间隔（角度范围很宽的手臂约为 10°）。每个关键形都按运行时实际构建的变形器变换计算，所以刚体部分落点与变形器完全一致。未拆分网格中挂载骨骼以外的部位由关键形线性插值定位，两个键之间有很小的弦误差（离关节 160px 时约 1px 以内）；需要完全精确时，把肢体拆分成段。
- **关节加密**：绑定的网格在每个关节带内沿角平分线方向插入 5 行顶点（带的两侧边缘、1/4 处和关节处）。行与外轮廓的交点一定会插入顶点，保证轮廓能弯成弧线。新顶点是原顶点的仿射组合，所以画面不会移动，已有关键形和 Glue 会自动重映射。重复烘焙不会再增加顶点。
- **姿势参数**：每个预设姿势是一个融合变形参数，只在当前骨架能用到时生成。它以融合变形的形式叠加到相关对象上：身体变形器（髋部运动）、躯干/腿部弯曲（上半身反向回正）、骨骼旋转变形器（关节转角）、蒙皮网格（关节带的弯曲）。姿势不是关键形轴，所以不会和骨骼角度参数或其他姿势的关键形相乘；姿势叠加在骨骼自身参数之上，摆过姿势的肢体仍然可以手动转动。
- **腿部姿态**：下蹲和重心转移在每个关键值上都按运行时实际的髋部位置用两骨 IK 求解，膝盖朝外弯，脚掌保持水平。两者各自以另一个为 0 求解，同时生效时只是简单相加，只有其中一个幅度很小时脚才能保持不动；预设动作因此从不同时驱动这两个参数。
- **导出要求**：旋转变形器上的融合变形需要 Cubism 5.0 及以上。导出更旧的版本时，旋转变形器上的姿势会被去掉（导出时会给出提示）。

## 限制

- **左右合在一起的网格不会被绑定。** 肢体图层应在导入时通过「批量按网格拆分图层」拆成左右各一个。如果双腿或双脚仍画在同一个图层里，自动推断会建出两条腿的骨骼，但不绑定这个网格，也就不会生成下蹲和重心转移；先拆分，再到「编辑骨架」里分别绑定。
- **手工改过拓扑的网格不加密。** 历史中有手工拓扑编辑（细分、刀切等）的网格，其编辑是按顶点序号重放的，所以骨骼不会给它插入顶点。如果弯曲处不够平滑，请手动在关节处加点。
- 超过约 90° 的弯曲，关节内侧会出现重叠，与 Spine 的线性蒙皮一样，需要靠调整关节带宽或拆分原画来改善。
- 骨骼烘焙之后，Cubism Editor 里不保留骨骼语义；如需继续改骨骼，请保留本程序的工程文件。
