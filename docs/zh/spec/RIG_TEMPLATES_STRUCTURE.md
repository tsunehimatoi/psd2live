# 算法模板目录：结构与表现

> 本目录写于部位与模块架构之前，沿用“插槽 / 模板”的说法：同一插槽下互斥的做法将登记为该部位的**基础算法**，可叠加的能力登记为**模块**，`*/current` 对应各部位的 `legacy` 基础算法。实现状态以注册表（MCP `module_catalog`）为准，本页的 P0/P1/P2 只是规划优先级，“已实现”指引入注册表之前已有的算法。见 [Rig 预设架构](RIG_PRESETS.md)。

[文档目录](../../README.md) · [预设架构](RIG_PRESETS.md) · 模板目录：[面部](RIG_TEMPLATES_FACE.md) · [头发与身体](RIG_TEMPLATES_HAIR_BODY.md) · [物理与动作](RIG_TEMPLATES_PHYSICS_MOTION.md) · [结构与表现](RIG_TEMPLATES_STRUCTURE.md)

本页是 [Rig 预设架构](RIG_PRESETS.md) 的模板目录之一：每个区域插槽可注册多个算法模板，模型预设为每个插槽选择一个模板并给出参数值。同一问题的不同做法作为同一插槽下的不同模板并存。设计依据为通用 Live2D 制作惯例；数值均为建议默认值与可调范围，实现后按出图调校。每个插槽的 `*/current` 是现有算法，作为默认模板登记，选它时输出不变。

通用记号：FW = 脸宽，EH/EW = 眼高/眼宽，H = 角色身高（画布中人物高度），T = 开关参数，统一 `0..1`（导出时可映射到 0..30 等宿主习惯）。“引擎能力”一栏用以下缩写：

- MK：多键（一轴三键以上，含非均匀键与紧邻键对）
- BS：混合形状（加法形状参数，mesh/warp 级 = Cubism 4.2；rotation 级 = 5.0）
- BSC：通道混合形状（不透明度 / 颜色 / 绘制顺序的加法）——Cubism 5.0 Extended，umamo 目前未建模
- DOP：变形器级不透明度通道（整棵子树淡出）
- DOK：绘制顺序关键形
- RM：反向蒙版（Cubism 4.0+）
- MM：多蒙版（一个网格多个蒙版源）
- PG：乘积门控（多开关轴的键网格只填不透明度）
- RPT：repeat 参数（Cubism 5.3；umamo 只读写标志，不建模）
- PHY：物理输出（含级联、reflect）
- HOST：宿主映射侧车（VTS 参数设置、热键、表情 exp3）
- MOT：动作生成（锯齿 / 斜坡 / 阶跃曲线）
- CHK：质量检查规则（`core/quality`）

PSD2Live 现状（写各插槽 `*/current` 与“差距”的依据）：

- 参数：`StandardParameters` 20 个参数无条件加入，默认值固定（嘴形 0、眉 0），`parameterTree` 固定 6 组；TOGGLE / SWITCH 差分图层生成 0/1 不透明度网格参数（`RigBuilder.buildChannels`）。没有参数“角色”之外的分类（只有眨眼/口型角色），没有派生参数、宿主映射配置。
- 变形器分层：生成器全部用关键形轴；混合形状只有三处先例——`SkeletonPoses` 预设姿态（blend shape）、模拟 `SimGenerator.usesBlendShapes`（目标轴乘积超过 64 格时自动改用混合形状）、内部造型 `NativeInteriorEffect`（原生 blend 字段）。umamo 支持 mesh/warp/rotation 的混合形状与权重限制曲线（`BlendWeightLimit`），通道混合形状未建模。
- 网格：按标签系数（脸/头发/上衣 0.65，眼/眉/嘴/牙/舌 0.45，其余 1）× 全局间距（GUI 40 / CLI 64），最小间距 12；密度表在 `RigBuilder.meshSettings`、`GenerationDefaults`、`ComponentSplitter` 三处重复。不读形变复杂度。
- 绘制顺序：静态，按 PSD 顺序 × `drawOrderStep`，用户可覆盖；多键编辑可手写绘制顺序关键形；生成器只给远侧耳朵 AngleX 不透明度（`earOpacity`），没有顺序翻转。
- 蒙版：虹膜被眼白剪、牙舌被嘴剪；`SeeThroughLayers`：眉毛复制件 + 刘海在眼睛处反向开窗；无投影、无光影蒙版。
- 开关：TOGGLE/SWITCH 只有 0/1 不透明度，无过渡、无互斥结构、无变形器级门控；`ModelSidecars.standard` 表情只是 MouthForm/EyeOpen/BrowY 偏移。
- 特效、光影：无生成器；通道关键形（不透明度、正片叠底色、滤色）可手工编辑。

## 插槽 param.system（参数体系）

### param.system/current — 标准参数集
- 目的：现有默认。20 个标准参数 + 差分参数；范围、默认值固定；物理和动作写同一个标准参数。
- 差距：无按驱动源分层、无影子参数、无派生信号表、无宿主映射、默认值不随原画。
- 优先级：保留为默认（P0 登记）。

### param.system/source-split — 按驱动源拆分的影子参数（追踪与表演分离）
- 目的：同一形变由多个驱动源（待机、表演、物理、追踪、姿势库）各写一条加法参数，互不覆盖。
- 适用：任一需要被多个来源同时驱动的可动单元（手臂旋转、头发摆动、身体倾斜、眼球）。
- 产出结构：
  - 每个单元 u、每个源 s ∈ {idle, act, phys, track, pose} 一个 BS 参数 `<Unit>_<Src>`（例 `ArmR_Lift_Phys`），范围 −1..1，默认 0。
  - 主参数（标准参数，追踪写入）保留为关键形轴；影子参数作为该单元的混合形状挂在同一对象（旋转用角度增量，warp/网格用位移场）。
  - 参数树按源分组：`Tracking` / `Idle` / `Performance` / `Physics` / `PoseLibrary`。
- 算法：
  1. 定义单元的“单位形变” D_u（旋转：角度增量；warp：位移场）。
  2. 源幅度上限 A_s（相对单元满幅）：idle 0.2、act 1.0、phys 0.75、track 0.5、pose 1.0；BS 端点 = D_u(±A_s)。
  3. 形变非线性（大角度、走弧线）时为 BS 加中间键（见 deformer.layering/arc-baked-keys）。
  4. 绑定：PhysicsGenerator 输出 → `_Phys`；MotionGenerator 待机 → `_Idle`；触摸/表演动作 → `_Act`；视线/鼠标 → `_Track`；`_Pose` 预置姿势供动作调用。
  5. 表演时可整体压低 `_Idle`（BS 权重限制曲线以表演门控参数为约束），无须改物理。
  6. 降级：目标不支持 BS 时把所有源相加烘焙进一个参数，并在损失报告写“源不可独立驱动”。
- 可调参数：`sources`（启用的源集合，默认 idle/phys/track）；`amp.<src>`（相对满幅，见上，范围 0.1–1）；`idleDuck`（表演时待机衰减，默认 0.3，0–1）。
- 失败模式与检查：warp 位移相加在多源同时满幅时失真（大角度单元优先旋转）；Σ源上限 ≤ 单元允许范围（CHK：超限 warning）；同一驱动同时写两个源导致翻倍（CHK：同一物理组/动作轨道写同一单元两个源 → error）。
- 引擎能力：BS（含 rotation BS = 5.0）、BS 权重限制、PHY、MOT、参数分组。
- 难度：medium；优先级 P1（依赖 deformer.layering/pose-grid-plus-blend）。

### param.system/derived-signals — 单信号扇出的派生参数表
- 目的：一个情绪/追踪信号按阈值与时间常数分层点亮多个部件（嘴先动、眼中等笑意才弯、腮红慢浮现、尾巴大笑才翘）。
- 适用：有宿主追踪（VTS 等）的模型；有对应部件（眼笑、腮红、尾/耳）。
- 产出结构：预设中的“派生参数表”行：`{target, source, window [a,b], outRange, curve, smoothing τ}`；导出为宿主映射；编辑器预览按表模拟。
- 算法：
  1. 默认表：嘴形 ← MouthSmile [0.1,1] τ0；眼笑 ← MouthSmile [0.4,1] τ≈0.15 s；腮红 ← MouthSmile [0,1]→[0.5,1] τ≈0.7 s；尾抬起 ← MouthSmile [0.7,0.9] τ≈1.5 s；兽耳竖起 ← 眉高 [0.5,1]；身体 ← 头角 ×0.3 τ≈0.3 s。
  2. Rig 内部只能用物理组近似平滑，不能做阈值——阈值必须在宿主侧。
- 可调参数：每行 window、outRange、τ；`bodyFromHead`（0.3，0–0.5，与 body 物理二选一）。
- 失败模式：增益过大提前饱和；身体同时被头映射与物理“身随头”驱动导致双计（CHK）。
- 引擎能力：HOST（宿主映射侧车）、编辑器预览模拟。
- 难度：easy；优先级 P1。

### param.system/host-mapping — 宿主映射的平滑与增益表
- 目的：导出 VTS 等宿主配置时按通道频率设平滑与增益。
- 产出：宿主参数设置（输入 → 输出范围、平滑）；与 derived-signals 共用输出通道。
- 算法：平滑表（0–100 刻度）：口型 0、视线 10、眼开 10、眉 10–15、头 X/Y 15、头 Z 30、身体 20。增益 = 参数中性值 / 典型追踪中性值；AngleY 灵敏度 1.5 起步。
- 可调参数：平滑表、增益表。
- 失败模式：增益过大饱和；默认值改动（见 art-default）后需补偏置。
- 引擎能力：HOST。难度 easy；优先级 P1。

### param.system/art-default — 默认值放在原画位置
- 目的：参数默认 = 原画状态，范围两侧余量按表现需要分配而不是机械对称。
- 适用：嘴形（原画微笑）、眉角、齿开、手指、手势、绘制层级参数。
- 产出：参数 `[min, v0, max]`，v0 处键 = 原画；v0 在端点时该轴只做单向关键形。
- 算法：分类器或规则判断原画在该轴上的位置（嘴角高于嘴中线 → 微笑 → MouthForm 默认 1，范围 −1..1 全部留给“不笑→撇嘴”）；导出宿主映射时补偏置，使标准追踪中性仍落在 v0。
- 可调参数：`useArtDefault`（每参数开关，默认关，标准追踪参数谨慎）。
- 失败模式：标准参数默认值偏移导致宿主追踪错位（CHK：默认 ≠ 标准默认且无宿主偏置 → warning）。
- 引擎能力：HOST 偏置。难度 easy；优先级 P1。

### param.system/head-drives-body — 无身体参数时头角度分层驱动全身
- 目的：只有面部追踪的宿主下，不建 Body 参数组，直接把头部角度按比例分配给全身根链，歪头 = 全身轻侧倾 + 头再多歪。
- 适用：全身立绘、用户选择“无身体参数”模式。
- 产出：全身根链 AngleZ warp（6–8×6）→ AngleY warp → AngleX warp → 极小 AngleX 旋转（±1°）；头部旋转 AngleZ 只取 0.5×参数角；每条腿一层 AngleZ warp，朝该腿一侧倾斜时加一个中间键（约 0.4×端点，承重腿略屈膝、髋略升）。
- 算法：AngleZ 全身倾斜分担 0.2（行权重脚 0 → 头 1 缓入）；AngleX 全身 ≤0.03H 横移，躯干 warp 做胸转，头 warp 做主转；AngleY 躯干 ≤0.01H 伸缩。检查：AngleZ 端点脚底位移 <0.005H。
- 可调参数：`headRollShare` 0.5（0.4–0.6）；`bodyLeanShare` 0.2（0.15–0.3）；`stanceKey` 0.4（0.35–0.5）。
- 失败模式：日后再加 Body 参数会双计；根 warp 太粗时裙摆折角。
- 引擎能力：MK（单侧中间键）。难度 medium；优先级 P2（与 body.turn 冲突，作为模式）。

（说明：参数插值相关的“弧线烘焙密键”放在 deformer.layering/arc-baked-keys；循环参数放在 effect/loop-cycle。）

## 插槽 deformer.layering（变形器分层）

### deformer.layering/current — 关键形轴乘法组合
- 现状：所有生成的次级运动（头发摆动、眼球果冻、身体次级）都作为普通关键形轴并入主网格；模拟在乘积 >64 格时自动改混合形状；骨骼姿态用混合形状。
- 差距：无“主姿态网格 + 加法次级”的统一规则。
- 优先级：保留为默认（P0 登记）。

### deformer.layering/pose-grid-plus-blend — 姿态网格 + 加法层（主模板）
- 目的：关键形只留给少数可组合的“姿态轴”，所有次级运动、表情修饰、完美同步、物理输出都做成混合形状，键数从乘法变加法。
- 适用：全部生成器的架构规则；尤其头发、衣服、饰物、眼、嘴。
- 产出结构：
  - 姿态轴（关键形网格，每对象 ≤3 轴）：头 AngleX×Y（3×3），身体 X×Y，眼开×笑（或开×笑×情绪 3×2×2）。
  - 在主姿态 warp **之下**插入一个“加法 warp”（自身无关键形轴，只有 BS），次级形状写在它上面——位移处于局部坐标，自动随父级转头/透视。
  - 物理输出参数一律为 BS 参数；每个加法 warp 叠加 ≤4–5 个形。
- 算法：
  1. 参数分类：姿态轴 vs 加法层（判据：该形变“在任何主姿态下都长得差不多”）。
  2. 加法层增量在默认姿态下计算，两端 ±1 分别计算、不强求对称；默认两键线性，必要时加中间键。
  3. 组合安全：随机采样姿态×加法组合，用 `GeometrySafetyEvaluator` 检查翻折、自交；不合格处加修正组合键或改回关键形。
  4. 大幅形变（单形位移 > 对象尺寸 25–30%）不做加法，改分层（nested-segment-cascade）或关键形。
  5. 降级：目标 <4.2 时每个 BS 参数降为“额外关键形轴”或“以该参数为轴的子 warp”（数学等价），损失报告写组合数增长。
- 可调参数：`maxPoseAxes` 3（2–3）；`maxBlendPerTarget` 4（3–6）；`maxBlendDisplacement` 0.25（0.15–0.3，相对对象长度）；`autoBlendCells` 64（现有模拟的自动阈值，作为“自动”档）。
- 失败模式与检查：加法形互相拉扯（CHK：同目标 BS 数超限 warning）；物理参数与头/身角度进同一关键形网格（CHK：info，建议改 BS）。
- 引擎能力：BS（mesh/warp 4.2、rotation 5.0）、BS 降级器（已有 `MocBlendLowering`）、组合采样检查。
- 难度：hard（架构）；优先级 **P0**（预设重构的基础约定）。

### deformer.layering/cross-parent-modifier — 跨父级的衰减修饰形
- 目的：正交修饰（笑眼、歪嘴）作为一个 BS 参数同时作用于分属不同父级的多个对象（嘴、脸颊、鼻），按距离衰减。
- 适用：修饰类参数——在主轴两端制作修饰形，差量方向夹角 <20°、长度比 0.7–1.3。
- 产出：BS 参数，范围统一为 0..1；作用对象：修饰中心半径内的所有网格/warp。
- 算法：
  1. 在主轴代表键上算差量（眼：闭 0 与睁 1；嘴：OpenY=0）；两端差量不一致时每个主键各存一份（BS 随主轴插值，需“每键差量”能力）。
  2. 影响范围：从修饰中心（嘴角、眼角）smoothstep 衰减，半径约 0.25 FW。
  3. 降级：<4.2 时在主轴网格展开第二轴并报告维度增长。
- 可调参数：`radius` 0.25 FW（0.15–0.35）；`perKeyDelta` 判定阈值（夹角 20°）。
- 失败模式：主轴极端处差量不可加（全闭眼时“笑”应改弧线方向）→ 必须每键差量。
- 引擎能力：BS、每键差量（BS 与关键形轴组合）。难度 medium；优先级 P1。

### deformer.layering/cross-hierarchy-shared-blend — 跨层级共享次级形（长发搭在手臂上）
- 目的：一个物件按“此刻压在哪个部位上”拆片，各片挂到所在部位的变形器，再共用同一组 BS 叠加来自头部的摆动——既随承载部位动，又随头摆。
- 适用：长发越过肩线搭在胸/上臂/前臂；披肩、围巾、长缎带。
- 产出：发片切成 2–4 段，各挂胸/躯干/上臂/前臂的子 warp；一组发丝物理（头 roll 为主输入，3 输出 = 相邻节点）作为 BS 加到所有段；段间 Glue。
- 算法：
  1. 静息姿态下每个发丝顶点取其下方覆盖的身体网格作归属，无则归头；连通区域平滑，最短段 ≥ 2 倍发宽。
  2. 位移场沿整根发丝弧长 s 连续定义，每段截取自己的 s 区间 → 跨段连续。
  3. 振幅随 s 增加，被压附段乘 0.3–0.6。
- 可调参数：`pressFactor` 0.45（0.3–0.6）；`segments` 3（2–4）；`headRollWeight` 0.75（0.6–0.9）。
- 失败模式：手臂大抬时压附段被带离，与头上段拉开（Glue 留余量，或加手臂角补偿 warp）；归属判定抖动。
- 引擎能力：BS（跨不同父级共享同一参数）、Glue、PHY。
- 难度：hard（research 级的归属拆分）；优先级 P2。

### deformer.layering/nested-segment-cascade — 嵌套分段 warp 逐层递减（甩鞭）
- 目的：同一区域建 n 层嵌套 warp，第 k 层只弯末端 s>(k−1)/n，分别吃物理的第 k 个输出，幅度逐层递减——末端相位滞后、总幅最大。
- 适用：发区、裙前后片、袖口、领坠等摆动区；同区的发影、马尾根挂进同一套层。
- 产出：n=3 层嵌套 warp；物理 n+1 粒子，输出 v_k → 第 k 层，缩放 `scale0·r^(k−1)`；左右各一个摆，竖直输入在一侧 reflect。
- 算法：粒子长度逐段略减（约 1 : 0.9 : 0.85）；质量与阻尼取偏高值（约 0.95），加速度略低（约 0.9），软而不拖；头上物件以 AngleZ（角度型输入）为主、AngleX / AngleY（位移型输入）为辅，权重约 3.5 : 1 : 1；身上物件以 BodyZ 为主、BodyX / BodyY 约为其一半。
- 可调参数：`layers` 3（2–4）；`decay` 0.7（0.6–0.8）；`zToXWeight` 3.5（2–4）。
- 失败模式：层数多时外层小角度被内层放大，末端抖；脸上发影挂同链时蒙版必须是脸。
- 引擎能力：PHY 多输出、嵌套 warp、reflect。难度 medium；优先级 P1（与 physics.cascade 组共享，此处登记分层约定）。

### deformer.layering/inherit-not-reinput — 层级继承与物理输入分工
- 目的：挂在头上的条带（系带、发带、耳挂），头部运动由层级继承，物理只接身体输入，避免重复计入；另加一层小幅、不对称的 AngleZ 补偿。
- 产出：条带物理层之上插 AngleZ rotation/warp；条带物理组只含 BodyX/Y/Z 输入。
- 算法：AngleZ 两端求条带根点在头部轮廓上的切线变化，角度 = −k·Δθ；拉紧侧 k≈1，松弛侧 k≈0.4；补偿角 ≤10°；两端都固定在头上或很短（<0.5 EH）时省略。
- 可调参数：`kTight` 0.9（0.8–1）；`kSlack` 0.4（0.3–0.5）；`maxComp` 10°。
- 失败模式：物理组同时含头输入与层级继承 → 双倍（CHK：挂在头部子树下的物理组含头角度输入 → warning）。
- 引擎能力：PHY 输入集合按挂载位置推导。难度 easy；优先级 P1。

### deformer.layering/arc-baked-keys — 弧线烘焙密键（自适应插键）
- 目的：Live2D 键间线性插值，绕点转动的部件中途走弦线会缩短变扁；生成器只“作者”锚点键，再按弧线自适应补中间键。
- 适用：头部角度、物理输出参数、发尾、手指、绕关节转的任何关键形；表情开关不启用。
- 算法：
  1. 生成器内部用旋转链/3D 代理求任意参数值下形状 S(p)；或对每控制点用三锚点 p₋,p₀,p₊ 拟合外接圆，沿圆弧按角度插值（近共线偏离 <0.2% 对象尺寸时保持线性）。
  2. 自适应：半段中点 S(mid) 与线性插值偏差 > ε（对象尺寸 0.5%）时插键并递归，至偏差 < ε/4，每半段最多 6 段；二维轴各自适应、取并集网格。
  3. 正面附近加密（非均匀键 x_k = sign(k)·R·(|k|/K)^1.4）作为可选分布。
  4. 导出前合并近共线键（偏差 < ε/2）。
- 可调参数：`epsilon` 0.5%（0.3–1%）；`maxSubdiv` 6（2–6）；`maxKeysPerAxis` 13（发）/ 37（手指）；`centerDensityExp` 1.4（1–1.6）。
- 失败模式：均匀密键使文件暴涨（必须自适应）；外接圆近共线半径爆炸（必须判定）。
- 引擎能力：MK；生成器需能求任意 p 的形状（不只锚点）。难度 medium；优先级 P1。

### deformer.layering/rigid-pin — 硬质饰物钉在布料上
- 目的：纽扣、徽章、铆钉等硬件放在旋转变形器下，布料 warp 只搬运其原点，饰物不随褶皱剪切。
- 适用：面积 <1% 所在布料、轮廓分离、对比强的小件。
- 产出：每件一个 rotation（原点 = 饰物中心，挂布料最内层 warp）→ 3×3–5×5 warp（BodyAngleX：转离侧水平压缩 5–15%）；网格 12–20 顶点。
- 可调参数：`followRotation` 0.25（0–0.5）；`perspectiveSquash` 10%（5–15%）。
- 引擎能力：rotation 挂在 warp 下。难度 easy；优先级 P1。

### deformer.layering/root-spaces — 根空间：舞台相机 / 角色相机 / 场景根
- 目的：根部分出纯刚体的“空间”层：舞台相机（整个画面）、角色相机（只角色）、场景根（桌椅、立式麦克风，不随角色动）。
- 产出：`StageCam` rotation（平移 ±0.6 画布宽、缩放参数 −1→≈0、0→1、3→4，1 与 4 间补中间键使推镜匀速）→ 背景特效分支 + `ActorCam` rotation（平移 ±0.3 宽、缩放 0→1 / 30→3、旋转 ±45°，轴心取支撑点）→ 角色根；`SceneRoot` warp 与角色根并列，只有开关不透明度键。图层标注 scene / held / worn 决定挂载。
- 检查：两层相机只允许刚体变换，默认严格为单位变换（CHK）。
- 可调参数：平移范围 0.3–1.2 宽；缩放上限 3–4；旋转 ±30–45°。
- 引擎能力：rotation 缩放、DOP。难度 easy；优先级 P2（演出预设，默认关）。

## 插槽 mesh.density（网格密度与拓扑）

### mesh.density/current — 标签系数 × 全局间距
- 现状：脸/头发/上衣 0.65、眼眉嘴牙舌 0.45、其余 1；最小间距 12；嘴线开启时嘴外边距 0、最小间距 6。三份密度表重复且不一致。
- 优先级：保留为默认，P0 合并为单一表。

### mesh.density/deformation-driven — 按形变复杂度分配顶点与 warp 分辨率（主模板）
- 目的：顶点放在“图案自身会弯的地方”；只被父 warp 搬运或刚性旋转的大件稀疏；warp 行列按区域长宽比与形变波长分配。
- 适用：全部网格与生成 warp。
- 算法：
  1. 每网格目标边长 L = min(父 warp 单元边长 × 0.5, 线稿细节尺度, 自身关键形特征尺度 × 0.25)，夹在 [ℓ_min, ℓ_max]。
     - 自身关键形强度 D = 自身关键形间顶点位移二阶差分均值 / 包围盒短边；L = ℓ_base / (1 + k·D)。D=0（只被父级搬运）时 L ≈ 父 warp 单元 0.5 或短边 /4。
     - 首次生成时还没有关键形：用“该部件绑定的参数数 × 预期位移”估计（由模板声明的产出结构给出）。
  2. 类别默认边长：线条类（唇线、眼线、睫毛）0.06 EW；五官面片 0.05 EW；发束 0.01 头高；脸、躯干面片 0.03 头高；刚性肢体 0.05 H；大面积布料 0.02–0.03 H；特效贴片 = 四边形。
  3. 特征线沿线加密：沿线边长 ≤ 线宽，垂直方向 2–3 列；高曲率轮廓、关节、换画交接处局部加密。
  4. warp 行列：rows : cols = 高 : 宽 × 形变复杂度系数；cell ≈ 区域形变波长 / 4（面部 2–3% 头高，身体 1–2% H）；只平移/整体旋转的 warp 2×2–5×5；总控制点 ≤600。
  5. 最小顶点数：小件 16，一般 30。
  6. 总预算 30k–60k 顶点，超出时按非关键类等比降密。
- 可调参数：`kComplexity`（k，默认 1）；`edgeTable`（上述类别表）；`rigidWarpMax` 5；`warpPointBudget` 600；`vertexBudget` 45000（30k–60k）。
- 失败模式与检查：密 warp × 多键导致导出体积和运行开销上升（CHK：单对象控制点 × 键数超限 warning）；有 IK 屈膝的腿不能取刚性肢体的低密度（模板需声明“该部件有内部弯折”）。
- 引擎能力：网格生成接受每层目标边长场；需读取模板声明的预期形变；生成后可二次细化（RasterMeshJournal 迁移关键形）。
- 难度：medium；优先级 **P0**（先合并密度表并加入“刚性 / 只被搬运 / 自身关键形”三档；按关键形的二次细化 P1）。

### mesh.density/structure-aligned — 沿结构线布网（条带 / 极坐标 / 约束边）
- 目的：网格边沿结构线（伞骨、条带中轴、衣褶）布置，形变时结构线保持直/平滑。
- 适用：条形部件（缎带、流光、尾巴、长发束）→ 沿中轴四边形条带 2–3 行；圆盘状道具（伞、花、魔法阵）→ 极坐标网格（每根骨一条径向线，3–5 圈）；带明显直线结构的部件 → 约束边。
- 可调参数：`stripRows` 2（2–3）；`polarRings` 4（3–5）；结构线检测阈值。
- 引擎能力：约束三角化。难度 medium；优先级 P2。

### mesh.density/rigid-quad — 硬质贴片用四点网格
- 目的：硬质装饰（冰晶、金属翼、光片、粒子、家具贴片）用 4 顶点网格，几乎零成本，由 rotation/warp 整体移动。
- 适用：标为 rigid/effect 的图层；透明边缘浪费贴图面积时可裁切包围框。
- 引擎能力：无特殊。难度 easy；优先级 P1。

## 插槽 mesh.glue（补充插槽：胶水）

### mesh.glue/same-topology-lock — 同拓扑复制层全点胶合
- 目的：同一形状拆成底色/阴影/线稿等多张同拓扑网格时，全点胶水锁成一体；生成器只对主层算关键形。
- 算法：检测拓扑与静息位置一致（顶点距离 <0.5 px）的网格对 → 全点胶水强度 1，以底色或蒙版源为主层；导出时可烘焙到副层关键形（目标支持胶水则保留）；副层有自身 BS 或局部动作时按区域降权。
- 可调参数：`matchTolerance` 0.5 px（0.5–1）。
- 失败模式：副层局部动作被拉回。SeeThrough 复制件明确不复制胶水（避免伙伴被拉两次），需排除。
- 引擎能力：Glue、Glue 烘焙。难度 easy；优先级 **P0**（投影孪生、光影复制件都依赖它）。

### mesh.glue/seam-auto — 相邻块接缝自动 Glue
- 目的：相邻块挂在不同最深变形器下时自动加接缝胶水，避免裂缝。
- 算法：两网格属于不同最深变形器、alpha 边界 2 px 内相邻长度 ≥ 两者周长 5% → 用 GlueSeam 让边界顶点重合，沿弧长每 1.5–2 个网格边长取一对；权重 0.5/0.5，挂点固定一侧 0.7/0.3；同父且关键形相同不加。
- 可调参数：`adjacencyPx` 2；`minShare` 5%；`pairSpacing` 1.75 边长。
- 引擎能力：Glue、GlueSeam。难度 medium；优先级 P1。

### mesh.glue/hierarchy-bridge — 跨头身的连接件切段胶合
- 目的：横跨头与身体的物件（耳机线、围巾、项链）在颈线处切成头段与身段，各挂所属层级，接缝胶合，拉伸而不断开。
- 算法：像素同时落在头/身两区且连通 → 在颈线切开（重叠 1–2 个网格单元）；接缝权重 0.5（线）或偏重侧；接缝顶点密度 ≥ 每 3% 线长一个；姿势切换会分开的部件，在切换点把胶水强度键到 0（需 Glue 关键形/BS = 5.0）。
- 引擎能力：Glue、（Glue BS 5.0 可选）。难度 medium；优先级 P1。

## 插槽 draw-order（绘制顺序）

### draw-order/current — 静态顺序 + 用户覆盖
- 现状：PSD 顺序 × `drawOrderStep`；`drawOrderOverrides`；多键编辑可手写；远侧耳只淡出不翻转。
- 优先级：保留为默认（P0 登记）。前提约定：静态顺序使用稀疏刻度（层间留空），为下列模板留插入缝隙。

### draw-order/group-level — 组深度滑杆（连续 level 参数）
- 目的：手臂、翅膀、道具、子角色等组的绘制顺序做成一个连续参数，整组平移、组内保持相对偏移；一条曲线描述穿插时刻，中间值可插进身体栈任意缝隙。
- 适用：可动到身前/身后的肢体组、翅膀、可移动道具。
- 产出：`<Group>_Level` 参数，范围 = [栈中最低可插入位置, 栈顶]，默认 = 原画位置（常在端点）；组内每网格键 level ∈ {min, max}，顺序 = level + δ_i；端点外扩 |δ_i| 防截断。另输出“地标深度表”（后发后、身体与手臂间、身体前、脸前、最前）供动作生成器与 MCP 选用。
- 算法：
  1. δ_i = 组内排名 × 小步长，步长 < 相邻非组网格间距 / (组内层数 + 1)；|δ| ≤ 相邻地标间隔 1/3。
  2. 动作中按深度关系设 level（手是否落在躯干轮廓内、前臂旋转区间），无深度信息时由作者手 K。
  3. 与其他顺序关键形（手指弯到掌后）组合时用乘积键把偏移相加。
  4. 校验：level 采样时组内顺序不变，组与非组相对顺序只在穿插处变一次；绘制顺序相等处必须错开（CHK）。
- 可调参数：`levelStep` 相对栈间距 0.25–0.5；`innerStep` 0.01–0.05；`default` = 原画。
- 失败模式：带蒙版的组，蒙版网格须同组移动；每网格多一个 level 轴使关键形翻倍——目标支持部件级顺序时优先放部件上。
- 引擎能力：DOK（作为额外关键形轴）；理想为部件级绘制顺序或 BSC（加法通道）。
- 难度：easy–medium；优先级 P1。

### draw-order/additive-offset — 绘制顺序加法通道
- 目的：前后切换做成加法偏移参数（±Δ），表演可在任何姿态下单独切换，不需要每个姿态关键形都带顺序。
- 适用：手指 vs 握持物、手/袖、尾巴 vs 衣服、道具面片。
- 算法：offset = ±Δ，Δ = 两组顺序差 + 1；绘制顺序不插值，在参数中点跳变；动作在遮挡最小帧切换。
- 引擎能力：BSC（绘制顺序混合形状，Cubism 5.0；umamo 未建模）——降级为关键形轴。
- 难度：easy（引擎侧 medium）；优先级 P2。

### draw-order/turn-flip — 转头/转身时的遮挡显隐与顺序翻转
- 目的：侧面要素（耳、侧发、远侧眼角、环形饰物两半）按 3D 代理深度随角度显隐和翻转顺序。
- 产出：在角度轴上加不透明度键（v 跨 0/0.5/1 处）与绘制顺序键（深度翻转角 θ* ± δ 处）。
- 算法：
  1. 头部椭球（或躯干圆柱、手臂在肩偏移处的圆柱）投影深度 z = cos(φ + θ)。
  2. 近侧耳在转到约一半范围后顺序升到头发之上；远侧淡出（已有）。
  3. 只在发生翻转的一侧做（不对称）。
  4. 中线精确切换的件用紧邻键对（0 与 −ε）做阶跃。
  5. 绘制顺序按整数插值，两键之间的数值不得跨过无关层（CHK）。
- 可调参数：`flipThreshold` 0.5 范围；`delta` 0.05–0.1 范围；`epsilon` 范围 0.01%。
- 引擎能力：DOK、MK（紧邻键对）。难度 medium；优先级 P1。

### draw-order/ring-split — 环形饰物分半、分级下沉
- 目的：头冠、发箍、光环、头巾按头部中线切成两半，转头时远侧一半分 2–3 级依次沉到前发、侧发、脸之下。
- 适用：语义为环形头饰，或跨越头部左右的闭合/半闭合带状层。
- 算法：方位角 φ → z = cos(φ + θ)；在 AngleX 键（0, ±20, ±40, ±60 等）求 z，映射到头部栈插入位置（前发 > 侧发 > 脸 > 后发）；同时以 AngleX 打几何键做椭球透视压缩；两半额外键左右镜像。
- 可调参数：`stages` 2（2–3）。
- 失败模式：原画未分层时需切图（不得在像素上做阈值切割，切线由几何决定、整体归属两半）。
- 引擎能力：DOK、MK、镜像。难度 medium；优先级 P1。

### draw-order/depth-slice — 跨深度拆片与露出补丁
- 目的：抱臂等姿势中同一肢体跨越多个绘制深度：把后片放进躯干部件，在躯干链里以相同参数复现肢体运动；手臂离开后被遮区域用补丁层交换。
- 算法：按遮挡关系切前片/后片 → 后片放躯干变形链，以姿势参数做不透明度；对肢体链受的全局参数逐个采样后片锚点位移并拟合到后片 warp 键；补丁 = 默认画与姿势画躯干可见像素差异区；校验接缝 <0.1% H。
- 可调参数：接缝阈值 0.05–0.1% H；每参数采样 3 点。
- 引擎能力：跨链运动拟合（采样另一链形变）、Glue。难度 research；优先级 P2。

## 插槽 mask（蒙版、透发、投影孪生、发影）

### mask/current — 透过刘海与五官剪切
- 现状：`SeeThroughLayers`：眉毛复制件以刘海为蒙版；刘海在眼睛处反向开窗 + 刘海复制件；虹膜被眼白剪、牙舌被嘴剪。
- 优先级：保留为默认，作为 `mask/see-through` 模板登记（P0），其“复制件 + 记录表 + 成品阶段制作”的框架是下面投影孪生的样板。

### mask/cast-shadow-twin — 投影孪生：跟随投射者、裁剪于接收者（主模板）
- 目的：影子的形状由投射者决定、可见范围由接收者决定：阴影网格放在投射者的最内层形变里（共享 warp 与 BS），以接收者为蒙版，正片叠底。
- 适用：发束→脸、帽檐→头发/脸、缎带→衣身、裙摆→大腿、外套→连体衣、胸饰→胸。来源二选一：PSD 已有阴影层（名含 影/阴影/shadow 或正片叠底暗色）→ 识别；否则从投射者生成。
- 产出：阴影网格（投射者拓扑副本，或独立低密度网格）；混合 Multiply；蒙版 = 接收者；父级 = 投射者父级；可选额外视差 warp（AngleX×Y）。
- 算法：
  1. 识别：投射者 = 阴影上方、外轮廓最相似（Chamfer 距离最小）的图层；接收者 = 下方重叠面积 >20% 的图层。
  2. 生成：偏移 d = L·k·(z_投 − z_受)（光向默认左上偏前），轮廓收缩/羽化；颜色 = 受影面色 ×0.8（或灰度纹理）。
  3. 视差：头转向角点给阴影额外位移 Δ = −c·(z_投 − z_受)·sin(angle)，c≈0.3。
  4. 多接收者分属不同分支/顺序不相邻 → 复制阴影，每份一个接收者蒙版，顺序放在该接收者之上。
  5. 开关：阴影随投射者的开关节点一起淡出（挂同一 DOP 子树）。
  6. 若阴影只能挂在接收者下（接收者形变主导）：几何键控投射者运动参数，跟随系数 0.6–0.9。
- 可调参数：`lightDir` 左上 45°；`offset` 投射者宽 0.3–1.0（或 0.5–2% H）；`opacity` 0.35（0.2–0.5）；`parallax` 0.3（0.2–0.5）；`split` 自动。
- 失败模式与检查：接收者自身被剪切需合并蒙版；蒙版数上限；隐藏投射者后阴影残留（CHK：阴影未随投射者开关 → warning）；与腮红、发影、脸部阴影多层叠加过暗。
- 引擎能力：MM、正片叠底、复制件框架（同 SeeThrough：记录表、成品阶段制作、跟随原件全部编辑）、DOP 继承。
- 难度：medium；优先级 P1。

### mask/hair-shadow-window — 发影：阴影色脸副本 × 跟随发丝的蒙版
- 目的：刘海在脸上的阴影随发丝摆、不越出脸、保持皮肤色调、边缘不因贴图拉伸变形。
- 产出：每片发片一个阴影蒙版网格（发片轮廓沿光向偏移 2–4% 脸高，可软边），挂发片的变形器并复制其 BS；接收层 = 脸皮颜色 × 阴影色（亮度 ×0.85、偏红）的脸副本，画在脸之上，以所有阴影蒙版并集为蒙版；眉下、饰件同理。
- 可调参数：`offset` 3% 脸高（2–4%）；`darken` 15%（10–20%）；`soften`。
- 失败模式：蒙版不看不透明度——阴影蒙版网格本身须隐藏（静态不透明度 0 但仍做蒙版）。
- 引擎能力：MM（蒙版并集）、复制件（脸副本，同拓扑胶合）、蒙版网格可隐藏。
- 难度：medium；优先级 P1（与 cast-shadow-twin 二选一，作为同插槽另一解法）。

### mask/chin-neck-shadow — 下巴颈影：挂头空间、脖子裁切
- 目的：颈上下巴影由头投下，挂在头部变形器下（随下巴、张嘴、俯仰），以脖子为蒙版；或以脸/下巴副本做反向蒙版，永不画到脸上。
- 产出：带状 Multiply 阴影（沿下巴轮廓下沿偏移 0.08 FW，软边）；父 = 头部转向 warp（或张嘴 warp）；蒙版 = 脖子（正向）或下巴副本（反向）；AngleY 键：低头变宽变长（多覆盖 10–15% 颈高），抬头变窄，上仰半程加中间键表达非线性收缩；AngleX 时向转头反方向偏。
- 可调参数：`offset` 0.08 FW（0.05–0.1）；`opacity` 0.4（0.3–0.5）；`midKey` 0.5（0.4–0.6）。
- 引擎能力：MM、RM（可选）、MK。难度 easy；优先级 **P0**（低成本、普适、已有脖子与头部链）。

### mask/contour-cutter — 反向蒙版切割网格雕刻轮廓
- 目的：随转向改变的轮廓（下颌、下巴、体块重叠边）不拉伸纹理，而用一块随角度精确移动的“橡皮擦”切出可见边界。
- 算法：3D 代理（头部椭球 + 下颌曲线）求每姿态目标轮廓；切割网格 = 目标轮廓外侧带状多边形（宽 0.1–0.2 FW）；键位正面附近加密（x_k = sign(k)·30°·(|k|/K)^1.4，K=12）+ AngleY 13 键；目标层反向蒙版 = 切割网格；轮廓线稿另设不被切的描边层；体块重叠版本挂与被切体相同的物理链。
- 失败模式：<4.0 无 RM；蒙版数上限；线稿被切。
- 引擎能力：RM、MK（非均匀）、3D 代理。难度 research（用途为推断）；优先级 P2。

### mask/interleave-cutout — 反向蒙版表达交织深度
- 目的：长条（尾巴、丝带、拇指）与遮挡物部分在前、部分在后时，长条整体画在遮挡物之后，再让遮挡物被“应在前的那几段”反向剪切开洞。
- 算法：每段中心处判断原画中谁可见 → 全前/全后用普通顺序，否则 S 排 O 之后，O 以应在前的段并集为反向蒙版；<4.0 时拆分 O 或改用 draw-order/additive-offset。
- 可调参数：每遮挡物蒙版数上限。
- 引擎能力：RM、MM。难度 medium；优先级 P1。

### mask/pattern-slide — 轮廓蒙版内的表面图案滑动（伪 3D 翻滚）
- 目的：尾巴、袖子等圆柱状部件的花纹在轮廓蒙版内横向滑动，读作翻滚/扭转。
- 算法：图案与轮廓分层（需要美术分好，不在像素上切），图案网格挂同段变形器，被轮廓并集蒙版；每段一个滚动参数，键形沿垂直中线平移 ±30–50% 段宽、近边缘 cos 压缩；由第二个摆（delay ×0.8）或角速度驱动；图案纹理在轮廓外留余量。
- 可调参数：`rollAmp` 40%（30–50%）；`phaseDelay` 0.8。
- 引擎能力：MM、PHY（第二摆）。难度 hard；优先级 P2。

## 插槽 toggle（表情、换装、变体槽、门控、交叉淡化、过场参数）

### toggle/current — 差分 0/1 不透明度
- 现状：TOGGLE/SWITCH 图层各生成 0/1 不透明度参数；标准表情为面部参数偏移。
- 优先级：保留为默认（P0 登记）；下列模板把“开关”扩展为：结构（谁让位）× 时序（怎么过渡）× 打包（几个参数）× 输出（表情/热键）四个正交维度。

#### 结构类

### toggle/product-gate — 乘积门控（NOR）：默认件让位于任一替代件（主模板）
- 目的：默认件不透明度 = Π(1 − T_i)：所有开关为 0 时可见，任一开启即隐藏；互斥写在 Rig 里，不依赖表情文件覆盖顺序。
- 适用：默认件 D + 替代件集合 {A_i, T_i}（眼型、嘴型、手臂姿势差分、发型、服装）。
- 产出：门控放在 D 的父组变形器（DOP）上，轴 T_1…T_n，每轴两键 {0, t_off}；只填不透明度，几何全部复制默认形。n>6 时分组嵌套：两层门控 warp 各做一组 NOR，靠逐层不透明度相乘。替代件 A_i 只以 T_i 为轴。
- 可调参数：`tOff` 0.5（配合 morph-swap 两段式）或 1；`groupSize` 6。
- 失败模式与检查：被隐藏件若是他人蒙版源，隐藏后对方剪切也消失（CHK：门控子树含蒙版源 → warning）；隐藏件的物理继续运行（可接受）；开关同时开启时替代件叠加（需优先级或 signed-slot）。
- 引擎能力：PG、DOP（不支持时下推到每网格，键数相乘 → 损失报告）。
- 难度：easy；优先级 **P0**。

### toggle/slot-swap — 插槽替换：组变形器不透明度整组开关
- 目的：可选部件按“插槽”（头顶饰、右前臂、后发、手持物）分组，每选项一个组变形器只带不透明度轴，一个开关同时“隐藏旧件 + 显示新件”；替代件挂在与原件相同的最内层姿态 warp 下，切换后照样跟随转头/物理。
- 适用：图层标注插槽与选项（命名约定 `slot@option`），或 PSD 差分组。
- 产出：每选项一个门控变形器 G_i（覆盖选项包围盒，无形变）；默认选项 G_0 用 product-gate；替换件挂到默认件的同一关节/姿态链（差分标注挂接关节：肘/腕），继承物理。
- 可调参数：交叉淡化时序（引用 timing 类模板）；表情淡入 0.3–0.8 s。
- 失败模式：导出到不支持 DOP 的目标需下推每网格；被替换件仍参与物理与蒙版。
- 引擎能力：DOP、PG、HOST（表情）。难度 easy；优先级 **P0**。

### toggle/signed-slot — 带符号变体槽：一个参数两端放两种互斥变体
- 目的：语义互斥的两个变体放在同一参数的 −1 与 +1，参数数减半、互斥由结构保证；经过 0 的默认态过渡；两条槽乘积门控默认件。
- 适用：眼型、虹膜型、嘴型、腮红档、漫符、粒子组选择。
- 产出：每槽 p ∈ [−1, 1]（变体多时扩到 [−2, 1] 三态）；负端变体不透明度 max(0, −p)，正端 max(0, p)；默认件 Π_slots(1 − |p|)（每槽键 {−1, 0, 1}）；所有变体挂同一追踪/透视 warp（视线、开闭、头转）；可选单独 `off` 参数只淡出默认件；可选“弹出”：组 warp 0→±1 从 0.6 缩放到 1，±0.7 处 1.1 过冲。
- 可调参数：`crossfadeWidth`（整半程线性，或 ±0.1 更硬）；`popScale` 0.6→1.1。
- 失败模式：变体不随眨眼闭合（须挂在开闭 warp 下或开闭参数也门控）；超过 2 槽时默认件键维度 3^n，应改部件不透明度或表情文件（CHK）。
- 引擎能力：PG、MK、DOP。难度 easy；优先级 P1。

### toggle/state-machine — 表情状态机：one-hot 状态参数 + 组不透明度真值表
- 目的：每个表情一个状态参数 E_i ∈ [0,1]，表情文件 = one-hot；每个面部变体（睁眼组、闭眼线组、^^ 眼、○ 眼、>< 眼、泪、口型组）一个组变形器，不透明度 = 真值表 V(blink, E_1..E_n)。
- 适用：面部差分丰富、表情是“换画 + 形变”的模型。
- 算法：
  1. 变体标注适用表情：`eyeL: {open:[neutral,rage,…], happyClosed:[cheek], circle:[sp8,sp10], blinkLine:[*]}`。
  2. 每变体只把真正影响它的轴加入（≤6 轴），每轴键 {0, 切换点, 1}，填 0/1；内部可用“任一 E_i 超阈值即隐藏”的 max 规则，导出时烘焙为网格。
  3. 闭眼线组必须同时受眨眼与表情控制（符号眼下眨眼不露普通闭眼线）。
  4. 生成 exp3：每表情 {E_i=1}，中性 = 全 0，淡入淡出 0.5 s。
- 失败模式：两个表情同时为 1 时真值表未定义——写明优先级或互斥。
- 引擎能力：PG（真值表 → 键网格）、DOP、HOST。难度 medium；优先级 P1。

### toggle/variant-twin — 变体孪生网格（换色/换贴图版本）
- 目的：同一图层的变体版本复制原网格拓扑、共享全部父变形器/物理/胶水，只在最后一层用不透明度淡入；组合变体用乘积键（发型 H × 变色 V）。
- 产出：孪生网格紧贴原件之上；不透明度轴 V；原件不淡出（上层覆盖即可，变体有透明区时用 staggered-crossfade 淡出原件）；孪生件之间复制胶水对。
- 引擎能力：复制件框架、PG、Glue 复制。难度 easy；优先级 P1。

### toggle/recolor — 换色：通道关键形 + 预绘替身交叉淡化，依赖开关乘积门控
- 目的：部位 X 的正片叠底/滤色关键形做目标色；其上叠一份原色同形副本 X′，切换时淡出，原色时完全是原画、换色时是调好的色；依赖开关（纱裙换色只在纱裙开时生效）用 T_parent × T_child 乘积。
- 算法：X′ 与 X 共父共关键形（或全胶合）；X 在 T=1：multiply = 目标色/原色近似比，screen 抬暗部；X′ 不透明度 T=0:1 → T=1:0–0.05；乘算无法变浅时只能用预绘替身。
- 可调参数：`residual` 0.05（0–0.1）。
- 引擎能力：通道关键形（multiply/screen，4.2）、PG、same-topology-lock。难度 easy；优先级 P1。

### toggle/outfit-blend — 整套换装：混合形状同时携带不透明度与几何差
- 目的：两套服装对应部位挂在同一父 warp（物理、身体关键形只做一次），换装参数作为一层“加法”：旧套 −1、新套 +1 不透明度，加少量几何修正，角度与物理照常起作用，不翻倍关键形。
- 算法：语义标签对应两套部位；T ∈ [0,1] BS：旧套不透明度 −1、新套静态 0 + BS +1；轮廓不同处在共用父 warp 上加 T 的几何 BS；新套“底色层”在 T=0.5 已达 0.7–0.8，或错开 0.1–0.2 防透底；依赖新套的装饰用乘积门控。
- 可调参数：`stagger` 0.15（0–0.2）；几何修正幅度。
- 失败模式：目标不支持通道 BS 时需烘焙成 T 轴关键形（键数 ×2）；与其他互斥开关共存时必须 Rig 内乘积门控。
- 引擎能力：BSC（不透明度 BS，5.0 Extended；umamo 未建模）→ 降级为 T 轴关键形 + DOP。难度 medium；优先级 P2（通道 BS 建模后升 P1）。

#### 时序类（同一开关怎么过渡；可与任一结构类组合）

### toggle/staged-transition — 开关即一段小动画：单参数内编排过场（主模板）
- 目的：宿主表情只能设目标值与淡入时间；把“参数值”当“时间”编排位移、先后、闪光，单个热键得到有动作的过场。
- 适用：可开关道具/变体/服装；底层被遮区域须有完整绘制（覆盖检查）。
- 产出：参数 T ∈ [0,1]（宿主侧可映射 0..30），默认 0；导出为 Add 表情 T=1 + 热键，建议淡入 ≥0.5 s；过渡写在服装子树顶的过渡变形器（几何 + 不透明度）。
- 算法（按类别选子模板）：
  - 出现（appear）：从来源方向位移 d 进入并同时淡入；头顶道具 d = −0.1 物体高，召唤物 d = 0.3–1 物体高，眼镜 d ≈ 0.03 EH（略放大 5–10%）。
  - 穿戴（wear-in）：袜/手套/袖套沿肢体主轴从远端滑向近端，帽子从上落下；d = 配件长 15–30%；阴影/乘算层终值按原画、同曲线淡入；偏移须在其蒙版内；配件有物理时开关键放在物理 warp 之内。
  - 消失（exit / lift-off）：反向位移并淡出；大件“先飘起再分批淡出”：键 {0, 0.25, 0.5, 1}，从挂点放射 + 上升 d(T) = D·{0, 0.25, 0.6, 1}（D = 0.8–1.2 服装高），各块外转 10–20°；不透明度 T≤0.25 全 1，之后按块面积排序，大块慢（0.5 时 0.6）、小块快（0.5 时 0.35），连带子线性。
  - 替换（replace）：旧件在 [0, 0.66] 淡出，新件同段淡入并沿弧线到位（中间键弧高约位移 0.2）；带物理的次级件（缎带、链）在 [0.66, 1] 才出现（避免快速插值中乱甩）；闪光在 [0.67, 1] 扫过（effect/sweep-glint）。
  - 收折（fold）：见 toggle/fold-to-anchor。
- 可调参数：`phaseSplit` 0.66（0.5–0.8）；`offsetDir`、`offsetLen`；`arcRatio` 0.2（0.1–0.3）；`fadeOrder`（按面积）。
- 失败模式与检查：底层未画完整会露洞——覆盖检查：被遮区域中底层 alpha ≥0.95 的比例 ≥98%，否则 warning（不在像素上自动补）；宿主无淡入时间时过场消失但终态正确；T 停在中段是半飘中间态（表情只驻留 0/1）。
- 引擎能力：MK、DOP、过渡变形器插入在子树顶、HOST（Add 表情、热键、淡入时长）、CHK（覆盖检查）。
- 难度：medium；优先级 **P0**（appear / exit / replace 三子模板）；lift-off 分批淡出 P1。

### toggle/fold-to-anchor — 可拆卸模块缩向挂点后淡出
- 目的：可拆卸组（发髻、发尾、缎带、帽子、外套）最上层插一个 rotation，原点 = 挂点，开关时缩向挂点再淡出，有“收进去”的动画；按模块组合出多种发型/装束。
- 产出：`Toggle<Group>` 0..1：0 → scale 1/opacity 1；0.6 → scale 0.3/opacity 0.5；1 → scale 0.001–0.05/opacity 0；角度不变。生成单项表情 + 常用组合（左右对称组、只留核心）。
- 可调参数：`endScale` 0.02（0.001–0.05）；`fadeStart` 0.6（0.4–0.7）；组合表情列表。
- 失败模式：缩放时跨组强 Glue 把本体顶点拉向挂点（CHK：可拆卸组与本体间有 Glue → warning，或在 T>0 把 Glue 强度键到 0）；被隐藏组是他人蒙版源。
- 引擎能力：rotation 缩放、DOP、HOST。难度 easy；优先级 **P0**。

### toggle/staggered-crossfade — 错位交叉淡化
- 目的：对称交叉淡化中点两层各 50%，合成只有 75% 不透明会透底；让上层新件先满、下层旧件后退，任何时刻至少一层 100%。
- 算法：新件顺序高于旧件 → 新件 [0, 0.5] 淡入、旧件 [0.5, 1] 淡出，反之互换；需交换绘制顺序时在中点硬切且两件此刻都 100%；与新件重叠的旧件可用 (1−t)² 更快淡出（减少重影），不重叠件线性。
- 可调参数：`overlap` 0（0–0.25）；`fadeExponent` 1（1–3）。
- 引擎能力：MK、DOK。难度 easy；优先级 **P0**（作为所有开关的默认时序）。

### toggle/morph-swap — 先压扁再换图（变形桥接）
- 目的：两张图在形状几乎相同（一条线）的瞬间切换，切换不可见，过渡读作连续动画（“眨一下变成 >< 眼”）。
- 算法：桥形 = 两者共同退化形（以眼中心为中点、0.9 眼宽的水平细线，厚 3–8% EH）；A：0 原形 → t_s 压到桥形；B：t_s+ε 压到桥形 → 1 原形（0.75 处放大 5% 弹出）；不透明度 A [0, t_s] 为 1、t_s+ε 为 0，B 反之；整组用组变形器不透明度。
- 质检：A、B 桥形中心距 <1% FW；ε ≤0.02；表情只驻留 0/1。
- 可调参数：`tSwitch` 0.5（0.4–0.6）；`epsilon` 0.01（0.005–0.02）；`squash` 0.15（0.1–0.3）。
- 引擎能力：MK（紧邻键对）、DOP。难度 easy–medium；优先级 P1。

### toggle/bridge-layer — 交接桥接画
- 目的：即使轮廓对齐，交接时线条粗细、阴影、手形仍会跳；在切换瞬间满不透明度出现一张介于两张原画之间的过渡画，随后线性淡出让位给终态画（终态画始终垫底）。
- 算法：差异 Δ 超阈值时生成；来源优先美术中间画，自动方案为两者在交接姿态下网格对应点平均后重栅格化，或复制跳变最大的局部；挂终态分支、绘制顺序紧贴终态之上；自身不透明度键 {s+ε:1, e:0}，父分支 s+ε 前为 0。
- 可调参数：`fadeEnd` 0.85（0.7–1）；每交接 0–2 张。
- 引擎能力：MK、DOP 相乘。难度 research（自动生成过渡画）；优先级 P2。

#### 打包与输出类

### toggle/gated-axis — 门控轴：开关修改追踪而不覆盖追踪
- 目的：修饰性开关（情绪、模式）只改变连续轴端点的形状——生气时皱眉更凶，但眉的追踪依然有效；交互型开关（点下）为 0 时 X/Y 平面全等于中性形（不响应）。
- 算法：开关声明作用的连续轴集合；生成 Toggle[0,1] × Axis 键网格，Toggle=1 行在 Axis 默认值处与原形相同或只小偏移；交互型 Gate × X × Y。同一对象多个门控开关时改用 BS（加法）代替乘法网格。
- 可调参数：作用轴、变体强度。
- 引擎能力：MK、PG、BS。难度 medium；优先级 P1。

### toggle/pose-macro — 表情 = 开关 + Add 偏移的姿态宏
- 目的：表情文件一次设置开关集合与连续参数 Add 偏移，叠在实时追踪上（“拍照”：拿笔、头歪、看下方、半张嘴笑）。
- 算法：情绪模板 = {特效开关: 1, 面部偏移: {BrowForm, MouthForm, EyeOpen, MouthOpenY, AngleY/Z…}}，偏移取满量程 10–60%（超 0.6 会被截断）；眼开偏移为负时 ≤0.2；叠加色层最大不透明度 0.6–0.8 并以脸皮 + 耳为蒙版；多个 Add 表情同开会超范围 → 互斥分组或 Overwrite。
- 引擎能力：HOST（exp3 Add/Multiply）。难度 easy；优先级 P1（替换 `ModelSidecars.standard`）。

### toggle/storyboard-param — 单参数阶段动画（分镜 → 参数阶段）
- 目的：小剧情（打开信件、物体飞到身后）的多个阶段排进一个参数范围：阶段内普通关键形，阶段边界用紧邻三键 t_i−δ, t_i, t_i+δ 瞬切不透明度/绘制顺序；动作只需一条曲线。
- 可调参数：`delta` 范围 0.2%（0.1–0.5%）。
- 引擎能力：MK（紧邻键）、DOK、MOT。难度 medium；优先级 P2。

### toggle/handoff-twin — 道具交接：双副本挂不同父级 + 交叉淡化
- 目的：运行时不能改父级；道具从一个空间（领口、腰侧）移到手里时，两个副本各挂正确父级，在手遮挡的一瞬交叉淡化，父变形器不透明度整体淡出整棵子树。
- 算法：P_A（父 A）、P_B（父 B，几何换算到 B 局部空间对齐交接时刻）；swap 0..1，过渡带 20–30%；动作把跳变放在手与道具重合帧；各副本自带物理/姿态参数。
- 引擎能力：DOP、复制件、MOT。难度 medium；优先级 P2（与 prop 插槽共享）。

## 插槽 effect（特效）

### effect/current — 无
- 现状：无特效生成器；内部造型（`NativeInteriorEffect`）是唯一的“效果配方”先例，其配方 + 自有参数 + 原生 blend 字段 + 失效传播的框架可复用。

### effect/loop-cycle — 循环相位参数（生命周期参数）
- 目的：Live2D 没有时间；一个 0..1 相位参数只要两端关键形完全一致，线性推进即无缝循环。多个对象在同一参数上错开窗口 = 相位不同的粒子流。
- 适用：泪滴、汗、闪光、火焰、星光、自转装饰（雪花、齿轮、魔法阵）、上浮爱心。
- 产出：相位参数 c ∈ [0,1]（标 repeat）；可选强度参数 I 与 c 的乘积网格（|I| ≥ θ_i 时第 i 颗启用，θ 递增 → 强度越大颗数越多）；常驻循环动作（锯齿 / 斜坡）或宿主循环映射。
- 算法：
  1. 单对象：窗口 [a, a+w]（w 0.25–0.4）内前 15% 淡入/从缩放 s0 长到 1、沿路径移动、后 15% 淡出；窗口外不透明度 0 且几何回起点。
  2. 多对象：a_i = i/(n·c) + 抖动（确定性种子，低差异序列 0, 0.4, 0.7, 0.2…），可每循环出现 c 次。
  3. 随机感：每精灵确定性分配 4–9 个不规则内部键；精灵多时按相似曲线归并到 10–15 个参数，每参数驱动多处精灵。
  4. 自转：rotation 键 0→0°、1→±360°（同参数正反两套 → 一顺一逆）；动作写 0→n 线性斜坡 = n 倍速。
  5. 瞬移循环（速度线）：在 [t, t+0.3%] 内从终点跳回起点，各组 t 错开。
  6. 动作：周期 T 锯齿波（单帧回零），线性段（贝塞尔在循环点速度突变）；特效动作周期与角色待机周期取互质比（如 8:9）。
  7. 降级：目标不支持 repeat（<5.3）时 0..1 线性 + 动作循环点硬跳（两端状态一致，不可见）。
- 可调参数：`window` 0.3（0.25–0.4）；`fadeFrac` 0.15（0.1–0.2）；`period` T（汗 0.3–0.6 s、星光 10–20 s、自转 4–12 s/圈）；`count` 4–8；`paramGroups` 10–15。
- 失败模式与检查：首尾逐顶点（含不透明度、颜色）必须一致（CHK：c=0 与 c=1 求值差 > 0.5 px 或 >0.01 不透明度 → error）；窗口相加 >1 时两颗同位；旋转原点必须在精灵中心。
- 引擎能力：RPT（umamo 需真正建模：求值回绕、预览、导出标志）、MK、MOT（锯齿/斜坡/相位偏移）、PG（强度 × 相位）。
- 难度：easy–medium；优先级 P1（需 RPT 建模）。

### effect/burst — 一次性爆发：进度参数驱动成组粒子
- 目的：把“动作里几十条曲线”压缩为 Rig 里一个进度参数 p 0→1；粒子从小缩放迸出、三档相位错开、像随机。
- 产出：每粒子一个 rotation（原点 = 粒子中心），键 p ∈ {0, a_i, a_i+w/2, a_i+w, 1}；位置 C → C+R·d_i（R = 0.2–0.4 H，ease-out）；缩放 a_i:0.15 → 中点 1 → 末 0.8；不透明度窗口；a_i 三档 {0.15, 0.25, 0.35} 轮换，w = 0.5；粒子组由 signed-slot 选择；旋转型粒子再加 loop-cycle。
- 可调参数：`phaseStep` 0.1；`window` 0.5（0.4–0.6）；`startScale` 0.15（0.1–0.2）；`radius` 0.3 H。
- 失败模式：粒子父变形器不应随头转（除非挂脸上）。
- 引擎能力：rotation 缩放、MK、MOT（0→1 斜线）。难度 medium；优先级 P2。

### effect/collapsed-rest — 塌缩静止形：特效从一点长出
- 目的：特效网格静止几何缩到发射点，即使不透明度插值出错或参数关闭也绝不可见；“从一点长出”即出场动画；默认姿态干净。
- 算法：发射点（泪：眼内下角；炸毛：发际线；鼻涕泡：鼻孔；汗：太阳穴）；静止几何全部顶点向发射点收缩到 1–5%（拓扑不变）；满值 = 原画几何，70% 处 1.05–1.15 过冲；静止不透明度也为 0。
- 可调参数：`collapse` 0.03（0.01–0.05）；`overshoot` 1.1（1.05–1.15）。
- 失败模式：塌缩网格在编辑器里难选、网格密度统计失真（CHK 统计应排除）。
- 引擎能力：生成关键形时可把“静止”设为非原画几何（默认键 ≠ 原画）。难度 easy；优先级 P1（作为所有 effect 的默认出场）。

### effect/manga-symbol — 漫符系统（情绪贴片）
- 目的：怒筋、汗滴、阴沉线、红晕斜线、思考泡、音符、炸毛等程序化或 PSD 提供的情绪贴片，按五官锚点放置、挂面部角度 warp 随头转、不透明度与运动同轴、剪切到皮肤。
- 算法：
  1. 锚点（相对五官）：怒筋在眼外角向外上 0.6 EW；汗滴在太阳穴侧；阴沉线覆盖额到眼；红晕在颊；思考泡在头顶侧上方。
  2. 关键形：出现 = 参数 0..0.3 内缩放 0→1.1→1（collapsed-rest）；跳动 = 成对紧邻键或 throb 参数缩放 ±10–15%（动作 2 Hz）；滑入 = 阴沉线下滑贴片高 10–20%；腮红放大 5–10%。
  3. 蒙版：脸皮 + 耳多蒙版；思考泡内容以泡体为蒙版，内容滚动参数。
  4. 每对相反情绪一个 signed-slot 参数。
  5. 最大不透明度 0.35–0.7（色层封顶）。
- 可调参数：尺寸（怒筋 1 EW、汗滴 0.5 EW）；`maxOpacity` 0.6；`throb` 12%。
- 引擎能力：MM、MK、signed-slot、矢量模板贴图（程序化生成为 research）。难度 medium；优先级 P1（PSD 提供贴片时的放置与键）/ P2（程序化生成贴图）。

### effect/sweep-glint — 扫光：加算渐变带剪切到金属件
- 目的：对金属、宝石、玻璃件生成一条斜向加算渐变带，以这些部件为蒙版，开关过场或循环参数时横扫一次，一眼读成“闪了一下”。
- 产出：渐变带网格（宽约包围盒对角线 0.3，斜 30–45°，网格极粗）；混合加算；蒙版 = 该物件全部网格（按物体分组）；关键形：起始在包围盒一侧外、结束在另一侧外，不透明度 0→1→0；挂开关 T 的指定时段（staged-transition 的 [0.67,1]）或 loop-cycle。
- 可调参数：`bandWidth` 0.3 对角线（0.2–0.4）；`angle` 35°；`peakOpacity` 0.8（0.6–1）。
- 失败模式：蒙版部件太多增加开销；扫动方向应与物体主轴斜交。
- 引擎能力：MM、加算混合、MK。难度 easy；优先级 P1。

### effect/ambient-fx — 环境特效库（闪烁、漂移、流光、扫掠、拍翅、总开关）
- 目的：极低成本的环境动效：四边形粒子闪烁、组漂移、条带流光、反向蒙版扫掠、六点蝴蝶拍翅，特效树根一个总淡出参数。
- 子模板：
  - twinkle(quad)：不透明度 0..1 半正弦，周期 ∈ {T, 2T, 4T}，相位确定性随机。
  - drift(group)：组 warp 平移 BS ±(0.3–1% H)，周期 2T。
  - streak(strip)：2×N 条带；K 个局部波形基（窗内 sin 的法向位移），每基 13 键；动作错相正弦。
  - wipe(strip)：反向蒙版矩形沿条带切线移动，锯齿 0→1（4–5 s）+ 1–2 帧复位脉冲把蒙版推到全覆盖以藏住跳变。
  - flutter(6v)：两翼绕中线缩放 BS 2–6 Hz；漂移约 1 s。
  - master：特效树根不透明度参数 + 开/关动作。
- 可调参数：周期档位、粒子数、漂移幅度、扫掠周期；与角色待机周期互质。
- 引擎能力：RM、BS、DOP、MOT、RPT。难度 medium；优先级 P2。

### effect/audio-glow — 声音驱动的加色辉光
- 目的：麦克风等道具随说话亮起：加色辉光层以一块随音量参数平移/扩张的形状为蒙版，像电平条逐渐填满。
- 产出：辉光层（加色）不透明度随音量参数；蒙版网格随同参数移动；宿主映射 VoiceVolume → 参数。
- 可调参数：`maxOpacity` 0.8（0.6–1）；`maskTravel` = 发光区长度。
- 引擎能力：蒙版网格自身关键形、HOST。难度 easy；优先级 P2。

### effect/liquid-slosh — 容器内液面晃动
- 目的：液体被容器剪切，挂 X（横晃）、Y（上涌）两层 warp；X 层中间键给一个完整正弦波形，经过中间值时起波再倾斜。
- 算法：±1：液面以容器中心为轴倾 10–15°（体积守恒）；±0.5：完整正弦波，波幅 3–5% 液面宽，倾斜为端点一半；Y 层 ±5–8% 容器高 + 边缘弯月面；物理输入取容器所在部位的运动（身体），2–3 质点，读第 2 个。
- 可调参数：`tilt` 12°（8–15°）；`waveAmp` 4%（3–5%）。
- 失败模式：液体图层顶部须有余量；容器小时提高 warp 分辨率。
- 引擎能力：MK（BS 带中间键需 ExtendedBlendShapes 时降为关键形轴）、PHY。难度 medium；优先级 P2。

## 插槽 lighting（光影）

### lighting/current — 无
- 现状：没有任何随角度/姿态变化的光影生成；通道关键形（不透明度、正片叠底色、滤色）可手工编辑，且通道关键形已参与变化检测。生成器首次键入通道时需注意 `journalOnly` 对通道键不剥离生成轴（DOCUMENT_LAYER“后续”）。

### lighting/sliding-mask-window — 转头光影：滑动的明暗遮罩窗口（主模板）
- 目的：转头时脸的受光面变化：远侧颊进入阴影、近侧更亮、下巴下阴影跟着移动；用一块软边小遮罩扫过脸，露出一张同拓扑“明暗版”脸。
- 适用：脸（及可推广到躯干、后发）。
- 产出：
  - 明暗版脸：与脸同拓扑的副本（底色 × 阴影色合成，或 PSD 标出），全胶合到脸（same-topology-lock），可直接复制全部关键形；
  - 遮罩网格：软边、约 1/3 脸宽、约 30 顶点，挂头根 warp 下，以 AngleX × AngleY 为轴；静止放在光源对侧的脸外；
  - 明暗版以遮罩为蒙版（正片叠底或普通）。
- 算法：AngleX ±端点：遮罩平移到覆盖远侧颊 25–40% FW；AngleY：低头露额头暗部、抬头露下巴下暗部；最大位移 0.5–0.7 FW。
- 可调参数：`lightDir`；`shadeStrength` 0.3（0.1–0.5）；`sweep` 0.6 FW（0.5–0.7）；`maskWidth` 0.33 FW。
- 失败模式：遮罩是硬边——明暗版纹理须自带渐变（生成明暗版时在暗面一侧做渐变，不切像素）；与腮红、发影叠加过暗（CHK：同一像素正片叠底层数 >3 → info）。
- 引擎能力：复制件（同拓扑副本 + 胶合）、蒙版、MK、生成纹理（明暗版合成）。
- 难度：hard；优先级 P1（明暗版若由 PSD 提供则 medium）。

### lighting/shade-slide — 阴影叠层在基底内相对滑动
- 目的：光源固定、物体转动时明暗交界线在物体上滑动；阴影/高光叠层在基底剪切范围内额外滑动，后发与脸不再像“一张纸转动”。
- 产出：叠层父 warp 之下再加一层 AngleX×Y（或单轴）warp；叠层以基底为蒙版；叠层与基底重合的轮廓顶点 Glue 到基底，只让内部交界线滑动。
- 算法：偏移 Δ = k·(转角/最大转角)·基底宽，沿光源反方向，k 0.03–0.12；靠近明暗交界一侧轻微拉伸；叠层比可见范围多画 10–15%（或只移动内部交界线）。
- 可调参数：`k` 0.08（0.03–0.12）；`axes` Y 或 X×Y。
- 失败模式：滑出一侧出现“无阴影”空白；与基底同时被父级转向时双重施加（CHK）。
- 引擎能力：蒙版、Glue（部分顶点）、MK。难度 medium；优先级 **P0**（对已有阴影层的 PSD 直接生效，成本低）。

### lighting/view-falloff — 视角相关的光照层强度
- 目的：脸部柔和阴影/高光层正面最明显，转向侧面时按转角衰减不透明度，凹面区域（口腔、舌）随俯仰改滤色。
- 算法：识别光照层（脸部高光、柔和阴影、口腔/舌）；不透明度：正面 α0，AngleX 端点 0.75 α0；偏一侧的层朝该侧转 ×1.2、背向 ×0.6；凹面滤色：AngleY 俯视 +8%、仰视 −5%，AngleX 朝光源侧提亮。
- 可调参数：`sideFalloff` 0.75（0.6–0.85）；`screenAmp` 5%（3–10%）。
- 失败模式：变化太大会闪；通道关键形须进变化检测（已覆盖）。
- 引擎能力：通道关键形（不透明度、滤色）在角度轴上生成。难度 easy；优先级 **P0**。

### lighting/orientation-shade — 按朝向生成正片叠底/滤色（伪法线光照）
- 目的：有朝向参数（俯仰/偏航）的部件，由代理形状法线与主光方向写颜色关键形；四肢折叠时遮挡阴影加深。
- 算法：主光 L（左上前）；代理（平面/圆柱）法线 n(p)；multiply m = lerp(1, shadeColor, k·max(0, −n·L))；screen s = hiColor·max(0, n·L)^γ；遮挡阴影层不透明度 = o0 + k·弯曲角/90°；表面阴影层（口袋、褶皱）单独 warp 按深度给额外视差。
- 可调参数：`strength` 0.2（0.1–0.3）；`gamma` 2（1–3）；`occlusionRange` ±0.25。
- 引擎能力：通道关键形（multiply/screen 4.2）、3D 代理、MK。难度 medium；优先级 P2。

### lighting/pose-highlight — 姿态相关亮面叠层
- 目的：手臂、腿等大幅运动肢体举向光源时肤色变亮：每肢一张亮面层（原图提亮 10–20%，剪切到肢体），不透明度参数默认 0，动作生成时与肢体角度的“朝光程度”联动。
- 引擎能力：蒙版、MOT 联动（或以肢体角度为轴直接写不透明度键，免动作）。难度 easy；优先级 P2。

### lighting/dynamic-gloss — 参数驱动的动态光泽
- 目的：金属/亮面加色副本的不透明度成为摆角的函数（朝光静止时峰值，摆开衰减，cos 波瓣）；呼吸驱动滤色微脉动。
- 算法：加色副本共享变形器与 BS；不透明度在摆动参数上峰值 α0≈0.4，两端 ≈0.6 α0；可选区域蒙版限制发光范围；滤色以呼吸为键，亮度 5–10%。
- 可调参数：`peak` 0.4（0.3–0.5）；`falloff` 0.6；`pulse` 7%。
- 引擎能力：复制件、通道关键形在物理参数轴上（若物理参数是 BS 参数则需 BSC 或改为关键形轴）。难度 easy–medium；优先级 P2。

## 对预设架构的要求

以下归纳本组模板共同需要的引擎与架构能力，供预设注册机制设计使用。每条注明受益模板。

### 1. 模板注册、适用条件与组合

- 模板以 `slot/name` 注册，声明：适用条件选择器（语义标签、左右、标注点、图层标注如 `scene/held/worn`、`slot@option`、`rigid`、`metal`）、产出结构、可调参数（与 `RigTuning` 同一描述格式，含单位、默认、范围）、所需引擎能力、生成器依赖（登记到 `DocumentGenerators` 依赖图）。
- 同一插槽允许“二选一”的互斥模板（`mask/cast-shadow-twin` 与 `mask/hair-shadow-window`），也允许**正交组合**：`toggle` 插槽至少分结构（谁让位）、时序（怎么过渡）、打包（几个参数）、输出（表情/热键）四个维度，一个开关组选一个结构模板 + 一个时序模板。架构需要“组合型插槽”，而不是每插槽只选一个。
- 模板只声明，不硬编码 `when (semantic.tag)`；现有算法以 `*/current` 登记为默认模板，选择存入文档设置并参与三方合并。

### 2. 关键形声明：多键、中间键、紧邻键、非原画静止形

- 键位按参数比例声明（`[0, 0.25, 0.5, 1]`、非均匀分布 `sign(k)·(|k|/K)^p`），支持中间键与**紧邻键对**（`t, t+ε`，用于瞬切、阶跃、跳动）。
- 框架提供“自适应弧线插键”服务（`deformer.layering/arc-baked-keys`）：模板只给锚点键与“任意参数值下的形状函数”，框架按弧弦偏差补键、合并近共线键。因此模板接口应能返回 `S(p)`，而不只是锚点形状。
- 允许默认键几何 ≠ 原画（`effect/collapsed-rest` 塌缩静止形），允许参数默认值放在原画位置而非中点（`param.system/art-default`）。
- 受益：toggle 全部时序模板、draw-order/turn-flip、mask/chin-neck-shadow、effect/*。

### 3. 混合形状输出

- 模板可输出混合形状（mesh / warp 4.2，rotation 5.0），含：每键差量（混合形状随主轴插值，`deformer.layering/cross-parent-modifier`）、权重限制曲线（表演时压低待机层，`param.system/source-split`）、同一混合形状参数跨多个不同父级共享（`deformer.layering/cross-hierarchy-shared-blend`）。
- 框架提供“加法 warp”插入点：在指定姿态 warp 之下插一个只带混合形状、无关键形轴的 warp（`deformer.layering/pose-grid-plus-blend`）。
- 统一降级器：混合形状 → 额外关键形轴，或 → 以该参数为轴的子 warp；写损失报告（组合数增长、源不可独立驱动）。现有 `SimGenerator.usesBlendShapes` 的“乘积超过阈值才改混合形状”成为全局策略的一档。
- 通道混合形状（不透明度 / 颜色 / 绘制顺序的加法）当前未建模；`toggle/outfit-blend`、`draw-order/additive-offset` 需要它或降级到关键形轴。

### 4. 参数角色、分组、repeat 与宿主映射

- 参数角色从“眨眼 / 口型”扩展为：`tracking`、`idle`、`performance`、`physics`、`pose`、`toggle`、`variant-slot`（带符号槽）、`state`（表情状态）、`level`（绘制深度）、`phase`（循环相位）、`progress`（一次性进度）、`camera`、`derived`。角色决定参数树分组、影子参数命名 `<Unit>_<Src>`、动作生成器写哪条、宿主映射与导出行为。
- `repeat` 标志须真正建模：求值回绕、编辑器预览、导出标志，以及 5.3 以下目标的降级（线性 + 动作硬跳）。
- 宿主映射侧车（输入 → 输出范围、平滑、增益、默认值偏置、派生信号表、热键、表情 Add/Overwrite、淡入时长）作为参数角色的导出产物，编辑器能按同一张表模拟预览。

### 5. 物理组贡献

- 模板可声明物理组：输入集合**按挂载位置推导**（挂在头部子树下的物件不再接头部输入，`deformer.layering/inherit-not-reinput`）、多输出逐层缩放（`deformer.layering/nested-segment-cascade`）、左右竖直输入 reflect、输出写到混合形状参数。
- 同一物理输出可被多个模板消费（发束、发影、马尾根、阴影孪生共用同一组输出），因此物理组与其消费者分开登记，避免“谁拥有参数”冲突。

### 6. 开关组对象

- 开关组 = { 结构：默认件、替代件集合、插槽、乘积门控、带符号槽、状态真值表；时序：过渡模板及相位分段；依赖：父子开关乘积；输出：单项表情、组合表情、热键 }。
- 门控实现为组变形器不透明度（整棵子树），维度超过上限（如 6 轴）时自动分组嵌套相乘；目标不支持变形器不透明度时下推到网格并报告键数增长。
- 框架负责的检查：同组互斥、隐藏子树中含蒙版源、可拆卸组与本体之间的胶水、被遮区域底层覆盖率（只报 warning，不在像素上补）、表情只驻留在 0/1。

### 7. 结构插入点（挂载槽）

- 模板需要稳定的挂载槽名：角色根、舞台根、场景根、头根、面部角度 warp、眼开闭 warp、关节链末端、物理分段层、子树顶（过渡变形器）、姿态 warp 之下（加法 warp）。
- 插入的变形器 ID 确定（由模板 ID + 目标 ID 派生），后续批量成员可引用。

### 8. 通用复制件框架

- 把透过刘海（`SeeThroughLayers`）的复制件机制推广为通用服务：复制件记录表、在成品阶段制作、跟随原件全部编辑、点名复制件的编辑返回 `generated_copy`。
- 使用者：投影孪生、明暗版脸、变体孪生、换色替身、交接双副本、动态光泽副本。
- 区分两种胶水策略：复制件与原件之间的**全点锁定**（`mesh.glue/same-topology-lock`，阴影与明暗版需要）与“复制原件的胶水伙伴”（透过刘海禁止，避免伙伴被拉两次）。

### 9. 蒙版与目标能力门控

- 多蒙版并集、反向蒙版、隐藏但仍作蒙版的网格（蒙版不看不透明度）、蒙版引用依赖图（隐藏或删除时检查）、每网格蒙版数上限。
- 按运行时目标门控与降级：反向蒙版 4.0、混合形状与正片叠底/滤色 4.2、扩展混合形状 5.0、repeat 与部件合成 5.3。模板声明所需能力，框架选择降级路径并写损失报告。

### 10. 绘制顺序

- 静态顺序使用稀疏刻度并保留层间缝隙；组 level 参数（组内偏移固定）；绘制顺序关键形不得在两键之间跨过无关层的检查；输出“地标深度表”供动作生成器与 MCP 使用；目标支持部件级顺序时优先放在部件上。

### 11. 网格

- 模板声明部件的预期形变（类别：线条 / 五官面片 / 发束 / 刚性 / 只被搬运 / 内部弯折；绑定参数数；父 warp 单元），网格生成器据此取目标边长场；合并为单一密度表；生成关键形后可按关键形二次细化并经 `RasterMeshJournal` 迁移。
- 结构网格类型：条带、极坐标、四点贴片、约束边。

### 12. 通道关键形生成

- 生成器写不透明度、正片叠底色、滤色关键形是常态（光影、开关、特效）；生成结果覆盖与 `journalOnly` 需正确处理通道键（剥离生成轴、按通道读取），通道变化参与变化检测。

### 13. 共用几何服务

- 3D 代理：头部椭球、躯干圆柱、肢体圆柱、光向；供 `draw-order/turn-flip`、`draw-order/ring-split`、`mask/contour-cutter`、`mask/cast-shadow-twin`、`lighting/orientation-shade` 共用。
- 遮挡分析：静息姿态下某像素被哪个图层覆盖、哪个在前（投射者 / 接收者识别、长条交织段判定、发丝归属）。

### 14. 动作曲线

- 动作生成器支持锯齿、单调斜坡、阶跃、相位偏移、按确定性种子的低差异相位序列、与待机互质的周期；特效与角色待机分轨。

### 15. 质量规则

- 新增规则枚举（各自确定等级与类别）：循环首尾不一致（error）、多源幅度和超限（warning）、物理输入与层级继承双计（warning）、同一驱动写两个源（error）、门控子树含蒙版源（warning）、可拆卸组跨组胶水（warning）、底层覆盖不足（warning）、绘制顺序相等或跨无关层（warning）、单目标混合形状数超限（warning）、相机层含非刚体变形（error）、正片叠底层数过多（info）、带符号槽超过 2 槽（info）。

### 16. 确定性与重放

- 随机相位、粒子分配一律用确定性种子；复制件与插入对象 ID 确定（`<原件 ID>_<角色>`）；全部产出进入生成器依赖图，在“全部生成器之后”的覆盖合并中三方合并；模板设置变化只触发相关生成器重算。
