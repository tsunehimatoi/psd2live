# 网格拓扑与图层拆分

## 生成流程

`AdaptiveMeshGenerator` 从图层 alpha 建立轮廓。预处理先消除边缘噪点，再追踪外轮廓与孔洞；Bezier 采样决定轮廓顶点，`maxEdgeDistance` 控制其间距。偏移轮廓形成外边缘；开启双层网格时再形成内圈。窄形状可生成带状网格。

每个连通域先按轮廓约束耳切，再按所选算法放入内部点，随后进行受约束 Delaunay 翻边与过长内部边细分。轮廓边及孔洞边始终是受保护的边，最后检查边使用次数和 Euler 关系；无效结果由恢复路径处理。`interiorDensity` 控制内部的最大间距，点数受预算限制。

内部填充可选三种算法：

- **渐疏泊松填充（默认）**：根据到轮廓的距离连续增大点间距，在抖动候选格上进行确定性的可变半径泊松筛选。边缘留有较多支撑点，内部渐疏，避免成片的固定栅格痕迹。
- **自适应四叉树填充**：在方格上按轮廓距离递归细分。顶点有规则、数量可控；方格方向会在部分形状上比较明显。
- **简单三角填充**：保留原有的均匀错列三角点阵，作为兼容选项，已不是默认算法。

旧的“加密近边缘的内部点”额外采样已移除。渐疏密度由所选填充算法本身控制。

“抑制边缘点之间的跨越连线”默认关闭。轮廓上相邻顶点仍须相连，才能闭合图层边界。开启后，对非相邻轮廓顶点之间的内部对角线，算法先尝试翻成连接内部顶点的边；无法翻转的对角线在边上插入一个内部顶点。此约束只作用于单层轮廓的三角化；双层网格的内圈属于内部支撑行，允许内圈之间连接。如果约束导致平滑轮廓构网失败，同一轮廓会先以普通拓扑重试，避免退化为锯齿状像素轮廓。

## 两种拆分路径

- **导入时自动拆分**：`ComponentSplitter` 根据生成网格的连通域识别双侧部件，并在可水平分离时按两域之间的轴线分配像素；其他情况按最近网格顶点分配。它产生用于分析的虚拟部件。
- **编辑器“按网格拆分”**：`MeshComponentSplit` 用当前屏幕网格的三角形连通关系确定部件。若各网格岛在 X 或 Y 轴上可分开，直接按岛间分界线分配源像素；否则先用实际三角形覆盖区域标记归属，再扩散到抗锯齿边缘和未覆盖像素。生成的部件会保存为独立图层，随后重新生成各自的网格。

编辑器拆分保留所有非透明源像素，避免把相邻图层的边缘像素分错。已经保存的拆分图层拥有独立像素数据，修改算法后需要从原图层重新拆分才能更新其归属。

## 设置流向

模型设置中的填充算法和拓扑开关可用于全局默认值，也可在部件的网格详细设置中覆盖。它们随项目状态和 Agent 工作区保存；更改会使相关网格缓存失效并重建预览。`AdaptiveMeshTopologyTest` 检查三种填充、拓扑开关、鞋子轮廓，以及 `ds.psd` 两只鞋的拆分归属。
