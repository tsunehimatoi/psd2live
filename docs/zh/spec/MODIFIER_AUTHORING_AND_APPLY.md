# 修改器与手工编辑共存

## 目标与边界

普通修形应当与修改器共存，不要求用户先应用修改器。确实需要脱离生成逻辑时，提供可检查范围、可撤销的应用操作；不能隐式固化，也不能静默丢弃手工修改。对象父子关系、修改器求值依赖和插件包依赖分别处理。

笔刷只是产生几何编辑的一种工具。顶点拖动、变换框、临时变形器、路径和控制柄、数值输入、关键形操作以及 Agent 命令应遵守同一编辑契约。交互工具负责采样，模型层负责准备关键形、归属、重放和依赖验证。骨骼姿态工具的输出就是参数值，不属于固定参数后修改几何的操作。

## 编辑契约

一次编辑固定文档版本、目标、姿态、通道、执行阶段和合并方式。显示、拾取、吸附、预览和提交使用相同阶段的模型与坐标。文档在编辑中变化时取消或拒绝提交；提交失败不产生部分模型或历史记录。

非关键值编辑默认保持当前参数值，从插值结果准备所需关键形。用户可显式选择最近共同关键形：多对象按参数求关键值交集，一次选取最近值；交集为空时阻止吸附并说明原因，不能逐对象反复切换参数。手势从开始到异步提交结束或取消期间保持姿态及合并方式。

`edit_stage` 指定修正位置：

| 值 | 源模型与执行位置 |
| --- | --- |
| `auto` | 当前最终模型，按通道实际写入者自动归属 |
| `base` | 修改器之前的作者模型 |
| `modifier:<id>` | 指定有效修改器之后 |
| `final` | 本次编辑时最后一个有效修改器之后；没有有效节点时为基础 |

显式阶段目前接受几何和关键形值，不接受拓扑操作。一个事务不得混合阶段，也不得引用该阶段尚不存在的参数。停用、失败节点不可作为编辑源。`final` 在开始编辑时解析为具体位置，后续新增修改器不会搬移旧修正。

## 修正的归属与合并

归属报告记录对象和已有关键形的实际改写，同一通道按最后写入者归属，不能只根据对象创建者或新增轴判断。基础编辑在生成前执行；局部修正放在相关生成结果之后；最终外观修正由作者显式选择。

`correction_mode` 选择几何合并方式：

- `delta`：网格与 Warp 保存编辑前后局部坐标之差。每次生成后重放一次，再运行下游，不累计上次重算的位移。
- `absolute`：保存明确的固定覆盖；未触碰分量跟随生成结果。发生三方冲突时保留作者值并报告冲突。

显式关键形 API 未指定模式时保留固定覆盖语义；画布按工具栏选择提交。未记录模式的旧覆盖保留历史三方合并规则，不自动迁移为增量。

旋转修正的枢轴与角度采用局部增量，正缩放采用比例；显式赋值使用固定覆盖。颜色、透明度等通道保持明确的设置语义，不强制相加。

几何修正记录绑定指纹：网格顶点数、连接关系、UV 和父级链；Warp 的格点行列、插值方式和父级链。绑定变化后保留记录并报告失配，不继续套用。当前采用保守检查，UV 重排也可能要求处理修正；不自动迁移拓扑。

算法写入与作者修正分别记录。算法之间继续检查写入可组合性；作者修正按照指定阶段重放，不能把挂在动作节点之后的几何修正误算成动作算法生成几何。缓存复用和固化重放使用相同的算法写入记录。

## 应用机制

`modifier_apply_plan` 是只读范围规划，GUI 与命令共用。应用前展示固化、停用和保留项，修正数量、固定覆盖冲突、失配记录及跨边界依赖；应用后仍须重新求值并比较完整结果。

| 范围 | 行为 |
| --- | --- |
| `selected` | 把所选节点固化在原求值位置，保留前后节点 |
| `prefix` | 将截至所选节点的前缀等价写入基础，保留后缀 |

对 `A → B → C`，不能把 `B(A(基础))` 作为新基础后继续运行 A。单项应用保存原节点的前后输出、能力契约、实际输入读取和算法写入；不再执行原算法。固化节点的配置、位置和启停状态不再作为生成控制项，作者编辑其持久输出。

应用包含完整结果校验，不能只比较当前画面。启用项的失配修正和失败依赖阻止应用；固定覆盖冲突保留当前作者值并提示。停用项的作者记录保持休眠；继续应用前缀时，停用动作和物理组仍可重新启用。

插件身份继续保存在历史归档中。固化节点运行时不需要查找原插件包；旧前缀能力记录若缺少 `provides` 契约，保留兼容查询。输入契约不兼容时拒绝上游改动，提示处理前置依赖；不能用失效输出替代固化内容。

## 上下游依赖与内容编辑

规划检查配置能力、显式参数提供者、手工结构引用和动作输入的跨边界依赖。作者修正还根据关键参数与目标对象查找前序实际贡献者；固化节点保存被替换或移除对象的输入身份，继续显示相应依赖。共享父级、参数、轨道和模拟输入必须纳入范围判断；模拟输入身份改变时需要重新烘焙。

已知依赖可以由固化契约满足时，保留下游。无法保留完整契约时，应扩大应用范围或拒绝操作并解释原因。当前提供单项和前缀两种范围，尚无完整的自动最小依赖闭包选择。插件未声明的隐式读取不能仅凭规划认定安全，最终重建验证始终保留。

动作的作者记录独立于冻结配置。内置动作沿用原记录；其他插件按实际新增或修改的 Clip 建立作者记录，一个节点可以持有多个动作。原始 Clip 单独保存，停用不丢弃其曲线、淡入淡出、事件或非参数轨道；编辑时只替换作者修改的字段。通用记录、前缀应用和磁盘保存路径的定向回归已通过。重命名、曲线编辑、启停、删除更新持久 Clip；复制固化动作将副本保留在原阶段，完整前缀应用后转为普通内容，复制时保留原始通道；未修改曲线保留原表示。曲线只能引用原节点位置已有的参数，停用记录也检查此约束。继续应用前缀采用编辑后的记录和原始轨道。普通动作的参数、部件改名同步更新原始引用；删除记录一并移除原始数据。工作区 clips 节点使用新的 schema，模型对象二进制使用版本 7 保存事件、非参数轨道和逐轨道淡入淡出，同时保留版本 4–6 的读取兼容。不含这些新增字段的对象和整包辅助资源继续写为版本 6，使已有 worker 仍能读取；宿主读取版本 6 和 7 的整包资源，不能通过降级丢弃新字段。宿主管理的 SDK 在构建前刷新实际序列化模块，指定的外部 SDK 不自动覆盖。

固化物理组接入普通调参、启停、拟合、删除和导入。同 ID 导入修改固化组；新组占用相同输出时按导入规则停用冲突组。内置摆动物理算法读取其他组仅用于冲突检查，固化后改为重新验证 ID 与输出冲突，不锁死整个物理列表或 FPS；其他插件仍保留原读取契约。

普通候选、设置修改和批量命令产生新的修改器执行失败时，拒绝提交部分结果。未改变的已有失败不阻止无关编辑；预设初始化仍可记录其显式隔离失败。主动停用提供者导致的下游依赖停用保持可恢复状态，不当作算法执行错误。删除或停用固化内容的结构提供者、删除固化动作的输入参数时，验证下游输出契约；不兼容则整笔拒绝，模型和历史保持不变。

## 实现与验收状态

主要入口为 `GeometryEditStages`、`GeneratedOverrides`、`RotationCorrections`、`JournalRecording`、`RigModifierEvaluator`、`AppliedModifierNode`、`ModifierApplyPlan` 和 `WorkspaceDocumentCommands`。画布通过共同提交路径传递阶段与合并方式。

已有通过的定向回归证据：

- 增量重放不累积、固定覆盖、拓扑失配、中间关键值插入、共同关键值与已有关键形实际写入归属。
- 直接几何、笔划、Bezier 和旋转修正；阶段源与拾取目标关键轴一致。
- 顶点在中间参数值开始后实际拖动，参数保持不变；取消或移回起点释放后恢复原几何并解除锁定。
- 单项应用保持非交换操作顺序，最终阶段修正可原位固化；原插件缺失时仍可重放。
- 固化动作及物理编辑、停用内容继续应用后的恢复、物理导入替换与冲突停用。
- 普通编辑遇到新的修改器执行失败时，不发布候选模型或历史。
- 历史往返、工作区落盘重读、CMO3 序列化回读及端点和中间姿态比较。

主模块与格式模块最终完整回归已通过（命令 `./gradlew.bat :format-compile:test :test --console=plain`；日志 `build/modifier-authoring-final-tests-3.log`，2 分 18 秒）。主模块报告 1228 项，其中 1087 项通过、141 项跳过、0 失败；格式模块 5 项通过。覆盖旧项目修订身份、旧格式读取、插件开发闭环、动作原始数据保存、失效补偿的原子拒绝，以及路径、Bezier 控制柄和骨骼姿态交互。跳过项不计作通过。这些是合成数据的验证，不代表 issue #81 的原始操作录像已复现。

统一编辑入口的验收覆盖顶点、变换框、临时 Warp、路径和 Bezier 控制柄的姿态保持与取消；真实工作区顶点拖动覆盖异步提交、撤销重做、提交后解锁。骨骼姿态验证参数能够随拖动变化，不获取几何姿态锁。

保持子级外观会重新计算父级修正下的直接子级补偿。子级尚未绑定当前参数时准备所需关键形；独立参数的中间值按实际变形误差自适应细分，最多 8 轮、每轮最多 16384 个采样姿态，不能收敛则整笔拒绝。已验证 31 个独立参数采样值、重新生成、失配和固化。该采样检查不能证明任意复杂层级上的连续误差上界。

依赖和复杂层级补充验收已通过（`modifier-authoring-tests-35.log`）：删除或停用固化内容的提供者、删除固化动作的输入参数会拒绝整笔编辑且不改历史；应用完整前缀可以保留结果并解除生成依赖。共享父级、嵌套旋转和混合变形的平移保持外观；非线性组合若无法表示相同的深层网格位置，则明确拒绝。校验覆盖子级关键值、混合变形关键值及限制点和其中点；上限之外不静默近似。

最后的动作复制兼容修正已通过完整回归：固化副本位于原阶段，普通副本保留自动生成导出文件名的既有行为；两种复制均保留原始曲线、事件和非参数轨道。上述交付范围验收完成。
