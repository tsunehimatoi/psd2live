本文件保留原路径以兼容链接，内容改为当前实现参考。绘画已经有可用的独立会话，不再把基础工具列为待实施 PRD。

## 用户流程

选择图层 → 绘画模式 → 画笔 / 铅笔 / 橡皮 / 填充 / 吸管 / 形状 → 会话内撤销重做 → 应用或放弃 → 检查模型并保存工程。

像素绘制在文档画布栅格上，不受旧网格边界限制；但保留旧网格时，超出网格覆盖的新像素不会自然变成可渲染区域。应用时可选择保留或重建网格。

## 组件分工

| 组件 | 职责 |
| --- | --- |
| `CanvasEditor` | 会话启动、工具交互、提交、素材 / 网格 / UV 更新 |
| `PaintSession` | 画布尺寸工作图、独立笔画历史、应用前状态 |
| `PixelPatch` | 记录受影响的 64×64 像素瓦片，恢复或交换以撤销 / 重做 |
| `LayerPaintEngine` | 绘画、擦除、填充等栅格操作 |
| `PaintShape` | 形状工具相关定义 |

会话所有像素修改应走 `edit` / `willWrite` 等记录入口；绕过它会破坏撤销和增量预览。单笔的覆盖取经过区域的最大值，再乘不透明度，避免同一笔反复经过时不断加深。橡皮使用覆盖去除 Alpha。

## 坐标与提交

指针先转换到文档画布坐标；画笔使用浮点位置，采样类工具再按像素读取。预览按受影响区域发布，不必每次复制整张画布。

应用时扫描非透明包围盒、裁切源层并更新贴图集。保留网格时按画布位置重新计算 UV；重建时沿用当前 Rig 的原有父级坐标框架，避免绘画后包围盒改变导致父级下的形状被重新缩放。完全擦空的图层使用空透明栅格处理。

成功应用进入工程保存 / 历史链路。独立绘画撤销和工程分支撤销是两个层次，界面与文档应明确当前操作的对象。

## 需要验证的场景

- 半透明笔画往返、自交和橡皮：实时显示与松手结果一致。
- 多次撤销重做：像素和预览同步恢复。
- 修色且保留网格：纹理不漂移。
- 扩大轮廓后重建：父级变形器和已有姿态关系没有意外变化。
- 保存重开、历史恢复和导出：源像素与 UV 仍对应。

压感、防抖、绘画专用选区、草稿图层和对称绘制等方向应单独实现与验收，不能因为模型支持混合模式就声称绘画工具已具备完整图像编辑器能力。
