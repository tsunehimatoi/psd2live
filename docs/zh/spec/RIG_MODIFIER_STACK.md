# 模型预设修改器栈

## 当前实现状态

本页记录重构中的内部接口。已实现有序求值核心、部分算法适配、工程修订、保存恢复、预览／导出、原子工作区命令和 MCP 进程任务；基础绑定已接入静止结构、六类旧算法、眼／眉／嘴的拟合算法和头发链，附加模块已接入笑眼、虹膜压缩、睁大、眼睑线淡出、高光视差、视线眼睑、眼部情绪、眉形、眉毛回弹、眨眼余震、眨眼随动、眉眼耦合、元音口型、嘴眼耦合、口型捕捉、伸舌、下颌随动、口腔纵深、嘴部回弹、脸红、阴沉、皮肤裁切、颈部联动、头脸纵深转动、胸部随动、手臂滞后、裙摆、飘带与饰坠、兽耳／尾／翼链、眼部和眉部刘海透视、开关编排与嘴部轮廓。**其余附加模块与快捷预设、旧工程转换及 GUI 的其余配置入口尚未完成**，显式栈工程已有基础面板，仍不能把它当作已经完成的完整用户功能。没有显式修改器栈的旧工程仍走原路径。

`core/modifier` 提供以下基础：

- `RigModifierStack`：有序实例、版本、固定目标引用、预设组来源、覆盖、已应用能力、退休 ID 与单调 ID 分配器；严格 JSON 编解码。
- `RigModifierRegistry`：按类型与算法版本查找定义，检查未知依赖、重复版本和依赖环。
- `RigModifierEvaluator`：在中立 `RigIR` 上依次求值，检查目标、顺序、互斥算法、共享参数定义和写入冲突；输出实际贡献。
- `RigModifierAlgorithms`：适配现有摆动、已烘焙模拟、物理组与动作片段，不改动这些算法的运动设计。
- `RigSourceModifiers` / `RigLegacyBindings` / `RigSourceBinding`：`rig.scaffold` 从捕获的源图生成静止绑定结构；`body/legacy`、`face/legacy`、`eye/legacy`、`brow/legacy`、`mouth/legacy`、`hair/legacy` 追加各自的原算法；`eye/fitted`（版本 2）、`brow/fitted`、`mouth/fitted` 使用原拟合算法，`hair/chains` 使用原分段链，眼部的 `eye.smile`、`eye.squash`、`eye.wide`、`eye.lid-fade`、`eye.highlight`、`eye.aftershock`、`eye.gaze-lid`、`eye.emotion`，眉部的 `brow.shape`、`brow.spring`、`brow.blink`、`brow.lid-coupling`，以及嘴部的 `mouth.vowel`、`mouth.cheek-lid`、`mouth.capture`、`mouth.tongue`、`mouth.jaw`、`mouth.interior-depth`、`mouth.spring` 及 `expression.cheek`／`expression.gloom`、`face.skin-clip`／`face.neck`／`face.depth-turn`、`body.bust`／`body.arms`、`outfit.skirt`／`outfit.ribbons`／`outfit.creature` 追加各自的原模块绑定。拟合与模块的可调值存在实例的 `values`，范围来自原目录。身体和头脸的强度、各部位高级数值（`tuning`）存于实例，不读取旧全局绑定强度或数值。目标网格保留原拓扑和作者编辑，上游作者变形器继续生效。结构分支 ID 由结构实例与固定目标确定，不按当前父级重新分组；新增参数文件夹也按实例分配 ID，兼容标准参数和参数配对可复用。共用同一源图的作者副本仍可分别接受不同实例。
- `RigModifierPipeline`：从普通素材网格与作者日志构建输入，按实例顺序运行生成器；预览模型与导出 IR 共用求值结果，并附带每项实际贡献报告。空栈不隐式生成绑定、物理或动作；已有普通参数的名字也不会重新触发预设物理。
- `WorkspaceModifierEdits`：添加单项／组、更新、启停、移除、移动和应用前缀共用纯候选；通过 `WorkspaceDocumentCommands` 进入隔离重建、CAS 和单历史节点提交。显式实例 ID 可供同一批量的后续成员引用。添加可指定从 0 开始的 `index`；省略时追加，用于在缺失依赖的消费者之前显式插入提供者，既有项不自动重排。
- 添加预览复用 `workspace_preview_regeneration` 的只读后台候选：`modifiers` 返回候选栈的实际贡献、依赖状态与覆盖冲突，不发布文档、历史或模型；使用同一输入状态和请求提交时，实例分配及候选修订保持一致。
- `modifier_catalog` / `modifier_stack`：目录与捕获版本的配置、状态和实际贡献；模拟只返回烘焙摘要。全部修改器操作声明严格结果及任务 schema，在 CORE MCP 的 `modifier` 族、FULL 操作和 `workspace_call` 中均可调用。

`ModelPresetsSection` 在显式栈工程中显示修改器面板，旧工程继续显示原面板。实例标题包含部位与算法，显示固定目标及生效、禁用、依赖缺失状态；可展开贡献、数值和固定提供者，启停、移除、应用前缀及拖动排序共用应用层命令。连续数值操作保留本地字段草稿，仅在手势／字段结束时提交一次，并校验捕获状态；失败还原显示值。贡献按类型折叠，新增对象的名称也进入报告，添加前不会显示编码后的内部对象 ID。

添加源图绑定使用 `modifier_plan`：固定目标、递归列出所需提供者、复用当前有效或已固化的提供者，并为新增项预分配稳定身份。`fitted` 组组合六类基础绑定，各项独立；它不是全部旧快捷预设的替代。计划本身不提交文档，确认前用现有只读候选求值展示实际贡献，确认后只提交一个组操作。对话框的选择变化不改变已捕获目标，提交仍受同一状态 CAS 约束。该添加入口支持已注册源图绑定及原生摆动、物理、模拟和动作的创建与数值编辑；模拟已接入具名权重组、碰撞体、混合形输出模式和静态输入轴配置；训练片段引用上游动作，缺失时暂停求值，非法排序会被拒绝。

实例状态存于 `RigEditOverlay.modifierStack`，缺省为 `null`，与显式空栈有别。该字段参与工作区修订身份；缺省值从旧文档的修订文本中省略，保持既有修订 ID。工作存储与归档保存完整实例、顺序、版本、配置、休眠覆盖和退休身份。转换捕获的层级、参数文件夹、物理组与动作在实例的 outputAliases 中保存原输出 ID，后续更新不可改写；新实例使用自己的身份，不继承已移除项的别名。空别名字段不参与旧实例的序列化。包含它的 v2 rig 节点使用 schema 6；旧字段继续使用原 schema。

目前栈工程不走旧的生成输入合并与作者态缓存捷径，而由权威源图、作者日志和完整栈重建，避免排序被错误固化或缓存掉。后续性能优化必须保持同一求值结果。旧工程尚未转换时继续保留原生成流程；栈工程的旧预设设置写入会被拒绝并指向修改器操作。

源图适配器按固定目标收集该项之前的有效基础算法及已应用能力，计算加入前后的原算法差异，然后合并到实际上游几何、通道和关系。局部网格修正使用各自的静止祖先投影，避免重复计算祖先运动；拟合改变中性父坐标时，先使用普通 DCC 重绑定原语迁移作者几何，保持画布位置。源图模板只纳入依赖已满足的前驱，暂停的模块不会被下游另一部位重新启用；启用模块也不触发任何未添加的相邻模块。只在同一隔离候选内缓存纯源图模板和参数定义，不缓存最终栈结果；作者编辑、摆动等非模板内容仍来自实际输入。已应用能力保存后续绑定求值所需的源图算法版本、身份、输出别名和配置；不复制模拟烘焙等无此依赖需求的大数据。

网格和 Warp 的独立混合形以实际默认关键形为参考，合并作者贡献与加入该模块前后的原生贡献差异；保留参数、键、零贡献位置与权重限制曲线，不把它们铺成所有参数组合的关键形。网格拓扑通过原素材映射迁移；默认几何与通道变化后重新表达混合形参考值。源图求值出现新增承载 Warp 时，由首次创建它的持久实例分配输出 ID，后续更新及前置项固化不重新命名。作者在网格与原父级之间添加的 Warp 继续保留；坐标转换仅逆求共同锚点之下的作者路径，避免域外拟合祖先造成多解。当前适配范围是原算法在原路径之下追加的承载结构；替换或改排原路径的基础算法仍需独立适配。

## 求值与应用

求值输入是普通作者内容和栈快照。适配器接收前一项的实际结果，必须是纯函数，并在昂贵工作中调用传入的取消检查。求值器不保存工程、不提交历史、不访问 UI；宿主在隔离候选上调用，再经过工作区 CAS 提交一次完整终态。

禁用项不求值。依赖能力必须覆盖全部目标；缺失时保留该项并暂停求值，其下游同样暂停。启用的依赖若只在消费者之后出现，则拒绝该顺序，不自动排序。基础算法可声明同目标互斥族。依赖还可固定到具体提供者身份：绑定实例的 `scaffold` 配置引用对应结构实例，模块的 `base` 配置固定引用所属部位的基础实例，眉眼和嘴眼耦合还通过 `dependencies` 固定引用 `eye/fitted` 实例；另建同类型结构或基础绑定不会静默替代它们。应用前缀后，已应用能力保留该身份，下游仍可定位已固化的普通对象。

栈作者态通过独立普通素材入口构建，在作者日志之前清除旧生成器隐式附带的标准参数、语义分组、关键形与语义蒙版。保留源图文件夹和原始剪贴关系；作者日志或固化点随后恢复显式作者内容。导入的 CMO3 作者内容不走这一步清理。

参数的范围、默认值、种类、循环属性与键定义相容时可以共享。实际贡献区分新增、修改、移除和复用。同一对象的写入默认不允许跨修改器重叠；两方适配器都明确声明该种内容可组合时才允许。

覆盖按实例归属，在该实例生成后重放。禁用和移除不丢弃覆盖；移除的实例 ID 永久退休，新建实例不继承其覆盖。没有覆盖重放器时，非空覆盖明确失败，不静默忽略。

已接入生成关键形的编辑捕获：求值报告记录实际新增的网格／Warp 几何轴和通道轴，`DocumentGenerators` 从捕获版本的报告建立拥有关系，现有关键形与画布编辑通过原三方合并记录为实例覆盖。默认值处的生成关键形也归实例；组合多个修改器的关键形在最后提供其参数轴的项之后合并，确保所有坐标维度已经存在。生成的包裹 Warp 的静止关键形也归该实例。覆盖不混入先于栈重放的作者日志。报告的 `owned_keyforms` 提供对象、参数与可选 `channel` 引用，`override_issues` 区分合并冲突和无法匹配的覆盖；无法匹配的记录继续保留，并阻止前缀固化。这里尚不涵盖生成参数定义、对象结构、旋转几何和所有混合形编辑。

“应用截至此处”先求值完整栈，再求值前缀，把前缀有效内容及覆盖变成普通作者内容。前缀中禁用项一起移除但不产生内容，其未应用的覆盖仍休眠保存；缺失依赖的前缀不能应用。下游保留原实例和输出 ID，通过已应用能力继续识别前置内容。再次求值下游与完整原结果必须完全相等，否则拒绝候选。

工作区应用命令把几何与关键形写入标准作者态固化点，把前缀生成的物理组和动作追加为普通文档内容，再从候选文档冷重建并比较完整 IR，之后才交给工作区提交。已应用动作的 `MotionClip.fileStem` 独立于显示名，存为 `file`；带该字段的 clips 节点使用 schema 6。普通替换操作保留文件名，新建副本分配自己的文件名，旧片段缺省字段不改变原有修订身份。

模拟适配要求已有有效且与输入匹配的烘焙，保留多键绑定，不固化当前预览帧。物理组和动作作为 `RigIR` 的普通侧车内容进入应用结果；经过 Puppet 转换的生成器保留这些侧车。

## 已有测试覆盖

`RigModifierStackTest` 验证顺序敏感的组合、独立目标、依赖链、互斥、写入冲突、稳定身份、休眠覆盖、应用前缀、序列化和取消。`RigModifierAlgorithmsTest` 验证真实生成器适配、侧车保留、物理配置导出读回、动作事件，以及模拟烘焙有效性和应用后绑定一致性。

`RigModifierPersistenceTest` 验证工作存储与 `.psd2live` 归档保存重开、历史修订身份和 v2 节点拆分／拼回。`RigModifierPipelineTest` 验证空栈、普通参数不触发隐式预设、工作区预览、冷重建、模型重建、启停后的刷新，以及运行时物理与动作文件读回。

`WorkspaceModifierCommandsTest` 通过真实工作区事务验证组、批量引用、撤销重做、状态冲突、取消、前缀应用及普通内容后续编辑，也验证生成关键形覆盖的休眠、恢复、身份隔离、冲突合并、无法匹配时的保留与拒绝固化，以及生成包裹 Warp 的静止关键形。修改器组的添加预览验证实际贡献与提交一致、自动实例身份稳定、候选不发布以及过期状态拒绝。`WorkspaceModifierSchemasTest` 验证各原生配置的严格 schema、批量成员移除上下文字段，以及 CORE MCP 族和任务契约。`AppliedMotionFileTest` 验证应用后动作的文件身份、存储版本，以及名字和事件中含字段形似文本时的旧修订身份兼容性。

源图适配的工作区回归比较原身体算法的单轴与组合姿态，检查多目标实例、参数复用、固定依赖身份、非法移动与修复缺失依赖；静止结构或身体项固化后须能冷重建。身体绑定与摆动互换顺序的测试比较 CPU 求值后的实际几何，避免仅重排面板。普通素材回归检查空栈不携带标准参数和语义分组，原始文件夹与剪贴关系保持，语义标签不会隐式创建蒙版。

`WorkspaceLegacyBindingTest` 用程序绘制的小型素材比较六类旧绑定组合后的实际几何、透明度、绘制顺序、蒙版与参数配对；覆盖不同顺序的前缀固化与冷重建、闭口默认关键形和默认睁眼透明度的实例覆盖，以及共用源图的两个对象各自绑定与固化。拟合眼／眉／嘴以及已接入的眼、眉、嘴模块组合，同原算法逐项对比动态姿态，验证版本选择、实例数值、同目标基础互斥、依赖暂停与恢复、非法排序和前置项固化后继续求值。插入前置项另验证失败不发布、保持既有顺序、冷重建与单步撤销。

组合模块回归还在已固化结构下添加普通作者 Warp，确认真实新增的承载 Warp 保留它；比较组合姿态、前缀固化与冷重建，并通过 CMO3 导出读回比较实际几何与透明度。

CMO3 导出在把基础网格改写到画布空间前，为没有自身几何关键形的变形器子对象补齐零轴静止形，保留其原父级坐标；无需新增参数。否则只依赖父级运动的普通素材或已固化内容在读回时会再次受到父级坐标变换。

`ModifierStackTool` 使用程序生成素材打开真实桌面工作区，通过实际指针事件拖动排序及调节数值、预览并确认添加。排序结果与同状态的 MCP 候选修订一致，并验证组合姿态改变；数值拖动的中间帧不发布历史，结束后只追加一个节点。工具覆盖全部内置主题、四种语言、1×／1.5× 界面缩放与 1.1× 字体，生成面板、展开项和添加预览截图，以及排序录制帧。新界面尚未覆盖全部原生配置和迁移入口，不能代替最终完整验收。

原生添加计划覆盖摆动、物理组、模拟与生成动作；原生配置使用同一严格 schema，动作可选择现有预设算法。物理默认值不创建隐藏参数，先检查可用输入／输出。添加对话框与持久项共用原生配置控件；预添加数值只触发隔离预览，失败候选保留配置以便修正。GUI 工具验证四类原生添加修订与候选一致，并验证添加前摆动拖动不改变文档状态。
