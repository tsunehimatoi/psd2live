# 按纹理结构重布点

[文档目录](../../README.md) · [内部造型](INTERIOR_SURFACE.md) · [网格拓扑与拆分](MESH_TOPOLOGY_AND_SPLIT.md)

## 范围

`layer_mesh_structure` 在一个已有网格上保留外轮廓行与边缘带，按纹理里画出的结构重建内侧：褶皱、明暗分界与图案线条成为顶点行，边沿线走。默认除边缘行与这些线外不放任何顶点，三角形在线与线、线与边缘之间张开，与布点的做法一致；`fill` 另在线间加渐变填充点，`bands` 在画出的褶皱线两侧各加一行并连横档，使网格能沿线折起。普通网格与内部造型共用这条命令。只读像素，不改像素；识别结果只决定拓扑，是否参与造型由作者把线标为褶皱（`FOLD`）决定。

代码：`core/mesh/structure/TextureStructure.kt`（识别）、`StructureMesher.kt`（保留外圈与拓扑）、`core/mesh/ConstrainedTriangulator.kt`（约束三角化）、`application/WorkspaceStructureMeshEdits.kt`（命令与预览）。

## 识别

在图层源栅格上进行，最长边超过 1024 时按整数倍盒式降采样。全过程确定，无随机数，各阶段检查取消。

1. **通道**：像素转线性 RGB 再转 OKLab；alpha ≥ 0.5 为材质。材质外的像素用材质内的归一化高斯卷积填充，轮廓不会被当作明暗台阶。若给了重建区域（保留外圈的内环），只在区域内取响应。
2. **三种响应**（暗线与台阶取尺度 σ = 1、2、4、8 工作像素，最宽一档对应以柔和明暗画出的褶皱；颜色边取 σ = 1、2；单位都折算为 OKLab 亮度台阶）：
   - **暗线**：Hessian 较大特征值减去较小特征值的绝对值，再减去 1.2 倍梯度。明暗台阶两侧的谷形旁瓣因此抵消，线中心的梯度为零不受影响。取最强尺度作为线宽估计。
   - **明暗台阶**：高斯梯度幅值，减去附近暗线响应的 1.2 倍，以消去线条两侧的梯度旁瓣。
   - **颜色边**：OKLab a/b 的 Di Zenzo 多通道梯度；台阶同时变色时归为颜色边。
3. **门控**：结构张量相干度（ρ = 3）低于 0.12 时清零，0.45 以上全通，噪点、网点与颗粒由此去除。响应再按局部亮度标准差（σ = 12）缩放 0.6–2.5 倍：暗布上的淡褶与亮布上的重线同等对待，颗粒不会被无限放大。每个尺度只在距材质边缘大于 2σ+1 的像素取响应。
4. **细化与连线**：沿法向做非极大值抑制，双阈值滞后（高阈值随灵敏度在 0.22–0.05 之间，低阈值为其一半），再用 Zhang–Suen 细化，按 m 邻接追踪成链。交叉点处方向相对（夹角在 35° 内）的两段接成一条线穿过，余下的分支作为 T 形接入；自由端之间沿切向 30° 锥内、距离不超过 4 倍线宽的断口按代价贪心接上。
5. **分类**：
   - 颜色边为 `PATTERN`；明暗台阶为 `SHADE`。
   - 暗线须有褶皱留下的证据才判为 `FOLD`：端部变淡变细（端部 15% 的线深低于中段的 55%），或一侧稳定偏暗（≥75% 的点同号，均差大于 0.04）。以下情况不判为褶皱：两侧颜色差得像两种材料（亮度差中位数大于 0.2，或色相差中位数大于 0.05，即缝线与部件边）；总转角超过 120°（布上图形的外框）；与轮廓等距平行（饰边）；闭合；三条及以上近平行、长度相近、等间距且不变细（印花）。这些都归为 `PATTERN`。
   - **阴影楔**：明暗分界在转角大于 100° 处断开，或两条分界的端点相距很近，且从端点出发的方向夹角小于 40° 时，视为一处褶皱阴影的两边。按与尖端等距的点对取中点得到楔的轴线，楔继续张开、两边未转向（偏离初始方向不超过 35°），且楔内亮度与两侧都不同时，轴线作为 `FOLD`（不加带）。被轴线覆盖的尖端短线丢弃。
   - 强度为平均响应乘以长度因子，按强度保留前 `max_lines` 条，并丢弃短于 `min_length` 的线。

## 保留外圈

在源像素坐标中从现有网格的拓扑推出：边界边只属一个三角形，从边界顶点做图距离 BFS。保留行数取图层网格设置的边缘模式（SINGLE 0、DOUBLE 1、TRIPLE 2）。三个顶点都在保留行内的三角形原样保留，其余三角形按共享边分成连通区域。每个区域的边界顶点由保留顶点组成，按面积最大者为外环、其余为孔。出现夹点（一个顶点有多条出边）的区域放弃重建、原样保留。区域间距取该区域内侧边（两端都不在环上）长度的中位数。

## 拓扑

线上间距为保留边缘行的点距乘以 `near_density`（默认 1），填充的远处边长为该区域原内侧边长乘以 `far_density`。每个区域独立构建并依次退化：带褶皱带（仅 `bands`）→ 只放单行 → 不放线，取第一个能三角化的结果。

- **放线**：按强度从高到低。每条线在区域内以 1/4 近距细采样，离区域边界的距离须大于 0.7 倍近距加带宽，离已放下的线的距离须大于 0.75 倍近距加带宽，不满足处断开。较弱的线在较强的线前停下，不与之相交，交叉处留出的空隙由填充补上。剩下的段按近距重采样成站点。
- **褶皱带**：`FOLD` 且本身是笔画的线（`banded`）在内侧站点两侧各放一行，偏移为 1.5 倍线宽，限制在近距的 0.35–0.8 倍之间。首末站点不加侧点，带在两端收成尖。约束边包括中线、两侧行、每个站点的横档，以及每格同向的对角线。因此每格的两个三角形是确定的，跨褶皱的边垂直于线。侧点出界或离他线过近时，该线只放单行。
- **填充**（仅 `fill`）：目标边长由到线的距离决定，在近距与远距之间平滑过渡（过渡长度为 2.5 倍远距）。候选点取半个近距的格点，加哈希抖动，按离线远近和哈希排序；离已选点、线与环的距离都够时才保留。
- **三角化**：先 Bowyer–Watson 增量构建。插入点看不见空腔边（共线的边界点）时，把对侧三角形并入空腔。然后按 Sloan 翻边恢复全部环边与约束边，删去域外三角形，对非约束边做 Lawson 合法化，有填充时最后按 1.5 倍目标边长对过长的自由内边做中点细分；不填充时不加任何点。
- **拼合与校验**：保留三角形与新三角形共用环上的旧顶点；旧顶点排在前面，序号按旧顺序。之后校验：无退化三角形，每条边最多被两个三角形使用，Euler 特征数与原网格相同，绕向与原网格多数三角形一致，顶点数不超过 `max_vertices`。任何一步失败都报错，不提交。

新顶点的网格局部坐标与 UV 取自它落入的旧三角形（源像素坐标中的重心坐标）。映射在每个三角形内是仿射的，重建前后画面不动。

## 命令与持久化

- `layer_mesh_structure`：先算出新网格，再用 `RasterMeshJournal.encode` 写一条 `canvas_mesh_rebuild` 日志。关键形、混合形、路径、顶点组与 Glue 按普通重建迁移；重放不再分析像素，结果只取决于日志。
- 目标网格有内部造型时，该命令把配方中检测出的 `TOPOLOGY` 引导线替换为新识别的线：绘制的引导线和已标为 `FOLD` 的检测线保留，并作为最强的线引导布点；与它们重合的新线不再加入。共享的纯候选编辑先重放网格替换，再在新网格上重新烘焙配方；单项 MCP、界面与 `workspace_apply_edits` 的批量成员执行相同逻辑，只写一个历史节点，任一步失败都不发布候选。
- 引导线新增可选字段 `detected`（`FOLD` / `SHADE` / `PATTERN`），只写在检测出的线上，旧工程的修订号不变。
- `layer_mesh_structure_preview` 从捕获版本计算同样的结果，不写任何东西。它返回识别线（源像素与画布坐标、类型、是否被网格采用、是否加带）和新网格的画布点与三角形，供界面叠加与 MCP 检查。

## 界面

网格面板与内部造型卡片（修改器栈中）的“内部网格”节共用 `StructureMeshControls`：灵敏度、线上间距、“线间填充”（打开后出现填充间距）与“褶皱带”开关、跟随的线类型、“显示线条”和“重布点”。显示线条时，画布用 `StructureLook` 的固定色调绘制预览：褶皱暖色（加带的更粗），阴影冷色，图案淡紫，未采用的线变淡；新网格以淡色线框显示。预览不进历史。内部造型面板在“内部网格”节列出检测线，可逐条标为褶皱并调强度；“局部褶皱”节只列手绘引导线。

## 验证与限制

```bash
./gradlew test --tests "*ConstrainedTriangulatorTest" --tests "*TextureStructureTest" --tests "*StructureMesherTest" --tests "*StructureMeshCommandTest"
PSD2LIVE_TOOLS=1 ./gradlew test --tests "*StructureMeshTool"
```

单元测试只用合成图：渐细的褶皱笔画、跨越材质的明暗台阶、色条与等距印花、颗粒与网点、阴影楔，以及只有轮廓的图层。拓扑测试检查保留部分逐点不变、中线落在笔画上、每个站点都有横档、流形、确定性和顶点上限。命令测试检查单条日志与重放一致，以及内部造型在新网格上重新烘焙、保留手绘褶皱、写入检测线。`StructureMeshTool` 在示例 PSD 的衣物与头发图层上并排绘出新旧网格和识别线，供目视检查。

分类基于通用绘制惯例（褶皱笔画渐细或带单侧阴影，缝线与部件边两侧颜色不同），对画风差异大的素材可能误判，可用线类型开关与灵敏度调整，或在内部造型中手工标注。近轮廓处的线因留出边缘带而不被采用。线之间不建立交点顶点：较弱的线在交叉处断开。
