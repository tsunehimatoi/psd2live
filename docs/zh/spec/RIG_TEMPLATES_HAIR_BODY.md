# 算法模板目录：头发与身体

> 本目录写于部位与模块架构之前，沿用“插槽 / 模板”的说法：同一插槽下互斥的做法将登记为该部位的**基础算法**，可叠加的能力登记为**模块**，`*/current` 对应各部位的 `legacy` 基础算法。实现状态以注册表（MCP `module_catalog`）为准，本页的 P0/P1/P2 只是规划优先级，“已实现”指引入注册表之前已有的算法。见 [Rig 预设架构](RIG_PRESETS.md)。

[文档目录](../../README.md) · [预设架构](RIG_PRESETS.md) · 模板目录：[面部](RIG_TEMPLATES_FACE.md) · [头发与身体](RIG_TEMPLATES_HAIR_BODY.md) · [物理与动作](RIG_TEMPLATES_PHYSICS_MOTION.md) · [结构与表现](RIG_TEMPLATES_STRUCTURE.md)

本页是 [Rig 预设架构](RIG_PRESETS.md) 的模板目录之一：每个区域插槽可注册多个算法模板，模型预设为每个插槽选择一个模板并给出参数值。同一问题的不同做法作为同一插槽下的不同模板并存。设计依据为通用 Live2D 制作惯例；数值均为建议默认值与可调范围，实现后按出图调校。每个插槽的 `*/current` 是现有算法，作为默认模板登记，选它时输出不变。

## 0. 约定

**单位**：H 角色身高；Hh 头高；Wf 脸宽；heye 眼高；L 物体沿主轴长度；W 物体宽；s ∈ [0,1] 沿主轴从根到梢的归一化弧长；参数“满值”记 ±1（导出时映射到 ±30 / ±10 等现有范围）。所有数值都是设计默认值与可调范围。

**插槽**：本文覆盖 `hair.front`、`hair.side`、`hair.back`、`hair.strand`、`hair.accessory`、`neck`、`body.turn`、`body.lean`、`breath`、`arm`、`hand`、`leg`、`chest`、`skirt`、`cloth`、`ribbon`、`tail`、`wing`、`prop`。补充四个插槽：`hair.variant`（发型变体）、`body.root`（骨盆根链与站姿）、`ornament`（吊坠、挂饰、纽扣、项圈等小件）、并把“细长物的链”统一放在 `hair.strand`，飘带、尾巴、绳、链引用它。

**与物理插槽的分界**：模板只声明“需要几个物理输出、每个输出接到哪一层、符号约定（同向 / 取反）”。质点数、mobility / delay / acceleration、输入权重、Angle / X 型、激励（呼吸、冲量）、滤波层由 `physics.chain` / `physics.cascade` / `physics.excitation` / `physics.filter` 模板负责。

**共享构件**（多个模板复用，应先做成库函数）：

| 编号 | 构件 | 说明 | 现状 |
| --- | --- | --- | --- |
| C1 | 条带描述 | 中轴（骨架化 + 最长路径 + 平滑）、根端、长度 L、半宽 w(s)、静息曲率、挂点 | 无（骨架有骨，但不从图层自动求中轴） |
| C2 | 保长弯曲 | 第 k 段只弯 s ≥ k/n 的部分，中心线保长，截面可平行 | `SwingDeformer` 已有 |
| C3 | 弧线密键 | 按弦高误差自适应插键：Δθ ≤ 2·acos(1 − ε/R)；或解析形状与线性插值差最大处插中间键 | 无（摆动与九姿态只有端点 + 中点） |
| C4 | 挂点局部转角求值 | 父变形器链在任意键下对一点及其邻域求值，取雅可比极分解的旋转角与位移 | `buildDeformerWorlds` + `SkeletonRig.inverse` 可复用 |
| C5 | 加法层 | 次级运动写成混合形状；旧目标降级为“每参数一层嵌套 warp”，写损失报告 | 引擎与导出支持混合形状，生成器从不产出 |
| C6 | 接缝胶水 | 切段缝、跨层级相邻件缝、同拓扑重复件全顶点缝 | 有 Glue 工具与 `GlueSeam`，无生成规则 |
| C7 | 绘制顺序关键形 | 紧邻键阶跃、组 level 参数（组内保持相对偏移） | 只有通道关键形可写，生成器绘制顺序静态 |
| C8 | 网格切分 | 一个图层沿切线切成多个 drawable，稳定 ID = 层 id + 段号（不用随机） | 无 |

**优先级**：P0 本轮实现；P1 下一轮；P2 研究或依赖素材约定。难度：易 / 中 / 难 / 研究。

## 1. hair.front（前发 / 刘海）

#### `hair.front/current` 头壳跟随 + 单参数摆 · 基线 · 已实现
- **现状**：`DeformHairFrontFollow`（AngleX×AngleY[×AngleZ]×BodyLean，3×4；横移与转头方向相反，`0.62+0.38v` 行权重，纵移与中部透视）→ `DeformHairFrontPhysics`（`ParamHairFront` −1/0/1，尖端权重 v³ 横摆 + 抬升，3×4）；物理单段单输出，输入固定头身四项。开启头发模拟时删除摆动层。
- **不足**：单输出、3 键（中途弦缩短）、所有发束同相、无“块 + 束”层次、无纵向弹动、无分组深度视差。
- **定位**：保留为默认；新模板在 follow 与 physics 之间插层，或替换 physics 层。

#### `hair.front/group-parallax` 发组深度视差层 · **P0** · 易
- **目的**：转头时刘海、侧发、后发、头饰按离头壳的深度有不同横移，消除“整张纸转动”。
- **适用**：有前发 / 侧发 / 后发 / 头饰标签的图层组；可选每束长度。
- **产出**：每个发组在 head container 之下、摆动层之上插一层单轴 `ParamAngleX` warp（3 键；转角 ≥ 30° 用 5 键，C3），网格 3×3–5×5。长发束（> 0.4 Hh）在每层摆动 warp 之下再插一层 AngleX 补偿 warp（“转头 / 摆动”交替夹层），使摆动后的形状仍在正确深度。
- **算法**：
  1. 组深度 z（以头半径 R 计）：鼻 1.0、头饰 0.95、刘海 0.9、眼 / 嘴 0.8、脸面 0.75、侧发 0.3、耳 0、后发 −0.6。
  2. AngleX = ±满值 θ 时，组横移残差 Δx = (z − z脸面)·R·sin θ（相对脸面层已给出的位移，避免重复施加）；远离转向侧的边压缩 5–10%。
  3. 夹层：第 k 层摆动 warp 下的补偿层 Δx_k = d_k·sin θ，d_k 每层增量 0.02–0.05 Wf。
  4. 后发组视差方向与脸面相反（在头后）。
- **可调**：`depthFront` 刘海深度（R）0.9 [0.6, 1.2]；`depthSide` 0.3 [0, 0.6]；`depthBack` −0.6 [−0.9, −0.3]；`depthHeadwear` 0.95 [0.7, 1.2]；`farCompress` 7% [3, 12]；`layerDepthStep` 0.03 Wf [0.02, 0.05]；`minStrandLen` 0.4 Hh。
- **失败与质检**：深度过大时刘海根脱离发际线——满值时刘海根与脸皮的重叠面积不应下降；与现有 follow 的横移叠加成双重计入——统一按残差计算。
- **引擎能力**：单轴 warp；关键形求值器（残差）。
- **差距**：现有 follow 只有一层统一视差。

#### `hair.front/block-then-strand` 整块先晃、单束后飘 · **P0** · 中
- **目的**：刘海先作为一整块滞后，再由各束各自飘；松戴物（帽、发饰、眼镜）与整块同档。
- **适用**：前发组含多束（子图层或连通分量）；单根硬发（呆毛、触角）单独处理。
- **产出**：参数 `ParamHairFrontBlock`（读物理质点 1）、`ParamHairFrontStrand`（读质点 2，多束共享，可叠 `hair.strand/group-drive` 逐束幅度）。结构：follow → 块 warp（单轴或 X×Y 2D，覆盖整组，上沿固定）→ 各束网格关键形（或束级小 warp）。单根硬发：根旋转变形器（原点发根，±10–15°）+ 网格尾弯。
- **算法**：
  1. 识别束：子图层或连通分量，C1 求中轴与根（靠发际线一端）。
  2. 块层：整块绕发际线中点平移 + 微转，权重从发际线 0 到下缘 1，下缘位移 ≤ 0.05 L。
  3. 束层：C2 保长弯曲，弯角 θ = θmax·s^p，按 C3 加键。
  4. 束层幅度为块层的 1.1–1.4 倍（scale 由 `physics.chain` 设定）；帽、发饰、眼镜读块层参数，幅度为自身高度的 5–10%。
- **可调**：`blockShift` 0.04 L [0.02, 0.08]；`strandBend` 20° [15, 30]；`strandExp` p 1.5 [1, 2]；`ahogeRoot` 12° [8, 18]；`looseWearAmp` 7% 自身高 [5, 10]。
- **失败与质检**：帽子与刘海滞后差大时露缝——帽下需有发色底；束层幅度大时相邻束穿插——相邻束幅度差 ≤ 30%。
- **引擎能力**：网格关键形；同一物理组多输出。
- **差距**：前发只有一个整块摆参数，物理只输出质点 1。

#### `hair.front/nested-warp-chain` 嵌套 warp 多质点鞭梢链 · **P0** · 中
- **目的**：一张发片网格做出根→梢传播的 S 弯与鞭梢，不切网格。宽发片（宽 / 长 > 0.4）的首选链形态。
- **适用**：前发、侧发、后发组，裙片、宽缎带同样适用。
- **产出**：K 层同包围盒嵌套 warp（外层覆盖整组，内层可只覆盖远端 0.4–1.0 L，包围盒外扩 10%），第 k 层参数 `Param<Group>X_k` 读物理质点 k；可选每层第二轴 `Param<Group>Y_k`（纵向）形成 2D 键；每轴按 C3 取 5–13 键。
- **算法**：
  1. 第 k 层只弯 s ≥ (k−1)/K 的部分（C2），弯曲中心在 s_k，[s_k, s_k + 0.2] 内 smoothstep 过渡，保长。
  2. 层幅度 A_k = A_1·r^(k−1)，r ≈ 0.7（嵌套位移会累积，外大内小）。
  3. 分级嵌套：外层收全部输出，内层只收远端输出。
  4. 2D 轴：角键 = 先施 a 后施 b（在 warp 局部坐标复合）；同号角键按 0.7–1 缩放防越界；第二轴可用 `hair.side/s-curve` 的可分离合成。
  5. 同区多束共享同一组层与参数，每束按自身中轴计算 s；该组的发影、马尾根挂进同一组层保持同步。
- **可调**：`layers` K 3 [2, 4]；`ampDecay` r 0.7 [0.6, 0.8]；`tipDisp` 梢部满值位移 0.2 L [0.1, 0.3]；`innerStart` 0.4 L [0.35, 0.5]；`arcTol` 弦误差 0.5 px [0.3, 1]；`keysSmall` 5（|θ| ≤ 20°）；`keysLarge` 9 [7, 13]。
- **失败与质检**：内层没盖住发梢出现折痕——检查所有顶点都在内层范围；挂点附近权重非零导致发根漂移——s < 0.05 处位移为 0；层数过多时内层放大外层抖动——K ≤ 4；键数膨胀——2D 只用于需要 S 形的组。
- **引擎能力**：嵌套 warp；多输出物理；C3 弧线键；可选 C5 混合形状替代第二轴。
- **差距**：`SwingDeformer` 已有段语义，但 `RigSwingEdits` 每参数只放 3 键并把全部段轴乘在同一 warp 上（3^(2n) 个关键形），各段物理参数与 scale 相同；头发预设单段单输出。

#### `hair.front/blend-modes` 同一 warp 上的根 / 中 / 梢混合形状模态 · P1 · 中
- **目的**：用加法混合形状代替乘法关键形网格，多模态同时叠加不爆炸，同组多束同步而不雷同。
- **适用**：已有转头乘法轴的发组；目标运行时支持混合形状时原生输出，否则降级（C5）。
- **产出**：在角度 warp 之内插“模态 warp”（10–20 行 × 5–14 列，长轴沿发束），无关键形轴，只挂 K = 2–3 个混合形状 `Param<Group>Mode_k`（±1）。也可每个物理轴单独一层（顺序：纵向 Y → 横摆 X → 卷曲 Z，慢而大的在外，细的在内）。
- **算法**：
  1. 模态 1（根）：绕发根刚体转，梢位移 0.3–0.4 L。
  2. 模态 2（中）：Δ = n·a2·L·smoothstep(0.25, 1, s)²。
  3. 模态 3（梢）：Δ = n·a3·L·s³；短而宽的刘海取反号得 S 弯。
  4. 每个模态在 s = 0 处严格为 0。
  5. 同侧多束共享模态 1 参数，模态 2、3 各自参数（scale 确定性抖动 ±10–30%）。
  6. 宽发片（宽 / 长 > 0.5）模态 3 按列独立。
- **可调**：`mode1Tip` 0.35 L [0.3, 0.4]；`mode2Amp` a2 0.25 [0.2, 0.3]；`mode3Amp` a3 0.15 [0.1, 0.2]；`tipReverse`（刘海 true）；`sumClamp` 梢总位移上限 0.6 L。
- **失败与质检**：多模态同号叠加越界——按 √Σp² 限幅；父层大转角时“局部右”方向不对——模态层必须在角度 warp 之内；降级为嵌套 warp 后键数估算并报告。
- **引擎能力**：C5。
- **差距**：生成器不产出混合形状。

#### `hair.front/xyz-axes` 横摆 / 卷曲 / 伸缩三轴 · P1 · 中
- **目的**：摇头、歪头、点头各有专属发丝反应，而不是都借横摆的形状。
- **产出**：每发组三套参数：X 横摆（位移 ∝ s^1.5）、Z 卷曲（垂直主轴，∝ s²，梢宽收窄 10–20%）、Y 伸缩（沿主轴，正拉长、负缩短并略加宽，梢最大）。作为三层混合形状 warp（或三层嵌套 warp）。Y 层可与 AngleX 做 2D 键，使纵向弹跳方向随朝向变化。
- **算法**：幅度比 X : Z : Y ≈ 1 : 1.5 : 2.5（以 %H 计）；Y 的中间值加一个形状，避免缩短时压扁成直线；三轴各由“最相关的头部输入”主导（`physics.*` 设计）。
- **可调**：`xTip` 0.6% H [0.4, 1]；`zTip` 1.5% H [1, 2]；`yTip` 2% H [1.5, 2.5]；`zNarrow` 15% [10, 20]。
- **失败与质检**：短刘海 Y 伸缩过大露出额头——刘海 Y ≤ 0.05 L；宽发束 Z 卷曲撕开相邻束——相邻束共享 Z 形状或加胶水。
- **引擎能力**：C5 或嵌套 warp；三组物理。
- **差距**：只有一个横摆参数。

## 2. hair.side（侧发 / 鬓发）

#### `hair.side/current` 无独立分支 · 基线
- **现状**：侧发按标签归入前发或后发分支（或直接挂 head container），没有独立视差、摆动与换层。
- **定位**：侧发应作为独立发组，复用 `hair.front/*` 模板（深度 z = 0.3），再加下列侧发专用模板。

#### `hair.side/s-curve` 相邻质点二维键的行波 S 形 · P1 · 中
- **目的**：单参数摆只能“整体弯向一侧”；两个相邻质点作为 2D 键的两轴，在角键上分别是“根弯尖直 / 根直尖弯 / 同向弯 / 反向 S”，摆动时曲率沿发束传播。
- **产出**：2D warp（行沿长轴），轴 p = 质点 j、q = 质点 j+1（第二轴默认取反，S 形为默认结果）；九键由两条基形状可分离合成。
- **算法**：横向位移 = p·f(s) + q·g(s)，f(s) = s²，g(s) = 4·max(0, s − 0.5)²；角键 (±1, ±1) 为两者之和，按 0.7–1 缩放；两层嵌套时外层 (v1, v2)、内层 (v3, v4)。
- **可调**：`fExp` 2 [1.5, 2.5]；`gStart` 0.5 [0.4, 0.6]；`secondReflect` true；`cornerScale` 0.85 [0.7, 1]。
- **失败与质检**：长轴方向判错（行沿横向）会扭成波浪边——用 C1 中轴确定行方向。
- **引擎能力**：2D 键；“四角自动合成”（可分离合成）。
- **差距**：每物一轴；四角自动合成列为后续。

#### `hair.side/turn-depth-swap` 转头换层（发束与环形头饰） · P1 · 中
- **目的**：近满转角时近侧鬓发、马尾、环形头饰的远侧半圈从脸前移到脸后（或反之），只给需要的对象加层级键。
- **适用**：侧发、鬓发、马尾、头冠 / 发箍 / 光环（按头部中线切左右两半）。
- **产出**：对象的绘制顺序关键形（轴 AngleX），在换层角 θs ± Δ 插一对紧邻键；可分 2–3 级下沉（前发之下 → 脸之上 → 后发之上）；需要在中线精确切换的件用 0 与 −ε 一对键阶跃；远侧一半同时按椭球透视压缩。
- **算法**：
  1. 根或件中心的经度 φ = asin((x − xc)/r_head)。
  2. 转头 θ 时视经度 φ' = φ + κθ，深度 z = cos φ'。
  3. |φ'| > 90° − δ 时应在脸后；在头部绘制栈中按 z 找插入位置；若 θs 在参数范围内则在 θs ± Δ 插键。
  4. 换层瞬间对象应大部分被裁掉，否则配反向蒙版过渡（遮罩模板）。
  5. 键值不跨越无关层（绘制顺序在两键之间整数插值）。
- **可调**：`swapDelta` Δ 3° [2, 5]；`swapMargin` δ 10° [5, 15]；`kappa` 1 [0.8, 1.2]；`levels` 2 [1, 3]；`epsilon` 范围的 0.01%。
- **失败与质检**：换层键落到参数范围外失效——生成时校验；换层瞬间色差大会闪——反向蒙版或换层发生在被遮挡处。
- **引擎能力**：C7；反向蒙版。
- **差距**：生成器绘制顺序静态（透过复制件除外）。

#### `hair.side/carrier-split` 搭在身体 / 手臂上的长发按承载部位拆片 · P2 · 难
- **目的**：长发既随头摆，又随手臂、胸、躯干动，两种运动都对。
- **产出**：长发按“静息时压在哪个部位上”切段，各段挂到对应部位变形器（头、胸物理 warp、躯干、上臂、前臂）的子 warp，段间胶水（C6）；一组发丝物理以混合形状加到所有段，位移场沿整根弧长 s 连续定义，各段截取自己的区间。
- **算法**：每个发丝顶点取画面深度上其后方覆盖它的身体网格定归属，无则归头 → 连通区域平滑（最短段 ≥ 2 发宽）→ C8 切段 + 胶水 → 混合形状幅度随 s 增加，压在部位上的段乘压附系数。
- **可调**：`pressFactor` 0.45 [0.3, 0.6]；`segments` 2–4；头部 roll 输入为主。
- **失败与质检**：手臂大幅抬起时段被拉开——胶水留余量，或加以手臂角为轴的补偿 warp；归属在边界抖动——平滑。
- **引擎能力**：跨层级共享混合形状；C6；C8。

#### `hair.side/drill-ring-chain` 钻头卷环链 · P2 · 难
- **目的**：螺旋卷是一串近刚性的环，每环绕上一环边缘转动，摆动时露出下一环的暗色内侧。
- **产出**：根旋转（AngleX×AngleY）→ 每环一个旋转（混合形状 ±α_k）+ 每环一个 AngleX×AngleY warp（俯仰改开口椭圆短轴，偏航按深度做视差）；每环拆前带 / 内侧，第 k 环画在第 k−1 环前带之下、内侧之上。
- **算法**：沿主轴在宽度局部极小或暗色内带处切 N 环；第 k 环支点在第 k−1 环下缘与轴交点（向下偏 0.3 环宽）；物理用长链，输出 scale 逐级乘 0.88（嵌套累加）。
- **可调**：`rings` N 4 [3, 5]；`ringAngle` 20° [15, 25]；`scaleDecay` 0.88 [0.85, 0.92]。
- **失败与质检**：分环与前后带拆分依赖素材标注。

#### `hair.side/curl-spring` 卷发弹簧伸缩 · P2 · 难
- **目的**：细卷发被甩时先伸长、圈距变大而卷形保持。
- **算法**：中线参数化为螺旋（半径 r(s)、圈距 p）；关键形 p → p·(1 + k|x|)，整体沿摆向偏转 θ·x，截面宽保持；网格沿中线排布（截面 3–5 点）。
- **可调**：`stretch` 1.3 [1.2, 1.5]；`deflect` 30° [20, 40]。
- **失败与质检**：自相交画法不适用中线模型——回退普通摆动。

## 3. hair.back（后发）

#### `hair.back/current` 跟随 + Angle Z 回转 + 单参数摆 · 基线 · 已实现
- **现状**：`DeformHairBackFollow`（含 `HairRoll`：发长过下巴时追加 AngleZ 轴，下巴以下的点按 smoothstep·hold 绕头部支点反向回转）→ `DeformHairBackPhysics`（`ParamHairBack`，3×6）。

#### `hair.back/split-strips` 宽后发分条各自摆 · P1 · 中

- **产出**：每条一套摆动层（可用 `hair.front/nested-warp-chain`），参数 `ParamHairBack<Side>_k`；中线上的宽发片按中线切两半。相邻条交替使用两套错调的摆参数（摆长比 1.1–1.3）。

- **失败与质检**：切线不在发缝上时摆动露裂缝；发梢被裙或手臂遮挡时穿出。
- **引擎能力**：C8 或子图层；C6。
- **差距**：只有一个 `ParamHairBack`。

#### `hair.back/strand-two-stage` 每束两段链 + 根部随转向外展 · P1 · 中
- **目的**：每束后发根段、尖段两级摆形成 S 形；转头时近侧 / 远侧发束外展或内收，伪造体积。
- **产出**：根旋转（支点根 R，键 AngleX×AngleY，角度 = k·偏航·侧向符号，转离时外展）→ 波动旋转（纵向参数 Wave）→ 透视 warp（8×4，AngleX×AngleY）→ 尖端旋转（支点 0.5 L 处，键 摆参数 × 偏航 × 俯仰，侧对时幅度 × cos 偏航）→ 尖端 warp。根旋转用 180° 基角，使局部 y 轴沿发束朝下，左右镜像只改符号。
- **可调**：`rootFlare` 每 45° 偏航 3° [2, 5]；`tipSway` 20° [15, 30]；`wave` 7° [5, 10]。
- **失败与质检**：基角约定不统一时镜像符号出错——全局固定“画布正方向”约定。
- **引擎能力**：旋转链；多维键。

#### `hair.back/vertical-splay` 纵向颠簸转为左右开合 · P1 · 中
- **目的**：点头、上下颠簸时两侧下垂物（侧发、后发、飘带）张开或收拢，显出体积。
- **适用**：按悬挂点位于中线哪一侧分组的下垂物；中线上的物体不加此层。
- **产出**：每个下垂区域一对纵向参数（读质点 1、2），形状：+1 每束绕挂点向远离中线方向转 θ = θmax·|x − xmid|/半宽，末端上提 0.05 L；−1 向内转 0.5θ 并伸长 3%；中间值按 |u|^1.3 缓入（用 C3 烘焙）。物理侧：纵向输入一侧取反（交 `physics.chain`）。
- **可调**：`splayMax` 15° [8, 25]；`innerRatio` 0.5 [0.3, 0.6]；`ease` 1.3 [1, 1.6]；位移按挂点到末端长度成比例。
- **失败与质检**：内收时与身体、手臂穿插——内收 ≤ 外张一半；左右不对称原画各按自己的中线计算；渲染 AngleY 正弦扫描，检查两侧末端水平位移符号相反。
- **差距**：VERTICAL 摆动把俯仰当横向位移，所有链同号，没有开合形状。

#### `hair.back/cylinder-turn` 圆柱代理密键转头 · P2 · 难
- **目的**：后发、颈后、领口绕颈轴做圆周运动（横移 ∝ sin θ，可见宽 ∝ cos θ），3 键线性插值在中间角明显偏差。
- **产出**：后发组 AngleX×AngleY warp，键 7×7（每 10°），必要时 13×13（每 5°），由代理批量出键；其下照常挂角度 Z、物理层。
- **算法**：圆柱轴 = 颈中线，半径 r 约 0.55 头宽，并约束 ±满值时后发边缘仍在头轮廓外 2–5% 头宽；控制点按角坐标 φ 旋转 θx（绕竖轴）、θy（俯仰按 cos 压缩）后正交投影；被头遮挡的前侧点只位移不改遮挡，遮挡变化交给 `hair.side/turn-depth-swap`。
- **可调**：`radius` 0.55 头宽 [0.45, 0.65]；`keyStep` 10° [5, 10]；`perspective` 0.1 [0, 0.2]。
- **失败与质检**：半径估错时后发滑出头轮廓；键数膨胀——7×7 通常已足够。
- **引擎能力**：密键批量烘焙；可与面部的 13×13 头部转向模板共用代理求值。
- **差距**：九姿态 3×3。

## 4. hair.strand（细长物通用链：发束、辫子、马尾、缎带尾、绳、藤蔓；飘带与尾巴引用）

#### `hair.strand/skinned-chain` 切段蒙皮旋转链 · P1 · 难
- **目的**：细长物做大幅 S 弯与鞭梢，段长守恒，接缝不开裂。
- **适用**：长宽比 ≥ 3（或语义 strand / braid / ponytail / ribbon-tail / rope / tail / vine），长度 ≥ 0.06 H；宽长比 > 0.4 的宽片改用 `hair.front/nested-warp-chain`。
- **产出**：
  - 网格：原图层沿中轴法向切成 N 段（C8），切缝两侧各留一列重合顶点，配对胶水强度 1（C6）。
  - 变形器：每段一个嵌套旋转变形器，原点 = 段起点关节；第 1 节基角 = 根部绝对方向，后续基角 = 相对上一段的中轴转角（静息还原原画曲线）。
  - 参数：每关节 `Param<Chain>_j` ±1 → ±45°（3 键即可，旋转插值走圆弧）；参数收进按链命名的折叠组。
  - 叠层：高光、花纹叠层不切，改以全部段网格的并集为蒙版，花纹连续。
  - 物理：一组链，输出接各关节（映射规则交 `physics.chain`：少质点驱动多关节、根部共享、scale 根→梢斜坡、锚定段不出参数）。
- **算法**：
  1. C1：距离变换 + 骨架化，取根到最远尖端的最长路径，平滑；根 = 与父部件重叠或最近的一端；求半宽 w(s)。
  2. 段数 N = clamp(round(L / (k·w̄)), 3, 9)，k ≈ 2；或按长度：< 0.08 H 取 3，0.08–0.2 H 取 5，0.2–0.5 H 取 7，主动肢体（尾）取 9。
  3. 关节位置前密后疏或按曲率自适应：中轴转角 > 30° 处补切点；麻花辫吸附到局部宽度极小处（辫结整体刚性）；不在 > 0.93 L 处放关节。
  4. 切缝避开高光与强纹理，两侧重叠带 0.03–0.06 段长。
  5. 清理：三角形 < 3 或面积 < 0.5% 的尖端段并入上一段（不得留空段）。
  6. 锚定：从头皮长出的发束，前 15–25% 不建参数、直接挂在发层 warp 下；从系结点垂下的物体根节可动；被腰带穿过、根部被固定的条带第 1 节不接物理。
  7. 链根挂在发层 warp（转头视差系数比脸面大 10–30%）下；需要继承头部透视时见 `warp-baked-chain` 或 `segment-perspective-keys`。
- **可调**：`segments` N [3, 9]；`segLenToWidth` k 2 [1.5, 2.5]；`anchorRatio` 0.2 [0.15, 0.25]；`jointRange` ±45° [30, 45]；`overlap` 0.04 段长 [0.03, 0.06]；`glueStrength` 1 [0.8, 1]；`maxBend` 每节 30°。
- **失败与质检**：退化尖段；切缝 UV 不一致出细缝；被遮挡部分没画完整时切开露缺口（素材要求）；两条链交叉时绘制顺序固定会穿插；每节转角 > 30° 内侧挤压、胶水被拉开——限制 scale；参数膨胀——折叠组 + 自动命名。
- **引擎能力**：C8（一图层 → 多 drawable，稳定 ID = 层 id + 段号）；嵌套旋转；C6；多输出物理。
- **差距**：`RigSwingEdits` 在单个 warp 上逐段写关键形，不切网格、不建旋转链、不缝胶水；骨架尾巴有链但不切段；长发与缎带默认用 warp 摆动。

#### `hair.strand/warp-baked-chain` 头部透视下把旋转链烘焙为嵌套 warp · P1 · 难
- **目的**：挂在头部 warp 之下的发束要继承头部 warp 的透视压缩；旋转变形器只接收原点与朝向，发束会像纸片。
- **产出**：按 `skinned-chain` 求出的关节，生成嵌套 warp 链（每关节一个覆盖“该段到梢”的 warp，约 16×7，长轴沿发束），关键形 = 刚性旋转后控制点在父 warp 局部坐标中的位置；物理输出仍按关节角，只是绑定从旋转改为 warp 参数。挂在头部以外的链保留旋转形态。
- **算法**：每关节采样步长由弦高误差决定（C3）：Δθ = 2·acos(1 − ε/R)，R = 关节到梢距离，ε ≤ 0.5 px；R < 0.05 H 取 6–10°，R > 0.1 H 取 1.5–3°。
- **可调**：`arcTol` 0.5 px [0.3, 1]；`warpCols` 16 [12, 16]。
- **失败与质检**：嵌套过深累计误差与开销（warp 格数 × 键数 × 节数）；采样不足时梢部走直线被拉长。

#### `hair.strand/segment-perspective-keys` 链段网格补父级透视残差 · P2 · 难
- **目的**：链段挂在带几何关键形的 warp（头部转向、上身弧形侧倾、身体转向）之下时，补上旋转变形器传不下来的弯曲与透视。
- **算法**：
  1. 沿祖先链收集几何 warp 的参数轴 A（不含物理层）。
  2. 对每个段网格、A 的每个关键组合 a：完整 warp 链求值 P_warp(a)，按“旋转只传原点与朝向”求值 P_rot(a)，段关键形 = 静止形 + (P_warp − P_rot) 换到段局部坐标。
  3. 键数取父 warp 键数；超过 3 轴时只保留位移最大的 2–3 个；位移 < 0.01 heye 的轴不打键。
  4. 登记为生成器产物，父 warp 关键形改动时重算；相邻段接缝处修正量须一致（胶水检查）。
- **可调**：`minAxisDisp` 0.01 heye；`maxAxes` 2 [2, 3]。
- **失败与质检**：维度爆炸——优先“链根加一层承接 warp、链挂在 warp 外”；大角度下段间接缝张开——胶水。

#### `hair.strand/gravity-hold` 下垂物重力保持（挂点反向旋转） · **P0** · 中
- **目的**：头或身体倾斜时，发束、辫子、耳坠、链、缎带尾、肩纱保持下垂；静态截图就正确，物理只描述偏离静平衡的摆动。
- **适用**：语义为下垂物（发束、辫子、流苏、链、缎带尾、耳坠、吊坠、肩纱、悬挂毛皮），静息主轴与重力夹角 < 45°，悬挂点在上端；排除朝上物（羽毛、呆毛）和贴身发片。
- **产出**：在链根（或贴附段之后的第一个关节）为每个祖先旋转源插一层旋转变形器 R_g（原点 = 挂点 p）：
  - 头 Z 源：轴 `ParamAngleZ`（若有头部惯性参数则 AngleZ × 惯性 3×3）；
  - 身体 Z 源：轴 `ParamBodyAngleZ`（× 躯干惯性）；
  - 全身倾源（若有 `body.root/pelvis-chain` 的全身倾参数）。
  - 角度关键形 = −k × 该键下祖先在 p 处的累计转角；物理层放在 R_g 之下。
- **算法**：
  1. C4：在各端点键下求 p 附近一根短向量的方向变化，得累计转角 Θ(key)。
  2. 贴附段：主轴上仍与载体重叠的前缀 ℓ_attach > 0.1 L 时，R_g 插在越过 ℓ_attach 的第一个关节之后，贴附段随载体转。
  3. 碰撞裁剪：在各端点检测下垂物与身体、脸、手臂轮廓是否相交，相交侧减小 k（会贴到支撑物的一侧可取 0）——得到左右不对称的角度范围。
  4. 挂点在会大幅转动的肢体上时，k 随肢体角递减，补偿限幅。
  5. 物理保留 Z 向 Angle 输入但 scale 小，只负责动态（交 `physics.*`）。
  6. 校验：端点渲染，主轴与竖直夹角 ≤ (1 − k)·父转角 + 3°。
- **可调**：`kHead` 0.85 [0.75, 0.9]（耳坠 0.8、链 0.9）；`kBody` 1.0 [0.8, 1]；`kRigid` 硬挂件 0.45 [0.3, 0.6]；`attachLen` 0.2 L [0.15, 0.25]；`innerOuterRatio` 0.8 [0.6, 1]；`limit` 50° [40, 60]。
- **失败与质检**：k = 1 时下垂物像冻在空中；宽发束单个 R_g 会让发根与头皮脱开——必须用贴附段规则；挂点在强 warp 区（脸侧）时 warp 自身带转角——叠加 `hang-jacobian-compensation`；贴身项链不补偿。
- **引擎能力**：C4；旋转变形器；2D 键。
- **差距**：现有 `HairRoll` 只在后发 follow warp 中对下巴以下做反向回转（单源、warp 形态）；侧发、辫子、饰品没有重力层；`SwingDeformer` 不区分静平衡与动态。

#### `hair.strand/hang-jacobian-compensation` 头部转向 warp 在挂点造成的局部转角补偿 · P1 · 难
- **目的**：头部转向主要靠 warp，warp 在挂点处带来剪切与局部转角；补偿后下垂物在九姿态下都竖直，又随头产生正确的视差位移。
- **产出**：在链根（`gravity-hold` 层之外）加 AngleX×AngleY 3×3 旋转层，角度 = −k_turn·θ(key)，θ 由挂点处父 warp 雅可比 J = R·S 极分解得到；只在 |θ| > 1° 时建层。另一种用法：角度恒 0、原点随 AngleX×Y 键移动的“定位旋转”，让挂点随头表面走（附着点在头部椭球代理上随头转后的投影）。朝上物体在此层不补偿，改为额外倾斜 g·θ。
- **可调**：`kTurn` 0.9 [0.8, 1]；`upwardGain` g 1 [0.5, 1.5]；`minAngle` 1°。
- **失败与质检**：挂点正好落在 warp 网格折线处时雅可比不连续——取邻域平均；warp 关键形改动后必须重算——登记生成器依赖；九宫格逐格量主轴角。

#### `hair.strand/upward-strand` 朝上附属物（羽毛、呆毛、触角） · P1 · 易
- **目的**：物理链本质是下垂摆，对朝上物体同一转向会把尖端推向相反侧。
- **产出**：静息方向 d（根→尖）满足 d·g < −0.3 时，该链所有物理输出取反；幅度为下垂链的 1.5–2.5 倍；外加随头倾斜层（`hang-jacobian-compensation` 的反符号版本）。呆毛：根旋转（±10–15°）+ 网格尾弯；拱形呆毛：3–6 节链 + 胶水，基角沿拱切线，根节也可摆。
- **可调**：`upThreshold` −0.3；`scaleMul` 2 [1.5, 2.5]；`ahogeSegments` 4 [3, 6]。
- **失败与质检**：水平伸出（|d·g| < 0.3）时符号判定不稳——改用侧向分量；硬质物不用链。校验：头阶跃后羽毛尖与发梢位移方向一致、都滞后于头。

#### `hair.strand/branch-and-cascade` 分叉链与级联子链 · P2 · 难
- **目的**：一绺头发末端分成几缕、软帽尖上挂金环等复合物体：子链跟随母链，过了挂接点再各自运动。
- **产出**：骨架图中度数 ≥ 3 的节点为分叉点；主干 = 根到最远尖端，分支长度 < 主干 15% 时并入主干轮廓；分支第 1 关节挂在分叉点所在主干段的旋转下（原点 = 分叉点），分叉线处与主干胶水；子链根关节刚性（输出 0–5%）。复合物体：子链根轴心命中哪条链的哪段网格（三角形命中），就挂到那段旋转下；母段上的装饰层（辉光、侧面）随段挂接。物理映射：子链从母链挂接段的质点往后读（深 1–2 个质点）。
- **可调**：`minBranchRatio` 0.15 [0.1, 0.25]；`branchRootStiff` 0–5%；`childOffset` 1 [1, 2]；`maxDepth` 3。
- **失败与质检**：分叉点距根 < 15% 长度时当两条独立链；挂接深度 > 3 级时角度累积失控——限制子链 scale。

#### `hair.strand/group-drive` 组驱动 + 逐束确定性幅度 · **P0** · 易
- **目的**：少量参数驱动大量发束 / 挂件，逐束幅度不同，打破“一整块同步摆”。
- **产出**：同组发束（或同类小饰件）共用一组参数；每束关键形幅度单独缩放。
- **算法**：
  1. 同组按长度归一化幅度（长的大、短的小）。
  2. 乘确定性系数 c_i ∈ [0.5, 1.5]（以对象稳定 id 的哈希为种子，禁止随机数）。
  3. 离身体远的外侧束再乘 1.2–1.3。
  4. 小饰件：摆角 φ_i = φ0·(1 + j_i)，j_i ∈ [−0.5, 0.3]，方向 ±15° 抖动。
  5. 左右镜像件不抖（保持镜像关系），只对同侧同类件抖动。
- **可调**：`jitterMin` 0.5、`jitterMax` 1.5；`outerBoost` 1.25 [1.2, 1.3]；`dirJitter` 15°。
- **失败与质检**：相邻件摆动后互相穿插——检查端点重叠。
- **差距**：摆动对多个目标用同一形状参数，没有确定性实例差异。

#### `hair.strand/float-wave` 漂浮长发：动作行波 × 物理残余双轴 · P2 · 中
- **目的**：反重力的漂浮长发 / 缎带由手写行波驱动，物理只叠加头部运动带来的残余，两者在不同参数上相加互不覆盖。
- **产出**：每侧 N 个行波参数 W_k 与 N 个物理参数 P_k；每节旋转以 (W_k, P_k) 3×3 键：角度 = a_k·W_k + b_k·P_k，a_k 根→梢递增，同侧不同发束乘 0.5–1.2 确定性系数；行波曲线归 `motion.idle`。静息造型偏置并入静息网格，不写进动作。
- **可调**：`tipAmp` 20° [15, 25]；`physScale` 根→梢递减。

## 5. hair.accessory（头饰）

#### `hair.accessory/current` 挂 head container · 基线
- **现状**：HEADWEAR 等默认挂 head container，随头壳变形，没有视差层、物理档与换层。

#### `hair.accessory/soft-shell` 头戴软壳的两级滞后 · P1 · 中
- **目的**：帽子、眼罩、发箍上的布偶等软壳只靠松紧固定，头一动应慢半拍并轻微滑动；前片动得多，贴后脑的部分动得少。
- **适用**：标为“头戴软壳”的图层组，分前片（远离头皮）、贴头片（贴后脑或被头发压住）、系带。
- **产出**：头部转向 warp → 物理外层 warp（P1×P2）→ 物理内层 warp（P3×P4）→ 局部透视 warp（AngleX×AngleY，按道具中心重求透视）→ 网格；贴头片跳过外层。道具上的附件（耳朵、蝴蝶结）必须挂在物理层之下。
- **算法**：P1 整体平移（沿头部切向 ±0.3–0.5 heye），P2 绕上缘中点小转角（±4–6°）；P3、P4 同理但幅度减半，形变集中在下缘（权重从上缘 0 到下缘 1）。物理：同一组链，外层读质点 2、内层读质点 3。
- **可调**：`outerShift` 0.4 heye [0.2, 0.5]；`outerTurn` 5° [3, 8]；`attachedDamp` 0.45 [0.3, 0.6]。
- **失败与质检**：在头部九宫格每格加 P 极值，道具上缘与头发接触线偏离 < 0.15 heye，否则缩小 P1；道具压着的头发不随之变形会露缝。

#### `hair.accessory/floating-halo` 悬浮附件（光环、浮冠） · P1 · 易
- **目的**：与头之间隔着空气的附件随头移动，但有自己的漂浮节律；转头透视位移小于头发。
- **适用**：与头部轮廓不接触、位于头顶上方 > 0.05 Hh 的图层（或标注为浮空）。
- **产出**：漂浮 warp（最外层，空闲参数驱动上移 0.08–0.12 Hh；可改由 `breath/attachment-bob` 驱动）→ 透视 warp（AngleX×AngleY，位移取头顶 warp 的 0.6–0.8）→ 开关；希望始终水平时放在头部滚转之外并加反向旋转。进阶（P2）：拟合椭圆还原三维圆环，按头姿态 + 物理附加转角重投影，外层整体漂浮、内层分件滞后（尾带 ×1.3），穿过头后时切前后两半设绘制顺序。
- **可调**：`floatAmp` 0.1 Hh [0.08, 0.12]；`perspRatio` 0.7 [0.6, 0.8]；`keepLevel` false。

#### `hair.accessory/thin-card` 薄片饰物的侧面显现 · P2 · 中
- **目的**：正面几乎侧视的薄环、薄片、宝石侧面在转头 / 转身时展开或显现，用“旋转 + 缩放 + 淡入”近似投影。
- **算法**：估计平面法线与视线夹角 φ0（标注或由宽高比推断）；yaw θ 下可见宽度 ∝ |sin(φ0 + θ)|，以 θ 为轴打 3 键，缩放 = |sin(φ0 + θ)|/|sin φ0|，封顶 3；旋转角取投影主轴变化；不透明度 = smoothstep(0.1, 0.4, 可见宽度比)；宝石侧面层在正面键 0、两端 1、中间 0.5。
- **可调**：`phi0`；`maxScale` 2.5 [2, 3]；淡入阈值。
- **失败与质检**：缩放 > 3 会糊——改用差分图；只适合单色对称物件。

#### `hair.accessory/strap-tilt` 系带 / 耳挂的头倾单侧补偿 · P2 · 易
- **目的**：跨越头部轮廓的系带随头倾时应沿头皮曲面变化，拉紧侧与松弛侧不对称。
- **产出**：系带物理层之上加一层 AngleZ 旋转或 warp，角度 = −k·Δθ_tangent（根点在头轮廓上的切线变化）；拉紧侧 k 0.8–1，松弛侧 0.3–0.5；最大补偿 ≤ 10°；系带物理只接身体输入，头部运动由层级继承。两端都固定在头上的发带不需要。

## 6. hair.variant（发型变体，补充插槽）

#### `hair.variant/fold-toggle` 可拆卸组缩向挂点再淡出 · P1 · 易
- **目的**：一个模型提供多种发型 / 配件组合（双马尾、单侧、丸子头、帽子、外套），切换过程是“收进去”而不是凭空消失。
- **产出**：每个可拆卸组最上层插一个旋转变形器（原点 = 挂点），参数 `Toggle<Group>` 0..1：0 → scale 1、opacity 1；0.6 → scale 0.3、opacity 0.5；1 → scale 0.001–0.05、opacity 0；角度不变。收回方向沿“附着部件内部”（向挂点、或沉进头发 / 身后约一个部件高），收回路径必须在遮挡物之后。同时生成单项与常用组合的表情文件。
- **可调**：`endScale` 0.02 [0.001, 0.05]；`fadeStart` 0.6 [0.4, 0.7]；`retractDist` 1 个部件高；`retractRotate`（可选向后倒）。
- **失败与质检**：缩到 0 时连向本体的胶水会把本体拉向挂点——可拆卸组与本体之间不建强胶水；被隐藏组若是别人的蒙版，对方剪切随之消失——检查蒙版引用；收回路径上无遮挡物时会滑过脸或身体。

#### `hair.variant/deform-restyle` 变形式发型变体层 · P2 · 易
- **目的**：不画新图，用变形把刘海拨向一侧、侧发外翻 / 内收、后发蓬松 / 收紧。
- **产出**：在发组“角度 warp”与“物理层”之间插变体层 V（同分辨率），轴为变体参数（0/1 或 −1/0/1）；变体后照样跟随转头与摆动。
- **算法**：拨刘海：以发旋点为中心向一侧旋转 15–25°，发梢侧收紧 10–20%，露出至少半只眼；侧发外翻：下段外移 1–1.5% H 并略上卷；后发：横向缩放 ±8–12%。自动检查被暴露区域下层图层的 alpha 覆盖率（额头、眉毛须画完整）。
- **可调**：`sweepAngle` 20° [10, 25]；`flipShift` 1.2% H [0.8, 1.5]；`backScale` 10% [8, 12]。

#### `hair.variant/twin-mesh` 变体孪生网格 · P2 · 易
- **目的**：换色、换贴图版本、差分手臂上的同一饰品，不复制整条 Rig。
- **产出**：变体网格复制原网格拓扑，挂在同一变形器下，绘制顺序紧贴原件之上，不透明度轴为变体开关；多维组合用乘积键（发型 H × 变体 V）；孪生件复制胶水对；互斥差分上的同一饰品共用一组物理参数，各自的 warp 按局部坐标换算使画面位移一致。

## 7. neck（颈与头身衔接）

#### `neck/current` 头部旋转支点在嘴线 · 基线
- **现状**：`DeformHeadRotation`（AngleZ → 原画倾角 + 旋转，支点 = 脸中心 x、嘴线 y）挂在 `DeformBodyZBreath` 下；脖子作为身体图层随身体 warp；没有颈部专属 warp，头 Z 全部由头部刚性旋转承担，支点不随转向移动。

#### `neck/tilt-share` 头部滚转分摊到头、颈、上身 · P1 · 中
- **目的**：歪头全由头部旋转承担会像贴纸转动、像脖子断了；把可见倾斜分给颈部剪切和上身（带滞后），读起来像有身体在动。
- **产出**：
  - 头部旋转角 = r_head × AngleZ 的满值角（r_head 0.4–0.6，给物理与表演留余量）；
  - 颈部 warp（轴 AngleZ，必要时其下再接 AngleX×AngleY）：上缘随头、下缘随躯干，剪切承担约 0.1；
  - 其余倾斜交给上身：`body.lean/c-arc-tilt`（几何直连）或 `physics.filter` 派生的身体 Z 参数（带滞后）；
  - 头部旋转原点随 AngleX/AngleY 键移动到“颈根点经头部 warp 求值后的位置”，转头加歪头时颈部连接不错位；
  - 可选：头发团整体滞后一层混合形状（绕头顶反向转 1–2% H，由物理输出驱动），加到各发组根 warp。
- **算法**：颈根点 = 下颌下方颈中线；对每个 AngleX×AngleY 键用 C4 求值得原点；全身站立且无身体参数时改用 `body.turn/head-driven`。
- **可调**：`headShare` r_head 0.5 [0.4, 0.6]；`neckShear` 0.1 [0.05, 0.15]；`hairLag` 1.5% H [1, 2]。
- **失败与质检**：追踪 AngleZ 同时直接转头又驱动上身会双重倾斜——三者之和应约等于原满值角；坐姿、半身模型只分到胸。
- **引擎能力**：C4；可选物理派生参数。
- **差距**：AngleZ 只驱动头部旋转；身体 Z 独立；支点固定。

#### `neck/collar-band` 环颈 / 环腰 / 环腕带状物的圆柱映射 · P1 · 中
- **目的**：项圈、腰带、手环在转身时应绕圆柱滑动（正面移动多、边缘压缩），饰件转到背面隐藏。
- **适用**：宽而薄、环绕颈 / 腰 / 腕的带状图层（标注，或几何判定横跨部位左右轮廓）。
- **产出**：带状 warp（2–3 行 × 12–20 列，沿带方向），轴 BodyAngleX（必要时 × BodyAngleY）；挂在带上的每个饰件各自一层 BodyAngleX 关键形；转到背面的饰件用不透明度或绘制顺序隐藏。
- **算法**：带上点归一化横坐标 u ∈ [−1, 1]，身体 X 满值时 u' = sin(asin(u) + Δ)，宽度 × cos；身体 Y 改变带的弧度（低头时成笑弧）；饰件按各自的圆柱位置偏移。
- **可调**：`delta` 满值 15° [10, 20]；圆柱半径 = 带半宽。
- **失败与质检**：饰件与带错位——饰件挂在带 warp 之下而不是并列。

#### `neck/cross-glue` 跨头身连接件与跨层级相邻件的自动缝合 · P1 · 中
- **目的**：横跨头与身体的物件（耳机线、围巾、项链、披肩发）应拉伸而不是断开；分属不同驱动链的相邻件（腰线上下、裙与腰、阴影叠层与基底）在交界处不开缝。
- **产出**：跨界图层在颈线处切成头段与身段（重叠 1–2 个网格单元，C8），各挂所属层级，接缝胶水（权重 0.5 或偏向较重一侧）；不同父链的相邻网格沿共享边界采样顶点对建胶水（对数 = 边界长 / 平均边长，下限 5）；同拓扑重复件（为绘制顺序或蒙版放在两处的同一部件）全顶点胶合；长缝只缝最外一圈边界顶点。
- **可调**：`boundaryDist` 0.5 平均边长 [0.3, 1]；`strength` 1 [0.5, 1]（软跟随饰物 0.5–0.8）；`overlapCells` 1–2。
- **失败与质检**：两侧网格密度差大时细侧被拉出尖角——先在边界重采样；强度 1 的长缝会把层间滞后平均掉一半——只缝边界；姿势切换会分开的部件在切换点把强度键到 0（目标不支持胶水关键形时避免跨组胶水）。

## 8. body.root（骨盆根链与站姿，补充插槽）

#### `body.root/current` 并列根 + 身体 X 带少量髋移 · 基线 · 已实现
- **现状**：`DeformLegs`（两骨 IK，脚在任何身体参数下不动）与 `DeformBodyXY` 是并列的根；身体 X 时骨盆刚体横移 `hipShift`，身体 Y 的下沉 / 上抬与转身绑在同一 warp；没有独立的髋部参数、全身倾、整体变换参数与默认站姿。

#### `body.root/pelvis-chain` 骨盆为根：整体变换 → 髋部 → 以脚为支点的全身倾 · P1 · 中
- **目的**：重心变化起于骨盆，脚是锚点；骨盆做成会动的根、腿做成反向旋转的子级，任何髋部动作都让脚留在地上。“上身侧弯”与“整个人绕脚歪”是两种倾斜，要分开。
- **适用**：全身站立（有腿与脚，或骨架腿）；下半身出画时把“脚不动”放宽为“膝不越出画布底边”。
- **产出**（根 → 叶）：
  - `ParamTotalX/Y`（平移）→ `ParamTotalZ`（绕画面底中点旋转）：只给动作用（跳跃、整体晃动），不接追踪；
  - `ParamHipY`（下沉 / 上提）→ `ParamHipX`（髋横移）；
  - `ParamBodyTilt`（以两脚中点或支撑脚为支点的全身倾）；
  - 其下分两支：上身支（现有 `DeformBodyXY` / lean / breath / Z）；腿支（每条腿一个以髋关节为原点的旋转，键 = HipX × BodyTilt [× HipY × BodyX]，角度由两骨 IK 在参数组合角点解出，使脚屏幕位置变化 < 2% H），其下腿 warp 做膝部弯曲与大腿根修形；
  - 物理组可把 HipX / HipY / BodyTilt / TotalY 作为输入（交 `physics.cascade`）。
- **算法**：
  1. 从分层或骨架取脚底锚点 F_L/F_R、髋关节 H_L/H_R、骨盆中心 P。
  2. 每个参数组合角点：父链变换后髋点 H′，大腿角 θ = ∠(F − H′) − ∠(F − H)；髋到脚距离变短时由腿 warp 屈膝（膝朝观众侧），变长时限幅（拉伸 ≤ 3%）。
  3. IK 非线性：在角点分别求解，建乘积关键形。
  4. 承重侧不对称见 `leg/weight-asymmetry`；悬挂物对 BodyTilt 做 `hair.strand/gravity-hold`。
- **可调**：`totalXY` 6% H [5, 7]；`totalZ` 10° [5, 12]；`hipShift` 5% H [3, 8]；`hipSink` 3% H [2, 4]；`tiltMax` 12° [8, 18]；`legCounter` 1.5 [1.2, 1.7]（腿反向角 / 全身倾角）。
- **失败与质检**：HipY 过大时膝弯超过 90° 画崩——限幅；长裙盖腿时裙跟骨盆走而不跟腿。
- **引擎能力**：C4；多维乘积键；骨架或推断的腿关节。
- **差距**：有两骨 IK 与身体 X 带髋移，但无独立髋参数、无以脚为支点的全身倾、无整体变换根。

#### `body.root/squat` 下蹲参数（IK 解烘焙进腿链） · P1 · 中
- **目的**：屈膝时只下移身体脚会穿地，只弯膝身体又不降低；一个参数同时驱动根下沉与两腿各关节，脚尖固定。
- **产出**：`ParamSquat` [−1, 1]（负 = 踮起），键 −1, 0, 0.5, 1；驱动根下沉 h = s·h_max 与每条腿髋 / 膝 / 踝关键形（与已有腿 FK 参数做 2D 组合）。
- **算法**：每个采样 s：根下移 h，对每条腿两骨 IK 使脚尖仍在 P，得 θ_hip、θ_knee、θ_ankle；膝角与 h 非线性（≈ arccos(1 − h/L)），至少补 s = 0.5 中间键；负向：根上移 0.01–0.02 H，踝绷直，膝伸直。
- **可调**：`squatDepth` h_max 6% H [4, 10]；`kneeDir`（朝观众 / 朝外）；`tiptoeRise` 1.5% H [1, 2]。
- **失败与质检**：脚尖偏离 < 0.002 H；与身体 Y 下沉同时使用时避免重复下沉。
- **差距**：身体 Y 向下“下沉、膝内扣”与转身绑在同一 warp，没有独立下蹲。

#### `body.root/rest-contrapposto` 非零默认值构成放松站姿 · P1 · 易
- **目的**：机械零点（对称制作、镜像关键形）与审美零点（放松的对立式站姿）分开；关键形仍按对称零点制作，站姿只靠默认值实现，换站姿只改默认值。
- **产出**：只改参数默认值（不改几何）：主导侧 s ∈ {−1, +1}（取原画头倾方向）；全身倾 = s·(0.15–0.25)·范围；髋横移 = −s·(0.15–0.25)·范围（移向支撑腿）；上身回倾 = 全身倾角的 40–60%（反向）；头倾与上身相反、为其 30–60%；支撑腿侧肩略低、另一侧耸肩 0.2–0.4。idle 围绕默认值摆动。另一用法：生成“展示姿势”作为 idle 常量或追踪偏置（头 X 8–15°、身体 X 与头同向约一半、单腿承重、前臂内收、放松手）。
- **可调**：`tilt` 3° [2, 5]；`upperBack` 0.5 [0.4, 0.6]；`headCounter` 0.45 [0.3, 0.6]；`hipShift` 1.5% H [1, 2]；`shrugDiff` 0.3 [0.2, 0.4]。
- **失败与质检**：脚不动、无穿插；裙摆与头发物理不应因默认偏置常驻偏移（以默认值为中心归一化）；直播用模型把展示姿势做成追踪偏置而不是动作。
- **差距**：标准参数默认全为 0，没有默认站姿概念。

## 9. body.turn（身体转向）

#### `body.turn/current` 椭圆截面躯干转向 · 基线 · 已实现
- **现状**：`DeformBodyXY`（12×14，BodyX×BodyY）：躯干椭圆截面绕中线转 `turnDegrees`，在胯下 `turnFade` 内渐隐，透视相机；躯干外侧点随轮廓平移；之后骨盆刚体横移 / 下沉。上半身作为整体转向，所有挂件同一深度，转向在胯部按空间衰减而不是时间滞后。

#### `body.turn/piece-depth` 挂件按躯干圆柱深度的逐件视差 · P1 · 中
- **目的**：躯干是圆柱，挂在上面的东西在不同深度（前面的饰带、侧面的翼、身后的衣片）；父 warp 只做整体转向，子 warp 叠加按深度的修正。身体前倾时头靠近镜头而变大。
- **产出**：每个身体件（颈饰、上衣前片、后衣片、侧翼、裙、饰带、袖）在身体 warp 下一层单轴 BodyAngleX warp；头部整体包在一个以 BodyAngleY 为轴的缩放旋转下（枢轴颈根）。
- **算法**：躯干半径 = 躯干半宽；件深度按绘制顺序与位置判前 / 侧 / 后；额外偏移 = (z_piece − z_body)·sin ψ·r，侧面件压缩或拉伸；头缩放 s = 1 + 0.1·(BodyY / 满值)。
- **可调**：`pieceParallax` 0.2 躯干半宽 [0.1, 0.3]；`headScale` 10% [8, 12]。
- **失败与质检**：大转角时前后件可能需换层——配 `body.turn/threshold-swap`。
- **差距**：上半身整体转；`BodyLean` 有透视缩放；缺逐件深度视差与身体 Y 头缩放。

#### `body.turn/lagged-layers` 上身 → 腰 → 胯 / 腿 → 裙的分层驱动结构 · P1 · 中
- **目的**：真人转身是“波”：躯干先动，骨盆、腿、衣摆依次跟上，骨盆还会反向扭一点（对立式）。每层需要自己的变形器与驱动参数，时间滞后由物理逐级低通得到（交 `physics.cascade`）。
- **产出**：
  - L0 上身（胸、肩、头）：现有身体 warp，读一级驱动参数；
  - L1 腰：覆盖腰带区的 2D warp（L1 参数 × 次级参数）；
  - L2 胯 / 腿：腿为独立根（不在上身 Z 之下），每条腿一个以髋为支点的旋转；下半身（骨盆、裙、尾根）旋转以“下半身扭转”参数为轴，方向与上身相反、幅度 0.4–0.7；
  - L3 裙摆 / 下垂物：读最近一层的驱动参数；
  - 层与层边界网格自动胶水（`neck/cross-glue`），腰线处加一个两轴都绑定的过渡 warp；
  - 臀部扭转关键形：骨盆区绕髋中心反向平移 3–4% H，一侧腿根抬高 1–2% H。
- **可调**：`levels` 4 [3, 5]；`lowerRatio` 0.5 [0.4, 0.7]；`levelDecay` 层间旋转幅值比 0.5 [0.4, 0.6]；`hipCounter` 20% [10, 30]。
- **失败与质检**：层间相位差大时腰线撕裂——胶水或锁定 L1 上缘；reflect 符号错时下层反向扭——正阶跃输入时各层输出同号（刻意反相除外）；脚贴地模型腿区横移过大像滑步。
- **差距**：转向在胯部按空间衰减，没有逐层时间滞后；腿与上身同步。

#### `body.turn/threshold-swap` 转身阈值处换层与替换画 · P1（换层）/ P2（替换画） · 中—难
- **目的**：身体转过约一半范围后遮挡关系改变（远侧手臂退到躯干后、胸部重叠翻转、袖与毛的前后）。
- **产出**：对每对重叠部件用粗 3D 代理（躯干圆柱、手臂在肩偏移处的圆柱）在采样偏航下算投影深度；顺序在 θ* 翻转时在 θ* ± δ 建绘制顺序紧邻键（只在翻转的一侧）；轮廓拓扑会变的部件（两胸重叠、领口侧面）在 |θ| > θ_alt 时换替换画，在 [θ_alt − δ, θ_alt] 内交叉。
- **可调**：`delta` 范围的 0.07 [0.05, 0.1]；`altThreshold` 0.45 范围 [0.4, 0.5]。
- **失败与质检**：替换画需素材或生成；两键之间绘制顺序整数插值不能跨无关层。

#### `body.turn/head-driven` 无身体参数时由头部角度分层驱动全身 · P1 · 中
- **目的**：只有面部追踪的宿主，不建身体参数、不加物理延迟，直接让全身根 warp 按头部角度做小幅、分层的形变：“歪头”自然变成“全身轻微侧倾 + 头再多歪一点”。
- **产出**：全身根链：AngleZ warp（全身，6–8×6）→ AngleY warp → AngleX warp → 极小 AngleX 旋转（±1°）；躯干支路 Breath → AngleY → AngleX；领口、颈前各一层 AngleZ；每条腿一层 AngleZ warp，在“朝该腿一侧倾斜”的半边加中间键（约 0.4 × 端点，膝略弯、髋略升）。
- **分配**：AngleZ：头部旋转 0.5 × 参数角，全身根 warp 让肩线倾 0.15–0.25 × 参数角，脚底固定（行权重从脚 0 到头 1）；AngleX：全身根只做 ≤ 0.03 H 横移与轻透视，躯干做胸部转向，头 warp 做主要转向；AngleY：躯干 ≤ 0.01 H 伸缩。
- **可调**：`headRollShare` 0.5 [0.4, 0.6]；`bodyTiltShare` 0.2 [0.15, 0.3]；`legMidKey` 0.4 [0.35, 0.5]。
- **失败与质检**：与“身随头物理”模式互斥，否则叠加过头；AngleZ 端点脚底位移 < 0.005 H；全身根 warp 太粗时裙摆出现折角。

#### `body.turn/performance-half` 表演型身体轴：一个半段内置小动作 · P2 · 难
- **目的**：同一参数不必是对称转身：在身体 X 一个半段叠加姿态片段（抬腿、踮脚、交叉腿），另一半保持标准转身，追踪中自然触发。
- **产出**：腿用髋旋转 + 膝 IK，负半段键：抬起腿膝弯 35–50°、脚离地 0.05–0.08 H、骨盆向支撑腿侧倾 3–5°，支撑腿伸直；腿网格对 BodyX × BodyZ × BodyY 做组合修正键（逐点 IK 精确计算）。
- **可调**：`side`（左 / 右 / 关）；`kneeBend` 40° [35, 50]；`footLift` 6% H [5, 8]。
- **失败与质检**：与“脚不动”约束冲突，作为显式选项；抬起的腿与另一条腿、尾巴的绘制顺序。

## 10. body.lean（身体 Z 侧倾与前后倾）

#### `body.lean/current` 前倾脊柱弧 + 单支点侧倾 · 基线 · 已实现
- **现状**：`DeformBodyLean`（前倾沿弧线弯脊柱，骨盆分担 `pelvisShare`，透视相机）；`DeformBodyZBreath`：身体 Z 让腰线以上绕腰倾斜，各行只平移、宽度不变，单支点。

#### `body.lean/two-joint-spine` 双关节脊柱侧弯 · **P0** · 易
- **目的**：单支点倾斜像一块木板；两个嵌套支点把弯曲分成一条弧（下段多、上段少），腰部接缝用同一参数的 warp 过渡，能做大幅而不僵硬的侧弯。
- **产出**：身体 Z 改为两级（嵌套旋转，或在现有 warp 点函数中按两支点生成行位移）：支点 1 = 腰部最窄行；支点 2 = 腰到肩线 40% 处（胸下）；角度分配下段 0.55–0.65、上段其余；腰臀网格放在一个 BodyZ warp 下：上缘行跟随支点 1、下缘行固定、中间 smoothstep 混合；裙与外套 warp 也键控同一参数；手臂、头继承；悬挂物加 `hair.strand/gravity-hold`。
- **可调**：`totalAngle` 满值总角（随风格 10–45°，默认沿用现有幅度设置）；`lowerShare` 0.6 [0.55, 0.65]；`chestPivot` 0.4 腰—肩 [0.3, 0.5]。
- **失败与质检**：总角大时“行只平移”会剪切变形——改为绕支点旋转；腰下撕开——裙与外套键控同一参数。
- **引擎能力**：旋转变形器或 `bodySecondaryWarpPoint` 改造。
- **差距**：现有身体 Z 单支点、行只平移。

#### `body.lean/c-arc-tilt` 头部 Z 驱动的上身 C 形弧侧倾 · P1 · 中
- **目的**：全身站立模型被追踪时，把歪头扩展成整个上身（连头、手臂、手持物、裙上部）的 C 形侧倾，脚不动。
- **产出**：上身侧倾 warp，放在身体 Z 之下、上身全部内容之上，约 20×20 覆盖上身包围盒，轴 AngleZ（或其派生参数），键间隔 ≤ 5°（C3）；腿不在其下。
- **算法**：以胯部中心为支点，高度 y 处转角 α(y) = θmax·((y_hip − y)/(y_hip − y_top))^β（越往上转得越多）；头部旋转原点按 `neck/tilt-share` 随转向移动。
- **可调**：`thetaMax` 7° [4, 10]；`beta` 1.4 [1.2, 1.6]；`pivotHeight`（胯 ↔ 腰）。
- **失败与质检**：坐姿或半身模型只到胸；与头部旋转同时满额会双重倾斜。

#### `body.lean/segmented-spine` 脊柱三段旋转链 + 全局 / 分段加法层 · P1 · 中
- **目的**：只用一个身体旋转时像纸片整体摇；骨盆 → 腰 → 胸三段嵌套、不同相位驱动，形成自下而上传递的 S 形摆动；base 角保留原画的对立式曲线。
- **产出**：三层嵌套旋转（枢轴：髋中点、腰线中点、胸线中点），base 角 = 原画脊柱折线段间角差；每层挂全局 lean 混合形状（三层同参数，角度按 1 : 1.2 : 1.4 分配）+ 该层专用混合形状（只影响本层及以上）；头链挂在胸层下，必要时加反向 roll 保持视线水平；需钉地的衣摆底行单独挂根。
- **可调**：`segments` 3 [2, 4]；`perSegAmp` 2° [1, 3]；待机相位差归 `motion.idle`。
- **失败与质检**：三层同时满值时上身倾角过大；底边需钉地时必须拆出。
- **引擎能力**：旋转变形器上的混合形状（角度加法）。

#### `body.lean/inertia-split` 侧倾分“直接层 + 惯性层” · P1 · 易
- **目的**：追踪输入没有惯性；把身体 Z 倾角拆为直接 warp（30–50%）与惯性旋转（其余，枢轴腰或胯），后者由物理输出驱动，整个人的倾斜有过冲和回落，所有子级物理在此基础上叠加。
- **产出**：身体根链：Breath → [BodyY 惯性 warp：上身下沉回弹，≤ 头高 10%] → BodyZ 直接 warp → [BodyZ 惯性旋转] → 身体 XY → 头。物理设计交 `physics.filter`。
- **可调**：`directShare` 0.4 [0.3, 0.5]；`pivotHeight`（腰 / 胯）。
- **失败与质检**：惯性过大像喝醉；动作已有缓入缓出时会二次延迟。

## 11. breath（呼吸）

#### `breath/current` 抬肩 + 胸口扩张 · 基线 · 已实现

- **可调**：`armOpen` 1.5° [1, 3]；`foreFollow` 0.4% [0.3, 0.5]。

- **差距**：呼吸只作用于肩、胸、头。

#### `breath/physics-only` 全身站立：呼吸主要经物理体现 · P1 · 易
- **目的**：全身站姿整体起伏易显得飘；呼吸作为胸、上衣、尾巴、饰物等物理的输入，躯干几何只保留很小的胸廓扩张；半身模型仍可直接抬肩。
- **产出**：有腿（全身站立）时 `breath/current` 的抬肩降到很小，`ParamBreath` 作为物理输入（权重分配交 `physics.excitation`）。
- **可调**：`standingLift` 0.3%（全身）/ 3%（半身）。

#### `breath/attachment-bob` 呼吸带动附着物起伏 · P1 · 易

## 12. arm（手臂）

#### `arm/current` 垂挂摆或骨架 FK · 基线 · 已实现
- **现状**：无骨架时 `DeformArmHang_L/R`（BodyX × BodyLean × Proportion，3×6；身体 X 时绕肩反向摆约 4°，先算目标画布位置再反求关键形）；有骨架时上臂为旋转变形器，以 Body X 抵消继承转角并加 `armSwing`；手臂与腿明确不进物理。

#### `arm/passive-chain` 被动下垂手臂链（肩 → 肘 → 腕 → 指） · **P0** · 中
- **目的**：面捕不追手时手臂是死的；放松下垂的手臂本就是一条摆链，身体一动手臂就晃，末端晃得最多。
- **适用**：下垂臂（肩—肘—腕接近竖直、手在肘下、主轴与竖直夹角 < 35°）；手持物或接触臂改用 `arm/contact-stabilized`；手臂设了姿势参数 / 动作时降权或关闭。
- **产出**：
  - 有骨架：肩、肘、腕三级旋转，每关节追加一个物理摆参数 `ParamArmSwing<Side>_k`，以**混合形状**（角度加法）或独立叠加旋转层挂上，不覆盖姿势与动作驱动的关节角；手指以最后一个输出做轻微张合（网格混合形状或每指一个小 warp）。
  - 无骨架：在现有 `DeformArmHang_*` 之下加 3 层嵌套混合形状 warp：上臂层（绕肩摆 4–6°）、前臂层（肘外弯约 3°）、手层（腕滞后约 5°），不切网格、无接缝。
  - 关节角度区间不对称：朝身体方向的限位 = 外展方向的 0.35–0.65（肩约 0.35、肘约 0.65、腕接近对称）。
  - 物理：一条链按关节顺序取连续质点，scale 根→梢递增（约 1 : 1.2 : 1.5 : 2，交 `physics.chain`）；左右手各一组，输入一侧取反（避免像拍翅膀）。
- **算法**：向内最大角由“手臂与躯干轮廓的最小间隙”求（通常 3–8°），向外 15–20°；手指静止弯度错开成梯度，各指幅度 = 基础 × (1 + 0.3k)（k 从食指到小指）。
- **可调**：`shoulderOut` 15° [10, 20]；`innerRatio` 0.5 [0.35, 0.65]；`elbow` ±15° [10, 20]；`wrist` ±10° [8, 12]；`fingerFan` 0.3。
- **失败与质检**：身体大幅前倾时摆锤重力方向不变，手臂往后漂——输入加身体 Y；摆动与动作打架——物理参数与姿势参数分开（2D 键或混合形状）；手位移在 3–10% H 以内。
- **引擎能力**：旋转变形器上的混合形状；多输出物理；骨架关节。
- **差距**：`skeletonRules` 明确让手臂不进物理；`DeformArmHang` 只是静态关键形。

#### `arm/outside-chain` 手臂作为躯干 warp 之外的旋转链 · P1 · 中
- **目的**：手臂放在躯干 warp 里转身时会被拉伸，大角度形变失控；独立旋转链只在肩点“读取”躯干位置。
- **产出**：肩点旋转 R_S（原点 S，键 = 身体 X×Y[× 耸肩]：原点平移到躯干 warp 求值的 S(key)，角度取躯干在 S 处局部转角的 0.1–0.3 倍）→ 上臂旋转 R_U → 上臂缩短 warp（0…1：+1 沿轴压到 75–85%、末端略加宽；−0.5 拉长到 105–110%）→ 前臂旋转 R_F（原点 E）→ 前臂缩短 warp → 前臂修形 warp → 腕旋转 R_W → 手；肩部修形 warp（键 = 上臂角）：抬臂时肩头轮廓上提、腋下收窄，位移 ∝ sin(角)。身体 Z 需单独给肩点加旋转。
- **可调**：`upperRange` −35…+50°；`shorten` 0.8 [0.75, 0.85]；`shoulderFollow` 0.2 [0.1, 0.3]。
- **失败与质检**：身体 Y 大角度时肩线与上臂根出缝——肩头修形层盖住，或上臂根画在躯干之下。

#### `arm/wide-fk-corrective` 大范围手臂 FK + 按角度采样的修形 · P2 · 难
- **目的**：举手、捂脸、托腮、叉腰、绕到脑后都用一个手臂网格完成；前臂可整圈转，动作用最短路径插值。
- **产出**：上臂旋转（参数即角度，约 −160…+30°，默认 = 原画姿势）+ 肩部修形 warp（上臂角 × 身体 X，在 0、25%、50%、100% 键；> 60% 时腋下遮挡层淡出）+ 上臂长度缩放 0.9–1；前臂旋转 0…360（0 与 360 键形相同，保证循环）+ 修形 warp（常用区 0–90°、270–360° 每 15°，其余每 30°；或统一每 45°）；肘帽小网格每 90° 一键，转动量为前臂角一半；肘窝折痕块 |θ| < 45° 不透明度 0、≥ 90° 为 1（不要缩放到 0）；腕、肘各加一个小幅平移的“接触补正”参数（±0.01 H）。
- **修形关键形**：两段刚体变换按以肘为中心、宽 0.3 前臂长的 smoothstep 混合，再保体积：外侧沿法向外推 r·(1 − cos(θ/2))·0.5，内侧内收一半；或用 ARAP 拟合使前臂近端覆盖以肘为心、半径 0.5–0.6 臂宽的肘帽圆。
- **可调**：`keyStepCommon` 15°；`keyStepRare` 30°；`volumeKeep` 0.5 [0.3, 0.7]；`creaseAngle` 60° [45, 90]；`perspScale` ±20% [15, 25]。
- **失败与质检**：以 5° 步长扫描，肘部缝隙面积与前臂长度变化 < 5%；手越过身体时配 `arm/depth-level`。

#### `arm/joint-mask` 关节裁切四边形 · P2 · 中
- **目的**：前臂转动时上臂远端与袖口会从关节另一侧露出；一个随前臂角度变换的 4 顶点隐形网格充当动态切线。
- **产出**：父段肢体变形器下建 4 顶点隐形网格，一条边过关节中心、方向垂直于父段与子段方向的角平分线，覆盖父段一侧半平面（边长 ≥ 2 倍肢宽）；每 90° 子段角一键（屈曲 > 120° 加密到 45°）；作为父段远端与关节附近重叠网格的蒙版。适用于肘、膝、腕。
- **可调**：`quadSize` 2.5 肢宽 [2, 3]；`keyStep` 90° [45, 90]。

#### `arm/contact-stabilized` 举起 / 接触臂：末端稳定 · P1 · 中
- **目的**：手放在胸前捏东西时身体一晃上臂被带动，但手应基本留在原处；手指与被捏物用同一参数共键，接触点在插值中不漂。
- **产出**：上臂同号（读质点 2），前臂反号（质点 3，scale ≈ s·L_upper/L_fore），手反号（质点 4，略大）；关节处胶水防反向转露缝；手动角度范围按关节活动度（上臂 ±20°、前臂 ±40°、手 ±30°），物理只用其 20–30%。接触对：一个交互参数同时绑定手指网格与被握物网格，被握物在接触半径 r_c 内跟随指尖位移（权重平滑衰减），按两者轨迹差 < 0.02 heye 自适应加键。
- **可调**：`counterRatio` 0.8 [0.6, 1]；`contactRadius` 0.45 heye [0.3, 0.6]；`endDispRatio` < 0.3。
- **失败与质检**：身体 Z 满幅时手中心位移应 < 0.3 倍上臂端点位移；反相过大时手向反方向甩；被握物另一端固定在身体时只让接触附近一小段跟手。

#### `arm/depth-level` 手臂组绘制顺序 level 参数 · P1 · 中
- **目的**：手从身前划到身后、叉腰、抱臂时的穿插，用一个连续 level 参数描述，组内相对顺序（手指永远在手掌之上）不变。
- **产出**：每组（手臂 L/R，也用于翅膀、道具、子角色）一个 `Param<Group>Level`，范围 = [栈中最低可插入位置, 栈顶]，默认 = 原画位置；组内每个网格绘制顺序 = level + δ_i（δ 按组内排名 × 小步长，端点外扩 |δ_i| 防截断）；简化形态：上臂、前臂加手两个三值阶跃参数（身后 / 默认 / 身前）。
- **可调**：`levelStep` 栈间距 0.25–0.5；`innerStep` 0.01–0.05。
- **失败与质检**：两网格绘制顺序相等时抖动——δ 错开、相邻非组网格留间隙；带蒙版的组蒙版网格一起移动；目标支持部件级绘制顺序时优先放在部件上。

#### `arm/pose-branches` 同一肢体的多姿势绘制分支 · P2 · 难
- **目的**：前臂大角度转动时透视与手形都变，单张画硬变形会扭曲；抱臂、握拳举手、持乐器、挥手等大姿势用专用画，过渡不出现半透明重影。
- **产出**：肩点共享根旋转（耸肩、呼吸 × 姿势、身体 X/Y 补偿、摆臂），其下每个姿势一个分支容器（旋转，原点肩，不透明度由姿势参数驱动），分支内 FK 链与分支专属微调参数（±10–20°）；次级物理（袖、腕带）的同一输出在每个分支对应部件上都绑定（键值按该姿势下主轴方向重投影）。单滑杆两段式：P ∈ [0, s] 默认画 FK 转到交接姿态 Ph，目标画反形变到 Ph 保持（不可见），s → s + ε 硬切，[s + ε, 1] 目标画从 Ph 形变回原姿，后段加 1–2 个中间键；交接姿态取两画轮廓差（alpha IoU / Chamfer）最小的比例。跨深度的肢体后片放进躯干部件，在另一条链里用同参数复现运动；露出的躯干区生成补丁层。只换远端段时，默认段不透明度在所有开关参数网格上“全 0 处为 1”。
- **可调**：`handoff` s 0.5 [0.4, 0.6]；`eps` 0.01 [≤ 0.02]；`alignTol` 3% 肢体面积。
- **失败与质检**：渲染 P = s 与 s + ε 两帧，肢体 alpha 差异面积 < 3%；两画拆分不一致时先统一部件；姿势互斥由生成器输出约束或优先级。

#### `arm/hidden-hand-peek` 背在身后的手，摆动时探出 · P2 · 中
- **目的**：完全静止的背手像被焊死；身体晃动时偶尔露出一点手指，暗示结构和重量。
- **产出**：被遮挡的肢体末端包两层 warp：A 手绕肩肘方向外摆，露出量为手长 0.3–0.5；B 手腕翻转与手指张合；绘制顺序在身体、头发之后，探出部分被轮廓自然遮住；左右手一侧纵向取反。
- **失败与质检**：原画须画出完整的被遮挡手；露出太多破坏背手设定。

## 13. hand（手）

#### `hand/current` 手是手臂末端的一块网格 · 基线
- **现状**：无手部生成；骨架可手工建手指链，没有分节规则、手指参数与手势库。

#### `hand/finger-chain` 手指三节链：握合 × 张开 · P1 · 中
- **目的**：两个参数覆盖“握 ↔ 张”与“并拢 ↔ 分开”；握拳时指尖走螺线，而不是绕指根的圆弧。
- **适用**：手指已分层（每指一条或已切节），或整手网格 + 关键点自动切段（需手部分割）。
- **产出**：每指三节嵌套旋转（原点 MCP、PIP、DIP，按指长 0.45 : 0.30 : 0.25 切），拇指两节；参数 `ParamFingerCurl<Side>`（−1 握紧 … +1 原画形）、`ParamFingerSpread<Side>`（只作用于近节，按相对中指方位角 ±5–15°，拇指 ±20°），2D 3×3 键；关节胶水取 1–2 对最近顶点；指甲、关节皱纹以所在指节为蒙版；戒指等附着物挂对应指节旋转下；手指弯过约 120° 时远节绘制顺序降到掌后。
- **算法**：
  1. 全握角：近节约 60°（ease-out）、中节 90–100°（线性）、远节约 70°（ease-in）；c = 0.5 时约为满值的 (0.7, 0.5, 0.3)；键 c ∈ {−1, −0.5, 0, 0.5, 1}。
  2. 小指到食指握紧角依次递减 10–15%（尺侧握得更紧）。
  3. 视角修正：手指平面与画面夹角 φ 大（侧视）时以角度表现屈曲；φ 小（正视指背）时改为沿轴缩短，角度系数 × sin φ、长度 × cos φ。
  4. 弯曲时外侧指节凸起 0.1 指宽（关节 warp）。
- **可调**：`curlMax` (60°, 95°, 70°)，各 [(55, 65), (80, 110), (60, 80)]；`easeExp` 2 [1.5, 2.5]；`spread` 10° [5, 15]；`ulnarExtra` 12% [10, 15]。
- **失败与质检**：正视掌心的手无法靠旋转表达屈曲——换手势；半屈不加中间键会“缩短穿模”。
- **引擎能力**：嵌套旋转；关节胶水；蒙版；绘制顺序关键形。

#### `hand/gesture-library` 手势库：整数姿势切换多套手绘，共享手指参数 · P2 · 难
- **目的**：张开、放松、指、握持、拳、剪刀手、托腮等无法靠一张画变形得到；手势参数“换画”，手指参数“在这张画上动手指”，两者正交。
- **产出**：`ParamHandPose<Side>` ∈ [0, K−1]（默认 = 原画手势）；每套手绘一个不透明度组容器（在 [k − 0.5 + ε, k + 0.5] 可见，两侧 0.05–0.15 交叉带或紧邻键阶跃），全部挂在同一腕旋转下（按腕点与掌方向求刚体变换写入容器基角与缩放）；每套内手指链复用 `hand/finger-chain`，键 = 手指参数 × 该手势区间端点；手掌 warp 只键手势；过渡带两端把两套手指角度调到指尖包络最接近处。动作中的阶跃切换放在腕角速度最大的帧。
- **可调**：`K` 4 [3, 7]；`band` 0.1 [0.05, 0.15]；切换方式（阶跃 / 2–4 帧淡化）。
- **失败与质检**：同一时刻 Σ opacity ≤ 1；手势区间外的手指关键形仍须合理。

#### `hand/palm-flip` 掌面 / 手背翻转 · P2 · 研究
- **目的**：转腕（掌心朝前 → 侧掌 → 手背朝前）用一个连续参数完成。
- **产出**：`ParamHandFlip` θ ∈ [−180, 180]（默认 = 原画视图）；每个视图负责一段区间，边界（±90°）处该视图关键形把手宽压到侧立宽约 0.25 手宽（桥形，两侧几何相同），用相距约 0.1° 的两个键做不透明度阶跃；手指每关节角以“开合 × θ”2D 网格（θ ∈ {−180, −90+ε, 0, 90+ε, 180}），面内弯角 α·|cos θ_rel|，朝向观众的分量用节段缩放 1 − k·|sin θ_rel|·c；越过侧视点时手指旋转角以 ±360 换向（极近的重合键）避免绕远路；指根位置随 θ 沿掌宽重排。
- **可调**：`edgeWidth` 0.25 手宽 [0.2, 0.3]；`eps` 0.1°；`views` 2 或 4。
- **失败与质检**：至少需要掌、背两张视图素材；透视投影角与轴心重排依赖求值器。

## 14. leg（腿）

#### `leg/current` 两骨 IK，脚不动 · 基线 · 已实现
- **现状**：`DeformLegs`（8 × 10–20，BodyX×BodyY×Proportion 27 键）：骨盆刚体 + 每条腿两骨 IK，膝朝观众方向弯并按 `kneeIn` 内扣，脚固定；骨架腿下有站姿 warp 承接；左右腿对称跟随。

#### `leg/weight-asymmetry` 承重腿不对称（对立式重心） · **P0** · 易
- **目的**：站立角色侧倾或髋移时承重腿伸直、另一条腿微屈，脚仍钉在地上；对称跟随看起来像两根柱子。
- **产出**：在现有腿 IK 关键形上加不对称：倾斜 / 髋移朝向的一侧为承重腿（伸直、略外推，角度 a_near），另一侧屈膝（a_far = 0.3–0.5 a_near）并髋略升；镜像腿互换；无身体参数模式下在每条腿的 AngleZ warp“朝该腿一侧”半边加中间键（约 0.4 × 端点）；腿随上身倾斜的跟随比 0.3–0.6。
- **算法**：对 BodyX、BodyZ（或全身倾）的每个端点键，按承重侧设定目标膝角与髋高，再用两骨 IK 求脚不动的解；中间键处单独求解（非线性）。
- **可调**：`asymRatio` 0.4 [0.3, 0.5]；`followUpper` 0.45 [0.3, 0.6]；`maxLegAngle` 3° [2, 4]；`midKey` 0.4 [0.35, 0.5]。
- **失败与质检**：比值过大像跛；端点脚底位移 < 0.005 H。
- **引擎能力**：现有 `BodyStance` 两骨 IK。
- **差距**：腿在身体参数下对称、只屈膝不分承重。

#### `leg/front-back-level` 哪条腿在前的层级参数 · P1 · 易
- **目的**：交叉腿、迈步、踢腿时两腿前后关系改变。
- **产出**：腿组绘制顺序阶跃参数（或与 `arm/depth-level` 同构的 level 参数），两腿交叉时切换。

#### `leg/fk-corrective` 腿三级 FK 骨架 + 逐级修形 · P2 · 难
- **目的**：踢腿、劈叉、勾绷脚这类 90° 以上的动作必须用旋转链；旋转管姿态，修形 warp 管皮肉，两者分开。
- **产出**：髋 R(θ_hip) → 膝 R(θ_knee) → 踝 R(θ_ankle)，原点在三个关节点；参数映射按人体活动度不对称（髋前踢大、后撤小，膝只朝一侧弯并给小量反弯，踝约 ±90°）；每个旋转下挂网格专属修形 warp（大腿约 13×6、小腿 20×5、脚 10×6），轴 = 该关节参数（再与相邻关节参数做 2D）；修形键取在 25%、75%（曲率变化最大处）与 100%：外侧轮廓按圆弧填充（半径 = 关节处肢宽 0.5），内侧压缩并略外鼓；髋加 ±0.03 H 平移修正（踢腿 > 90° 时髋点上移外移）；俯仰用节段缩放（±15–30%）表现透视。
- **可调**：关节范围（相对人体活动度）；修形中间键 20–35% / 65–80%。
- **失败与质检**：屈膝 > 90° 时小腿要画在大腿前——绘制顺序键或复制件。

#### `leg/view-swap` 按旋转方向符号瞬切的成对视图 · P2 · 中
- **目的**：脚从正面转到侧面，形状差异大到无法变形得到；交叉淡化会出现两只半透明的脚。同一机制适用于手、翅膀、鞋。
- **产出**：参数 p ∈ [−1, 1]，正面画 F 负责 [−1, 0]、侧面画 S 负责 [0, 1]；两画在 p = 0 处都变形到中间形（关键点平均位置，TPS / ARAP）；不透明度 F {−1:1, 0:1, +ε:0}、S {−ε:0, 0:1, 1:1}；阴影、绑带等细节层按 0 → 0.5 → 1 半程线性淡化。
- **可调**：`eps` 极小；`bridge` 中间形偏向 0.5 [0.3, 0.7]。
- **失败与质检**：p = ±ε 两侧渲染差异图，轮廓差 < 1 px。

#### `leg/shoe-proxy` 鞋的分件三轴近似三维 · P2 · 研究
- **目的**：全身主播的踮脚、脚尖朝外、露出鞋底。
- **产出**：鞋拆成鞋底、侧面、鞋面、鞋跟、鞋带；构造代理三维鞋（轮廓拉伸，高 0.3–0.4 鞋长，正交投影），按（偏航、俯仰、腿视角）3×3×3 组合求代理顶点并拟合各 warp 控制点；各面可见性按法线与视线点积符号决定（阶跃或背面剔除）；鞋带端点单对胶水钉在鞋面孔位上。

#### `leg/gait-rig` 原地行走的腿部结构 · P2 · 难
- **目的**：给虚拟主播一个“在走”的待机。

## 15. chest（胸部）

#### `chest/current` 只有呼吸扩张 · 基线

#### `chest/nested-bounce` 胸部分级嵌套 warp 多相弹跳 · P1 · 中
- **目的**：软组织运动是外层整体移动 + 内层更晚相位的颤动；交替符号让各层反向，形成“晃”而不是平移；盖在胸上的衣物、缎带、饰物一起动。
- **适用**：有胸部区域（语义标注或由上衣轮廓与肩线估计两侧胸心与半径）。
- **产出**：
  - L0 区域 warp（双侧，较密，约 26×26–30×40），可放在裙物理层之内、各件身体 X 修形之外，包住整个前身（饰带、侧翼、裙上部、上身）；

  - 物理参数：纵向组 Y1/Y2/Y3、横向组 X1/X2/X3（读质点 1/2/3，横向第 2、3 输出取反），交 `physics.chain`；

  - 两份胸面挂在通道子集不同的 warp 下并全顶点胶合（形变平均、线稿与填色不分离）；衣扣等细节放 L2 下或胶在胸面；

- **可调**：`ampX` 1.5% H [1, 2]；`ampY` 1.8% H [1.5, 2]；`sigma` 0.55 胸宽 [0.5, 0.7]；`clothFollow` 0.8 [0.6, 1]；`outerFollow` 0.45 [0.3, 0.6]。

- **引擎能力**：嵌套 warp、C5、C6（全顶点胶合）。
- **差距**：无胸部物理模板。

## 16. skirt（裙）

#### `skirt/current` 随身体 warp + 可选布料模拟 / 摆动 · 基线 · 已实现
- **现状**：裙挂在 `DeformBodyXY` / breath 下随身体关键形；可由模型预设“衣物模拟”烘焙（按名字或剪影分裙 / 裤）或 `SwingPreset.CLOTH` 单一摆动；没有层深度概念，内外层同幅、同相。

#### `skirt/layer-gradient` 多层裙按内外顺序的幅度梯度 + 双模态 · **P0** · 中
- **目的**：外层先被带动、内层隔着外层慢半拍且幅度小；轻薄层（纱、蕾丝）更飘；左右摆与上下弹是两种模态。
- **适用**：裙部件 ≥ 1 层；腿独立（腿与鞋不进裙摆层）。
- **产出**：
  - 按绘制深度排序裙层 ℓ = 0（最外）… L−1（衬裙 / 后片）；
  - 裙组变形栈：先 Y 模态（下摆竖直拉伸 / 压缩 + 张开 / 收拢）再 X 模态（下摆横向保长摆动），各 2–3 层嵌套（`hair.front/nested-warp-chain` 的裙版本：腰线固定、下摆自由，幅度随到腰距离平方递增）；
  - 每层幅度系数：最外层 1.0，最内层 0.15–0.3，线性插值；轻薄层再 ×1.5–2；
  - 物理输出按层深读质点：层 ℓ 的主驱动质点 = 1 + ℓ·(N−1)/(L−1)（外层读浅质点、内层读深质点），层数多于质点时相邻层共享并按 0.5 混合（链与输入交 `physics.chain`）；
  - 另加 Z（下摆沿径向外张，模拟旋起）可选通道。
- **算法**：X：以腰线为轴的横摆，下摆最大、腰线为 0；Y：下摆整体上提并略缩短；Z：径向外张。幅度：X 1–2% H，Y 2.5–4.5% H，Z 2–4% H（相对腰到下摆距离约 6–12%）。
- **可调**：`innerAmp` 0.25 [0.15, 0.3]；`sheerMul` 1.7 [1.5, 2]；`xAmp` 1.5% H [0.8, 2]；`yToX` 2 [1, 3]；`zEnable` false。
- **失败与质检**：内层位移大于外层会从外层下沿露出——内层 X 幅度 ≤ 外层，或以外层轮廓为蒙版；上弹不能露出腿根。
- **引擎能力**：嵌套 warp；多输出物理；可选 C5。
- **差距**：裙子只跟随身体关键形或单一摆动 / 模拟；没有层深度幅度梯度与双模态默认。

#### `skirt/depth-gradient-nest` 同一链多深度 → 多层 warp 的位移梯度（悬挂树） · P1 · 中
- **目的**：裙片先被腰整片带着平移，再中段鼓起，最后下摆甩出；挂在裙摆下的飘带只在第三层得到额外甩尾；相连衣物共用同一物理 warp 不撕开。
- **产出**：
  - 悬挂树：每个悬垂部件求挂点深度（腰 → 裙身 → 裙摆下的飘带 / 流苏）；第 k 个物理输出驱动一个包住所有深度 ≥ k 部件的 warp（集合逐级缩小，嵌套）；
  - 典型三层：W1（P1 × P2，整片）→ W2（P3，中段与下摆）→ 外层附加 W3（P3 × P2，只含外层下摆网格，幅度为 W2 的 0.3–0.5）；
  - 关键形：P1 整片平移 ±0.03 H（权重腰 0.6 → 下摆 1）；P2 以腰线为轴弯曲（腰 0 → 下摆 1，线性）；P3 下摆甩动（权重 s²）；挂线以上严格 0 位移；
  - 层级顺序：胯 warp（身体 X × 胯参数）在外 → 物理层 → 胸部层 → 各件身体 X 修正在最内。
- **可调**：层数 3 [2, 4]；层幅度比 1 : 0.6 : 0.35；`outerBoost` 0.4 [0.3, 0.5]；衰减过渡 0.15 Hh [0.1, 0.2]。
- **失败与质检**：P1 满幅时各网格位移变异系数 < 0.15；P3 满幅时下摆与腰的位移比 > 4；悬挂树错（飘带当裙身）时末端甩不起来；嵌套超过 3 层时把 W3 并入 W2。

#### `skirt/axis-channels` 按运动轴拆分的裙摆通道叠加 · P1 · 中
- **目的**：裙对转身（横摆）、起伏（掀起外张）、倾斜（持续偏）、急停（弹跳）、扭转的反应不同；每个通道一个参数组，在同一 warp 或逐层 warp 上加法叠加，不相乘。
- **产出**：前 / 后裙各一个密 warp（沿长约 30 行、沿宽约 40 列）或每轴一层 warp（顺序：Lift → Twist → Sway → 整体扭，腰线固定）；通道：横摆（3 输出，符号 +、−、−，增益 1、0.6、0.4，形成沿裙摆的 S 波）、掀起外张（2 输出，裙摆加宽上提）、倾斜（1 输出，绕腰刚性倾）、弹跳（2 输出，纵向挤压拉伸）、扭转（可选）；纵向弹跳层可与 AngleX / BodyX 做 2D 键使弹跳方向随朝向；外裙挂全部通道，衬裙只挂扭转 + 横摆；裙上挂件（链、腰带）把同样通道作为旋转的角度混合形状。物理组拆分交 `physics.chain`。
- **可调**：各通道最大裙摆位移 3–7% H；内层继承比例；前后比例。
- **失败与质检**：多通道同时满值越界——组合极值检测与限幅；不支持混合形状的目标降级为每通道一层嵌套 warp。

#### `skirt/panel-glue` 分片独立运动 + 接缝胶水 · P1 · 中
- **目的**：左右前片、前后片、竖向分段各自摆动，接缝处是两侧运动的平均，不开不交叉；比整件一个大网格（只能对称摆）更生动。
- **产出**：
  - 横向分片：沿共享边两侧各切一条窄带网格（宽 0.02–0.04 H），留在各自的 warp 分支下，配对胶水（强度 1，或边中心 1 → 两端 0.5）；左右片物理输入镜像（交 `physics.*`）；
  - 竖向分段：每片在 1/3、2/3 长度（或褶线）处横切，接缝留重叠行并胶水；第 k 段关键形键控本段输出（绕上缘接缝旋转 a_k 并加切变，越近下摆越呈扇形），最下段用 (s_(k−1) × s_k) 3×3 乘积键；两侧链参数各自抖动 ±10–25%（打破镜像同步）。
- **可调**：`seamBand` 0.03 H [0.02, 0.04]；`glueStrength` 1 [0.5, 1]；`segments` 2–3；`segAngle` 10° [6, 15]；`sideDetune` 15% [10, 25]。
- **失败与质检**：两片参数取相反极值时接缝顶点间距 < 0.005 H；胶水对配对点 UV 一致性要求高，切缝处保留一圈重叠；两侧运动差过大时窄带被剪切——加宽窄带或降低两侧在接缝附近的权重。
- **引擎能力**：C6；C8。
- **差距**：Glue 工具已有，但生成器不在布片接缝自动切窄带建胶水；裙子物理不分左右片。

#### `skirt/root-drape` 长后摆 / 披风挂根级，身体 Z 只经物理影响 · P1 · 中
- **目的**：从腰垂到膝下的长纱、长裙后摆、披风如果跟着身体 Z 刚性旋转，下摆横扫很远，像硬板；挂到根级（与腿同级），身体 Z 只通过物理让它滞后摆回。
- **适用**：长度 > 0.25 H 的下垂布片。
- **产出**：布片挂在根级（不在身体 Z 旋转之下）；上缘承接 warp 以上身侧倾参数和身体 X/Y 为轴，只移动上缘附近（权重从上缘 1 衰减到 0.3 H 处 0），让上缘跟随腰线；摆动层二级输出，第二级 5–13 键弧线；左右两片输入取反形成对称开合。
- **可调**：`followFade` 0.3 H [0.2, 0.4]；`secondKeys` 9 [5, 13]。
- **失败与质检**：身体 Z 满幅时上缘与腰脱开——承接 warp 补 BodyZ 键，或胶水粘住上缘。
- **差距**：`DeformBodyXY` 覆盖裙子，长后摆也在身体 Z / 呼吸之下。

#### `skirt/pleat-thigh` 分片褶的振幅梯度 + 大腿顶起裙摆 · P2 · 难
- **目的**：抬腿把裙子顶起来；各片振幅分级、两个相位不同的模态组合形成沿裙边传播的波。

## 17. cloth（袖、披风、围裙等布料）

#### `cloth/current` 布料模拟预设与单一摆动 · 基线 · 已实现
- **现状**：模型预设“衣物”按 Wear 分到上衣 / 领饰 / 袖 / 腿饰模拟并烘焙；或 `SwingPreset.CLOTH` 单层摆动；没有空间分层的嵌套摆与硬质附件规则。

#### `cloth/nested-arc-drape` 宽大垂落布料：同尺寸嵌套 warp 链 + 空间分层 · P1 · 中
- **目的**：振袖、泡泡袖、披风、围裙是“片”不是“条”：外层整体像钟摆有分量，内层只对下部更大弯曲，袖口花边再有细碎余韵。
- **产出**：在布料包围盒上建 W0（行数 ≈ 长宽比 × 10–14，挂在臂旋转或身体下）；K 层子 warp（同包围盒同分辨率，或按空间区域逐级缩小：整体 → 下半 → 袖口 / 下摆 → 花边），层 k 只弯 v ≥ v_k = k/(K+1)（v 为从附着线到下摆的归一化距离）；第 i 层读物理质点 i+1，scale 随层增大（链交 `physics.*`）。
- **算法**：层 k 把行当作链节，从 v_k 行开始逐行累积旋转 α_i = θ·smoothstep((v − v_k)/(1 − v_k))，旋转中心为上一行中点；θ 从 −θmax 到 +θmax 采样 9–13 键（C3）；花边层：相邻褶交替法向位移 0.05 布长，褶数不变。
- **可调**：`layers` K 3 [2, 4]；`thetaMax` 28° [20, 35]；`laceWave` 0.05 布长；`res` ≥ 10×8（内层）。
- **失败与质检**：外层大幅旋转时内层格子跟着变形——内层格子足够密；摆到端点时袖子被拉长——弧线键。

#### `cloth/rigid-hardware` 硬质饰物钉在可形变布料上 · P1 · 易
- **目的**：纽扣、徽章、铆钉、金属扣直接放在布料 warp 里会随褶皱剪切变形；放在旋转变形器下，布料只移动它的原点，硬件保持刚性。
- **适用**：面积 < 所在布料 1%、轮廓与布料分离、颜色对比强的小件（或标注为硬件）。
- **产出**：每个硬件一个旋转变形器（原点 = 硬件中心，挂在布料最内层 warp 下；角度键 0，或取布料局部旋转的 0–50%）→ 3×3–5×5 小 warp（键 BodyAngleX：转离观众一侧水平压缩 5–15%）→ 网格（12–20 顶点）。
- **可调**：`rotFollow` 0.25 [0, 0.5]；`perspCompress` 10% [5, 15]；`meshVerts` 16 [12, 20]。
- **失败与质检**：硬件跟布料脱开——原点必须在布料 warp 中求值（C4）。
- **差距**：布料上的部件随身体 warp 一起形变。

#### `cloth/sleeve-cylinder` 袖子作为独立圆柱：摆动、俯仰、扭转 · P2 · 中
- **目的**：宽松袖相对手臂的摆、俯仰、扭转显出布料独立性；扭转时袖面扣子、条纹沿圆柱滑动。
- **产出**：袖子图层与手臂分开，生成“联动旋转”（支点与角度关键形逐键复制前臂旋转，作者态记录联动、重放时重新复制）→ 摆动 SleeveZ（绕袖上沿 ±8°）→ 俯仰 SleeveY（开口椭圆短轴变化、露出内衬）→ 扭转 SleeveX：特征点 θ0 = asin((x − c)/r)，扭转 Δθ 后 x' = c + r·sin(θ0 + Δθ)，宽度 × cos(θ0 + Δθ)，cos < 0 时淡出；默认值取画中扭转状态（不一定是 0）。
- **可调**：`twistMax` 75° [60, 90]；`swing` 8° [6, 10]。

## 18. ribbon（飘带、缎带、蝴蝶结、纱）

#### `ribbon/current` 摆动预设 ACCESSORY / HAIR · 基线 · 已实现
- **现状**：缎带当作头发或配件，用 `SwingDeformer` 单 warp 分段摆动；不区分结体与飘带，没有链、没有成对开合。

#### `ribbon/frame-aligned-hang` 框架对齐静态旋转 + 驱动旋转 + 级联 warp · **P0** · 易
- **目的**：先用一个静态旋转把局部坐标对齐到饰物静息方向，之后驱动旋转的 ±θ 就是“垂直于饰物的摆”，下面 warp 的行也沿饰物长度排列，关键形好算、好镜像。
- **适用**：小悬挂物（尾带、挂饰、十字坠、流苏）；长宽比 > 3 时加级联 warp；很小（< 0.05% 人物面积）时用 4 顶点四边形。
- **产出**：静态旋转（原点 = 挂点，角 = atan2(主方向)，无参数；缩放补偿按父空间计算，不硬编码）→ 驱动旋转（参数取所在区域的“挂饰摆”输出，±20–30°）→ [长宽比 > 3] 级联 2–4 个 warp（沿长轴分行，分别以物理 v2…v4 为轴表达逐级弯折，最后两个以 v1/v2 做纵横伸缩 ±5%）→ 网格。同一载体上的同类小挂饰共用参数，按挂点 x 坐标给 ±10% scale 差或在 2–3 个参数间轮换。
- **可调**：`swing` 25° [15, 35]；`cascade` 0–4；`stretch` 5%；`sharedGroups` 2 [1, 3]；`quadArea` 0.05% 人物面积。
- **失败与质检**：共用参数完全同相显得机械——scale 差或轮换；静态旋转的缩放补偿须按父空间计算。
- **引擎能力**：旋转变形器（无参数静态层）、级联 warp。
- **差距**：摆动不区分微小挂饰与长尾带，不生成框架对齐静态旋转。

#### `ribbon/bow-knot` 蝴蝶结：结体一层 2D warp + 飘带链 · P1 · 中
- **目的**：结体是硬的、只小幅晃；飘带是软的、大幅弯；缎带比头发重，中段鼓起而梢部回落，不像头发那样鞭梢。
- **产出**：识别结体（中心团块）+ 2–4 条飘带（从结体伸出的细长条）；结体一层 2D warp（Pa × Pb：±0.02 H 平移、±5° 转角）；飘带按 `hair.strand/skinned-chain`（3–7 关节）或嵌套 warp 链，根关节挂在结体 warp 下；飘带输出 scale 曲线 f(s) = sin(π·(0.2 + 0.7·s))（中段最大、梢约 0.7）；结体与飘带用不同物理组（飘带阻尼更低）。飘带很短（< 0.3 heye）时用 warp 代替链。
- **可调**：`knotAmp` 0.02 H [0.01, 0.03]；`tailPeak` 中段；`tipFall` 0.75 [0.6, 0.9]。

#### `ribbon/whip-charm` 长飘带：根部旋转 + 弯曲 warp + 末端刚性挂件独立旋转 · P1 · 中
- **目的**：根部摆 + 中段弯 + 末端挂件独立转动构成鞭梢；刚性挂件用旋转而不是 warp，不被拉变形；挂件转角大于根部，末端甩得更开。
- **适用**：“长条 + 末端紧凑高细节块”（同层或分层）。
- **产出**：根旋转（支点 = 挂点，θ_root ±15–20°，键 = 横向输出 v1 × 纵向 v1）→ 弯曲 warp（长轴方向约 18 行 × 5 列，键 = v2 × v3，分段保长弯曲）→ 末端旋转（支点 = 挂件与带子连接点，θ_end = 1.5 θ_root，键 = v3 × 纵向）→ 挂件；带子网格稀、挂件网格密。
- **可调**：`rootAngle` 18° [15, 20]；`endRatio` 1.5 [1.2, 2]。

#### `ribbon/mirrored-pair` 成对长纱 / 环：镜像开合 · P1 · 易
- **目的**：左右两片轻纱、胸前蝴蝶结的左右环若同向摆，像一块硬板；一侧取反后对称开合，像衣摆随转身“呼吸”。
- **产出**：成对识别（同一饰物左右两半，基角差约 180° 或静息方向关于竖轴对称）；每片两层 warp（整体摆 + 二阶弯），摆幅 > 10% H 时加密键（C3）；模式选择：贴身成对件（胸前结、裙侧片）→ 一侧取反（开合）；离体悬挂件（耳坠、颈前飘带）→ 同向；物理输入按混合比 λ 取反（交 `physics.*`）。
- **可调**：`lambda` 0.6 [0.5, 0.7]（1 全镜像、0 同向）；`detachDist` 0.3 饰物长（判离体）。
- **失败与质检**：基角已在网格层面镜像时再取反会变同向——按实际屏幕方向判断；全镜像在急转身时不符合惯性。

#### `ribbon/stiff-joints` 条带链跳过部分关节，留出硬段 · P2 · 易
- **目的**：缎带、蕾丝带有刚度，打结或双层重叠处不会处处可弯；把相邻两段合成硬杆，折点变少变大，像有厚度的布带。
- **算法**：为每个关节算可弯度：原画中轴曲率 > 阈值或有扭转 → 必须可弯；打结 / 双层重叠区 → 不可弯；材质刚度（缎带、蕾丝较硬，头发较软）。不可弯关节保留参数但不接物理（scale 0）；可弯关节依次读 v1、v2…；连续跳过不超过 2 个；梢部最后一段始终可弯。
- **可调**：`skipRatio` 硬材质 30% [20, 40]、软材质 0%。

## 19. tail（尾巴）

#### `tail/current` 骨架尾链跟随物理 · 基线 · 已实现
- **现状**：有骨架时尾骨链为旋转变形器，第 2 节起由父骨参数经物理跟随（单段）；`SkeletonFlexWarps` 每关节一层嵌套 warp 沿链平滑分担弯曲；`TailSwing` 动作预设；无骨架时尾巴挂在身体根下（`DeformBodyXY` 覆盖）。

#### `tail/corrective-chain` 旋转链 + 相邻关节二维修正 warp + 段间胶水 · P1 · 中
- **目的**：纯刚体旋转链在关节处折出尖角、外侧毛块被拉开；以“本关节 × 下一关节”为键的 warp 把弯曲分给两段，弯折处成圆弧。
- **产出**：中轴等弧长（或按曲率）切 N 段（`hair.strand/skinned-chain`，厚重毛尾 3–4 段、细长尾 5–7 段），每段起点一个旋转并嵌套，关节范围 ±60°；段 k 在旋转 k 之下挂覆盖本段（沿长 ≥ 10 行）的 warp，键 (θ_k, θ_{k+1}) 3×3：近端向 θ_k 的一半弯、远端向 θ_{k+1} 的一半弯（修正 = 平滑样条拟合的中心线形状 − 刚性旋转结果）；段间轮廓胶水（权重 0.5）；尾根挂在下半身扭转旋转（`body.turn/lagged-layers`）而非上半身；末端毛簇另以倒数第 2 节的输出为输入做二级物理混合形状（外扩、抖动 0.05 段长，交 `physics.cascade`）；嵌套时输出 scale 沿链递减（ρ 0.6–0.75）防梢部过卷。
- **可调**：`segments` 5 [3, 7]；`jointRange` ±60°；`correctionShare` 0.5；`scaleDecay` 0.7 [0.6, 0.75]；修正 warp 数 1–3（第 2 节之后每隔一节）。
- **失败与质检**：呼吸或周期激励与链固有频率相近时共振——每节最大偏转 ≤ 25°；相邻段修正量须一致（胶水检查）。
- **差距**：`SkeletonFlexWarps` 已有逐关节嵌套 warp 与平滑分担，缺相邻关节 2D 修正、旋转 + warp 混合形态与尾根挂下半身的规则；差距较小。

#### `tail/active-tail` 主动肢体：抬尾旋转 + 网格级 S 波形 · P1 · 中
- **目的**：尾巴是肌肉主动控制的，物理只在身体动时才动，静止时尾巴就死了；用待机行波驱动各节（物理只给根部惯性或半权重），网格级 S 波形给段内柔软弯曲，情绪改变抬尾高度。
- **产出**：
  - 根部抬尾旋转 `ParamTailRaise` [0, 1] → 0…150–180°（从下垂到上翘）；
  - 关节链（同 `tail/corrective-chain`）；物理只驱动根节或以 0.5 权重作用于前 40–50% 节；
  - 后半段网格 K = 3 个 S 波形混合形状：法向位移 = A·sin(2π(s − c_k)/λ)，λ = 0.3–0.5 尾长，A = 0.3–0.6 尾宽，C3 弧线键；
  - 行波曲线（逐节相位滞后、根→梢幅度递增、静态卷曲偏置）归 `motion.idle`；情绪映射归 `motion.*` / `param.system`。
- **可调**：`raiseAngle` 160° [90, 180]；`physWeight` 0.5 [0.3, 0.7]；`waveLen` 0.4 尾长 [0.3, 0.5]；`waveAmp` 0.45 尾宽 [0.3, 0.6]。
- **失败与质检**：宿主不播放待机动作时尾巴冻住——可同时以呼吸为物理激励兜底；行波与物理打架——物理只给根部。

#### `tail/pattern-roll` 尾巴花纹在轮廓蒙版内异相滑动（伪 3D 翻滚） · P2 · 难
- **目的**：轮廓不动而表面图案滑动，读作尾巴在三维中翻滚或扭转（圆柱贴图滚动）。
- **产出**：表面图案与轮廓分开；图案网格挂在与轮廓相同的段变形器下，以轮廓网格并集为蒙版；每段一个表面滚动参数 r_k：图案沿垂直中心线方向平移 ±(30–50)% 段宽，近边缘按 cos 衰减压缩；r_k 由第二个同输入但延迟更小的摆驱动（相位差）；图案纹理在轮廓外留足延伸。
- **可调**：`rollAmp` 40% 段宽 [30, 50]。
- **失败与质检**：需要图案 / 轮廓分离与纹理延伸（素材要求）。

## 20. wing（翅膀）

#### `wing/current` 骨架翅骨跟随物理 · 基线 · 已实现
- **现状**：有骨架时翅骨以身体 Z 为输入经物理跟随，`wingFlap` 随呼吸的动作；无骨架时翅膀只随身体 warp；没有透视与展开参数。

#### `wing/yaw-perspective` 翅膀随身体转向的透视：近侧收窄、远侧伸展 · P1 · 中
- **目的**：翅膀是从背后向两侧伸出、几乎平行于画面但根部在身后的平面；身体一转，两只翅膀与画面的夹角一大一小，宽度应按 cos 变化，否则像贴在背后的纸板。
- **产出**：每侧翅膀在各段下一层 BodyAngleX × BodyAngleY warp；翼根定位旋转（角度 0，原点随背部 warp 求值，C4）；呼吸带动翼根上移（`breath/attachment-bob`）。
- **算法**：每只翅膀近似为根点在背部、朝外伸展的平面，初始与画面夹角 α0；身体 X 角 β：近侧翼沿长轴宽度 × cos(α0 + β′)/cos α0，远侧 × cos(α0 − β′)/cos α0，β′ = β × 跟随系数，根部不动；身体 Y：上下缘按俯仰纵向压缩 3–8%。
- **可调**：`alpha0` 20° [15, 25]；`follow` 0.65 [0.5, 0.8]；`pitchCompress` 5% [3, 8]。
- **失败与质检**：近侧翼转到身后时仍画在身体前——配翅膀组 level 参数（`arm/depth-level` 同构）或遮罩。

#### `wing/rigid-plates` 硬质翼片：四点贴片 + 远离轴心的大幅旋转 · P1 · 易
- **目的**：冰晶、金属、光片类硬翼不需要变形；4 顶点贴片几乎零成本，轴心在背部，远端位移自然与离轴心距离成正比（大翼扇得多、小翼扇得少）。
- **产出**：硬质翼片网格用 4 顶点；每侧一个旋转（轴心在附着点），左右角度范围不对称（约 [−a, 0.35a] 与 [0, 0.9a]，a ≈ 12°）以免镜像同步；由空闲周期参数或呼吸驱动。
- **可调**：`a` 12° [8, 18]；`asym` 0.35 / 0.9。
- **失败与质检**：软质翅膀（羽毛、蝙蝠翼）不适用；四点贴片在透明边缘浪费贴图面积。

#### `wing/three-segment-fold` 翅膀骨架：根部位移 + 三段关节，展开 × 扇动二维 · P2 · 难
- **目的**：鸟翼由臂骨与掌骨组成，折叠时各段依次收拢、羽毛重叠；整体 warp 展开会让羽毛拉伸变形。
- **产出**：翼根平移旋转（ROOT_X/Y，角度 0）→ 翼根旋转（ROOT_Z ±30°）→ 段 1（原点翼根 P0）→ 段 2（腕 P1）→ 段 3（掌 P2），每段下挂羽毛组 warp，每片大羽一个小 warp；展开参数 s1 ∈ [−1, 2]（−1 收拢、0 原画、2 全展，4 键）、上下扇参数 s2 ∈ [−1, 1]（主要转段 1 ±10–15°，段 2、3 追加同向 ±15–20° 滞后角）；三段角度比约 1 : 3 : 4；收拢时 Z 形折叠（段 2 折回约 80°、段 3 再折回约 100°），全展时三段近共线水平外指；羽毛片在各 s1 键上围绕自己的根点旋转到扇形均匀分布（收拢时夹角 → 0）；关节点可由同组羽毛根部连线交点估计。
- **可调**：段角比；折叠角 80° / 100°；扇动滞后。
- **失败与质检**：s1 扫描时相邻羽片在根部 30% 长度内保持重叠、翼尖轨迹平滑；只有一张整体翅膀画时只能做三段，展开会露出被遮住的羽毛空白（需补画）。

#### `wing/flap-view-swap` 拍翅过侧视换片 · P2 · 中
- **目的**：翅膀扑动是绕身体轴的 3D 转动，2D 中会经过“看不见”的侧视点；在侧视点附近换背面图，一张正面一张背面画出完整扑动。
- **产出**：每片翅膀旋转（轴心翅根），参数 f ∈ [0, 1] → 展开到合拢 100–150°；侧视点 f_s 附近 [f_s − 0.05, f_s + 0.05] 交换正 / 背面不透明度（背面可由正面镜像调暗生成）；每片挂 5×5 warp 在 f = 0、0.45、0.55、1 修弯曲（扑下时翅尖滞后上弯）。
- **可调**：`flapRange` 125° [100, 150]；`swapBand` 0.1 [0.05, 0.1]。

## 21. prop（道具）

#### `prop/current` 所有图层挂进角色根 · 基线
- **现状**：没有道具类别；场景物、手持物、穿戴物都按普通图层挂在角色树中。

#### `prop/scene-root` 场景道具放独立根 · **P0** · 易
- **目的**：桌子、电脑、麦克风支架、椅子属于场景，角色转头歪身时不应跟着倾斜；一次开关切出“直播间”。
- **适用**：图层标注 scene（或命名约定）；held 挂对应手变形器（`prop/held-socket`），worn 挂身体部位。
- **产出**：场景根 warp（5×5，与角色根并列，不受任何角色参数影响），只有开关不透明度键 `ParamSceneProps`；绘制顺序按场景前后（桌子在角色前、椅子在后）；可选位置参数以画布为单位与独立深度参数；镜像副本由水平翻转网格与关键形生成，由朝向参数选择。
- **可调**：`sceneToggle` 默认 1；深度。
- **失败与质检**：道具与角色遮挡关系固定，角色大幅动作时会穿插（手伸到桌后）——报告可能的重叠区域。
- **差距**：所有图层都挂进角色根，没有场景根。

#### `prop/held-socket` 手持道具：握持插座链 + 三自由度摆动 + 胶水握持 · P1 · 中
- **目的**：道具挂在手的变换链下，手臂怎么摆道具就怎么跟；道具自己的参数只描述“在手里的握法”，与手臂姿态解耦；手提重物有钟摆、偏航（露侧面）、绕握把扭转三种分量。
- **产出**：腕旋转 → 插座平移（原点 = 掌心握持点 A，参数 X/Y：握持偏移 ±30% 道具长）→ 朝向旋转（Z，±60° 或 ±180°）→ 变体选择组（带符号切换）→ 显现（opacity）→ 缩放（召唤 0.1 → 1）→ 道具自转 warp（按圆柱或球面投影生成偏航 / 俯仰关键形）。手提重物：钟摆旋转（原点握持点，±15–40°）→ 偏航 warp（正面宽度 × cos ψ，ψ ≤ 25°，侧面带从 0 展开到 sin ψ·深度；无侧面素材只做 3–5% 梯形透视）→ 扭转旋转（原点握把中心，约 −10°…+16°），由同一摆链不同质点驱动（交 `physics.*`）；握持：手网格切成手腕段与手掌段，手掌段挂在钟摆下、手腕段留在手臂下，交界胶水；道具绘制顺序 = 手的 level + 偏移（握持层介于掌与手指之间，拇指盖在道具上）；道具基角 = 原画中道具与前臂夹角，长道具挂在旋转下（不挂在前臂修形 warp 下）。
- **可调**：`gripOffset` ±30% 道具长；`orient` ±60°；`swing` 30° [15, 40]；`yaw` 15° [5, 25]；`summonScale` 0.1。
- **失败与质检**：道具大时钟摆与腿、裙穿插——限角或绘制顺序；没有侧面素材时偏航只能小角度。

#### `prop/handoff` 道具交接：双副本挂不同父级 + 交叉 · P2 · 中
- **目的**：运行时不能改父级；道具从领口、腰侧移到手里时，两个副本各挂在正确父级，在手遮挡的瞬间交叉。
- **产出**：副本 P_A（静置父）与 P_B（手，几何换算到手局部空间并对齐交接时刻位置）；参数 swap 0..1：P_A 父变形器不透明度 1 → 0、P_B 0 → 1，过渡带占范围 20–30%；动作中 swap 跳变放在手与道具重合的帧。

#### `prop/rigid-3d-proxy` 硬质道具的三维代理烘焙（伞、刀、扇、书、光环） · P2 · 研究
- **目的**：把一个小型 3D 渲染烘焙进参数网格：转动时每片透视与遮挡顺序都正确。
- **产出**：道具拆为平面面片（每片 4 顶点）或拟合圆锥 / 圆环代理；参数 yaw、pitch（步长 5–7.5°）、状态（收 / 出）、roll（旋转变形器 3 键整圈）、开合（旋转缩放 1 → 0.1）、周期化自转（范围恰好一个伞骨间距，首尾相同）；对每个采样组合旋转 → 弱透视投影 → 写面片四角关键形；面片中心深度排名 → 绘制顺序关键形（基准 ± 排名），深度相等处用加性绘制顺序参数修正；法线背向时不透明度 0 或背面剔除；伞面用极坐标网格（每根伞骨一条径向顶点线）。
- **可调**：采样步长；面片数 10–50；透视强度。

#### `prop/liquid` 容器中的液体 · P2 · 中
- **目的**：杯子随手摆动时液面相对重力保持水平并晃荡，被杯身剪切。
- **产出**：液体以容器为蒙版；液体 warp 以两节摆 (sx, sy) 为轴：液面线反向倾斜、一侧抬高（幅度按容器宽 0.1–0.2），中间加非线性键做“晃”；玻璃层部分不透明（上限 0.1–0.6）；液体网格向上留足余量；容器继承手部链摆动。
- **可调**：`tiltMax` 15° [10, 20]；`slosh` 0.15 容器宽。

#### `prop/companion-rig` 子角色：完整小 rig 作为独立根 · P2 · 难
- **目的**：伴随角色（宠物、人偶）独立表演并与主角互动（躲到身后）。
- **产出**：对伴随角色分层运行一遍简化 rig 生成（头 XYZ、身体、四肢 roll、眼与表情槽），所有参数加前缀；外层加显现、整体平移、翻滚 ±180°、层级参数；伴随动作归 `motion.*`。
- **可调**：伴随尺寸 0.2–0.35 H。

## 22. ornament（小饰品：吊坠、耳坠、挂饰、链，补充插槽）

#### `ornament/shared-bus` 区域饰品物理总线 + 逐件关键形 · **P0** · 易
- **目的**：每件饰品单独调物理很贵；同一身体区域的小饰物对运动的响应本该一致，共用一条链就有统一节奏，各件用各自的关键形形状与幅度，动作仍有差异。
- **适用**：面积 < 1% 人物面积、挂在衣物或身体上的小件（蝴蝶结、鞋带、腰侧结、袖口布、颈饰、侧翼），以及同类重复件（≥ 3 个相似连通件）。
- **产出**：
  - 按挂接区域聚类（头、颈、胸、上臂、腰、腿、脚），每区域一条总线：横向两级输出 b1x、b2x，纵向两级 b1y、b2y（交物理组，快速小摆）；
  - 每件：嵌套 warp (b1x × b1y) > (b2x × b2y)（或单层 5×5 warp），关键形 = 绕自身挂点转 ±10–15°（末端位移约 0.25 件尺寸），纵向上下翻 ±8°；吊坠类挂在旋转上，以 (bx × by) 为轴，±1 时 ±45–60°；
  - 幅度与件长度成比例，乘 `hair.strand/group-drive` 的确定性抖动；
  - 同类且屏幕距离 > 0.3 H 的挂件（如耳坠与腰坠）可共用一组输出，按长度缩放角度保持末端位移相近，根部加以 BodyX / AngleX 为键、角度恒 0 的定位旋转承担挂点平移；
  - 互斥差分（不同手臂、不同服装）上的同一件饰品共用总线参数，切换时相位一致。
- **可调**：`busPerRegion` 1；`itemSwing` 12° [10, 15]；`itemFlip` 8°；`pendantMax` 50° [45, 60]；`shareDist` 0.3 H [0.2, 0.4]。
- **失败与质检**：区域太大（跨头和身体）时节奏不对；同一件被两条总线驱动会叠加过量；相距很近的左右成对件共用会显得同步——成对件各用一组或取反。
- **差距**：每个摆动对象独立生成物理组，物理组数量随饰物线性增长；没有吊坠识别。

#### `ornament/rigid-on-chain` 刚性挂件随链末端走 · P1 · 中
- **目的**：宝石、樱桃、铃铛、吊坠这类硬挂件被骨权重弯曲会像橡皮；用以链参数为轴的 warp 让挂件整体刚体平移和转动，形状不变，始终连在末端。
- **产出**：标注刚性挂件及其所挂链与挂点（最近关节）；对挂点以上的每根骨由外到内包一层 warp，嵌套顺序与骨序一致，键 ±θ 的形状 = 挂件绕关节 i 刚体旋转 ±θ 后的格点位置；骨多时相邻两根合成一个 2D warp；最后一根骨可直接做在挂件网格关键形上；挂件朝向系数 α（1 随骨转，0 保持竖直只平移，钟摆式）；挂件不进胶水；高光层以挂件为蒙版一起走；角度大时用 C3 密键。
- **可调**：`alpha` 0.5 [0, 1]；`followBones` 全部或末 2 根。
- **失败与质检**：3 键时中间姿态挂件轻微变短变窄；挂件比链宽很多时 warp 外框要包住整个摆动范围。

#### `ornament/surface-follow` 贴在会晃动表面上的饰物读取表面物理 · P1 · 易
- **目的**：胸前吊坠、胸针贴在胸口，胸部晃动时应被带动；直接把表面的物理参数作为饰物链中的一层输入，比另建物理组省且同步。
- **产出**：饰物链中插入以表面物理参数为轴的旋转 / 位移层（幅度 = 表面在饰物根部的位移 × 1.0），之下再接饰物自己的摆动；贴身衣物同理（见 `chest/nested-bounce`）。
- **可调**：`surfaceFollow` 1.0 [0.8, 1]。

#### `ornament/chain-links` 刚性链节的双模摆 · P2 · 中
- **目的**：项链、锁链的链节始终刚性（金属），只旋转不拉伸；整体摆出弧度 + 逐节 S 形鞭梢。
- **产出**：识别沿一条线重复的小连通块，从锚点起排序；模态 1：第 k 节绕锚点旋转 A1·(k/n)^γ；模态 2：第 k 节绕自身上端旋转 A2·(k/n)^γ2；每节另有以身体 X/Y 为键的朝向旋转让链条随重力下垂；两个参数分别接物理（模态 2 摆更短）。
- **可调**：`A1` 15° [10, 20]；`A2` 25° [20, 30]；`gamma` 1.2 [1, 1.5]。

## 24. 与其他插槽的接口

- **physics.chain / physics.cascade**：本目录的链模板需要“少质点驱动多关节”的映射（根部共享质点、scale 根→梢斜坡、锚定段输出 0）、按材质的链参数谱、左右组纵向输入一侧取反、相邻同类件去同步、身体分层滞后链（上身 → 腰 → 胯 → 裙）、物理输出作为下一组物理输入。
- **physics.filter**：身体 X/Y/Z、头 Z 的“输入参数 → 单摆 → 驱动参数”滤波层；`body.turn/head-driven` 与“身随头物理”互斥。
- **physics.excitation**：呼吸作为物理输入（全身站立）、开关切换作为冲量、动作写入的激励通道。
- **motion.idle**：尾巴 / 漂浮长发的逐节相位行波、身体三段相位、展示姿势常量、行走步态。
- **deformer.layering / param.system**：C3 自适应弧线键、C5 加法层与降级、“姿态走乘法关键形，次级走加法层”的分工规则。
- **draw-order**：C7 组 level 参数、紧邻键阶跃（手臂、腿、翅膀、道具、环形头饰、转身换层）。
- **mask / lighting**：发影链（投影复制件跟随投射体、以受影面为蒙版）、阴影叠层随转头相对基底滑动——这里只保证发组层能被这些复制件复用。
- **toggle**：可拆卸组的折叠开关（`hair.variant/fold-toggle`）、穿戴型开关的滑入动画。
- **animal-ear**：兽耳的收回隐藏与转动密键（属面部插槽）。

## 25. 关键结论

1. **“细长物的链”是头发与身体模板最核心的共享构件**：发束、辫子、缎带、尾巴、绳、袖、裙片都是“条带描述 + 两种实现（嵌套 warp 多质点链 / 切段蒙皮旋转链）+ 物理输出映射”。切段蒙皮链是手工制作细长物的常见做法，但自动生成要求网格切分与稳定 ID，代价高；PSD2Live 的 `SwingDeformer` 已有段语义，本轮先把它升级为“每层一参数的嵌套 warp + 弧线密键 + 多输出”（P0），切段旋转链放下一轮。
2. **重力保持是性价比最高的观感提升**：歪头、侧倾时下垂物整体跟着歪是 2D 模型最显廉价的瞬间。做法是在挂点按祖先累计转角插反向旋转（保留 10–25% 跟随、贴附段、碰撞侧不对称），物理只负责动态。它依赖“父链在挂点的局部转角求值器”，这个求值器同时支撑头部 warp 雅可比补偿、链段透视残差、肩点跟随、硬件钉在布料上等一批模板，应作为基础设施先做。
3. **次级运动必须走加法层**：物理输出、纵向弹跳、发丝模态、胸部弹跳若都做成乘法关键形轴会组合爆炸（这正是现有摆动“全部段轴乘在同一 warp”的问题）。姿态（头 / 身体转向）用乘法关键形，次级用混合形状或“每个参数一层嵌套 warp”；生成器需要混合形状输出与旧目标降级。
4. **身体要分层、分侧、分时间**：现有 `DeformBodyXY` / `DeformLegs` 是一次性的空间衰减与对称 IK。最便宜的两步是双关节脊柱侧弯和承重腿不对称（P0），随后是骨盆为根的链（整体变换 → 髋部 → 以脚为支点的全身倾 → 上身 / 腿分支）、默认站姿、逐层滞后，以及“被动下垂手臂链”让手臂进入物理而不覆盖姿势。
5. **大动作离不开绘制顺序与视图切换**：转头时侧发 / 头冠换层、转身时远侧手臂退后、手臂穿插身体、腿交叉、手翻转、翅膀过侧视点，都靠“紧邻键阶跃 + 两侧形状在切换点对齐（桥形）”或“组 level 参数”。手、腿、翅膀、道具的大范围姿态模板多为 P2 / 研究，前提是素材约定（多视图、手指分节、成对视图），应先定 PSD 约定再做生成器。
