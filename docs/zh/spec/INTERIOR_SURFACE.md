# 内部造型

[English](../../en/spec/INTERIOR_SURFACE.md) · [讨论 #44](https://github.com/tsunehimatoi/psd2live/issues/44)

## 范围与操作

这是开发中的可选 Mesh 关键形生成器。它让原纹理随虚拟曲面产生内部收放和偏压，不生成新纹理、阴影或真实布料模拟，也不依赖深度模型。未启用的工程沿用原有路径。

选择已生成的图层，在右侧“内部造型”页签开启并调参。拖动结束提交一条历史记录；生成失败保留草稿和之前的有效结果。开关保留设置，关闭不重新烘焙。参数可以重新打开调整。“删除效果”移除配方及其自有物理，可通过撤销恢复；其他功能引用的自建参数会转为作者参数保留。

“独显并居中”临时独显、居中和适配选层，再按恢复该画布原显隐与相机；不移动图层。“二维参数盘”使用真实参数范围，向右/下为正，中心为默认值；松手保持姿态，物理继续。鼠标跟随默认关闭，与参数盘互斥。独显时零点为图层中性中心，整体显示时为主画布中心。鼠标倍率仅改变试动输入，不改变关键形幅度或导出参数范围。

局部试动在编辑画布使用临时输入别名，不改身体/头部源参数、不写历史。切换工程、工作区、画布或目标时清理临时投影；整个人物播放仍使用原生预览工作区。

## 参数合同

| 设置 | 范围 | 含义 |
| --- | --- | --- |
| 横向 / 纵向幅度 | 各 0–2 | 两个材料方向各自的造型总量 |
| 曲面鼓起 / 偏压 | 各 0–2 | 虚拟拱面及其偏压程度；任一为 0 时无曲面位移 |
| 褶皱强度 | 0–2 | 已标为 FOLD 的局部引导线贡献；没有引导线时不生效 |
| 轮廓保持 | 0–1 | 0 释放可见轮廓，1 保护源 alpha 轮廓；不是固定图层顶部 |
| 缓动与传动 | 开关 | 使用项目原生物理组驱动各区形变 |
| 缓动时间 | 0–0.6 秒 | 第一阶段响应；不修改全局时钟 |
| 传递时间 | 0–0.5 秒 | 后区相对前区的传播时间 |
| 传动强度 | 0–1 | 后区权重，0 不分区 |
| 方向起终点 | 各坐标 0–1 | 图层范围内的传播方向；两点距离至少 0.05 |
| 横 / 纵鼠标倍率 | 各 0.1–1 | 均匀线性倍率，只作用于鼠标试动 |

局部引导线保存源像素坐标、半径（正数）、强度和“仅纵向”标记。普通 TOPOLOGY 线不会自行产生褶皱；FOLD 才参与造型。当前界面通过数值控制点调整，引导线画布手柄尚未实现。

## 核心与生成表示

- `InteriorSurface.compile/evaluate` 是静态所有者，输入原网格、RGBA、设置和引导线，输出同拓扑的位移。按拱面弧长登记纹理，混合全局与行列截面；轮廓保持同时约束登记和边缘权重。中性精确返回原坐标，不设悬挂根部。
- alpha 轮廓不是矩形网格外框。横纵使用独立材料轴，纵向保留长宽标定。局部折面沿引导线法线作用。原面积约束阻止翻折；不能由有限姿态检查推出连续全域安全。
- `InteriorBasisKeyforms` 在制作时采样 X、Y 基础曲线及带局部权重的混合修正行，生成原生 blend 字段。新入口目标为 4 源像素采样误差，保守系数的误差计入统计，未满足预算/安全检查时拒绝生成。当前素材的视觉确认不代表所有素材 4px 都不可见。
- `NativeInteriorAuthoring` 经 `LayerTexture.rasterOfUv` 找回源栅格坐标，使用原 UV 三角形的材质微分把位移映射回 Mesh 局部。保留原网格、UV、权重、父变形器和既有关键形，不自动重布点。
- 输入可读已有 NORMAL/BLEND 参数，要求不循环且默认值位于范围内部。省略绑定时优先用标准身体 X/Y，缺少时创建私有输入；显式空 ID 表示新建。非零默认值使用 F(0) 常量/门控残差分解，保持 Cubism blend 的中性值 0。
- blend 字段加入当前 grid 默认偏移及标量参考，匹配原生求值器的减参考语义，避免重复扣除导致中性漂移。

自动内部布点、手工网格工具和曲面/引导线画布手柄留到后续 PR。本次保留原有网格，未接入的结构分析和约束重布点代码不随本次发布。

## 缓动和传播

`InteriorMotionGenerator` 将静态字段分成两个平滑区域，末区权重为方向投影的 smoothstep 乘强度，前区权重为其补数。两轴分别串联原生 ANGLE 物理组（最多四组），每个输出只有一个所有者。两区停稳后复合成同一静态造型。

沿用项目 `PhysicsEngine`、PhysicsCatalog 和项目物理 FPS；导出为标准 physics3。播放不运行图像分析、曲面求值或采样器。鼠标倍率用 `clamp(input,-1,1)*gain`；明确参数姿态不经过该倍率。生成前另做 600 帧快速反向面积检查；不安全的配置报错保留旧结果，不静默改幅度。

维护者已在 PR #45 审阅中同意保留可选缓动与传动。

## 文档、重放与所有权

`rigEdits.interiorEffects` 保存 schema 1 配方：设置、引导线、输入/自建参数、独占输出、原生 blend 字段、物理组、网格标识和素材 hash。Float32 字段以 gzip/base64 保存；稳定内容摘要用于配方身份。新可选空字段不改变旧工程的 revision。

`interiorEffect:<id>` 节点声明生成参数和目标 Mesh 关键形轴，既有输入只读。配方增删、开关或修改通知依赖图，失效传播到覆盖、物理与动作。生成在作者日志之后，手工关键形修改仍通过已有 GeneratedOverrides 叠加。

网格、纹理内容或输入范围不匹配时保留配方但不应用过期顶点数据，提示重新生成/绑定。禁用在编辑器中保留参数定义以支持重新启用，但不应用形变或激活物理；所有导出格式使用同一 IR，移除本效果拥有且未被几何、其他物理、动作或链接引用的闲置参数。失效效果及其物理显式跳过，并在模型导出的 warnings / 通用导出损失报告中提示。生成器缓存同时读取纹理来源和图集，不复用换图前的结果；新配方也记录“没有摘要”的初始状态。未发布的 `RigInteriorEdit/interiorSurfaces` 密集实验已从正式链路移除，不提供迁移兼容。

UI 与 MCP 共用 `interior_put` 和 `interior_delete` 文档命令。目标接受网格 ID 或 `mesh:<ID>`，可传 `enabled/settings/motion/parameters/guides`；上下文 state 仍遵守原生事务约束。只有 target/enabled 与上下文字段时为轻量开关。`workspace_inspect scope=interiors` 返回完整设置、引导线、参数 ID 与失效原因，不返回形变数组。settings/motion 支持局部更新，嵌套 schema 给出范围、单位和说明。

`InteriorController` 持有草稿、试动物理和独显状态；主 ViewModel 仅提供文档/画布入口。主界面草稿用版本和工程地址校验，异步旧结果不能写入另一个工程。临时预览不进入档案或导出。

## 验证与限制

```bash
./gradlew test --tests '*InteriorSurfaceTest' --tests '*InteriorReferenceParityTest' --tests '*InteriorBasisKeyformTest' --tests '*InteriorMotionTest' --tests '*NativeInteriorEffectTest'
./gradlew test
```

测试包含合成 alpha/孔洞/边缘、纯函数参考对照、原生 Mesh/MOC3 轨迹、已有非零不对称输入、开关、归档/历史和失效通知。参考 fixture 仅含合成数据；外部演示素材、视频和私人模型不分发。

本地已做原生 GUI/MCP、档案保存重开、导出文件生成与 CPU/MOC3 轨迹检查；完整官方 SDK 动态画面、更多素材及所有编辑组合仍需审阅。当前编辑器的静态和动态效果已有人工反馈，但不能把有限数值检查当作全面视觉保证。复杂/超强参数可能被面积预检拒绝；不降低网格密度或纹理质量来通过。

### 保留参数的面板重放阶段

删除效果时用“禁用原效果后完成全部生成及面板编辑”的结果检查外部引用，不能只调用生成器，否则会漏掉后置配对。需要保留的自建参数转成作者参数；对应的 `structure` 日志同时记录内部 `panel_after_generation` ID 列表，维持这些参数的配对/移动在原有生成后阶段和顺序执行。后续取消配对也遵守同一顺序，检查点与保存重开不会重新覆盖用户的新编辑；显式删除参数会结束其阶段标记，重新创建同名参数不会恢复旧配对。没有此元数据的项目不改变原重放行为。

异步草稿清理使用发起时的工程/工作区/目标键，并核对草稿对象和版本；晚到的删除结果不能清除新作用域或后来修改的草稿。鼠标试动与十字标记共同核对工程代次、工作区、活动画布和编辑模式，非活动画布的悬停不会驱动当前画布。
