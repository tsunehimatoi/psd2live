## 1. 背景与目标

当前桌面工作区面向专业 Live2D 建模流程设计，包含七种画布模式、数十项面板、快捷键体系与大量工程概念。对于只想“把立绘变成能动的模型”的初学者，学习成本与传统专业工具相近。

**极简工作区（Lite Workspace）**的目标是提供一套**零门槛、触控优先、手机亦可操作**的精简入口：

- **没有复杂描述与冗余按钮**：去掉专业术语、密集参数表、多画布与复杂菜单，用直接手势和最多 1–2 步向导完成操作。
- **只保留人工无法被自动生成替代的必要工具**：例如处理部件前后穿插的**前后分层**、五官拟合微调与部件部位纠错。
- **通过 MCP 接入外部 Agent**：用户无需在极简界面中操作复杂面板，进阶修改可通过 MCP 交由 AI Agent 完成。
- **与完整版工程完全互通**：底层继续使用同一套 `.psd2live` v2 工程与 `WorkspaceHost` 命令通道，在极简版与完整桌面版之间可无损切换与重开。

## 3. 核心工作流（四步闭环）

极简工作区以单一主流程组织，不要求用户理解“网格—变形器—参数—关键形”的层级概念：

1. **导入并自动生成**：
   - 选择本地 PSD / 图片或已有 `.psd2live` 工程。
   - 自动调用 `project_import_psd`（默认 `recommended` 预设）直接生成可动模型，并进入实时预览状态。
2. **手势试动与整体调节**：
   - 在画布上直接拖动，预览转头、眼神追随、呼吸与头发/服饰晃动。
   - 底部提供少量常用表情/动作切换与“动作幅度”整体滑条（映射到 `settings_update.rigTuning`），无需逐个调整参数滑条。
3. **必要的人工介入工具**：
   - **前后分层（核心保留工具）**：解决“同一图层一部分在前、一部分在后”的穿插问题（如衣领与脖子、头发与肩饰）。底层直接复用 `source_split_depth` 与前层橡皮擦绘画会话，但用三步触控向导替代右键多选与模式切换：
     1. 点选需要分层的图层（如上衣）；
     2. 点选应夹在中间的图层（如脖子）；
     3. 自动复制前后两层并进入擦除状态，直接用手指/触控笔在前层涂抹擦掉应藏在后面的区域，实时看到前后遮挡效果，点击“完成”即提交单步历史。
   - **特征点微调**：当自动拟合的眼角、眉峰、嘴角略有偏差时，在画布上显示大号触控手柄（对应 `settings_update.moves`），拖动即可重拟合。
   - **部位快速纠错**：点选部件后，以直观部位图标修正分类（如“这是左眼 / 前发 / 忽略”），对应 `layer_classify` 与再生成。
4. **一键导出**：
   - 选择目标用途（例如“用于 VTube Studio”或“导出 `.p2lrt`”），后台执行导出；仅当存在阻断性问题时给出简明提示。

## 4. 手机与触控优先的界面设计

为保证在手机竖屏、平板横屏与桌面窄窗下都能顺畅操作，界面遵循以下约束：

- **画布占满主视口**：85% 以上区域留给模型画布，取消常驻左右侧边栏与顶部多层菜单栏。
- **极简顶栏**：仅保留 4 个核心入口——`工程/返回`、`撤销 / 重做`（对应 `history` 分支历史）、`MCP 状态`、`导出`。
- **单层上下文底栏**：
  - 默认态仅提供三个主标签：`试动`、`修整`、`MCP`。
  - 进入具体工具（如“前后分层”的擦除阶段）时，底栏原地替换为该工具的最小控制条（如笔刷大小滑条、撤销笔画、取消 / 完成），不弹出遮挡画布的浮动窗口。
- **零悬停、零右键、零快捷键依赖**：
  - 不使用鼠标悬停提示作为唯一说明，不使用右键上下文菜单，不依赖 `Shift` / `Ctrl` 多选；多选操作一律改为显式“点选步骤”。
  - 所有触控目标保留足够热区（建议 ≥ 44–48 dp），滑条与画布拖拽手势互斥，避免误触模型。

## 5. MCP 接入方案

极简版将复杂编辑能力通过 MCP 外包给外部 Agent，既保持界面极简，又不封死上限：

- **复用现有服务与契约**：
  - 直接复用 `AgentMcpService` 的**精简工具集**（Streamable HTTP + Bearer Token），外部 Agent 可调用 `workspace_inspect`、`workspace_apply_edits`、`source_split_depth`、`settings_update`、`author_axis` 等完整应用层能力。
  - 与极简 UI 共用 `WorkspaceHost` 的 `state` 乐观并发控制与单历史节点提交语义：Agent 做的每次修改在极简端画布上实时可见，且用户可一键撤销。
- **极简端连接体验**：
  - `MCP` 面板仅展示三项内容：服务开关、当前连接状态（未连接 / 已连接 / Agent 正在编辑）、以及“复制连接配置 / 安装提示词”。
  - 在手机/平板上使用极简端时，支持配置外部可访问的宿主地址或通过配对令牌接入同一局域网内的 Agent 宿主。

## 6. 技术复用与分期建议

### 6.1 架构复用

仓库已完成桌面 UI 与应用层的解耦（`application` 不依赖 `ui` 与 Compose，`LayerDependencyTest` 守护边界）：

- **应用层与核心层零重写**：极简工作区直接作为 `WorkspaceHost` 的轻量前端表现层（类似桌面端的 `DesktopPresentation`），所有生成、编辑、历史、MCP 与导出均走既有命令通道。
- **工程与运行时兼容**：极简端保存的 `.psd2live` 可直接在桌面完整版中继续精修；完整版保存的工程也可在极简端试动、做前后分层或导出。

### 6.2 分期落地

1. **一期（桌面内极简模式）**：在现有桌面应用中提供“极简工作区”视图切换，先验证四步主流程、前后分层向导与 MCP 快捷入口的易用性，无需处理跨平台运行时差异。
2. **二期（窄屏与纯触控交互）**：完成无右键/无快捷键交互改造、竖屏单层底栏适配、特征点触控手柄与部位快速纠错。
3. **三期（移动端运行形态）**：评估在手机/平板端运行 Compose UI 的部署方式——优先可采用“移动端极简前端 + 远端/桌面 `WorkspaceHost` 服务（含预览流与 MCP）”，或结合 `.p2lrt` 运行时与核心裁剪方案实现本地端运行。
