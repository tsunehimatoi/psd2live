# PSD 素材与命名

[文档目录](../../README.md) · [操作速查](../guide/USER_GUIDE.md)

本页面向素材准备；自动识别只是预设入口，导入后仍可在图层表里修改标签与差分（见[语义标签](#语义标签)）。

## 准备素材

使用 RGB、8 位、透明背景的分层 PSD。需要保留的文字、矢量、图层样式和调整效果先栅格化或合并到对应像素层。身体保持基本正立；头部可轻微倾斜，自动基准估计仍需预览核对。

图层混合模式：线性减淡（添加）、发光添加与线性光生成 Cubism 的加算，正片叠底、线性加深与颜色加深生成乘算，滤色保持滤色（Cubism 5.3 的混合模式；导出到更早的运行时版本时改为加算，并写进损失报告），其余模式按普通绘制。图层组的混合模式不生效，需要时先把组合并为一个图层。

## 不用 PSD：Layout 清单

由程序拆好的部件（例如 AI 分层的结果）可以不经 PSD，写成 [Layout 清单](LAYOUT_MANIFEST.md) 交给 PSD2Live：一个 JSON（或根目录放着它的 zip），逐层写明图片、画布矩形、上下顺序、组、标签、差分，以及是否只作参考（如拆件前的原图，显示在画布上但不生成、不导出）。小部件可以带比画布更多的像素，打开后得到摆好的未生成工程。没有标签的图层按本页的名称规则识别。

## 部件分层

### 眼睛与睫毛
- **分层建议**：眼白、瞳孔、睫毛分别绘制，瞳孔保留被眼皮遮住的完整部分。
- **睫毛细分**：可包含多层横向主笔、尖束和侧包围（数字后缀默认表示共存图层）；独立下睫毛标为 `lower`，眼皮线和阴影分别标为 `lid`、`shadow`。
- **转头适配**：按上睫毛线（眼尾睫毛翼可单独一层）、眼白（画大、边缘靠睫毛遮盖）、虹膜（画满整圆、靠眼白裁剪）、瞳孔、高光分层。虹膜和高光在转头时几乎不变形，眼睑开口在它们周围变形。

### 嘴巴与口腔
- **基础要求**：提供最大张口素材；口腔可绘为整体，或另分上牙、下牙、舌头（闭口原图无法恢复不存在的口腔）。
- **厚涂唇 / 精细开合（推荐分成两组）**：
  - **口腔组**：`口腔`（最大张口形状的填充层，可设不透明度为 0 作纯裁剪蒙版）、`口腔底`（画得比张口更大并剪切到 `口腔`）、`上牙` / `下牙` / `舌`（画成真实牙列，平或略呈 U 形、不要截成 ∩ 形）、口腔暗部阴影层。
  - **嘴皮组**：`上唇`、`下唇`（含周围一圈与脸同色的皮肤）及有线稿时的 `上唇线`、`下唇线`（两条线闭合并在左右嘴角相接于同一点）。
- **吐舌**：启用吐舌时程序会自动生成外伸舌副本（取消口腔裁剪、置于下唇之上上唇之下），无需手绘额外外伸舌图层。

### 脸部、五官与头发
- **脸皮**：画成一整张（或完整轮廓带），下巴、下颌角、两颊、额角轮廓须清楚，转头时按读出的特征点保持原有脸形。
- **鼻子与耳朵**：鼻子可画在脸皮上或单独成层（独立层在转头时领先最多，复杂鼻可分鼻梁线、鼻底、侧影）；耳朵画全以便转头时收至发后。
- **头发**：前发、侧发（`side`）、后发分开；后发及被遮挡区域保留足够重叠以便运动。

## 左右与拆分

左右指角色自身：角色左侧通常在画面右边。可用 `eyelash-l`、`eyelash-r`、`eyelash_left`、`左睫毛`、`왼쪽 속눈썹`、`속눈썹_우` 等名称；韩文单字 `좌` / `우` 需用分隔符或括号隔开。箭头 `>` / `<` 也可作侧别（同样用分隔符或括号）：`>` 为角色左侧（指向其所在的画面右侧），`<` 为角色右侧，例如 `눈썹_>`、`흰자(<)`。

无侧别的双侧图层（例如两只眼睛画在同一层）导入时不会自动拆分，会作为一个部件生成；需要左右分开时在 PSD 里分层，或在编辑器中按网格、多边形拆分并检查分类。较早版本自动拆出的 `:r` / `:l` 部件在旧工程中保留。

## 数字与差分

`front hair 1` 等数字可区分素材；分类器还清理部分 Photoshop 副本后缀。数字名称本身不等于已经建立表情切换：开关差分需指定参数，切换差分需共享参数并设置不同关联 ID。

## 未知图层与检查

未识别图层不会仅因名字未知而丢弃，可生成网格并使用回退归属；请在图层面板手动修正。检查中立、眼口开合、转头和头发运动，核对层序、左右、遮罩及露底。命名成功不代表自动造型已通过验收。
