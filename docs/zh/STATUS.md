## 评价标准

| 评价 | 含义 |
| --- | --- |
| 很好 | 稳定完成 |
| 可用 | 完成，需要少量人工修正 |
| 勉强 | 需要大量返工或人工兜底 |
| 不可用 | 未完成，或结果不可接受 |

少量成功样本不代表在其他素材上同样稳定。

## 如何提交新记录

每条记录请包含：

- 应用版本或 commit、宿主、模型；
- 任务描述与源素材，是否使用了图像生成；
- 样本数、返工次数、耗时与额度消耗；
- 结果文件或历史节点，以及明确的通过 / 失败原因。

验收时对照实际模型的中立姿态、参数端点与动态效果，并检查保存重开和导出结果。仅有参考图、工具成功返回或单张截图，不足以证明任务完成。

## 算法插件开发验收

JVM 插件契约已抽为 `algorithm-api` 独立模块，宿主改为依赖该模块；实例和包引用、版本解析、依赖范围及实际求值接口不再随应用源码定义。独立模块的三项回归通过：无宿主实现求值、旧 JSON 与固定引用读回、版本范围比较。此项证明接口可独立编译，不代表内置算法包加载和历史二进制保留已经完成。

物理组算法已独立构建为可安装 JVM 包。开发工具实测安装、常驻进程连续两次求值、卸载及原包重装后求值均通过，完整结果与应用进程内的同一实现一致，包含输出别名和无关素材保留；安装包不含应用、UI、工程或 Umamo 类。工作进程通过带摘要的模型对象差异返回结果，不委托宿主重新执行物理算法。对象传输与结构校验定向测试通过。当前包身份改为 `builtin.70687973696373.v1`，以 `physics` 别名保持工程类型；完整包保留、旧版本目录重开、实例 JSON 读回后的固定引用求值及卸载重装恢复均通过开发工具检查。别名冲突与管理 schema 定向回归通过。这尚未覆盖其他内置算法迁出，也不代表完整工程冷重放验收已完成。

动作算法已迁到 `:algorithms:motion`，配置数据、JSON 读写和曲线转换由独立模块提供，应用注册入口只委托调用。独立模块的两项回归通过，覆盖四种插值、事件、参数角色、固定输出 ID、冲突与取消；应用动作回归和分层约束检查通过，物理与动作两种独立包均通过安装、常驻进程求值、目录重开和卸载重装恢复检查，且安装包不含应用或 Umamo 类。此项尚未覆盖其余生成模板迁移。

摆动算法已迁到 `:algorithms:swing`：网格包裹、关键形生成与物理组定义独立执行，应用入口不再把求值交给编辑日志。开发工具验证包裹结果与原日志重放一致，并通过真实工作进程、安装目录重开和卸载重装恢复；静止姿态与固定边的独立回归通过。此模块依赖 GPL Umamo 和格式转换器，安装包含引擎但不含应用、工程、历史或 UI 类。派生输出规则约束旧名称前缀、实例输出 token、对象种类与规范后缀，定向验证通过。

烘焙模拟求值已迁到 `:algorithms:simulation`。真实安装包验证通过：自动权重与原日志路径一致，输出包含模式参数、网格关键形和物理组，目录重开与卸载重装后可恢复。模拟导出及无窗口烘焙入口的相关回归通过。数值烘焙仍在原流水线中执行，未调整求解器；基础绑定仍待独立迁移。此批迁移没有新的完整生成性能测量，不表示已达到 4 秒目标。

基础绑定开始迁入 `:algorithms:binding`。目前拆出表情开关参数及透明度曲线计算，由原生成器和修改器共享；普通自定义表情不再为了获取这些通道调用整套绑定生成器，标准参数名称冲突仍使用原兼容路径。独立核函数回归、修改器相关回归及表情透明度／顺序／应用前缀等价检查通过。表情应用已进一步迁为独立 `ExpressionAlgorithm`，经作者输入上下文执行；通道残差合成由应用和插件共用。独立模块测试验证作者透明度残差、未选网格和取消，原表情等价回归继续通过。表情开关现已生成独立安装包，真实工作进程的连续求值、目录重开、实例身份恢复、卸载重装及规范入口调用通过开发工具检查。宿主批准的动态共享参数定向验证通过，错误定义及未批准的新增参数被拒绝。其余绑定尚未完成独立包迁移，也未实测本项对完整生成耗时的改善。

六种语言（Python、Kotlin、Rust、C、C++、C#）的示例已在 Windows 上构建为独立安装包，通过隔离目录安装、常驻进程连续两次真实求值及卸载检查。共享管理接口的严格 schema、包身份和作者输入缓存有定向回归；禁用缓存后的完整 IR 与缓存结果一致。此项是开发工具验收，不代表 Agent 建模或 GUI 人工验收。

内置算法已逐项提供插件身份、完整包版本与入口代码摘要，新建实例固定引用，旧实例仍按原格式读取。摆动、模拟、物理、动作、表情开关、眉眼透发和皮肤裁切已拆出独立实现入口；GUI／MCP 支持逐项启停，外部包可声明对内置入口的版本依赖。身份持久化、严格 schema、依赖停用与恢复已通过定向回归。其余绑定类仍调用共享模板生成服务，尚非独立安装 JAR，其历史实现的独立分发与保留尚未完成，不能视为全部插件化验收完成。
