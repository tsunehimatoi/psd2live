# 간소 작업 공간과 모바일 설계(설계 중)

[문서 목록](../README.md) · [로드맵](../ROADMAP.md) · [MCP 사용과 인터페이스](../agent/MCP_AUTHORING.md) · [앞뒤 분리 튜토리얼](../guide/DEPTH_SPLIT.md)

> **상태 설명**: 이 문서는 **설계 중**인 방안이며, 아직 코드로 구현되지 않았습니다. 본문에서 인용하는 `WorkspaceHost`, `AgentMcpService`, `source_split_depth`, `settings_update`, `layer_classify` 등의 하위 능력은 현재 저장소에 이미 구현된 모듈입니다.

## 1. 배경과 목표

현재 데스크톱 작업 공간은 전문 Live2D 모델링 흐름을 위해 설계되어 있습니다. 일곱 가지 캔버스 모드, 수십 개의 패널, 단축키 체계, 많은 프로젝트 개념이 들어 있습니다. 「그림을 움직이는 모델로 만들고 싶을」 뿐인 초보자에게는 학습 비용이 전통적인 전문 도구와 비슷합니다.

**간소 작업 공간(Lite Workspace)**의 목표는 **진입 장벽이 없고, 터치가 우선이며, 휴대폰에서도 조작할 수 있는** 간결한 입구를 제공하는 것입니다.

- **복잡한 설명과 남는 버튼이 없습니다**: 전문 용어, 빽빽한 파라미터 표, 여러 캔버스, 복잡한 메뉴를 빼니다. 직접적인 제스처와 최대 1–2단계 마법사로 조작을 끝냅니다.
- **사람이 해야 하고 자동 생성으로 대신할 수 없는 필수 도구만 남깁니다**: 예를 들어 파츠가 앞뒤로 엇갈리는 **앞뒤 분리**, 이목구비 맞춤 미세 조정, 파츠 부위 오류 수정입니다.
- **MCP로 외부 Agent에 연결합니다**: 사용자는 간소 화면에서 복잡한 패널을 조작하지 않습니다. 고급 수정은 MCP를 통해 AI Agent가 처리합니다.
- **완전한 프로젝트와 그대로 통합니다**: 아래층은 같은 `.psd2live` v2 프로젝트와 `WorkspaceHost` 명령 채널을 계속 씁니다. 간소판과 완전한 데스크톱판 사이를 손실 없이 전환하고 다시 열 수 있습니다.

## 2. 경계와 취사선택(무엇을 하고 / 하지 않는지)

| 차원 | 간소 작업 공간이 남기는 것 | 간소 작업 공간이 숨기는 것(완전판 또는 MCP에 맡김) |
| --- | --- | --- |
| 가져오기와 생성 | PSD / 그림을 가져오거나 프로젝트를 열고, `recommended` 프리셋으로 자동 생성 | 메시 밀도를 수동으로 수정, 모듈별 스위치 표, 모디파이어 스택 명세 |
| 미리보기와 시험 | 한 손가락 드래그로 따라가기, 두 손가락 확대·이동, 표정/모션 캡슐, 전체 폭 슬라이더 | 타임라인 키프레임과 곡선 편집, 파라미터 표의 축별 수치 편집, 물리 진자 노드 그래프 |
| 수동 다듬기 | **앞뒤 분리 마법사**, 이목구비 특징점 핸들 미세 조정, 레이어 부위/무시 표시, 실행 취소/다시 실행 | 메시 점 추가/변 삭제/삼각분할, 범용 변형 브러시, 스켈레톤 리그와 가중치 칠하기, 완전한 페인팅 도구 |
| AI 협업 | **MCP 한 번에 켜고 끄기와 연결 설정**, 조작 상태 안내와 한 번에 실행 취소 | 복잡한 일괄 트랜잭션 디버그, 하위 Schema 브라우저 |
| 내보내기 | 자주 쓰는 형식을 한 번에 내보내기(VTube Studio 패키지 / `.p2lrt` / 미리보기 애니메이션) | 대상별 다운그레이드 스위치, 내보내기 손실 보고서 명세 표 |

## 3. 핵심 작업 흐름(네 단계 닫힌 고리)

간소 작업 공간은 하나의 주 흐름으로 짜여 있습니다. 사용자가 「메시—디포머—파라미터—키폼」의 계층 개념을 이해할 필요는 없습니다.

1. **가져와서 자동 생성**:
   - 로컬 PSD / 그림, 또는 이미 있는 `.psd2live` 프로젝트를 고릅니다.
   - `project_import_psd`(기본 `recommended` 프리셋)를 자동으로 호출해 바로 움직이는 모델을 만들고, 실시간 미리보기로 들어갑니다.
2. **제스처로 시험하고 전체를 조절**:
   - 캔버스에서 바로 끌어, 고개 돌리기, 시선 따라가기, 호흡, 머리카락/의상 흔들림을 미리 봅니다.
   - 아래쪽에 자주 쓰는 표정/모션 전환 몇 가지와 「모션 폭」 전체 슬라이더(`settings_update.rigTuning`에 매핑)를 둡니다. 파라미터 슬라이더를 하나씩 조정할 필요가 없습니다.
3. **필요한 사람 개입 도구**:
   - **앞뒤 분리(핵심으로 남기는 도구)**: 「같은 레이어의 일부는 앞, 일부는 뒤」인 교차 문제(옷깃과 목, 머리카락과 어깨 장식)를 해결합니다. 아래에서는 `source_split_depth`와 앞층 지우개 페인팅 세션을 그대로 쓰지만, 오른쪽 클릭 다중 선택과 모드 전환 대신 세 단계 터치 마법사를 씁니다.
     1. 분리할 레이어를 누릅니다(예: 상의).
     2. 그 사이에 끼어야 하는 레이어를 누릅니다(예: 목).
     3. 앞뒤 두 층을 자동으로 복제하고 지우기 상태로 들어갑니다. 손가락/터치펜으로 앞층에서 뒤에 숨겨야 할 영역을 문질러 지우고, 앞뒤 가림을 실시간으로 본 뒤 「완료」를 누르면 히스토리 한 단계가 제출됩니다.
   - **특징점 미세 조정**: 자동으로 맞춘 눈꼬리, 눈썹 봉우리, 입꼬리가 조금 어긋나면, 캔버스에 큰 터치 핸들(`settings_update.moves`에 대응)을 표시합니다. 끌면 다시 맞춥니다.
   - **부위 빠른 오류 수정**: 파츠를 누른 뒤, 직관적인 부위 아이콘으로 분류를 고칩니다(예: 「이것은 왼쪽 눈 / 앞머리 / 무시」). `layer_classify`와 다시 생성에 대응합니다.
4. **한 번에 내보내기**:
   - 용도를 고릅니다(예: 「VTube Studio용」 또는 「`.p2lrt` 내보내기」). 내보내기는 백그라운드에서 실행됩니다. 진행을 막는 문제가 있을 때만 짧은 안내를 줍니다.

## 4. 휴대폰과 터치 우선 인터페이스

휴대폰 세로 화면, 태블릿 가로 화면, 데스크톱 좁은 창에서도 매끄럽게 조작되도록, 인터페이스는 다음 제약을 따릅니다.

- **캔버스가 주 뷰포트를 채웁니다**: 영역의 85% 이상을 모델 캔버스에 둡니다. 상주하는 좌우 사이드바와 위쪽의 여러 층 메뉴 막대를 없앱니다.
- **간소한 위쪽 막대**: 핵심 입구 4개만 남깁니다. `工程/返回`, `撤销 / 重做`(`history` 분기 히스토리에 대응), `MCP 状态`, `导出`.
- **한 층의 맥락 아래 막대**:
  - 기본 상태에서는 주 탭 세 개만 제공합니다. `试动`, `修整`, `MCP`.
  - 구체적인 도구(예: 「앞뒤 분리」의 지우기 단계)에 들어가면, 아래 막대가 그 자리에서 그 도구의 최소 제어 막대로 바뀝니다(브러시 크기 슬라이더, 획 실행 취소, 취소 / 완료). 캔버스를 가리는 떠 있는 창은 띄우지 않습니다.
- **호버 없음, 오른쪽 클릭 없음, 단축키 의존 없음**:
  - 마우스 호버 안내를 유일한 설명으로 쓰지 않습니다. 오른쪽 클릭 컨텍스트 메뉴를 쓰지 않으며, `Shift` / `Ctrl` 다중 선택에 의존하지 않습니다. 다중 선택은 모두 명시적인 「누르는 단계」로 바꿉니다.
  - 모든 터치 대상은 충분한 히트 영역을 유지합니다(권장 ≥ 44–48 dp). 슬라이더와 캔버스 드래그 제스처는 서로 배타적이어서, 모델을 잘못 건드리지 않습니다.

## 5. MCP 연결 방안

간소판은 복잡한 편집 능력을 MCP로 외부 Agent에 맡깁니다. 화면은 간소하게 유지하고, 상한은 막지 않습니다.

- **기존 서비스와 계약을 재사용합니다**:
  - `AgentMcpService`의 **간소 도구 집합**(Streamable HTTP + Bearer Token)을 그대로 씁니다. 외부 Agent는 `workspace_inspect`, `workspace_apply_edits`, `source_split_depth`, `settings_update`, `author_axis` 등 완전한 애플리케이션 층 능력을 호출할 수 있습니다.
  - 간소 UI와 `WorkspaceHost`의 `state` 낙관적 동시성 제어, 히스토리 노드 하나 제출 의미를 공유합니다. Agent가 한 수정은 간소 쪽 캔버스에 바로 보이고, 사용자는 한 번에 실행 취소할 수 있습니다.
- **간소 쪽 연결 경험**:
  - `MCP` 패널은 세 가지만 보여 줍니다. 서비스 스위치, 현재 연결 상태(연결 안 됨 / 연결됨 / Agent가 편집 중), 그리고 「연결 설정 복사 / 프롬프트 설치」입니다.
  - 휴대폰/태블릿에서 간소판을 쓸 때, 밖에서 도달할 수 있는 호스트 주소를 설정하거나, 페어링 토큰으로 같은 LAN의 Agent 호스트에 접속할 수 있습니다.

## 6. 기술 재사용과 단계별 제안

### 6.1 아키텍처 재사용

저장소는 데스크톱 UI와 애플리케이션 층의 분리를 이미 마쳤습니다(`application`은 `ui`와 Compose에 의존하지 않으며, `LayerDependencyTest`가 경계를 지킵니다).

- **애플리케이션 층과 코어 층은 다시 쓰지 않습니다**: 간소 작업 공간은 `WorkspaceHost`의 가벼운 프런트 표현 층입니다(데스크톱의 `DesktopPresentation`과 같은 역할). 생성, 편집, 히스토리, MCP, 내보내기는 모두 기존 명령 채널을 탑니다.
- **프로젝트와 런타임 호환**: 간소 쪽에서 저장한 `.psd2live`는 데스크톱 완전판에서 바로 이어서 다듬을 수 있습니다. 완전판에서 저장한 프로젝트도 간소 쪽에서 시험하고, 앞뒤 분리를 하거나, 내보낼 수 있습니다.

### 6.2 단계별 적용

1. **1기(데스크톱 안의 간소 모드)**: 기존 데스크톱 앱에 「간소 작업 공간」 뷰 전환을 제공합니다. 네 단계 주 흐름, 앞뒤 분리 마법사, MCP 바로가기의 쓰기 쉬움을 먼저 검증합니다. 플랫폼을 넘는 런타임 차이는 다루지 않습니다.
2. **2기(좁은 화면과 순수 터치 상호작용)**: 오른쪽 클릭/단축키 없는 상호작용, 세로 화면의 한 층 아래 막대, 특징점 터치 핸들, 부위 빠른 오류 수정을 마칩니다.
3. **3기(모바일 실행 형태)**: 휴대폰/태블릿에서 Compose UI를 실행하는 배포 방식을 평가합니다. 우선 「모바일 간소 프런트 + 원격/데스크톱 `WorkspaceHost` 서비스(미리보기 스트림과 MCP 포함)」를 쓸 수 있고, `.p2lrt` 런타임과 코어를 잘라 내는 방안을 결합해 로컬에서 실행할 수도 있습니다.
