# PSD2Live

[中文](../../README.md) · [English](../en/README.md) · [日本語](../ja/README.md) · [다운로드](https://github.com/tsunehimatoi/psd2live/releases/latest) · [변경 이력](../zh/CHANGELOG.md) · [문서](../README.md)

**레이어가 나뉜 PSD에서 Live2D 모델을 자동으로 생성하고, 형태 다듬기·리깅·애니메이션·물리·텍스처 작업을 하나의 데스크톱 작업 공간에서 마친 뒤 Cubism, VTube Studio, 웹 또는 동영상으로 내보냅니다.**

![PSD2Live 편집 작업 공간: 왼쪽에 계층 트리, 가운데 캔버스는 변형 모드에서 앞머리 메시를 표시, 오른쪽에 모델 프리셋과 레이어 분류 표](../imgs/overview.webp)

PSD2Live는 레이어 이름으로 파츠를 인식해 메시, 디포머 계층, 머리·몸·이목구비 파라미터, 기본 모션, 물리와 천 시뮬레이션을 자동으로 생성합니다. 생성 결과는 출발점일 뿐입니다. 캔버스에서 계속 형태를 다듬고, 메시를 분할하고, 텍스처를 그리고, 스켈레톤을 만들고, 모션 커브를 편집하고, 텍스처 아틀라스를 조정한 다음 Cubism Editor에서 이어서 작업할 수 있는 `.cmo3`, 바로 전달할 수 있는 `.moc3` 파일 세트, 또는 다른 형식으로 내보낼 수 있습니다.

![같은 모델을 여러 머리·몸 각도로 미리 본 모습: 왼쪽, 오른쪽 아래, 정면, 오른쪽 위, 왼쪽 아래](../imgs/poses.webp)

<sub>위 이미지는 예제 PSD를 가져온 뒤 손으로 수정하지 않은 자동 생성 결과이며, 머리와 몸 각도 파라미터로 구동됩니다.</sub>

## 다운로드

[Releases](https://github.com/tsunehimatoi/psd2live/releases/latest)에서 최신 버전을 받을 수 있으며, 버전별 변경 사항은 [변경 이력](../zh/CHANGELOG.md)(중국어)을 참고하세요.

| 플랫폼 | 설치 패키지 | 설명 |
| --- | --- | --- |
| Windows 10 / 11 x64 | 포터블 ZIP, EXE, MSI | Java 런타임이 포함되어 있어 압축을 풀거나 설치한 뒤 바로 실행. 각각 ffmpeg가 포함된 `-ffmpeg` 버전도 있음. 업그레이드 시 설치된 폴더에 설치되어 경로를 다시 고를 필요 없음 |
| Linux x86_64 | Deb | 런타임과 Cubism 네이티브 미리보기 포함, X11 / GLX 필요(XWayland 사용 가능) |
| macOS 및 기타 | 설치 패키지 없음 | JDK 21을 설치한 뒤 [소스에서 실행](#소스에서-빌드) |

Windows에서 제거해도 설정과 작업 공간 데이터는 남습니다. 함께 삭제하려면 제거 마법사에서 「Remove」를 선택하고 「Also delete my PSD2Live data」를 체크하세요. 저장한 프로젝트 파일은 항상 남습니다.

Linux 네이티브 미리보기는 XWayland 없는 순수 Wayland, aarch64, musl(Alpine 등)을 지원하지 않으며, 이런 환경에서는 내장 렌더러로 자동 전환됩니다. 자세한 내용은 [Cubism 네이티브 미리보기](../en/guide/CUBISM_SDK_SETUP.md)(영어)를 참고하세요.

## 빠른 시작

1. **PSD 가져오기**: **파일 → 가져오기 → PSD에서 새 프로젝트…**(`Ctrl+Shift+O`)를 선택하거나 PSD를 창에 끌어다 놓습니다. 이어서 열리는 시작 화면에서 모델 프리셋(최소 / 기본 / 전체)을 고르고, 메시 단위로 분할할 레이어(한 레이어에 함께 그린 양쪽 다리 등)를 선택합니다.
2. **인식 결과 확인**: 레이어 표에서 각 레이어의 파츠 종류, 좌우 구분, 차분 설정을 확인하고 잘못 인식된 항목은 바로 고칩니다.
3. **미리보기와 수정**: 미리보기 작업 공간에서 모션과 물리를 확인한 다음, 필요에 따라 편집·리깅·애니메이션·물리·텍스처 작업 공간에서 수정합니다.
4. **저장과 내보내기**: `Ctrl+S`로 `.psd2live` 프로젝트를 저장하고, `Ctrl+G`로 `.moc3` / `.cmo3`를 내보냅니다. 다른 형식은 **파일 → 다른 형식으로 내보내기**에 있습니다.

<img src="../imgs/import-split.webp" width="560" alt="메시 단위 레이어 분할: legwear, footwear, eyelash, front hair가 각각 두 개의 파츠로 인식된 모습">

**처음 사용한다면 「도움말 → 튜토리얼…」(`F1`)을 여세요.** 앱 내 튜토리얼은 해당 컨트롤을 강조 표시하고 현재 단축키 설정에 맞춰 조작 방법을 안내합니다. 입문자 코스(18강)와 Cubism 경험자 코스(13강)가 있으며, [사용자 가이드](../en/guide/USER_GUIDE.md)(영어)가 그 텍스트판입니다.

## 소재 준비

자동 생성 품질은 대부분 PSD 레이어 구성에 달려 있습니다. 가장 중요한 몇 가지는 다음과 같습니다.

- 흰자, 눈동자, 윗속눈썹을 레이어로 분리하고, 눈동자는 눈꺼풀에 가려지는 부분까지 남겨 둡니다.
- 벌린 입 소재를 준비하거나 윗니, 아랫니, 혀를 분리합니다.
- 앞머리와 뒷머리를 분리하고, 가려지는 영역에는 여유분을 남겨 둡니다.
- 몸은 대체로 똑바로 선 자세로 두고, 레이어 효과와 텍스트는 미리 래스터화합니다.

전체 명명 표와 레이어 구성 권장 사항은 [PSD 소재와 명명 규칙](../en/spec/PSD_LAYER_SPEC.md)(영어)을 참고하세요. 인식되지 않은 레이어도 유지되며, 화면에서 종류를 직접 지정할 수 있습니다.

## 내보내기

**파일 → Live2D 모델 내보내기…**(`Ctrl+G`)는 Cubism 형식으로 출력합니다.

| 파일 | 용도 |
| --- | --- |
| `.psd2live` | PSD2Live 프로젝트: 원본 PSD, 소재, 설정, 모든 편집과 히스토리 분기. 작업을 이어가려면 이 파일을 저장하세요 |
| `.cmo3` | Cubism Editor 모델 프로젝트. 공식 편집기에서 검토하고 다듬는 용도 |
| `.model3.json` + `.moc3` + 텍스처, 물리, 모션 등 | 런타임 모델 파일 세트. 함께 전달해야 하며 `.model3.json`에서 불러옵니다 |
| `.psd2live.json` | 내보내기 진단 보고서. 프로젝트를 대신할 수 없습니다 |

대상 버전은 Cubism 3.0 – 5.3 중에서 고를 수 있으며(기본값 5.0), 대상 버전이 지원하지 않는 기능은 낮은 수준으로 변환되고 보고서에 표시됩니다.

**파일 → 다른 형식으로 내보내기**에서 다른 형식을 사용할 수 있습니다.

| 형식 | 설명 |
| --- | --- |
| VTube Studio | `.moc3` 파일 세트와 `.vtube.json`. 페이스 트래킹을 표준 파라미터에 매핑하고, 모션마다 핫키 하나를 할당 |
| PSD2Live 런타임 모델 / 웹 플레이어 | `.p2lrt` 모델, 또는 브라우저에서 바로 여는 WebGL 플레이어 페이지. [런타임](../zh/spec/RUNTIME.md)(중국어) 참고 |
| PNG 시퀀스, 스프라이트 시트, GIF | 모션을 샘플링해 렌더링 |
| APNG, 애니메이션 WebP, MP4, WebM, ProRes 4444 | ffmpeg로 인코딩. Windows `-ffmpeg` 패키지에는 포함되어 있으며, 그 외에는 직접 설치해야 합니다(설정에서 지정하거나 `PATH`에 추가) |
| 지정 포즈의 PSD, 원본 PSD | 현재 포즈를 레이어 PSD로 출력하거나, 생성된 레이어를 포함한 원본 PSD를 내보냄 |

모든 내보내기는 같은 중립 리그 IR을 거쳐 컴파일되며, 대상 형식이 보존할 수 없는 내용을 나열한 손실 보고서가 함께 생성됩니다. Spine 4.2, DragonBones 5.5, glTF 2.0은 실험적 대상으로, 명령줄에서만 내보낼 수 있습니다. 자세한 내용은 [내보내기 대상](../zh/spec/EXPORT_TARGETS.md)(중국어)을 참고하세요.

내보내기에 성공했다고 해서 모든 런타임에서 결과가 같다는 보장은 없으므로, 정식으로 전달하기 전에 대상 편집기와 실행 환경에서 확인하세요. 지원 범위는 [런타임과 내보내기 경계](../zh/spec/RUNTIME_EXPORT_ARCHITECTURE_AND_GAPS.md)(중국어)에 정리되어 있습니다. 내장 렌더러는 공식 SDK가 전혀 필요 없으며, [Cubism 네이티브 미리보기](../en/guide/CUBISM_SDK_SETUP.md)(영어)는 공식 런타임의 렌더링과 물리를 비교하기 위한 선택 사항입니다.

## 내 프로젝트에서 재생하기

[`runtime/`](../../runtime/)은 내보낸 `.p2lrt` 모델을 재생하는 오픈 소스(MIT) Rust 런타임입니다. 파라미터 기반 변형, 물리, 모션 클립, 그리고 눈 깜빡임·호흡·시선 추적·립싱크 같은 절차적 동작을 지원합니다. C 인터페이스를 제공하며, 웹 플레이어는 이 런타임의 WebAssembly 빌드를 사용하고, Godot 4 노드 `P2LCharacter`([`runtime/godot/`](../../runtime/godot/))도 있습니다. 편집기의 소프트웨어 미리보기도 같은 라이브러리로 계산됩니다. 자세한 내용은 [런타임](../zh/spec/RUNTIME.md)(중국어)을 참고하세요.

## 에이전트 연결(MCP)

1. PSD2Live를 실행한 상태에서 **도구 → MCP…**를 엽니다. 여기서 포트, 액세스 토큰, 공개할 도구 세트(기본값은 간소화)를 설정할 수 있습니다.
2. 사용하는 호스트(Claude Code, Codex, 일반 JSON)에 맞는 명령이나 설정을 복사합니다. Stdio만 지원하는 호스트는 저장소 루트의 [`mcp_proxy.py`](../../mcp_proxy.py)를 사용합니다.
3. 에이전트가 먼저 `workspace_overview`로 프로젝트 개요를, `workspace_inspect`로 개별 객체를 읽게 합니다. 도구로 나열되지 않은 작업은 `workspace_list_operations`로 찾아 `workspace_call`로 호출합니다. 모든 쓰기 작업은 화면에서의 편집과 같은 히스토리에 기록되며, 앱에서 실행 취소할 수 있습니다.

여러 편집은 `workspace_apply_edits`로 원자적으로 커밋하거나(모두 성공하거나 모두 적용되지 않음), `workspace_preview_edits`로 먼저 시험 실행해 프로젝트를 바꾸지 않고 기하 문제를 확인할 수 있습니다. 인터페이스 설명과 호출 예시는 [MCP 사용법과 인터페이스](../zh/agent/MCP_AUTHORING.md)(중국어)를 참고하세요. MCP 자체는 이미지를 생성하지 않으므로, 새 소재를 추가하려면 호스트에 이미지 생성 기능이 있어야 합니다. 도구를 호출할 수 있다고 해서 복잡한 모델링 작업이 안정적으로 수행된다는 뜻은 아니며, [실측 기록](../zh/STATUS.md)(중국어)에 실제 작업의 성공과 실패 사례가 정리되어 있습니다.

## 소스에서 빌드

JDK 21이 필요하며, Gradle은 저장소에 포함된 Wrapper를 사용합니다. Rust(cargo)가 설치되어 있으면 Rust 런타임도 함께 빌드하고, 없으면 자동으로 건너뛰며 편집기는 내장 계산기를 사용합니다.

```bash
# GUI 실행 (Windows: .\gradlew.bat run 또는 run-gui.bat)
./gradlew run

# 명령줄에서 PSD로 바로 모델 생성
./gradlew run --args="--input examples/tml/psd-input/tml.psd --output build/example-output"

# 프로젝트를 다른 형식으로 내보내기, 예: GIF
./gradlew run --args="export model.psd2live --target gif --set clip=Nod"

# 테스트 실행 / 현재 플랫폼용 설치 패키지 빌드
./gradlew test
./gradlew packageDistributionForCurrentOS
```

소스 빌드는 기본적으로 내장 렌더러를 사용하며, 공식 Cubism SDK는 직접 받아서 브리지 라이브러리를 따로 빌드해야 합니다. 전체 CLI 옵션, 패키징, 네이티브 미리보기 빌드는 [개발과 명령줄](../en/guide/DEVELOPMENT.md)(영어)을 참고하세요. 명령줄에서 `--lang ko`로 인터페이스 언어를 한국어로 지정할 수 있습니다.
