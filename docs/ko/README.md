# PSD2Live

**오픈 소스 2D 캐릭터 리깅·애니메이션 편집기**

레이어로 나뉜 PSD에서 움직이는 초안을 자동으로 만들고, 하나의 작업 공간에서 형태 수정, 뼈대, 물리와 시뮬레이션, 애니메이션까지 다룬 뒤<br>
Cubism, VTube Studio, 자체 런타임, 웹, 게임 엔진, 동영상으로 내보냅니다.

PSD2Live는 2D 캐릭터 리깅을 위한 완결된 도구 체인입니다. 레이어로 나뉜 PSD에서 메시, 디포머, 파라미터, 모션, 물리를 자동 생성하고, 데스크톱 편집기에서 계속 수정한 뒤 Cubism, 자체 런타임 p2lrt, 여러 범용 형식으로 컴파일합니다. 독자적인 평가 엔진, 프로젝트 형식, 분기 히스토리를 갖추고 있으며, 원클릭 생성은 출발점일 뿐입니다. 모든 수정은 재생 가능한 편집 기록으로 저장되어 다시 생성한 뒤에도 그대로 적용됩니다.

> [!NOTE]
> Cubism은 주요 내보내기 대상일 뿐 기능의 한계가 아닙니다. 뼈대, 2D 시뮬레이션처럼 Cubism에 없는 기능은 내보낼 때 네이티브 디포머, 파라미터, 키폼, 진자로 베이크되며, 납품한 모델은 PSD2Live에 의존하지 않습니다.

## 이런 분께

| 당신이 | PSD2Live가 해 주는 일 |
| --- | --- |
| **입문자라 일단 움직이는 모델이 필요하다면** | 명명 규칙대로 레이어를 나누고 가져와서 프리셋을 고르면, 몇 분 만에 대기·눈 깜빡임·끄덕임·머리카락 물리가 있는 모델이 만들어지고 VTube Studio나 웹으로 바로 내보낼 수 있습니다 |
| **모델링이 익숙하지 않아 AI에 맡기고 싶다면** | 로컬 MCP 서버로 Claude Code, Codex 같은 에이전트가 프로젝트를 직접 읽고 수정합니다. 모든 단계가 같은 히스토리에 기록되어 편집기에서 확인하고 취소할 수 있습니다 |
| **경험자로서 반복 작업을 줄이고 싶다면** | 메시, 디포머 체인, 얼굴 파라미터, 물리를 원클릭으로 생성한 뒤 캔버스에서 세부를 다듬습니다. 수작업 수정은 재생 가능한 기록으로 저장되어 다시 생성해도 유지됩니다 |
| **오픈 소스 대안이 필요하다면** | 편집기, 엔진, 프로젝트 형식이 모두 오픈 소스이며, 공식 SDK 없이 편집, 미리보기, `.moc3` / `.cmo3` 내보내기가 가능합니다 |
| **Cubism의 기능으로는 부족하다면** | 뼈대와 IK, 2D 천·머리카락 시뮬레이션, 자동 뼈대 등 Cubism에 없는 도구를 내보낼 때 네이티브 구조로 베이크합니다 |
| **캐릭터를 내 프로그램에 넣고 싶다면** | 오픈 소스 Rust 런타임 p2lrt는 C / C++, .NET, Android, 웹, Godot에 연동되며 소프트웨어 렌더러를 내장합니다. 동영상, 연번 이미지, Spine, glTF(실험적)로도 내보낼 수 있습니다 |

## 핵심 기능

| 분야 | 기능 |
| --- | --- |
| **자동 생성** | 중 / 영 / 일 / 한 레이어 이름 인식. 적응형 메시, 머리와 몸의 디포머 체인, 얼굴 파라미터, 대기 / 깜빡임 / 끄덕임 / 고개 젓기 모션, 머리카락 물리와 천 시뮬레이션 |
| **캔버스 편집** | 선택, 변형, 편집, 시뮬레이션, 뼈대, 페인트, 미리보기의 7가지 모드. 변형 브러시, 메시 토폴로지 편집, 레이어 분할과 앞뒤 분할, Warp / Rotation, Glue |
| **뼈대와 시뮬레이션** | 자동 뼈대, FK / IK, 프리셋 모션, XPBD 천·머리카락 시뮬레이션. 모두 Cubism 네이티브 구조로 베이크 |
| **애니메이션과 물리** | 타임라인, 키프레임, 커브. 진자를 시각적으로 편집하며 평가 결과는 Cubism Native Framework와 일치 |
| **텍스처** | 아틀라스 배치, 레이어별 텍스처 밀도, 선택적 2× / 4× 고해상도화 |
| **컴파일과 내보내기** | 모든 대상을 하나의 중립 리그 IR에서 컴파일하고, 내보낼 때마다 손실 보고서를 출력 |
| **p2lrt 런타임** | 오픈 소스 Rust 런타임: C ABI, 소프트웨어 렌더러, WebAssembly 웹 플레이어, Godot 4 노드, .NET과 Android 빌드. 편집기의 평가와 포즈 단위로 일치 |
| **에이전트** | 180개가 넘는 공개 작업을 제공하는 로컬 MCP 서버. 편집기와 편집 명령·히스토리를 공유하며 원자적 일괄 편집과 시험 실행 지원 |

## Cubism과의 관계

PSD2Live는 Cubism Editor나 SDK 없이 동작하면서 Cubism 형식과의 호환성을 유지합니다. 각 기능은 Cubism에 들어갈 수 있는지에 따라 세 단계로 나뉩니다.

| 단계 | 의미 | 예 |
| :---: | --- | --- |
| **무손실** | Cubism이 네이티브로 지원하거나 편집 과정에만 영향 | 메시, 디포머, 파라미터, 물리, 모션. 브러시, 분할, 자동 생성 |
| **베이크** | Cubism에는 없지만 키폼, 파라미터, 진자로 베이크 가능 | 뼈대와 IK, 천 / 머리카락 시뮬레이션, 흔들림 생성 |
| **런타임 전용** | 베이크할 수 없으며 자체 런타임, 웹, Godot, 래스터 내보내기에서만 동작 | 계획 중인 동적 조명과 스타일 렌더링. [로드맵](../zh/ROADMAP.md)(중국어) 참고 |

`.moc3` / `.cmo3`로 내보낼 때 뒤의 두 단계는 대상 버전(Cubism 3.0 – 5.3)에 맞게 변환되고 손실 보고서에 기록됩니다.

## 다운로드

[Releases](https://github.com/tsunehimatoi/psd2live/releases/latest)에서 최신 버전을 받을 수 있으며, 버전별 변경 사항은 [변경 이력](../zh/CHANGELOG.md)(중국어)을 참고하세요.

| 플랫폼 | 패키지 | 설명 |
| --- | --- | --- |
| Windows 10 / 11 x64 | 포터블 ZIP, EXE | Java 런타임 포함. 압축을 풀거나 설치한 뒤 바로 실행. 각각 ffmpeg가 포함된 `-ffmpeg` 버전도 있음 |
| Windows 11 ARM64 | 포터블 ZIP, EXE | Java 런타임 포함. Cubism 네이티브 미리보기 없음(Live2D가 이 플랫폼용 Cubism Core를 제공하지 않음), 미리보기는 PSD2Live 런타임 사용 |
| Linux x86_64 / arm64 | Deb | 런타임과 Cubism 네이티브 미리보기 포함(arm64는 Live2D의 실험 버전). X11 / GLX 필요(XWayland 사용 가능) |
| macOS 및 기타 | 패키지 없음 | JDK 21 설치 후 [소스에서 실행](#소스에서-빌드) |

<details>
<summary>업그레이드, 제거, Linux 안내</summary>

- **업그레이드**: 설치된 폴더에 설치되어 경로를 다시 고를 필요가 없습니다. 3.1.x 이하의 EXE / MSI 설치는 자동으로 제거되고 그 폴더를 그대로 사용합니다.
- **제거**: 설정과 작업 공간 데이터는 기본적으로 남습니다. 제거할 때 PSD2Live 데이터도 삭제할지 묻고, 「예」를 고르면 함께 삭제됩니다. 저장한 프로젝트 파일과 설치 폴더에 넣은 파일은 항상 남습니다.
- **Linux**: 네이티브 미리보기는 XWayland가 없는 순수 Wayland와 musl(Alpine 등)을 지원하지 않으며, 이런 환경에서는 내장 렌더러로 자동 전환됩니다. [Cubism 네이티브 미리보기](../en/guide/CUBISM_SDK_SETUP.md)(영어)를 참고하세요.

</details>

## 빠른 시작

1. **PSD 가져오기**: **파일 → 가져오기 → PSD에서 새 프로젝트…**(`Ctrl+Shift+O`)를 선택하거나 PSD를 창에 끌어다 놓습니다. 시작 화면에서 모델 프리셋(최소 / 기본 / 전체)을 고르고, 메시 단위로 분할할 레이어(한 레이어에 함께 그린 양쪽 다리 등)를 선택합니다.
2. **인식 결과 확인**: 레이어 표에서 각 레이어의 파츠 종류, 좌우 구분, 차분 설정을 확인하고 잘못 인식된 항목은 바로 고칩니다.
3. **미리보기와 수정**: 미리보기 작업 공간에서 모션과 물리를 확인한 다음, 필요에 따라 편집·리깅·애니메이션·물리·텍스처 작업 공간에서 수정합니다.
4. **저장과 내보내기**: `Ctrl+S`로 `.psd2live` 프로젝트를 저장하고, `Ctrl+G`로 `.moc3` / `.cmo3`를 내보냅니다. 다른 형식은 **파일 → 다른 형식으로 내보내기**에 있습니다.

> [!TIP]
> **처음 사용한다면 「도움말 → 튜토리얼…」(`F1`)을 여세요.** 앱 내 튜토리얼은 해당 컨트롤을 강조 표시하고 현재 단축키 설정에 맞춰 안내합니다. 입문자 코스(18강)와 Cubism 경험자 코스(13강)가 있으며, [사용자 가이드](../en/guide/USER_GUIDE.md)(영어)가 그 텍스트판입니다.

### 소재 준비

자동 생성의 품질은 주로 PSD 레이어 구성에 달려 있습니다.

- 흰자, 홍채, 윗속눈썹을 나누고, 눈꺼풀에 가려지는 홍채 부분도 남겨 둡니다.
- 입을 벌린 소재를 준비합니다(또는 윗니, 아랫니, 혀를 나눕니다).
- 앞머리와 뒷머리를 나누고, 가려지는 영역에 여유를 둡니다.
- 몸은 대체로 똑바로 세우고, 레이어 효과와 텍스트는 미리 래스터화합니다.

전체 명명 규칙은 [PSD 소재와 명명 규칙](../en/spec/PSD_LAYER_SPEC.md)(영어)에 있습니다. 인식되지 않은 레이어도 남아 있으며 화면에서 직접 종류를 지정할 수 있습니다.

## 내보내기와 재생

| 대상 | 출력 |
| --- | --- |
| **Cubism Editor** | `.cmo3` 모델 프로젝트. 공식 편집기에서 확인하고 다듬기 |
| **Cubism 런타임** | `.model3.json` + `.moc3`와 텍스처, 물리, 모션 등 파일 묶음. `.model3.json`에서 불러오기 |
| **VTube Studio** | `.moc3` 파일 묶음과 `.vtube.json`. 얼굴 추적을 표준 파라미터에 연결하고 모션마다 단축키 |
| **내 프로그램 / 엔진 / 웹** | C / C++, .NET, Unity, Godot, Android용 `.p2lrt` 모델, 또는 브라우저에서 바로 여는 WebGL 재생 페이지 |
| **이미지와 동영상** | PNG 연번, 스프라이트 시트, GIF. APNG, 애니메이션 WebP, MP4, WebM, ProRes 4444(ffmpeg 사용) |
| **PSD** | 현재 포즈의 레이어 PSD, 또는 생성 레이어를 포함한 원본 PSD |
| **실험적** | Spine 4.2, DragonBones 5.5, glTF 2.0. 명령줄에서만 내보내기 가능 |

`Ctrl+G`로 Cubism 형식을 내보내며 대상 버전은 3.0 – 5.3(기본 5.0) 중에서 고릅니다. 나머지는 **파일 → 다른 형식으로 내보내기**에 있습니다. [내보내기 대상](../zh/spec/EXPORT_TARGETS.md)(중국어)을 참고하세요.

> [!IMPORTANT]
> 작업을 이어 가려면 `.psd2live` 프로젝트를 저장하세요. 원본 PSD, 소재, 설정, 모든 편집과 히스토리 분기가 들어 있습니다. 내보낼 때 함께 생기는 `.psd2live.json`은 진단 보고서일 뿐입니다. 내보내기에 성공했다고 모든 런타임에서 같은 결과가 나오는 것은 아니므로, 납품 전에 대상 편집기와 실행 환경에서 확인하세요. 지원 범위는 [런타임과 내보내기 경계](../zh/spec/RUNTIME_EXPORT_ARCHITECTURE_AND_GAPS.md)(중국어)를 참고하세요.

내장 렌더러는 공식 SDK 없이 동작합니다. [Cubism 네이티브 미리보기](../en/guide/CUBISM_SDK_SETUP.md)(영어)는 선택 사항으로, 공식 런타임의 렌더링과 물리를 비교할 때 사용합니다.

## p2lrt 런타임

[`runtime/`](../../runtime/)은 내보낸 `.p2lrt` 모델을 재생하는 오픈 소스(MIT) Rust 런타임입니다. 편집기의 소프트웨어 미리보기도 같은 라이브러리로 평가합니다.

| **물리와 모션** | physics3.json 의미를 따르는 진자 물리(바람과 안정화 포함). 최대 16개 모션 레이어를 우선순위로 겹치고 이벤트와 파츠 / 전체 불투명도 커브를 지원하며, 페이드는 Cubism과 동일. 여러 표정 동시 적용 |
| **절차적 동작** | 눈 깜빡임, 호흡, 시선 추적, 립싱크(오디오로 구동 가능). 호스트 레이어로 모션 위에 외부 파라미터(얼굴 추적 등)를 겹칠 수 있음 |
| **고급 확장** | 선택적으로 활성화: 관절 런타임 스키닝, 정확한 링크, XPBD 실시간 천·머리카락과 충돌. 끄면 결과가 핵심 평가와 비트 단위로 일치 |
| **렌더링** | 헤더의 그리기 규칙대로 호스트가 직접 그리거나, 내장 소프트웨어 렌더러 `p2l_render`로 RGBA 이미지에 바로 그림: 모든 색 / 알파 블렌드 모드, 마스크, 분리 그룹, 컬링을 편집기의 기준 래스터라이저와 같은 규칙으로 처리. 메시별 변경 플래그로 바뀐 부분만 업로드 가능 |

## 에이전트 연결(MCP)

1. MCP 서버는 기본으로 켜져 있으며 PSD2Live와 함께 `http://127.0.0.1:23871/mcp`에서 시작합니다. **도구 → MCP…**에서 끄거나 포트, 액세스 토큰, 공개할 도구 세트(기본값은 간소화)를 설정할 수 있습니다. 액세스 토큰은 로컬 사용자 설정(Java Preferences)에 평문으로 저장됩니다.
2. 사용하는 호스트(Claude Code, Codex, 일반 JSON)에 맞는 명령이나 설정을 복사합니다. Stdio만 지원하는 호스트는 저장소 루트의 [`mcp_proxy.py`](../../mcp_proxy.py)를 사용합니다.
3. 에이전트가 먼저 `workspace_overview`로 프로젝트 개요를, `workspace_inspect`로 개별 객체를 읽게 합니다. 도구로 나열되지 않은 작업은 `workspace_list_operations`로 찾아 `workspace_call`로 호출합니다.

여러 편집은 `workspace_apply_edits`로 원자적으로 커밋하거나(모두 성공하거나 모두 적용되지 않음), `workspace_preview_edits`로 먼저 시험 실행할 수 있습니다. 인터페이스 설명과 호출 예시는 [MCP 사용법과 인터페이스](../zh/agent/MCP_AUTHORING.md)(중국어)를 참고하세요.

> [!NOTE]
> MCP 자체는 이미지를 생성하지 않으므로, 새 소재를 추가하려면 호스트에 이미지 생성 기능이 있어야 합니다. 도구를 호출할 수 있다고 복잡한 모델링 작업이 안정적으로 수행되는 것은 아니며, [실측 기록](../zh/STATUS.md)(중국어)에 실제 작업의 성공과 실패 사례가 정리되어 있습니다.

## 소스에서 빌드

JDK 21이 필요하며 Gradle은 저장소에 포함된 Wrapper를 사용합니다. Rust(cargo, rustc 1.87 이상)가 설치되어 있으면 Rust 런타임도 함께 빌드합니다. cargo가 없거나 rustc가 오래되었으면 알림을 표시하고 건너뛰며 편집기는 내장 평가기를 사용합니다(`rustup update` 후 빌드할 수 있습니다).

```bash
# GUI 실행(Windows: .\gradlew.bat run 또는 run-gui.bat)
./gradlew run

# 명령줄에서 PSD로 모델 생성
./gradlew run --args="--input examples/tml/psd-input/tml.psd --output build/example-output"

# 프로젝트를 다른 형식으로 내보내기(예: GIF)
./gradlew run --args="export model.psd2live --target gif --set clip=Nod"

# 테스트 / 현재 플랫폼용 패키지
./gradlew test
./gradlew packageDistributionForCurrentOS
```

소스 빌드는 기본적으로 내장 렌더러를 사용합니다. 공식 Cubism SDK는 직접 받아 브리지 라이브러리를 따로 빌드해야 합니다. 전체 CLI 옵션, 패키징, 네이티브 미리보기 빌드는 [개발과 명령줄](../en/guide/DEVELOPMENT.md)(영어)을 참고하세요.
