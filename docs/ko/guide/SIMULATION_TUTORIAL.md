# 시뮬레이션 그림 안내: 머리카락과 의상을 자연스럽게 흔들기

[문서 목차](../README.md) · [시뮬레이션과 베이크](SIMULATION.md) · [캔버스 편집](CANVAS_EDITOR.md) · [조작 요약](USER_GUIDE.md)

머리카락, 치마 자락, 헐렁한 의상은 시뮬레이션으로 따라오기, 지연, 되튀김을 얻을 수 있습니다. 이 안내는 먼저 앞머리의 수정 전후 비교로 조정 목표를 설명한 다음, 고정점 가중치와 베이크 조작을 보여 줍니다.

## 문제와 수정 목표를 먼저 봅니다

자동으로 만든 고정 범위가 모든 소재에 맞지 않을 수 있습니다. 이 예에서는 앞머리가 흔들릴 때 얼굴 옆 머리카락 묶음의 형태와 위치를 조정해야 합니다. 머리카락 뿌리는 머리를 따르게 두고, 아래에서 자유롭게 움직일 수 있는 영역을 조정해 앞머리를 원하는 윤곽에 더 가깝게 만듭니다.

![앞머리 시뮬레이션 수정 전후 비교: 왼쪽은 수정 전, 오른쪽은 수정 후](../../imgs/simulation-tutorial/preview-comparison.webp)

*왼쪽은 수정 전의 전체 미리보기에서, 오른쪽은 수정 후의 부분 미리보기에서 가져왔습니다. 잘라 붙여 머리 비교 그림 한 장으로 만들었습니다. 두 스크린샷의 원래 내용을 남겨 얼굴 옆 머리카락 묶음을 대조하기 쉽게 했습니다. 동적인 흔들림은 파라미터 변화나 모션 재생으로도 확인해야 합니다.*

조정 순서는 다음과 같습니다. **고정점 확인 → 가중치 페인트로 고정 범위 수정 → 참조 시뮬레이션 관찰 → 다시 베이크 → 내보내기 결과 확인**. 고정점을 수정할 때는 뿌리 연결을 남기고, 그라데이션으로 어느 영역이 머리를 따르고 어느 영역이 흔들릴 수 있는지를 조절합니다.

## 작업 전 준비

**참조 시뮬레이션**은 실시간 조정용이고, **내보내기 결과**는 베이크 뒤의 모습을 보는 용도입니다. 이 움직임이 내보낸 모델에 나타나게 하려면 베이크를 마쳐야 합니다. 먼저 메시와 리그가 이미 생성된 모델을 연 다음, 아래 단계를 따르세요.

## 1. 모델 프리셋에서 시뮬레이션을 켭니다

**모델 프리셋 → 물리와 시뮬레이션**을 엽니다. 앞머리와 뒷머리에는 각각 드롭다운이 있어 움직임 방식을 따로 정할 수 있습니다.

![모델 프리셋의 물리와 시뮬레이션 그룹, 그리고 머리카락 움직임 방식 드롭다운](../../imgs/simulation-tutorial/model-presets.webp)

*이 스크린샷은 드롭다운 입구를 보여 주며, 빨간 상자로 표시된 것은 「클래식 스윙」입니다. 이 안내를 따를 때는 그 위의 「시뮬레이션」을 고르세요.*

| 옵션 | 용도 |
| --- | --- |
| 시뮬레이션 | 머리카락 물리체와 고정점 가중치를 만들고 베이크 결과를 생성합니다. 이후 더 조정할 수 있습니다 |
| 클래식 스윙 | 기존의 머리카락 스윙과 진자를 쓰며, 이 안내에서 쓰는 머리카락 시뮬레이션 물리체는 만들지 않습니다 |
| 끄기 | 그 종류 머리카락의 흔들림을 끕니다 |

먼저 **앞머리**를 **시뮬레이션**으로 설정하고 생성이 끝나기를 기다립니다. 뒷머리도 참여해야 하면 **뒷머리**를 **시뮬레이션**으로 설정합니다. 일부 레이어만 처리하려면 먼저 선택한 다음 **선택만**을 켭니다.

프리셋은 머리카락 묶음 뿌리에 고정점을 자동으로 만듭니다. 기본 결과를 먼저 본 다음 손으로 조정할지 정하면 됩니다.

### 의상도 여기서 켤 수 있습니다

**의상**을 체크하면 프로그램이 부위별로 시뮬레이션을 만들고, 헐렁한 영역만 움직임에 참여하게 하며 몸에 붙는 영역은 계속 리그를 따릅니다.

![의상 프리셋 아래에 나열된 상의, 치마 헐렁함, 몸에 붙는 파츠](../../imgs/simulation-tutorial/clothing-report.webp)

*의상 줄 아래에는 시뮬레이션에 참여하는 부위와 헐렁함이 나열되고, 몸에 붙는 파츠는 「몸에 붙음, 시뮬레이션하지 않음」 한 줄로 모입니다.*

여기의 백분율은 프로그램이 소재의 헐렁함을 보고한 것으로, 프리셋이 어느 부위를 처리했는지 파악하는 데 씁니다. 실제 움직임은 고정점, 재질, 미리보기로 확인해야 합니다.

## 2. 조정할 물리체와 메시를 고릅니다

**시뮬레이션** 패널을 열고, **물리체** 목록에서 **앞머리(프리셋)**를 선택합니다. 목록 왼쪽의 체크 상자는 그 물리체를 켤지 결정합니다.

디버그할 때는 패널 위의 미리보기 스위치를 켜 라벨이 **참조 시뮬레이션**이 되게 합니다. 이때 편집기 안의 실시간 시뮬레이션이 실행되므로, 파라미터 패널에서 머리를 돌리고 몸을 기울여 머리카락 묶음이 어떻게 따라오는지 볼 수 있습니다.

고정점을 수정하려면 해당 앞머리 메시를 선택하고, 캔버스 왼쪽 위의 모드를 **시뮬레이션**으로 바꾼 다음 왼쪽 도구 모음에서 **가중치 페인트 → 고정**을 고릅니다. 시뮬레이션 패널의 **정점 가중치 그룹**을 펼치고 고정 줄의 **그리기**를 눌러 그 도구로 들어갈 수도 있습니다.

![시뮬레이션 모드에서 고정점 가중치 그룹을 선택. 앞머리 뿌리는 빨강, 끝은 파랑](../../imgs/simulation-tutorial/pin-weights.webp)

*그림에서 고른 것은 앞머리 메시이며, 색은 현재 고정점 가중치를 표시합니다. 다른 파츠가 어두워진 것은 편집 표시 효과입니다.*

| 색 | 고정점 가중치 | 의미 |
| --- | --- | --- |
| 빨강 | 1에 가까움 | 기존 리그를 단단히 따릅니다. 머리카락 뿌리나 연결부에 맞습니다 |
| 초록／노랑 | 중간값 | 일부만 고정되어 전환에 씁니다 |
| 파랑 | 0에 가까움 | 비교적 자유롭게 시뮬레이션에 참여합니다. 머리카락 끝이나 밑단에 맞습니다 |

머리카락은 보통 뿌리에서 고정하고 끝으로 갈수록 풀어 줍니다. 치마 자락은 보통 허리에서 고정하고 밑단으로 갈수록 풀어 줍니다. 먼저 연결부가 안정적인지 확인한 다음 흔들릴 수 있는 영역을 조정합니다.

## 3. 가중치 페인트로 고정 범위를 조정합니다

캔버스 왼쪽 아래 도구 옵션 막대에 가중치 페인트 설정이 표시됩니다(캔버스에서 오른쪽 클릭해도 같은 설정을 열 수 있습니다). 먼저 수정 방식을 고른 다음 **반경, 강도, 경도**를 조정합니다.

![가중치 페인트 오른쪽 클릭 설정: 반경, 경도, 강도, 그리고 더하기, 빼기, 설정, 부드럽게](../../imgs/simulation-tutorial/weight-brush.webp)

*스크린샷은 「빼기」가 선택된 상태입니다. 고정을 약하게 하고 흔들릴 수 있는 영역을 넓히기에 맞습니다.*

| 조작 | 맞는 조정 |
| --- | --- |
| 더하기 | 뿌리나 연결부를 더 단단히 고정합니다 |
| 빼기 | 너무 많이 고정된 영역이 더 자유롭게 흔들리게 합니다 |
| 설정 | 가중치를 현재 강도 값 쪽으로 서서히 당깁니다 |
| 부드럽게 | 이웃 정점 사이의 가중치 변화를 부드럽게 합니다 |

예를 들어 머리카락이 너무 많이 고정되어 묶음이 잘 흔들리지 않으면, **빼기**로 뿌리 아래를 가볍게 칠해 전환 영역을 조금씩 풀어 줍니다. 머리에 실제로 연결된 뿌리는 남깁니다. 연결부까지 미끄러지기 시작하면 **더하기**로 뿌리 가중치를 되돌립니다.

작은 반경으로 가장자리를 다듬고, 낮은 경도로 부드러운 전환을 만듭니다. 조금씩 수정하고 색을 본 다음 계속합니다. **부드럽게**로 급격한 변화를 정리할 수 있습니다. 한 방향으로 전환이 필요하면 **가중치 그라데이션**을 쓸 수도 있습니다.

## 4. 가중치 분포와 참조 시뮬레이션을 확인합니다

아래는 조정 뒤의 분포 한 가지입니다. 위쪽은 여전히 높은 고정 가중치를 유지하고, 양쪽과 머리카락 끝으로 갈수록 낮아집니다.

![조정된 앞머리 고정점 가중치. 뿌리와 자유 영역 사이에 그라데이션이 생김](../../imgs/simulation-tutorial/weights-adjusted.webp)

*중요한 것은 연결부가 안정적이고, 전환이 이어지며, 끝에 자유도가 있는 것입니다. 고정 범위는 자신의 소재에 맞게 조정합니다.*

**미리보기** 모드로 돌아가 **참조 시뮬레이션**을 켠 채로 둡니다. 천천히 고개를 돌린 다음, 빠르게 돌리고 멈춰, 따라오기, 휘둘림, 되돌아옴을 각각 봅니다. 머리카락 전체가 거의 움직이지 않으면 너무 많이 고정되지 않았는지 확인합니다. 뿌리가 미끄러지면 연결부 고정점이 충분한지 확인합니다.

시뮬레이션 패널의 **재질**에서도 조정할 수 있습니다.

| 항목 | 조정 목적 |
| --- | --- |
| 굽힘 | 머리카락 묶음이 굽기 쉬운 정도를 조절합니다 |
| 감쇠 | 움직임이 잦아드는 속도를 조절합니다. 키우면 보통 더 빨리 멈춥니다 |
| 형태 유지 | 원화 형태로 되튀는 정도를 조절합니다 |
| 늘어남 | 머리카락 묶음 길이를 유지합니다. 머리카락은 보통 1에 가까워야 합니다 |

먼저 **머리카락** 재질 프리셋을 쓰고, 한 번에 한 항목만 바꿉니다. 다른 재질, 가중치 그룹, Glue 역할은 [시뮬레이션과 베이크](SIMULATION.md)를 참고하세요.

모델 프리셋의 **고정 가중치 자동 설정**은 가중치를 다시 계산하고 다시 베이크합니다. 고정점을 손으로 다듬은 뒤 그 분포를 남기려면, 시뮬레이션 패널의 베이크 버튼을 계속 사용합니다.

## 5. 수정 후 다시 베이크합니다

가중치나 재질을 조정하면 기존 베이크는 **만료됨**이 됩니다. 시뮬레이션 패널에서 방금 수정한 물리체를 선택하고 **베이크**를 펼친 다음 **다시 베이크**를 누릅니다. 아직 결과가 없으면 버튼은 **베이크**로 표시됩니다.

![시뮬레이션 패널의 앞머리 물리체가 만료됨. 빨간 상자가 다시 베이크 버튼](../../imgs/simulation-tutorial/rebake.webp)

*빨간 상자 버튼은 현재 물리체만 베이크합니다. 여러 물리체를 갱신해야 하면 패널 위의 「모두 베이크」를 쓸 수 있습니다.*

처음에는 기본값인 **모드 수 2, 키 5, 과장 ×1.3**을 그대로 두고 한 번 베이크한 다음 관찰해도 됩니다. 모드 수는 몇 개의 파라미터로 전체 흔들림과 추가 변형을 표현할지를 정하고, 키는 형태 샘플의 세부에 영향을 주며, 과장은 베이크 뒤의 진폭을 조절합니다.

**만료됨**은 현재 설정이 이전 베이크와 다르다는 뜻이며, 내보내기는 여전히 이전 결과를 씁니다. 다시 베이크한 뒤에야 가중치와 재질 수정이 새 내보내기 결과에 나타납니다.

## 6. 베이크가 끝나기를 기다립니다

베이크하는 동안 아래쪽 상태 막대에 진행 상황이 표시됩니다. 시간은 메시와 물리체의 복잡도에 따라 달라지므로, 끝난 뒤에 결과를 확인합니다.

![시뮬레이션 베이크 중. 빨간 화살표가 아래쪽 상태 막대의 진행 막대를 가리킴](../../imgs/simulation-tutorial/bake-progress.webp)

*화살표는 이번 베이크의 진행을 가리킵니다. 끝나면 가장 최근에 베이크한 물리체는 목록에 초록 점으로 표시됩니다.*

멈춰야 하면 진행 옆의 취소 버튼을 쓸 수 있습니다. **자동 베이크**는 기본이 꺼져 있습니다. 가중치를 이어서 손으로 다듬어야 하면 먼저 수정을 모은 다음 끝난 뒤에 한꺼번에 베이크하면 됩니다.

## 7. 내보내기 결과로 돌아가 저장합니다

시뮬레이션 패널 위의 미리보기 스위치를 꺼 라벨이 **내보내기 결과**가 되게 합니다. 이때 캔버스는 베이크된 키폼과 진자를 재생하며, 내보낸 모델의 모습을 확인하는 데 씁니다.

고개 돌리기, 기울이기, 빠르게 움직인 뒤 멈추기, 몸이 위아래로 움직이는지를 확인합니다. 뿌리가 안정적인지, 끝이 자연스럽게 되돌아오는지, 의상이 원래 조형을 유지하는지를 살펴봅니다. 대조가 필요하면 같은 움직임으로 **참조 시뮬레이션**과 **내보내기 결과**를 전환합니다. 물리체의 **비교** 절을 펼쳐 참조 시뮬레이션을 내보내기 위에 겹치거나(**겹침**), 캔버스 두 장에서 **나란히** 재생할 수도 있습니다. 모션 하나를 골라 **재생**하면 둘 다 정지에서 동시에 시작하고, **검사**하면 그 모션에서의 진폭, 지연, 되돌아옴 비교를 얻습니다.

결과를 확인한 뒤 `.psd2live` 프로젝트를 저장하고 모델을 내보냅니다. 이후 가중치, 메시, 재질을 계속 수정하면 베이크 상태를 확인하고 갱신하세요.

## 자주 있는 문제

| 현상 | 먼저 확인할 것 |
| --- | --- |
| 시뮬레이션 패널에 앞머리 물리체가 없음 | 앞머리 드롭다운이 「시뮬레이션」인지, 소재가 앞머리로 인식되었는지. 대상 메시를 선택하고 시뮬레이션 패널 「새로 만들기 → 머리카락」으로 직접 만들 수도 있습니다 |
| 가중치 색이 표시되지 않음 | 대상 메시를 선택했는지, 캔버스 「시뮬레이션」 모드와 「고정」 가중치 그룹으로 들어갔는지 |
| 머리카락 뿌리가 풀리거나, 거의 흔들리지 않음 | 고정점이 너무 적거나 너무 많은지. 먼저 연결부를 안정시킨 다음 끝을 서서히 풀어 줍니다 |
| 참조 시뮬레이션은 움직이는데 내보내기 결과가 갱신되지 않음 | 베이크하지 않았거나 만료되었는지. 베이크하거나 다시 베이크해야 합니다 |
| 일부 의상 파츠에 시뮬레이션이 없음 | 의상 헐렁함 보고와 「몸에 붙음, 시뮬레이션하지 않음」 목록을 보고, 프리셋 인식이 소재와 맞는지 확인합니다 |
| 베이크 결과가 참조 시뮬레이션과 다름 | 베이크는 실시간 시뮬레이션을 맞춘 것입니다. 품질 안내를 보고, 필요하면 모드 수나 키를 조정한 뒤 다시 베이크하고, 실제 움직임으로 개선을 확인합니다 |
