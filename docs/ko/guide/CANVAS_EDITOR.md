# 캔버스 편집 요약

[문서 목차](../README.md) · [조작 요약](USER_GUIDE.md) · [앞뒤 분리 그림 안내](DEPTH_SPLIT.md) · [변형 경로](DEFORM_PATHS.md)

앱 안의 입문 경로 제 3, 6–12과에 해당합니다. 이 페이지는 캔버스 위의 편집 규칙을 주제별로 정리합니다. 버튼 위치와 현재 단축키는 도움말의 **튜토리얼**을 기준으로 합니다.

## 먼저 모드를 고르고, 그다음 도구를 고릅니다

캔버스 왼쪽 위의 모드 메뉴(Blender의 모드 드롭다운과 비슷합니다)에는 모든 모드가 나열됩니다. 메뉴가 열려 있을 때 1–7로 바로 고르고, 방향키로 이동하고, Enter로 확정할 수 있습니다. 「미리보기」도 이 메뉴에 있으며, 예전 제목 표시줄의 「미리보기」와 같습니다. 미리보기 캔버스에서 다른 모드를 고르면 편집으로 돌아갑니다.

| 모드 | 바꾸는 내용 | 자주 쓰는 도구 |
| --- | --- | --- |
| 오브젝트 | 오브젝트 선택 | 클릭 선택, 상자 선택, 올가미. 계층 트리와 동기화. 내부 조형 핸들. 도구 모음의 「만들기」 |
| 변형 | 기본 형태 또는 현재 파라미터 키폼 | 점 / 변 / 면 선택, 변환, 밀고 당기기, 스무딩, 팽창, 경로 제어점 |
| 편집 | 메시 토폴로지와 경로 바인딩 | 점 / 변 / 면 선택, 정점 배치(점 / 선), 연결, 병합, 세분화, 변 삭제, 다시 삼각화, 삭제, Glue(메시를 두 장 선택했을 때) |
| 시뮬레이션 | 시뮬레이션이 읽는 정점 가중치 그룹(이 소프트웨어만) | 가중치 페인트, 가중치 그라데이션. 아래에서 종류(고정, 강성 등)를 바꿔 칠할 그룹을 고릅니다. 모드 막대에서 천 / 머리카락을 새로 만들고, 참조 시뮬레이션(내보내지 않음)을 전환합니다 |
| 스켈레톤 | 스켈레톤 | 포즈, 본 편집. 포즈로 바꾸거나 모드를 나갈 때 본 편집을 저장합니다 |
| 페인트 | 레이어 픽셀 | 브러시, 연필, 지우개, 흐림, 채우기, 그레이디언트, 스포이트, 도형, 선택 영역 |
| 미리보기 | 수정하지 않음 | 재생, 마우스 추적, 물리, 프레임 속도 |

시뮬레이션 모드는 편집 모드와 같이 선택한 모든 메시에 동시에 작용하며, 항상 Blender의 가중치 색(파랑 0 → 초록 → 노랑 → 빨강 1)으로 현재 가중치 그룹을 표시합니다. 가중치 페인트의 고리는 모드에 따라 색이 달라집니다(더하기는 흰색, 빼기는 빨강, 설정은 강조색, 부드럽게는 청록). 마우스를 올리면 고리가 눌렀을 때 영향을 받는 정점을 표시하고, 포인터 옆 숫자는 가장 가까운 정점의 가중치입니다. Alt + 오른쪽 버튼 드래그로 반경 / 경도를 조절하고 감쇠를 미리 봅니다. 가중치 그라데이션은 가득 찬 값에서 옅어지는 위치까지 드래그합니다. 시뮬레이션 자체는 편집기 안에서만 실행되며, 내보내려면 시뮬레이션 패널에서 베이크해야 합니다. [시뮬레이션과 베이크](SIMULATION.md)를 참고하세요.

현재 도구의 설정은 몇 곳에 나뉘어 있고, 각자 역할이 다릅니다.

| 위치 | 내용 |
| --- | --- |
| 왼쪽 도구 모음 | 현재 모드의 도구. 도구마다 한 줄이고, 범주별로 구분선이 있습니다. 오브젝트 모드의 마지막 묶음은 Warp, Rotation, 변형 경로 만들기입니다. 선택한 도구의 변형(브러시 모양, 페인트 도형, 선택 방식, Glue와 스켈레톤 하위 도구, 가중치 그룹 종류)은 도구 아래에 펼쳐지며, `1`–`5`로도 고를 수 있습니다 |
| 모드 막대(캔버스 위) | 모드 메뉴 다음에는 캔버스를 어떻게 조작할지 정하는 항목이 있습니다. 변형 / 편집 모드의 선택류 도구에서 점 / 변 / 면(`1`–`3`), 그리고 현재 단계의 확인과 취소(배치, 자르기, 경로, Glue 등)입니다 |
| 도구 옵션 막대(캔버스 왼쪽 아래) | 현재 도구의 수치: 반경, 강도, 경도, 불투명도, 모드 등. 수치를 좌우로 드래그해 조절하고, 클릭하면 위로 슬라이더가 나옵니다. 페인트 모드에서는 맨 앞에 전경 / 배경색이 있습니다 |
| 캔버스 오른쪽 클릭 메뉴 | 모드 막대, 옵션 막대와 같은 설정(항목마다 한 줄)에 그 도구의 조작이 더해지며, 조작마다 아이콘이 있습니다. 열리고 마우스를 올렸을 때의 애니메이션은 모드 메뉴와 같습니다. 오브젝트 모드에서는 Warp, Rotation, 변형 경로, 스켈레톤, 스윙 만들기가 「만들기」 하위 메뉴에 모입니다. 오브젝트, 편집, 페인트 모드에서는 레이어 전체에 대한 조작도 각각 하위 메뉴가 있습니다. 「메시」에는 현재 픽셀로 메시를 다시 만들고, 이 레이어의 독립 메시를 검사하고, 가능할 때의 앞뒤 분리가 있습니다. 소재가 연결된 레이어에는 「소재」가 더 있어, 소재 창에서 열거나 연결을 해제할 수 있습니다. 나머지 내용이 10줄을 넘지 않으면 모두 바로 표시합니다. 넘을 때만 가장 큰 묶음(토폴로지, 감쇠 등)을 한 줄로 접고, 마우스를 올리면 오른쪽에서 펼칩니다. 각 패널의 오른쪽 클릭 메뉴(계층 트리, 소재, 텍스처 아틀라스, 모션, 물리 등)는 캔버스 메뉴와 모양과 열림 애니메이션이 같습니다. 누른 자리에서 펼쳐지고, 창 가장자리에 가까우면 반대쪽으로 뒤집힙니다 |

모드 막대, 옵션 막대, 오른쪽 클릭 메뉴는 같은 정의를 보여 주므로 범위가 같습니다. `[` `]` 같은 브러시 단축키가 조절하는 값도 옵션 막대에 있는 현재 도구의 같은 값입니다. 오른쪽 「도구 상세」 패널에는 공간이 더 필요한 고급 설정만 남습니다. 정밀 수치 변환, Warp / Rotation의 생성 기본값, 경로 목록, 스켈레톤 바인딩과 가중치, 페인트 팔레트입니다. 스킨 가중치 표시는 오른쪽 아래 표시 막대에서 켜고 끕니다.

기본은 휠로 확대·축소, 가운데 버튼 또는 스페이스 + 왼쪽 버튼으로 이동, Shift로 추가 선택, Alt로 선택 해제입니다.

캔버스 배경을 「바탕 화면」으로 고르면 주 창이 투명해집니다. 이 선택은 앱을 정상적으로 종료한 뒤에야 유지됩니다. 투명 창 세션이 충돌하거나 강제 종료되면, 다음 시작 때는 이전의 단색 또는 체커보드 배경으로 돌아갑니다(복원할 설정이 없으면 체커보드). 색 설정은 남습니다. 복구 정보는 세션 로그에 기록됩니다. 이렇게 하면 투명 창 고장으로 반복해서 시작하지 못하는 일을 피하지만, 기반 그래픽 드라이버나 바탕 화면 합성기 문제가 해결되었다는 뜻은 아닙니다.

고정 가중치 페인트의 조작 스크린샷과 베이크 절차는 [시뮬레이션 그림 안내](SIMULATION_TUTORIAL.md)를 참고하세요.

## 캔버스의 점과 선

모든 모드에서 편집할 수 있는 점과 선의 모양은 같고, 색에는 각각 정해진 의미가 있습니다.

| 모양 | 의미 |
| --- | --- |
| 옅은 가는 선과 작은 점 | 편집 중인 메시 또는 Warp 메시. 여러 메시를 동시에 편집하면 메시마다 자기 색으로 구분합니다 |
| 강조색, 확대, 흰 테두리 | 선택된 점, 변, 면 |
| 흰 바깥 고리 | 마우스를 올린 점. 클릭하면 선택되는 점입니다 |
| 빨간 원 | 브러시를 누르면 밀리는 점. 원이 크고 진할수록 영향이 셉니다. 마우스를 올리면 바로 보이고, 드래그 중에도 남습니다 |
| 강조색 원 | 선택 브러시를 누르면 선택되는 점 |
| 가중치 색(파랑 → 빨강) | 시뮬레이션과 스켈레톤의 가중치 |

점의 모양은 그것이 무엇인지를 나타냅니다. 메시 정점은 원, Warp 제어점은 사각형, Glue 점은 마름모입니다. 직접 클릭해 고를 수 있는 점만 표시됩니다. 오른쪽 아래 표시 막대의 메시 스위치는 각 파츠의 메시 선만 그립니다(파츠 자신의 색). 점은 다시 그리지 않습니다. 편집 중인 메시나 Warp는 캔버스가 직접 그리므로, 표시 막대는 같은 것을 한 번 더 그리지 않습니다.

## 변형과 키폼

파라미터에 바인딩되지 않은 오브젝트는 기본 형태를 편집합니다. 바인딩된 오브젝트는 현재 파라미터 조합을 편집합니다. 대상이 메시 디포머(Warp)이면 모드 막대에서 「정점」(메시 점 편집)과 「베지어」를 전환할 수 있습니다. 베지어에서는 청록 앵커와 호박색 핸들만 드래그할 수 있고, 자세한 메시는 옅게 표시되며 편집할 수 없습니다. 다른 오브젝트에서는 둘의 차이가 없어 표시하지 않습니다. 먼저 파라미터 패널에서 목표 값을 맞춘 다음 제어점을 조정합니다. 오브젝트 자신의 축과 부모가 물려받은 움직임을 확인해, 부모 포즈를 현재 오브젝트의 직접 바인딩으로 착각하지 않도록 합니다.

변형 모드의 캔버스 오른쪽 클릭 메뉴 「키폼 미러」는 현재 키의 키폼을 세로선을 기준으로 좌우 미러하고, 결과를 일반 키폼으로 씁니다. 실행 취소할 수 있습니다.

| 조작 | 작용 |
| --- | --- |
| 대칭 키로 미러 | 현재 키를 대칭 키로 미러합니다(예: AngleX 30 → −30). 이어서 그 키로 전환해 결과를 보여 줍니다. 단축키 `Shift+M` |
| 대칭 키에서 미러 | 반대 방향입니다. 대칭 키의 형태로 현재 키를 덮습니다 |
| 반대쪽 오브젝트로 미러 | 반대쪽의 같은 종류 오브젝트에 씁니다(왼쪽 눈 → 오른쪽 눈). 키도 함께 미러됩니다. L/R이 붙은 파라미터는 반대쪽으로 바뀌고(EyeLOpen → EyeROpen), 좌우 파라미터는 부호가 뒤집힙니다 |
| 제자리 좌우 반전 | 오브젝트 자신의 중심을 기준으로 현재 키를 뒤집습니다 |
| 모든 키를 반대쪽으로 미러 / 반대쪽 오브젝트로 | 모든 키를 한 번에 처리합니다. 같은 오브젝트는 현재 포즈가 있는 쪽의 키만 복사합니다 |

부호를 뒤집는 「좌우 파라미터」는 범위가 기본값을 기준으로 대칭이고, 2차원 연관의 가로축이거나 ID가 X, Z로 끝나는 파라미터입니다(AngleX, AngleZ, BodyAngleX, EyeBallX 등). 반대쪽 오브젝트는 먼저 레이어 의미로 짝을 맞추고, 그다음 ID나 이름의 L/R, Left/Right, 左/右로 짝을 맞춥니다. 미러는 오브젝트 자신의 변형만 처리하며, 좌표계는 기본 포즈의 부모입니다. 부모의 키폼은 따로 미러해야 합니다. 레이어를 여러 개 선택하면 각 메시를 따로 미러하고, 하나의 히스토리에 제출합니다.

같은 오른쪽 클릭 메뉴의 「키폼」은 현재 키의 형태를 처리하며, 결과도 일반 키폼으로 씁니다. 실행 취소할 수 있습니다. 파라미터는 오브젝트의 키 위에 정확히 있어야 합니다.

| 조작 | 작용 |
| --- | --- |
| 키폼 복사 | 현재 오브젝트가 현재 파라미터에서 보여 주는 형태를 기억합니다. 단축키 `Ctrl+Alt+C` |
| 키폼 붙여넣기 | 복사할 때 고정한 형태를 변위로 현재 키에 씁니다(메시는 원래 형태 기준, Warp와 회전 디포머는 기본 키 형태 기준). 원래 오브젝트에 다시 쓸 수도 있고, 같은 종류이고 삼각형(Warp는 행과 열)이 같으며 부모가 같은 오브젝트에 쓸 수도 있습니다. `Ctrl+Alt+V` |
| 기본 키 형태로 재설정 | 현재 키를 각 파라미터가 기본값일 때의 형태로 되돌립니다. `Ctrl+Alt+X` |
| 메시 원래 형태로 재설정 | 메시만 해당합니다. 변형되지 않은 메시로 되돌립니다 |
| (파라미터)의 인접 키로 보간 | 그 파라미터 양쪽 인접 키의 형태를 위치로 보간해 현재 키를 다시 만듭니다. 보간할 수 있는 파라미터가 여러 개이면 하나씩 나열하고, 단축키 `Ctrl+Alt+I`는 첫 번째를 씁니다 |
| 옵션을 지정해 붙여넣기… | 대화 상자에서 붙여넣을 내용(형태, 불투명도, 그리기 순서, 곱하기 색, 스크린 색), 혼합 비율(100%는 붙여넣기, 더 작으면 비율대로 혼합), 좌우 / 상하 반전(Warp는 열 / 행을 뒤집고, 메시는 정지 형태가 대칭이어야 하며 미러 위치로 정점을 대응)을 고르고, 복사한 각 형태를 어느 오브젝트에 붙여넣을지 줄마다 확인합니다 |
| 모든 키를 기본 키 형태로 복원 | 오브젝트의 모든 키를 기본 키 형태로 되돌리고 처음부터 다시 합니다 |
| 다중 키 편집… | 파라미터 키 값으로 범위를 고르고, 여러 오브젝트와 여러 키폼의 불투명도, 그리기 순서, 색을 한 번에 수정합니다(덮어쓰기, 더하기, 곱하기, 스크린) |

복사할 때 선택한 각 메시는 형태를 하나씩 기억합니다. 붙여넣을 때는 자신에게 다시 쓰거나, 그것을 받을 수 있는 다음 선택 오브젝트에 차례로 맞춥니다. 모든 형태는 복사했을 때의 모습 그대로 기록됩니다. 점을 선택했으면 붙여넣기, 재설정, 보간은 선택한 점만 바꾸며, 메뉴 줄에 점 개수가 표시됩니다. Warp의 「베지어」 단계와 회전 디포머는 항상 전체를 처리합니다. 생성기가 소유한 키폼의 형태를 바꾸면 생성 결과 덮어쓰기로 기록됩니다. 파라미터가 오브젝트의 키 위에 없거나 오브젝트가 파라미터에 바인딩되지 않았으면, 메뉴가 이유를 설명합니다.

**소프트 선택**: 선택 또는 변환 도구에서 도구 옵션 막대의 「소프트 선택」(`O`)을 켜면, 선택한 점을 드래그하거나 변환할 때 주변 점이 가장 가까운 선택 점까지의 거리에 따라 감쇠하며 따라옵니다. 「영향 범위」는 캔버스 단위이며 `[` / `]`로 조절할 수 있습니다. 감쇠 곡선은 변형 브러시와 공유합니다. 영향을 받는 점은 빨간 원으로 표시되며, 원이 클수록 더 많이 따라옵니다. 제출되는 것은 여전히 한 번의 일반 지오메트리 편집입니다.

**임시 변형**: `Shift+T` 또는 오른쪽 클릭 메뉴 「임시 변형(메시)」는 선택한 점(선택이 없으면 메시 전체 또는 Warp) 위에 일회용 격자를 깝니다. 격자 점을 드래그하면 그 안의 점이 쌍선형 보간으로 따라오고, 손을 뗄 때마다 히스토리 한 단계가 됩니다. 파라미터가 키 위에 없으면 누를 때 먼저 키에 붙습니다. 형태가 다른 조작으로 이미 바뀌어 있으면 누를 때 현재 형태로 격자를 다시 깝니다. 이 두 번의 누름은 드래그를 시작하지 않으므로, 한 번 더 누르면 됩니다. 도구 모음의 「격자」로 1×1–4×4를 전환합니다. Enter, Esc 또는 「완료」로 끝내며, 격자 자체는 저장되지 않습니다.

## 여러 캔버스, 파라미터, 애니메이션

같은 작업 공간의 모든 캔버스는 파라미터 포즈, 파라미터 잠금, 재생 제어를 공유합니다. 편집／미리보기 모드를 바꾸거나, 초점을 옮기거나, 캔버스를 숨겨도 다른 포즈로 돌아가지 않습니다. 선택, 도구, 카메라, 표시 설정은 캔버스마다 따로 저장됩니다. 작업 공간이 다르면 포즈도 각각 유지됩니다.

편집 캔버스에서 파라미터를 드래그하거나 스켈레톤으로 포즈를 잡으면 애니메이션이 일시 정지하고, 편집 값이 바로 표시됩니다. 파라미터를 재설정하거나 키에 스냅해도 자동으로 잠기지 않습니다. 애니메이션 편집기에서 타임라인을 드래그하면 샘플 포즈가 작업 공간으로 전달되며, 편집 캔버스에서도 보고 이어서 조정할 수 있습니다. 편집 값은 이전에 재생이 남긴 미리보기 프레임을 쓰지 않습니다. 포즈를 잡을 때 마우스 추적과 일시 정지된 물리가 그 값을 덮지 않습니다. 재생을 다시 켜거나 마우스 추적을 전환하면 동적 미리보기로 돌아갑니다. 미리보기 캔버스에서 파라미터를 조절하면 일시 정지된 물리의 반응을 계속 볼 수 있습니다.

애니메이션 트랙 이름 옆의 작은 눈금자는 파라미터 키를 표시하고, 곡선 보기는 값이 적힌 기준선으로 같은 키를 표시합니다. 파라미터를 삭제하면 해당 애니메이션 트랙이 제거되고, 파라미터 범위를 줄이면 애니메이션 키 값과 베지어 제어점도 함께 제한됩니다.

재생, 타임라인, 베이크는 캔버스를 자동으로 새로 만들거나 표시하거나 전환하지 않습니다. 캔버스가 필요하면 창 메뉴나 패널의 캔버스 표시 버튼으로 직접 엽니다.

## 변형 브러시

변형 브러시는 지오메트리를 바꾸고 텍스처는 바꾸지 않습니다. 제어점 선택이 없으면 현재 오브젝트의 모든 점에 작용하고, 선택이 있으면 선택한 점으로 제한됩니다. 반경은 캔버스 단위로 계산합니다. 기본은 Alt + 오른쪽 버튼 드래그로 반경 또는 경도를 조절하고, Esc로 현재 제스처를 취소합니다.

붓끝 모양은 왼쪽 도구 모음의 브러시 아래에서 고릅니다(가중치 페인트도 같습니다). 나머지 설정은 도구 옵션 막대와 캔버스 오른쪽 클릭 메뉴에 있습니다.

| 설정 | 작용 |
| --- | --- |
| 모양 | 원, 직선, 사각형 |
| 반경 / 경도 / 강도 | 작용 범위, 가장자리의 부드러움, 한 번 미는 힘 |
| 감쇠 | 중심에서 가장자리까지의 가중치 곡선: 부드럽게, 구형, 루트, 역제곱, 날카롭게, 선형, 일정, 무작위 |
| 연결된 것만 | 포인터 아래 메시와 연결된 점만 영향을 받습니다. 원형 브러시는 메시 변을 따라 거리를 잽니다 |

![변형 브러시 설정 패널과 「연결된 것만」을 켰을 때의 작용 범위](../../imgs/mesh-brush.webp)

*왼쪽: 브러시 설정. 오른쪽: 「연결된 것만」을 켜면, 원이 옆 머리카락 묶음을 덮어도 영향을 받는 정점(빨강)은 포인터가 있는 한 가닥에만 남습니다. 마우스를 올리면 이 정점들이 빨간 원으로 표시되고, 원이 클수록 영향이 셉니다. 가까이 붙은 머리카락, 윗입술과 아랫입술처럼 붙어 있는 파츠를 따로 칠할 때 적합합니다.*

## 메시 토폴로지

| 조작 | 결과 |
| --- | --- |
| 변 세분화 / 영역 세분화 | 맞은 변에 점을 더하고 삼각형을 다시 구성합니다. 인접 면은 이음매를 함께 처리합니다 |
| 연결 / 병합 | 선택한 점 사이를 연결하거나, 선택한 정점을 한 점으로 합칩니다 |
| 복사 | 선택한 정점과 그것이 완전히 덮는 면을 복사하고, 새 복제본이 선택이 됩니다 |
| 삭제 | 선택을 지우고 빈자리를 다시 만들려 합니다. 올바른 토폴로지가 되지 않으면 조작을 거부합니다 |
| 변 삭제 | 선택한 변을 삭제합니다(변 모드에서 `Del`, 또는 토폴로지 메뉴 「변 삭제」). 내부 변은 양쪽 삼각형이 이루는 사각형 안에서 다른 대각선으로 바뀝니다. 사각형이 정지 형태나 어떤 키폼, 블렌드 형태에서든 볼록하지 않으면 거부합니다(그렇지 않으면 포즈를 잡을 때 면이 뒤집힙니다). 윤곽 변은 그것이 속한 삼각형을 지우고, 더 이상 쓰이지 않는 정점도 함께 지웁니다. 정점이 한 점으로만 연결되거나 삼각형이 모두 사라지면 거부합니다 |
| 다시 삼각화 | 토폴로지 메뉴입니다. 선택한 정점 주변(선택하지 않으면 메시 전체)에서 가늘고 긴 삼각형을 더 고른 연결로 뒤집습니다. 정점, 윤곽, 텍스처는 움직이지 않습니다. 이미 가장 고르면 처리할 필요가 없다고 알립니다 |
| 정점 배치 | 자동 배치를 고쳐야 할 때 점마다 조정합니다. 「점」은 점 추가, 점 이동, 점 삭제이고, 「선」은 한 줄을 따라 연결된 변을 더합니다. 아래를 참고하세요 |

### 정점 배치

편집 모드 도구 모음에서 토폴로지 묶음의 첫 도구입니다. 일반 메시와 내부 조형이 있는 메시 모두 쓸 수 있습니다. 두 가지 모드가 있으며, 옵션 막대나 도구 모음 아래에서 전환하고, 각자의 단축키를 바로 누를 수도 있습니다.

| 모드 | 단축키 | 용도 | 로그 명령 |
| --- | --- | --- | --- |
| 점 | `Alt+M` | 점 추가, 점 이동, 점 삭제, 메시 밀도 조정. 클릭마다 또는 한 획마다 바로 제출합니다. 새 점 주변의 연결은 메시가 자동으로 정리하며, 점과 점 사이에 **변이 있다고 보장하지 않습니다** | `add_points`(`connect` / `delete` / `delete_edges` 포함) |
| 선 | `K` | 점을 하나씩 클릭해 꺾은선을 그립니다. Enter로 한 번에 제출합니다. 각 점은 이전 점과 변으로 연결되며, 메시는 이 선을 따라 **접힐 수 있습니다**(눈꺼풀, 입술 선, 주름) | `knife` |

두 모드의 착지 규칙은 같습니다. 포인터가 정점이나 변에 가까우면 스냅합니다(스냅 반경은 하나입니다. Shift는 「선」 모드에서 스냅을 잠시 끕니다). 마우스를 올린 곳에 누르면 어디에 떨어질지가 표시되며, 메시 밖에도 놓을 수 있습니다.

#### 점

| 조작 | 결과 |
| --- | --- |
| 빈 곳 클릭 | 그 자리에 정점을 하나 더합니다. 삼각형 안이면 세 개로 나누고, 변 위이면 그 변을 나누고, 메시 밖이면 가장 가까운 보이는 윤곽 변에서 삼각형을 하나 늘립니다 |
| 빈 곳에서 드래그 | 획을 따라 「점 간격」(캔버스 픽셀)마다 정점을 하나 더하고, 한 획을 한 번에 제출합니다 |
| 정점 드래그 | 정점을 이동합니다. 선택 도구와 같습니다. 텍스처는 움직이지 않고, 붙어 있는 점은 함께 이동합니다 |
| Shift + 정점 클릭 | 현재 선택된 정점 하나에서 그 점까지 선을 잇고, 그다음 선택이 그 점으로 이동합니다. Shift + 클릭을 이어 하면 꺾은선이 됩니다 |
| Alt + 클릭 | 정점을 삭제하고(빈자리를 메움) 또는 변을 삭제합니다 |

#### 선

점을 하나씩 클릭합니다. 클릭할 때마다 앵커가 하나 떨어집니다. 정점 위이면 그 정점을 쓰고, 변 위이면 그 변을 나누고, 삼각형 안이나 메시 밖이면 정점을 새로 더합니다. 이웃한 두 앵커 사이는 변이 되고, 지나가는 변은 나뉩니다. Enter(또는 모드 막대의 「선 그리기 완료」)로 선 전체를 한 번에 제출하고, Delete로 한 점 되돌리고, Esc로 취소합니다. 연결할 수 없으면(메시와 겹치면) 선 전체를 거부하고 초안은 남으므로, 마지막 점을 되돌리고 다시 놓을 수 있습니다.

#### 공통 사항

새 정점의 위치, UV, 키폼, 블렌드 형태, 정점 가중치는 모두 주변의 원래 정점에서 같은 가중치로 나옵니다. 그래서 점을 더해도 화면은 움직이지 않습니다. 점을 더한 뒤에는 텍스처를 바꾸지 않는 범위에서 주변 변을 뒤집어 가늘고 긴 삼각형을 줄입니다. 「좌우 대칭」을 켜면, 점 추가, 삭제, 변 삭제가 메시의 현재 바운딩 박스 세로 중심선을 축으로 한 대칭 위치에서도 함께 일어납니다(대칭 위치에 점이나 변이 없으면 이쪽만 처리합니다). 오른쪽 클릭 메뉴의 선택 묶음에는 「윤곽 정점 선택」「내부 정점 선택」도 있어, 경계만 또는 내부만 조정하기 쉽습니다.

내부 조형이 있는 메시는 점을 더하거나, 점을 지우거나, 변을 지우거나, 다시 삼각화하거나, 정지 형태 정점을 옮긴 뒤, 같은 단계에서 새 메시에 맞춰 조형을 다시 베이크합니다. 새 메시가 조형의 면적 검사를 통과하지 못하면 편집은 그대로 제출되고, 내부 조형 패널이 메시가 바뀌어 다시 생성해야 한다고 알립니다.

토폴로지 업데이트는 UV, 키폼, 블렌드 형태, Glue 정점 참조를 함께 처리하고 경로를 다시 바인딩합니다. 그래도 기존 포즈를 확인해야 합니다. 특히 윤곽 점을 지운 뒤의 경계 변화입니다.

## 내부 조형 핸들

오브젝트 모드의 「내부 조형 핸들」(Shift+I, 또는 내부 조형 패널 도구 막대의 「캔버스에서 편집」. 다른 모드에서 누르면 오브젝트 모드로 전환됩니다)은 선택한 메시 위에서 내부 조형을 직접 조정합니다. 오브젝트 모드는 메시 정점을 그리지 않으므로 핸들이 정점과 겹치지 않습니다. 메시에 아직 효과가 없거나 효과가 꺼져 있으면 옵션 막대가 안내하고 한 번 눌러 켤 수 있습니다. 다른 오브젝트를 클릭하면 그것이 선택되고 핸들도 따라 이동합니다.

| 핸들 | 작용 |
| --- | --- |
| 가운데 십자 | 위쪽 팔은 부풀기, 왼쪽 팔은 기울임, 오른쪽 팔은 가로 폭, 아래쪽 팔은 세로 폭입니다. 팔이 길수록 값이 크고, 점선 상자 가장자리가 2입니다 |
| 아치 선 | 실선은 정지 때의 가상 아치면이고, 점선은 입력이 가득 찼을 때 기울임에 따라 기운 아치면(보기)입니다 |
| 화살표 | 완화와 전달을 켜면 표시됩니다. 양쪽 끝을 드래그해 시작점 / 끝점을 바꾸고, 가운데를 드래그해 전체를 옮깁니다 |
| 가이드 선 | 메시 위나 캔버스 빈 곳을 클릭해 주름선을 그리기 시작하고, 마지막 점을 클릭하거나 Enter로 끝냅니다. 점을 드래그해 이동하고, 선분을 드래그해 선 전체를 옮기고, Ctrl+클릭으로 점을 더하고, Alt+클릭으로 점을 지우고, Delete로 선택한 점 또는 선 전체를 지웁니다. 선택한 주름선은 반경 핸들을 드래그할 수 있습니다 |

마우스를 올리면 핸들과 선이 강조되고, 상태 막대에 이름과 값이 표시됩니다. 드래그하고 손을 뗄 때마다 히스토리 한 줄만 기록되며, Esc는 드래그를 취소합니다. 패널 수치와 핸들은 실시간으로 맞습니다. 시험 동작을 켜면 드래그하는 동안 조형 변화를 바로 볼 수 있습니다.

## 특징점

오브젝트 모드의 **특징점** 도구(기본 `Shift+Y`)는 이목구비를 맞춘 핸들을 표시합니다. 각 눈의 안쪽·바깥쪽 눈꼬리와 위·아래 눈꺼풀 중점, 각 눈썹의 양쪽 끝과 눈썹산, 입의 양쪽 입꼬리와 위·아래 입술 중점입니다(이 부위에 맞추기 기초 알고리즘을 쓸 때만 나타납니다). 핸들을 드래그한 뒤 놓으면 이목구비가 새 위치로 다시 맞춰지고, 여닫기, 웃는 눈, 감정, 입 모양 등 모든 포즈가 함께 갱신됩니다. 눈꺼풀 가장자리나 입술 가장자리는 중점에서 가장 많이 따라오고, 양쪽 끝에서는 눈꼬리나 입꼬리를 따라옵니다. 수정은 Rig 레시피에 기록되고, 드래그 한 번은 히스토리 한 단계이며, 다시 생성해도 남습니다. 옮겨진 핸들은 사각형으로 그려지고, `Alt` + 클릭하면 원화 위치로 돌아갑니다. 맞추기는 바꾸지 않고 이목구비 전체를 조금 옮기려면, 그것을 구동하는 메시(눈, 눈썹, 입의 형태 디포머)를 드래그합니다. 편집 모드에서, 또는 변형 모드에서 `Ctrl`을 누른 채 격자점을 드래그하면, 그 변위가 그 디포머의 모든 키폼과 블렌드 형태에 더해져 모든 포즈가 함께 움직이고, 다시 생성해도 남습니다. 옵션 막대는 최근 조작한 부위의 기초 알고리즘 수치를 표시합니다(눈의 아래 눈꺼풀 밀어 올리기, 눈동자 둥글기, 입의 앞부분 벌림, 입 모양 폭 등). 드래그 한 번은 히스토리 한 단계입니다. **이 특징 초기화**와 **모든 특징 초기화**는 그 특징 전체 또는 모든 특징의 이동을 한 번에 되돌립니다. MCP는 `settings_update`의 `changes.rig.moves`로 같은 데이터를 수정합니다.

## 만들기와 소재 배치

1. 대상을 선택하고, 오브젝트 모드 도구 모음의 마지막 묶음에서 Warp, Rotation 또는 변형 경로를 고르거나 `C` / `R` / `P`를 바로 누릅니다. 계층 트리 오른쪽 클릭에서 부모 / 자식 Warp 또는 Rotation 추가를 고르거나, 오브젝트 모드 캔버스 오른쪽 클릭 메뉴 「만들기」에서 고를 수도 있습니다.
2. 캔버스의 배치 미리보기를 조정하고, 영향 받는 오브젝트, 이름, 부모, 분할 설정을 확인합니다.
3. 모드 막대의 「확인」을 누르거나 Enter로 프로젝트에 기록합니다. 「취소」를 누르거나 Esc로 취소합니다.

PNG / WebP / TIFF / BMP를 계층 트리로 드래그하거나, 트리 오른쪽 클릭 「레이어 가져오기…」를 써도 배치 세션으로 들어갑니다. 드로어블에 드롭하면 새 레이어는 그 드로어블의 부모 디포머 아래에 붙습니다. 배치를 끝낸 뒤 가림과 여러 파라미터 포즈를 확인합니다.

## 변환 상자

「변환」 도구, Warp / 레이어의 배치 상자, 텍스처 아틀라스 페이지에서 선택한 조각은 같은 변환 상자를 쓰며 모양과 조작이 같습니다. 변환 도구는 아무것도 선택하지 않았을 때 선택 도구와 같아 클릭 선택이나 상자 선택이 되고, 선택된 뒤에 변환 상자가 나타납니다.

| 조작 | 효과 |
| --- | --- |
| 상자 안을 드래그 | 이동 |
| 모서리 / 변 중점을 드래그 | 확대·축소. 반대쪽 변은 그대로입니다. `Shift`로 모서리를 드래그하면 비율을 유지하고, `Alt`는 앵커를 중심으로 확대·축소합니다 |
| 위쪽 변 밖의 원형 핸들, 또는 모서리 바깥(마우스를 올리면 모서리 밖에 화살표가 있는 호가 켜짐)을 드래그 | 앵커를 중심으로 회전합니다. `Shift`는 15° 단계입니다 |
| 앵커(획이 있는 십자 원)를 드래그 | 앵커를 이동합니다. 중심, 모서리, 변 중점에 가까우면 스냅하고, 원래 자리로 되돌리면 기본으로 돌아갑니다 |

앵커의 기본 위치는 선택 중심(각 점의 무게중심)입니다. 선택이 상자 안에서 차지하는 상대 위치는 유지되며, 이동, 확대·축소, 회전 뒤에도 선택을 따라갑니다. 「정밀 수치 변환」의 회전과 확대·축소도 이것을 중심으로 합니다. 선택을 바꾸거나 Esc로 도구를 나가면 앵커는 기본 위치로 돌아갑니다. 드래그 중에는 포인터 옆에 회전 각도, 양쪽의 배율, 또는 이동한 캔버스 픽셀이 표시되고 나머지 핸들은 옅어집니다. 상자가 화면에서 너비나 높이가 40픽셀보다 작으면 가운데는 항상 이동이고 앵커는 드래그할 수 없습니다(보기를 확대하면 됩니다). Warp와 레이어의 배치 상자는 사각형으로 만들어지므로 이동과 확대·축소만 되고 회전은 되지 않습니다. 텍스처 아틀라스 조각의 모서리는 비율에 맞춰 밀도를 확대·축소하며, 변 중점은 없습니다.

## 회전 디포머

원점을 드래그하면 이동하고, 끝점을 드래그하면 회전합니다. 기본은 `Shift`를 누른 채 각도에 스냅하고, `Alt` + 끝점 드래그로 비율을 조정합니다.

## 여러 메시 편집

편집 모드는 선택한 모든 드로어블에 동시에 작용합니다.

- 정점 클릭 선택, 상자 선택, 브러시 선택, 변환 상자, 변형 브러시는 모두 메시를 가로질러 적용됩니다.
- 어떤 메시의 정점을 클릭 선택하면 그 메시가 **주 메시**가 됩니다. 정점 배치의 「선」, 변 / 면 모드, 경로는 주 메시에만 작용합니다.
- 삭제 같은 정점 조작은 선택이 있는 메시마다 한 번씩 제출되고, 같은 히스토리 기록으로 들어갑니다.

## Glue

메시 두 장을 선택한 뒤 편집 모드에서 Glue 도구를 고르면, 도구 모음 아래에 하위 도구 세 가지가 나열됩니다. Glue 브러시, 가중치 브러시, 다시 병합(`1`–`3`). Glue 점은 두 메시가 공유하는 같은 점이며, 캔버스에는 마름모 하나로 표시됩니다. 선택하거나 드래그하면 양쪽 정점이 항상 함께 움직이고, 편집할 때 붙어 있어서 어긋나지 않습니다.

Cubism과 같이, 붙임은 메시의 정지 형태(모든 파라미터가 기본값)에서 이루어지며, 붙은 점은 정지 때 양쪽이 겹치고 잡아당김이 생기지 않습니다. 파라미터가 기본값이 아니면 Glue 브러시, 다시 병합, 「Glue 생성」, 선택한 정점 붙이기는 먼저 파라미터를 부드럽게 기본값으로 되돌린 다음 붙입니다. 가중치를 조절하거나 붙임을 해제해도 포즈는 바뀌지 않습니다.

| 조작 | 효과 |
| --- | --- |
| Glue 브러시 | 메시만 바꾸고 화면은 바꾸지 않습니다. 겹친 곳(또는 스냅 허용 거리 안)에서 다른 메시에 정점을 새로 만들거나 밀어 맞추고, UV도 함께 이동합니다. 넣은 뒤에는 텍스처를 바꾸지 않는 범위에서 변을 뒤집어 가늘고 긴 삼각형을 피합니다 |
| `Alt` + 드래그 | 붙임 해제 |
| 가중치 브러시 | 파랑(A) / 주황(B)으로 텍스처 위에 양쪽 가중치를 표시합니다 |
| 다시 병합 | 칠한 정점에 이미 있는 붙임을 없앤 뒤, 스냅 허용 거리로 다시 붙입니다 |
| `Enter` 또는 모드 막대 「Glue 생성」 | 두 윤곽을 따라 구간 전체를 붙입니다 |
| `Ctrl+G`(모델 내보내기 키. 이때는 내보내기를 열지 않습니다) | 어느 한 메시에서 선택한 정점을 붙입니다 |
| 오른쪽 클릭 「거리로 구간 전체 다시 병합」 | 두 메시 사이의 붙임을 모두 없애고 윤곽을 따라 다시 붙입니다 |

## 페인트의 적용과 버리기

먼저 레이어를 고른 다음 페인트로 들어갑니다. 획은 별도의 페인트 세션에 저장되며, 세션 안에서 실행 취소와 다시 실행을 지원합니다. 첫 획을 그린 뒤 캔버스 위 가운데에서 세션 막대가 미끄러져 나옵니다(텍스처 아틀라스의 조정 세션 막대와 같습니다). 페인트 중인 레이어와 획 수를 보여 주고, 실행 취소, 다시 실행, 버리기, **적용**을 제공합니다. 캔버스가 좁으면 버튼은 아이콘만 보이고, 마우스를 올리면 이름이 나옵니다. 「도구 상세」 패널에도 「버리기」와 「적용 확인」이 있습니다.

팔레트는 Photoshop 방식을 씁니다. 왼쪽 아래 도구 옵션 막대 맨 앞은 전경색 / 배경색이 겹친 색 조각이고, 오른쪽 위는 교환(X), 왼쪽 아래는 기본 검정 / 하양으로 되돌리기입니다. 색 조각을 클릭하면 색 선택기가 열립니다. 왼쪽은 채도 / 명도 영역, 오른쪽은 세로 색상 막대, 「새 색 / 현재」 비교 조각(「현재」를 누르면 되돌림), H S B와 R G B 수치 및 16진 코드, 아래는 색 견본과 최근 사용 색입니다. 「도구 상세」 패널에는 전경색의 색 영역과 색상 막대, 색 견본, 최근 사용 색이 바로 들어 있습니다. 브러시, 연필, 지우개, 도형의 크기는 서로 독립이며, 도형의 선 두께가 브러시 크기를 바꾸지 않습니다.

도구 모음은 세 묶음입니다. 브러시, 연필, 지우개, **흐림**. 페인트 통, **그레이디언트**, 스포이트. 도형, **선택 영역**. 각 도구의 옵션은 왼쪽 아래 옵션 막대에 있고, 선택 영역 명령은 캔버스 오른쪽 클릭 메뉴의 「선택 영역」 묶음에 있습니다.

| 기능 | 사용법 |
| --- | --- |
| 선택 영역 도구(`Alt+L`) | 사각형, 타원, 올가미, 다각형 올가미, 마법봉, 빠른 선택의 여섯 변형이며 `1`–`6`으로 전환합니다. 드래그로 상자 선택합니다. 올가미는 누른 채 윤곽을 드래그합니다. 다각형은 점을 하나씩 클릭하고, 시작점을 다시 찍거나 `Enter`로 닫고, `Delete`로 이전 점을 되돌리고, `Esc`로 버립니다. 마법봉은 허용 오차로 클릭한 곳의 색을 고르고, 「연속」을 끄면 그림 전체의 같은 색 픽셀을 고릅니다. 빠른 선택은 브러시이며, 칠한 곳과 이어진 비슷한 색(그레이디언트 그림자 포함)이 함께 선택되고, 색이 갑자기 바뀌는 가장자리에서 멈춥니다. 획마다 선택에 더해지고, `Alt`를 누른 채 칠하면 뺍니다. `[` `]`로 브러시 크기를 조절하고, 허용 오차는 옵션 막대의 「허용 오차」를 씁니다. 색을 비교할 때 알파를 미리 곱하므로, 투명 영역은 어떤 색이 숨어 있어도 같은 색으로 칩니다. `Shift`는 더하기, `Alt`는 빼기, `Shift+Alt`는 교차이며, 옵션 막대에서 조합 방식을 고정할 수도 있습니다. 드래그하지 않고 클릭하면 선택이 해제됩니다. 선택 영역은 행진하는 점선으로 표시됩니다 |
| 선택 영역 명령 | `Ctrl+A` 전체 선택, `Ctrl+D` 선택 해제, `Ctrl+I`(또는 `Ctrl+Shift+I`) 반전 선택, `Alt+Backspace`로 전경색을 선택 영역에 채웁니다(선택이 없으면 레이어 전체). `Del`은 선택 내용을 지웁니다. 오른쪽 클릭 메뉴에는 「선택 영역 페더」「선택 영역 확장」「선택 영역 축소」(거리는 옵션 막대의 「페더」「확장/축소」. 축소는 캔버스 가장자리에서 안쪽으로 줄이지 않습니다)와 「불투명도로 픽셀 선택」(레이어 투명도를 선택 영역으로 삼으며, Photoshop에서 Ctrl+클릭으로 레이어 썸네일을 누르는 것과 같습니다)이 있습니다 |
| 선택 영역의 작용 | 선택 영역이 있으면 모든 도구(브러시, 지우개, 흐림, 채우기, 그레이디언트, 도형, 지우기)는 선택 안만 바꾸고, 부드러운 가장자리는 비율대로 이어집니다. 선택 영역은 획 히스토리에 들어가지 않습니다. 획을 하나 실행 취소해도 선택 영역은 그대로입니다. 적용, 버리기, 또는 레이어를 바꾼 뒤 선택 영역은 지워집니다 |
| 자유 변형(`Alt+T`, 페인트 모드에서는 `T`도 가능) | 도구를 고르면 선택 안의 픽셀(선택이 없으면 레이어의 모든 내용)이 변환 상자에 들어가고, 원래 자리는 바로 비워집니다. 상자 안을 드래그하면 이동합니다. 모서리를 드래그하면 비율을 유지해 확대·축소하고(`Shift`는 비율을 풀고), 변의 제어점은 한 방향으로 확대·축소하며, `Alt`는 중심에서 확대·축소합니다. 상자 밖을 드래그하면 중심을 기준으로 회전합니다(`Shift`는 15° 단계). `Enter` 또는 옵션 막대 「변환 적용」으로 획을 확정하고, `Esc` 또는 `Ctrl+Z`로 취소해 원래 자리에 되돌리며, 도구를 바꾸면 바로 적용됩니다. 옵션 막대 「부드럽게」를 끄면 가장 가까운 픽셀로 샘플링하므로 픽셀 아트에 맞습니다. 적용 뒤 변환 전체는 획 히스토리의 한 단계이고, 선택 영역은 픽셀과 함께 이동합니다 |
| 그레이디언트(`Alt+G`) | 드래그로 시작점과 끝점을 정합니다. 선형 또는 방사형이며, 전경색에서 배경색 또는 투명으로 가고, 선택 영역과 투명도 보호의 제약을 받습니다 |
| 흐림(`Alt+J`) | 칠한 곳이 부드러워집니다. 「강도」가 흐림 정도를 정하며, 같은 획을 왔다 갔다 해도 점점 더 흐려지지 않습니다 |
| 손떨림 보정 | 브러시, 연필, 지우개, 흐림의 옵션 막대 「손떨림 보정」은 0–30입니다. 값이 클수록 선이 안정되고 따라오는 속도는 느려지며, 손을 뗄 때 놓은 위치까지 이어 줍니다 |
| 대칭 | 위 네 도구는 좌우, 상하, 또는 네 방향 미러를 고를 수 있습니다. 축은 캔버스 중심이며, 캔버스에 점선으로 표시됩니다 |
| 투명도 보호(`/`) | 이미 있는 픽셀에만 색을 칠하고 투명도는 바꾸지 않습니다. 이때 지우개는 배경색으로 칠합니다 |
| 페인트 통 | 「연속」을 끄면 그림 전체의 같은 색 픽셀을 채웁니다 |
| 직선 | `Shift` + 클릭으로 이전 획의 끝점에서 직선을 그립니다 |
| 기본 색 | `Alt+D`로 검정 / 하양을 되돌립니다(`X`는 전경 / 배경 교환) |

필압, 보기 회전 / 뒤집기, 문지르기, 수채 혼합은 아직 지원하지 않습니다. Photoshop / SAI와의 전체 대응은 페인트 시스템을 참고하세요.

페인트는 레이어 사각형에 제한되지 않으며 캔버스 전체에 그릴 수 있습니다. 적용할 때는 레이어의 메시로 자릅니다.

- **메시 위의 부분**은 레이어에 남습니다. 레이어의 메시, 키폼, 바인딩은 바뀌지 않습니다.
- **메시 밖의 부분**은 새 레이어로 나뉩니다. 이름은 원래 레이어 이름에 「+」를 붙인 것이고, 원래 레이어 바로 위에 놓입니다. 새 레이어는 자기 메시가 있고, 원래 레이어와 같은 부모, 같은 파츠에 붙으므로 함께 움직입니다. 소재 라이브러리에도 소재로 나타나며, 원래 레이어의 소재 옆에 놓입니다(원래 레이어에 소재가 없으면 맨 위). 레이어와 이 소재는 연결됩니다.
- 메시 밖을 지워도 효과가 없습니다. 그곳의 픽셀은 원래 표시되지 않고, 레이어에 원래 있던 옅은 가장자리도 떼어지지 않습니다.
- 아직 메시가 없는 레이어(예를 들어 첫 획을 방금 그린 투명 레이어)는 자르지 않고, 메시는 모든 픽셀로 생성됩니다.
- 소재가 연결된 레이어는 메시 위의 부분이 소재에 기록되어, 이 소재를 쓰는 모든 레이어가 함께 바뀝니다. 메시 밖의 부분도 마찬가지로 새 레이어로 나뉩니다.

레이어 자신의 메시가 새로 그린 영역을 덮게 하려면, 메시 패널에서 「메시 다시 만들기」를 쓸 수 있습니다. 키폼, 경로, 가중치, 붙임은 새 메시로 옮겨 갑니다.

적용한 뒤 변형과 마스크를 확인하고 프로젝트를 저장합니다. 구현 세부는 페인트 시스템을 참고하세요.

## 제출과 복구

일반 지오메트리 제스처는 드래그 중에 미리 보고, 성공적으로 끝나면 프로젝트 히스토리에 들어갑니다. 만들기, 정점 배치의 선 그리기, 페인트는 각자의 확인 단계가 있습니다. 「현재 초안」「이미 제출된 히스토리」「디스크에 기록된 프로젝트」를 같은 상태로 여기지 마세요.

경로의 모드 차이와 내보내기 제한은 [변형 경로](DEFORM_PATHS.md)를 참고하세요. 프로젝트 저장은 [프로젝트 형식](../spec/PROJECT_FORMAT.md)을 참고하세요.
