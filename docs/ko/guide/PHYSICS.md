# 물리

[문서 목차](../README.md) · [스윙 생성](SWING.md) · [시뮬레이션과 베이크](SIMULATION.md) · [MCP 사용과 인터페이스](../agent/MCP_AUTHORING.md)

물리는 파라미터가 머리, 몸 등의 입력을 따라 관성으로 흔들리게 합니다. PSD2Live는 Cubism의 진자 모델을 씁니다. 뿌리에서 늘어뜨린 진자 한 줄(Cubism Editor 「진자 설정」에서 번호 1, 2, 3…인 각 행)이며, 입력이 뿌리를 밀거나 중력을 기울이면 진자가 관성으로 흔들리고, 지정한 진자의 각도가 출력 파라미터에 기록됩니다. 내보낼 때는 `physics3.json`과 `.cmo3`에 기록됩니다.

## 물리 그룹은 어디서 옵니까

모델의 모든 물리 그룹은 물리 패널에 나열되며, 출처는 다섯 가지입니다.

| 출처 | 설명 | ID |
|------|------|----|
| 프리셋 | 레이어에서 자동 생성된 앞머리, 뒷머리, 젤리 눈(레이어에 해당 파츠가 있을 때만) | `PhysicsHairFront`, `PhysicsHairBack`, `PhysicsEyeJelly` |
| 스켈레톤 | 스켈레톤 두 번째 마디 이후의 꼬리, 날개의 따라오기 | `PhysicsSkel_<骨骼 id>` |
| 스윙 | 각 스윙의 각 방향마다 진자 하나. [스윙 생성](SWING.md)을 참고하세요 | `PhysicsSwing_<id>[_X\|_Y]` |
| 시뮬레이션 | 베이크된 시뮬레이션마다 맞춰진 진자 하나. 각 마디가 모드 파라미터 하나를 구동합니다. 상하 운동에는 이동 입력을 받는 진자가 하나 더 있습니다. [시뮬레이션과 베이크](SIMULATION.md)를 참고하세요 | `PhysicsSim_<id>`, `PhysicsSim_<id>_y` |
| 사용자 지정 | 패널이나 MCP에서 새로 만듦 | 기본 `PhysicsCustom<N>` |

생성된 그룹도 직접 편집할 수 있습니다. 편집하면 「수정됨」이 되고, 저장되는 것은 사용자의 버전입니다. 출처(스윙, 스켈레톤)가 나중에 바뀌어도 덮어쓰지 않습니다. 시뮬레이션 진자는 다시 베이크하거나 출력 이름을 바꾼 뒤 3자 병합되며, 사용자가 바꾼 필드만 남고 나머지는 새 맞춤 결과를 따릅니다([시뮬레이션과 베이크](SIMULATION.md) 참고). 「생성값으로 되돌리기」로 생성된 버전으로 돌아갑니다. 각 그룹은 따로 끌 수 있으며, 꺼진 그룹은 내보내지 않습니다. 사용자 지정 그룹이 어떤 생성 그룹의 출력 파라미터를 구동하면, 그 생성 그룹은 「대체됨」으로 표시되고 마찬가지로 내보내지 않습니다.

가져온 CMO3의 물리 설정은 파일의 ID를 그대로 씁니다. Cubism Editor는 ID가 같은 설정을 여러 개 저장할 수 있습니다. 이때 두 번째부터 차례로 `<id>_2`, `<id>_3`…으로 바꿉니다(파일에 이미 있는 ID는 건너뜀). 모든 설정은 유지되고, 가져올 때마다 같은 ID가 되며, 내보낼 때도 이 ID를 씁니다.

같은 파라미터는 유효한 그룹 하나만 구동할 수 있습니다. 그룹이 유효하지 않으면(파라미터가 없거나, 입력이나 출력이 없거나, 어떤 파라미터가 입력이면서 출력인 경우) 목록에 「유효하지 않음」으로 표시되고 내보내지 않으며, 편집 영역에 이유가 표시됩니다.

## 물리 패널

물리 전체 스위치와 물리 프레임 속도는 미리보기 캔버스의 왼쪽 도구 모음에 있으며, 대기 애니메이션, 마우스 추적과 함께 있습니다. 물리 프레임 속도는 30 / 60 / 90 / 120 / 제한 없음(기본 60)이며, 프로젝트 설정입니다. 물리는 이 값으로 계산하고, 내보내는 `physics3.json`(`Fps`)과 CMO3에도 이 값이 기록됩니다. 「제한 없음」을 고르면 물리는 렌더 프레임마다 계산되고, 내보내기는 `Fps`를 선언하지 않으며, 런타임은 각자의 프레임으로 물리를 계산합니다(CMO3에는 물리 FPS를 쓰지 않습니다). 미리보기의 프레임 출력은 이 제한을 받지 않습니다. 미리보기 프레임 속도 상한은 캔버스 왼쪽 아래 상태 캡슐 메뉴에 있으며 기본은 「디스플레이 따르기」입니다. 물리 프레임 속도와 무관하고, 물리는 두 단계 사이를 보간합니다.

패널 위에는 물리가 실행 중인지, 현재 프레임 속도, 「유효 n / m」 개수, 그리고 미리보기의 대기 애니메이션과 마우스 추적 스위치가 표시됩니다.

대기 애니메이션과 물리는 서로 독립입니다. 대기 애니메이션이 멈추고 물리가 켜져 있으면, 파라미터 슬라이더를 드래그하거나 마우스 추적으로 고개를 돌려도 미리보기의 물리는 그대로 흔들리고, 멈추면 미리보기도 프레임 출력을 멈춥니다. 물리를 끄면 편집 포즈만 표시됩니다. 일시 정지 중 물리는 내보내기와 같은 엔진으로 계산되며(아래 「미리보기와 내보내기의 일치」 참고), 일시 정지된 모션이 계속 재생되지는 않습니다.

파라미터 패널과 미리보기는 항상 같습니다. 대기 애니메이션이 재생되면 슬라이더가 미리보기를 프레임마다 따르고, 멈추면 마우스 추적이 움직이는 각도와 눈동자 파라미터도 파라미터 패널에 실시간으로 표시됩니다. 물리 패널의 진자가 읽는 것도 같은 포즈입니다.

물리를 집중해서 조정할 때는 「물리」 작업 공간을 새로 만들 수 있습니다(탭 막대의 + 메뉴). 왼쪽에서 오른쪽으로 미리보기 캔버스, 파라미터 패널, 물리 패널이며 너비는 약 2 : 1 : 1입니다. 다른 패널은 숨겨지고, 필요하면 창 메뉴에서 엽니다.

아래는 물리 그룹 목록이며, 계산 순서대로 나열되고 번호가 붙습니다. 각 줄은 체크로 켤 수 있고, 출처와 상태(수정됨 / 유효하지 않음 / 대체됨)가 표시됩니다. 제목 표시줄의 ↑ / ↓는 선택한 그룹의 계산 순서를 바꿉니다. Cubism은 순서대로 계산하며, 뒤의 그룹은 같은 단계에서 앞 그룹의 출력을 읽을 수 있습니다. 그래서 한 그룹이 다른 그룹의 출력을 입력으로 쓸 때(연쇄 물리) 읽히는 그룹을 앞에 두어야 합니다.

「+ 새로 만들기」에서는 다음을 할 수 있습니다.

- 빈 진자를 새로 만듭니다. 기본 입력은 머리와 몸의 흔들림이고, 길이 10인 진자 하나이며 출력은 아직 없습니다.
- 선택한 그룹을 새 그룹으로 복제합니다(출력 파라미터는 비워 원래 그룹과 충돌하지 않게 합니다).
- physics3.json을 가져옵니다. 파일의 각 그룹이 사용자 지정 그룹이 되고, 파일 순서대로 기존 그룹 뒤에 놓입니다. ID가 같은 그룹은 대체됩니다(생성된 그룹은 생성값으로 되돌리기 전까지 대체된 상태를 유지합니다). 같은 출력을 구동하는 다른 사용자 지정 그룹은 꺼지고, 파일이 선언한 `Fps`가 프로젝트의 계산 FPS가 됩니다. 모델에 없는 파라미터는 로그에 기록되고, 해당 그룹은 유효하지 않음으로 표시됩니다.
- 캔버스에서 선택한 메시나 곡선형 디포머에 스윙을 만듭니다([스윙 편집](SWING.md)으로 들어갑니다).

### 진자 캔버스

그룹을 선택하면 편집 영역 위쪽은 그 진자입니다. 실선은 실시간으로 흔들리는 진자이고, 점선은 정지 포즈이며 실시간 뿌리에서 늘어집니다. 각 진자 끝에는 고리가 있습니다. 화면은 좌우가 미러되어 표시되므로, 오른쪽으로 당기면 뿌리가 오른쪽으로 이동합니다.

| 조작 | 작용 |
|------|------|
| 빈 곳에서 좌우로 드래그 | Cubism Viewer에서 모델을 가로로 드래그하듯 모델을 당깁니다(수평 방향만). 손을 놓으면 부드럽게 원래 자리로 돌아갑니다. 뿌리는 항상 위쪽 가로선을 따라 이동합니다 |
| 고리를 위아래로 드래그 | 그 진자의 길이입니다. 클릭하면 그 진자를 선택하고(다시 클릭하면 해제), 아래 슬라이더는 그것만 조절합니다 |
| 오른쪽의 출력 라벨 | 라벨은 그것이 읽는 진자와 같은 높이에 있고, 선은 그 진자의 실시간 위치를 가리키며, 막대는 현재 파라미터 값을 표시합니다. 위아래로 드래그하면 가장 가까운 진자가 강조되고, 놓으면 그 진자를 읽도록 바뀝니다(출력 줄의 「진자 수」) |
| 출력 라벨 클릭(또는 출력 줄 앞의 색 점) | 진자 위에 이 출력의 범위 부채꼴을 표시합니다. 이 진자가 이전 진자에 대해 부채꼴 각도만큼 흔들리면 파라미터가 한쪽 끝에서 다른 쪽 끝으로 갑니다. 부채꼴 가장자리의 원을 드래그해 범위를 조정합니다(배율). 부채꼴이 좁을수록 흔들림이 더 분명합니다 |

클릭은 선택만 하고, 짧은 거리 이상 드래그해야 수정되므로 생성된 그룹을 실수로 바꾸지 않습니다. 마우스를 올리거나 드래그하면 왼쪽 위에 그 항목의 의미와 수치가 표시됩니다.

당길 때 포인터 위치는 목표입니다. 모델은 Cubism의 CubismTargetPoint로 제한된 속도와 가속도를 따라가고, CubismLook 계수로 각도 X, 몸 X, 눈동자 X로 바꿉니다(그룹의 다른 입력 파라미터는 드래그량이 그 범위의 절반에서 차지하는 비율을 따릅니다). 실시간 진자는 미리보기를 재생할 때 미리보기 파라미터 위에 겹칩니다(모션과 시선 추적 포함). 일시 정지 때는 파라미터 패널 값 위에 겹치므로, 파라미터 슬라이더를 직접 드래그해도 반응을 볼 수 있습니다. 오른쪽 아래 버튼은 진자를 즉시 정지시킵니다.

뿌리가 움직이는 범위와 중력이 기우는 범위(입력 정규화)는 「고급」에서 설정합니다.

### 응답 곡선

진자 아래의 곡선은 이 그룹이 표준 당김 한 번에 어떻게 반응하는지를 보여 줍니다. 오른쪽으로 1초 동안 끝까지 당긴 뒤 놓으면, 출력마다 곡선 하나가 있습니다(파라미터 범위로 정규화, 점선은 파라미터 끝값). 옅은 곡선은 당긴 양 자체입니다. 곡선 아래에는 각 출력의 최대 진폭과 놓은 뒤 얼마나 지나 정지하는지가 나열됩니다. 길이와 역학 슬라이더를 조정하면 곡선이 함께 갱신되므로, 설정마다 오버슈트와 수렴을 바로 비교할 수 있습니다.

### 진자 설정

「프리셋」 줄은 Cubism Editor의 진자 프리셋에 대응합니다. 프리셋을 고른 뒤 「가져오기」를 누르면 그 그룹의 진자를 모두 바꿉니다(진자가 줄어들면, 삭제된 진자를 읽던 출력은 끝을 읽습니다). 기본 제공 프리셋은 자동 생성된 앞머리, 뒷머리, 젤리 눈, 3단 진자에서 가져옵니다. 「⋯」에서는 현재 진자를 「추가…」로 자신의 프리셋에 넣거나, 자신의 프리셋을 덮어 저장, 이름 변경, 삭제할 수 있습니다. 프리셋은 이 컴퓨터에 저장되며 모든 프로젝트가 공유합니다.

「진자 편집」 줄은 아래 슬라이더가 작용하는 대상을 고릅니다. 「전체」는 모든 진자를 함께 조정하고, 숫자는 그 하나만 조정합니다(캔버스에서 고리를 클릭해 고를 수도 있습니다). 이것은 슬라이더가 어느 진자를 바꿀지만 정하며, 출력의 「진자 수」와는 무관합니다. 오른쪽 버튼은 다음과 같습니다.

- ↑ / ↓: 선택한 진자를 이동합니다. 그것을 읽는 출력도 따라갑니다.
- +: 선택한 진자 아래에 하나를 추가합니다(선택한 진자의 수치를 복사). 선택하지 않았으면 끝에 추가합니다. 더 깊은 출력은 아래로 따라 이동하며 원래 진자를 계속 읽습니다.
- −: 선택한 진자를 삭제합니다(선택하지 않았으면 마지막을 삭제). 그것을 읽던 출력은 이전 진자를 읽고, 더 깊은 출력은 위로 따라 이동합니다.

| 슬라이더 | Cubism Editor 이름 | 효과 |
|------|-------------|------|
| 전체 길이 / 길이 | 길이 | 길수록 더 느리게 흔들리고 진폭이 큽니다. 「전체」를 고르면 모든 진자를 비율대로 확대·축소합니다 |
| 스윙도 | 스윙도(Mobility) | 클수록 멈추기 어렵습니다 |
| 반응 속도 | 반응 속도(Delay) | 클수록 입력에 더 빨리 반응합니다 |
| 수렴 속도 | 수렴 속도(Acceleration) | 클수록 중력이 세고, 더 빨리 아래로 돌아갑니다 |

### 입력

각 입력은 파라미터 하나와 그것이 영향을 주는 방식입니다.

- **유형**: **위치X**는 진자 뿌리를 좌우로 밉니다. **각도**는 중력 방향을 기울입니다.
- **영향도**: 0–100%. 파라미터 전체 범위가 입력 정규화 범위에 대응하는 비율입니다.
- **⇄**: 반전입니다.

「+ 추가」는 쓸 수 있는 파라미터를 나열하며, 자주 쓰는 머리와 몸 각도가 앞에 있습니다.

「프리셋」 줄은 Cubism Editor의 입력 프리셋에 대응합니다. 프리셋 하나에는 모든 입력과 입력 정규화가 들어 있습니다. 기본 제공 프리셋에는 머리와 몸의 흔들림(±10°, 앞머리와 같음. ±30°, 뒷머리와 같음), 머리와 몸의 상하(세로 스윙과 같음), 눈 여닫기(젤리 눈과 같음)가 있습니다. 모델에 없는 파라미터와 이 그룹 자신의 출력 파라미터는 건너뜁니다. 관리 방식은 진자 프리셋과 같습니다.

### 출력

각 출력은 어떤 진자의 각도를 파라미터에 기록합니다.

- **진자 수**: 출력이 몇 번째 진자의 각도를 읽는지입니다(이전 진자 기준, 진자 1은 중력 방향 기준). Cubism Editor 출력 설정의 「진자 수」, `physics3.json`의 `VertexIndex`입니다. 위의 「진자 편집」과는 무관합니다. 캔버스에서 오른쪽 라벨을 어떤 진자 옆으로 드래그해 놓아도 바꿀 수 있습니다. 여러 진자를 서로 다른 파라미터에 연결하면 채찍처럼 구간마다 따라오게 할 수 있습니다.
- **배율**: 진자 각도 1라디안에 대응하는 파라미터 값입니다. 결과는 파라미터 범위 안으로 제한됩니다. 캔버스에서 부채꼴 호 끝을 드래그해 조정할 수도 있습니다.
- **⇄**: 반전입니다.

출력은 각도 유형만 있습니다. Cubism 네이티브 런타임은 위치X 유형 출력의 배율을 읽지 않으며, 이런 출력은 항상 0입니다. 읽어 들인 이전 데이터에 위치X 유형 출력이 있으면 안내하고, 한 번 눌러 각도로 바꿀 수 있습니다.

「+ 추가」에서 다른 유효 그룹이 이미 구동하는 파라미터는 고를 수 없게 표시되고, 어느 그룹이 구동하는지가 적힙니다.

각 출력 줄 오른쪽의 「최대 출력력」은 Cubism Editor 출력 설정의 같은 이름 열에 대응합니다. 이 그룹을 연 뒤부터(또는 마지막으로 초기화한 뒤부터) 이 출력이 현재 배율에서 도달한 최댓값이 파라미터 끝값에서 차지하는 백분율입니다. 캔버스를 당기거나, 미리보기를 재생하거나, 시선을 따를 때 모두 기록됩니다. 100%를 넘으면 경고색으로 표시되며, 파라미터가 끝값에서 잘렸다는 뜻입니다. 배율을 바꾼 뒤 백분율은 새 배율로 바로 환산되므로 다시 당길 필요가 없습니다.

- 「최댓값에 맞춰 배율 조정」: 각 출력의 배율을 최대 출력력이 정확히 100%가 되도록 조정합니다. 아직 기록이 없으면 응답 곡선의 표준 당김으로 측정합니다.
- 「출력 최댓값 초기화」: 기록을 비우고 측정을 다시 시작합니다.

### 고급

「고급」 아래에 접혀 있는 것은 캔버스와 슬라이더가 이미 다루며, 정확한 수치가 필요할 때만 쓰는 데이터입니다.

- 진자 설정 표: 각 진자의 길이, 스윙도, 반응 속도, 수렴 속도.
- 출력 세부: 배율과 영향도.
- 입력 정규화: 위치X와 각도 입력의 최솟값 / 중심 / 최댓값.

그룹 이름은 클릭하면 바꿀 수 있습니다. 「⋯」 메뉴에는 이름 변경, 복제, 스윙 편집(스윙 출처), 생성값으로 되돌리기, 삭제(사용자 지정 그룹)가 있습니다.

드래그, 슬라이더 드래그, 수치 입력은 손을 놓은 뒤 히스토리 한 줄로 기록되며 실행 취소할 수 있습니다. 편집은 프로젝트에 저장되고, 모델을 다시 구축하면 같은 그룹으로 다시 생성됩니다.

## 미리보기와 내보내기의 일치

패널의 진자, 응답 곡선, 내장 렌더의 소프트웨어 미리보기, MCP의 시뮬레이션은 같은 물리 엔진을 쓰며, 항목마다 Cubism Native Framework 5-r.5의 `CubismPhysics::Evaluate`에 대응합니다. 입력 정규화, `Fps`에 따른 고정 스텝과 프레임 사이 입력 보간, 그룹 사이의 파라미터 캐시 전달(뒤 그룹이 앞 그룹의 같은 단계 출력을 읽을 수 있음), 마디 갱신과 공기 저항, 출력 보간과 가중치 혼합, SDK 자체의 일부 특수 동작까지 포함합니다. 저장소의 `PhysicsReferenceTest`는 공식 Framework가 내보낸 모델에서 만든 프레임별 데이터(`native/physics_reference`)로 검증합니다. 900프레임의 불규칙한 프레임 간격, 연쇄 그룹, 반전, 부분 가중치, 변위 출력이며, `Fps`가 있을 때와 없을 때 최대 편차는 약 1e-5입니다.

내보내는 `physics3.json`은 프로젝트의 프레임 속도를 선언합니다(`Fps`, 기본 60. 「제한 없음」이면 선언하지 않음). CMO3의 물리 FPS도 이와 같고, 흔들림은 렌더 프레임 속도에 따라 변하지 않습니다. CMO3를 Cubism Editor를 거쳐 다시 내보내도 일치가 유지됩니다. 그룹은 목록 순서대로 내보내며, 이것이 런타임의 계산 순서입니다. 공식 SDK 미리보기를 쓸 수 있으면, 미리보기는 SDK가 내보낸 `physics3.json`을 직접 읽습니다.

물리는 파라미터만 기록합니다. 흔들림 효과는 출력 파라미터의 키폼에 달려 있습니다. 사용자 지정 그룹은 먼저 출력 파라미터의 끝 형태를 만들어 두어야 합니다. 그렇지 않으면 파라미터는 움직이는데 모델은 움직이지 않습니다.

## MCP

물리 그룹 조작은 용도별로 여러 도구로 나뉩니다. 파라미터는 모두 `{"request": {...}}`에 둡니다(전체 필드는 [MCP 사용과 인터페이스](../agent/MCP_AUTHORING.md)를 보거나 `workspace_get_operation`을 호출하세요). 수정과 샘플링에는 모두 `project_id`, `state`(`workspace_inspect` 또는 이전 결과), 고유한 `request_id`가 필요합니다. 백그라운드 작업으로 표시된 도구는 작업 핸들을 반환하며, `job_wait` / `job_get`으로 결과를 가져옵니다.

- `physics_put`(백그라운드 작업): `id`로 새로 만들거나 수정하며, 준 필드만 기록합니다. 이미 있는 ID(생성된 그룹 포함)는 현재 그룹을 기준으로 합니다. `inputs` / `outputs` / `segments`는 목록 전체를 바꾸고, `length` / `mobility` / `delay` / `acceleration`은 모든 마디에 작용하며, `output_scale`은 모든 출력에 작용하고, `segment_count`는 마디 수를 바꾸며, `normalization`은 입력 정규화를 설정하고, `enabled=false`는 아무 그룹이나 끕니다.
- `physics_delete`(백그라운드 작업): 사용자 지정 그룹을 삭제하거나, 수정된 생성 그룹을 생성값으로 되돌립니다. 생성된 그룹 자체는 `physics_put`의 `enabled=false`로 끕니다.
- `physics_simulate`(읽기 전용 백그라운드 작업): 정지에서 시작해 `inputs`의 파라미터를 주어진 값으로 계단 변화시키고, `hold`초 동안 유지한 뒤 되돌립니다. 각 출력이 유지 동안과 놓은 뒤의 시작값, 최댓값, 최종값, 안정 시간, 그리고 `samples`로 샘플링한 곡선을 반환합니다. `ids`는 지정한 그룹만 보고, `duration`은 전체 시간을 설정합니다.
- `physics_fit`(백그라운드 작업): 그룹 `id`의 각 출력 배율을, 최댓값이 파라미터 끝의 `target`%(기본 100)에 정확히 닿도록 조정합니다. `observed_peaks`를 주지 않으면 응답 곡선의 표준 당김으로 측정하며, 실시간 기록이 없을 때의 패널 「최댓값에 맞춰 배율 조정」과 같습니다. 주면 실측값으로 조정합니다. 키는 출력 번호(`"0"`, `"1"`…)이고, 값은 `physics_audition`이 보고한 `peaks`입니다(1이 파라미터 끝값).
- `physics_config`(백그라운드 작업): `order`는 계산 순서를 설정합니다(나열한 그룹이 앞에 옵니다). `fps`는 프로젝트 프레임 속도를 설정합니다(0은 제한 없음).
- `physics_import`(백그라운드 작업): physics3.json을 가져옵니다(`path`는 절대 경로). 규칙은 패널과 같으며, 가져온 그룹, 꺼진 그룹, 없는 파라미터를 반환합니다.

진자 캔버스의 당김은 미리듣기 세션에 대응하며, 문서, 히스토리, 저장된 포즈를 수정하지 않습니다.

- `physics_audition`: `mode`가 `start`이면(`group_id`를 주고, 선택적으로 `values`로 파라미터 값을 겹침) 미리듣기를 시작하고 이 작업 공간의 이전 세션을 멈춥니다. `target`은 뿌리를 `x`, `y`로 당깁니다(-1–1, 패널 포인터). `release`는 손을 놓고, `reset`은 진자를 정지시키며, `reset_peaks`는 최댓값을 다시 기록하고, `stop`은 끝냅니다. 뒤의 것들은 모두 `session_id`를 갖습니다.
- `physics_audition_step`: `dt`초(최대 0.1)씩 `steps`단계(1–240)를 진행하고, 진자 정점, 출력, `peaks`를 반환합니다.
- `physics_audition_get`: 최신 프레임만 읽고 시간은 진행하지 않습니다.

미리듣기 중에 문서를 수정하면 세션은 새 그룹으로 계속 흔들립니다. 프로젝트를 다시 열거나 그 그룹을 삭제하면 세션은 만료됩니다. 당기고, 손을 놓고, 몇 단계를 진행한 뒤 `peaks`를 그대로 `physics_fit`의 `observed_peaks`에 넘기면, 패널에서 당긴 뒤 「최댓값에 맞춰 배율 조정」을 누른 것과 같습니다.

`workspace_inspect`의 `scope=physics`는 계산 FPS와 계산 순서대로 늘어선 모든 그룹을 반환합니다. 각 그룹에는 출처, 유효한지, 누구에게 대체되었는지, 유효하지 않은 이유가 있습니다.

입력과 진자 프리셋도 MCP로 쓸 수 있습니다. `physics_preset_list`는 기본 제공과 자신의 프리셋을 나열하고, `physics_apply_preset`은 그중 하나를 어떤 그룹에 적용합니다. `physics_preset_put` / `physics_preset_rename` / `physics_preset_delete`는 자신의 프리셋을 관리하며, 목록이 반환한 `library_state`가 필요합니다.
