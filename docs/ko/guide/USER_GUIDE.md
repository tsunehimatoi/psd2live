# 조작 요약

[문서 목록](../README.md) · [PSD 레이어 사양](../spec/PSD_LAYER_SPEC.md) · [캔버스 편집](CANVAS_EDITOR.md) · [개발과 CLI](DEVELOPMENT.md)

> [!TIP]
> 처음 사용할 때는 프로그램 안에서 `F1`로 도움말 페이지를 열고, **기본 워크플로**부터 대화형 튜토리얼을 시작하는 것을 권합니다(기초 없음 19과 / Cubism 경험자 14과). 이 문서는 조작을 다시 보고 단축키를 찾을 때 씁니다.

---

## 1. 가장 짧은 절차

1. **가져오기**: `Ctrl+Shift+O`로 레이어 PSD를 가져옵니다(이미 있는 `.psd2live` 프로젝트는 `Ctrl+O`로 엽니다).
2. **확인**: 자동 생성 미리보기와 레이어 분류를 보고, 필요하면 캔버스에서 조금씩 조정합니다.
3. **저장**: `Ctrl+S`로 `.psd2live` 프로젝트에 저장합니다(`Ctrl+Shift+S`는 다른 이름으로 저장).
4. **내보내기**: `Ctrl+G`로 대상 모델을 내보냅니다(`.moc3` / `.cmo3` 등).

> **이미 있는 Cubism 모델 가져오기**:
> - **파일 → 새로 만들기 → CMO3에서 새 프로젝트…**: 현재 모델을 비운 뒤 가져옵니다. 모델 내용은 그 CMO3에서만 옵니다.
> - **모델 → CMO3로 현재 모델 교체…**: 파일에 나타난 객체를 ID로 교체하고 새 객체를 넣으며, 나타나지 않은 기존 내용은 남깁니다.
> - 두 방법 모두 프리셋을 자동 생성하지 않습니다. 가져온 파라미터, 키폼, 디포머, 텍스처, 물리는 프로젝트와 함께 저장할 수 있습니다.

---

## 2. 저장 상태와 복구

입력이나 드래그 중인 편집을 끝낸 뒤 `Ctrl+S`로 저장합니다. 아래 상태 막대가 현재 저장 상태를 표시합니다.

| 상태 막대 문구 | 의미와 조작 |
| --- | --- |
| 초안 편집 중 | 입력이나 드래그가 아직 진행 중이거나, 초안을 제출하는 중입니다. 먼저 현재 편집을 끝냅니다 |
| 변경 사항이 메모리에 적용됨 | 변경이 현재 프로젝트에 들어갔지만, 복구 사본 쓰기는 아직 확인되지 않았습니다. 프로젝트를 저장해야 합니다 |
| 복구 사본 저장 중… | 비정상 종료 복구용 로컬 사본을 쓰는 중입니다 |
| 복구 사본 저장됨 · 프로젝트 미저장 | 복구 사본을 썼습니다. `Ctrl+S`로 변경을 `.psd2live` 파일에 저장합니다 |
| 복구 저장 실패 · 재시도 | 클릭하면 복구 사본 쓰기를 다시 시도합니다(가리키면 오류를 봅니다). 히스토리는 늘어나지 않습니다 |
| 프로젝트 저장 중… | 프로젝트 파일을 쓰는 중입니다. 끝날 때까지 기다립니다 |
| 프로젝트 저장 실패 | 가리켜 오류를 본 뒤, 처리하고 다시 저장하거나 다른 이름으로 저장합니다 |
| 프로젝트 저장됨 | 현재 변경이 `.psd2live` 파일에 저장되었습니다 |

> 복구 사본은 비정상 종료 뒤의 복구에만 씁니다. 백업, 전달, 다른 기기에서 이어서 작업하려면 `.psd2live` 프로젝트 파일을 저장하세요. 파츠 하위 설정의 조작은 [프리셋과 모디파이어](MODIFIERS.md#파츠-하위-설정과-물리)를 참조합니다.

## 3. 앱 페이지와 메뉴

작업 공간 탭 막대 맨 앞은 앱이 제공하는 페이지입니다. **시작**, **도움말**, **설정**. 프로젝트와 함께 저장되지 않으며, 패널은 끌어 도킹하고 합치고 띄울 수 있습니다. 배치는 이 컴퓨터의 환경설정에 저장됩니다. **창** 메뉴에서 다시 열거나 **레이아웃 초기화**를 할 수 있습니다.

### 시작 페이지
시작할 때 자동으로 표시됩니다(프로젝트를 열거나 새로 만든 뒤 접히며, **파일 → 시작 페이지**에서 다시 열 수 있습니다). 목록은 `↑` / `↓`로 바꾸고, 주 버튼은 `Enter`로 실행합니다.

- **PSD에서 생성**: 오른쪽에서 프리셋(최소 / 기본 / 전체)을 고르고, PSD를 창에 끌어 넣거나 **생성…**을 누릅니다. 아래 **최근 PSD**는 한 번 클릭하면 미리보기, 두 번 클릭하면 생성합니다. 오른쪽에서 「가져올 때 독립 메시 검사」를 조절할 수 있습니다. PSD 프로젝트를 새로 만들거나 그림 레이어를 가져올 때, 나눌 수 있는 독립 메시가 있으면 먼저 확인 창이 뜹니다. **모델 → 모델 전체의 독립 메시 검사…**로 직접 스캔하거나, 대상 메시를 오른쪽 클릭해 「메시」에서 이 레이어를 검사할 수도 있습니다.
- **배치 프로젝트**: 왼쪽에서 비율대로 캔버스를 미리보고, 오른쪽에서 자주 쓰는 크기를 고르거나 사용자 너비와 높이를 입력합니다. 만든 뒤 먼저 배치하고 나중에 생성하는 흐름으로 들어갑니다([소재와 Layout](LAYOUT.md) 참조).
- **CMO3에서 가져오기**: 새로 만들거나 현재 모델을 교체합니다.
- **최근**: 그리드나 목록으로 최근 프로젝트와 PSD를 검색하고 거릅니다. 두 번 클릭하면 엽니다.
- **기능 업데이트**: 버전별로 업데이트 설명을 보고, 대응하는 대화형 튜토리얼로 바로 이동할 수 있습니다.

### 제목 표시줄 메뉴
- **파일**: 새로 만들기, 열기, 저장, 내보내기, 있는 폴더 열기(프로젝트 / 원본 파일 / 출력 / 앱 데이터).
- **보기**: 캔버스, 패널, 작업 공간 배치 제어.
- **모델**: 모델 전체에 작용하는 조작(PSD 다시 분석, CMO3로 교체, 모델 전체의 독립 메시 검사, 텍스처 고해상도화, 생성 결과 업데이트).
- **도움말**: 도움말 페이지와 온라인 자료(GitHub, 문서, 예제 저장소, 릴리스, 문제 보고).
- **오른쪽 도구**: 사이드바 스위치, 언어, 밝기 테마, **설정**(톱니바퀴).

### 도움말 페이지(`F1`)
`F1`을 한 번 더 누르면 작업 공간으로 돌아갑니다. 목록에는 **매뉴얼**, **튜토리얼**, 예제, 커뮤니티 링크, 서드파티 라이선스, 정보가 있습니다.
- 매뉴얼과 튜토리얼은 Cubism Editor 구조로 정리되어 있고, 색 태그가 **동일** / **조작 다름** / **고유** / **미구현**(회색, 열 수 없음)을 표시합니다.
- 매뉴얼 끝의 「MCP와 도구」는 대응하는 MCP 조작과 필드를 나열합니다(실행 중인 서비스에서 읽음).
- 레이어 사양은 **매뉴얼 → 소재 나누기/PSD 제작 → PSD를 만들 때의 주의 사항**을 참조합니다. 단축키는 **매뉴얼 → 편집에 대하여 → 단축키 목록**을 참조합니다.

### 설정 페이지(`Ctrl+,`)
확대와 표시, 테마, 언어, 표시, 그래픽, 안내, 단축키, 파일과 데이터, MCP가 들어 있습니다. 대부분의 변경은 바로 적용됩니다(MCP는 **적용 후 다시 시작**을 눌러야 합니다).
- **표시**: 창 / 최대화 / 전체 화면(`F11`)을 지원합니다.
- **그래픽과 성능**: 화질 프리셋(낮음 / 중간 / 높음 / 매우 높음), 렌더 경로(GPU / GPU 창에 소프트웨어 캔버스 / 전체 소프트웨어), 그래픽 카드 선택, 수직 동기화, 안티앨리어싱, 텍스처 필터, 성능 오버레이. 캔버스 표시가 이상하면 먼저 「GPU 창, 소프트웨어 캔버스」를 시도합니다.
- **파일과 데이터**: 업스케일 캐시, 오류 로그, 비정상 종료 임시 잔여, 최근 파일 목록을 보고 정리합니다.

## 4. 작업 공간과 텍스처 작업 공간

위쪽 탭 막대 오른쪽 **+**를 누르면 작업 공간을 새로 만들 수 있습니다. 프리셋 8종과 빈 배치를 제공합니다.

![새 작업 공간 메뉴](../../imgs/workspace-presets.webp)

| 프리셋 | 용도 |
| --- | --- |
| 편집 | 편집 캔버스 하나에서 디포머, 키폼, 스켈레톤을 다루며 속성 패널이 갖춰져 있습니다 |
| 메시 | 계층 트리, 편집 캔버스, 메시 패널. 메시 토폴로지에 집중합니다 |
| 리깅 | 편집 캔버스와 실시간 미리보기를 나란히 두고, 파라미터 패널을 항상 둡니다 |
| 애니메이션 | 모션 목록, 미리보기 캔버스, 애니메이션 편집기 |
| 미리보기 | 큰 미리보기. 모션 목록만 남깁니다 |
| 물리 | 미리보기 캔버스에 파라미터와 물리 패널을 더해, 모델을 당기면서 조정합니다 |
| 텍스처 | 텍스처 아틀라스 페이지, 편집 캔버스, 텍스처 패널. 타일 배치와 텍스처 밀도를 관리합니다 |
| 히스토리 | 히스토리 트리와 조작 목록만 남겨, 분기를 살펴보고 전환합니다 |
| 빈 작업 공간 | 빈 도킹 영역. **창** 메뉴에서 패널을 직접 추가합니다 |

### 텍스처 작업 공간 요점
각 레이어에는 세 가지 크기가 있습니다. **캔버스 사각형**(캔버스 단위), **자신 래스터 픽셀**, **텍스처 아틀라스 타일 픽셀**.

- **텍스처 아틀라스 뷰(왼쪽)**:
  - 확대/이동은 편집 캔버스와 같습니다(휠 확대, 가운데 버튼 또는 `Space` + 드래그로 이동, `F`로 포커스, `Home`/`0`으로 맞추기, `Ctrl+A`로 모두 선택).
  - 타일 드래그, 모서리 점으로 밀도 조절, 바깥 핸들로 회전은 모두 **조정 세션**에 들어갑니다(미리보기만 하고 모델을 다시 만들지 않음). 위쪽 세션 막대에서 실행 취소/다시 실행/버리기를 할 수 있고, **적용**(또는 `Enter`)을 누르면 한 번에 히스토리 노드 하나로 제출합니다.
  - 타일이 다른 타일 메시와 겹치거나 페이지를 벗어나면 빨강으로 표시되며 적용할 수 없습니다.
  - 왼쪽 위 떠 있는 막대는 **배치**(메시 형태 / 사각형, 전체 / 선택), **자동 배치**(MaxRects) 스위치와 페이지 번호를 제공합니다. 오른쪽 위에서 예산(페이지 크기 1024–16384, 페이지 수, 간격)을 설정합니다. 오른쪽 아래에서 **밀도 히트맵**을 켤 수 있습니다(파랑 < 1, 초록 ≈ 1, 주황 > 1).
- **텍스처 패널(오른쪽)**:
  - 「캔버스 → 원본 → 텍스처 아틀라스」 세 칸의 크기와 실제 밀도를 표시합니다.
  - **텍스처 밀도**(`1/64`–`16`), **크기 잠금**, **회전**, **이미지 교체…**(메시를 다시 만들지 선택), **텍스처 고해상도화…**를 조절할 수 있습니다.
- **원본 픽셀 미리보기**: 편집 캔버스 오른쪽 아래 표시 막대에서 **원본 픽셀**을 켜면, 그 캔버스는 레이어의 원본 래스터를 직접 샘플링합니다. 묶은 뒤의 선명도와 비교하기 쉽습니다(내보내기와 미리보기 캔버스는 항상 텍스처 아틀라스 픽셀을 사용).
- Agent 쪽의 같은 이름 조작은 [MCP 사용과 인터페이스](../agent/MCP_AUTHORING.md#텍스처와-텍스처-아틀라스)를 참조합니다.

## 5. 대화형 튜토리얼 목차(주제 20개)

기초가 없는 경로는 아래 19과를 포함합니다. Cubism 경험이 있는 경로는 먼저 용어 대조를 읽고, 입문 과 일부를 건너뜁니다.

| 과 | 주제 | 조작 요점 |
| --- | --- | --- |
| 1 | 기본 흐름 | 레이어 PSD를 가져오고, 미리보기와 프리셋을 확인한 뒤 내보냅니다 |
| 2 | 작업 공간 둘러보기 | 편집 / 미리보기 / 히스토리 페이지가 함께 일합니다. 각 캔버스는 카메라와 스위치를 따로 저장합니다 |
| 3 | 계층 트리와 모드 바 | 선택, 검색, 부모 변경. 투명 그림을 끌어 레이어로 만듭니다 |
| 4 | 차분 | 차분 없음 / 스위치 차분(파라미터 하나로 있음·없음을 제어) / 전환 차분(여러 개 중 하나) |
| 5 | 소재와 배치 | 소재를 가져와 배치하고, 태그로 부위를 설명한 뒤 생성합니다([소재와 Layout](LAYOUT.md) 참조) |
| 6 | 파라미터와 키폼 | 슬라이더나 XY 컨트롤을 끌고, 오른쪽 클릭으로 스냅을 표시합니다. 파라미터 값을 먼저 정한 뒤 키폼을 편집합니다 |
| 7 | 오브젝트 모드 | 상자 선택, 올가미, 트리와 캔버스의 연동 위치 지정. 기하는 수정하지 않습니다 |
| 8 | 디포머 만들기 | 대상을 선택 → 부모/자식 디포머 추가 → 배치를 미리보기 → 확인 |
| 9 | 변형 모드 | 제어점, 전체 변환, 브러시를 조정합니다. 메시 디포머는 `1`/`2`로 정점/베지에를 전환합니다 |
| 10 | 편집 모드 | 메시 토폴로지를 수정합니다(세분, 연결, 점 배치, 삭제). 끝난 뒤 자세를 다시 확인합니다 |
| 11 | 페인팅 모드 | 브러시, 지우개, 채우기 등으로 픽셀을 다듬습니다. 세션 안에서 따로 실행 취소하고, 적용하거나 버립니다 |
| 12 | 인스펙터 | 이름, 소속, 마스크, 그리기 순서, 투명도, 색을 수정합니다 |
| 13 | 도구 옵션 | 왼쪽 아래 옵션 막대에서 반지름, 경도, 강도를 조절합니다. 「도구 세부」에 고급 설정이 있습니다 |
| 14 | 스켈레톤 리그와 편집 | 본 만들기/미러, 아트메시 바인딩, FK/IK 포즈, 가중치 칠과 베이크 내보내기 |
| 15 | 애니메이션과 모션 편집기 | 생성 모션을 조절합니다. 타임라인에서 파라미터 트랙, 키프레임, 베지에 이징을 편집합니다 |
| 16 | 물리 캔버스 디버그 | 입력, 진자, 출력을 설정하고, 실측 최댓값으로 배율을 맞춥니다 |
| 17 | 천과 머리카락 시뮬레이션 | 시뮬레이션을 만들고, 고정점/강성 등의 가중치를 칠한 뒤 파라미터와 진자로 베이크해 내보냅니다 |
| 18 | 프로젝트와 히스토리 | `.psd2live`를 저장하고, 히스토리 트리에서 분기를 검색/체크아웃합니다. **생성 결과 업데이트**가 새 버전을 병합합니다 |
| 19 | 텍스처 고해상도화 | 로컬 백엔드를 설정하고, 2× / 4×를 고른 뒤 가장자리와 내보내기 결과를 확인합니다 |

## 6. 혼동하기 쉬운 개념

- **저장과 내보내기**: 저장(`.psd2live`)은 프로젝트와 분기 히스토리를 남깁니다. 내보내기는 대상 소프트웨어가 쓰는 모델을 만듭니다. `.psd2live.json`은 진단 보고서일 뿐입니다. CMO3를 내보낼 때 모션은 같은 이름의 `.can3`로 따로 저장되며, 같은 디렉터리의 같은 배치로 열어야 합니다.
- **키폼과 키프레임**: 키폼은 파라미터 모델링에 속하며, 파라미터 키 사이에서 변형을 보간합니다. 키프레임은 애니메이션 타임라인에 있으며, 어느 시점의 파라미터 값을 기록합니다.
- **변형과 편집**: 변형은 형태를 바꿉니다. 편집은 메시 토폴로지 구조를 바꿉니다. 페인팅은 픽셀을 수정하고 독립 세션을 탑니다.
- **표시와 차분**: 트리의 임시 단독 표시/정적 표시는 편집 확인용입니다. 파라미터에 따라 바꾸려면 차분이나 불투명도 키폼을 사용합니다.
- **앞뒤 분리**: 깃이 목을 통과하는 경우처럼, 깃을 오른쪽 클릭해 **앞뒤 분리…**를 선택합니다(자세한 내용은 [앞뒤 분리 그림 튜토리얼](DEPTH_SPLIT.md)). 머리카락과 의상 시뮬레이션 단계는 [시뮬레이션 그림 튜토리얼](SIMULATION_TUTORIAL.md)을 참조합니다.

## 7. 생성 결과와 이전 프로젝트 업그레이드

- **Rig 모듈**: 새 프로젝트는 부위(눈, 눈썹, 입, 머리, 머리카락, 몸, 의상, 표정, 모션)별로 생성되며, 각 부위는 기초 알고리즘과 따로 켜고 끌 수 있는 모듈로 이루어집니다. **모델 프리셋 › 부위와 모듈**에서 간소 / 표준 / 전체 또는 파라미터 예산으로 한 번에 조정할 수 있습니다. 스타일 이목구비는 캔버스의 **특징점** 도구(`Shift+Y`)로 고칠 수 있습니다([캔버스 편집](CANVAS_EDITOR.md#특징점) 참조).
- **이전 프로젝트의 분할 기록**: 이전 버전의 분할 결과는 처음 편집할 때 일반 메시로 고정되며, 이미 있는 수정을 남깁니다. 새 분할은 원래 레이어 위치에서 바로 생성에 참여하고, 얼굴이나 스켈레톤을 수정할 때 파츠를 함께 갱신할 수 있습니다.
- **생성 결과 업데이트**: **모델 → 생성 결과 업데이트**는 수정하지 않은 부분을 새 생성기 결과로 올리고, 삼자 병합으로 손 편집을 남깁니다. **모델 → 생성 결과 업데이트 미리보기**는 변경 항목 수만 미리보고 프로젝트는 바꾸지 않습니다.

## 9. 점검과 문제 해결

| 현상 | 먼저 확인할 것 |
| --- | --- |
| 파츠 모션이 이상하거나 모션이 없습니다 | [PSD 레이어 사양](../spec/PSD_LAYER_SPEC.md)과 「레이어」 표의 유형, 좌우, 마스크, 부모 |
| 정지 자세는 정상인데 움직일 때 뚫립니다 | 애니메이션이나 물리 패널에서 전체 운동 궤적을 재생합니다 |
| 패널이 보이지 않습니다 | **창** 메뉴의 패널 스위치, 또는 **레이아웃 초기화** |
| 캔버스에서 모델이 보이지 않습니다 | 먼저 캔버스를 맞추고(`F` / `Home`), 레이어 표시를 확인합니다 |
| 내보내기 실패 또는 다운그레이드 안내 | 로그 패널, 내보내기 보고서 `.psd2live.json`, 내보내기 대상 버전 |
