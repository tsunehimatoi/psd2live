# 소재와 Layout

[문서 목록](../README.md) · [사용 가이드](USER_GUIDE.md) · [캔버스 편집](CANVAS_EDITOR.md) · [Layout 매니페스트](../spec/LAYOUT_MANIFEST.md)

Layout은 프로젝트 안에 파츠를 먼저 배치한 뒤 Rig를 생성합니다. 생성한 뒤에도 그림을 더하고 태그를 바꾼 다음 다시 생성할 수 있으며, 이미 만든 편집은 남습니다.

## 시작

- **빈 캔버스에서 시작**: 「시작」 페이지에서 「배치 프로젝트」를 고릅니다(「파일 > 새로 만들기 > 새 Layout 프로젝트」도 여기를 엽니다). 자주 쓰는 크기를 고르거나 속성 패널에 너비와 높이를 입력한 뒤 「배치 프로젝트 만들기」를 누르거나 크기를 두 번 클릭합니다. 새 프로젝트에는 아직 Rig가 없고, Layout 작업 공간으로 자동 전환됩니다.
- **PSD에서 시작**: 평소처럼 PSD를 가져옵니다. 프로젝트는 바로 Rig를 만들고, PSD의 각 레이어도 소재 패널에 나타나 캔버스의 레이어와 연결됩니다.
- **Layout 매니페스트에서 시작**: 외부 도구(예: AI 분할)가 쓴 [Layout 매니페스트](../spec/LAYOUT_MANIFEST.md)입니다. JSON 하나이거나, 루트에 그 JSON이 있는 zip입니다. PSD를 여는 방식으로 열거나 창에 바로 끌어 놓습니다. 레이어는 매니페스트대로 놓입니다. 위치, 위아래 순서, 그룹, 태그, 차분이 이미 설정되어 있고, 작은 파츠는 캔버스보다 많은 픽셀을 유지합니다. 프로젝트에는 아직 Rig가 없고, Layout 작업 공간으로 자동 전환됩니다.
- 어떤 작업 공간에서든 창 메뉴로 「소재」 패널을 열 수 있습니다.

Layout 작업 공간: 왼쪽은 소재 패널, 가운데는 편집 캔버스(오브젝트 모드), 오른쪽은 계층 트리와 레이어 표입니다.

## 소재 패널

- **가져오기**: 「가져오기」를 눌러 파일을 고르거나, 「폴더 가져오기」로 폴더 전체를 고르거나, 파일과 폴더를 패널에 바로 끌어 놓습니다(어떤 폴더나 경로 막대의 한 단계 위에 놓으면 그곳으로 가져옵니다). 폴더는 원래 중첩 구조대로 들어오고, 각 단계의 하위 폴더는 소재 폴더가 됩니다. 파일은 이름 안의 숫자 순으로 정렬됩니다(arm2가 arm10보다 앞). 숨김 파일과 폴더(예: .git), 지원하지 않는 파일은 건너뜁니다. PNG, BMP, TIFF, WebP(손실 포함), JPEG, PSD, CMO3 안의 각 ArtMesh 이미지, SVG를 지원합니다. PSD는 폴더가 되고, 레이어 그룹은 하위 폴더가 되며, 각 레이어는 PSD 안의 위치를 기억합니다.
- **탐색**: 왼쪽은 간소한 소재 트리입니다(폴더와 그 안의 그림. 기본은 모두 펼침. 도구 막대의 트리 버튼으로 접을 수 있습니다. 트리의 그림도 캔버스로 끌거나 두 번 클릭해 열 수 있습니다). 오른쪽은 현재 폴더의 내용입니다. 폴더가 먼저, 그다음 소재이며, 그리드와 목록을 바꿀 수 있습니다. 두 열 사이의 구분선을 끌어 너비를 조절합니다. 그리드의 썸네일 크기는 오른쪽 아래 슬라이더로 조절합니다(둘레에 투명 영역이 많은 소재는 내용이 있는 부분만 표시). 폴더를 두 번 클릭해 들어가고, 트리, 위쪽 경로 막대의 ↑, 또는 어느 단계로든 돌아갑니다. 검색은 모든 폴더에서 찾습니다. 항목 오른쪽 위의 숫자는 그것을 쓰는 레이어 수입니다.
- **출처**: PSD나 CMO3에서 가져온 폴더는 「PSD」/「CMO3」 색띠가 있는 파일 아이콘으로 표시되고, 뒤에 페이지가 겹치며, 오른쪽 아래는 그 안의 항목 수와 화살표입니다. 두 번 클릭해 열 수 있다는 뜻입니다. 가리키면 출처 파일 이름이 보입니다.
- **정리**: 소재나 폴더를 다른 폴더 위로 끌어 옮깁니다(그리드, 트리, 경로 막대의 어느 단계든 가능). 오른쪽 클릭 메뉴는 클릭한 곳에서 열리며, 캔버스 오른쪽 클릭 메뉴와 같습니다. 트리의 최상위와 폴더 메뉴에서 여기에 폴더를 만들거나 파일·폴더를 가져올 수 있습니다. 그리드나 목록의 빈 곳을 오른쪽 클릭하면 현재 폴더에 만들거나 가져오고, 그리드, 목록, 폴더 트리를 전환합니다. 트리의 빈 곳을 오른쪽 클릭하면 소재 라이브러리 최상위에 만들거나 가져옵니다. 항목 메뉴에서 이름 변경, 태그 편집, 한 단계 위로 이동, 삭제를 할 수 있습니다. 태그는 쉼표로 구분하며, 비우면 지웁니다. 폴더 태그는 검색에 쓰이고, 배치한 소재가 상속합니다. 레이어나 레퍼런스 이미지가 쓰고 있는 소재는 삭제할 수 없고, 그런 소재가 들어 있는 폴더도 삭제할 수 없습니다. 메뉴에 참조 수가 표시됩니다. 삭제 항목은 경고색이며, 프로젝트가 바쁘면 수정 조작을 쓸 수 없습니다.
- **기본 레퍼런스 레이어**: 소재나 폴더를 오른쪽 클릭해 「기본으로 레퍼런스 레이어에 배치」하면, 그 소재를 캔버스에 끌 때의 기본 유형이 바뀝니다. 폴더는 모든 하위 디렉터리의 소재에 적용됩니다. 메뉴의 「캔버스에 배치」는 모델 레이어로 명확히 놓고, 「레퍼런스로 추가 > 레이어 안」은 레퍼런스 레이어로 명확히 놓습니다.
- **소재는 레이어의 유일한 출처**: 모든 레이어는 소재 하나를 표시합니다. PSD, CMO3, 그림을 가져오거나, 레이어를 나누거나, 메시를 그릴 때 자동으로 등록됩니다. 자기만 쓰는 소재는 레이어 수정을 따라갑니다. 여러 레이어가 소재 하나를 공유하면, 그중 하나를 그리는 것은 소재를 그리는 것이고 나머지 레이어도 같이 바뀝니다. 하나만 따로 고치려면 오른쪽 클릭 「독립 소재로 설정」을 사용합니다. 아직 소재가 없는 이전 프로젝트의 레이어는 패널 위에 「소재 라이브러리에 등록」이 안내됩니다.
- **SVG**: 오른쪽 클릭 「텍스처 해상도…」에 `512x256`처럼 입력합니다. 해상도는 텍스처 아틀라스에 들어가는 픽셀을 정하며, 캔버스상의 크기는 변하지 않습니다. 이미 배치한 레이어도 함께 갱신됩니다.
- **PSD 내보내기**: 폴더에서 오른쪽 클릭 「폴더를 PSD로 내보내기…」를 사용합니다.

## 소재 창

소재를 두 번 클릭하거나(또는 오른쪽 클릭 「소재 창에서 열기」) 독립 창이 열립니다. 크기를 자유롭게 조절하고 다른 화면으로 옮길 수 있습니다. 창이 열린 상태에서 패널의 다른 소재를 클릭하면 창이 그 소재로 바뀝니다.

- **보기**: 휠로 확대·축소하고, 마우스 가운데 버튼이나 스페이스를 누른 채 끌어 이동합니다. 오른쪽 아래에서 바둑판 / 흰 배경 / 검은 배경을 바꾸고, 「창에 맞추기」(F)와 1:1(Home)이 있습니다. 2배 이상으로 확대하면 픽셀 단위로 표시합니다.
- **페인팅**: 창 안은 캔버스의 페인팅 모드입니다. 왼쪽 도구 막대, 아래 옵션 막대, 위의 페인팅 세션 막대(실행 취소, 다시 실행, 버리기, 적용), 오른쪽 클릭 메뉴, 붓끝과 스포이드 표시, 모든 단축키가 페인팅 모드와 같습니다. 다만 소재 자신의 픽셀에 그립니다. 색과 각 도구의 크기 같은 설정은 현재 캔버스에서 가져오고, 창을 닫으면 다시 가져갑니다.
- **적용**: 페인팅 모드와 같이, 획은 먼저 세션에 남습니다. 「적용」(Enter)은 한 단계의 히스토리로 소재에 기록하고, 「버리기」는 버립니다. 다른 소재로 바꾸거나 창을 닫으면 자동으로 적용됩니다. 그리는 동안 주 창에서 다른 내용을 평소처럼 편집할 수 있습니다.
- **조정**: 왼쪽 위 「조정」 메뉴에서 가로 또는 세로로 뒤집고, 색상, 채도, 명도, 대비를 조절합니다. 슬라이더를 끌 때는 먼저 미리보기하고, 「적용」을 누르면 기록됩니다. 적용하지 않은 획이 있으면 먼저 적용하거나 버립니다.

이 소재를 이미 배치한 모든 레이어가 함께 갱신되며, 캔버스상의 위치와 크기는 변하지 않습니다. SVG 소재는 페인팅이나 조정 뒤에 현재 해상도의 비트맵이 됩니다.

## 소재와 레이어의 연결

소재에서 배치한 레이어(그리고 PSD를 가져올 때의 레이어)는 소재와 연결됩니다. 레이어가 표시하는 것은 소재의 픽셀이고, 소재가 유일한 출처입니다.

- 페인팅 모드에서 이런 레이어를 그리면 소재 자체를 그리는 것이며, 이 소재를 쓰는 모든 레이어가 함께 바뀝니다. 세션 막대에는 「소재 「…」 페인팅 · 레이어 N개가 공유」라고 적힙니다. 캔버스 전체에 그릴 수 있습니다. 적용할 때 레이어 메시 위에 떨어진 부분은 소재에 기록되고, 메시 밖의 부분은 새 레이어로 나뉘어 바로 위에 놓이며, 새 소재로 원 소재 옆에 놓입니다.
- 레이어 표에서 연결된 레이어 이름 뒤에는 사슬 표시가 있고, 가리키면 소재 이름과 공유 레이어 수가 보입니다. 열면 「소재 창에서 열기」 또는 「연결 해제」를 할 수 있습니다.
- 연결을 해제하면 레이어의 픽셀은 그 레이어 것이 되고, 다시 그려도 소재와 다른 레이어에 영향을 주지 않습니다. 레이어 픽셀을 소재와 다르게 만드는 다른 편집(예: 분할, 다른 그림으로 교체)도 자동으로 연결을 해제합니다.
- 다른 소재로 「선택한 레이어의 그림 교체」를 하면 레이어가 그 소재와 연결되도록 바뀝니다.

소재는 프로젝트와 함께 저장되며, 모든 수정은 실행 취소할 수 있습니다.

## 배치

- 소재나 폴더 전체를 **캔버스 위로 끌어** 놓은 자리에 배치합니다. 오른쪽 클릭 「캔버스에 배치」도 됩니다. 폴더 안의 소재는 상대 위치를 유지하고, 하위 폴더는 원본 그림 그룹이 됩니다.
- **파일과 소재 끌어 놓기**: 컴퓨터에서 파일을 끌어 오는 것과 소재 패널에서 소재를 끄는 것은 같은 낙하지점을 씁니다. 손을 떼는 위치가 할 일을 정하며, 마우스 옆 안내가 먼저 알려 줍니다. 소재 패널로 끌면 소재로 가져옵니다(어떤 폴더 위에 놓으면 그곳으로 가져옴). 그림을 계층 트리로 끌면, 디포머 위에 놓으면 그 아래로 들어가고, 메시의 위쪽 절반이나 아래쪽 절반에 놓으면 그 앞이나 뒤에 삽입됩니다. 편집 캔버스로 끌면 캔버스 아래에 큰 선택지가 나타납니다. 배경 / 레이어 안 / 전경의 세 가지 레퍼런스(각각 모델에 들어가는지 적혀 있음), 선택한 레이어의 그림 교체, 소재 라이브러리에만 가져오기(파일에만 해당). 캔버스의 다른 곳에서 손을 떼면 그곳에 레이어로 배치됩니다. 프로젝트, PSD, CMO3, Layout 매니페스트를 다른 곳으로 끌면 열립니다. 받지 않는 위치에는 놓이지 않고, 오류도 나지 않습니다.
- PSD에서 온 소재는 기본적으로 PSD 안의 위치로 돌아갑니다. PSD 캔버스 전체가 프로젝트 캔버스 한가운데에 놓이고, 프로젝트 캔버스보다 크면 비율을 유지해 줄어듭니다. 크기가 같으면 원래 위치입니다. 다른 소재는 「소재 픽셀 1 = 캔버스 단위 1」로 캔버스 중앙에 놓이고, 캔버스를 넘으면 자동으로 줄어듭니다.
- 캔버스 단위는 모델의 좌표입니다. Cubism으로 내보내면 모델 캔버스의 픽셀이 되며, 모델의 크기와 비율을 정하고 선명도는 정하지 않습니다. 선명도는 소재 자신의 픽셀에서 옵니다. 배치와 크기 조절은 리샘플링하지 않으며, 레이어를 작게 놓을수록 텍스처가 촘촘해집니다. 내보낼 때 텍스처는 텍스처 아틀라스 예산(텍스처 작업 공간의 페이지 크기와 페이지 수)에 들어가야 하고, 들어가지 않으면 타일이 함께 줄어듭니다.
- 오브젝트 모드에서 변형 상자로 레이어를 **이동, 크기 조절, 반전**합니다. 픽셀은 리샘플링되지 않습니다. 600×600 눈을 64×64 캔버스 범위로 줄여도, 텍스처 아틀라스에는 여전히 600×600 밀도로 저장됩니다(텍스처 아틀라스 예산의 제한을 받습니다).
- **위아래 순서**: 새로 놓은 레이어는 맨 위에 있고, 폴더 전체를 놓을 때는 폴더 안의 원래 위아래 순서를 유지합니다. 레이어를 선택한 뒤 레이어 표 도구 막대의 「한 층 위로」「한 층 아래로」를 쓰거나, 캔버스에서 Ctrl+] / Ctrl+[ 로 한 층 올리거나 내리고, Ctrl+Shift+] / Ctrl+Shift+[ 로 맨 위, 맨 아래로 보냅니다. 레이어 표는 뒤에서 앞으로 레이어를 나열하며, 아래로 갈수록 앞입니다. Cubism의 그리기 순서와 같습니다. 아직 생성하지 않은 레이어는 모두 조정할 수 있습니다. 생성한 뒤에는 이미 생성된 레이어의 앞뒤를 그리기 순서로 조정하고, 새로 놓은 레이어는 다시 생성하기 전까지 조정할 수 있으며, 생성 전에는 잠시 맨 앞에 표시됩니다.
- **레퍼런스**: 원본 그림, 설정화, 스케치 같은 대조 그림은 계층 트리의 한 종류(레퍼런스 아이콘)이며 여러 개일 수 있습니다. 각 레퍼런스는 세 곳 중 하나에 표시되고, 표시 방식이 모델에 들어가는지를 정합니다. **배경**(모델에 들어가지 않음. 편집기에서만 모델 전체 아래에 깔림), **레이어 안**(모델에 들어감. 모델 안의 네 점 직사각형 ArtMesh이며, 추가할 때 픽셀 윤곽 추적이나 완전한 메시 생성을 하지 않고, 그리기 순서에 따라 레이어 사이에 놓이며, 디포머 아래에 매달아 변형을 따라갈 수 있고, 내보낼 때는 레퍼런스 그림 파츠에 속하며, 내보내기 창에서 「가이드 레이어 내보내기」를 선택했을 때만 씁니다), **전경**(모델에 들어가지 않음. 편집기에서만 모델 전체를 덮음). 레이어 안의 레퍼런스는 캔버스에 들어오는 즉시 편집 가능한 직사각형 ArtMesh이며, 먼저 Rig를 생성할 필요가 없습니다. 추가: 그림이나 소재를 편집 캔버스로 끌어 캔버스 아래의 큰 선택지에서 표시 방식을 고릅니다. 또는 계층 도구 막대, 캔버스 오른쪽 아래 표시 막대의 레퍼런스 그림 버튼(전경에 추가), 또는 소재 오른쪽 클릭 「레퍼런스로 추가」를 사용합니다. 계층 트리에서 배경이나 전경 레퍼런스를 선택하면 편집 캔버스에 핸들이 나타납니다. 안쪽을 끌어 이동하고, 모서리 점을 끌어 비율을 유지해 확대·축소하고, 위의 원점을 끌어 회전하며, 손을 뗄 때 히스토리 한 번이 기록됩니다. 레이어 안의 레퍼런스는 다른 ArtMesh와 같이 변형 상자로 조정합니다. 레퍼런스 오른쪽 클릭: 「표시 방식」이 세 곳 사이를 전환합니다(각 항목이 모델에 들어가는지 표시하고, 소재, 위치, 표시, 고정은 모두 유지). 표시/숨기기, 불투명도, 잠금(배경, 전경), 모델 레이어로 되돌리기(레이어 안), 제거도 있습니다. Alt+R은 현재 캔버스가 배경과 전경 레퍼런스를 표시하는지를 전환합니다.
- **레이어를 레퍼런스로 설정**: 아직 생성에 참여하지 않은 레이어(생성 전의 모든 레이어, 그 뒤에 새로 놓은 레이어)와 가져온 그림은 레이어 표 도구 막대의 「레퍼런스로」 또는 Ctrl+Alt+R로 레이어 안 레퍼런스가 됩니다. 캔버스 오른쪽 클릭 메뉴에도 「레퍼런스로」 스위치가 있습니다. 레퍼런스 레이어 이름 뒤에는 레퍼런스 아이콘이 있고, 누르면 모델 레이어로 돌아갑니다. 이미 모델에 들어간 것은 메시를 일반 레이어로 유지합니다. Layout 매니페스트에서 `reference`로 표시된 레이어는 열면 레이어 안 레퍼런스입니다. 이미 생성된 레이어는 레퍼런스로 설정할 수 없습니다.
- **키폼에 고정**: 각도가 다른 레퍼런스(정면, 측면, 올려다보기……)를 같은 위치에 겹치고, 각자 해당하는 키폼에서만 표시할 수 있습니다. 레퍼런스 하나가 여러 키폼에 나타날 수도 있으며, 세 가지 표시 방식 모두 가능합니다. 레퍼런스를 오른쪽 클릭하면 메뉴 아래의 「키폼에 고정」이 파라미터 패널의 형태로, 모델에서 키폼이 있는 파라미터를 나열합니다. 1차원 파라미터는 키폼 점이 있는 슬라이더이고, 짝을 이룬 파라미터는 2D pad입니다. 키폼 점을 누르면 그곳에 점을 찍고(채움), 다시 누르면 취소합니다. 레퍼런스는 어느 한 점에 있으면 표시됩니다(각 파라미터와 점의 차이가 파라미터 범위의 0.5%를 넘지 않음). 나머지 자세에서는 숨깁니다. 회색 표시는 현재 자세입니다. 「고정 취소」는 모든 점을 지웁니다. 캔버스 오른쪽 클릭 메뉴의 같은 이름 하위 메뉴가 같은 패널입니다. 고정은 편집기에서 언제 표시할지만 정하며, 내보내기에는 쓰지 않습니다.
- **그림 교체**: 레이어를 먼저 선택한 뒤 소재에서 오른쪽 클릭 「선택한 레이어의 그림 교체」를 사용합니다. 레이어의 캔버스상 위치와 크기는 변하지 않고, 픽셀과 텍스처 아틀라스 타일만 바뀝니다. 텍스처 아틀라스 뷰의 오른쪽 클릭 교체도 같습니다.

## 태그

레이어 표의 각 레이어에는 **태그** 칸이 있고, 열면 바로 편집합니다.

- 부위와 좌우를 나타내는 단어가 생성기에게 무엇인지 알려 줍니다. 예를 들어 「머리카락 + 앞」은 앞머리, 「눈 + 눈동자 + 왼쪽」은 왼쪽 눈동자, 「입 + 벌림」은 벌린 입입니다. 메뉴 아래에서 부위와 좌우를 바로 고를 수 있습니다.
- 입력란에는 단어 표의 단어를 넣을 수도 있고, 흔한 레이어 이름(예: 「앞머리」, 「eye-l」)을 넣을 수도 있으며, 해당하는 단어로 바뀝니다. 그 밖의 글자는 자신의 태그가 되어 정리와 검색에만 쓰이고 생성에는 영향을 주지 않습니다.
- 파츠 역할 단어는 레이어가 부위 안에서 무엇인지를 설명합니다. `highlight`(하이라이트), `pupil`(눈동자), `lower`(아랫속눈썹), `lid`(쌍꺼풀 선), `shadow`(그림자), `blush`(볼터치), `side`(옆머리), `ahoge`(삐죽 머리), `ponytail`(포니테일), `braid`(땋은 머리), `animal`(짐승 귀), `ribbon`(리본), `pendant`(펜던트, 술), `rigid`(단추, 배지 같은 단단한 장식), `sleeve`(소매), `skirt`(치마), 그리고 층을 나눈 입의 `upperlip`, `lowerlip`(주변 피부 한 바퀴를 포함한 윗입술, 아랫입술), `upperline`, `lowerline`(윗입술선, 아랫입술선). 생성할 때 레이어 이름, 있는 폴더, 레이어 사이 위치로 자동 판단해 태그에 표시합니다. 판단이 틀리면 고쳐 쓸 수 있고, 자동 판단한 역할을 지우면 다시 자동 판단하지 않습니다. 역할은 「부위와 모듈」의 모듈에만 영향을 주며, 기존의 생성 방식은 바꾸지 않습니다.
- 스위치 차분, 전환 차분은 태그에 없고, 옆의 「차분」 칸에서 설정합니다.
- 소재나 소재 폴더에 태그를 달면, 거기에서 배치한 레이어가 자동으로 그 태그를 가져갑니다.

## 생성과 다시 생성

편집 캔버스 오른쪽 위의 생성 막대는 아직 기다리는 것이 무엇인지 보여 줍니다.

- **미생성**: 새로 만든 Layout 프로젝트입니다. 레이어가 캔버스에 들어오면 정식 메시가 있어 메시, 디포머, 파라미터, 계층을 편집할 수 있고 내보낼 수도 있습니다. 빈 캔버스도 편집할 수 있습니다. 배치한 뒤 「생성」을 누르면 태그에 따라 자동 리그를 만듭니다.
- **생성 대기 N**: 생성한 뒤에 놓은 레이어, 태그나 분류를 바꾼 레이어입니다. 새로 놓은 레이어는 바로 일반 작업 공간의 모든 편집과 내보내기를 지원하고, 다음 생성 때 자동 리그에 들어갑니다. 바꾼 분류는 다음 생성 전까지 Rig에 영향을 주지 않습니다(레이어 표에서 강조색 테두리로 표시).
- 「다시 생성」을 누르면 이 내용이 Rig에 합쳐집니다. 만든 키폼, 디포머, 물리, 스윙, 스켈레톤, Glue는 남습니다. 깨끗하게 옮길 수 없는 내용은 품질 검사에 나열됩니다.
- 그림을 교체한 레이어는 기본적으로 새 픽셀에 맞춰 메시를 다시 만듭니다. 원래 메시를 남기려면 생성 버튼의 드롭다운에서 「생성하되 교체한 그림의 기하는 유지」를 고릅니다.

한 번 생성하는 시간은 같은 크기의 PSD를 가져오는 것과 비슷합니다.
