# 스윙 생성

[문서 목차](../README.md) · [물리](PHYSICS.md) · [MCP 사용과 인터페이스](../agent/MCP_AUTHORING.md)

스윙 생성은 Cubism Editor 5.1의 「揺れの自動生成」에 대응합니다. 곡선형 디포머를 선택하면 -1 / 0 / 1에 흔들리는 키폼을 자동으로 만듭니다. 그 위에 다음도 합니다.

- 메시를 선택해도 됩니다. 메시에 맞는 곡선형 디포머를 자동으로 한 겹 씌웁니다.
- **좌우**와 **상하** 두 가지 스윙이 있으며, 둘을 동시에 켤 수 있습니다.
- 끝을 수평으로 유지하고 하단을 평행하게 흔들어, 디포머 하나로 여러 묶음 머리카락이 함께 흔들리게 할 수 있습니다.
- 대응하는 **물리 진자**도 함께 만듭니다.
- 설정은 프로젝트와 함께 저장되며, 언제든 다시 열어 조정할 수 있습니다.

## 여는 방법

- 캔버스(오브젝트 모드)에서 선택한 메시나 곡선형 디포머를 오른쪽 클릭 → 「스윙 생성...」. 여러 개를 선택하면 함께 등록됩니다.
- 계층 트리에서 메시나 곡선형 디포머를 오른쪽 클릭 → 「스윙 생성...」. 이미 스윙을 만든 오브젝트는 「스윙 편집...」으로 표시됩니다.
- 물리 패널 → 「+ 새로 만들기」 → 「선택한 오브젝트에 스윙 만들기…」. 물리 그룹 목록에서 스윙에서 온 그룹은 「⋯」 메뉴의 「스윙 편집」으로 열 수 있습니다.

열면 현재 캔버스가 편집 캔버스로 바뀌고(미리보기가 아님) 스윙 편집으로 들어갑니다. 편집 중에는 캔버스를 가리는 창이 뜨지 않습니다. 형태는 캔버스에서 직접 드래그하고, 설정은 작업 공간 왼쪽 아래에 떠 있는 스윙 패널에 있습니다. 제목을 누르면 접히고, 제목 표시줄의 「↗」로 독립 창으로 옮길 수 있습니다(「↙」는 작업 공간에 다시 도킹).

- 여러 대상이 같은 파라미터와 진자를 공유합니다.
- 편집하는 동안 캔버스는 잠깁니다. 핸들 밖을 눌러도 다른 오브젝트를 선택하거나 드래그하지 않고, 오른쪽 클릭 메뉴도 뜨지 않습니다.
- 대상을 더하려면 계층 트리에서 다른 메시를 선택한 다음 패널의 「선택 항목 등록」을 누릅니다.
- 회전 디포머는 대상이 될 수 없습니다.

## 캔버스의 컨트롤

캔버스에는 스윙 사각형(너비는 지점 변, 길이는 지점 변 중점에서 맞은편 변 중점까지)의 윤곽 세 가지를 그립니다. 정지 형태(점선), +1 포즈(실선), -1 포즈(옅은 색)이며, 두 포즈의 중심선도 그립니다. 고정된 변은 더 굵게 표시됩니다. 모든 핸들은 지금 편집하는 방향의 +1 포즈 위에 있으며, 드래그한 곳으로 +1 포즈의 그 부분이 이동합니다.

| 핸들 | 위치 | 드래그 효과 |
| --- | --- | --- |
| 원 | 끝 | 가로로 드래그하면 폭을 정하고, 반대쪽으로 드래그하면 뒤집힙니다. 축을 따라 드래그하면 들림 / 처짐을 정합니다. 신축 바운스일 때는 축 방향으로만 작용합니다 |
| 마름모 | 중심선 중점 | 부드러움을 정합니다. 가운데가 끝을 덜 따라갈수록 뿌리가 더 빳빳합니다 |
| 작은 사각형 | 끝의 두 모서리 | 끝의 확대 / 축소를 정합니다. 굽힐 때는 하단 평행 정도(끝 변이 얼마나 수평을 유지하는지)도 정합니다 |
| 십자 원 | 지점 변 중점 | 스윙 사각형 전체를 이동합니다. 지점 변 중점이 포인터를 따릅니다 |
| 빈 원 | 정지 중심선이 끝을 지나 연장된 곳 | 지점 중점을 중심으로 스윙 사각형 전체를 회전합니다(축 각도). 포인터 방향만 봅니다. 0°에 가까우면 0°로 스냅합니다 |
| 빈 사각형 | 나머지 세 변의 중점 | 클릭하면 그 변을 지점으로 정합니다 |

모든 수정은 모델에 바로 표시됩니다. 패널의 「스윙 미리보기」는 파라미터를 -1과 1 사이에서 왕복합니다(여러 단이면 단마다 어긋나고, 상하와 좌우도 어긋납니다). 「생성」 / 「적용」 또는 Enter는 히스토리 한 줄로 기록합니다. 「취소」 또는 Esc는 어떤 변경도 남기지 않습니다.

## 두 가지 스윙과 지점

「스윙 방향」은 끝이 화면에서 움직이는 방향입니다. 「지점」은 고정되어 움직이지 않는 변입니다(격자점의 행과 열로 계산하며, 0행이 위쪽 변입니다). 둘의 조합이 변형 방식을 정합니다.

| 방향 | 지점 | 변형 | 전형적인 용도 |
| --- | --- | --- | --- |
| 좌우 | 위 / 아래 | 호형 굽힘 | 머리카락, 리본, 꼬리 |
| 상하 | 왼쪽 / 오른쪽 | 호형 굽힘 | 옆으로 뻗은 장식, 옆 리본 |
| 상하 | 위 / 아래 | 신축 바운스 | 귀걸이, 풍성한 머리카락 끝, 가슴 |
| 좌우 | 왼쪽 / 오른쪽 | 신축 바운스 | 거의 쓰지 않음 |

- **호형 굽힘**: 중심선을 따라 굽힐 때 길이가 유지되므로, 끝이 밖으로 흔들릴 때 자연스럽게 올라갑니다. 단순히 평행 이동하듯 늘어나지 않습니다.
- **신축 바운스**: 끝이 지점 방향으로 늘어나거나 줄어듭니다. 늘어날 때 좁아지고, 압축될 때 넓어져 부피감이 유지됩니다.
- **자동 지점**:
  - 가늘고 긴 오브젝트는 위쪽 변을 씁니다.
  - 가로로 누운 오브젝트는 몸 중심선에 더 가까운 쪽을 씁니다.

### 스윙 사각형의 회전과 이동

기본 스윙 사각형은 디포머와 정렬됩니다. 소재가 비스듬히 늘어져 있는데(옆머리, 비스듬히 단 장식) 디포머는 여전히 바른 사각형이면, 끝 밖의 빈 원을 드래그해 스윙 사각형 전체를 지점 변 중점을 중심으로 회전할 수 있습니다. 범위는 ±75°입니다.

- 양수는 끝을 지점 변의 끝쪽으로 돌립니다(위 / 아래 지점은 오른쪽 끝, 왼쪽 / 오른쪽 지점은 아래쪽 끝). 미러된 부모 공간도 함께 미러됩니다.
- 사각형 크기는 그대로이고 방향만 돌아갑니다. 굽힘은 돌아간 축에 수직이고, 호형 길이 유지, 들림, 신축, 평행은 모두 돌아간 사각형 안에서 계산됩니다. 캔버스의 윤곽, 고정 변, 지점과 끝 핸들도 함께 돌아갑니다.
- 고정되는 것은 사각형의 지점 변입니다. 그 뒤쪽은 움직이지 않고, 격자점의 원래 변 중 한쪽 끝이 지점 변 앞으로 나와 있으면 뿌리에 가까운 굽힘에 따라 조금 움직입니다.
- 지점 변 중점의 십자 원을 드래그하면 사각형 전체를 옮길 수 있습니다. 예를 들어 지점을 머리카락 뿌리가 실제로 있는 곳으로 내리면, 그 위쪽은 그대로 있습니다. 회전은 옮긴 뒤의 중점을 중심으로 합니다.
- 이동량은 사각형 자신의 비율로 저장됩니다. 축을 따라서는 길이로, 지점 변을 따라서는 너비로(각각 ±1) 재므로, 대상 디포머의 각 키폼이 확대·축소되거나 이동해도 소재의 같은 위치에 놓입니다.
- 축 각도와 이동은 스윙 전체에 속하며 두 방향이 공유합니다. 패널에 현재 수치가 표시되고, 각자의 「0으로」가 기본으로 되돌립니다. 다른 변을 클릭해 지점을 바꾸면 둘 다 0이 됩니다. 예전에 저장한 스윙은 0으로 열립니다.

### 좌우와 상하의 조합

패널 「스윙 방향」의 두 옵션은 동시에 체크할 수 있으며, 둘 다 같은 디포머에 작용합니다.

- 두 방향은 각자 파라미터, 형태 설정, 진자가 있습니다.
- 같은 지점에서는 반드시 하나는 굽힘, 하나는 신축입니다. 생성할 때 먼저 신축하고 그다음 굽히므로, 조합 포즈는 정확하며 둘을 단순히 더한 것이 아닙니다.
- 두 방향을 모두 켜면 패널에 「편집」 줄이 더해져, 캔버스 핸들이 어느 방향에 대응하는지를 고릅니다.

## 하단 평행(여러 묶음 머리카락)

머리카락을 나누지 않으면 왼쪽 머리, 앞머리, 오른쪽 머리가 같은 디포머 안에 있습니다. 보통의 굽힘은 각 단면을 중심선과 함께 돌리므로, 덩어리 전체가 판처럼 돕니다. 끝 변이 기울고 한쪽은 올라가고 다른 쪽은 내려가 이상해 보입니다.

「평행」 설정은 단면이 얼마나 도는지 조절합니다.

- **0**: 단면이 굽힘을 따라 돌고, 덩어리 전체가 판처럼 흔들립니다. 한 가닥의 머리카락, 장식에 맞습니다.
- **1**: 단면이 수평을 유지하고 끝 변은 기울지 않습니다. 각 열이 고정 변의 자기 위치에 매달려 옆 열과 나란히 이동하므로, 여러 묶음 머리카락이 함께 흔들리는 것처럼 보입니다.
- 중심선의 호는 영향을 받지 않으므로, 폭, 들림, 부드러움의 의미는 그대로입니다.
- 앞머리처럼 고정 변에 가까운 짧은 묶음은 원래 굽힘이 작은 자리에 있으므로 자연히 적게 흔들립니다. 나눌 필요도, 디포머를 더할 필요도 없습니다.

머리카락과 천 프리셋은 기본적으로 평행 쪽입니다(머리카락 좌우 0.7). 장식 프리셋은 0입니다. 캔버스에서 끝의 두 모서리에 있는 작은 사각형을 드래그하면 조정됩니다.

## 설정

패널에는 캔버스에 대응 위치가 없는 옵션만 둡니다(스윙 방향, 편집 방향, 자동 추정, 분할 수, 자동 지점, 물리). 나머지 몇 항목은 현재 방향의 수치를 읽기 전용으로 보여 줍니다.

| 설정 | 작용 |
| --- | --- |
| 스윙 폭 | ±1일 때 끝이 이동하는 거리. 지점에서 끝까지의 길이로 잽니다(0.25 = 길이의 4분의 1) |
| 들림 / 처짐 | 굽힐 때 끝이 추가로 올라가는 양(양수) 또는 처지는 양(음수) |
| 부드러움 | 0: 전체가 고르게 굽습니다. 1: 뿌리는 빳빳하고 주로 끝이 움직입니다 |
| 확대 / 축소 | ±1일 때 끝에 가까운 부분이 넓어지거나 좁아집니다 |
| 평행 | 0: 덩어리가 판처럼 돕니다. 1: 끝 변이 수평을 유지하고 각 열이 나란히 흔들립니다 |
| 축 각도 | 스윙 사각형이 지점 중점을 중심으로 회전하는 각도(±75°). 비스듬히 단 소재에 씁니다 |
| 이동 | 스윙 사각형의 지점 변 중점이 축을 따라 / 지점 변을 따라 어긋난 양. 길이 / 너비로 잽니다 |
| 좌우 반전 | +1과 -1의 방향을 바꿉니다 |
| 분할 수 | 방향마다 1–3단이며, 단마다 파라미터가 하나입니다. 제 k단은 그 아래 부분만 굽히고, 물리에서는 마디가 있는 진자 하나를 공유합니다. 아래 단이 위 단보다 한 박 늦어 채찍처럼 따라옵니다 |
| 자동 추정 | 머리카락 / 장식 / 천. 초기 형태와 진자 파라미터 한 벌을 줍니다. 진자 길이는 대상의 픽셀 길이로 추정합니다 |

파라미터가 없으면 자동으로 만듭니다(범위 -1..1). 이름은 `ParamSwing<id>`이고, 두 방향을 모두 켜면 `_X`(좌우) / `_Y`(상하)를 붙이며, 여러 단이면 `_1`, `_2`…를 더 붙입니다. 방향이나 단 수를 바꾸면 파라미터가 이 규칙으로 다시 이름 붙여집니다. 이미 있는 파라미터를 고르면 키는 그 최솟값, 기본값, 최댓값에 놓입니다.

예전에 저장한 스윙에는 「평행」 설정이 없습니다. 열 때는 0으로 처리해 원래 모습을 유지합니다.

## 물리

「이 스윙의 물리 진자 생성」을 체크하면, 내보내는 physics3.json과 cmo3에 진자 물리 그룹이 추가됩니다.

- 방향마다 진자가 하나입니다. 방향이 하나뿐이면 그룹 이름은 `PhysicsSwing_<id>`이고, 두 방향이면 `PhysicsSwing_<id>_X`와 `PhysicsSwing_<id>_Y`입니다.
- **좌우**: 입력은 앞머리·뒷머리와 같습니다. 머리와 몸의 각도 X(X 유형), 각도 Z(각도 유형)입니다.
- **상하**: 입력은 머리와 몸의 각도 Y, 그리고 가중치가 작은 각도 Z입니다.
  - Cubism의 진자 막대는 강체라서, 수직으로 매달린 진자는 상하 이동에 반응하지 않습니다.
  - 그래서 여기서는 각도 Y를 가로(X 유형) 가진 입력으로 삼고, 진자의 각도로 상하 형태를 구동합니다.
- **분할 수**: 각 단은 물리 그룹의 진자 하나에 대응합니다. 제 k단 파라미터는 진자 수가 k인 출력이 구동합니다.

진자도 [물리 패널](PHYSICS.md)에 나열되며, 그곳에서 직접 편집할 수 있습니다(입력, 출력, 각 진자의 역학 등). 물리 패널에서 수정하면 물리 패널의 버전이 우선하고, 스윙 패널의 진자 수치는 더 이상 적용되지 않으며 패널이 이를 알립니다. 물리 패널에서 「생성값으로 되돌리기」를 누르면 스윙으로 생성한 진자로 돌아갑니다. 같은 출력 파라미터에 새로 만든 사용자 지정 그룹은 해당 진자를 대체합니다. 스윙을 삭제하거나 방향을 바꾸면 이전 진자의 수정도 함께 지워집니다.

## 생성기 의미와 베이크

스윙은 「생성기」입니다. 모델을 다시 구축할 때마다 대상 디포머의 현재 형태를 기준으로 다시 계산한 다음, 뒤에 스윙 축을 붙입니다. 그래서 다음이 성립합니다.

- 대상에 원래 있던 키 축(예를 들어 각도 X)은 모두 유지됩니다. 원래의 각 키폼은 스윙의 각 형태로 펼쳐집니다.
- 이 스윙 축은 스윙이 소유합니다. 이 축의 키폼을 손으로 바꾸면 다시 구축할 때 덮어씁니다.
- 손으로 미세 조정하려면 패널에서 「키로 베이크」를 누릅니다.
  - 현재 형태가 일반 키폼으로 기록되고, 그 뒤로는 자유롭게 편집할 수 있습니다.
  - 진자는 남고, 스윙은 물리 부분만 남습니다.
- 「삭제」는 생성된 축과 자동으로 만든 파라미터를 함께 제거합니다.

## Agent

MCP는 `swing_put`으로 스윙을 새로 만들거나 바꾸고, `swing_delete`로 스윙을 삭제합니다. 파라미터는 `{"request": {...}}`에 두며, `project_id`, `state`, `request_id`를 함께 보냅니다.

- `swing_put`은 `id`로 기록합니다. `targets`는 메시 또는 곡선형 디포머입니다. 방향이 하나뿐이면 최상위에 `kind`(`lateral` / `vertical`), `segments`, `parameters`와 형태 필드(`magnitude`, `lift`, `softness`, `zoom`, `parallel`, `flip`)를 바로 씁니다.
- 두 방향을 조합할 때는 `motions: [{kind: "lateral", ...}, {kind: "vertical", ...}]`를 쓰고, 각 항목에 자기 필드, 파라미터, `physics`를 둡니다.
- 최상위의 `fulcrum`은 지점 변을 고르고, `tilt`는 스윙 사각형이 지점 중점을 중심으로 회전하는 각도(도, ±75)이며, `offset_along` / `offset_across`는 사각형의 이동(길이 / 너비, ±1)입니다. 두 방향이 공유합니다. `preset`(`hair` / `accessory` / `cloth`)은 패널의 자동 추정에 대응합니다.
- `physics`를 생략하면 대상 크기로 진자를 추정합니다. `physics_enabled=false`는 진자를 만들지 않는다는 뜻입니다.
- `swing_delete`의 `bake=true`는 「키로 베이크」와 같습니다.

캔버스의 스윙 편집은 미리듣기 세션에 대응하며, 제출하기 전에는 문서와 히스토리에 들어가지 않습니다. `swing_preview`는 `mode=begin`과 `targets`로 시작하고, 그 뒤 `update`, `kinds`, `segments`, `preset`, `physics`, `select`, `handle`(캔버스 핸들과 같음), `play`, `cancel`로 수정합니다. `swing_preview_get`은 초안, 핸들 위치, 재생 포즈를 읽고, `swing_preview_render`는 현재 포즈를 렌더링하며, `swing_preview_commit`은 한 번 제출합니다. `swing_preview`와 `swing_preview_commit`은 백그라운드 작업 핸들을 반환하며, `job_wait`로 결과를 가져옵니다.

`workspace_inspect`의 `scope=swings`는 현재의 모든 스윙을 나열합니다.
