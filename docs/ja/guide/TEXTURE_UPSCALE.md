# テクスチャ高解像度化

[ドキュメント目次](../README.md) · [操作早見表](USER_GUIDE.md) · [開発とコマンドライン](DEVELOPMENT.md)

プログラム内の入門コース第 19 課に対応します。高解像度化は、テクスチャをパックする前にレイヤーごとにテクスチャを拡大します。既定はオフです。元の PSD、キャンバスサイズ、リグは変わりません。プレビューと書き出しは、処理後のテクスチャを使います。

## 設定と使い方

**モデル → テクスチャ高解像度化…**（既定は `Ctrl+U`）を開き、次を設定します。

| フィールド | 記入内容 |
| --- | --- |
| Python | nunif の依存関係を導入した Python 実行ファイル。引数付きのコマンド文字列ではありません |
| nunif ディレクトリ | `nunif` と `waifu2x` のサブディレクトリを含む、ローカルのソースディレクトリ |
| モデルディレクトリ | Art の `.pth` 重みを実際に保存しているディレクトリ。アプリは `swin_unet_v3/art` と `swin_unet/art` のパスを検出できます |
| 倍率 | 1 はオフ。2× または 4× で拡大します |
| ノイズ除去 | -1 は拡大のみ。0–3 は、使用するモデルが対応するノイズ除去レベルです。既定は 1 |
| ニューラル Alpha | 既定はオン。オフにすると、Alpha はバイリニアで拡大します |
| 入力タイル | 64–512。既定は 256。VRAM が足りないときは小さくします |

ローカルの Python、PyTorch、nunif、および対応する重みを用意してから適用してください。上流の特定バージョンに必要なインストール手順は、そのバージョンに付属する説明を参照してください。配布パッケージに、完全な推論環境は含まれません。適用するとプレビューを再構築し、設定はプロジェクトとともに保存されます。別のコンピューターでは、ローカルパスを確認し直す必要があります。

4× は、ネイティブの 4× 重みを優先します。ない場合、現在の worker は、対応している 2× モデルを 2 回実行できます。一致するモデルがないときはエラーになり、通常の補間を超解像の代わりには使いません。

## CLI の例

```powershell
.\gradlew.bat run --args="--input examples/tml/psd-input/tml.psd --output build/upscaled-model --upscale 2 --upscale-python C:/venv/Scripts/python.exe --nunif-dir C:/nunif --upscale-model C:/nunif/waifu2x/pretrained_models/swin_unet_v3/art --upscale-tile 256"
```

ニューラル Alpha をオフにするには `--no-upscale-neural-alpha` を使います。その他の引数は [CLI 表](DEVELOPMENT.md) を参照してください。例示のパスは、手元のパスに置き換えてください。空白を含むときは、起動方法の規則に従って引用します。

## 効果とリソース

RGB と Alpha は別々に処理します。透明領域の色を外側へ広げるのは、サンプリング時に縁が汚れるのを軽くするためです。ニューラル Alpha でも、半透明の輪郭が変わることがあります。明るい背景と暗い背景の両方で、髪の毛、まつ毛、リップライン、および動きの中のマスク縁を確認してください。

推論はレイヤーごとに直列で実行されます。出力とテクスチャのパックでも、システムメモリを使います。キャッシュはユーザーディレクトリの `.psd2live/cache/upscale` にあり、素材、設定、コード、重みに関する識別子を含みます。アプリの終了後に削除できます。モデルのエラー、サイズ上限の超過、タイムアウトが起きたときはログを確認してください。テクスチャアトラスを広げるだけでは、再試行しないでください。

実装の根拠：[設定とプロセス管理](../../../src/main/kotlin/io/github/psd2live/core/TextureUpscale.kt)、[nunif worker](../../../src/main/resources/upscale/nunif_worker.py)。
