# 変形パス（実験的）

[ドキュメント目次](../README.md) · [キャンバス編集](CANVAS_EDITOR.md)

パスは ArtMesh に付く編集補助オブジェクトであり、Warp / Rotation とは別の第三のデフォーマではありません。現在は 1 つの ArtMesh 上に複数のパスを置けますが、1 本のパスで複数の ArtMesh を制御することはできません。

## 最短の操作

1. ArtMesh を選択し、ツリーを右クリックして「変形パスを追加」します（既定は `P` / `D`）。
2. 制御点を少なくとも 2 つクリックして配置し、Enter で確定、Esc でキャンセルします。
3. **編集モード**で、パスのバインド位置、幅、硬さ、閉じ、角の点を調整します。この段階では画像の形状は変わりません。
4. パラメータパネルで目標のポーズを決め、**変形モード**に切り替えて制御点をドラッグし、結果を ArtMesh の形状へ書き込みます。

オブジェクトモードはオブジェクトの選択だけを行います。パスは L2 / L3 の 2 組に分かれ、それぞれ一式を保持します（`.cmo3` へ書き出すときは、パスの編集レベルになります）。メッシュデフォーマの「頂点 / ベジェ」レベルとは無関係です。パスを新規作成するときは、配置パネル、または「ツール詳細」の「パス編集レベル」で組を選びます。既存のパスは、インスペクターの「編集レベル」で変更します。キャンバスには、現在の組のパスだけを表示して編集します。補助線は、選択中のオブジェクトと編集ページのビュー設定に従って表示され、プレビューページにはパスを表示しません。通常の編集は、メインキャンバスの履歴をそのまま使います。

## 保存と書き出し

| ファイル | 保存される内容 |
| --- | --- |
| `.psd2live` | パスの設定、バインド、再実行できる形状編集 |
| `.cmo3` | ネイティブのコントローラー構造と、メッシュのキーフォーム |
| `.moc3` | ベイク後のメッシュキーフォーム。ランタイムはパスのアルゴリズムを実行しません |

現在のアルゴリズムは、カーブのサンプリング、移動最小二乗法、三角形へのバインドを使います。コントローラーを読み書きできることは、ドラッグ結果が Cubism Editor と一致するまで確認済みであることを意味しません。幅、硬さ、大きな角度の変形、均一でない親のスケールは、特に確認してください。

メインキャンバスでのトポロジ操作は、パスを再バインドします。頂点が疎すぎるメッシュや、互いに矛盾する制約があると、変形が拒否されることがあります。公式 Editor で開く、ドラッグする、保存し直す、という一連の互換性確認は、このページにはまだ記録していません。

Agent は `path_list` と `path_get` でパスを確認し、`path_put` と `path_delete` でパスを作成、変更、削除し、`path_preview` で制御点のドラッグを試し、`path_deform` でドラッグ結果をキーフォームとして書き込みます。`workspace_inspect` の `scope=paths` は、すべてのパスを列挙します。フィールドは [MCP インターフェース](../agent/MCP_AUTHORING.md) を参照してください。
