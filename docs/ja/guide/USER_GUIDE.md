# 操作早見表

[ドキュメント目次](../README.md) · [PSD レイヤー仕様](../spec/PSD_LAYER_SPEC.md) · [キャンバス編集](CANVAS_EDITOR.md) · [開発と CLI](DEVELOPMENT.md)

> [!TIP]
> 初めて使うときは、プログラム内で `F1` を押してヘルプを開き、**制作の流れ** から対話型チュートリアルを始めることを勧めます（入門 19 課 / Cubism 経験者 14 課）。この文書は、操作を見直すときと、ショートカットをすばやく調べるときに使います。

---

## 1. 最短の手順

1. **読み込み**：`Ctrl+Shift+O` でレイヤー分けした PSD を読み込みます（既存の `.psd2live` プロジェクトは `Ctrl+O` で開きます）。
2. **確認**：自動生成のプレビューとレイヤー分類を見て、必要ならキャンバス上で微調整します。
3. **保存**：`Ctrl+S` で `.psd2live` プロジェクトとして保存します（`Ctrl+Shift+S` は別名で保存）。
4. **書き出し**：`Ctrl+G` で対象のモデルを書き出します（`.moc3` / `.cmo3` など）。

> **既存の Cubism モデルを読み込む**：
> - **ファイル → 新規作成 → CMO3 から新規プロジェクト…**：現在のモデルを空にしてから読み込みます。モデルの内容は、その CMO3 だけから来ます。
> - **モデル → CMO3 で現在のモデルを置き換え…**：ファイルに現れるオブジェクトを ID で置き換え、新しいオブジェクトを追加します。現れない既存の内容は残します。
> - どちらの方法もプリセットは自動生成しません。読み込んだパラメータ、キーフォーム、デフォーマ、テクスチャ、物理演算は、プロジェクトとともに保存できます。

## 2. 保存状態と復元

入力中またはドラッグ中の編集を終えてから、`Ctrl+S` で保存します。下部のステータスバーが、現在の保存状態を示します。

| ステータスバーの文字 | 意味と操作 |
| --- | --- |
| 下書きを編集中 | 入力またはドラッグが続いているか、下書きを反映中です。先に現在の編集を終えます |
| 変更をメモリに反映済み | 変更は現在のプロジェクトに入っていますが、復元用コピーの書き込みはまだ確認されていません。プロジェクトの保存は引き続き必要です |
| 復元用コピーを保存中… | 異常終了からの復元に使うローカルコピーを書き込んでいます |
| 復元用コピー保存済み · プロジェクト未保存 | 復元用コピーは書き込み済みです。`Ctrl+S` で変更を `.psd2live` ファイルへ保存します |
| 復元保存に失敗 · 再試行 | クリックして復元用コピーの書き込みを再試行します（ホバーでエラーを確認）。履歴は増えません |
| プロジェクトを保存中… | プロジェクトファイルを書き込んでいます。完了を待ちます |
| プロジェクトの保存に失敗 | ホバーでエラーを確認し、対処したあと、もう一度保存するか別名で保存します |
| プロジェクト保存済み | 現在の変更は `.psd2live` ファイルへ保存済みです |

> 復元用コピーは、異常終了のあとの復元にだけ使います。バックアップ、受け渡し、別の機器での継続には、`.psd2live` プロジェクトファイルを保存してください。パーツの子設定の操作は [プリセットとモディファイア](MODIFIERS.md#パーツのサブ設定と物理演算) を参照してください。

## 3. アプリのページとメニュー

ワークスペースのタブバーの先頭は、アプリ自身のページです。**スタート**、**ヘルプ**、**設定**。これらはプロジェクトとともに保存されず、パネルはドラッグしてドック、結合、フローティングにできます。レイアウトはローカルの設定に保存されます。**ウィンドウ** メニューから開き直すか、**レイアウトをリセット** できます。

### スタートページ
起動時に自動で表示されます（プロジェクトを開くか新規作成すると折りたたまれ、**ファイル → スタートページ** から開き直せます）。目次は `↑` / `↓` で移動し、主ボタンは `Enter` で実行します。

- **PSD から生成**：右側でプリセット（最小 / 標準 / フル）を選び、PSD をウィンドウへドロップするか、**生成…** をクリックします。下の **最近の PSD** は、クリックでプレビュー、ダブルクリックで生成です。右側で「読み込み時に独立メッシュを確認」を制御できます。新しい PSD プロジェクトの作成時、または画像レイヤーの読み込み時に、分割できる独立メッシュが見つかると、先に確認ダイアログが出ます。**モデル → モデル全体の独立メッシュを確認…** で手動スキャンすることも、対象メッシュを右クリックして「メッシュ」からこのレイヤーを確認することもできます。
- **レイヤー読み込みプロジェクト**：左側でキャンバスを比率どおりにプレビューし、右側でよく使うサイズを選ぶか、幅と高さを入力します。作成後は、先に配置してから生成する流れに入ります（[素材と Layout](LAYOUT.md) を参照）。
- **CMO3 から読み込み**：現在のモデルを新規作成するか、置き換えます。
- **最近**：グリッドまたはリストで、最近のプロジェクトと PSD を検索、絞り込みし、ダブルクリックで開きます。
- **新機能**：バージョンごとに更新説明を見られ、対応する対話型チュートリアルへ直接移動できます。

### タイトルバーのメニュー
- **ファイル**：新規作成、開く、保存、書き出し、所在フォルダを開く（プロジェクト / ソースファイル / 出力 / アプリデータ）。
- **表示**：キャンバス、パネル、ワークスペースのレイアウト制御。
- **モデル**：モデル全体に作用する操作（PSD の再解析、CMO3 での置き換え、モデル全体の独立メッシュの確認、テクスチャ高解像度化、生成結果の更新）。
- **ヘルプ**：ヘルプページとオンラインリソース（GitHub、ドキュメント、サンプルリポジトリ、リリース、不具合の報告）を開きます。
- **右側のツール**：サイドバーのスイッチ、言語、明暗テーマ、**設定**（歯車）。

### ヘルプ（`F1`）
もう一度 `F1` を押すと、ワークスペースへ戻ります。目次には **マニュアル**、**チュートリアル**、サンプル、コミュニティリンク、サードパーティのライセンス、概要があります。
- マニュアルとチュートリアルは Cubism Editor の構成に沿い、色付きラベルが **同じ** / **操作が異なる** / **独自** / **未実装**（灰色で開けない）を示します。
- マニュアル末尾の「MCP とツール」は、対応する MCP 操作とフィールドを列挙します（実行中のサービスから読みます）。
- レイヤー仕様は **マニュアル → 素材の分割/PSD 制作 → PSD 作成時の注意**、ショートカットは **マニュアル → 編集について → ショートカット一覧** にあります。

### 設定（`Ctrl+,`）
スケールと表示、テーマ、言語、表示、グラフィックス、ヒント、ショートカット、ファイルとデータ、MCP を含みます。ほとんどの変更はすぐに反映されます（MCP は **適用して再起動** が必要です）。
- **表示**：ウィンドウ / 最大化 / 全画面（`F11`）に対応します。
- **グラフィックスと性能**：画質プリセット（低 / 中 / 高 / 最高）、レンダリング経路（GPU / GPU ウィンドウにソフトウェアキャンバス / すべてソフトウェア）、グラフィックスカードの選択、垂直同期、アンチエイリアス、テクスチャフィルタ、性能オーバーレイ。キャンバスの表示が異常なときは、まず「GPU ウィンドウ、ソフトウェアキャンバス」を試します。
- **ファイルとデータ**：超解像キャッシュ、エラーログ、異常終了の一時ファイルの残り、最近使ったファイルの一覧を見て、片付けられます。

## 4. ワークスペースとテクスチャワークスペース

上部タブバー右側の **+** をクリックすると、新しいワークスペースを作れます。8 種のプリセットと、空のレイアウトがあります。

![新規ワークスペースのメニュー](../../imgs/workspace-presets.webp)

| プリセット | 用途 |
| --- | --- |
| 編集 | 編集キャンバス 1 枚で、デフォーマ、キーフォーム、ボーンを扱い、プロパティパネルがそろっています |
| メッシュ | 階層ツリー、編集キャンバス、メッシュパネル。メッシュトポロジに集中します |
| リギング | 編集キャンバスとライブプレビューを並べ、パラメータパネルを常時表示します |
| アニメーション | モーション一覧、プレビューキャンバス、アニメーションエディター |
| プレビュー | 大きなプレビュー。モーション一覧だけを残します |
| 物理演算 | プレビューキャンバスにパラメータと物理パネルを加え、モデルを動かしながら調整します |
| テクスチャ | テクスチャアトラスのページ、編集キャンバス、テクスチャパネル。タイル配置とテクスチャ密度を管理します |
| 履歴 | 履歴ツリーと操作一覧だけを残し、分岐の閲覧と切り替えに使います |
| 空白 | 空のドック領域。**ウィンドウ** メニューから自分でパネルを追加します |

### テクスチャワークスペースの要点
各レイヤーには 3 つのサイズがあります。**キャンバス矩形**（キャンバス単位）、**自身のラスターピクセル**、**テクスチャアトラスのタイルピクセル**。

- **テクスチャアトラスビュー（左）**：
  - ズーム / パンは編集キャンバスと同じです（ホイールでズーム、中ボタンまたは `Space` + ドラッグでパン、`F` でフォーカス、`Home`/`0` でフィット、`Ctrl+A` で全選択）。
  - タイルのドラッグ、角での密度スケール、外側ハンドルでの回転は、いずれも**調整セッション**に入ります（プレビューするだけで、モデルは再構築しません）。上部のセッションバーで元に戻す / やり直す / 破棄ができ、**適用**（または `Enter`）で、1 つの履歴ノードとしてまとめて確定します。
  - タイルが他のタイルのメッシュと重なる、またはページをはみ出すときは、赤く表示され、適用できません。
  - 左上のフローティングバーには **配置**（メッシュ形状 / 矩形、すべて / 選択）、**自動配置**（MaxRects）のスイッチ、ページ番号があります。右上で予算を設定します（ページサイズ 1024–16384、ページ数、間隔）。右下で **密度ヒートマップ** をオンにできます（青 < 1、緑 ≈ 1、橙 > 1）。
- **テクスチャパネル（右）**：
  - 「キャンバス → 元画像 → テクスチャアトラス」の 3 マスのサイズと、実際の密度を表示します。
  - **テクスチャ密度**（`1/64`–`16`）、**サイズをロック**、**回転**、**画像を置き換え…**（メッシュを再構築するかを選べます）、**テクスチャ高解像度化…** を調整できます。
- **元ピクセルのプレビュー**：編集キャンバス右下の表示バーで **元ピクセル** をオンにすると、そのキャンバスはレイヤーの元のラスターを直接サンプリングし、パック後の鮮明さと比較しやすくなります（書き出しとプレビューキャンバスは、常にテクスチャアトラスのピクセルを使います）。
- Agent 側の同名操作は [MCP の使い方とインターフェース](../agent/MCP_AUTHORING.md#テクスチャとテクスチャアトラス) を参照してください。

## 5. 対話型チュートリアルの目次（20 テーマ）

入門コースは次の 19 課です。Cubism の経験があるコースは、先に用語対照を読み、入門の一部を飛ばします。

| 課 | テーマ | 操作の要点 |
| --- | --- | --- |
| 1 | 基本の流れ | レイヤー分けした PSD を読み込み、プレビューとプリセットを確認してから書き出す |
| 2 | ワークスペースの案内 | 編集 / プレビュー / 履歴ページの連携。各キャンバスは視点とスイッチを別々に保存する |
| 3 | 階層ツリーとモードバー | 選択、検索、親の変更。透明な画像をドロップしてレイヤーにする |
| 4 | 差分 | 差分なし / スイッチ差分（1 つのパラメータで有無を制御）/ 切り替え差分（複数から 1 つ） |
| 5 | 素材と配置 | 素材を読み込んで配置し、タグで部位を示してから生成する（[素材と Layout](LAYOUT.md) を参照） |
| 6 | パラメータとキーフォーム | スライダーまたは XY コントロールをドラッグし、右クリックで吸着を印す。先にパラメータ値を決めてからキーフォームを編集する |
| 7 | オブジェクトモード | 矩形選択、なげなわ、ツリーとキャンバスの連動で位置を特定する。ジオメトリは変えない |
| 8 | デフォーマの作成 | 対象を選ぶ → 親 / 子のデフォーマを追加 → 配置をプレビュー → 確定 |
| 9 | 変形モード | 制御点、全体変換、ブラシを調整する。メッシュデフォーマは `1`/`2` で頂点 / ベジェを切り替える |
| 10 | 編集モード | メッシュトポロジを変更する（細分化、接続、点の配置、削除）。終わったらポーズを見直す |
| 11 | 描画モード | ブラシ、消しゴム、塗りつぶしなどでピクセルを直す。セッション内で独立して元に戻し、適用または破棄する |
| 12 | インスペクター | 名前、所属、マスク、描画順、不透明度、色を変更する |
| 13 | ツールオプション | 左下のオプションバーで半径、硬さ、強度を調整する。「ツール詳細」に詳細設定がある |
| 14 | ボーンのリグと編集 | ボーンの新規作成 / ミラー、ArtMesh のバインド、FK/IK でのポーズ、ウェイトのブラシとベイク書き出し |
| 15 | アニメーションとモーションエディター | 生成されたモーションを調整する。タイムラインでパラメータトラック、キーフレーム、ベジェのイーズを編集する |
| 16 | 物理キャンバスのデバッグ | 入力、振り子、出力を設定し、実測の最大値で倍率を較正する |
| 17 | 布と髪のシミュレーション | シミュレーションを生成し、固定点 / 剛性などのウェイトを描き、パラメータと振り子へベイクして書き出す |
| 18 | プロジェクトと履歴 | `.psd2live` を保存し、履歴ツリーで分岐を検索 / チェックアウトする。**生成結果を更新** で新しいバージョンをマージする |
| 19 | テクスチャ高解像度化 | ローカルバックエンドを設定し、2× / 4× を選んで、縁と書き出し結果を確認する |

## 6. 混同しやすい概念

- **保存と書き出し**：保存（`.psd2live`）はプロジェクトと分岐履歴を残します。書き出しは、対象ソフトウェアが使うモデルを生成します。`.psd2live.json` は診断レポートにすぎません。CMO3 を書き出すとき、モーションは同名の `.can3` として別に保存され、同じディレクトリの同じ回の書き出しとして開く必要があります。
- **キーフォームとキーフレーム**：キーフォームはパラメータモデリングに属し、パラメータのキーの間で変形を補間します。キーフレームはアニメーションのタイムライン上にあり、ある時刻のパラメータ値を記録します。
- **変形と編集**：変形は形状を変えます。編集はメッシュのトポロジを変えます。描画はピクセルを変え、独立したセッションを通ります。
- **表示の切り替えと差分**：ツリー内の一時的な単独表示 / 静的な表示切り替えは、編集中の確認用です。パラメータに追従させるときは、差分か不透明度のキーフォームを使います。
- **前後分割**：たとえば衿が首を貫くときは、衿を右クリックして **前後分割…** を選びます（詳細は [前後分割の図解チュートリアル](DEPTH_SPLIT.md)）。髪と衣装のシミュレーション手順は [シミュレーション図解チュートリアル](SIMULATION_TUTORIAL.md) を参照してください。

## 7. 生成結果と古いプロジェクトのアップグレード

- **リグモジュール**：新しいプロジェクトは部位（目、眉、口、頭、髪、体、衣装、表情、モーション）ごとに生成されます。各部位は、基礎アルゴリズムと、個別にオンオフできるモジュールで構成されます。**モデルプリセット › 部位とモジュール** で、簡略 / 標準 / フル、またはパラメータ予算により一括で調整できます。スタイル化した顔パーツは、キャンバス上の **特徴点** ツール（`Shift+Y`）で直せます（[キャンバス編集](CANVAS_EDITOR.md#特徴点) を参照）。
- **古いプロジェクトの分割記録**：旧版の分割結果は、最初の編集のときに普通のメッシュとして固定され、既存の変更は残ります。新しい分割は、元のレイヤーの位置で直接生成に参加し、顔やスケルトンを変更したときにパーツを同期して更新できます。
- **生成結果の更新**：**モデル → 生成結果を更新** で、未変更の部分を新しいジェネレーターの結果へ上げ、三方マージで手作業の編集を残します。**モデル → 生成結果の更新をプレビュー** は、プロジェクトを変えずに、変更項目数を先にプレビューできます。

## 8. よく使うショートカット（既定は Photoshop スタイル）

**設定** で Blender / Cubism のプリセットへ切り替えるか、自分で割り当てられます（修飾キー + ホイール、およびマウスのサイドボタンに対応します）。

| 操作 | 既定のキー |
| --- | --- |
| プロジェクトを開く / PSD を読み込む | `Ctrl+O` / `Ctrl+Shift+O` |
| 保存 / 別名で保存 | `Ctrl+S` / `Ctrl+Shift+S` |
| 元に戻す / やり直す | `Ctrl+Z` / `Ctrl+Shift+Z` または `Ctrl+Y` |
| モデルを書き出す / PSD を書き出す | `Ctrl+G` / `Ctrl+Shift+E` |
| PSD を再解析 / テクスチャ高解像度化 | `Ctrl+R` / `Ctrl+U` |
| ヘルプ / 設定 / 全画面 | `F1` / `Ctrl+,` / `F11` |
| キャンバスのズーム / パン | ホイール / 中ボタン（または `Space` + 左ボタン）のドラッグ |
| ドラッグでキャンバスをズーム | `Ctrl+MouseMiddle` を上下にドラッグ |
| ブラシの大きさ・硬さ / 不透明度・角度を調整 | `Alt+MouseRight` / `Shift+Alt+MouseRight` のドラッグ |
| ブラシを回転 | `Alt+WheelUp` / `Alt+WheelDown`（`Shift` を足すと 45° ステップ） |
| 選択に合わせる / 視点をリセット | `F` / `Home` または `0` |
| ブラシの大きさ / 硬さ / 不透明度 | `[` `]` / `Shift+[` `Shift+]` / `Alt+Shift+[` `Alt+Shift+]` |
| モードまたはツールの 1–5 番目 | `1`–`5` |
| 描画：選択範囲 / グラデーション / ぼかし / 自由変形 | `Alt+L` / `Alt+G` / `Alt+J` / `Alt+T`（描画モードでは `T` で自由変形） |
| 描画：全選択 / 解除 / 反転 / 塗りつぶし / 消去 | `Ctrl+A` / `Ctrl+D` / `Ctrl+I` / `Alt+Backspace` / `Del` |
| 描画：入れ替え・既定色 / 透明を保護 / 直線 | `X` / `Alt+D` · `/` · `Shift` + クリック |
| 一時選択 / クイックプレビュー | `Z` を押したまま / バッククォート `` ` `` |
| オブジェクトモード / 前回のモードの切り替え | `Tab` |
| 現在の操作を確定 / キャンセル | `Enter` / `Esc` |
| タイムライン：再生 / キーフレーム / コマ送り | `Space` / `K` / `Left` `Right` |

## 9. 確認と切り分け

| 現象 | 先に確認すること |
| --- | --- |
| パーツの動きが違う、または動きがない | [PSD レイヤー仕様](../spec/PSD_LAYER_SPEC.md) と、「レイヤー」表の種類、左右、マスク、親 |
| 静止ポーズは正常だが、動くと破綻する | アニメーションまたは物理パネルで、動きの軌跡全体を再生する |
| パネルが見当たらない | **ウィンドウ** メニューのパネルスイッチ、または **レイアウトをリセット** |
| キャンバスにモデルが見えない | 先にキャンバスを合わせ（`F` / `Home`）、レイヤーの表示を確認する |
| 書き出しに失敗する、またはダウングレードと出る | ログパネル、書き出しレポート `.psd2live.json`、書き出し先のバージョン |
