# 操作早見表

[文書一覧](../../README.md) · [中文](../../zh/guide/USER_GUIDE.md) · [English](../../en/guide/USER_GUIDE.md)

まず **ヘルプ → チュートリアル** を開いてください。操作箇所と現在のキー設定が画面に表示されます。この文書は同じ全 14 講座の復習用メモです。

## 基本の流れ

PSD をインポート（`Ctrl+Shift+O`）→ 分類とプレビューを確認 → 編集 → 保存（`Ctrl+S`）→ 書き出し（`Ctrl+G`）。既存の `.psd2live` は `Ctrl+O` で開きます。

## 講座一覧

| 講座 | テーマ | 要点 |
| --- | --- | --- |
| 1 | 基本操作 | 分層 PSD を読み込み、パーツと設定を確認して書き出す。 |
| 2 | ワークスペース | 編集・プレビュー・履歴を使い分ける。各キャンバスタブは独立した視点と表示設定を持つ。 |
| 3 | 階層とモード | 検索、選択、親の変更。透過画像をツリーへ入れて配置を確定する。描画順と変形の親子関係は別。 |
| 4 | レイヤー種別と差分 | プリセット、表示オン・オフ、共通パラメータと異なる ID による択一差分。 |
| 5 | パラメータとキー | スライダーや XY を操作し、キーマーカーを右クリックして吸着。形を変える前に値を決める。 |
| 6 | 選択 | キャンバスとツリーで対象を選ぶ。選択だけでは形状は変わらない。 |
| 7 | デフォーマ作成 | 対象選択 → ツリーの右クリック → 配置を調整 → 確定。 |
| 8 | 変形 | 現在のパラメータ姿勢で点やブラシを操作。L1 / L2 の階層を確認する。 |
| 9 | 編集 | メッシュの細分化・接続・切断・削除後、既存の姿勢を確認する。 |
| 10 | 描画 | レイヤーを選び画素を編集。セッション内で元に戻せる。最後に適用か破棄。 |
| 11 | インスペクター | 選択対象の名前、所属、マスク、描画順、不透明度や色を調整する。 |
| 12 | ツール詳細 | 使用中のツールの半径・硬さ等を設定。右クリックメニューも文脈に応じて変わる。 |
| 13 | 工程と履歴 | 保存、過去ノードへの復元、そこからの分岐。分岐の非表示は削除ではない。 |
| 14 | 高解像度化 | ローカル環境を設定して 2× / 4× を選び、輪郭・半透明部・出力を確認する。 |

## 間違えやすい点

- 保存は素材・編集・履歴の保持、書き出しはモデルの受け渡しです。`.psd2live.json` は診断レポートです。
- 変形は形状、編集はメッシュ構造、描画は画素を変えます。描画には独立した適用・破棄の操作があります。
- 一時的な単独表示や静的な非表示と、パラメータで駆動する差分は別です。

## 初期ショートカット

| 操作 | キー |
| --- | --- |
| 工程を開く / PSD をインポート | `Ctrl+O` / `Ctrl+Shift+O` |
| 保存 / 別名保存 | `Ctrl+S` / `Ctrl+Shift+S` |
| 元に戻す / やり直し | `Ctrl+Z` / `Ctrl+Y` または `Ctrl+Shift+Z` |
| モデル出力 / PSD 再出力 | `Ctrl+G` / `Ctrl+Shift+E` |
| 拡大縮小 / 移動 | ホイール / 中ボタンドラッグまたは Space + 左ドラッグ |
| 全体表示 | `F` / `Home` / `0` |

キー設定は変更可能です。`F1` で現在の一覧を確認し、確定・取消は使用中のツールの表示に従ってください。

## 確認と関連資料

結果がおかしい場合は[素材命名](../spec/PSD_LAYER_SPEC.md)、左右、マスク、親を確認します。動きはアニメーション・物理パネルで確認してください。パネルが見えない場合はレイアウト、モデルが見えない場合は全体表示と可視設定を確認します。出力失敗時はログとレポートを確認してください。
