# 素材と Layout

[ドキュメント目次](../README.md) · [利用ガイド](USER_GUIDE.md) · [キャンバス編集](CANVAS_EDITOR.md) · [Layout マニフェスト](../spec/LAYOUT_MANIFEST.md)

Layout では、先にプロジェクト内へパーツを配置してからリグを生成します。生成後も画像の追加やタグの変更を続け、再生成できます。すでに行った編集は残ります。

## 開始

- **空のキャンバスから始める**：スタートページで「レイヤー読み込み」を選びます（「ファイル > 新規作成 > 新規レイヤー読み込みプロジェクト」でもここに来ます）。よく使うサイズを選ぶか、プロパティパネルで幅と高さを入力し、「レイヤー読み込みプロジェクトを作成」をクリックするか、サイズをダブルクリックします。新しいプロジェクトにはまだリグがなく、自動で Layout ワークスペースに切り替わります。
- **PSD から始める**：通常どおり PSD を読み込みます。プロジェクトはすぐにリグを生成し、同時に PSD の各レイヤーが素材パネルに現れ、キャンバス上のレイヤーと関連付きます。
- **Layout マニフェストから始める**：外部ツール（たとえば AI によるパーツ分割）が書き出した [Layout マニフェスト](../spec/LAYOUT_MANIFEST.md)——1 つの JSON、またはルートにそれを置いた zip——を、PSD を開くのと同じ方法で開くか、ウィンドウへ直接ドロップします。レイヤーはマニフェストどおりに配置されます。位置、上下の順、グループ、タグ、差分はすでに設定され、小さいパーツはキャンバスより多くのピクセルを保ちます。プロジェクトにはまだリグがなく、自動で Layout ワークスペースに切り替わります。
- どのワークスペースからでも、ウィンドウメニューで「素材」パネルを開けます。

Layout ワークスペースは、左が素材パネル、中央が編集キャンバス（オブジェクトモード）、右が階層ツリーとレイヤー表です。

## 素材パネル

- **読み込み**：「読み込み」でファイルを選び、「フォルダを読み込み」でフォルダ全体を選ぶか、ファイルやフォルダをパネルへ直接ドロップします（フォルダ、またはパスバーの一段の上へドロップすると、そこへ読み込みます）。フォルダは元の入れ子のまま読み込まれ、各段のサブフォルダが素材フォルダになります。ファイルは名前の中の数字の順に並びます（arm2 は arm10 より前）。隠しファイルと隠しフォルダ（.git など）、および非対応のファイルはスキップします。対応形式は PNG、BMP、TIFF、WebP（非可逆を含む）、JPEG、PSD、CMO3 内の各 ArtMesh の画像、SVG です。PSD は 1 つのフォルダになり、レイヤーグループはサブフォルダになり、各レイヤーは PSD 内での位置を覚えています。
- **閲覧**：左側は簡略な素材ツリーです（フォルダとその中の画像。既定ではすべて展開。ツールバーのツリーボタンで折りたためます。ツリー内の画像も、キャンバスへドラッグしたり、ダブルクリックで開いたりできます）。右側は現在のフォルダの内容で、フォルダが先、素材が後です。グリッドとリストを切り替えられます。2 つの欄の間の区切りはドラッグして幅を調整できます。グリッドのサムネイルサイズは、右下のスライダーで調整します（周囲の透明が多い素材は、内容のある部分だけを表示します）。フォルダをダブルクリックして入り、ツリー、上のパスバーの ↑、または任意の段で戻ります。検索はすべてのフォルダを対象にします。項目の右上の数字は、それを使っているレイヤー数です。
- **出所**：PSD または CMO3 から読み込んだフォルダは、「PSD」/「CMO3」の色帯が付いたファイルアイコンで表示され、そのうしろにページが重なります。右下は中の項目数と矢印で、ダブルクリックで開けることを示します。ホバーすると、元ファイル名が見えます。
- **整理**：素材またはフォルダを別のフォルダへドラッグします（グリッド、ツリー、パスバーの任意の段）。それで移動できます。右クリックメニューはクリック位置から開き、キャンバスの右クリックメニューと同じです。ツリーの最上位とフォルダのメニューでは、ここにフォルダを新規作成したり、ファイルやフォルダを読み込んだりできます。グリッドまたはリストの空白を右クリックすると、現在のフォルダで新規作成または読み込みができ、グリッド、リスト、フォルダツリーを切り替えられます。ツリーの空白を右クリックすると、素材ライブラリの最上位で新規作成または読み込みができます。項目メニューでは、名前の変更、タグの編集、1 つ上へ移動、削除ができます。タグはカンマ区切りで、空にすると消去します。フォルダのタグは検索に使え、配置した素材が継承します。レイヤーまたは参照画像が使っている素材は削除できず、そのような素材を含むフォルダも削除できません。メニューには参照数が表示されます。削除項目は警告色になり、プロジェクトが処理中のときは変更操作を使えません。
- **既定の参照レイヤー**：素材またはフォルダを右クリックして「既定で参照レイヤーとして配置」を選ぶと、その素材をキャンバスへドラッグしたときの既定の種類が切り替わります。フォルダは、すべてのサブディレクトリ内の素材に作用します。メニューの「キャンバスへ配置」は、モデルレイヤーとして明示的に配置します。「参照として追加 > レイヤー内」は、参照レイヤーとして明示的に配置します。
- **素材はレイヤーの唯一の出所**：各レイヤーには対応する素材が表示されます。PSD、CMO3、画像の読み込み、レイヤーの分割、メッシュの描画のときは、自動で登録されます。自分だけが使っている素材は、レイヤーの変更に従います。複数のレイヤーが 1 つの素材を共有しているとき、そのうちの 1 つを描くことは素材を描くことであり、残りのレイヤーも同期します。1 つだけを別々に直すには、右クリックして「独立した素材にする」を選びます。古いプロジェクトで、まだ素材のないレイヤーがあるときは、パネル上部に「素材ライブラリへ登録」と出ます。
- **SVG**：右クリックして「テクスチャ解像度…」を選び、`512x256` のように入力します。解像度はテクスチャアトラスへ入るピクセルを決め、キャンバス上の大きさは変わりません。すでに配置したレイヤーも、一緒に更新されます。
- **PSD の書き出し**：フォルダを右クリックして「フォルダを PSD として書き出し…」を選びます。

## 素材ウィンドウ

素材をダブルクリックする（または右クリックして「素材ウィンドウで開く」）と、独立したウィンドウが開きます。大きさは自由に変えられ、別の画面へ移動できます。ウィンドウが開いているとき、パネルで別の素材をクリックすると、ウィンドウもそれに切り替わります。

- **表示**：ホイールでズームし、マウスの中ボタン、またはスペースを押したままドラッグしてパンします。右下で市松 / 白地 / 黒地を切り替えられます。「ウィンドウに合わせる」（F）と 1:1（Home）もあります。2 倍以上に拡大すると、ピクセル単位で表示します。
- **描画**：ウィンドウの中は、キャンバスの描画モードそのものです。左のツールバー、下のオプションバー、上の描画セッションバー（元に戻す、やり直す、破棄、適用）、右クリックメニュー、ペン先とスポイトの表示、すべてのショートカットが描画モードと同じで、描く対象が素材自身のピクセルになるだけです。色や各ツールの大きさなどの設定は、現在のキャンバスから引き継がれ、ウィンドウを閉じると戻します。
- **適用**：描画モードと同じく、ストロークはまずセッションに残り、「適用」（Enter）で 1 ステップの履歴として素材へ書き込まれ、「破棄」で捨てられます。別の素材へ切り替えるとき、またはウィンドウを閉じるときは、自動で適用されます。描画中も、メインウィンドウでは他の内容を通常どおり編集できます。
- **調整**：左上の「調整」メニューで、水平または垂直に反転し、色相、彩度、明度、コントラストを調整できます。スライダーをドラッグしている間はプレビューし、「適用」で書き込みます。未適用のストロークがあるときは、先に適用するか破棄します。

この素材をすでに配置しているレイヤーは、すべて一緒に更新されます。キャンバス上の位置と大きさは変わりません。SVG 素材は、描画または調整のあと、現在の解像度のビットマップになります。

## 素材とレイヤーの関連

素材から配置したレイヤー（および PSD 読み込み時のレイヤー）は、素材と関連しています。レイヤーに表示されるのは素材のピクセルであり、素材が唯一の出所です。

- 描画モードでこのようなレイヤーを描くことは、素材そのものを描くことです。この素材を使うすべてのレイヤーが一緒に変わります。セッションバーには「素材「…」を描画 · N 個のレイヤーが共有」と出ます。キャンバス全体に描けます。適用時、レイヤーのメッシュ上に落ちた部分は素材へ書き込まれ、メッシュの外の部分は新しいレイヤーに分割され、そのすぐ上に置かれ、新しい素材として元の素材の横に置かれます。
- レイヤー表では、関連するレイヤー名のうしろに鎖の印が付き、ホバーすると素材名と共有レイヤー数が見えます。開くと「素材ウィンドウで開く」または「関連を解除」ができます。
- 関連を解除すると、レイヤーのピクセルはそのレイヤー自身のものになり、その後の描画は素材や他のレイヤーに影響しません。レイヤーのピクセルを素材と違える他の編集（分割、別の画像での置き換えなど）も、自動で関連を解除します。
- 別の素材で「選択中レイヤーの画像を置き換え」を行うと、レイヤーはその素材に関連付くように変わります。

素材はプロジェクトとともに保存され、すべての変更は元に戻せます。

## 配置

- 素材またはフォルダ全体を**キャンバスへドラッグ**し、離した位置に配置します。右クリックの「キャンバスへ配置」でも同じです。フォルダ内の素材は相対位置を保ち、サブフォルダはソース画像のグループになります。
- **ファイルと素材のドロップ**：コンピューターからドロップしたファイルと、素材パネルからドラッグした素材は、同じ着地点を使います。離した位置が処理を決め、マウスの横の案内が先に内容を示します。素材パネルへドラッグすると素材として読み込みます（フォルダの上で離すと、そこへ読み込みます）。画像を階層ツリーへドラッグし、デフォーマの上で離すとその下へ入れ、メッシュの上半分または下半分で離すとその前または後ろへ挿入します。編集キャンバスへドラッグすると、キャンバスの下に大きな選択肢が出ます。背景 / レイヤー内 / 前景の 3 種の参照（それぞれモデルに入るかどうかが書いてあります）、選択中レイヤーの画像の置き換え、素材ライブラリへの読み込みのみ（ファイルだけ）です。キャンバスのそれ以外の場所で離すと、そこにレイヤーとして配置します。プロジェクト、PSD、CMO3、Layout マニフェストを他の場所へドラッグすると開きます。受け付けない位置では落ちず、エラーにもなりません。
- PSD 由来の素材は、既定では PSD 内の位置へ戻します。PSD のキャンバス全体をプロジェクトのキャンバスの中央に置き、プロジェクトのキャンバスより大きいときは縦横比を保って縮小します。両方のサイズが同じなら、元の位置です。その他の素材は「素材 1 ピクセル = キャンバス 1 単位」でキャンバス中央に置き、キャンバスをはみ出すときは自動で縮小します。
- キャンバス単位はモデルの座標です。Cubism へ書き出したあとはモデルキャンバスのピクセルになり、モデルの大きさと比率を決めます。鮮明さは決めません。鮮明さは素材自身のピクセルから来ます。配置や拡大縮小では再サンプリングせず、レイヤーを小さく置くほどテクスチャは密になります。書き出し時、テクスチャはテクスチャアトラスの予算（テクスチャワークスペースのページサイズとページ数）に入れる必要があり、入りきらないときはタイルがそろって縮小します。
- オブジェクトモードでは、変換枠でレイヤーを**移動、拡大縮小、ミラー**します。ピクセルは再サンプリングされません。600×600 の目を 64×64 のキャンバス範囲へ縮めても、テクスチャアトラスには 600×600 の密度のまま保存されます（テクスチャアトラスの予算の制限は受けます）。
- **上下の順**：新しく配置したレイヤーは一番上になります。フォルダ全体を配置するときは、フォルダ内の元の上下順を保ちます。レイヤーを選択したあと、レイヤー表ツールバーの「1 つ上へ」「1 つ下へ」、またはキャンバス上で Ctrl+] / Ctrl+[ により 1 つ上、1 つ下へ、Ctrl+Shift+] / Ctrl+Shift+[ により最前面、最背面へ移動します。レイヤー表は後ろから前へレイヤーを列挙し、下にあるほど前です。Cubism の描画順と同じです。まだ生成していないレイヤーは、すべて調整できます。生成後は、生成済みレイヤーの前後を描画順で調整します。新しく配置したレイヤーは、再生成の前までは調整でき、生成前は一時的に一番前に表示されます。
- **参照**：原画、設定画、ラフなどの対照図は、階層ツリーの一種のメンバーです（参照アイコン）。複数置けます。各参照は 3 か所のいずれかで表示され、表示方法がモデルに入るかどうかを決めます。**背景**（モデルには入らず、エディター内でモデル全体の下に敷くだけ）、**レイヤー内**（モデルに入る。モデル内の 4 点の矩形 ArtMesh であり、追加時にピクセル輪郭の追跡や完全なメッシュ生成は行わず、描画順に従ってレイヤーの間に置き、デフォーマの下へ付けて変形に追従でき、書き出し時は参照画像パーツに属し、書き出しウィンドウで「ガイドレイヤーを書き出す」をオンにしたときだけ書き出されます）、**前景**（モデルには入らず、エディター内でモデル全体の上に被せるだけ）。レイヤー内の参照は、キャンバスに入った時点で編集できる矩形 ArtMesh になり、先にリグを生成する必要はありません。追加方法：画像または素材を編集キャンバスへドラッグし、キャンバス下の大きな選択肢から表示方法を選ぶ。または階層ツールバー、キャンバス右下の表示バーの参照画像ボタン（前景に追加）、または素材の右クリック「参照として追加」。階層ツリーで背景または前景の参照を選ぶと、編集キャンバスにハンドルが出ます。内側をドラッグして移動し、角をドラッグして縦横比を保って拡大縮小し、上の丸をドラッグして回転します。離したときに初めて履歴が 1 件記録されます。レイヤー内の参照は、他の ArtMesh と同じく変換枠で調整します。参照を右クリックすると、「表示方法」で 3 か所を切り替えられます（各項目にモデルへ入るかどうかが示され、素材、位置、表示、固定は残ります）。表示 / 非表示、不透明度とロック（背景、前景）、モデルレイヤーへ戻す（レイヤー内）、削除もあります。Alt+R は、現在のキャンバスで背景と前景の参照を表示するかを切り替えます。
- **レイヤーを参照にする**：まだ生成に参加していないレイヤー（生成前の任意のレイヤー、その後に新しく置いたレイヤー）と、読み込んだ画像は、レイヤー表ツールバーの「参照にする」、または Ctrl+Alt+R で、レイヤー内の参照にできます。キャンバスの右クリックメニューにも「参照にする」のスイッチがあります。参照レイヤーの名前のうしろには参照アイコンがあり、それをクリックするとモデルレイヤーに戻ります。すでにモデルに入っているものは、メッシュを普通のレイヤーとして残します。Layout マニフェストで `reference` と印の付いたレイヤーは、開いた時点でレイヤー内の参照です。生成済みのレイヤーは、参照にできません。
- **キーフォームへ固定**：角度の違う参照（正面、側面、あおり……）を同じ位置に重ね、それぞれ対応するキーフォームのときだけ表示できます。1 つの参照を複数のキーフォームに出すこともでき、3 つの表示方法のどれでもできます。参照を右クリックすると、メニュー下部の「キーフォームへ固定」が、パラメータパネルと同じ形で、モデル内にキーフォームのあるパラメータを列挙します。1 次元のパラメータはキーフォームの点付きスライダー、対になるパラメータは 2D pad です。キーフォームの点をクリックすると、そこに点が付きます（塗りつぶし）。もう一度クリックすると解除します。参照は、いずれかの点で表示されます（各パラメータと点の差が、パラメータ範囲の 0.5% 以内）。それ以外のポーズでは隠れます。灰色の印は現在のポーズです。「固定を解除」は、すべての点を消します。キャンバス右クリックメニューの同名のサブメニューは、同じパネルです。固定はエディター内でいつ表示するかを決めるだけで、書き出しには入りません。
- **画像の置き換え**：先にレイヤーを選択し、素材を右クリックして「選択中レイヤーの画像を置き換え」を選びます。レイヤーのキャンバス上の位置と大きさは変わらず、ピクセルとテクスチャアトラスのタイルだけが変わります。テクスチャアトラスビューでの右クリック置き換えも同じです。

## タグ

レイヤー表の各レイヤーには **タグ** の欄があり、開くと編集できます。

- 部位と左右の語は、ジェネレーターにそれが何であるかを伝えます。たとえば「髪 + 前」は前髪、「目 + 瞳 + 左」は左目の瞳、「口 + 開き」は開いた口です。メニューの下で、部位と左右を直接選べます。
- 入力欄には語彙表の語を入力でき、よくあるレイヤー名（「前髪」、「eye-l」など）も入力できます。対応する語へ換算されます。それ以外の文字は自分用のタグになり、整理と検索だけに使い、生成には影響しません。
- パーツの役割語は、レイヤーが部位の中で何であるかを示します。`highlight`（ハイライト）、`pupil`（瞳）、`lower`（下まつ毛）、`lid`（二重の線）、`shadow`（影）、`blush`（頬紅）、`side`（横髪）、`ahoge`（アホ毛）、`ponytail`（ポニーテール）、`braid`（三つ編み）、`animal`（獣耳）、`ribbon`（リボン）、`pendant`（ペンダント、房）、`rigid`（ボタンやバッジなどの硬い飾り）、`sleeve`（袖）、`skirt`（スカート）、およびレイヤー分けした口の `upperlip`、`lowerlip`（周囲の皮膚を含む上唇、下唇）、`upperline`、`lowerline`（上のリップライン、下のリップライン）です。生成時は、レイヤー名、所属フォルダ、レイヤー間の位置から自動で判断し、タグに表示します。判断が違うときは書き換えられ、自動判断された役割を 1 つ削除すると、それ以降は自動判断しません。役割は「部位とモジュール」の中のモジュールにだけ影響し、元の生成方法は変えません。
- スイッチ差分と切り替え差分はタグの中にはなく、隣の「差分」欄で設定します。
- 素材または素材フォルダにタグを付けると、そこから配置したレイヤーは、それらのタグを自動で持ちます。

## 生成と再生成

編集キャンバス右上の生成バーは、まだ何が待っているかを示します。

- **未生成**：新しく作った Layout プロジェクトです。レイヤーがキャンバスに入った時点で正式なメッシュを持ち、メッシュ、デフォーマ、パラメータ、階層を編集でき、書き出しもできます。空のキャンバスも同様に編集できます。配置が終わったら「生成」をクリックし、タグに従って自動リグを生成します。
- **生成待ち N**：生成後に配置したレイヤー、タグまたは分類を変えたレイヤーです。新しく配置したレイヤーは、すぐに通常のワークスペースのすべての編集と書き出しに対応し、次の生成で自動リグへ加わります。変えた分類は、次の生成までリグに影響しません（レイヤー表では強調色の縁で示します）。
- 「再生成」をクリックすると、これらの内容がリグへ取り込まれます。自分が行ったキーフォーム、デフォーマ、物理演算、スイング、スケルトン、Glue は残ります。きれいに移行できない内容は、品質チェックに列挙されます。
- 画像を置き換えたレイヤーは、既定では新しいピクセルに合わせてメッシュを再生成します。元のメッシュを残したいときは、生成ボタンのドロップダウンで「生成するが、置き換えた画像のジオメトリは残す」を選びます。

1 回の生成にかかる時間は、同じ大きさの PSD を読み込むときと同程度です。
