# 前後分割の図解チュートリアル

[ドキュメント目次](../README.md) · [操作早見表](USER_GUIDE.md) · [キャンバス編集](CANVAS_EDITOR.md)

1 つのレイヤーの中の別々の部分が、別のパーツの前と後ろにそれぞれ入ることがあります。**前後分割**は、前後 2 枚をすばやく複製し、重なり順を設定し、グルーで一緒に変形させます。新しい前レイヤーで、後ろに隠すべき部分を消せば十分です。

このチュートリアルでは、襟と首の交差で一通りの操作を示し、そのあと髪と肩の装飾で別の使い方を説明します。PSD または画像から生成したモデルに使えます。読み込んだ CMO3 モデルは、現在この機能に対応していません。

## 1. 前後の重なりが必要な部分を見つける

下の図では、衿の後ろ側が首を覆っています。襟全体が同じレイヤーにあるため、そのまま首の前や後ろへ移すと、どちらかの重なりが不正になります。

![処理前：衿の後ろ側が首の前に重なっている](../../imgs/depth-split/collar-before.webp)

*処理前：本来は首の後ろにあるべき衿ぐりが、首の前に出ています。*

後ろの衿ぐりは首の後ろに隠し、前の衿は首の下端を覆ったままにします。

![目標：首が後ろの衿ぐりと前の衿の間にある](../../imgs/depth-split/collar-target.webp)

*目標：首が衿ぐりから見え、前後の重なりが自然になります。*

対応する重なりは次のとおりです。

| 位置 | パーツ | 役割 |
| --- | --- | --- |
| 最前面 | 襟のあるレイヤー · 前 | 後ろの衿ぐりを消し、首の前に出す内容だけを残します |
| 中間 | 首 | 後ろの衿ぐりを隠し、前の衿に隠れます |
| 最後面 | 襟のあるレイヤー · 後 | 元のレイヤー全体を残し、後ろ側の内容を出します |

スクリーンショットの襟は、上衣全体の `topwear` レイヤーに属しているため、実際に分割するのは上衣全体です。先に襟だけを切り離す必要はありません。

## 2. 上衣と首を同時に選択する

編集キャンバスを **オブジェクト** モードにし、襟のある上衣レイヤーを選んでから、**Shift** を押したまま首を追加選択します。階層ツリーでも複数選択できます。

![上衣と首を同時に選択し、キャンバスに 2 つの選択枠が出ている](../../imgs/depth-split/select-layers.webp)

*2 つの選択枠は、上衣と首に対応します。上衣は前後 2 枚に分ける対象、首は間に挟む対象です。*

間に挟む ArtMesh は複数追加できますが、一度に分割できる ArtMesh は 1 つです。残りの選択オブジェクトは、前後のレイヤーの間にまとめて置かれ、互いの描画順は保たれます。

## 3. 上衣を右クリックし、「前後分割」を実行する

複数選択を保ったまま、分割する **上衣** を右クリックし、**「topwear」を前後分割** を選びます。メニューの名前は、レイヤー名に従います。クリックする前に、複製するオブジェクトが表示されているか確認してください。

![右クリックメニューで赤枠に示された「topwear を前後分割」](../../imgs/depth-split/context-menu.webp)

*赤枠の項目は、前後のレイヤーを直接作り、前レイヤーの消しゴムへ入ります。*

作成が終わると、元のレイヤーは「`topwear · 後`」と「`topwear · 前`」の 2 つの新しいレイヤーに置き換わります。どちらも、元のレイヤーの全ピクセルを持っています。プログラムは首との描画順を自動で決め、メッシュと変形データを複製し、前後レイヤーの対応する頂点を接着して、前レイヤーが後レイヤーの動きに従うようにします。元のレイヤーはレイヤー一覧に残りません。分割前に戻すには、元に戻すを使います。

**上衣だけを選んでいた場合：** 階層ツリーで上衣を右クリックし、**前後分割…** を選びます。ダイアログの **間に挟むオブジェクト** で首を選び、前／中間／後の関係を確認してから、**作成して消去** をクリックします。

## 4. 前レイヤーで後ろの衿ぐりを消す

作成後、プログラムは新しい前レイヤーを自動で選び、**描画** モードと **消しゴム** に切り替えます。まず、キャンバス上部が「`topwear · 前`」になっているか確認します。

衿ぐりを拡大し、首の縁に沿って、前レイヤーのうち本来首の後ろにある衿ぐりを消します。下の図の矢印が、消す位置です。

![topwear の前レイヤーで消しゴムを使い、赤い矢印が消すべき後ろの衿ぐりを指している](../../imgs/depth-split/erase-front.webp)

*消しているのは、前レイヤーの中の後ろの衿ぐりです。元の後レイヤーはこれらのピクセルを残すので、消したあとに中間の首が見えます。*

消しゴムの大きさを調整し、まず領域の内側を片付け、小さいブラシで縁を整えます。前の衿と、首の前に置く内容は残します。上衣全体を空にする必要はありません。

消しすぎたときは、描画セッションの **元に戻す** でストロークを戻せます。図の他のパーツは、描画中に暗くなります。これは編集用の表示です。

## 5. 適用を確認し、別のポーズを調べる

消去が終わったら、キャンバス上部またはツールパネルの **適用を確定** をクリックします。前後分割で作った前レイヤーは、元のメッシュと変形を自動で残すため、適用時にメッシュを再生成する必要はありません。

![適用後の襟：首が見え、前の衿は首の前に残っている](../../imgs/depth-split/collar-result.webp)

*完成した重なり：後ろの衿ぐりは首の後ろ、前の衿は首の前です。*

続いてパラメータパネルで、振り向き、上を向く、下を向く、体の回転を確認し、特に衿ぐりの境目に注意します。あるポーズで後ろの衿ぐりがまだ首を覆っている場合は、前レイヤーの描画に戻り、消しゴムで縁を直し、再び適用を確定します。

前後のレイヤーは一緒に変形しますが、どのピクセルを消すかは自分で決めます。最後に `.psd2live` プロジェクトを保存し、分割、テクスチャの変更、履歴を残します。

## 6. 同じ方法で髪と肩の装飾も扱える

下の図の肩の装飾と髪も、一部は前、一部は後ろに置く必要があります。まず、分割が必要な装飾のあるレイヤーと、間に挟む髪のレイヤーを見つけます。

![処理前：髪と肩の装飾の重なりを調整する必要がある](../../imgs/depth-split/shoulder-before.webp)

*どの装飾を髪の前に出し、どれを髪の後ろに隠すかを、先に判断します。*

装飾のあるレイヤーと関係する髪を複数選択し、**装飾のあるレイヤー** を右クリックして前後分割を実行します。そのあと、新しい前レイヤーで、髪に隠すべき装飾の部分を消します。

![肩の装飾の前レイヤーを消している過程](../../imgs/depth-split/shoulder-erase.webp)

*新しい前レイヤーだけで、後ろに隠す部分を削ります。後レイヤーは内容全体を残します。*

適用を確定したあと、髪と装飾の境目を確認し、関係するパラメータを動かして、動きの中の重なりを見ます。

![処理後：髪と肩の装飾が前後に交差しながら重なる](../../imgs/depth-split/shoulder-result.webp)

*完成：同じ装飾レイヤーが、前側と後側の内容を同時に出せます。*

## よくある問題

| 現象 | 対処 |
| --- | --- |
| キャンバス内のクイック分割メニューが見つからない | オブジェクトモードに切り替え、分割するメッシュと、少なくとも 1 つの中間オブジェクトを同時に選択します。階層ツリーの「前後分割…」からダイアログを開くこともできます |
| メニューに出るオブジェクトが違う | 複製するオブジェクトを右クリックします。襟の例では上衣であり、首ではありません |
| 作成した直後は、見た目がまだ変わらない | 新しい前レイヤーは、最初は完全な複製です。隠れるべき部分を、消しゴムで消す必要があります |
| 先に描画を適用するか破棄するよう表示される | まだ確定していない描画セッションを処理してから、前後分割を作成します |
| 正面は正常だが、回転すると交差する | 関係するパラメータの複数のポーズを確認し、前レイヤーに戻って追加で消し、縁を整えます |
