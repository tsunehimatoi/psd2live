# シミュレーション図解チュートリアル：髪と衣装を自然に揺らす

[ドキュメント目次](../README.md) · [シミュレーションとベイク](SIMULATION.md) · [キャンバス編集](CANVAS_EDITOR.md) · [操作早見表](USER_GUIDE.md)

髪、スカートの裾、ゆったりした衣装は、シミュレーションで追従、遅れ、戻りを得られます。このチュートリアルでは、まず前髪の修正前後を比べて調整の目標を説明し、そのあと固定点ウェイトとベイクの操作を示します。

## 問題と修正目標を先に見る

自動生成された固定範囲は、すべての素材に合うとは限りません。この例では、前髪が揺れるときの顔横の毛束の形と位置を調整します。毛根は頭に追従させたまま、その下で自由に動ける範囲を調整し、前髪を望む輪郭に近づけます。

![前髪シミュレーションの修正前後。左側が修正前、右側が修正後](../../imgs/simulation-tutorial/preview-comparison.webp)

*左側は修正前の全体プレビュー、右側は修正後の部分プレビューから取り、切り出して 1 枚の頭部比較図にしています。2 枚のスクリーンショットの元の内容は残してあり、顔横の毛束を見比べられます。動いている揺れは、パラメータの変化かモーションの再生でも確認してください。*

調整の流れは、**固定点を確認する → ウェイトブラシで固定範囲を変える → 参照シミュレーションを見る → ベイクし直す → 書き出し結果を確認する** です。固定点を変えるときは根元のつながりを残し、グラデーションで、頭についていく領域と揺れてよい領域を制御します。

## 操作の前に

**参照シミュレーション**はリアルタイムの調整に使い、**書き出し結果**はベイク後の見た目を確認するために使います。これらの動きを書き出したモデルに載せるには、ベイクを完了する必要があります。先に、メッシュとリグが生成済みのモデルを開き、次の手順で操作します。

## 1. モデルプリセットでシミュレーションをオンにする

**モデルプリセット → 物理演算とシミュレーション** を開きます。前髪と後ろ髪にはそれぞれドロップダウンがあり、動き方を別々に設定できます。

![モデルプリセットの物理演算とシミュレーショングループ、および髪の動き方のドロップダウン](../../imgs/simulation-tutorial/model-presets.webp)

*このスクリーンショットが示しているのはドロップダウンの入り口で、赤枠は「従来のスイング」です。このチュートリアルに沿うときは、その上にある「シミュレーション」を選んでください。*

| オプション | 用途 |
| --- | --- |
| シミュレーション | 髪の物体と固定点ウェイトを作り、ベイク結果を生成します。そのあとさらに調整できます |
| 従来のスイング | もとからある髪のスイングと振り子を使います。このチュートリアルで使う髪のシミュレーション物体は作りません |
| オフ | その種類の髪の揺れをオフにします |

先に **前髪** を **シミュレーション** にし、生成の完了を待ちます。後ろ髪も参加させるときは、そのあと **後ろ髪** を **シミュレーション** にします。一部のレイヤーだけを扱いたいときは、先にそれらを選択し、**選択のみ** をオンにします。

プリセットは、毛束の根元に固定点を自動で作ります。先に既定の結果を見てから、手で調整するかどうかを決められます。

### 衣装もここからオンにできます

**衣装** にチェックを入れると、プログラムは部位ごとにシミュレーションを作り、ゆったりした領域だけを動かし、体に沿った領域は引き続きリグに追従させます。

![衣装プリセットの下に並ぶ上衣、スカートのゆったり度、体に沿ったパーツ](../../imgs/simulation-tutorial/clothing-report.webp)

*衣装の行の下には、シミュレーションに参加する部位とゆったり度が並び、体に沿ったパーツは「体に沿うため、シミュレーションしない」の 1 行にまとまります。*

ここにある百分率は、プログラムが素材のゆったり具合を報告したもので、プリセットがどの部位を処理したかを知るためのものです。実際の動きは、固定点、材質、プレビューで確認します。

## 2. 調整する物体とメッシュを選ぶ

**シミュレーション** パネルを開き、**物体** の一覧で **前髪（プリセット）** を選択します。行の左のチェックボックスは、その物体を有効にするかどうかを制御します。

調整するときは、パネル上部のプレビュースイッチをオンにし、ラベルを **参照シミュレーション** にします。このときエディタ内のリアルタイムシミュレーションが動き、パラメータパネルで頭を回したり体を傾けたりして、毛束の追従を観察できます。

固定点を変えるには、対応する前髪メッシュを選択し、キャンバス左上のモードを **シミュレーション** に切り替え、左側ツールバーで **ウェイトペイント → 固定点** を選びます。シミュレーションパネルの **頂点ウェイトグループ** を展開し、固定点の行の **描画** をクリックして、同じツールに入ることもできます。

![シミュレーションモードで固定点ウェイトグループを選択。前髪の根元は赤、毛先は青](../../imgs/simulation-tutorial/pin-weights.webp)

*図で選ばれているのは前髪メッシュで、色は現在の固定点ウェイトです。ほかのパーツが暗くなるのは、編集表示の効果です。*

| 色 | 固定点ウェイト | 意味 |
| --- | --- | --- |
| 赤 | 1 に近い | もとからあるリグにしっかり追従します。毛根や接続部に向いています |
| 緑／黄 | 中間値 | 部分的な固定で、遷移に使います |
| 青 | 0 に近い | 比較的自由にシミュレーションへ参加します。毛先や裾に向いています |

髪は通常、根元を固定して毛先へ向かって徐々に自由にします。スカートの裾は通常、腰を固定して裾へ向かって自由にします。先に接続部が安定しているかを確認し、そのあと揺れてよい領域を調整します。

## 3. ウェイトブラシで固定範囲を調整する

キャンバス左下のツールオプションバーに、ウェイトブラシの設定が表示されます（キャンバス上で右クリックしても、同じ設定を開けます）。先に変更の仕方を選び、そのあと **半径、強度、硬さ** を調整します。

![ウェイトブラシの右クリック設定。半径、硬さ、強度、および加算、減算、設定、ぼかし](../../imgs/simulation-tutorial/weight-brush.webp)

*スクリーンショットで選ばれているのは「減算」で、固定を弱め、揺れてよい領域を広げるのに向いています。*

| 操作 | 向いている調整 |
| --- | --- |
| 加算 | 根元や接続部をよりしっかり固定します |
| 減算 | 固定が多すぎる領域を、より自由に揺らします |
| 設定 | ウェイトを、現在の強度の値へ徐々に引き寄せます |
| ぼかし | 隣り合う頂点の間のウェイト変化を柔らかくします |

たとえば髪の固定が多すぎて毛束が揺れにくいときは、**減算** で根元の下を軽く塗り、遷移領域を少しずつ自由にします。頭に本当につながっている毛根は残します。接続部まで滑り始めたら、**加算** で根元のウェイトを補います。

小さい半径で縁を整え、低い硬さで柔らかい遷移を作ります。毎回少しだけ変え、色を見てから続けます。急な変化は **ぼかし** で整えられます。一方向へ遷移させたいときは、**ウェイトグラデーション** も使えます。

## 4. ウェイト分布と参照シミュレーションを確認する

次は、調整後の分布の一例です。上部は高い固定ウェイトのまま、両側と毛先へ向かって徐々に下がっています。

![調整後の前髪の固定点ウェイト。根元と自由な領域の間にグラデーションがある](../../imgs/simulation-tutorial/weights-adjusted.webp)

*大切なのは、接続部が安定し、遷移が連続し、毛先に自由度があることです。固定範囲は、自分の素材に合わせて調整します。*

**プレビュー** モードに戻り、**参照シミュレーション** をオンのままにします。ゆっくり頭を回し、次に素早く回して止めて、追従、振り出し、戻りをそれぞれ観察します。髪全体がほとんど動かないときは固定が多すぎないか確認し、根元がずれるときは接続部の固定点が足りているか確認します。

シミュレーションパネルの **材質** でも調整できます。

| 項目 | 調整の目的 |
| --- | --- |
| 曲げ | 毛束が曲がる難しさを制御します |
| 減衰 | 動きが収まる速さを制御します。大きくすると、通常はより早く止まります |
| 形状保持 | 原画の形へ戻る程度を制御します |
| 伸び | 毛束の長さを保ちます。髪は通常 1 に近づけます |

先に **髪** の材質プリセットを使い、一度に変える項目は 1 つだけにします。ほかの材質、ウェイトグループ、Glue の役割は[シミュレーションとベイク](SIMULATION.md)を参照してください。

モデルプリセットの **Pin 物理ウェイトを自動設定** は、ウェイトを計算し直し、ベイクし直します。固定点を手で整えたあと、その分布を残したいときは、シミュレーションパネルのベイクボタンを使い続けます。

## 5. 修正後に再ベイクする

ウェイトや材質を変えると、既存のベイクは **期限切れ** になります。シミュレーションパネルで、先ほど変更した物体を選択し、**ベイク** を展開して **再ベイク** をクリックします。まだ結果がないときは、ボタンは **ベイク** と表示されます。

![シミュレーションパネルで前髪の物体が期限切れになり、赤枠が再ベイクボタンを示している](../../imgs/simulation-tutorial/rebake.webp)

*赤枠のボタンは、現在の物体だけをベイクします。複数の物体を更新するときは、パネル上部の「すべてベイク」を使えます。*

最初は既定の **モード数 2、キー数 5、誇張 ×1.3** のまま、一度ベイクして観察できます。モード数は、全体の揺れと追加の変形をいくつのパラメータで表すかを決め、キー数は形状サンプルの細かさに影響し、誇張はベイク後の振れ幅を制御します。

**期限切れ** は、現在の設定が古いベイクと違うことを意味し、書き出しは引き続き古い結果を使います。ベイクし直してから、ウェイトと材質の変更が新しい書き出し結果に現れます。

## 6. ベイクの完了を待つ

ベイク中は、下部のステータスバーに進行状況が表示されます。所要時間はメッシュと物体の複雑さによります。完了してから結果を確認します。

![シミュレーションのベイク中。赤矢印が下部ステータスバーのプログレスバーを指している](../../imgs/simulation-tutorial/bake-progress.webp)

*矢印は、今回のベイクの進行状況を指しています。完了すると、最後にベイクした物体は一覧で緑の点になります。*

止める必要があるときは、進行状況の横のキャンセルボタンを使えます。**自動ベイク** は既定でオフです。ウェイトを手で続けて直すときは、先にまとめて変更し、終わってから一度にベイクできます。

## 7. 書き出し結果に戻して保存する

シミュレーションパネル上部のプレビュースイッチをオフにし、ラベルを **書き出し結果** にします。このときキャンバスは、ベイク後のキーフォームと振り子を再生し、書き出しモデルの見た目を確認するために使います。

頭を回す、傾ける、素早い動きのあとで止める、体を上下に動かす、を確認します。根元が安定しているか、毛先が自然に戻るか、衣装がもとからの造型を保っているかに注意します。見比べたいときは、同じモーションで **参照シミュレーション** と **書き出し結果** を切り替えます。物体の **比較** 節を展開し、参照シミュレーションを書き出しの上に重ねる（**重ね表示**）か、2 つのキャンバスで **並べて** 再生することもできます。モーションを 1 つ選んで **再生** すると、両方が静止から同時に始まり、**検証** するとそのモーションでの振れ幅、遅れ、収まりの比較が得られます。

結果を確認したら `.psd2live` プロジェクトを保存し、そのあとモデルを書き出します。そのあとウェイト、メッシュ、材質を変え続けるときは、ベイク状態を確認して更新してください。

## よくある問題

| 現象 | 先に確認すること |
| --- | --- |
| シミュレーションパネルに前髪の物体がない | 前髪のドロップダウンが「シミュレーション」になっているか、素材が前髪として認識されているか。対象メッシュを選択し、シミュレーションパネルの「新規 → 髪」から手で作ることもできます |
| ウェイトの色が表示されない | 対象メッシュを選択し、キャンバスの「シミュレーション」モードと「固定点」ウェイトグループに入っているか |
| 髪の根元が外れる、またはほとんど揺れない | 固定点が少なすぎるか多すぎるか。先に接続部を安定させ、そのあと毛先を徐々に自由にします |
| 参照シミュレーションは動くが、書き出し結果が更新されない | 未ベイクか期限切れです。ベイクするか、ベイクし直します |
| 一部の衣装パーツがシミュレーションされない | 衣装のゆったり度レポートと「体に沿うため、シミュレーションしない」の一覧を見て、プリセットの認識が素材に合っているか確認します |
| ベイク結果と参照シミュレーションに差がある | ベイクはリアルタイムシミュレーションへの当てはめです。品質の案内を見て、必要に応じてモード数やキー数を調整してからベイクし直し、実際の動きで改善を確認します |
