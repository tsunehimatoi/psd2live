# キャンバス編集早見表

[ドキュメント目次](../README.md) · [操作早見表](USER_GUIDE.md) · [前後分割の図解チュートリアル](DEPTH_SPLIT.md) · [変形パス](DEFORM_PATHS.md)

アプリ内の入門コース第 3、6–12 課に対応します。このページは、キャンバス上の編集ルールをテーマ別にまとめたものです。ボタンの位置と現在のショートカットは、ヘルプの **チュートリアル** を基準にしてください。

## 先にモード、次にツール

キャンバス左上のモードメニュー（Blender のモード一覧に似たドロップダウン）には、すべてのモードが並びます。メニューを開いているときは、1–7 で直接選び、方向キーで移動し、Enter で確定できます。「プレビュー」もこのメニューにあり、以前タイトルバーにあった「プレビュー」と同じ働きです。プレビューキャンバスでほかのモードを選ぶと、編集に戻ります。

| モード | 変更する内容 | よく使うツール |
| --- | --- | --- |
| オブジェクト | オブジェクトの選択 | クリック選択、矩形選択、投げ縄。階層ツリーと同期。内部造形ハンドル。ツールバーの「作成」 |
| 変形 | 基本形状、または現在のパラメータのキーフォーム | 頂点 / 辺 / 面の選択、変形、押し引き、スムーズ、膨張、パス制御点 |
| 編集 | メッシュトポロジとパスのバインド | 頂点 / 辺 / 面の選択、頂点配置（点 / 線）、接続、結合、再分割、辺の削除、再三角形化、削除、Glue（メッシュを 2 枚選択しているとき） |
| シミュレーション | シミュレーションが読む頂点ウェイトグループ（本ソフトのみ） | ウェイトペイント、ウェイトグラデーション。その下で種類（固定点、剛性など）を切り替え、描くグループを選びます。モードバーから布 / 髪を新規作成し、参照シミュレーションを切り替えます（書き出されません） |
| ボーン | スケルトン | ポーズ、ボーン編集。ポーズへ切り替えるとき、またはモードを抜けるときにボーン編集を保存します |
| 描画 | レイヤーのピクセル | ブラシ、鉛筆、消しゴム、ぼかし、塗りつぶし、グラデーション、スポイト、図形、選択範囲 |
| プレビュー | 変更しない | 再生、マウス追従、物理演算、フレームレート |

シミュレーションモードは編集モードと同じく、選択中のすべてのメッシュに同時に作用し、常に Blender のウェイト色（青 0 → 緑 → 黄 → 赤 1）で現在のウェイトグループを表示します。ウェイトブラシの円はモードごとに色が付きます（加算は白、減算は赤、設定は強調色、ぼかしはシアン）。ホバーすると、押したときに影響する頂点を円が示し、ポインタ横の数字は最も近い頂点のウェイトです。Alt + 右ドラッグで半径 / 硬さを調整し、減衰をプレビューします。ウェイトグラデーションは、満値の位置から薄くなる位置までドラッグします。シミュレーション自体はエディタ内だけで動き、書き出すにはシミュレーションパネルでベイクします。詳しくは[シミュレーションとベイク](SIMULATION.md)を参照してください。

現在のツールの設定は、役割の違ういくつかの場所に分かれています。

| 場所 | 内容 |
| --- | --- |
| 左側のツールバー | 現在のモードのツール。ツールは 1 行に 1 つで、カテゴリごとに区切り線でグループ化されます。オブジェクトモードの最後のグループは、Warp、Rotation、変形パスの作成です。選択中のツールのバリエーション（ブラシ形状、描画図形、選択方法、Glue とボーンのサブツール、ウェイトグループの種類）はツールの下に展開され、`1`–`5` でも選べます |
| モードバー（キャンバス上部） | モードメニューのあとに、キャンバスの操作を決める項目が続きます。変形 / 編集モードの選択系ツールでは頂点 / 辺 / 面（`1`–`3`）、現在の手順の確定とキャンセル（配置、切断、パス、Glue など）です |
| ツールオプションバー（キャンバス左下） | 現在のツールの数値。半径、強度、硬さ、不透明度、モードなどです。数値を左右にドラッグして調整し、クリックすると上にスライダーが出ます。描画モードでは先頭が前景色 / 背景色です |
| キャンバスの右クリックメニュー | モードバーとオプションバーと同じ設定（1 項目 1 行）に、そのツールの操作が加わります。各操作にはアイコンが付きます。開くときとホバーのアニメーションはモードメニューと同じです。オブジェクトモードでは、Warp、Rotation、変形パス、ボーン、スイングの作成が「作成」のサブメニューにまとまります。オブジェクト、編集、描画の各モードでは、レイヤー全体への操作もそれぞれサブメニューになります。「メッシュ」には、現在のピクセルからメッシュを再構築する項目、このレイヤーの独立メッシュを確認する項目、使えるときの前後分割があります。素材に関連付いたレイヤーには「素材」もあり、素材ウィンドウで開くか、関連付けを解除できます。残りの内容が 10 行以内ならすべて直接表示します。超えるときだけ、最大のグループ（トポロジ、減衰など）を 1 行に折りたたみ、ホバーで右側に展開します。各パネルの右クリックメニュー（階層ツリー、素材、テクスチャアトラス、モーション、物理演算など）は、キャンバスメニューと同じ見た目と開くアニメーションです。押した位置から展開し、ウィンドウ端に近いときは反対側へ折り返します |

モードバー、オプションバー、右クリックメニューは同じ定義を表示し、範囲も一致します。`[` `]` などのブラシショートカットが変えるのも、オプションバーにある現在のツールの同じ値です。右側の「ツール詳細」パネルには、広い場所が必要な詳細設定だけが残ります。正確な数値変形、Warp / Rotation の作成時の既定値、パス一覧、ボーンのバインドとウェイト、描画パレットです。スキンウェイトの表示は、右下の表示バーで切り替えます。

既定ではホイールでズーム、中ボタンまたはスペース + 左ボタンでパン、Shift で追加選択、Alt で選択解除です。

キャンバス背景に「デスクトップ」を選ぶと、メインウィンドウが透明になります。この選択が残るのは、アプリを通常の手順で閉じたあとです。透明ウィンドウのセッションがクラッシュした、または強制終了された場合、次回起動時は以前の単色またはチェッカー背景に戻ります（復元できる設定がないときはチェッカー）。色の設定は残ります。復元の情報はセッションログに書き込まれます。これで、透明ウィンドウの不具合によって起動できない状態が繰り返されるのを避けられます。グラフィックスドライバやデスクトップコンポジタ自体の問題が解消したわけではありません。

固定点のウェイトブラシの操作画面とベイクの手順は、[シミュレーション図解チュートリアル](SIMULATION_TUTORIAL.md)を参照してください。

## キャンバス上の点と線

どのモードでも、編集できる点と線の見た目は共通で、色には決まった意味があります。

| 見た目 | 意味 |
| --- | --- |
| 明るい細い線と小さな点 | 編集中のメッシュ、または Warp の格子。複数のメッシュを同時に編集するときは、それぞれ自分の色で区別します |
| 強調色で拡大され、白い縁が付く | 選択中の頂点、辺、面 |
| 白い外輪 | ホバー中の点。クリックすると選択される点です |
| 赤い円 | ブラシを押すと動く点。円が大きく濃いほど影響が強いです。ホバー中に表示され、ドラッグ中も残ります |
| 強調色の円 | 選択ブラシを押すと選択される点 |
| ウェイト色（青 → 赤） | シミュレーションとボーンのウェイト |

点の形は種類を表します。メッシュ頂点は丸、Warp の制御点は四角、Glue の点はひし形です。直接クリックできる点だけを表示します。右下の表示バーのメッシュスイッチは、各パーツのメッシュ線だけを描き（パーツ自身の色）、点は描きません。編集中のメッシュや Warp はキャンバスが直接描くため、表示バーは同じものを重ねて描きません。

## 変形とキーフォーム

パラメータにバインドされていないオブジェクトでは基本形状を編集し、バインド済みのオブジェクトでは現在のパラメータの組み合わせを編集します。対象がメッシュデフォーマ（Warp）のとき、モードバーで「頂点」（格子点を編集）と「ベジェ」を切り替えられます。ベジェでは、シアンのアンカーと琥珀色のハンドルだけをドラッグできます。詳細な格子は薄く表示され、編集できません。ほかのオブジェクトでは両者に違いはなく、表示もしません。先にパラメータパネルで目標値を設定し、そのあと制御点を調整します。オブジェクト自身の軸と、親から継承する動きを確認し、親のポーズを現在のオブジェクトへの直接のバインドと取り違えないようにします。

変形モードのキャンバス右クリックメニュー「キーフォームをミラー」は、現在のキーのキーフォームを垂直線に沿って左右反転します。結果は通常のキーフォームとして書き込まれ、取り消せます。

| 操作 | 働き |
| --- | --- |
| 対称キーへミラー | 現在のキーを対称キーへミラーします（AngleX 30 → −30 など）。そのあと、そのキーへ切り替えて結果を表示します。ショートカットは `Shift+M` |
| 対称キーからミラー | 逆方向です。対称キーの形状で現在のキーを上書きします |
| 反対側のオブジェクトへミラー | 反対側の同種オブジェクトへ書き込みます（左目 → 右目）。キーもミラーされます。L/R の付いたパラメータは反対側に置き換わり（EyeLOpen → EyeROpen）、左右パラメータは符号が反転します |
| その場で左右反転 | オブジェクト自身の中心で、現在のキーを反転します |
| すべてのキーを反対側へ / 反対側のオブジェクトへ | すべてのキーを一度に処理します。同じオブジェクトでは、現在のポーズがある側のキーだけを複製します |

符号を反転する「左右パラメータ」は、範囲が既定値を中心に対称で、かつ二次元関連の横軸であるか、ID が X または Z で終わるパラメータです（AngleX、AngleZ、BodyAngleX、EyeBallX など）。反対側のオブジェクトは、まずレイヤーの意味でペアにし、次に ID または名前の L/R、Left/Right、左/右でペアにします。ミラーが扱うのはオブジェクト自身の変形だけで、座標系は既定ポーズの親です。親のキーフォームは別にミラーします。複数のレイヤーを選択しているときは、各メッシュを別々にミラーし、1 件の履歴として確定します。

同じ右クリックメニューの「キーフォーム」は、現在のキーの形状を扱います。結果も通常のキーフォームとして書き込まれ、取り消せます。パラメータは、オブジェクトのキー上にぴったり合っている必要があります。

| 操作 | 働き |
| --- | --- |
| キーフォームをコピー | 現在のオブジェクトが現在のパラメータで表示している形状を覚えます。ショートカットは `Ctrl+Alt+C` |
| キーフォームを貼り付け | コピー時に固定した形状を、変位として現在のキーへ書き込みます（メッシュは元の形に対する変位、Warp と回転デフォーマは既定キーの形状に対する変位）。元のオブジェクトへ書き戻すことも、同種で三角形が同じ（Warp は行と列が同じ）で親も同じオブジェクトへ書くこともできます。`Ctrl+Alt+V` |
| デフォルトキーの形状にリセット | 現在のキーを、各パラメータが既定値のときの形状に戻します。`Ctrl+Alt+X` |
| メッシュの初期形状にリセット | メッシュのみです。変形していないメッシュに戻します |
| （パラメータ）の隣接キーから補間 | そのパラメータの両隣のキーの形状を位置で補間し、現在のキーを作り直します。補間できるパラメータが複数あるときは 1 つずつ並び、ショートカット `Ctrl+Alt+I` は先頭を使います |
| オプションを指定して貼り付け… | ダイアログで、貼り付ける内容（形状、不透明度、描画順、乗算色、スクリーン色）、ブレンド率（100% がそのままの貼り付け、小さいときはその割合で混ぜる）、左右 / 上下の反転（Warp は列 / 行を反転。メッシュは静止形状が対称である必要があり、ミラー位置で頂点を対応させます）を選び、コピーした各形状をどのオブジェクトへ貼り付けるか行ごとに確認します |
| 全キーをデフォルトキーの形状に復元 | オブジェクトのすべてのキーをデフォルトキーの形状に戻し、最初からやり直せます |
| 複数キーの編集… | パラメータのキー値で範囲を選び、複数のオブジェクトと複数のキーフォームの不透明度、描画順、色を一度に変更します（上書き、加算、乗算、スクリーン） |

コピー時に選択していた各メッシュは、形状を 1 つずつ覚えます。貼り付け時は自身へ書き戻すか、それを受け取れる次の選択オブジェクトへ順に割り当てます。すべての形状は、コピーしたときの見た目のまま書き込まれます。点を選択しているときは、貼り付け、リセット、補間は選択中の点だけを変え、メニュー行に点数を示します。Warp の「ベジェ」レベルと回転デフォーマは、常に全体を処理します。ジェネレーターが持つキーフォームの形状を変えると、生成結果の上書きとして記録されます。パラメータがオブジェクトのキー上にない、またはオブジェクトがパラメータにバインドされていないときは、メニューが理由を示します。

**ソフト選択**：選択ツールまたは変形ツールで、ツールオプションバーの「ソフト選択」（`O`）をオンにすると、選択点をドラッグまたは変形したとき、周囲の点が最も近い選択点までの距離で減衰しながら追従します。「影響範囲」はキャンバス単位で、`[` / `]` で調整できます。減衰カーブは変形ブラシと共通です。影響を受ける点は赤い円で示され、円が大きいほど追従量が多くなります。確定されるのは、通常のジオメトリ編集 1 回分です。

**一時変形**：`Shift+T`、または右クリックメニューの「一時変形（メッシュ）」は、選択点（選択がないときはメッシュ全体または Warp）の上に使い捨ての格子を敷きます。格子点をドラッグすると、中の点は双一次補間で追従し、離すたびに履歴が 1 歩進みます。パラメータがキー上にないときに押すと、先にキーへ吸着します。形状がほかの操作で変わっているときに押すと、現在の形状に合わせて格子を敷き直します。この 2 つの押し方ではドラッグを始めないので、もう一度押します。ツールバーの「格子」で 1×1–4×4 を切り替えます。Enter、Esc、または「完了」で終了し、格子自体は保存されません。

## 複数キャンバス、パラメータ、アニメーション

同じワークスペースのすべてのキャンバスは、パラメータのポーズ、パラメータロック、再生制御を共有します。編集／プレビューモードの切り替え、フォーカスの移動、キャンバスを隠す操作のいずれでも、別のポーズには戻りません。選択、ツール、カメラ、表示設定はキャンバスごとに保存されます。別のワークスペースは、それぞれのポーズを保持します。

編集キャンバスでパラメータをドラッグする、またはボーンでポーズを付けると、アニメーションは一時停止し、編集値が直接表示されます。パラメータのリセットとキーへの吸着は、自動ではロックしません。アニメーションエディタでタイムラインをドラッグすると、サンプルしたポーズがワークスペースへ送られ、編集キャンバスでも確認と調整を続けられます。編集値は、以前の再生が残したプレビューフレームを使いません。ポーズを付けているとき、マウス追従と一時停止中の物理演算は、その値を上書きしません。再生を再開するか、マウス追従を切り替えると、動的プレビューに戻れます。プレビューキャンバスでパラメータを動かすと、一時停止中の物理演算の応答を引き続き観察できます。

アニメーショントラック名の横の小さな目盛りはパラメータのキーを示し、カーブビューは同じキー群を数値付きのガイド線で示します。パラメータを削除すると対応するアニメーショントラックが取り除かれ、パラメータ範囲を縮めるとアニメーションのキー値とベジェ制御点も同じ範囲に制限されます。

再生、タイムライン、ベイクは、キャンバスを自動では新規作成、表示、切り替えしません。キャンバスが必要なときは、ウィンドウメニュー、またはパネル内のキャンバス表示ボタンから手動で開きます。

## 変形ブラシ

変形ブラシはジオメトリを変更し、テクスチャは変更しません。制御点の選択がないときは現在のオブジェクトのすべての点に作用し、選択があるときは選択点に限定します。半径はキャンバス単位です。既定では Alt + 右ドラッグで半径または硬さを調整し、Esc で現在のジェスチャをキャンセルします。

ブラシ先端の形状は、左側ツールバーのブラシの下で選びます（ウェイトブラシも同じです）。残りの設定は、ツールオプションバーとキャンバスの右クリックメニューにあります。

| 設定 | 働き |
| --- | --- |
| 形状 | 円、直線、または矩形 |
| 半径 / 硬さ / 強度 | 作用範囲、縁の硬さ、1 回の押しの強さ |
| 減衰 | 中心から縁までのウェイトカーブ。スムーズ、球状、ルート、逆二乗、シャープ、リニア、一定、ランダム |
| 接続のみ | ポインタ下のメッシュとつながっている点だけに影響します。円ブラシは、メッシュの辺に沿った距離で測るように変わります |

![変形ブラシの設定パネルと、「接続のみ」をオンにしたときの作用範囲](../../imgs/mesh-brush.webp)

*左：ブラシ設定。右：「接続のみ」をオンにすると、円は隣の毛束まで覆っていても、影響を受ける頂点（赤）はポインタがある束だけに残ります。ホバーした時点で、それらの頂点は赤い円で示され、円が大きいほど影響が強いです。隣り合う毛先や、上下の唇のように近いパーツを分けて塗るときに向いています。*

## メッシュトポロジ

| 操作 | 結果 |
| --- | --- |
| 辺の再分割 / 領域の再分割 | 当たった辺に点を足して三角形を組み直します。隣り合う面の継ぎ目も同時に処理します |
| 接続 / 結合 | 選択点の間に接続を作るか、選択頂点を 1 点にまとめます |
| 複製 | 選択頂点と、それらが完全に覆う面を複製し、新しい複製が選択になります |
| 削除 | 選択を削除し、欠けた部分の再構築を試みます。正当なトポロジにできないときは操作を拒否します |
| 辺の削除 | 選択した辺を削除します（辺モードで `Del`、またはトポロジメニューの「辺を削除」）。内部の辺は、両側の三角形が作る四角形の中でもう一方の対角線へ入れ替わります。静止形状、いずれかのキーフォーム、ブレンドシェイプのいずれかで四角形が凸でないときは拒否します（そうしないと、ポーズ時に面が裏返ります）。輪郭の辺は、それが属する三角形を削除し、使われなくなった頂点も削除します。頂点が 1 点だけでつながる状態になる、または三角形がすべてなくなるときは拒否します |
| 再三角形化 | トポロジメニューです。選択頂点の周囲（未選択ならメッシュ全体）で、細長い三角形をより均等な接続へ裏返します。頂点、輪郭、テクスチャは動きません。すでに最も均等なときは、処理不要と知らせます |
| 頂点配置 | 自動配置を直すとき、点ごとに調整します。「点」は点の追加、移動、削除、「線」は 1 本の線に沿ってつながった辺を足します。以下を参照してください |

### 頂点配置

編集モードのツールバーで、トポロジグループの先頭にあるツールです。通常のメッシュと、内部造形を持つメッシュの両方で使えます。モードは 2 つあり、オプションバーまたはツールバーの下で切り替えます。それぞれのショートカットを直接押すこともできます。

| モード | ショートカット | 用途 | ログコマンド |
| --- | --- | --- | --- |
| 点 | `Alt+M` | 点の追加、移動、削除でメッシュ密度を調整します。クリックまたは 1 ストロークのたびにすぐ確定し、新しい点の周囲の接続はメッシュが自動で整えます。点と点の間に**辺があるとは限りません** | `add_points`（および `connect` / `delete` / `delete_edges`） |
| 線 | `K` | 点を順にクリックして折れ線を描き、Enter で一度に確定します。各点は直前の点と辺でつながり、メッシュはこの線に沿って**折れ曲がれます**（まぶた、口の線、しわ） | `knife` |

2 つのモードの落下位置の規則は同じです。ポインタが頂点か辺に近いときは吸着します（吸着半径は共通。Shift は「線」モードで吸着を一時的に切ります）。ホバー位置には、押したときにどこへ落ちるかが表示されます。どちらもメッシュの外に置けます。

#### 点

| 操作 | 結果 |
| --- | --- |
| 空白をクリック | その位置に頂点を 1 つ足します。三角形の中なら 3 つに分け、辺の上ならその辺を分割し、メッシュの外なら最も近い可視の輪郭辺から三角形を 1 つ伸ばします |
| 空白をドラッグ | ストロークに沿って「配置間隔」（キャンバスピクセル）ごとに頂点を 1 つ足し、ストローク全体を一度に確定します |
| 頂点をドラッグ | 頂点を移動します。選択ツールと同じで、テクスチャは動かず、接着された点は一緒に動きます |
| Shift + 頂点をクリック | 現在選択している 1 つの頂点からそこへ線を結び、そのあと選択をその点へ移します。Shift + クリックを続けると折れ線になります |
| Alt + クリック | 頂点を削除して欠けを埋めるか、辺を削除します |

#### 線

点を順にクリックし、クリックのたびにアンカーを 1 つ置きます。頂点の上ならその頂点を使い、辺の上ならその辺を分割し、三角形の中またはメッシュの外なら新しい頂点を足します。隣り合う 2 つのアンカーの間は辺になり、通過した辺は分割されます。Enter（またはモードバーの「線を完了」）で線全体を一度に確定し、Delete で 1 点戻し、Esc でキャンセルします。つなげないとき（メッシュと重なるとき）は線全体を拒否し、下書きは残るので、最後の点を戻して置き直せます。

#### 共通事項

新しい頂点の位置、UV、キーフォーム、ブレンドシェイプ、頂点ウェイトは、周囲の元の頂点から同じウェイトで求まるため、点を足しても画面は動きません。点を足したあと、テクスチャを変えずに周囲の辺を裏返し、細長い三角形を減らします。「左右対称」をオンにすると、点の追加、削除、辺の削除は、メッシュの現在のバウンディングボックスの垂直な中心線を軸にした対称位置でも同時に行われます（対称位置に点や辺がないときは、こちら側だけを処理します）。右クリックメニューの選択グループには「輪郭頂点を選択」「内部頂点を選択」もあり、境界だけ、または内部だけを調整しやすくなっています。

内部造形を持つメッシュは、点の追加、点の削除、辺の削除、再三角形化、または静止形状の頂点移動のあと、同じステップで新しいメッシュに合わせて造形をベイクし直します。新しいメッシュが造形の面積チェックを通らないときは、編集はそのまま確定され、内部造形パネルがメッシュの変化と再生成の必要を知らせます。

トポロジの更新は、UV、キーフォーム、ブレンドシェイプ、Glue の頂点参照を同時に処理し、パスをバインドし直します。既存のポーズ、特に輪郭点を削除したあとの境界の変化は、引き続き確認してください。

## 内部造形ハンドル

オブジェクトモードの「内部造形ハンドル」（Shift+I、または内部造形パネルのツールバーの「キャンバス編集」。ほかのモードで押すとオブジェクトモードへ切り替わります）は、選択メッシュ上で内部造形を直接調整します。オブジェクトモードはメッシュ頂点を描かないので、ハンドルが頂点と重なって詰まることはありません。メッシュにまだ効果がない、または効果がオフのときは、オプションバーが案内し、ワンクリックでオンにできます。別のオブジェクトをクリックすると、そのオブジェクトが選択され、ハンドルもそこへ移ります。

| ハンドル | 働き |
| --- | --- |
| 中央の十字 | 上の腕は膨らみ、左の腕は偏り、右の腕は横方向の振幅、下の腕は縦方向の振幅です。腕が長いほど値が大きく、破線の枠の縁で 2 になります |
| アーチ線 | 実線は静止時の仮想アーチ面、破線は入力が最大のときに偏りで傾くアーチ面（模式）です |
| 矢印 | イージングと伝達をオンにすると表示されます。両端をドラッグすると始点 / 終点が変わり、中点をドラッグすると全体が平行移動します |
| ガイド線 | メッシュ上またはキャンバスの空白をクリックしてしわ線を描き始め、最後の点をクリックするか Enter で完了します。点をドラッグすると移動し、線分をドラッグすると線全体が平行移動します。Ctrl+クリックで点を足し、Alt+クリックで点を削除し、Delete で選択点または線全体を削除します。選択したしわ線は、半径ハンドルをドラッグできます |

ホバーするとハンドルと線がハイライトされ、ステータスバーに名前と数値が表示されます。ドラッグを離すたびに履歴は 1 件だけ記録され、Esc でドラッグをキャンセルします。パネルの数値とハンドルはリアルタイムで同期します。試動をオンにすると、ドラッグ中に造形の変化を直接見られます。

## 特徴点

オブジェクトモードの **特徴点** ツール（既定は `Shift+Y`）は、顔のパーツをフィットしたハンドルを表示します。各目の目頭・目尻と上下まぶたの中点、各眉の両端と眉山、口の両口角と上下唇の中点です（これらの部位がフィットの基本アルゴリズムを使っているときだけ出ます）。ハンドルをドラッグして離すと、顔のパーツが新しい位置でフィットし直し、開閉、笑い目、感情、口の形など、すべてのポーズが更新されます。まぶたの縁と唇の縁は、中点で最も多く追従し、両端では目尻・目頭または口角に追従します。変更は Rig のレシピに記録され、1 回のドラッグが履歴の 1 歩で、再生成後も残ります。動かしたハンドルは四角で描かれ、`Alt` + クリックで原画の位置に戻ります。フィットを変えずに顔のパーツ全体を少し動かすには、それを駆動するメッシュ（目、眉、口の形状デフォーマ）をドラッグします。編集モード、または変形モードで `Ctrl` を押しながら格子点をドラッグすると、その変位がそのデフォーマのすべてのキーフォームとブレンドシェイプに加算され、すべてのポーズが一緒に動きます。再生成後も残ります。オプションバーには、直前に操作した部位の基本アルゴリズムの数値が表示されます（目の下まぶたの押し上げ、眼球の丸み、口の前半の開き、口の形の振幅など）。ドラッグ 1 回が履歴の 1 歩です。**この特徴をリセット** と **すべての特徴をリセット** は、その特徴全体、またはすべての特徴の移動を一度に戻します。MCP は `settings_update` の `changes.rig.moves` で同じデータを変更します。

## 作成と素材の配置

1. 対象を選択し、オブジェクトモードのツールバーの最後のグループで Warp、Rotation、または変形パスを選ぶか、`C` / `R` / `P` を直接押します。階層ツリーの右クリックから親 / 子の Warp または Rotation を追加することも、オブジェクトモードのキャンバス右クリックメニュー「作成」から選ぶこともできます。
2. キャンバス上の配置プレビューを調整し、影響するオブジェクト、名前、親、分割設定を確認します。
3. モードバーの「確定」をクリックするか Enter でプロジェクトへ書き込みます。「キャンセル」をクリックするか Esc で取り消します。

PNG / WebP / TIFF / BMP を階層ツリーへドロップするか、ツリーの右クリック「レイヤーをインポート…」を使っても、配置セッションに入ります。描画オブジェクトへドロップすると、新しいレイヤーはその描画オブジェクトの親デフォーマの下にぶら下がります。配置が終わったら、重なりと複数パラメータのポーズを確認します。

## 変形枠

「変形」ツール、Warp / レイヤーの配置枠、テクスチャアトラスページで選択した図塊は、同じ変形枠を使い、見た目と操作も一致します。変形ツールは、何も選択していないときは選択ツールと同じで、クリック選択や矩形選択ができます。選択すると変形枠が出ます。

| 操作 | 効果 |
| --- | --- |
| 枠の内側をドラッグ | 移動 |
| 角 / 辺の中点をドラッグ | 拡大縮小。向かいの辺は動きません。`Shift` で角をドラッグすると縦横比を保ち、`Alt` はアンカーを中心に拡大縮小します |
| 上辺の外にある円形ハンドル、または角の外側（ホバーすると角の外に矢印付きの弧が光ります）をドラッグ | アンカーを中心に回転します。`Shift` は 15° 刻みです |
| アンカー（縁取りのある十字の円）をドラッグ | アンカーを移動します。中心、角、辺の中点に近いと吸着し、元の位置へ戻すと既定に戻ります |

アンカーの既定位置は選択の中心（各点の重心）です。枠の中での選択の相対位置は変わらず、移動、拡大縮小、回転のあとも選択についてきます。「正確な数値変形」の回転と拡大縮小も、これを中心にします。選択を変えるか Esc でツールを抜けると、アンカーは既定位置に戻ります。ドラッグ中、ポインタの横に回転角、両方向の拡大率、または移動したキャンバスピクセルが表示され、ほかのハンドルは薄くなります。画面上の枠の幅または高さが 40 ピクセル未満のときは、中央は常に移動になり、アンカーはドラッグできません（ビューを拡大してください）。Warp とレイヤーの配置枠は矩形として作られ、移動と拡大縮小だけで、回転はできません。テクスチャアトラスの図塊の角は、密度を縦横比を保って拡大縮小し、辺の中点はありません。

## 回転デフォーマ

原点をドラッグすると平行移動し、端点をドラッグすると回転します。既定では `Shift` を押しながら角度を吸着し、`Alt` + 端点のドラッグで比率を調整します。

## 複数メッシュの編集

編集モードは、選択中のすべての描画オブジェクトに同時に作用します。

- 頂点のクリック選択、矩形選択、ブラシ選択、変形枠、変形ブラシは、メッシュをまたいで効きます。
- あるメッシュの頂点をクリック選択すると、そのメッシュが**主メッシュ**になります。頂点配置の「線」、辺 / 面モード、パスは主メッシュだけに作用します。
- 削除などの頂点操作は、選択があるメッシュごとに一度ずつ確定され、同じ履歴に入ります。

## Glue

メッシュを 2 枚選択してから編集モードで Glue ツールを選ぶと、ツールバーのその下に 3 つのサブツールが並びます。Glue ブラシ、ウェイトブラシ、再結合です（`1`–`3`）。Glue の点は 2 枚のメッシュが共有する同じ点で、キャンバス上では 1 つのひし形として表示されます。選択またはドラッグすると両側の頂点は常に一緒に動き、編集中に接着でずれません。

Cubism と同じく、接着はメッシュの静止形状（すべてのパラメータが既定値）の上で行われ、接着点は静止時に両側が重なり、引っ張りを生みません。パラメータが既定値にないとき、Glue ブラシ、再結合、「Glue を作成」、選択頂点の接着は、先にパラメータを滑らかに既定値へ戻してから接着します。ウェイトの調整と接着の解除は、ポーズを変えません。

| 操作 | 効果 |
| --- | --- |
| Glue ブラシ | メッシュだけを変え、画面は変えません。重なっている場所（または吸着許容の中）で、もう一方のメッシュに頂点を追加するか滑らせ、UV もそれに合わせて動きます。挿入後、テクスチャを変えずに辺を裏返し、細長い三角形を避けます |
| `Alt` + ドラッグ | 接着を解除します |
| ウェイトブラシ | 青（A）/ オレンジ（B）で、テクスチャ上に両側のウェイトを表示します |
| 再結合 | 塗った頂点にある既存の接着を外し、吸着許容で接着し直します |
| `Enter` またはモードバーの「Glue を作成」 | 2 本の輪郭に沿って、区間全体を接着します |
| `Ctrl+G`（モデル書き出しのキー。このときは書き出しを開きません） | いずれかのメッシュで選択されている頂点を接着します |
| 右クリック「距離で区間全体を再結合」 | 2 枚のメッシュの間の接着をすべて外し、輪郭に沿って接着し直します |

## 描画の適用と破棄

先にレイヤーを選んでから描画に入ります。ストロークは独立した描画セッションに保存され、セッション内の取り消しとやり直しができます。最初の 1 筆を置くと、キャンバス上部中央からセッションバーがスライドして出ます（テクスチャアトラスの調整セッションバーと同じです）。描画中のレイヤーと筆数が表示され、取り消し、やり直し、破棄、**適用** があります。キャンバスが狭いときはボタンはアイコンだけになり、ホバーで名前が出ます。「ツール詳細」パネルにも「破棄」と「適用を確定」があります。

パレットは Photoshop の方式です。左下のツールオプションバーの先頭は、前景色 / 背景色が重なった色塊で、右上で入れ替え（X）、左下で既定の黒 / 白に戻します。色塊をクリックするとカラーピッカーが開きます。左側が彩度 / 明度の色域、右側が縦の色相バー、「新しい / 現在」の比較色塊（「現在」をクリックすると戻ります）、H S B と R G B の数値と 16 進コード、その下にスウォッチと最近使った色があります。「ツール詳細」パネルには、前景色の色域と色相バー、スウォッチ、最近使った色が直接埋め込まれます。ブラシ、鉛筆、消しゴム、図形のサイズは互いに独立し、図形の線幅はブラシサイズを変えません。

ツールバーは 3 グループです。ブラシ、鉛筆、消しゴム、**ぼかし**。塗りつぶし、**グラデーション**、スポイト。図形、**選択範囲**。各ツールのオプションは左下のオプションバーにあり、選択範囲のコマンドはキャンバス右クリックメニューの「選択範囲」グループにあります。

| 機能 | 使い方 |
| --- | --- |
| 選択範囲ツール（`Alt+L`） | 矩形、楕円、投げ縄、多角形投げ縄、自動選択、クイック選択の 6 つのバリエーションで、`1`–`6` で切り替えます。ドラッグで矩形選択します。投げ縄は押したままドラッグして輪郭を描きます。多角形は点ごとにクリックし、始点に戻るか `Enter` で閉じ、`Delete` で 1 点戻し、`Esc` で破棄します。自動選択は許容差でクリック位置の色を選び、「隣接」をオフにすると画像全体の同色ピクセルを選びます。クイック選択はブラシで、塗った場所と、つながった近い色（グラデーションの陰影を含む）を一緒に選択し、色が急に変わる縁で止まります。毎ストロークが選択範囲に追加され、`Alt` を押しながら塗ると減算します。`[` `]` でブラシサイズを調整し、許容差はオプションバーの「許容差」を使います。色を比べるときはアルファを事前乗算するため、透明領域は隠れた色が何であっても同じ色として扱います。`Shift` で追加、`Alt` で減算、`Shift+Alt` で交差します。オプションバーで合成方法を固定することもできます。ドラッグせずにクリックすると選択を解除します。選択範囲はアリの行進で表示されます |
| 選択範囲コマンド | `Ctrl+A` で全選択、`Ctrl+D` で選択解除、`Ctrl+I`（または `Ctrl+Shift+I`）で反転、`Alt+Backspace` で前景色を選択範囲へ塗ります（選択範囲がないときはレイヤー全体）。`Del` で選択範囲の内容を消去します。右クリックメニューには「選択範囲をフェザー」「選択範囲を拡張」「選択範囲を縮小」（距離はオプションバーの「フェザー」「拡張/縮小」。縮小はキャンバスの端から内側へは縮めません）と「不透明度でピクセルを選択」（レイヤーの透明度を選択範囲にします。Photoshop でレイヤーサムネイルを Ctrl+クリックするのに相当します）もあります |
| 選択範囲の働き | 選択範囲があるとき、すべてのツール（ブラシ、消しゴム、ぼかし、塗りつぶし、グラデーション、図形、消去）は選択範囲の中だけを変え、ソフトな縁は割合に応じて遷移します。選択範囲はストローク履歴に入りません。1 筆取り消しても選択範囲はそのままです。適用、破棄、またはレイヤーを変えると選択範囲は消えます |
| 自由変形（`Alt+T`。描画モードでは `T` も可） | ツールを選ぶと、選択範囲内のピクセル（選択範囲がないときはレイヤー上のすべての内容）が変形枠に入り、元の位置は空きます。枠の内側をドラッグすると移動します。角をドラッグすると縦横比を保って拡大縮小し（`Shift` で縦横比を崩します）、辺上の制御点は一方向に拡大縮小し、`Alt` は中心から拡大縮小します。枠の外をドラッグすると中心を軸に回転します（`Shift` は 15° 刻み）。`Enter` またはオプションバーの「変形を適用」でストロークとして確定し、`Esc` または `Ctrl+Z` でキャンセルして元へ戻します。ツールを変えると適用されます。オプションバーの「スムーズ」をオフにすると最近傍ピクセルでサンプルし、ピクセルアートに向きます。適用後、変形全体がストローク履歴の 1 歩になり、選択範囲はピクセルと一緒に動きます |
| グラデーション（`Alt+G`） | ドラッグで始点と終点を決めます。線形または放射状で、前景色から背景色、または透明へ向かいます。選択範囲と透明度の保護に従います |
| ぼかし（`Alt+J`） | 塗った場所が柔らかくなります。「強度」がぼかしの程度を決め、同じストロークを往復しても、どんどんぼやけることはありません |
| 手ブレ補正 | ブラシ、鉛筆、消しゴム、ぼかしのオプションバー「手ブレ補正」は 0–30 です。値が大きいほど線は安定し、追従は遅くなり、離したときに離した位置まで補います |
| 対称 | 上の 4 つのツールは、左右、上下、または四方向のミラーを選べます。軸はキャンバス中心で、キャンバス上に破線で示されます |
| 透明度を保護（`/`） | すでにあるピクセルにだけ色を付け、透明度は変えません。このとき消しゴムは背景色で塗るように変わります |
| 塗りつぶし | 「隣接」をオフにすると、画像全体の同色ピクセルを塗りつぶします |
| 直線 | `Shift` + クリックで、前のストロークの終点から直線を描きます |
| 既定の色 | `Alt+D` で黒 / 白に戻します（`X` で前景 / 背景を入れ替え） |

筆圧、ビューの回転 / 反転、指先、水彩の混色はまだ対応していません。Photoshop / SAI との詳しい対応は、描画システムを参照してください。

描画はレイヤーの矩形に制限されず、キャンバス全体に描けます。適用時はレイヤーのメッシュで切り抜きます。

- **メッシュ上の部分**はレイヤーに残ります。レイヤーのメッシュ、キーフォーム、バインドは変わりません。
- **メッシュ外の部分**は新しいレイヤーに分かれます。名前は元のレイヤー名に「+」を足したもので、元のレイヤーのすぐ上に置かれます。新しいレイヤーは自分のメッシュを持ち、元のレイヤーと同じ親、同じパーツの下にぶら下がるので、一緒に動きます。素材ライブラリにも素材として現れ、元のレイヤーの素材の隣に置かれます（元のレイヤーに素材がないときは最上位）。レイヤーとこの素材は関連付きます。
- メッシュの外を消しても効果はありません。そこにあるピクセルはもともと表示されず、レイヤーにもとからある薄い縁も分離されません。
- まだメッシュがないレイヤー（たとえば最初の 1 筆を描いたばかりの透明レイヤー）は切り抜かず、メッシュはすべてのピクセルから生成されます。
- 素材に関連付いたレイヤーでは、メッシュ上の部分が素材へ書き込まれ、その素材を使うすべてのレイヤーが一緒に変わります。メッシュ外の部分は、同様に新しいレイヤーへ分かれます。

レイヤー自身のメッシュに、新しく描いた領域を含めたいときは、メッシュパネルの「メッシュを再構築」を使えます。キーフォーム、パス、ウェイト、接着は新しいメッシュへ移行します。

適用したあと、変形とマスクを確認してからプロジェクトを保存します。実装の詳細は描画システムを参照してください。

## 確定と復元

通常のジオメトリのジェスチャはドラッグ中にプレビューされ、成功して終わるとプロジェクト履歴に入ります。作成、頂点配置の線描き、描画には、それぞれ確認の手順があります。「現在の下書き」「すでに確定した履歴」「ディスクへ書き込まれたプロジェクト」を、同じ状態として扱わないでください。

パスのモードの違いと書き出しの制限は[変形パス](DEFORM_PATHS.md)を参照してください。プロジェクトの永続化は[プロジェクト形式](../spec/PROJECT_FORMAT.md)を参照してください。
