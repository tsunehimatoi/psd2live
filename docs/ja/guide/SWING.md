# スイング生成

[ドキュメント目次](../README.md) · [物理演算](PHYSICS.md) · [MCP の使い方と API](../agent/MCP_AUTHORING.md)

スイング生成は、Cubism Editor 5.1 の「揺れの自動生成」に対応します。曲げデフォーマを選択すると、-1 / 0 / 1 にスイングのキーフォームを自動で作ります。それに加えて、次のことも行います。

- メッシュを選択してもよく、その場合はメッシュに沿った曲げデフォーマを自動で 1 枚かぶせます。
- **左右**と**上下**の 2 種類のスイングがあり、両方を同時にオンにできます。
- 先端を水平に保ち、下側を平行に振らせ、1 つのデフォーマで複数の毛束が一緒に揺れるようにできます。
- 対応する**物理振り子**も同時に生成します。
- 設定はプロジェクトに保存され、いつでも開き直して調整できます。

## 開き方

- キャンバス（オブジェクトモード）で、選択中のメッシュまたは曲げデフォーマを右クリック →「スイングを生成...」。複数選択のときはまとめて登録します。
- 階層ツリーでメッシュまたは曲げデフォーマを右クリック →「スイングを生成...」。すでにスイングを生成したオブジェクトは「スイングを編集...」と表示されます。
- 物理パネル →「+ 新規」→「選択対象にスイングを作成…」。物理グループ一覧で、スイング由来のグループは「⋯」メニューの「スイングを編集」から開けます。

開くと、現在のキャンバスは編集キャンバスに切り替わり（プレビューではなくなります）、スイング編集に入ります。編集中は、キャンバスを隠すウィンドウは出ません。形状はキャンバス上で直接ドラッグし、設定はワークスペース左下に浮かぶスイングパネルにあります。タイトルをクリックすると折りたたみ、タイトルバーの「↗」で独立ウィンドウへ移せます（「↙」でワークスペースへドッキングし直します）。

- 複数の対象は、同じパラメータと振り子を共有します。
- 編集中はキャンバスがロックされます。ハンドル以外の場所をクリックしても、ほかのオブジェクトは選択もドラッグもされず、右クリックメニューも出ません。
- 対象を追加するには、階層ツリーでほかのメッシュを選択し、パネルの「選択を登録」をクリックします。
- 回転デフォーマは対象にできません。

## キャンバス上のコントロール

キャンバスに描かれるのは、スイング矩形（幅は支点辺、長さは支点辺の中点から向かいの辺の中点まで）の 3 つの輪郭です。静止形状（破線）、+1 のポーズ（実線）、-1 のポーズ（薄い色）で、2 つのポーズの中心線も描きます。固定辺は太く表示されます。すべてのハンドルは、現在編集している方向の +1 ポーズ上にあり、ドラッグした先へ、+1 ポーズのその部分が移動します。

| ハンドル | 位置 | ドラッグの効果 |
| --- | --- | --- |
| 丸 | 先端 | 横ドラッグで振幅を設定し、反対側までドラッグすると反転します。軸に沿ってドラッグすると、跳ね上げ / 垂れ下がりを設定します。伸縮バウンドのときは、軸方向にだけ作用します |
| ひし形 | 中心線の中点 | 柔らかさを設定します。中間が先端についていく量が少ないほど、根元はピンとします |
| 小さな四角 | 先端の両角 | 先端の拡大 / 縮小を設定します。曲げのときは、下端の平行度（先端の辺をどれだけ水平に保つか）も設定します |
| 十字の丸 | 支点辺の中点 | スイング矩形全体を平行移動します。支点辺の中点がポインタに追従します |
| 白抜きの丸 | 静止中心線が先端を越えて延びた位置 | 支点の中点を軸に、スイング矩形全体を回転します（軸角）。見るのはポインタの方向だけです。0° に近いと 0° へ吸着します |
| 白抜きの四角 | 残りの 3 辺の中点 | クリックすると、その辺を支点にします |

すべての変更は、モデル上にリアルタイムで表示されます。パネルの「スイングをプレビュー」は、パラメータを -1 と 1 の間で往復させます（複数セグメントのときはセグメントごとにずらし、上下と左右もずらします）。「生成」/「適用」または Enter で、履歴を 1 件書き込みます。「キャンセル」または Esc では、変更は何も残りません。

## 2 種類のスイングと支点

「スイング方向」は、先端が画面上で動く方向です。「支点」は動かない辺です（格子の行と列で数え、第 0 行が上辺です）。この組み合わせが変形の仕方を決めます。

| 方向 | 支点 | 変形 | 典型的な用途 |
| --- | --- | --- | --- |
| 左右 | 上 / 下 | 弧を描く曲げ | 毛先、リボン、尻尾 |
| 上下 | 左 / 右 | 弧を描く曲げ | 横に伸びる飾り、横のリボン |
| 上下 | 上 / 下 | 伸縮バウンド | 耳飾り、ふわっとした毛先、胸 |
| 左右 | 左 / 右 | 伸縮バウンド | あまり使いません |

- **弧を描く曲げ**：中心線に沿って曲がるとき長さは変わらないので、先端が振り出すと自然に持ち上がり、単純な平行移動のように引き伸ばされません。
- **伸縮バウンド**：先端が支点の方向に伸びるか縮みます。伸びるときは細くなり、圧縮するときは太くなり、体積感を保ちます。
- **自動の支点**：
  - 細長いオブジェクトは上辺を取ります。
  - 横長のオブジェクトは、体の中心線に近い側を取ります。

### スイング矩形の回転と移動

既定のスイング矩形はデフォーマに揃います。素材が斜めに垂れていて（横髪、斜めに掛かった飾り）、デフォーマは正立の矩形のままのとき、先端の外にある白抜きの丸をドラッグすると、スイング矩形全体を支点辺の中点の周りに回転できます。範囲は ±75° です。

- 正の値は、先端を支点辺の末端のほうへ向けます（上 / 下の支点では右端、左 / 右の支点では下端）。ミラーされた親空間も、それに合わせてミラーされます。
- 矩形の大きさは変わらず、向きだけが変わります。曲げは回転後の軸に垂直で、弧の長さ保持、跳ね上げ、伸縮、平行は、回転後の矩形の中で計算されます。キャンバス上の輪郭、固定辺、支点と先端のハンドルも一緒に回転します。
- 固定されるのは矩形の支点辺です。その後ろの部分は動かず、格子の元の辺の一端が支点辺の前まで伸びている場合は、根元に近い曲げに合わせてわずかに動きます。
- 支点辺の中点にある十字の丸をドラッグすると、矩形全体を平行移動できます。たとえば支点を、毛根が実際にある位置まで下げると、上の部分は動かないままになります。回転は、移動後の中点を軸に行います。
- 移動量は矩形自身の比率で保存されます。軸方向は長さ、支点辺方向は幅で数えます（それぞれ ±1）。そのため、対象デフォーマの各キーフォームが拡大縮小・移動したあとも、素材の同じ位置に落ちます。
- 軸角と移動はスイング全体に属し、2 方向で共有します。パネルには現在の数値が表示され、それぞれの「ゼロに戻す」で既定に戻ります。ほかの辺をクリックして支点を変えると、両方ともゼロに戻ります。以前保存したスイングは、0 として開きます。

### 左右と上下の組み合わせ

パネルの「スイング方向」の 2 つのオプションは同時にチェックでき、両方とも同じデフォーマに作用します。

- 2 つの方向は、それぞれ自分のパラメータ、形状設定、振り子を持ちます。
- 同じ支点の下では、必ず一方が曲げ、もう一方が伸縮になります。生成時は先に伸縮してから曲げるので、組み合わせたポーズは正確で、両者を単純に足したものではありません。
- 両方の方向がオンのとき、パネルに「編集」の行が追加され、キャンバスのハンドルがどちらの方向に対応するかを選びます。

## 下端を水平に（複数の毛束）

髪を分割していないとき、左の髪、前髪、右の髪は同じデフォーマの中にあります。普通の曲げでは、各断面が中心線と一緒に回転し、全体が 1 枚の板のように回ります。先端の辺が傾き、片側が上がって反対側が沈むので、見た目が不自然です。

「平行」は、断面がどれだけ回転するかを制御します。

- **0**：断面が曲げに合わせて回転し、全体が 1 枚の板のように揺れます。1 本の毛先や飾りに向いています。
- **1**：断面は水平を保ち、先端の辺は傾きません。各列は固定辺上の自分の位置からぶら下がり、隣の列と並んで平行移動するので、複数の毛束が一緒に揺れて見えます。
- 中心線の弧は影響を受けないので、振幅、跳ね上げ、柔らかさの意味は変わりません。
- 前髪のように固定辺に近い短い束は、もともと曲げ量の小さい位置にあるので、自然に小さく揺れます。分割も、追加のデフォーマも要りません。

毛先と布のプリセットは、既定で平行寄りです（毛先の左右は 0.7）。飾りプリセットは 0 です。キャンバス上で、先端の両角の小さな四角をドラッグすると調整できます。

## 設定

パネルに置かれるのは、キャンバス上に対応する位置がない項目だけです（スイング方向、編集方向、自動推定、セグメント、自動の支点、物理演算）。残りの項目は、現在の方向の数値を読み取り専用で表示します。

| 設定 | 働き |
| --- | --- |
| スイング振幅 | ±1 のとき先端が動く距離。支点から先端までの長さで数えます（0.25 = 長さの 4 分の 1） |
| 跳ね上げ / 垂れ下がり | 曲げのとき、先端を追加で持ち上げる（正）か、垂れ下がらせる（負）量 |
| 柔らかさ | 0：全体が均等に曲がります。1：根元は真っすぐなまま、主に先端が動きます |
| 拡大 / 縮小 | ±1 のとき、先端に近い部分が太くなるか細くなります |
| 平行 | 0：全体が板のように回転します。1：先端の辺が水平を保ち、各列が並んで揺れます |
| 軸角 | スイング矩形が支点の中点の周りに回転する角度（±75°）。斜めに掛かる素材向けです |
| 移動 | スイング矩形の支点辺の中点が、軸方向 / 支点辺方向へずれる量。長さ / 幅で数えます |
| 左右反転 | +1 と -1 の方向を入れ替えます |
| セグメント | 各方向 1–3 セグメントで、セグメントごとにパラメータが 1 つあります。第 k セグメントは、その下の部分だけを曲げます。物理上は 1 本の多節振り子を共有し、下のセグメントは上のセグメントより 1 拍遅れて、ムチのような追従になります |
| 自動推定 | 毛先 / 飾り / 布。初期の形状と振り子パラメータの一式を出します。振り子の長さは、対象のピクセル長から見積もります |

パラメータがないときは自動で作成されます（範囲 -1..1）。名前は `ParamSwing<id>` で、両方向がオンのときは `_X`（左右）/ `_Y`（上下）が付き、複数セグメントのときはさらに `_1`、`_2`… が付きます。方向やセグメント数を変えると、パラメータはこの規則で改名されます。既存のパラメータを選んだ場合、キーはその最小値、既定値、最大値に置かれます。

以前保存したスイングに「平行」の設定がない場合、開くときは 0 として扱い、元の見た目を保ちます。

## 物理演算

「このスイングの物理振り子を生成する」にチェックすると、書き出す physics3.json と cmo3 に振り子の物理グループが追加されます。

- 方向ごとに振り子が 1 本です。方向が 1 つだけのとき、グループ名は `PhysicsSwing_<id>` です。2 方向のときは `PhysicsSwing_<id>_X` と `PhysicsSwing_<id>_Y` です。
- **左右**：入力は前後の髪と同じで、頭と体の角度 X（X タイプ）、角度 Z（角度タイプ）です。
- **上下**：頭と体の角度 Y と、小さいウェイトの角度 Z を入力します。
  - Cubism の振り子の棒は剛体で、垂直に下がった振り子は上下の平行移動に反応しません。
  - そのため、ここでは角度 Y を横方向（X タイプ）の励振入力として扱い、振り子の角度で上下の形状を駆動します。
- **セグメント**：各セグメントは物理グループ内の振り子 1 本に対応し、第 k セグメントのパラメータは、振り子番号が k の出力で駆動されます。

振り子は[物理パネル](PHYSICS.md)にも並び、そこで直接編集できます（入力、出力、各振り子のダイナミクスなど）。物理パネルで変更したあとは、物理パネルの版が優先され、スイングパネルの振り子数値は効かなくなり、パネルが知らせます。物理パネルで「生成値に戻す」とすると、スイングから生成した振り子に戻ります。同じ出力パラメータに対して新しく作ったカスタムグループは、対応する振り子を置き換えます。スイングを削除する、または方向を変えると、古い振り子への変更も一緒に消えます。

## ジェネレーターの意味とベイク

スイングは「ジェネレーター」です。モデルを再構築するたびに、対象デフォーマの現在の形状から計算し直し、そのあとにスイング軸を足します。そのため、次のようになります。

- 対象にもとからあるキー軸（角度 X など）はすべて残ります。もとからある各キーフォームは、それぞれスイングの各形状へ展開されます。
- これらのスイング軸はスイングが所有します。これらの軸上のキーフォームを手で変えても、再構築すると上書きされます。
- 手で微調整したいときは、パネルの「キーにベイク」をクリックします。
  - 現在の形状は通常のキーフォームとして書き込まれ、そのあと自由に編集できます。
  - 振り子は残り、スイングは物理の部分だけになります。
- 「削除」は、生成した軸と自動作成したパラメータも一緒に取り除きます。

## Agent

MCP は `swing_put` でスイングを新規作成または置換し、`swing_delete` でスイングを削除します。パラメータは `{"request": {...}}` に置き、`project_id`、`state`、`request_id` を付けます。

- `swing_put` は `id` で書き込みます。`targets` はメッシュまたは曲げデフォーマです。方向が 1 つだけのときは、トップレベルに `kind`（`lateral` / `vertical`）、`segments`、`parameters`、形状フィールド（`magnitude`、`lift`、`softness`、`zoom`、`parallel`、`flip`）を直接書きます。
- 2 方向を組み合わせるときは `motions: [{kind: "lateral", ...}, {kind: "vertical", ...}]` を使い、各項目に自分のフィールド、パラメータ、`physics` を付けます。
- トップレベルの `fulcrum` は支点辺を選びます。`tilt` はスイング矩形が支点の中点の周りに回転する角度（度、±75）です。`offset_along` / `offset_across` は矩形の移動（長さ / 幅、±1）で、2 方向で共有します。`preset`（`hair` / `accessory` / `cloth`）は、パネルの自動推定に対応します。
- `physics` を省略すると、対象の寸法から振り子を見積もります。`physics_enabled=false` は、振り子を生成しないことを意味します。
- `swing_delete` の `bake=true` は「キーにベイク」と同じです。

キャンバス上のスイング編集は試聴セッションに対応し、確定するまではドキュメントと履歴に入りません。`swing_preview` は `mode=begin` と `targets` で開始し、そのあと `update`、`kinds`、`segments`、`preset`、`physics`、`select`、`handle`（キャンバスのハンドルと同じ）、`play`、`cancel` で変更します。`swing_preview_get` は下書き、ハンドル位置、再生ポーズを読み、`swing_preview_render` は現在のポーズを描画し、`swing_preview_commit` は一度確定します。`swing_preview` と `swing_preview_commit` はバックグラウンドタスクのハンドルを返し、`job_wait` で結果を取ります。

`workspace_inspect` の `scope=swings` は、現在のすべてのスイングを列挙します。
