[中文](../zh/PSD_LAYER_SPEC.md) | [English](../en/PSD_LAYER_SPEC.md)

## PSD 画像の共通要件

1. **カラーモード**: **RGB / 8bit チャンネル**（CMYK、Lab、16bit、32bit モードは使用不可）。
2. **背景の透明化**: 不透明な白背景や塗りつぶし背景レイヤーは削除してください。
3. **ラスタライズと統合**:
   - テキスト、シェイプ、ベクターレイヤーはラスタライズしてください。
   - レイヤースタイル（ドロップシャドウ、光彩、境界線）は結合してください。
   - 調整レイヤー（色調補正、トーンカーブ等）は対象レイヤーへ結合してください。
4. **レイヤー名**: `レイヤー 1` 等のデフォルト名ではなく、意味のある名称を使用してください。

## 立ち絵ポーズおよび構図基準

自動トポロジー生成およびデフォーマ階層がキャラクターの動きを正確に再現するため、原画 PSD の作成時は以下のポーズ基準に従ってください：

### 1. 頭部の初期傾きと回転可動域
- **初期の傾き（首かしげ）は許容**：原画立ち絵におけるキャラクターの頭部は、初期状態で傾いていても（首かしげポーズなど）問題ありません。
- **基準角の自動認識**：両目の水平基準線（白目、瞳、まつ毛）および顔の中心軸から頭部の初期回転角（Initial Roll / `initialAngleZ`）を自動検出し、回転デフォーマ（`DeformHeadRotation`）のピボット基準角と一致させます。
- **可動域の決定**：顔の九軸経緯網（`ParamAngleX` / `ParamAngleY`）および頭部平面回転（`ParamAngleZ` $\in [-30^\circ, +30^\circ]$）は、**原画の初期角度をニュートラル（基準原点）として回転可動域を展開・決定します**。頭部が強制的に垂直へ直立補正されることはありません。左右の回転余白を美しく保つため、初期の傾きは自然な範囲（$\pm 25^\circ$ 以内を推奨）に留めることをお勧めします。

### 2. 身体ポーズの制限（過度に傾いた身体は非対応）
- **直立または微傾斜の維持**：キャラクターの胴体・身体は、**原則として直立（垂直）または小角度の自然な傾きを維持してください**。
- **過度に傾いた身体は非対応**：**大きく横に傾いたポーズ、横たわった状態、斜めに寝そべった身体の PSD はサポートしていません**。
- **理由**：身体の三軸デフォーマ（`ParamBodyAngleX` / `ParamBodyAngleY`）および胸部呼吸（`ParamBreath`、胴体縦座標 $v \approx 0.42$ を中心とするガウス分布）は、垂直なキャンバス座標系を基準に幾何構築されています。身体が過度に傾いていると、呼吸の膨張方向が横方向にズレたり、胴体回転時に異常な非線形せん断歪みが発生し、メッシュの破綻やテクスチャの裂けを引き起こします。

## 左右パーツの命名規則

左右対称のパーツ（目、眉、耳など）は、プレフィックスまたはサフィックスで左右を指定できます：

- **サフィックス構文**: `eyelash-l`, `eyelash-r`, `eyelash_left`, `eyelash_right`, `まつ毛左`, `まつ毛右`
- **プレフィックス構文**: `l-eyelash`, `r-eyelash`, `左まつ毛`, `右まつ毛`

> **左右の基準について**:
> PSD2Live では**キャラクター自身の左右**を基準とします：
> - **キャラクターの左 (`-l` / `LEFT`)**: 画面向かって**右側**。
> - **キャラクターの右 (`-r` / `RIGHT`)**: 画面向かって**左側**。

## 8 近傍連結成分による自動左右分離

左右のパーツ（`eyelash`, `eyewhite`, `irides`, `eyebrow`, `eye_close`）が 1 枚のレイヤーに結合して描画されている場合：

1. **8 近傍 BFS 連結成分解析**を自動実行；
2. 12 ピクセル未満の微小ノイズを除去；
3. 顔の中心線（`faceCenterX`）を挟む最大 2 領域を検出；
4. 条件を満たす場合、自動的に左右の仮想レイヤー（`:l` および `:r`）へ分割して各パラメータにバインドします。

## 主要パーツのレイヤー設計ガイド

### 1. 目パーツ (Eye System)
- **白目 (`eyewhite`)**: 目の輪郭全体を白くきれいに描画してください。
- **瞳 (`irides`)**: まぶたに隠れる部分も含め、きれいな円形で描画することを推奨します（白目で自動クリッピングされます）。
- **まつ毛 (`eyelash`)**:
  - **目の上半部（上まつ毛）のみ描画**：`eyelash` レイヤーには**上まぶたおよび上まつ毛のみを描画し、下まつ毛や下まぶたの輪郭線を絶対に混在させないでください**。
  - **閉眼変形アルゴリズム**：閉眼時、システムは上まつ毛レイヤーの Alpha 重心軌跡を列ごとに算出し、白目の下端 U 字形状に沿って下方へ滑らかに湾曲・圧縮します。下まつ毛が混在していると、Alpha 重心が眼球の中央付近へ引き下げられ、閉眼時に上下まつ毛同士が激しく圧縮し合い、二重像や破綻・テクスチャの裂けが発生します。
  - **下まつ毛の配置**：キャラクターに特徴的な下まつ毛や下アイラインがある場合は、`facedetail`（顔ディテール）または独立した静的レイヤーに分離し、閉眼変形の対象外として配置してください。

### 2. 口・口腔パーツ (Mouth System)
- **統合口形方式（推奨）**:
  - `mouth` / `mouth_open`: 唇、歯、舌、口内を含む**最大開口状態**で描画。
  - **最大開口での描画**：開口原画がメッシュの基準幾何（$\text{ParamMouthOpenY}=1$）となります。閉口時（$\text{ParamMouthOpenY}=0$）は水平中心線へ向かって約 1.25px の隙間まで求心圧縮されます。原画を閉口状態で描画すると、実行時に口を開くことができなくなります。
  - **明確な輪郭線（アウトライン推奨）**：唇の外周にははっきりとした線画・輪郭線を描くことを強く推奨します。求心圧縮時、上下の輪郭線が中心線上で自然に合わさり、鮮明で美しい閉口リップラインが形成されます。輪郭線のないグラデーション塗りや厚塗りの場合、極限圧縮時に境界がぼやけたり、周囲の肌色と濁って癒着しやすくなります。
  - 個別の歯・舌レイヤー（`tooth-t`/`tooth-b`/`tongue`）がある場合、`mouth` を参照して自動クリッピングされます。

### 3. 髪パーツ (Hair System)
- **前髪 (`front hair`)**: 前髪、サイドの髪など。
- **後ろ髪 (`back hair`)**: 後頭部、後ろへ垂れる長い髪など。
- 毛根を固定し、先端に向かって $v^3$ 立方勾配で揺れを拡大します。

## チェックリスト

- [ ] カラーモードが RGB / 8bit チャンネルになっているか。
- [ ] 背景レイヤーが削除され、透明になっているか。
- [ ] 身体が直立姿勢を保っているか（過度に傾いた姿勢や横たわり姿勢でないか）。
- [ ] 頭部の初期傾きが自然な範囲に収まっているか（初期角度を基準に可動域が決定されます）。
- [ ] 口が最大開口状態で描かれ、唇の輪郭線が明瞭であるか。
- [ ] まつ毛レイヤーが目の上半部（上まつ毛）のみになっているか（下まつ毛が含まれていないか）。
- [ ] 左右の目や眉が適切に命名されているか（または左右が明確に分かれているか）。
- [ ] 前髪と後ろ髪が別レイヤーに分かれているか。
