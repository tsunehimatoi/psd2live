# 実装比較と技術的設計決定

[中文](../zh/IMPLEMENTATION_COMPARISON.md) | [English](../en/IMPLEMENTATION_COMPARISON.md)

本ドキュメントでは、AutoLive2D の各処理段階における技術選定、アルゴリズム設計、およびアーキテクチャ上の決定事項について説明します。

---

## 処理段階別の比較と設計

| 処理段階 | 従来／一般的な手法 | AutoLive2D のアルゴリズムと実装 |
| :--- | :--- | :--- |
| **1. PSD デコード** | 簡易デコーダ（描画モード対応が不完全） | 統合された `PsdReader` パイプラインにより、切り抜き RGBA、描画順、不透明度、可視性、グループ構造、クリッピングマスク、描画モードを一括抽出。 |
| **2. セマンティック分類** | 固定の英語タグのみ、多言語別名や表記揺れの対応不足 | NFKC 正規化、小文字化、Photoshop コピー名除去、最長プレフィックス一致、L/R・左右の自動判定により 31 種のタグを判定し、未分類レイヤーも保持。 |
| **3. 左右自動分離** | 単純な境界ボックス分割（連結成分の解析なし） | 8 近傍 BFS 連結成分抽出により 12px 未満のノイズを除去し、顔中心線を挟む最大 2 領域を左右として自動分離し仮想 ID を付与。 |
| **4. 口腔処理** | 複数パターンの手動描き分け、または内部パーツとの連動不足 | 統合口形向心補間を採用：`mouth` 原画を最大開口状態とし、閉口時は中心線へ滑らかに圧縮。歯・舌パーツは口描画要素を参照して自動クリッピング。 |
| **5. アンカー推定** | 粗い外接矩形による単純推定 | 有効 Alpha 領域の結合とセマンティクス優先度に基づき、顔中心・顎・肩・腰アンカーを算出。フォールバック時は診断ログへ記録。 |
| **6. メッシュ生成** | 均一格子または粗い三角化（輪郭ジャギーや細長パーツの縮退が発生） | Alpha ガウス平滑化と適応的二値化；周期的 3 次 Bézier 曲線フィッティングによる角点検出と適応サンプリング（最大 12 倍）；位相適応型 Lawson 辺反転と超長辺中点二分割を備えた拘束付き Delaunay 三角化。 |
| **7. テクスチャアトラス** | 固定単一ページまたは無駄な余白の発生 | 決定論的多ページ Shelf Packer により、1:1 ピクセル精度と 2px 安全余白を維持し、最大描画要素に合わせてサイズを自動拡張。 |
| **8. デフォーマ階層** | 髪や装飾を顔メッシュ直下に配置し、首振り時に歪みが発生 | 分離型階層構造：`BodyXY` → `BodyZ_Breath` → `HeadRotation` → `HeadContainer`。頭部追従と顔面 9 軸変形を完全分離し、前髪・後髪を独立配置。 |
| **9. 顔面 9 軸変形** | 単純な 3D 球殻投影（広角時に手前の目が過剰伸長） | 8×8 経緯度格子；$C^1$ 連続水平 Roll 曲線（手前展開、手前目の幅維持プラトー、奥側透視圧縮）；垂直 $V/\wedge$ 仰俯曲率；斜め 4 隅の $C_{xy} = \text{yaw} \times \text{pitch}$ 相互干渉補正。 |
| **10. 身体動作** | 線形シアーまたは全体スケーリングによる歪み | `BodyAngleX` 縦方向ベル型エンベロープ Roll（行幅不変）；`BodyAngleY` $S$ 字型緯線再配置（全高不変）；`Breath` ガウス型胸部膨張；正負角度の完全鏡像対称性。 |
| **11. パーツ変形** | 一様なオフセット（空間深度差の欠如） | 知覚深度スケール（鼻 > 口 > 目 > 耳）；目・眉の共有透視傾斜拘束面；瞳の形状維持と逆方向補正；まつ毛の Alpha 重心追従による閉眼 U 字曲線；奥側耳の透視フェード（約 52%）。 |
| **12. マスクシステム** | 手動マスク指定（まばたき時の瞳の変形・はみ出し） | 瞳は同側の白目を自動的に `maskedBy` として参照；白目メッシュの収縮により瞳を自然にクリップ；口腔内部品は口メッシュを自動参照。 |
| **13. 物理演算** | 単純な単振り子、または顔面連動物理の欠如 | 毛根固定と $v^3$ 立方先端揺れ・浮き上がり勾配；まばたき速度連動の 2 階減衰振動子による瞳のぷるぷる物理（`ParamEyeBallForm`）。 |
| **14. 待機モーション** | 外部モーション依存またはデフォルト動作なし | 呼吸・微小な揺れ・自然なまばたきを含む 6 秒間のシームレスループ `idle.motion3.json` を自動生成。 |
| **15. パラメータ構成** | 独自命名規則やフラットな構造 | Cubism 標準パラメータ ID への準拠；標準 6 グループ構成；XY 結合パラメータ（Combined Links）を `.cdi3.json` に出力。 |
| **16. 出力と自己検証** | 単一形式出力（出力後のジオメトリ検証なし） | デュアルフォーマット出力（`.cmo3` 編集用プロジェクト + `.moc3` ランタイム群）；中立姿勢・極限姿勢・対称性検証の 3 段階整合性ゲート。 |

## 座標空間とフォーマット不変条件

1. **ラスタおよびアトラス空間**：原点は左上、Y 軸下方向、UV 座標の V 軸は非反転。
2. **デフォーマローカル空間**：ルート Warp はキャンバス絶対空間；子 Warp および初期メッシュは親 Warp の正規化ローカル空間 $[0, 1] \times [0, 1]$ で定義。
3. **CMO3 変換規則**：プロジェクト書き出し前に基準メッシュをキャンバス空間へ変換し、キーフォーム差分絶対量は親空間の拘束を維持。
4. **マニフェストの自己完结性**：`model3.json` に記述されたすべての相対パス参照は出力ディレクトリ内で完結。
5. **整合性監査基準**：中立姿勢における世界座標と PSD 元レイヤー境界の誤差は $\le 4\%$；極限姿勢において各描画要素は元サイズの $8\% \sim 400\%$ 内を維持し不透明度が 0 にならないこと。
