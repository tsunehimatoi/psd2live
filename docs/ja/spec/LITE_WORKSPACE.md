# 極簡ワークスペースとモバイルの設計（設計中）

[ドキュメント目次](../README.md) · [ロードマップ](../ROADMAP.md) · [MCP の使い方とインターフェース](../agent/MCP_AUTHORING.md) · [前後分割のチュートリアル](../guide/DEPTH_SPLIT.md)

> **状態の説明**：このドキュメントは**設計中**の案であり、まだコード実装には入っていません。文中で参照する `WorkspaceHost`、`AgentMcpService`、`source_split_depth`、`settings_update`、`layer_classify` などの下層能力は、現在のリポジトリに実装済みのモジュールです。

## 1. 背景と目標

現在のデスクトップワークスペースは、専門的な Live2D のモデリング手順向けに設計されています。キャンバスモードは 7 種類、パネルは数十、ショートカット体系と、多数のプロジェクト概念を含みます。「立ち絵を動くモデルにしたい」だけの初学者にとって、学習コストは従来の専門ツールに近くなります。

**極簡ワークスペース（Lite Workspace）**の目標は、**前提知識がなく、タッチを優先し、スマートフォンでも操作できる**簡素な入り口を提供することです。

- **複雑な説明と余分なボタンを置かない**：専門用語、密なパラメータ表、複数のキャンバス、複雑なメニューを外します。直接のジェスチャーと、多くても 1〜2 ステップのガイドで操作を完了します。
- **自動生成では代わりになれない、人が行う必要のあるツールだけを残す**：たとえば、パーツの前後が入れ替わる**前後分割**、顔パーツのフィット微調整、パーツ部位の訂正です。
- **MCP で外部 Agent に接続する**：ユーザーは極簡画面で複雑なパネルを操作しません。進んだ修正は MCP を通じて AI Agent に任せられます。
- **完全版のプロジェクトと完全に相互運用する**：下層は同じ `.psd2live` v2 プロジェクトと `WorkspaceHost` のコマンド経路を使い続けます。極簡版と完全なデスクトップ版のあいだで、損失なく切り替え、開き直せます。

## 3. 中核の作業手順（4 ステップの閉ループ）

極簡ワークスペースは、単一の主手順で組み立てます。ユーザーが「メッシュ—デフォーマ—パラメータ—キーフォーム」という階層概念を理解している必要はありません。

1. **インポートして自動生成する**：
   - ローカルの PSD / 画像、または既存の `.psd2live` プロジェクトを選びます。
   - `project_import_psd`（既定は `recommended` プリセット）を自動で呼び、動くモデルを直接生成して、リアルタイムプレビューに入ります。
2. **ジェスチャーで試し、全体を調整する**：
   - キャンバス上で直接ドラッグし、顔の向き、視線の追従、呼吸、髪 / 衣装の揺れをプレビューします。
   - 下部には、よく使う表情 / モーションの切り替えを少数と、「動きの大きさ」の全体スライダー（`settings_update.rigTuning` に対応）を置きます。パラメータスライダーを 1 つずつ調整する必要はありません。
3. **必要な人手のツール**：
   - **前後分割（残す中核ツール）**：「同じレイヤーの一部が手前、一部が奥」という入れ替わり（衿と首、髪と肩の装飾など）を解決します。下層は `source_split_depth` と手前レイヤーの消しゴム描画セッションをそのまま再利用します。右クリックの複数選択とモード切り替えの代わりに、3 ステップのタッチガイドを使います。
     1. 分割したいレイヤーをタップします（たとえば上衣）。
     2. そのあいだに挟むレイヤーをタップします（たとえば首）。
     3. 前後 2 枚を自動で複製して消去状態に入ります。指またはタッチペンで手前レイヤーを塗り、後ろに隠すべき領域を消します。前後の遮蔽はリアルタイムに見えます。「完了」をタップすると、履歴 1 歩として確定します。
   - **特徴点の微調整**：自動フィットした目尻、眉の山、口角が少しずれているとき、キャンバスに大きなタッチハンドル（`settings_update.moves` に対応）を表示します。ドラッグすると再フィットします。
   - **部位のすばやい訂正**：パーツをタップしたあと、直感的な部位アイコンで分類を直します（「これは左目 / 前髪 / 無視」など）。`layer_classify` と再生成に対応します。
4. **ワンクリックで書き出す**：
   - 用途を選びます（たとえば「VTube Studio で使う」「`.p2lrt` を書き出す」）。書き出しはバックグラウンドで実行します。続行を止める問題があるときだけ、短い案内を出します。

## 4. スマートフォンとタッチを優先する画面

スマートフォンの縦画面、タブレットの横画面、デスクトップの狭いウィンドウでも滞りなく操作できるよう、画面は次の制約に従います。

- **キャンバスが主ビューポートを占める**：面積の 85% 以上をモデルキャンバスに残します。常駐の左右サイドバーと、上部の多段メニューバーは置きません。
- **極簡のトップバー**：中核の入り口は 4 つだけです。`工程/返回`、`撤销 / 重做`（`history` の分岐履歴に対応）、`MCP 状态`、`导出`。
- **1 段の文脈ボトムバー**：
  - 既定では主タブを 3 つだけ置きます。`试动`、`修整`、`MCP`。
  - 具体的なツールに入ったとき（たとえば「前後分割」の消去段階）は、ボトムバーをその場で、そのツールの最小コントロール（ブラシサイズのスライダー、ストロークの取り消し、キャンセル / 完了）に置き換えます。キャンバスを覆うフローティングウィンドウは出しません。
- **ホバーなし、右クリックなし、ショートカットに依存しない**：
  - マウスホバーの説明を唯一の説明にはしません。右クリックのコンテキストメニューは使わず、`Shift` / `Ctrl` の複数選択にも依存しません。複数選択は、すべて明示的な「タップの手順」に変えます。
  - タッチ対象には十分なヒット領域を残します（目安は 44〜48 dp 以上）。スライダーとキャンバスのドラッグジェスチャーは互いに排他にし、モデルへの誤タッチを避けます。

## 5. MCP の接続方式

極簡版は、複雑な編集能力を MCP 経由で外部 Agent に委ねます。画面は極簡のまま、上限は閉じません。

- **既存のサービスと契約を再利用する**：
  - `AgentMcpService` の**簡略ツールセット**（Streamable HTTP + Bearer Token）をそのまま再利用します。外部 Agent は、`workspace_inspect`、`workspace_apply_edits`、`source_split_depth`、`settings_update`、`author_axis` などのアプリケーション層の能力を呼び出せます。
  - 極簡 UI と `WorkspaceHost` の `state` による楽観的並行制御、および履歴ノード 1 つの確定意味を共有します。Agent の各変更は極簡側のキャンバスにすぐ見え、ユーザーはワンクリックで取り消せます。
- **極簡側の接続体験**：
  - `MCP` パネルに出す内容は 3 つだけです。サービスのスイッチ、現在の接続状態（未接続 / 接続済み / Agent が編集中）、そして「接続設定をコピー / インストール用プロンプト」。
  - スマートフォンやタブレットで極簡版を使うときは、外部から到達できるホストアドレスを設定するか、ペアリングトークンで同じ LAN 内の Agent ホストに接続できます。

## 6. 技術の再利用と段階的な提案

### 6.1 アーキテクチャの再利用

リポジトリでは、デスクトップ UI とアプリケーション層の分離が済んでいます（`application` は `ui` と Compose に依存せず、`LayerDependencyTest` が境界を守ります）。

- **アプリケーション層と中核層は書き直さない**：極簡ワークスペースは、`WorkspaceHost` の軽いフロント表現層として直接置きます（デスクトップ側の `DesktopPresentation` に相当します）。生成、編集、履歴、MCP、書き出しは、すべて既存のコマンド経路を通ります。
- **プロジェクトとランタイムの互換**：極簡側が保存した `.psd2live` は、デスクトップの完全版でそのまま精修を続けられます。完全版が保存したプロジェクトも、極簡側で試し動かし、前後分割、または書き出しができます。

### 6.2 段階的な実装

1. **第 1 期（デスクトップ内の極簡モード）**：既存のデスクトップアプリに「極簡ワークスペース」のビュー切り替えを用意します。まず 4 ステップの主手順、前後分割のガイド、MCP の近道の使いやすさを検証します。プラットフォームをまたぐランタイムの差は扱いません。
2. **第 2 期（狭い画面とタッチだけの操作）**：右クリックなし / ショートカットなしの操作への変更、縦画面の 1 段ボトムバー、特徴点のタッチハンドル、部位のすばやい訂正を完成させます。
3. **第 3 期（モバイルでの実行形態）**：スマートフォン / タブレットで Compose UI を動かす配置方法を評価します。優先できるのは「モバイルの極簡フロント + 遠隔またはデスクトップの `WorkspaceHost` サービス（プレビューストリームと MCP を含む）」です。`.p2lrt` ランタイムと中核を削った案を組み合わせ、端末上で動かす方法もあります。
