# PSD 素材と命名

[ドキュメント目次](../README.md) · [操作早見表](../guide/USER_GUIDE.md)

このページは素材の準備向けです。自動認識はプリセットの入り口にすぎず、インポート後もレイヤー表でタグと差分を変更できます（[意味タグ](#意味タグ)を参照）。

## 素材を用意する

RGB、8 ビット、透明背景のレイヤー分けした PSD は、自動リグを容易にするための推奨であり、ユーザーが先に固定の名前やグループで素材を整理している必要はありません。リーダーは 16 ビットの RGB / グレースケール、インデックスカラー、1 ビットのビットマップにも対応します。独立したレイヤーがない PSD は、統合画像を 1 つのレイヤーとしてインポートします。文字、ベクター、レイヤースタイル、調整効果は、ファイル内にすでにあるラスターピクセルに依存し、Photoshop の編集上の意味を完全には残せません。体がほぼ正面で直立し、パーツが分かれて描かれていると自動リグに役立ちますが、インポートの条件ではありません。

## インポートの寛容さと境界

- 未知の名前、重複するレイヤー名、重複するグループ名で、インポートを止めるべきではありません。重複するグループには独立した内部パスを割り当て、表示名は残します。
- 1 つのレイヤーのピクセルチャンネルをデコードできないときは、レイヤー名と位置を残し、空のピクセルを使い、警告を出します。デコードできる他のレイヤーは読み続けます。空のピクセルは、壊れた内容を回復したことを意味しません。元の PSD は残してください。
- モディファイアが現在の入力を処理できないときは、そのモディファイアの出力をロールバックし、モディファイアメニューに理由を表示し、それとそれに依存する機能を一時停止します。独立したモディファイアは実行を続けます。失敗した項目を再び有効にすると、再試行します。シミュレーション準備段階の失敗記録はプロジェクトとともに保存され、他のランタイム状態は再構築時に再計算されます。キャンセル操作は、今までどおり構築を直ちに終了します。
- PSD の解析と RLE デコードは、中断の検査に対応します。プリセットの構築は現在の段階を報告します。大きなキャンバス、多数のレイヤー、シミュレーションのベイクは、なお時間がかかることがあります。インポートできることは、すべての自動的な動きが使える品質に達したことではありません。
- 現在対応していないのは、PSB、32 ビット浮動小数、CMYK、Lab、マルチチャンネル、ダブルトーンです。ファイル構造がひどく壊れているとき、または利用可能なメモリを超えるときも、回復は保証できません。明確にエラーを報告するべきであり、任意のファイルを損失なくインポートできるとは約束できません。

以下のレイヤー分けと命名の提案は、自動認識と変形の品質を上げるためのものです。インポート後に段階的に調整できます。

名前のないピクセルレイヤーは、最も近い明確なパーツフォルダ（たとえば「脸」「嘴」「眉毛」）を継承できます。「身体」「眼睛」のような広いグループは、ピクセルの用途を直接は指定しません。明確なレイヤー名が優先し、汎用のレイヤー番号は、継承したパーツの差分番号としては扱いません。左右の印がない片側の眉は、目の位置から左右を判断します。ユーザーが手動で指定した分類が優先します。

レイヤーのリニアドッジ（加算）、グロー加算、リニアライトは加算を生成します。乗算、リニアバーン、カラーバーンは乗算を生成します。スクリーンはスクリーンのままです。Cubism 5.3 より前のランタイムへ書き出すときは加算へ下げ、損失レポートに書きます。残りのレイヤー合成モードは、通常の描画として扱います。自動リグは、ソースフォルダの非表示状態を残します。クリッピングを使っていない乗算グループは、まず内部レイヤーを合成し、そのあとグループ全体を元の不透明度で下のレイヤーと乗算します。通常合成で独立して合成できるグループも、グループの不透明度を残します。その中の通過グループは、内部の描画が通常合成であり、クリッピングがないことを要求します。

透かし髪の効果をすでに描いた半透明の眉と目は、`眼眉透发` グループに置けます。自動リグは、合成後のグループ全体を、下にある可視の前髪の内側へ切り抜き、グループの不透明度を残します。`刘海脸部投影` グループに置いた乗算の髪の影は、下の主となる顔の肌で切り抜きます。影のレイヤーは `front hair shadow fringe 1` と、対応する `front hair fringe 1` で対にできます。プログラムはソースの Alpha が重なるかも同時に検査し、同じ髪片の振り向き軌跡を再利用します。頭の後ろとともに回したいカチューシャは、`headwear rear` または `后置头饰` で印を付けられます。

## PSD を使わない場合：Layout マニフェスト

プログラムが分けたパーツ（たとえば AI によるレイヤー分けの結果）は、PSD を通さず、[Layout マニフェスト](LAYOUT_MANIFEST.md) として PSD2Live に渡せます。1 つの JSON（またはルートにそれを置いた zip）で、レイヤーごとに画像、キャンバス矩形、上下の順、グループ、タグ、差分、参照専用かどうか（パーツを分ける前の原図など。キャンバスには表示するが、生成も書き出しもしない）を書きます。小さいパーツはキャンバスより多くのピクセルを持てます。開くと、配置済みでまだ生成していないプロジェクトになります。タグのないレイヤーは、このページの名称規則で識別します。

## パーツのレイヤー分け

### 目とまつ毛
- **レイヤー分けの提案**：白目、瞳、まつ毛は別々に描きます。瞳は、まぶたに隠れる部分も含めて完全に残します。
- **まつ毛の細分**：横方向の主筆、尖った束、側面の囲みを複数層含められます（数字の接尾辞は、既定では共存するレイヤーを意味します）。独立した下まつ毛は `lower`、まぶたの線と影はそれぞれ `lid`、`shadow` と印を付けます。
- **振り向きへの適合**：上まつ毛の線（目尻のまつ毛の翼は単独の層にできる）、白目（大きく描き、縁はまつ毛で隠す）、虹彩（円全体を描き、白目で切り抜く）、瞳、ハイライトに分けます。虹彩とハイライトは振り向きのときほとんど変形せず、まぶたの開口がそれらのまわりで変形します。

### 口と口腔
- **基礎の要件**：最大に開いた口の素材を用意します。口腔は一体として描くか、上の歯、下の歯、舌に分けられます（閉じた口の原図からは、存在しない口腔を回復できません）。
- **厚塗りの唇 / 精密な開閉（2 つのグループに分けることを推奨）**：
  - **口腔グループ**：`口腔`（最大開口の形の塗りレイヤー。不透明度を 0 にして純粋なクリッピングマスクにできる）、`口腔底`（開口より大きく描き、`口腔` にクリップする）、`上牙` / `下牙` / `舌`（実際の歯列として描く。平らか、やや U 字。∩ に切り詰めない）、口腔の暗い影のレイヤー。
  - **唇のグループ**：`上唇`、`下唇`（周囲に顔と同じ色の皮膚を一回り含む）、線画があるときの `上唇线`、`下唇线`（2 本の線は閉じて、左右の口角で同じ点に接する）。
- **自動の縁取り**：唇の原画がない単一の口腔にだけ、縁取りを生成します。唇の線、唇の肌、閉じた口の縫い目、または重なる完全な口形の差分がすでにあるときは、原画を使います。口の内側の切り抜きレイヤー、ハイライト、影は、縁取りの出所にはしません。ピクセルはあるが現在隠れている唇レイヤーも、判断に参加します。
- **舌を出す**：舌を出すを有効にすると、プログラムは外へ伸びた舌の複製を自動生成します（口腔の切り抜きを外し、下唇の上、上唇の下に置く）。手描きの追加の伸出舌レイヤーは不要です。

### 顔、顔パーツ、髪
- **顔の肌**：1 枚（または完全な輪郭の帯）として描きます。あご、下顎角、両頬、額の角の輪郭は明確である必要があります。振り向きのときは、読み取った特徴点に従って元の顔形を保ちます。
- **鼻と耳**：鼻は顔の肌に描くか、単独のレイヤーにできます（独立レイヤーは振り向きのとき最も先行する。複雑な鼻は鼻筋の線、鼻の底、横顔に分けられる）。耳は全体を描き、振り向きのとき髪の後ろへ収められるようにします。
- **髪**：前髪、横髪（`side`）、後ろ髪を分けます。後ろ髪と、隠れる領域は、動きのために十分な重なりを残します。

## 左右と分割

左右はキャラクター自身を指します。キャラクターの左側は、通常は画面の右側にあります。`eyelash-l`、`eyelash-r`、`eyelash_left`、`左睫毛`、`왼쪽 속눈썹`、`속눈썹_우` などの名前を使えます。韓国語の 1 文字 `좌` / `우` は、区切りまたは括弧で分ける必要があります。矢印 `>` / `<` も左右に使えます（同様に区切りまたは括弧を使う）。`>` はキャラクターの左側（それがいる画面の右側を指す）、`<` はキャラクターの右側です。例は `눈썹_>`、`흰자(<)`。

まぶたの赤み、アイラインのハイライト、アイラインの覆いなどは `eyelash eye-detail-l/r` を使えます。それらは対応する目の肌の変形に従い、主となるまつ毛の線と透かし髪の層は独立した素材を使います。眉の影は `eyebrow brow-detail-l/r` を使えます。原画が前髪の上の眉をすでに用意しているときは、`eyebrow front-l/r` または `eyebrow cover-l/r` で示せます。自動の透かし眉は、同じ側にすでにある覆いを尊重します。

左右のない両側レイヤー（たとえば両目を同じ層に描いたもの）は、インポート時に自動では分割されず、1 つのパーツとして生成されます。左右を分ける必要があるときは、PSD でレイヤーを分けるか、エディタでメッシュまたはポリゴンにより分割し、分類を確認してください。より早いバージョンが自動で分けた `:r` / `:l` のパーツは、古いプロジェクトに残ります。

## 数字と差分

`front hair 1` などの数字は、素材を区別できます。分類器は、Photoshop の複製接尾辞の一部も取り除きます。数字の名前そのものは、表情の切り替えがすでに作られていることではありません。スイッチ差分にはパラメータの指定が必要で、切り替え差分にはパラメータの共有と、異なる関連 ID の設定が必要です。

## 未知のレイヤーと確認

識別されなかったレイヤーは、名前が未知であることだけを理由に捨てられません。メッシュを生成し、フォールバックの帰属を使えます。レイヤーパネルで手動修正してください。中立、目と口の開閉、振り向き、髪の動きを確認し、レイヤー順、左右、マスク、地の露出を照合してください。命名に成功したことは、自動造形が受け入れを通過したことではありません。
