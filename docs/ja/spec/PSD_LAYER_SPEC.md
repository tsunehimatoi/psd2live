# PSD 素材と命名

[ドキュメント一覧](../../README.md) · [中文](../../zh/spec/PSD_LAYER_SPEC.md) · [English](../../en/spec/PSD_LAYER_SPEC.md) · [操作早見表](../guide/USER_GUIDE.md)

自動分類は入口にすぎず、読み込み後にレイヤー表で各レイヤーのタグと差分を変更できます（[セマンティックタグ](#セマンティックタグ)）。

## 素材準備

RGB・8 ビット・透過背景のレイヤー付き PSD を使います。必要な文字、ベクター、レイヤー効果や調整結果は対象画素へ統合してください。体はほぼ直立させます。頭の軽い傾きは推定されますが、結果を確認してください。

レイヤーの描画モード：覆い焼き（リニア）- 加算、加算（発光）、リニアライトは Cubism の加算、乗算、焼き込み（リニア）、焼き込みカラーは乗算になり、スクリーンはスクリーンのまま残ります（Cubism 5.3 の描画モード。それより前のランタイムバージョン向けに書き出すと加算で近似し、損失レポートに記録します）。その他のモードは通常として描画されます。グループの描画モードは反映されないため、必要ならグループを 1 枚のレイヤーに統合してください。

## PSD を使わない：レイアウトマニフェスト

AI によるレイヤー分解など、プログラムで分けたパーツは PSD を経ずに[レイアウトマニフェスト](../../zh/spec/LAYOUT_MANIFEST.md)（中国語）として PSD2Live に渡せます。レイヤーごとに画像、キャンバス上の矩形、前後順、グループ、タグ、差分と、参照専用かどうか（分解前の原画など。キャンバスに表示され、生成と書き出しには含まれません）を記した JSON か、それをルートに置いた zip です。小さなパーツはキャンバスより多くの画素を持てます。開くと配置済みの未生成プロジェクトになります。タグのないレイヤーはこのページの名前規則で認識されます。

## パーツ分け

白目・瞳・上まつ毛を分け、瞳はまぶたに隠れる部分も描きます。下まぶた線を上まつ毛へ混ぜないでください。「下まつ毛」が分類されても、上まつ毛用変形に適しているとは限りません。

口は最大に開いた素材を用意します。一体の口でも、上下の歯と舌を分けても構いません。閉口画像から存在しない口内を生成するものではありません。

厚塗りの唇や、よりきれいな開閉にしたいときは、モデラーの慣例どおり口を二つのグループに分けます。口内は `口腔`（最大に開いたときの開口部の形。塗りつぶしで、口内のほかのレイヤーをクリッピングします。縁は唇線の太さの中ほどまでにし、唇レイヤーで隠れない限り線の外側にはみ出さないこと）、口内の地色（`口腔底` など。口がどう開いても収まるより大きく描き、PSD で `口腔` にクリッピングします。どの口の形でも開口部に後ろが見えません）、`上歯`、`下歯`、`舌`（これも開口部より大きく描き、上歯は上へ、下歯は下へ唇線の下まで伸ばして口腔でクリッピングします。こうするとどの口の形でも歯が唇線に接します）。口内の暗部は影として別レイヤーにできます。唇は `上唇`、`下唇`（唇と、その周りの顔と同じ色の肌を含めて描き、唇の色・つや・影もその中に描きます）と、線画がある場合の `上唇線`、`下唇線`（二本で一つの閉じた輪郭になり、左右の口角で同じ点に接し、太さは均一）。唇は潰れずに縁ごと動き、閉じると口内を隠します。唇レイヤーのある口は「口内の閉じ方」の設定分だけ口内を閉じます。線は太さを保って縁に沿い、閉じると一本に重なります。唇や唇線を分けた口には口元の輪郭線を生成しません。前髪・後ろ髪を分け、隠れた部分にも動きの余白を残します。

## 左右と分離

左右はキャラクター自身の基準で、左は通常画面右です。`eyelash-l`、`eyelash-r`、`eyelash_left`、`왼쪽 속눈썹`、`속눈썹_우` 等が使えます。韓国語の一文字 `좌` / `우` は区切り文字か括弧が必要です。左右未指定の適格レイヤーは、生成メッシュが二つの非連結成分になる場合に分離されます。目・眉・髪・四肢等が対象になり、顔・口・口内パーツは除外されます。接触した図形や細片の多い素材は手動で分けてください。

## 数字と差分

`front hair 1` のような番号で素材を区別でき、一部の Photoshop 複製接尾辞も除去されます。番号だけで表情差分が設定されるわけではありません。表示切替にはパラメータ、択一差分には共通パラメータと異なる関連 ID を指定します。

## 未分類と確認

名前が未分類というだけで素材は破棄されません。レイヤーパネルで分類を直してください。初期姿勢・端点・眼口の開閉・遮蔽・左右・描画順・動いた時の隙間を確認します。
